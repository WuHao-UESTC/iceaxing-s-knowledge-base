# TMUX1208 5V 双向 8:1、单通道多路复用器TMUX1209 5V 双向 4:1、双通道多路复用器

## 1 特性

1• 轨至轨运行

• 双向信号路径

• 低导通电阻：5Ω

• 宽电源电压范围：1.08V 至 5.5V

• -40°C 至 +125°C 运行温度

• 兼容 1.8V 逻辑

• 失效防护逻辑

• 低电源电流：10nA

• 行业标准 TSSOP 和 QFN 封装

• 模拟和数字多路复用/多路信号分离

• HVAC：取暖、通风和空调

• 烟雾探测器

• 视频监控

• 电子销售终端

• 电池供电类设备

• 电器

• 消费类音频

## 3 说明

TMUX1208 和 TMUX1209 为通用互补金属氧化物半导体 (CMOS) 多路复用器 (MUX)。TMUX1208 提供8:1 单端通道，而 TMUX1209 提供差动 4:1 或双 4:1单端通道。1.08V 至 5.5V 的宽电源电压工作范围 可支持 的各种 应用中运行。该器件可在源极 (Sx) 和漏极(D) 引脚上支持从 GND 到 $\mathsf { V } _ { \mathsf { D D } }$ 范围的双向模拟和数字信号。

所有逻辑输入均具有兼容 1.8V 逻辑的阈值，当器件在有效电源电压范围内运行时，这些阈值可确保 TTL 和CMOS 逻辑兼容性。失效防护逻辑 电路允许在电源引脚之前的控制引脚上施加电压，从而保护器件免受潜在的损害。

导通电阻是器件源极 $( { \mathsf { S } } { \mathsf { x } } )$ 与漏极 (D) 引脚之间的欧姆电阻。导通电阻会随输入电压和电源电压变化。符号 ${ \mathsf { R } } _ { \mathsf { O N } }$ 用于表示导通电阻。测量 ${ \mathsf { R } } _ { \mathsf { O N } }$ 所用的测量设置如下所示。使用该设置测量电压 (V) 和电流 (I)，${ \mathsf { R } } _ { \mathsf { O N } }$ 的计算方法如图 7 所示，即 $\sf R _ { O N } = \sf V / \tau l _ { S D } \mathrm { : }$

## 8.1.2 关断漏电流（Off-Leakage Current）

开关处于关断状态时涉及两类漏电流：

1. 源极关断漏电流

2. 漏极关断漏电流

漏极漏电流定义为开关关断时流入或流出漏极引脚的漏电流。该电流用符号 I<sub>D(OFF)</sub> 表示。

## 8.3 特性说明

## 8.3.1 双向操作

TMUX1208 和 TMUX1209 从源极（Sx）到漏极（D）或从漏极（D）到源极（Sx）的导通性能同样出色。每个通道在两个方向上都具有非常相似的特性，并同时支持模拟信号和数字信号。

## 8.3.2 轨到轨操作

TMUX1208 和 TMUX1209 的有效信号通路输入/输出电压范围为 GND 至 $\mathsf { V } _ { \mathsf { D D } }$。

## 8.3.3 兼容 1.8 V 逻辑的输入

TMUX1208 和 TMUX1209 的所有逻辑控制输入均支持兼容 1.8 V 逻辑的控制。逻辑输入阈值随电源电压成比例变化，但在 5.5 V 电源电压下工作时仍可提供 1.8 V 逻辑控制。1.8 V 逻辑电平输入使多路复用器能够与逻辑 I/O 电源轨较低的处理器对接，无需额外的电平转换器，从而同时节省空间和 BOM 成本。有关 1.8 V 逻辑实现的更多信息，请参阅《使用 1.8V逻辑多路复用器和开关简化设计》。

## 8.3.4 失效防护逻辑

TMUX1208 和 TMUX1209 在控制输入引脚（EN、A0. A1、A2）上具有失效防护逻辑（Fail-Safe Logic），无论电源引脚处于何种状态，均可支持最高 5.5 V 的工作电压。该特性允许在电源引脚上电之前先向控制引脚施加电压，从而保护器件免受潜在损坏。失效防护逻辑无需对逻辑控制引脚进行电源时序控制，从而最大限度地降低了系统复杂度。例如，失效防护逻辑特性允许在 $\mathsf { V } _ { \mathsf { D D } } = 0 \mathsf { V } .$ 的情况下将 TMUX1208 或 TMUX1209 的选择引脚斜升到 5.5 V。此外，该特性还使多路复用器能够在 $\mathsf { V } _ { \mathsf { D D } } = 1 . 2 \mathrm { ~ V ~ }$ 下工作，同时允许选择引脚与其他器件最高 5.5 V 的逻辑电平对接。

## 8.3.5 器件功能模式

当 TMUX1208 的 EN 引脚被拉高时，根据地址线的状态，其中一个开关闭合。类似地，当 TMUX1209 的 EN 引脚被拉高时，根据地址线的状态，其中两个开关闭合。当 EN 引脚被拉低时，无论地址线处于何种状态，所有开关均处于断开状态。

## 9.1 应用信息

TMUX12xx 系列在宽工作电源范围（1.08V 至 5.5V）内可提供良好的系统性能。这些器件包含兼容 1.8V 逻辑的控制输入引脚，可在具有 1.8V I/O 电源轨的系统中工作。此外，控制输入引脚支持失效防护逻辑，无论电源引脚处于何种状态，均可支持最高 5.5V 的工作电压。该保护功能可防止逻辑引脚对电源轨反向供电。这些特性使 TMUX12xx 成为一类通用多路复用器和开关，可降低系统复杂度、电路板尺寸和整体系统成本。

## 9.2 典型应用

利用 TMUX1208 特性的一种实用应用是将各种信号多路复用至集成在 MCU 中的 ADC。与使用外部 ADC 相比，在 MCU 中使用集成 ADC 可使系统成本降至最低，但可能需要牺牲一定的系统性能。多路复用器允许使用器件的一个 ADC 引脚监测多个输入/传感器，这在 I/O 受限的系统中至关重要。TMUX1209 适用于采用差分信号的类似设计示例，或可用作两个 4:1 多路复用器。

## 10 电源建议

TMUX1208 和 TMUX1209 的工作电源范围较宽，为 1.08 V 至 5.5 V。请勿超过绝对最大额定值，因为超出所列额定值的应力可能会对器件造成永久损坏。

电源旁路可改善噪声容限，并防止开关噪声从 $\mathsf { V } _ { \mathsf { D D } }$ 电源传播到其他元件。良好的电源去耦对于实现最佳性能非常重要。为提高电源噪声抗扰度，请在 $\mathsf { V } _ { \mathsf { D D } }$ 到地之间使用 $0 . 1 ~ \mu \mathsf { F }$ 至 $\dot { 1 } 0 ~ \mu \mathsf { F }$ 的电源去耦电容。请使用低阻抗连接将旁路电容尽可能靠近器件的电源引脚放置。TI 建议使用具有低等效串联电阻 (ESR) 和低等效串联电感 (ESL) 特性的多层陶瓷片式电容 (MLCC) 进行电源去耦。对于非常敏感的系统或处于恶劣噪声环境的系统，避免使用过孔将电容连接至器件引脚可获得更出色的噪声抗扰度。并联使用多个过孔可降低整体电感，有利于与接地平面的连接。

## 11.1.1 布局信息

当 PCB 走线以 $9 0 ^ { \circ }$ 角转弯时，可能会发生反射。反射的产生主要是由于走线宽度的变化。在转弯的顶点处，走线宽度增大到原宽度的 1.414 倍。这种增大破坏了传输线特性，尤其是走线的分布电容和自感，从而导致反射。并非所有 PCB 走线都能保持直线，因此某些走线必须转弯。图 20 展示了逐步改进的圆角处理技巧。只有最后一个示例（最佳）能够保持走线宽度恒定并最大限度地减少反射。

![](images/tmux1208/c93674004fc9ce010b971ec576d2708485473fa571dfab7c6ef11747fad68570.jpg)  
图 20. 走线示例

布线高速信号时应尽量减少过孔和转角，以减少信号反射和阻抗变化。必须使用过孔时，请增大其周围的间隙尺寸以最大限度地减小其电容。每个过孔都会在信号的传输线中引入不连续点，并增加从电路板其他层拾取干扰的几率。设计测试点时请务必小心，高频下不建议使用通孔引脚。

图 21 展示了采用 TMUX1208 的 PCB 布局示例。一些关键注意事项如下：

• 使用 0.1-µF 电容对 $\mathsf { V } _ { \mathsf { D D } }$ 引脚去耦，并尽可能靠近该引脚放置。确保电容的额定电压足以满足 $\mathsf { V } _ { \mathsf { D D } }$ 电源的要求。

• 使输入走线尽可能短。

• 使用实心接地平面，以帮助减少电磁干扰 (EMI) 噪声拾取。

• 不要将敏感模拟走线与数字走线平行布置。尽可能避免数字走线与模拟走线交叉，必要时仅以垂直方式交叉。
