## 说明

ADC124S051 是一款低功耗、四通道 CMOS 12 位模数转换器，配有高速串行接口。与传统上仅在单一采样率下规定性能的做法不同，ADC124S051 在 200 ksps 至 500 ksps 的采样率范围内具有完整规格。该转换器基于逐次逼近寄存器（Successive-Approximation Register）架构，内置跟踪保持电路。可通过配置使其接受最多四路输入信号，输入为 IN1 至 IN4。

输出串行数据为直通二进制格式，并兼容多种标准，例如 SPI™、QSPI™、MICROWIRE 以及许多常见的 DSP 串行接口。

ADC124S051 采用单电源供电，电源电压范围为 +2.7V 至 +5.25V。使用 +3V 或 +5V 电源时的正常工作功耗分别为 3.0 mW 和 10.0 mW。掉电（Power-Down）功能可将功耗降至使用 +3V 电源时仅 0.14 µW，或使用 +5V 电源时 0.32 µW。

ADC124S051 采用 10 引脚 VSSOP 封装。可确保在 $\angle 4 0 ^ { \circ } \mathsf { C }$ 至 $+ 8 5 ^ { \circ } \mathsf { C }$ 的工业温度范围内工作。

## 规格定义

采集时间（ACQUISITION TIME）是采集输入电压所需的时间。也就是说，它是保持电容充电至输入电压所需的时间。

孔径延迟（APERTURE DELAY）是一次转换中第四个 SCLK 下降沿与输入信号被采集或保持以进行转换的时刻之间的时间。

转换时间（CONVERSION TIME）是在输入电压被采集之后，ADC 将输入电压转换为数字字所需的时间。

串扰（CROSSTALK）是指能量从一个通道耦合到另一个通道，或者一个模拟输入的信号能量出现在被测模拟输入端的量。

微分非线性（DNL）是相对于 1 LSB 理想步长的最大偏差的度量。

占空比（DUTY CYCLE）是重复数字波形处于高电平的时间与一个周期总时间之比。此处的规格是指 SCLK。

有效位数（ENOB，或称有效位，EFFECTIVE NUMBER OF BITS）是表征信噪失真比（SINAD）的另一种方法。ENOB 定义为 (SINAD − 1.76) / 6.02，其含义是该转换器等效于一个具有此（ENOB）位数的理想 ADC。

满功率带宽（FULL POWER BANDWIDTH）是这样一个频率的度量：对于满量程输入，重建输出的基波比其低频值下降 3 dB 时的频率。

满量程误差（FSE）是最后一个码转换距离 V<sub>REF</sub>+ 以下 1½ LSB 的理想值有多远的度量，其定义为：

V<sub>FSE</sub> = V<sub>max</sub> + 1.5 LSB – V<sub>REF</sub>+

其中

$\mathsf { V } _ { \mathsf { m a x } }$ 是发生向最大码转换时的电压。FSE 可以用伏特、LSB 或满量程范围的百分比表示。(1)

增益误差（GAIN ERROR）是在调整失调误差之后，最后一个码转换 (111...110) 至 (111...111) 相对于理想值（V<sub>REF</sub> − 1.5 LSB）的偏差。

积分非线性（INL）是每个单独码相对于一条直线的偏差的度量，该直线从负满量程（第一个码转换以下 ½ LSB）画到正满量程（最后一个码转换以上 ½ LSB）。任一给定码与该直线的偏差从该码值的中心处测量。

互调失真（IMD）是同时向 ADC 输入端施加两个正弦频率时产生额外频谱分量的现象。它定义为二阶和三阶互调产物的功率与其中一个原始频率功率之比。IMD 通常用 dB 表示。

失码（MISSING CODES）是指永远不会出现在 ADC 输出端的那些输出码。无论输入为何值都无法得到这些码。ADC124S051 保证不存在任何失码。

失调误差（OFFSET ERROR）是第一个码转换 (000...000) 至 (000...001) 相对于理想值（即 GND + 0.5 LSB）的偏差。

信噪比（SNR）是以 dB 表示的输入信号 rms 值与所有其他低于二分之一采样频率的频谱分量之和的 rms 值之比，其中不包括 d.c. 或计入 THD 的谐波。

信噪失真比（S/N+D 或 SINAD）是以 dB 表示的输入信号 rms 值与所有其他低于二分之一时钟频率的频谱分量的 rms 值之比，其中包括谐波，但不包括 d.c.。

无杂散动态范围（SFDR）是以 dB 表示的所需信号幅度与峰值杂散频谱分量幅度之差，其中杂散频谱分量是指输出频谱中存在而输入端不存在的任何信号，它可能是谐波，也可能不是。

总谐波失真（THD）是以 dB 或 dBc 表示的输出端前五个谐波分量的 rms 总和与输出端所见的输入信号频率 rms 值之比。THD 的计算公式为：

$$
\mathrm{THD} = 2 0 \cdot \log_ {1 0} {\sqrt {\frac {A _ {f 2} ^ {2} + \cdots + A _ {f 6} ^ {2}}{A _ {f 1} ^ {2}}}}
$$

其中

$\mathsf { A f } _ { 1 }$ 是输出端输入频率的 RMS 功率，并且

$\mathsf { A A f } _ { 2 }$ 至 $\mathsf { f } _ { 6 }$ 是前 5 个谐波频率的 RMS 功率。

(2)

吞吐时间（THROUGHPUT TIME）是两次连续转换开始之间所需的最短时间。它等于采集时间加上转换时间和读出时间。对于 ADC124S051，该时间为 16 个 SCLK 周期。

# 应用信息

## ADC124S051 的工作原理

ADC124S051 是一款逐次逼近型模数转换器，其设计基于电荷再分配型数模转换器。图 47 和图 48 分别给出了 ADC124S051 在跟踪模式和保持模式下的简化原理图。在图 47 中，ADC124S051 处于跟踪模式：开关 SW1 通过多路复用器将采样电容连接至四个模拟输入通道之一，SW2 使比较器输入保持平衡。在 CS 拉低后的前三个 SCLK 周期内，ADC124S051 一直处于该状态。

图 48 给出了 ADC124S051 处于保持模式的情况：开关 SW1 将采样电容连接至地，以保持采样电压，开关 SW2 使比较器失衡。随后控制逻辑指示电荷再分配 DAC 向采样电容加入固定数量的电荷，直至比较器达到平衡。当比较器平衡时，提供给 DAC 的数字字即为模拟输入电压的数字表示。在 CS 拉低后的第四个至第十六个 SCLK 周期内，ADC124S051 处于该状态。

CS 为低电平的这段时间被视为一个串行帧。每一帧应包含 16 个 SCLK 周期的整数倍，在此期间完成一次转换并在 DOUT 引脚上时钟输出，同时数据被时钟输入到 DIN 引脚，以指示下一次转换的多路复用器地址。

## ADC124S051 的使用

ADC124S051 的时序图以及 ADC124S051 的串行接口时序图见“时序图”一节。CS 为片选信号，用于启动转换并界定串行数据传输的帧。SCLK（串行时钟）同时控制转换过程和串行数据的时序。DOUT 为串行数据输出引脚，转换结果以串行数据流的形式从此引脚输出，MSB 在前。要写入 ADC124S051 控制寄存器的数据置于 DIN，即串行数据输入引脚。每次转换都会通过 DIN 向 ADC 写入新数据。

串行帧在 $\overline { { \mathsf { C S } } }$ 的下降沿开始，在 $\overline { { \mathsf { C S } } } .$ 的上升沿结束。每一帧必须包含 16 个 SCLK 上升沿的整数倍。当 CS 为高电平时，ADC 输出数据（DOUT）处于高阻态；当 CS 为低电平时，输出有效。因此，CS 起到输出使能的作用。此外，当 CS 为高电平时，以及在连续转换周期之间，器件进入掉电状态。

在 SCLK 的前 3 个周期内，ADC 处于跟踪模式，采集输入电压。在接下来的 13 个 SCLK 周期内完成转换并时钟输出数据，从第 5 个时钟开始，MSB 在前。如果一帧中包含不止一次转换，则 ADC 将在 SCLK 第 N\*16 个上升沿之后的 SCLK 下降沿重新进入跟踪模式，并在 SCLK 第 N\*16+4 个下降沿重新进入保持/转换模式，其中“N”为整数。

当 CS 拉高时，SCLK 在内部被门控关闭。如果在 CS 为高电平期间 SCLK 停止在低电平状态，则随后 CS 的下降将产生内部 SCLK 的一个下降沿，使 ADC 进入跟踪模式。ADC 将其视为 SCLK 的第一个下降沿。如果 SCLK 停止时处于高电平，则 ADC 在 CS 下降沿之后的 SCLK 第一个下降沿进入跟踪模式。

在每次转换期间，数据在 CS 下降之后 SCLK 的前 8 个上升沿通过 DIN 时钟输入 ADC。对于每一次转换，都必须时钟输入用于指示当前转换之后所选输入的数据。参见表 2、表 3 和表 4。
如果 CS 和 SCLK 在 $\mathsf { t } _ { \mathsf { C S U } }$ 和 $\mathsf { t } _ { \mathsf { C L H } } ,$ 所规定的时间内变为低电平，则开始在 DIN 上锁存数据的 SCLK 上升沿可能比预期晚一个时钟周期。因此，最好严格遵守“时序规格”中给出的最小 t<sub>CSU</sub> 和 $\mathsf { t } _ { \mathsf { C L H } }$ 时间。

ADC124S051 无需上电延迟或虚转换（dummy conversion）。ADC 在上电后即可立即对输入进行采样并完成完整转换。上电后的第一个转换结果将是 IN1 的结果。

## 数字输入和输出

ADC124S051 的数字输出 DOUT 受电源电压 $\mathsf { V } _ { \mathsf { A } }$ 限制，且不能超过该电压。数字输入引脚不易发生闩锁，并且尽管不推荐，但 SCLK、CS 和 DIN 仍可在 $\mathsf { V } _ { \mathsf { A } }$ 之前施加，而不会有任何闩锁风险。

## 电源考虑

只要 $\overline { { \mathsf { C S } } }$ 为低电平，ADC124S051 就处于完全上电状态；只要 $\overline { { \mathsf { C S } } }$ 为高电平，就处于完全关断状态，但有一个例外：在一次转换的第 16 个下降沿与随后一次转换的第 1 个下降沿之间，ADC124S051 会自动进入关断模式（见时序图）。

ADC124S051 可以连续进行多次转换；每次转换需要 16 个 SCLK 周期。只要 CS 保持低电平，ADC124S051 就会连续进行转换。

用户可以通过简单地减少单位时间内的转换次数来以吞吐量换取功耗。“典型工作特性”部分中的功耗与采样率曲线显示了 ADC124S051 的典型功耗与吞吐量的关系。要计算功耗，只需将处于正常模式的时间占比乘以正常模式功耗，再加上处于关断模式的时间占比乘以关断模式功耗。

## 电源管理

当 ADC124S051 在正常模式下连续工作时，最大吞吐量为 $\mathsf { f } _ { \mathsf { S C L K } } / 1 6 .$。可以通过让 $\mathsf { f } _ { \mathsf { S C L K } }$ 以其最大 8 MHz 运行并减少单位时间内的转换次数、在转换之间使 ADC124S051 进入关断模式，从而以吞吐量换取功耗。典型功耗与吞吐量的关系曲线见“典型工作特性”部分。要计算给定吞吐量下的功耗，请将处于正常模式的时间占比乘以正常模式功耗，再加上处于关断模式的时间占比乘以关断模式功耗。通常，用户会将器件置于正常模式，然后再将器件切回关断模式。请注意，功耗与吞吐量的曲线近似为线性。这是因为关断模式下的功耗非常小，在所有实际应用场合都可以忽略不计。

## 电源噪声注意事项

对任何输出负载电容充电都需要来自电源 $\mathsf { V } _ { \mathsf { A } } .$ 的电流。为给输出电容充电而从电源获取的电流脉冲会在电源上引起电压波动。如果这些波动足够大，就会降低 ADC 的 SNR 和 SINAD 性能。此外，当数字输出从逻辑高电平变为逻辑低电平时，输出电容放电会将电流泄放到电阻性的芯片衬底中。负载放电电流会在衬底中引起“地弹”噪声，如果该电流足够大，就会降低噪声性能。输出电容越大，流过芯片衬底的电流就越大，耦合到模拟通道中的噪声也越大，从而使噪声性能变差。

为防止噪声进入电源，应使输出负载电容尽可能小。如果负载电容大于 35 ${ \mathsf { p F } } _ { \mathrm { : } }$，请在 ADC 输出端使用一个 100 Ω 的串联电阻，并尽可能靠近 ADC 输出引脚放置。这将限制输出电容的充电和放电电流，从而保持噪声性能。
