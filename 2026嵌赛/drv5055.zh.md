## DRV5055比例式线性霍尔效应传感器

## 1 特性

• 比例式线性霍尔效应磁传感器

• 可由 3.3V 和 5V 电源供电

• 模拟输出，提供 ${ \mathsf { V } } _ { \mathsf { C } \mathsf { C } } / 2$ 静态偏移电压

• 磁性灵敏度选项 $( \mathsf { V } _ { \mathsf { C C } } = 5 \mathsf { V }$ 时）：

– A1/Z1：100mV/mT，±21mT 范围

A2/Z2：50mV/mT，±42mT 范围

A3/Z3：25mV/mT，±85mT 范围

– A4/Z4：12.5mV/mT，±169mT 范围

– A8：66mV/mT，±75mT 范围

• 高速 20kHz 检测带宽

• 低噪声输出，具有 ±1mA 驱动电流

• 磁体温度漂移补偿（针对 A 版本提供，针对 Z 版本不提供）

• 行业标准封装：

– 表面贴装 SOT-23

– 穿孔 TO-92

## 2 应用

• 工业自动化和机器人

• 家用电器

• 游戏手柄、踏板、键盘、触发器

• 高度找平、倾斜和重量测量

• 流体流速测量

• 医疗设备

• 绝对值角度编码

## 3 说明

DRV5055 是一款线性霍尔效应传感器，可按比例响应磁通量密度。该器件可用于在各种应用中进行精确的位置检测。

该器件由 3.3V 或 5V 电源供电。当不存在磁场时，模拟输出可驱动 1/2 $\mathsf { V } _ { \mathsf { C C } }$ 。输出会随施加的磁通量密度呈线性变化，多个灵敏度选项可根据所需的检测范围提供最大的输出电压摆幅。南北磁极产生唯一的电压。

该器件可检测垂直于封装顶部的磁通量，两个封装选项可提供不同的检测方向。

该器件使用比例式架构，当外部模数转换器 (ADC) 使用相同的 $\mathsf { V } _ { \mathsf { C C } }$ 作为其基准电压时，可消除 $\mathsf { V } _ { \mathsf { C C } }$ 容差产生的误差。此外，该器件具有磁体温度补偿功能，可抵消磁体漂移，在 $\scriptscriptstyle - 4 0 ^ { \circ } \mathsf C$ 至 $1 2 5 ^ { \circ } \mathrm { C }$ 的宽温度范围内实现线性性能。此外，无磁体漂移温度补偿的器件选项也可供使用。

## 6.3.2 磁响应

当 DRV5055 通电后，DRV5055 根据方程式 1 输出模拟电压：

$$
\mathrm{V} _ {\text { OUT }} = \mathrm{V} _ {\mathrm{Q}} + \mathrm{B} \times \left(\text { Sensitivity } _ {(2 5 ^ {\circ} \mathrm{C})} \times (1 + \mathrm{S} _ {\mathrm{TC}} \times (\mathrm{T} _ {\mathrm{A}} - 2 5 ^ {\circ} \mathrm{C}))\right)\tag{1}
$$

其中

${ \mathsf { V } } _ { \mathsf { Q } }$ 通常是 $\mathsf { V } _ { \mathsf { C C } }$ 的一半

• B 是施加的磁通密度

$\mathsf { S e n s i t i v i t y } _ { ( 2 5 ^ { \circ } \mathsf { C } ) }$ 取决于器件选项和 $\mathsf { V } _ { \mathsf { C C } }$

• 对于器件选项 DRV5055A1 - DRV5055A4，通常为 $0 . 1 2 \% / ^ { \circ } \mathrm { C }$ ，对于 DRV5055Z1 - DRV5055Z4 选项，通常为$0 \% 1 ^ { \circ } \mathrm { C }$

$\mathsf { T } _ { \mathsf { A } }$ 是环境温度

$\mathsf { V } _ { \mathsf { O U T } }$ 处于 $\mathsf { V } _ { \mathsf { L } }$ 范围之内

例如，假设使用 DRV5055A3， $\mathsf { V } _ { \mathsf { C C } } = 3 . 3 \mathsf { V }$ ，温度为 $5 0 ^ { \circ } \mathrm { C }$ ，施加 $6 7 \mathsf { m T }$ 0

在不考虑容差的情况下， $\mathsf { V } _ { \mathsf { O U T } } = 1 6 5 0 \mathsf { m V } + 6 7 \mathsf { m T } \times ( 1 5 \mathsf { m V } / \mathsf { m T } \times ( 1 + 0 . 0 0 1 2 / ^ { \circ } \mathsf { C } \times ( 5 0 ^ { \circ } \mathsf { C } - 2 5 ^ { \circ } \mathsf { C } ) ) ) = 2 6 8 5 \mathsf { m V } _ { \mathsf { c } }$

## 6.3.3 灵敏度线性度

当输出电压处于指定的 $\mathsf { V } _ { \mathsf { L } }$ 范围内时，该器件会产生线性响应。在该范围之外，灵敏度会降低且呈非线性。图 6-3磁响应。

![](images/drv5055/2572ace9f8328dc33a2435f441a4abb84432e1e79733944a18cb1ecf71a4e98c.jpg)

方程式 2 用于计算 $\mathsf { B } _ { \mathsf { L } }$ ，即 $\boldsymbol { 2 5 ^ { \circ } \mathrm { C } }$ 时的最小线性检测范围（考虑了最大静态电压和灵敏度容差）。

$$
B _ {L (M I N)} = \frac {V _ {L (M A X)} - V _ {Q (M A X)}}{S _ {(M A X)}}\tag{2}
$$

参数 $\mathsf { S } _ { \mathsf { L E } }$ 将线性误差定义为输出处于 $\mathsf { V } _ { \mathsf { L } }$ 范围内时任意两个正 B 值和任意两个负 B 值之间的灵敏度差异。

参数 $\mathsf { S } _ { \mathsf { S E } }$ 将对称性误差定义为输出电压处于 ${ \mathsf { V } } _ { \mathsf { L } }$ 范围内时任何正 B 值与具有相同幅度的负 B 值之间的灵敏度差异。

## 6.3.4 比例式架构

DRV5055 具有比例式模拟架构，可随电源电压线性调整静态电压和灵敏度。例如，与 $\mathsf { V } _ { \mathsf { C C } } = 5 \mathsf { V }$ 相比， $\mathsf { V } _ { \mathsf { C C } } =$ 5.25V 时静态电压和灵敏度要高 5%。当 ADC 使用 $\mathsf { V } _ { \mathsf { C C } }$ 作为其基准时，无论电源电压容差如何，该行为都使外部ADC 能够数字化一致的值。

方程式 3 计算灵敏度比例式误差：

$$
S _ {R E} = 1 - \frac {S _ {(V C C)} / S _ {(5 V)}}{V _ {C C} / 5 V} \text {for} V _ {C C} = 4. 5 \mathrm{Vto} 5. 5 \mathrm{V}, \quad S _ {R E} = 1 - \frac {S _ {(V C C)} / S _ {(3 . 3 V)}}{V _ {C C} / 3 . 3 V} \text {for} V _ {C C} = 3 \mathrm{Vto} 3. 6 3 \mathrm{V}\tag{3}
$$

其中

$\mathsf { S } _ { \mathsf { ( V C C ) } }$ 是当前 $\mathsf { V } _ { \mathsf { C C } }$ 电压下的灵敏度

$\mathsf { S } _ { ( 5 \mathsf { V } ) }$ 或 $\mathsf { S } _ { ( 3 . 3 \mathsf { V } ) }$ 是 $\mathsf { V } _ { \mathsf { C C } } = 5 \mathsf { V }$ 或 3.3V 时的灵敏度

$\mathsf { V } _ { \mathsf { C C } }$ 是当前的 $\mathsf { V } _ { \mathsf { C C } }$ 电压

方程式 4 计算静态电压比例式误差：

$$
V _ {Q R E} = 1 - \frac {V _ {Q (V C C)} / V _ {Q (5 V)}}{V _ {C C} / 5 V} \text {for} V _ {C C} = 4. 5 \mathrm{Vto} 5. 5 \mathrm{V}, \quad V _ {Q R E} = 1 - \frac {V _ {Q (V C C)} / V _ {Q (3 . 3 V)}}{V _ {C C} / 3 . 3 V} \text {for} V _ {C C} = 3 \mathrm{Vto} 3. 6 3 \mathrm{V}\tag{4}
$$

其中

$\mathsf { V } _ { \mathsf { Q } ( \mathsf { V } \mathsf { C } \mathsf { C } ) }$ 是当前 $\mathsf { V } _ { \mathsf { C C } }$ 电压下的静态电压

• $V _ { \sf Q ( 5 V ) }$ 或 $\mathsf { V } _ { \mathsf { Q } ( 3 . 3 \mathsf { V } ) }$ 是 $\mathsf { V } _ { \mathsf { C C } } = 5 \mathsf { V }$ 或 3.3V 时的静态电压

• $\mathsf { V } _ { \mathsf { C C } }$ 是当前的 $\mathsf { V } _ { \mathsf { C C } }$ 电压

## 6.3.5 工作 $v _ { c c }$ 范围

## 6.3.6 磁体的灵敏度温度补偿

## 7.1 应用信息

## 7.1.1 选择灵敏度选项

选择可测量所需磁通密度范围的最高 DRV5055 灵敏度选项，从而尽可能地扩大输出电压摆幅。

与距离很近的极小磁体相比，尺寸更大的磁体和距离更远的感应距离通常可以实现更好的位置精度，因为磁通密度随着磁体的接近而呈指数级增长。TI 在 https://www.ti.com/product/drv5013 上创建了一个在线工具来帮助进行简单的磁体计算。

## 7.1.2 磁体的温度补偿

DRV5055 温度补偿旨在直接补偿钕 (NdFeB) 磁体的平均漂移并部分补偿铁氧体磁体。磁体的剩余感应 $( \mathsf { B } _ { \mathsf { r } } )$ 对于NdFeB 通常降低 0.12%/°C，对于铁氧体通常降低 $0 . 2 0 \% / ^ { \circ } \mathrm { C }$ 。当系统的工作温度降低时，温漂误差也会降低。

## 7.1.3 添加一个低通滤波器

如功能方框图中所示，当不需要完整的 20kHz 带宽时，可以将一个 RC 低通滤波器添加到器件输出端以最大限度地减小电压噪声。该滤波器可以提高信噪比 (SNR) 和整体精度。请勿在中间没有电阻器的情况下将电容器直接连接到器件输出端，因为这样做会使输出不稳定。

## 7.1.4 断线检测设计

一些系统必须检测互连导线是否开路或短路。DRV5055 支持该功能。

首先，选择一个灵敏度选项，使输出电压在正常操作期间保持在 $\mathsf { V } _ { \mathsf { L } }$ 范围内。接下来在 OUT 和 $\mathsf { V } _ { \mathsf { C C } }$ 之间添加一个上拉电阻器。TI 建议采用介于 20kΩ 和 100kΩ 之间的值，并且流经 OUT 的电流不得超过 $\mathsf { I } _ { 0 }$ 规格，包括进入外部 ADC 的电流。然后，如果测得的输出电压处于 $\mathsf { V } _ { \mathsf { C C } }$ 或 GND 的 150mV 范围以内，则存在故障情况。图 7-1 展示了该电路，表 7-1 说明了故障情况。

## 7.2.2 详细设计过程

线性霍尔效应传感器有助于实现灵活的机械设计，因为许多可能的磁体方向和运动会产生可用的传感器响应。图7-2 展示了最常见的方向之一，它使用传感器的整个北到南范围，在磁体移动时使磁通密度发生接近线性的变化。

在设计线性磁感应系统时，始终考虑以下三个变量：磁体、感应距离和传感器范围。选择灵敏度最高的DRV5055，其 $\mathsf { B } _ { \mathsf { L } }$ （线性磁感应范围）大于应用中的最大磁通密度。要确定传感器接收到的磁通密度，TI 建议使用磁场仿真软件，参考磁体规格并进行测试。
