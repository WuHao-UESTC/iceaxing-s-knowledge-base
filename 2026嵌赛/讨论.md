# 概念梳理

## 1. 从电子、信号的角度，如何实现多种不同的音色

### 核心结论

音高主要由周期信号的基频决定，而音色主要由以下因素共同决定：

- **频谱结构**：基频及各次谐波的相对幅度、相位。不同波形本质上是在改变频谱。
- **时间包络**：声音的起音、衰减、持续和释放过程（常用 ADSR 描述）。
- **动态与非线性**：力度变化、饱和、削波、失真会产生新的谐波。
- **噪声和瞬态**：击打、摩擦、气流等非周期成分决定声音的质感和起音特征。
- **空间特征**：混响、延时、左右声道差异会改变听感，但它们更多改变的是声音所处的空间。

因此，“做出不同音色”就是让输出信号在频域、时域或动态特性上产生可听的差异。

### 典型电子信号链

```text
振荡器/采样源 -> 混合 -> 包络控制 -> 滤波器 -> 放大器/VCA -> 非线性处理 -> 空间效果 -> 功放/扬声器
```

#### 1. 选择或生成不同的基础波形

- **正弦波**：只有基频，声音纯净、单薄。
- **方波**：含较强的奇次谐波，声音明亮、空洞。
- **锯齿波**：含丰富的整数次谐波，声音明亮、尖锐。
- **三角波**：以较弱的奇次谐波为主，声音比方波柔和。
- **脉冲波**：通过改变占空比改变谐波比例，可连续改变音色。
- **噪声或采样**：适合模拟鼓、风声、摩擦声等非周期声音。

模拟电路中可用 RC/LC 振荡器、比较器、积分器等产生这些波形；数字系统中通常用 DDS、查表（wavetable）或采样回放产生。

#### 2. 用滤波器重塑频谱

滤波器不一定改变基频，而是选择性地衰减或保留某些频率成分：

- **低通**：削弱高频，使声音变暗、变圆；
- **高通**：削弱低频，使声音变薄、变轻；
- **带通/峰值滤波**：突出某一频段，形成共鸣或“鼻音”；
- **陷波**：抑制特定频率。

截止频率、斜率和 Q 值（共振程度）决定滤波后的音色。让包络或低频振荡器（LFO）随时间调制截止频率，可以得到扫频、wah-wah 等动态音色。

#### 3. 改变时间包络和力度响应

同一波形，如果起音和衰减不同，听起来也会像不同乐器。用包络发生器控制 VCA 增益或滤波器截止频率：

- 短起音、快速衰减：打击乐感；
- 慢起音、长释放：弦乐或铺底感；
- 起音时先提高高频，再快速关闭：更像拨弦或敲击。

键盘力度、传感器信号或 MIDI velocity 还可以映射到音量、滤波器、失真量等参数，使音色随演奏变化。

#### 4. 叠加、调制与产生新谐波

- **加法合成**：叠加多个不同频率和幅度的正弦波，直接构造目标频谱。
- **减法合成**：先产生含丰富谐波的波形，再用滤波器削减频谱。
- **AM/RM（幅度调制/环形调制）**：产生和频、差频，适合金属感、钟声。
- **FM（频率调制）**：用一个振荡器调制另一个振荡器的频率，调制指数越大，产生的边带越多，音色越复杂。
- **失真/饱和/削波**：非线性电路把原有波形变形，生成新的谐波，可得到温暖、粗糙或强烈的声音。

#### 5. 加入噪声、瞬态和反馈

把白噪声、粉红噪声或短促脉冲与周期波形混合，可以模拟拨弦、气息、鼓槌和机械冲击。延迟反馈、梳状滤波和物理建模还可以模拟琴弦、管腔等共振结构。

### 一个具体例子：从锯齿波得到“明亮”和“柔和”两种音色

1. 振荡器产生同一个锯齿波，保证音高相同。
2. **明亮音色**：滤波器截止频率较高，保留更多高次谐波；起音时提高截止频率，并加入少量饱和。
3. **柔和音色**：使用较低截止频率的低通滤波器，降低共振和高频谐波；包络起音、释放更缓慢。
4. 若再加入短延时或混响，两者会获得不同的空间听感。

### 工程上需要注意

- 扬声器、功放和房间的频响也会改变最终音色，所以“合成出的信号”和“听到的声音”并不完全相同。
- 数字实现要注意采样率和抗混叠；波形中的高次谐波超过奈奎斯特频率时会折叠成非预期的杂音。
- 评价音色不能只看频谱幅度，还要看随时间变化的频谱、包络和动态响应。

## 2. 几种常见的音频合成算法

这里的“播表采样”通常指 **波表（Wavetable）合成/波表采样**。它和“把一段录音直接播放出来”的采样器不同：波表通常只保存一个周期或少量短波形，通过周期循环和参数控制生成持续声音；采样器则回放完整录音，细节更真实，但可变性较低。

### 2.1 波表合成（Wavetable Synthesis）

#### 基本思想

预先存储一张或多张波形表，运行时以不同速度读取表中的样本。若表中是一个周期的波形，就可以通过循环读取产生任意音高。

设波表长度为 `L`，采样率为 `Fs`，目标频率为 `f`，相位累加器每个采样点增加：

```text
phase += f * L / Fs
index = phase 的整数部分
y[n] = wavetable[index]
```

实际系统通常使用定点相位累加器，例如 N 位相位：

```text
phase += frequency_word
index = phase 的高若干位
```

这样可以高效地产生任意频率，而且频率分辨率与波表长度不必绑定。

#### 插值与抗混叠

相位通常落在两个表项之间，因此需要插值：

- **最近邻读取**：计算量最小，但音高较高时容易产生量化噪声和杂散。
- **线性插值**：在相邻表项之间按小数相位加权，音质和计算量较均衡。
- **高阶插值**：质量更好，但 MCU 运算量更高。

一个固定波表含有的谐波可能超过当前采样率允许的范围。高音播放时，这些谐波会混叠到低频，产生刺耳的非谐波杂音。常见处理方法是为不同音高准备不同带宽的波表（multi-table、band-limited wavetable 或 mipmap），音高越高就选择高频谐波越少的表。

#### 波表扫描

如果不是只有一张表，而是沿着多个波形之间的位置连续扫描，就能让音色随时间变化：

```text
table_position = table_position + scan_speed
sample = 在相邻两张波表之间插值
```

例如按“正弦 -> 三角 -> 锯齿 -> 脉冲”顺序扫描，会得到连续变化的谐波结构。扫描位置可以由包络、LFO、键盘力度或演奏控制器驱动。

#### 优缺点和适用场景

- **优点**：音色查找快，CPU 占用低；可以保存复杂的单周期波形；适合嵌入式乐器、游戏音效和虚拟模拟振荡器。
- **缺点**：循环周期内的细节有限；若没有带限处理，高音容易混叠；很难自然表现弦、膜、管等强烈的物理变化。
- **适合**：需要低延迟、低算力，同时又希望比正弦/方波拥有更丰富音色的场景。

### 2.2 加法合成（Additive Synthesis）

#### 基本思想

任何周期信号都可以分解为基频及其谐波的叠加。根据傅里叶级数，一个声音可以近似写成：

```text
y(t) = A0 + Σ Ak * sin(2π * k * f0 * t + φk)
```

其中：

- `f0` 是基频，决定音高；
- `k * f0` 是第 k 个谐波；
- `Ak` 决定该谐波的响度，决定频谱形状；
- `φk` 是相位，影响瞬态、波形形状和多个分量叠加后的细节。

方波、锯齿波、管风琴音色都可以看作许多正弦振荡器的组合。例如理想方波主要由奇次谐波构成，而锯齿波包含强度逐渐下降的整数次谐波。

#### 实现方式

为每个谐波维护一个相位累加器和幅度：

```text
for each partial k:
    phase[k] += 2π * frequency[k] / Fs
    y += amplitude[k] * sin(phase[k])
```

为了节省计算量，正弦函数通常使用查表、递推振荡器或硬件 DSP 指令。声音开始和结束时，再让每个分量的幅度乘以包络；也可以让高次谐波的包络更短，从而模拟真实乐器起音时“先亮后暗”的特性。

#### 音色控制

加法合成的优势是参数与频谱对应得很直接：

- 增大高次谐波幅度，声音更明亮；
- 减少高次谐波，声音更柔和；
- 在非整数倍频率处加入分量，可以制造不谐和、金属或钟声效果；
- 让每个分量有独立的包络，可以模拟复杂的频谱随时间变化。

#### 优缺点和适用场景

- **优点**：控制精确、可解释性强，能够直接设计目标频谱。
- **缺点**：分量数量越多，CPU 和内存开销越大；要做出真实乐器，必须同时管理大量分量及其时间变化。
- **适合**：管风琴、钟声、频谱实验、教育演示，以及需要精确控制谐波的声音。

### 2.3 FM 调频合成（Frequency Modulation）

#### 基本模型

FM 合成不是直接把两个声音相加，而是用一个调制信号改变另一个振荡器的瞬时频率：

```text
x(t) = Ac * sin(2π * fc * t + I * sin(2π * fm * t))
```

- `fc`：载波频率（carrier），通常决定主要音高；
- `fm`：调制频率（modulator）；
- `I`：调制指数，决定频率偏移的大小和音色复杂度；
- `Ac`：载波幅度。

调制器输出也可以使用包络控制，典型做法是起音时 `I` 较大、随后减小，使声音先明亮后变柔和。

#### 频谱结果

FM 会在载波频率两侧产生一组边带，频率近似为：

```text
fc ± n * fm       (n = 1, 2, 3, ...)
```

调制指数越大，边带数量通常越多，音色越复杂、越明亮；调制器与载波的频率比决定边带是否呈现谐和关系：

- `fm/fc` 为简单整数比：容易得到有明确音高的乐器音色；
- 复杂整数比或非整数比：更容易得到金属、铃声、机械等不谐和音色。

多个调制器串联或并联，就形成 FM 算法中的 operator 网络。经典数字合成器常用 4 或 6 个 operator，通过不同的算法连接方式得到钢琴、钟声、铜管等音色。

#### 计算实现

每个 operator 本质上只需一个相位累加器和一个正弦查表：

```text
mod = modulator_amplitude * sin(modulator_phase)
carrier_phase += carrier_step + mod
out = carrier_amplitude * sin(carrier_phase)
```

注意这里的 `mod` 是相位偏移量，实际代码需要根据相位单位进行缩放。使用相位调制（PM）实现时，结构与 FM 很接近，数字系统中通常更容易保持稳定。

#### 优缺点和适用场景

- **优点**：用很少的振荡器就能产生大量边带；计算效率高；非常适合表现有明确谐波关系或金属质感的声音。
- **缺点**：参数和听感不是线性对应，调音门槛较高；调制指数过大或频率过高时容易混叠。
- **适合**：电钢琴、钟声、金属打击乐、数字感较强的贝斯和特效。

### 2.4 物理建模合成（Physical Modeling）

#### 基本思想

物理建模不是先存一段声音，而是近似描述乐器的发声机制，例如：

```text
激励源 -> 传播/延迟 -> 共振结构 -> 输出
```

激励源可以是拨弦脉冲、弓摩擦、气流脉冲或鼓槌冲击；传播部分描述波在弦、管或膜中的运动；共振结构描述琴体、管腔或箱体对频率的选择性放大。

#### Karplus-Strong：最简单的拨弦模型

Karplus-Strong 用一段短噪声初始化延迟线，然后循环反馈，并通过低通滤波器逐渐损失高频能量：

```text
buffer <- 短噪声或脉冲
loop:
    y[n] = 0.5 * (buffer[i] + buffer[(i + 1) % L])
    buffer[i] = feedback * y[n]
```

延迟线长度 `L` 主要决定基频，近似关系是 `f0 ≈ Fs / L`；低通滤波器和反馈系数决定衰减速度与音色。通过改变延迟长度、滤波器、激励噪声和反馈，可以模拟不同弦长、拨弦位置和材料。

#### 数字波导（Digital Waveguide）

数字波导把连续介质中的传播过程离散成延迟线和滤波器。弦乐器可用一条或两条传播方向相反的延迟线，加上端点反射滤波器；管乐器则可加入唇簧/簧片的非线性激励和管口辐射滤波器。

典型组成包括：

- 延迟线：决定传播时间和音高；
- 反射系数：决定能量损失和衰减；
- 低通或频率相关滤波器：模拟材料损耗；
- 非线性元件：模拟簧片、弓弦接触、嘴唇等；
- 辐射滤波器：模拟声音从乐器传播到空气的过程。

#### 优缺点和适用场景

- **优点**：参数具有物理意义，力度、弦长、材料等变化可以自然地影响声音；生成声音所需存储空间小，适合实时交互。
- **缺点**：模型建立和调参复杂；模型不准确时会有“像某种乐器但不完全像”的听感；非线性求解可能增加 CPU 负担。
- **适合**：弦乐、管乐、打击乐、交互式虚拟乐器，以及需要连续改变演奏方式的系统。

### 2.5 直接采样回放（Sample Playback）作为对照

直接采样回放会存储完整的真实演奏波形，播放时进行变速、移调、循环和包络处理。它不是严格意义上的“从零合成”，但在追求真实度时非常有效。

- **优点**：真实度高，复杂瞬态和演奏细节可以被完整保留。
- **缺点**：占用 Flash/RAM 大；移调幅度过大时音质下降；难以连续改变力度、弓速、气流等物理参数；循环点处理不好会有接缝。
- **常见改进**：多力度采样、多麦克风/多关节采样、循环区间、交叉淡化、时间伸缩和颗粒化处理。

### 2.6 方法对比

| 方法 | 核心资源 | 音色可控性 | 真实度 | 计算量 | 存储量 | 典型用途 |
|---|---|---:|---:|---:|---:|---|
| 波表 | 单周期或多张短波形 | 中高 | 中 | 低 | 低 | 虚拟模拟、游戏音效、嵌入式合成 |
| 加法 | 大量正弦分量 | 很高 | 取决于模型 | 中高 | 低 | 管风琴、钟声、频谱设计 |
| FM | operator 和调制指数 | 高但较难调 | 中高 | 低中 | 低 | 电钢琴、金属和数字音色 |
| 物理建模 | 延迟线、滤波器、非线性模型 | 很高且有物理意义 | 高（模型准确时） | 中高 | 很低 | 弦乐、管乐、交互式乐器 |
| 直接采样 | 完整录音 | 低中 | 很高 | 低中 | 高 | 钢琴、管弦乐、拟真音源 |

### 2.7 在嵌入式系统中的选型思路

1. **CPU 很紧张、需要多声部**：优先考虑带限波表或简单 FM。
2. **需要精确控制谐波**：选加法合成，但限制谐波数量并使用正弦查表。
3. **需要随演奏连续改变弦长、力度、拨弦方式**：选物理建模。
4. **目标是尽可能还原真实乐器**：选采样回放，配合多力度采样和合理循环。
5. **实际产品常用混合架构**：例如“采样瞬态 + 波表持续音 + 物理建模共鸣 + 混响”，兼顾真实度、可控性和资源占用。

无论选哪种算法，都要检查相位累加精度、插值误差、滤波器稳定性、动态范围、过采样/抗混叠和多声部资源调度。这些实现细节往往比算法名称本身更决定最终听感。

## 3. 电钢琴如何根据按压力度产生不同音量

这里要先区分两类“电钢琴”：

- **电声钢琴**，如 Rhodes、Wurlitzer：按键带动槌头敲击金属簧片或音叉，拾音器把机械振动转换成电信号。按得越快，槌头初速度越大，通常输出越响，同时频谱也会变化。
- **数字电钢琴**：没有真正的弦或簧片，使用传感器测量按键动作速度，再用这个速度控制采样或合成器的音量、音色和起音方式。

### 3.1 数字电钢琴真正测量的不是“压力”，而是“按键速度”

一次按键通常有两个或三个检测点：

```text
按键静止 -> 经过第一个传感器 -> 经过第二个传感器/触底 -> 发出 Note On
```

设两个传感器之间的距离为 `d`，触发时间分别为 `t1` 和 `t2`，则按键速度近似为：

```text
v = d / (t2 - t1)
```

`t2 - t1` 越短，说明按键移动得越快，演奏力度越大。键盘控制器通常把这个速度转换成 MIDI velocity，范围为 `1~127`：

- `1` 附近：极轻触键；
- `60~80`：中等力度；
- `127`：最大力度。

因此，手指按得更深但速度很慢，并不一定被判定为大力度；系统主要关心从第一个检测点到第二个检测点的运动速度。按键松开则由释放开关检测，并产生 Note Off。

### 3.2 常见传感器结构

#### 双触点开关

最常见、成本较低的方案是在键下放置两个橡胶导电触点。控制器记录两个触点闭合的时间差，再计算 velocity。

- 优点：电路简单、成本低、功耗小；
- 缺点：机械触点会抖动，速度分辨率和重复性受结构影响；
- 处理：需要硬件或软件消抖，并对时间差设置上下限。

#### 光学传感器

用遮光片和红外发光器/接收器检测键的位置，连续测量或检测多个位置。

- 能测出更连续的位移和速度；
- 没有机械触点磨损，重复性较好；
- 需要处理环境光、发光器老化和传感器一致性。

#### 霍尔传感器或磁传感器

在琴键上安装磁铁，通过霍尔元件输出随位置变化的电压，再由 ADC 采样。这样可以估计完整的位移曲线、速度和释放速度，但硬件成本与校准工作更高。

### 3.3 从 velocity 到音量的映射

传感器得到的速度不能直接当作线性音量。因为人耳对响度的感知近似对数关系，而且琴键机械动作和扬声器声压也不是理想线性关系。常用做法是先归一化：

```text
x = (velocity - 1) / 126
```

再通过力度曲线映射到振幅：

```text
amplitude = x^γ
```

- `γ > 1`：轻按时更容易得到小音量，适合手感偏“重”的键盘；
- `γ < 1`：轻按也能获得较大音量，适合手感偏“灵敏”的键盘；
- 实际产品常使用分段曲线或查表，以便调出不同的键盘手感。

如果要用分贝表示，可以先计算增益：

```text
gain_dB = min_dB + x * (max_dB - min_dB)
amplitude = 10^(gain_dB / 20)
```

例如把最小力度映射到 `-60 dB`、最大力度映射到 `0 dB`，再在中间使用非线性曲线，就比简单的 `amplitude = x` 更符合听感。

### 3.4 不只是音量，力度还会改变音色

真实钢琴强弹时，槌头与弦的碰撞更剧烈，激发更多高次谐波和瞬态。因此数字电钢琴通常同时控制多个参数：

1. **振幅**：velocity 越大，Note On 的初始增益越高。
2. **起音包络**：强弹时攻击段可能更短，瞬态更突出。
3. **滤波器**：强弹时提高低通滤波器截止频率，保留更多高频，使声音更亮。
4. **采样层**：把 `velocity` 分成多个区间，分别播放轻奏、中奏、强奏采样，避免单纯放大一个样本导致声音不自然。
5. **失真或饱和量**：模拟 Rhodes 等电声钢琴时，强弹可产生更明显的饱和和非线性。

因此“力度响应”通常是“音量 + 频谱 + 包络”的联合控制，而不是一个简单的音量旋钮。

### 3.5 数字电钢琴的一条典型处理链

```text
传感器 -> 定时器捕获 t1/t2 -> 计算 velocity -> 力度曲线/校准
       -> 选择采样层或合成参数 -> 包络和增益控制 -> 混音 -> DAC/功放
```

伪代码可以写成：

```text
on_first_contact(key):
    t1[key] = timer_now()

on_second_contact(key):
    dt = timer_now() - t1[key]
    velocity = clamp(K / dt, 1, 127)
    level = velocity_curve[velocity]
    layer = choose_sample_layer(velocity)
    start_voice(key, layer, level)
```

其中 `K` 由传感器间距、定时器单位和机械结构决定。工程上一般先实测大量按键动作，把时间差转换为 velocity 查表，而不是完全依赖理想公式。

### 3.6 真实电声钢琴为什么也会有力度变化

以 Rhodes 为例，按键带动槌头敲击金属音叉，音叉的振动幅度与槌头速度有关。电磁拾音器输出的感应电压随振动速度和幅度变化，所以强弹时电信号自然更大；同时槌头冲击位置、接触非线性和磁拾音器响应会改变谐波结构。这种“机械激励 -> 共振体 -> 拾音器”的链路本身就产生了力度与音色的耦合。

数字电钢琴需要通过传感器、力度曲线、分层采样或合成模型，去近似这种耦合关系。

### 3.7 工程实现中的关键问题

- **消抖**：机械触点可能在几毫秒内多次开合，必须避免一次按键被识别成多次触发。
- **定时精度**：两个触点的时间差可能只有几毫秒，定时器分辨率应明显高于这个量级。
- **最小/最大速度限制**：过慢或过快的异常时间差要限幅，否则会得到无效 velocity。
- **键间校准**：不同琴键的弹簧、摩擦和传感器位置不同，需要校正，使相同力度产生相近 velocity。
- **延迟**：从第二触点确认到声音开始的路径应尽量短，否则会感觉按键“粘滞”。
- **释放速度**：部分高级系统还测量松键速度，用于控制消音、踏板共鸣或释放噪声。
- **不要把 aftertouch 混淆为 velocity**：velocity 是按下瞬间的速度；aftertouch 是按住之后继续施加压力产生的控制量，两者作用时间不同。

## 4. 音乐领域中的“表情维度”是什么

“音乐表情”指演奏者在不改变或基本不改变乐曲音符本身的情况下，通过控制声音的各种属性来表现力度、情绪、语气和乐句。它不是一个单独的参数，而是一组随时间变化的控制维度。

可以把一个音的听感粗略表示为：

```text
音符 = 音高（Pitch） + 时值/时刻（Time） + 音色（Timbre） + 表情控制（Expression）
```

### 4.1 主要表情维度

#### 1. 动态：声音有多强

包括音量、声压和力度变化，是最直观的表情维度。

- 单音的强弱：轻触、重击；
- 乐句内的渐强（crescendo）和渐弱（diminuendo）；
- 重音、突强、回落等局部变化。

在数字系统中，通常映射到振幅、VCA 增益或 MIDI velocity/CC。真实乐器中，强弱还会联动改变频谱和起音，不能只做简单的线性放大。

#### 2. 音色：声音具有什么质感

音色包含频谱、谐波比例、噪声比例、瞬态和非线性等特征。演奏者可以通过触弦/击键位置、吹气方式、拨弦角度、力度和发音部位改变音色。

电子合成器中常见的对应参数有：

- 滤波器截止频率和共振；
- 波表位置或振荡器波形；
- FM 调制指数；
- 噪声混合比例；
- 失真、饱和和反馈量。

因此“强弹更亮”是动态和音色的联动，而不仅是音量变大。

#### 3. 时间：音符如何进入、持续和离开

时间维度包括起音时刻、时值、间隔、速度变化和包络形状：

- **起音（attack）**：突然进入还是渐入；
- **持续（sustain）**：声音是否稳定、是否有周期性波动；
- **释放（release）**：松键后立即停止还是自然衰减；
- **节奏微偏差**：提前、延后、抢拍、拖拍；
- **rubato**：乐句内部有意改变速度。

同样的音符和音量，起音提前几毫秒、释放延长一倍，听起来就可能完全不同。数字乐器通常用 ADSR、分段包络、延音踏板和量化/非量化时序实现这些控制。

#### 4. 发音方式与关节：音符之间如何连接

这通常称为 articulation，包括：

- **连奏（legato）**：相邻音之间平滑连接；
- **断奏（staccato）**：短促、音符之间留空；
- **跳音、重音、顿音**：改变起音瞬态和时值；
- **滑音（glissando/portamento）**：音高在两个音之间连续移动；
- **重复音的重新起音**：每个音是否都有独立的攻击瞬态。

在合成器中，legato 可能意味着不重新触发包络、只改变振荡器频率；staccato 则使用更短的 gate 和 release；portamento 通过连续改变振荡器频率实现。

#### 5. 音高相关表情：音高如何变化

除了离散音符的基本音高，还包括：

- 颤音（vibrato）：围绕目标音高周期性摆动；
- 推弦、滑音和弯音（pitch bend）；
- 音准微调和音律偏差；
- 和弦内音的微小音高错位。

颤音通常由低频振荡器调制音高，速度和深度分别控制摆动频率与幅度。弯音则可以由触摸条、摇杆、MIDI Pitch Bend 或连续位置传感器控制。

#### 6. 空间：声音位于什么位置、距离和环境中

空间表情包括声像、深度、宽度和混响：

- 左右声道位置（pan）；
- 直达声与混响声的比例，影响远近感；
- 延时、早期反射和混响时间，影响空间大小；
- 立体声宽度、双耳差异和移动声像。

它通常不改变音符本身，但会显著改变音乐的情绪、层次和现场感。

#### 7. 噪声与发音细节：声音是否带有“动作痕迹”

真实演奏包含手指落键、琴槌、拨片、弓毛、气流和摩擦等细节。这些成分往往持续时间短，却对“像不像真实演奏”非常重要。

数字乐器可以把它们作为独立的噪声层或瞬态采样，并用 velocity、release velocity、键位和 articulation 触发。

### 4.2 表情维度与音乐参数的关系

| 表情维度 | 主要听觉结果 | 常见电子控制参数 |
|---|---|---|
| 动态 | 强弱、重音、渐强渐弱 | velocity、CC11、振幅包络、VCA |
| 音色 | 明亮/暗、厚/薄、粗糙/纯净 | 滤波器、波表位置、FM 指数、失真 |
| 时间 | 起音、衰减、释放、律动 | gate、ADSR、Note On/Off 时刻、rubato |
| 发音方式 | 连奏、断奏、滑音、重击 | legato、trigger mode、portamento、release |
| 音高 | 颤音、弯音、音准变化 | Pitch Bend、LFO、连续音高控制 |
| 空间 | 位置、距离、宽度、环境 | pan、delay、reverb、声道增益 |
| 发音细节 | 真实感、触感、动作噪声 | attack/release sample、噪声层、键位映射 |

### 4.3 不同控制器能表达哪些维度

传统 MIDI 键盘的控制能力有限，但已经能表达一部分表情：

- **Velocity**：按下瞬间的力度，主要控制动态和起音音色；
- **Aftertouch**：按住后继续施压，常控制滤波器、颤音深度或音量；
- **Pitch Bend**：连续改变音高；
- **Modulation Wheel/CC**：常控制颤音、滤波器或混响量；
- **Sustain Pedal**：延长释放、改变共鸣和踏板噪声。

MPE（MIDI Polyphonic Expression）则可以让每个音符分别拥有独立的按键压力、横向滑动和音高变化，从而同时控制：

```text
按下速度 -> 动态/起音
按住压力 -> 持续音量或音色
横向滑动 -> 每个音符独立的音色变化
纵向滑动 -> 每个音符独立的音高变化
```

### 4.4 为什么表情通常是“耦合”的

真实乐器中，一个动作往往同时改变多个声学变量。例如钢琴强弹会同时带来：

```text
槌头速度增加 -> 振幅增加 + 高频谐波增加 + 起音瞬态更强
```

如果数字乐器只把 velocity 映射到音量，声音会像“同一个样本被放大”，缺乏真实感。更自然的做法是建立多个联动映射：

```text
velocity -> 振幅、滤波器截止频率、攻击时间、采样层、瞬态噪声比例
aftertouch -> 持续音量、颤音深度、共鸣或滤波器
release velocity -> 释放噪声、消音速度、尾音长度
```

### 4.5 一个实用的理解框架

分析一段演奏时，可以连续问六个问题：

1. 这个音有多强？（动态）
2. 这个音有多亮、厚、粗糙或纯净？（音色）
3. 它什么时候开始、持续多久、如何结束？（时间）
4. 它和前后音是连的还是断的？（发音方式）
5. 音高是否有颤动、滑动或偏移？（音高表情）
6. 它在空间中的位置和距离如何？（空间）

这六类维度基本覆盖了电子乐器设计、音源制作和演奏分析中最常见的“音乐表情”。
