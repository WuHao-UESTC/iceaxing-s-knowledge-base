# ILETS备考
## 考试大纲与备考方式
### Volcabulary
1. 每天150个左右的新单词（IELTS 与 GRE 同步）
2. 单词学习流程：背新单词 -> 复习旧单词 -> 过所有已经学的单词
3. 需要注意的内容：发音，拼写，3s内想不出意思的单词就是不会
### Listening
1. 技巧：看懂选项，翻译出来 并记忆；放无用信息的时候提前看题目
2. 专项训练：看懂题目，翻译并记忆的能力
3. 注意事项：确定题型‘
4. 练习方式：先做一套题目 -> 错题收集 -> 精听练习
### Reading
1. 技巧：先读选项再读题；不要纠结not given
2. 核心：意思读懂，语法拆解看懂
3. 练习方式： 做题 -> 复盘（以语法/句意分析为主）
### Writing 
1. 练习方式：写作 -> AI批改 -> 老师批改
2. 注意事项：尽早练习，注意语法错误
### Speaking
1. 练习方式：研究题库，与AI对话
## 备考计划
**周期：以一周为一个周期，一周完成三套雅思真题的练习，每天三个小时**
1. 周一：背单词，听力加写作
2. 周二：背单词，阅读加口语
3. 周三：背单词，听力加写作
4. 周四：背单词，阅读加口语
5. 周五：背单词，听力加写作
6. 周六：背单词，阅读加口语
7. 周日：背单词，复盘
