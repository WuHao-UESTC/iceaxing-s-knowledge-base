### 阈值电压
- [[C2.MOS器件物理基础#2.2.1 阈值电压|Razavi: $V_{TH}$ 公式、耗尽→反型、掺杂调整]]
- $V_{TH} = \Phi_{MS} + 2\Phi_F + Q_{dep}/C_{ox}$
- → 体效应：$V_{TH} = V_{TH0} + \gamma(\sqrt{2\Phi_F + V_{SB}} - \sqrt{|2\Phi_F|})$

### I/V 特性（三极管区与饱和区）
- [[C2.MOS器件物理基础#2.2.2 I/V 特性推导|Razavi: 三极管区 → 饱和区 I/V 推导、平方律]]
- 三极管区：$I_D = \mu_n C_{ox} \frac{W}{L}[(V_{GS}-V_{TH})V_{DS} - \frac{1}{2}V_{DS}^2]$
- 深三极管区：$R_{on} = [\mu_n C_{ox} \frac{W}{L}(V_{GS}-V_{TH})]^{-1}$，压控电阻
- 饱和区 (平方律)：$I_D = \frac{1}{2}\mu_n C_{ox} \frac{W}{L}(V_{GS}-V_{TH})^2$
- ⚡ $V_{D,sat} = V_{GS} - V_{TH}$ → 过驱动决定电压裕度（headroom）
- → 饱和 MOSFET 作为电流源：[[C5.电流镜与偏置技术#5.1 基本电流镜|电流镜原理]]
- → NMOS/PMOS 电流驱动不对称：$\mu_p \approx \mu_n/2$

### 跨导 $g_m$
- [[C2.MOS器件物理基础#2.2.3 跨导|Razavi: $g_m$ 定义、三种等价形式]]
- $g_m = \mu_n C_{ox} \frac{W}{L}(V_{GS}-V_{TH}) = \sqrt{2\mu_n C_{ox} \frac{W}{L} I_D} = \frac{2 I_D}{V_{GS}-V_{TH}}$
- ⚡ 三种形式对应三种设计视角：增大过驱 / 增大尺寸 / 减小过驱（$I_D$ 固定时）
- ⚡ $g_m$ 不能通过无限增大 $W/L$ 任意提升——亚阈值导电限制 $g_m/I_D$ 上限
- → $g_m$ 直接决定 [[C3.单级放大器#3.3.1 阻性负载的共源级|CS 级增益]] $A_v = -g_m R_D$

### 体效应（Body Effect）
- [[C2.MOS器件物理基础#2.3.1 体效应|Razavi: 体效应物理机制、$V_{TH}$ 修正、源随器体效应]]
- $V_{TH} = V_{TH0} + \gamma(\sqrt{2\Phi_F + V_{SB}} - \sqrt{|2\Phi_F|})$，$\gamma$ 典型 0.3–0.4 $\text{V}^{1/2}$
- ⚡ 体效应通常不受欢迎——$V_{TH}$ 随信号变化，引入非线性
- → 源极跟随器增益 < 1 的主要原因：[[C3.单级放大器#3.4 源极跟随器|CD 级体效应]]
- → 正向体偏置可降低 $V_{TH}$（PFET 独立 n 阱优势）：低电压设计手段

### 沟道长度调制（CLM）
- [[C2.MOS器件物理基础#2.3.2 沟道长度调制|Razavi: CLM 物理、$\lambda$ 系数、$r_o$ 来源]]
- $I_D \approx \frac{1}{2}\mu_n C_{ox} \frac{W}{L}(V_{GS}-V_{TH})^2 (1 + \lambda V_{DS})$，$\lambda \propto 1/L$
- ⚡ CLM → 有限 $r_o$ → 限制放大器本征增益 $g_m r_o$
- ⚡ $L \to 2L$ → $\partial I_D/\partial V_{DS}$ 除以 4（$W$ 不变时）——更理想的电流源
- → [[C5.电流镜与偏置技术#5.2 Cascode 电流镜|Cascode 电流镜]] 抑制 CLM 导致的电流复制误差
- 仅饱和区有 CLM（三极管区无夹断，沟道长度不被调制）

### 亚阈值导电（Subthreshold）
- [[C2.MOS器件物理基础#2.3.3 亚阈值导电|Razavi: 弱反型 I/V 指数律、$g_m/I_D$ 上限]]
- $I_D = I_0 \exp(V_{GS} / \xi V_T)$，$V_T = kT/q \approx 26$ mV
- ⚡ $g_m = I_D/(\xi V_T)$——MOSFET 的 $g_m/I_D$ 上限，$\xi > 1$ 意味着劣于 BJT ($I_C/V_T$)
- ⚡ 强-弱反型边界：$V_{GS}-V_{TH} \approx 2\xi V_T \approx 80$ mV
- ⚡ 高 $g_m/I_D$ 效率 vs 极低速度——亚阈值设计的根本权衡
- → 与 BJT 对比：[[Magnetic Theory|BJT $g_m = I_C/V_T$]]

### 小信号模型
- [[C2.MOS器件物理基础#2.4.3 MOS 小信号模型|Razavi: $g_m$、$r_O$、$g_{mb}$ 推导、完整等效电路]]
- 核心：$g_m v_{GS}$（压控电流源） + $r_O \approx 1/(\lambda I_D)$（CLM → 有限输出电阻） + $g_{mb} v_{bs} = \eta g_m v_{bs}$（体效应 → "背栅"）
- ⚡ $r_O$ 限制放大器最大增益：本征增益 $g_m r_O$
- ⚡ $\eta = g_{mb}/g_m = \gamma/(2\sqrt{2\Phi_F + V_{SB}})$，典型值 ≈ 0.25
- ⚡ PMOS 小信号模型与 NMOS 完全相同——注意绘图陷阱
- → $r_O$ 与 Cascode：[[C5.电流镜与偏置技术#5.2 Cascode 电流镜|Cascode 倍增 $r_O$]]
- → $g_{mb}$ 对源随器的影响：[[#体效应（Body Effect）|体效应]] → CD 级增益 < 1

### 偏置技术（5.4 节）

#### 偏置的核心原则
- [[C5.电流镜与偏置技术#5.4 偏置技术|Razavi: 偏置三大原则]]
- "不打架"：DC/AC 通过 R、C 在频域分离
- "不固定"：$V_{GS} = f^{-1}(I_{REF})$，不能是恒压源
- "不冲突"：两个电流源串联 → 一个在 DC 上屈服（自偏置）
- → 直接关联：[[#基本电流镜|$f[f^{-1}(I_{REF})] = I_{REF}$ 原理]]

#### CS 级偏置
- [[C5.电流镜与偏置技术#5.4.1 共源级偏置|Razavi: CS 偏置（电容耦合、自偏置、互补 CS）]]
- $R_B C_B$ 高通，$1/(2\pi R_B C_B) < f_{min}$
- 深三极管 MOSFET 替代 $R_B$：$R_{on,R} = (W/L)_C/(W/L)_R \cdot 1/g_{m,C}$
- 自偏置：DC 二接管 / AC 共源——同一组管子两个角色
- 互补 CS：$V_{GS1} + |V_{GS2}| = V_{DD}$ → $R_F$ 反馈自偏置
- ⚡ $I_G R_G$ 电平移位 → 对称输出摆幅

#### CG 级偏置
- [[C5.电流镜与偏置技术#5.4.2 共栅级偏置|Razavi: CG 偏置（电阻/电流源/Cascode 尾电流）]]
- $R_S$ 通路 → 信号衰减 $V_X/V_{in} = (1/g_m \parallel R_S)/(R_1 + 1/g_m \parallel R_S)$
- $R_S$ → 电流源 $M_2$ → 低压 Cascode 的三级递进
- → 同源：[[#Cascode 电流镜|Cascode 强制 $V_{DS}$ 相等]]

#### CD 级偏置
- [[C5.电流镜与偏置技术#5.4.3 源极跟随器偏置|Razavi: CD 偏置]]
- $A_v \approx 1$ → 输入 DC 范围宽 → 可直接耦合
- → 关联：[[#源极跟随器 (CD)|源极跟随器特性]]

#### 差分对偏置
- [[C5.电流镜与偏置技术#5.4.4 差分对偏置|Razavi: 差分对偏置]]
- 最低输入 CM = $V_{GS} + V_{DS,min}$ → 最大化输出摆幅
- 两级直接级联的 CM 矛盾 → 交流耦合解耦
- → 引出 CMFB 必要性（第 9 章）

## 放大器噪声

### 噪声统计特性与类型
- [[C7放大器噪声#7.1 噪声的统计特性|Razavi 7.1: PSD、高斯分布、SNR、噪声分析四步法]]
- [[C7放大器噪声#7.2 噪声类型|Razavi 7.2: 热噪声、闪烁噪声、栅电阻噪声]]
- 电阻热噪声：$\overline{V_n^2} = 4kTR$ → RC 网络：$P_{n,out}=kT/C$（与 R 无关）
- MOS 沟道热噪声：$\overline{I_n^2}=4kT\gamma g_m$（长沟 $\gamma=2/3$，纳米 $\gamma\approx 1$）
- 闪烁噪声：$\overline{V_n^2}=K/(C_{ox}WL)\cdot 1/f$（$\propto 1/$面积；PMOS < NMOS）
- 栅电阻：$\overline{V_{n,RG}^2}=4kT R_G/3$ → 多指版图 $\propto 1/N^2$
- → 直接关联：[[#MOS 器件物理|Ch2 电容/小信号模型]] → 热噪声 $\propto g_m$；闪烁噪声 $\propto 1/(WL)$

### 噪声表示方法
- [[C7放大器噪声#7.3 噪声在电路中的表示|Razavi 7.3: 输入参考噪声、双口模型、相关性问题]]
- $\overline{V_{n,in}^2} = \overline{V_{n,out}^2}/A_v^2$ → 三部分：沟道热噪声 + 闪烁噪声 + 负载噪声
- 完整双口：$\overline{V_{n,in}}$（串联）+ $\overline{I_{n,in}}$（并联），两者一般相关
- ⚡ 决定 $\overline{I_{n,in}}$ 是否重要的不是电路的 $Z_{in}$，而是前级的 $Z_S$

### CS 级噪声
- [[C7放大器噪声#7.4.1 共源级|Razavi 7.4.1: CS 噪声 = $4kT\gamma/g_{m1} + 4kT\gamma g_{m2}/g_{m1}^2$]]
- ⚡ $g_{m1}\uparrow$（输入管，降输入参考噪声）vs $g_{m2}\downarrow$（负载管，降输出噪声）——核心不对称
- 互补 CS：$\overline{V_{n,in}^2} = 4kT\gamma/(g_{m1}+g_{m2})$ —— 两管都放大，噪声更低
- ⚡ 噪声-功耗-裕度-速度四元折中

### CG 级与 CD 级噪声
- [[C7放大器噪声#7.4.2 共栅级|Razavi 7.4.2: CG 噪声——无电流增益、低频 $\overline{I_{n,in}}$ 已不可忽略]]
- [[C7放大器噪声#7.4.3 源极跟随器|Razavi 7.4.3: CD 噪声 = CS 噪声，但 $A_v<1$ → 恶化 SNR 无增益]]

### Cascode 级噪声

- [[C16.锁相环#16.1.2 基本 PLL 拓扑|Razavi 16.1.2: 锁定=暂时频率变化→永久相位对齐、锁定条件$\omega_{out}=\omega_{in}$（频率精确相等）、PD+LPF+VCO环路、相位/频率阶跃响应定性分析]]

- [[C16.锁相环#16.2.1 锁定的捕获问题|Razavi 16.2.1: I型捕获范围≈$\omega_{LPF}$不足→辅助捕获（FD+PD双环路）→引出PFD合并方案]]
- [[C16.锁相环#16.2.2 相位/频率检测器（PFD）|Razavi 16.2.2: 三态时序机、UP/DOWN脉冲、D触发器+AND门复位、复位脉宽≈$5T_D$、输入输出特性跨±360°（vs XOR的±$\pi/2$）]]

- [[C16.锁相环#16.3.1 PFD/CP 的非理想因素|Razavi 16.3.1: 死区(重合复位脉冲消除)、UP/DOWN延迟失配(传输门均衡)、电流失配(PLL自纠正→静态相位误差)、电荷共享(自举钳位)]]

### 延迟锁定环（DLL）与 PLL 应用
- [[C16.锁相环#16.4 延迟锁定环（Delay-Locked Loop, DLL）|Razavi 16.4: VCDL替代VCO——相位传输全通（vs PLL低通）、环路阶数=LPF阶数（无VCO原点极点→稳定性天然宽松）、噪声低（受损过零点不循环）、不能频乘、锁定模糊($T_{in}$或$2T_{in}$)]]

- [[C16.锁相环#16.5.2 偏斜消除（Skew Reduction）|Razavi 16.5.2: 缓冲器放PLL环路内→恒定相移被无穷环路增益除→偏斜消除；DLL也可用（更优，若频乘不需）]]

### 缩放理论
- [[C17.短沟道效应与器件模型#17.1 缩放理论|Razavi 17.1: 恒场缩放三规则——尺寸↓α / 电压↓α / 掺杂↑α]]

- ⚡ 实际为恒压缩放（电压不缩放）→ 电场 $\uparrow\alpha$ → 击穿风险 + 短沟效应恶化

## 放大器频率响应

### Miller 效应与节点-极点关联
- [[C6.放大器频率响应#6.1.1 Miller 效应|Razavi 6.1: Miller 定理、倍增物理、三大局限]]
- [[C6.放大器频率响应#6.1.2 节点-极点关联|Razavi 6.1: 极点-节点关联]]
- $Z_1 = Z/(1-A_v)$, $Z_2 = Z/(1-A_v^{-1})$ → 电容倍增 $(1-A_v)$ 倍
- ⚡ 只用 DC 增益做 Miller 近似——省力但丢失零点和多余极点
- → 直接关联：[[#MOS 器件物理|$C_{GS}, C_{GD}, C_{DB}, C_{SB}$]]

### CS 级频率响应
- [[C6.放大器频率响应#6.2 共源级|Razavi 6.2: CS 频响]]
- RHP 零点 $\omega_z = +g_m/C_{GD}$——$C_{GD}$ 前馈通路
- 输入极点 $\omega_{p1}$ ≈ $\{R_S[C_{GS} + (1+g_m R_D)C_{GD}]\}^{-1}$
- ⚡ Miller 倍增是 CS 级带宽的头号瓶颈
- ⚡ 大 $C_L$ → 增益提前衰减 → Miller 效应自动减弱

### CD 级频率响应（源随器）
- [[C6.放大器频率响应#6.3 源极跟随器|Razavi 6.3: CD 频响]]
- LHP 零点（$C_{GS}$ 同相前馈） vs CS 的 RHP 零点（$C_{GD}$ 反相前馈）
- ⚡ Bootstrapping：$A_v \approx 1$ → $C_{GS}$ 等效应大幅缩小
- ⚡ 输出阻抗呈电感 $L = (C_{GS}/g_m)(R_S - 1/g_m)$ → 有源电感
- ⚡ 驱动容性负载时输入端出现负阻 → 可能振荡

### CG 级频率响应
- [[C6.放大器频率响应#6.4 共栅级|Razavi 6.4: CG 频响]]
- 无浮空电容 → 天然无 Miller 效应 → 宽带潜力
- $\lambda \neq 0$ 时输入/输出通过 $r_O$ 耦合
- ⚡ 栅极 $R_G$ 必须尽量低——否则引入局部 Miller 效应

### Cascode 级频率响应
- [[C6.放大器频率响应#6.5 Cascode 级|Razavi 6.5: Cascode 频响]]
- CS 级 Miller 倍增被 CG 级源极输入低阻压制 → $C_{GD1}$ 仅倍增 ≈2
- 三个极点：$\omega_{p,A}$（输入）、$\omega_{p,X} \approx f_T/2$（中间）、$\omega_{p,Y}$（输出）
- → 同源：[[#Cascode 电流镜|5.2 Cascode 屏蔽 $V_{DS}$]]

### 差分对频率响应
- [[C6.放大器频率响应#6.6 差分对|Razavi 6.6: 差分对 + 有源负载频响]]
- 差模 = CS 半电路；CMRR 随频率恶化（$C_P$ 在高频短路尾电流源）
- 五管 OTA 镜像极点 ≈ $g_{mP}/C_E$——PMOS 低 $f_T$ 的瓶颈
- 双路径（快 + 慢）叠加 → LHP 零点 $\omega_z \approx 2g_{mP}/C_E$
- ⚡ 全差分无镜像极点——延续 5.3.4 节的结论

### 增益-带宽权衡
- [[C6.放大器频率响应#6.7 增益-带宽权衡|Razavi 6.7: GBW、多级级联]]
- 单极点：$\mathrm{GBW} = g_m/(2\pi C_L)$——与 $R_{out}$ 无关
- 多级级联：GBW ↑ 但带宽 ↓、稳定性恶化（→ 第 10 章）

## 传输线理论

### 集总→分布过渡
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.1 为什么需要传输线理论？|Ludwig: $\lambda/10$ 准则、Kirchhoff 定律失效、无穷小分割 → 分布参数 $R,L,C,G$/单位长度]]
- ⚡ 决定是否需要传输线理论的不是频率本身，而是 $l/\lambda$ 比值——60 Hz 跨省电力线与 GHz 级 PCB 走线可有相同的 $l/\lambda$

### 传输线类型
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.2 传输线实例|Ludwig: 双线（辐射大→少用）、同轴（外导体接地→低辐射）、微带线（PCB 蚀刻走线+地平面)]]
- ⚡ 高 $\varepsilon_r$ 基板 → 场更集中于介质内 → 更小泄漏/交叉耦合 → 更高布线密度
- 微带线、同轴线均为 TEM 模式 ← [[Ludwig-RF Circuit Design/C1-引言#TEM 模式|Ch1 TEM: E⊥H⊥k]]

### 等效电路模型
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.3 等效电路表示|Ludwig: $\Delta z$ 段等效电路——串联 $R,L$（导线损耗+互感）+ 并联 $C,G$（电荷分离+介质损耗）]]
- ⚡ $R,L,C,G$ 均为频率相关；$L$ 自感 $\ll$ 互感（自感可忽略）
- → 通向广义传输线方程（2.4 节）

### 分布参数的理论基础
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.4.1 基本定律|Ludwig: Ampère 定律 $\oint H\cdot dl = \iint J\cdot dS$ + Faraday 定律 $\oint E\cdot dl = -d/dt \iint B\cdot dS$]]
- ⚡ $E$ 和 $H$ 相互耦合（时变 $E$ → $H$、时变 $H$ → $E$）→ 自持波传播
- ← $J$ 三部分：源 $J_0$ + 传导 $\sigma E$（导体损耗）+ 位移 $\partial(\varepsilon E)/\partial t$（辐射损耗）
- → 直接用于 2.5 节计算传输线 $R,L,C,G$ 参数

### 平行板传输线参数
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.5 平行板传输线的电路参数|Ludwig: $R_s=\frac{1}{w\sigma\delta}$、$L_s=\frac{1}{w\sigma\omega\delta}$（单板、×2 得总）、$C=\varepsilon w/d$、$L=\mu d/w$、$G=\sigma_{\text{diel}}w/d$]]
- ⚡ $G/C = \sigma_{\text{diel}}/\varepsilon$——三种构型统一规律（表 2-1）：$C$ 和 $G$ 公式互为 $\varepsilon \leftrightarrow \sigma_{\text{diel}}$ 替换
- ⚡ 趋肤 $L_s \ll$ 互感 $L$ → 总电感中 $L_s$ 可忽略

### 广义传输线方程
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.7.1 Kirchhoff 电压电流律形式|Ludwig: $-\frac{dV}{dz}=(R+j\omega L)I$、$-\frac{dI}{dz}=(G+j\omega C)V$（耦合一阶 PDE）]]
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.7.2 行进电压波与电流波|Ludwig: 解耦 → $\frac{d^2V}{dz^2}-k^2V=0$、$k=\sqrt{(R+j\omega L)(G+j\omega C)}$、$V(z)=V^+e^{-kz}+V^-e^{+kz}$]]

### 微带线设计
- [[Ludwig-RF Circuit Design/C2-传输线理论#2.8 微带传输线|Ludwig: $w/h<1$ 和 $w/h>1$ 经验公式（2.42–2.45）、$\varepsilon_{\text{eff}}$ 均匀化、反推公式（2.46）、非零厚度修正 $w_{\text{eff}}$]]

#### 增益与线性度

### 拓扑与匹配

#### 输入匹配网络
- [[C5.Low-Noise Amplifiers#5.1.3 输入回波损耗|Razavi RF: 为何 LNA 必须 50Ω 匹配——滤波器/天线/PCB 反射三大约束]]
- ⚡ $S_{11} < -10\ \mathrm{dB}$（反射 < 1/10），实际目标 −15 dB 以留封装裕量

#### 5.2 CS 级输入匹配的困境
- [[C5.Low-Noise Amplifiers#5.2.1 CS 级的输入导纳|Razavi RF: $C_F$ 反馈 $\mathrm{Re}\{Y_{in}\}\sim(k\Omega)^{-1}$ → 远离 $50\Omega$]]
- ⚡ $C_F$（10 fF 量级）反馈太弱——不能依赖寄生完成匹配
- → 小信号模型：[[C2.MOS器件物理基础#2.4.3 MOS 小信号模型|Ch2]]
- → Miller 效应：[[C6.放大器频率响应#6.2 共源级|Ch6: CS 频响]]
- [[C5.Low-Noise Amplifiers#5.2.2 电阻终端匹配|Razavi RF: 并联 $R_P$ 方案——NF > 3 dB，实体电阻的噪声不可接受]]
- ⚡ 核心洞察：LNA 必须用有源器件合成 50Ω——不靠实体电阻的热噪声
- [[C5.Low-Noise Amplifiers#5.2.3 匹配网络变换——热力学下限|Razavi RF: 无损匹配网络变换——NF ≡ 3 dB，热力学不可逾越]]
- ⚡ $R_P$ 增大 → 增益同步增大 → $kTR_P$ 噪声同步增大 → NF=2 恒定——物理极限而非设计限制
- → 唯一出路：有源阻抗合成（5.3 节三种途径：电感退化 CS / CG / 阻性反馈）

#### LNA 拓扑选择
- [[C5.Low-Noise Amplifiers#5.3.1 电感负载的 CS 级|Razavi RF 5.3.1: 电感负载 CS —— 增益-摆幅解耦、谐振提速、但 $C_F$ 反馈致失稳]]
- [[C5.Low-Noise Amplifiers#5.3.2 阻性反馈的 CS 级|Razavi RF 5.3.2: 阻性反馈 CS —— $R_{in}=1/g_{m1}$、NF ≥ 3 dB（$\gamma\approx 1$）、有源负载版更优但需更高 $V_{DD}$]]
- [[C5.Low-Noise Amplifiers#5.3.3 共栅级（CG）|Razavi RF 5.3.3: CG 级 —— $R_{in}=1/g_m$ 天然匹配、NF ≥ 3 dB、CLM 使 $R_{in}$ 过高、Cascode CG + $L_B$ 偏置为实用方案]]
- ⚡ CG 的设计矛盾：忽略 CLM → $R_{in}$ 太低；考虑 CLM → $R_{in}$ 太高；Cascode CG 用两级本征增益压制 $R_1$ 对 $R_{in}$ 的影响
- [[C5.Low-Noise Amplifiers#5.3.4 Cascode CS 级 + 电感源极退化|Razavi RF 5.3.4: 电感退化 Cascode CS —— $R_{in}=g_m L_1/C_{GS}\approx L_1\omega_T$（有源合成 50Ω！）、NF ≈ 1.5–2 dB、负载噪声被 $(\omega_0/\omega_T)^2$ 衰减]]
- ⚡ 最经典 LNA 拓扑：$L_G$ 谐振输入 + $L_1$ 退化提供实部 + Cascode 隔离 $C_{GD}$ → NF 打破 3 dB 壁垒
- → Cascode 在 RF 的应用：[[#基本放大级|共源共栅级]]提高反向隔离度
- → 退化 CS：[[C3.单级放大器#3.3.6 源极退化的共源级|Ch3: 源极退化]]
- [[C5.Low-Noise Amplifiers#5.3.5 CG LNA 的变体|Razavi RF 5.3.5: CG 变体——反馈（解耦 $g_m$ 与匹配）和前馈 $g_m$-boosting]]
- ⚡ 反馈 CG：$R_{in}=1/g_m+\alpha R_1$，$g_m R_S=4$ 时前两项 NF 仅 0.97 dB；前馈受限于增益级噪声
- [[C5.Low-Noise Amplifiers#5.3.6 噪声抵消 LNA（Noise-Cancelling LNA）|Razavi RF 5.3.6: 噪声抵消 LNA —— 信号反相、噪声同相 → 求和抵消 $M_1$ 噪声]]
- ⚡ 兼具宽带 + 低 NF：阻性反馈 + 辅助放大器 = 抵消 $M_1$ 噪声；CG/CS 变体兼做单端转差分
- [[C5.Low-Noise Amplifiers#5.3.7 电抗抵消 LNA（Reactance-Cancelling LNA）|Razavi RF 5.3.7: 电抗抵消 LNA —— 负反馈产生感性阻抗抵消 $C_{in}$、50 MHz–10 GHz 超宽带]]
- ⚡ 七种拓扑递进：电感负载 → 阻性反馈 → CG → 电感退化 CS（最优 NF）→ CG 变体 → 噪声抵消 → 电抗抵消

#### 隐式微分法 + 退化 CS
- [[C5.Low-Noise Amplifiers#5.7 非线性计算（Nonlinearity Calculations）|Razavi RF 5.7: 隐式微分法求 $\alpha_{1-3}$、退化 CS——$R_S$ 在平方律器件中创造 $\alpha_3$、CG 的 $\alpha_3$ 反号]]

### 静态特性
- [[Rabaey-数字集成电路/C5.CMOS反相器#静态 CMOS 反相器——直观综述|Rabaey 5.2: 开关模型 → 无比逻辑（ratioless）、全摆幅、低输出阻抗（kΩ 级）、零静态功耗；负载曲线图叠加法得 VTC，过渡区极窄]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#开关阈值|Rabaey 5.3.1: $V_M=\frac{(V_{Tn}+V_{DSATn}/2)+r(V_{DD}+V_{Tp}+V_{DSATp}/2)}{1+r}$，$r=k_pV_{DSATp}/k_nV_{DSATn}$；$r\approx1$ 得对称；0.25 μm 需 $(W/L)_p/(W/L)_n\approx3.5$]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#噪声容限|Rabaey 5.3.2: 逐段线性近似 → $NM_H=V_{DD}-V_{IH}$、$NM_L=V_{IL}$；增益 $g\approx\frac{1+r}{(V_M-V_{Tn}-V_{DSATn}/2)(\lambda_n-\lambda_p)}$ 几乎只由沟长调制决定]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#再谈稳定性|Rabaey 5.3.3: 器件参数变化只平移 $V_M$；降低 $V_{DD}$ 反而提高增益，但延时↑/参数敏感↑，极限 $V_{DDmin}>2\sim4\,kT/q$（室温≈100 mV，亚阈值仍可反转）]]
- ⚡ 无比逻辑 + 对称 VTC ⇒ 晶体管可取最小尺寸；工业上 PMOS 可比完全对称所需更窄（$V_M$ 对比值不敏感）

### 动态特性
- [[Rabaey-数字集成电路/C5.CMOS反相器#计算电容值|Rabaey 5.4.1: $C_L$ = 密勒 $2C_{GDO}W$ + 线性化结电容 $K_{eq}C_{j0}$ + 连线电容 + 扇出栅电容；0.25 μm 反相器 $C_L\approx6$ fF（本征/外部几乎各半）]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#传播延时：一阶分析|Rabaey 5.4.2: $t_p=0.69R_{eq}C_L$，$R_{eq}\approx\frac{3}{4}\frac{V_{DD}}{I_{DSAT}}$；$V_{DD}\gg V_T$ 时 $t_p$ 与 $V_{DD}$ 近似无关，$V_{DD}\to2V_T$ 时急剧恶化]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#从设计角度考虑传播延时|Rabaey 5.4.3: $\beta_{opt}=\sqrt{r(1+C_w/C_{int})}$（对称非最优）；尺寸系数 $S$ 不改变本征延时 $t_{p0}=0.69R_{eq}C_{int}$；反相器链 $f=F^{1/N}$，最优 $f\approx3.6$（$\gamma=1$），工程上取 4]]
- ⚡ 三大延时杠杆：↓$C_L$（版图）、↑$W/L$（受自载效应封顶）、↑$V_{DD}$（受可靠性封顶）
- ⚡ 长导线延时含线性项 + $0.38r_wc_wL^2$ 分布项；最小尺寸驱动下 65 μm 导线即使互连延时等于本征延时（二次项要到 >7 cm 才主导）
- ⚡ 输入斜率：一旦 $t_s>t_p$，$t_p$ 随斜率线性增加 → $t_p^i=t_{step}^i+\eta t_{step}^{i-1}$（$\eta\approx0.25$），即斜率工程设计

### 功耗与能量
- [[Rabaey-数字集成电路/C5.CMOS反相器#动态功耗|Rabaey 5.5.1: 每开关周期 $C_LV_{DD}^2$——一半存电容、一半耗在 PMOS（与尺寸无关）；$P_{dyn}=C_{EFF}V_{DD}^2f$，$C_{EFF}=P_{0\to1}C_L$；短路功耗 $P_{dp}=C_{sc}V_{DD}^2f$，靠输入/输出斜率匹配压到 <10%]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#静态功耗|Rabaey 5.5.2: $P_{stat}=I_{stat}V_{DD}$；结泄漏 10–100 pA/μm²（85 °C 时 ×60）+ 亚阈值泄漏 → $V_T$ 下限 → 性能 vs 静态功耗权衡；SOI 斜率 60 mV/dec]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#综合考虑|Rabaey 5.5.3: $P_{tot}=P_{dyn}+P_{dp}+P_{stat}$；PDP 是每翻转能量；EDP 最优 $V_{DDopt}=\frac{3}{2}V_{TE}$（0.25 μm → 1.1–1.2 V）]]
- [[Rabaey-数字集成电路/C5.CMOS反相器#利用 SPICE 分析功耗|Rabaey 5.5.4: 积分器电路（$C\,dP_{av}/dt=ki_{DD}$，$k/C=V_{DD}/T$）或 `.MEAS AVG` 测平均功耗]]
- ⚡ 三大功耗项：电容功耗主导、短路可控、漏电将成为主角；降低 $V_{DD}$ 收益是二次方但有性能/噪声容限代价
- ⚡ 能量最优与性能最优是两个不同工作点（扇出 20：$f_{opt}$ 3.53 vs 4.47）；过度加大尺寸是双输（面积↑ + 能量↑）
