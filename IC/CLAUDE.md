# IC 知识体系 — 项目配置

## 项目概述

本文件夹是 **集成电路（IC）** 的知识体系仓库，覆盖模拟 IC、数字 IC、RF IC 以及微电子工艺与封装。以多本经典教材和论文为学习路径，建立互相贯通的知识索引。

**核心理念**：
- 知识是同一套（MOSFET 物理、电路拓扑、设计方法论），但不同教材/论文的"切法"不同
- 笔记各自保持独立的叙事风格，但通过 `[[知识导图]]` 索引中枢和 wikilink 互联
- 概念本体（Markmap 思维导图）稳定，阅读路径（子文件夹）随学习扩展

## 知识导图 (Markmap) 索引体系

### 架构

本项目的概念索引由 `[[知识导图]]` 一文承担，采用 **纯 Markdown 标题层级 = 思维导图** 的方案（通过 `obsidian-markmind` 插件渲染为 Markmap）。

语法即结构，无需额外格式：

| 层级 | Markdown | 含义 | 示例 |
|------|----------|------|------|
| L0 | `#` | 根节点 | `# Analog IC 知识体系` |
| L1 | `##` | 知识域 | `## MOS 器件物理` |
| L2 | `###` | 子域 | `### 共源级 (CS)` |
| L3 | `####` | 具体概念 | `#### 阻性负载 CS` |
| L4 | `- [[wikilink]]` | 笔记链接 | `- [[子文件夹/笔记#标题\|Razavi: 阻性负载 CS]]` |

**Markmap 方案的优势**：
- **零语法**：增删概念就是增删 markdown 标题，不需要学任何 DSL
- **零坐标**：自动树形布局，永远不重叠
- **可点击**：`- [[wikilink]]` 列表项在思维导图中直接可点击跳转
- **可折叠**：节点多了可以折叠子树，不像 Canvas/Mermaid 那样撑爆视野
- **跨域关联**：通过列表项内的 `→` `←` `↔` `⚡` 等标记 + wikilink 实现

### 跨域关联的标注约定

Markmap 是树结构，不原生支持图边。跨域关系通过 L3 概念下的列表项标注：

```
#### 源极退化 CS
- [[单级放大器#3.3.6\|Razavi: 源极退化 CS]]
- ⚡ trade-off: Gm 线性化 → 线性度 ↑ 增益 ↓
- → 同源技术: [[差分放大器#4.2.3\|差分对退化]]
```

常用标记：
- `→` / `←`：单向依赖/应用（"A 用于 B"）
- `↔`：双向关联（"A 与 B 互补"）
- `⚡`：关键 trade-off / 设计洞察

### 知识导图的自动维护规则

**触发时机**：AI 每次完成一篇笔记的撰写或修改后，**必须**执行以下维护：

1. **读取 `[[知识导图]]`**：了解已有概念树结构
2. **增量更新标题层级**：
   - 若笔记引入了新概念 → 在对应 L2 子域下添加 `#### 概念名` + L4 链接列表项
   - 若新概念属于已有 L3 → 在已有 `####` 下添加新的 L4 `- [[link]]`
   - 若新概念需要新建 L2 子域甚至 L1 知识域 → 先与用户确认
3. **添加跨域关联标注**：
   - 若新概念与已有概念存在跨域关系 → 在两端概念下各加一行 `→` / `↔` 标注
4. **添加新教材/论文的 L4 链接**：
   - 同一概念多本书时，在对应 `####` 下追加 `- [[新书子文件夹/笔记#标题\|新书: 概念名]]`
   - 可附一句标注各书视角差异

**不做的操作**：
- ❌ 不删除已有概念/链接（除非知识归类明显错误且用户确认）
- ❌ 不为每个 `###` 子标题创建 `####` 概念节点（只到笔记的 `#` / `##` 级别）
- ❌ 不为尚未写的章节预建节点

## 笔记撰写通用标准

以下规则适用于所有课本/论文的笔记，不受具体教材风格影响。

### 深度原则

- **深度而非堆砌**：宁可一个知识点写透，也不要罗列十个概念定义
- **联想与贯通**：重在建立前后章节的联系，融汇贯通
- **直觉与数学并重**：每个结论既要物理直觉的直观分析，也要数学表达式的定量理解

### 组织原则

按照知识发展的自然顺序组织笔记——概念从哪里来 → 它是什么 → 它为什么重要 → 它通向哪里。物理直觉、数学推导、设计启示在知识展开中自然融入。

- 物理直觉和数学公式穿插使用，哪个适合解释当前问题就用哪个
- 概念定义、推导逻辑、设计意义之间平滑过渡
- 需要深入展开的知识点用 `###` 子标题自然引出

### 语言风格：简明扼要

**核心原则：结论直接说，不铺陈；保留所有技术实质，砍掉一切文字水分。**

- 不要写过渡句和引导句——"一个容易忽略的事实是""值得深思的是"这类句子直接删掉
- 同一个观点只解释一遍——在第一遍解释时就找准角度，一次说透
- 删掉过度修饰——让事实本身说话
- 不开辟大段背景铺陈——直接进入主题，必要的上下文一句话交代即可
- 允许写短段落，甚至一句话成段——节奏感比"完整性"重要
- 公式前后的引导句可以极简——"由此可得""即"

### 标题层级规则

- `#` — 章级小节（对应原书的一级 numbered section）
- `##` — 子节（对应原书的二级 numbered section），或章级小节内的主要子主题
- `###` — 子节内的具体知识点/例题，用于自然切分阅读节奏，不做更深的层级嵌套

### 数学推导准则

1. 给出起点和终点公式
2. 中间步骤写明用到的思想方法和近似，不展开全部代数运算
3. 关键步骤适当展开（如未做近似的原始结论、重要的中间结果）
4. 对结果公式逐项解读物理含义

### 术语规范

- 重要术语首次出现时，中文 + 英文/符号并列：`跨导（transconductance, $g_m$）`
- 后续统一使用符号或最常用称呼
- 公式中的符号遵循对应原书约定

### 插图（教材笔记专用）

教材插图**直接嵌入**笔记对应位置，不再使用 `> 【插入 … 图 X.XX】` 占位标注。

流程：
1. 从教材 `images/` 目录定位对应图片文件
2. 将该图片**复制**至 `E:\base_Obsidian\iceaxing's knowledge base\System\Attachments\`（文件名若为无意义哈希串，可重命名为 `书名-章节-图号.jpg` 之类的可读名），**原教材 `images/` 目录内容保持不变**
3. 在笔记对应位置用 Obsidian 嵌入语法插入：`![[图片文件名.jpg]]`，可附 `|宽度px` 控制显示尺寸

规则：
- 同一张图只复制一次，避免重复占用
- 图可配一句图注说明内容，图片本身直接嵌入正文

### AI 行为准则

#### 对每个结论，追问两个问题

1. **为什么（Why）**：物理直觉上为什么会这样？数学上为什么必然如此？
2. **然后呢（So What）**：这个结论对电路设计意味着什么？它会在后续哪一章用到？

#### 联想与贯通

- 遇到与前面章节呼应的内容，使用 `[[子文件夹/章节名]]` 链接，并**用一句话点明联系**
- 主动标注知识点在整个知识体系中的位置（如"这是模拟设计三大核心折中之一：增益-带宽-摆幅"）
- 可以将结论与 IC 内其他子领域及 vault 内其他领域关联：`[[Razavi-RF Microelectronics/Transceiver Architecture]]`、`[[Magnetic Theory]]`、`[[Digital Design]]`

#### 重要概念的首次引入

首次出现的重要概念必须给出：
- 中英双语名称
- 精确定义
- 物理含义
- 在电路设计中的意义

#### 写笔记前的上下文准备

AI 在撰写新章节笔记前，应执行以下步骤：
1. **读 `[[知识导图]]`**：在 Markmap 思维导图中定位该知识点在整体体系中的位置、与哪些已有概念关联
2. **读教材原文**：从对应页数范围读取原书内容
3. **搜相关笔记**：搜索其他子文件夹中是否有同一概念的讲解（用于跨书对比）
4. **在笔记中体现位置感**：利用 wikilink 链接到前置概念和后续应用

#### 不要做的事

- ❌ 不要逐句翻译教材段落
- ❌ 不要罗列无解释的公式
- ❌ 不要写"显然"、"易得"——把"为什么显然"说清楚
- ❌ 不要在不确定的情况下编造内容——宁可标注 `（此处需对照原书 X 页确认）`

### Obsidian 双向链接

本项目位于 Obsidian vault 内，使用 `[[wikilink]]` 链接。

**链接路径规则**：
- 同子文件夹内：`[[笔记文件名]]` 或 `[[笔记文件名#标题]]`
- 跨子文件夹：`[[子文件夹名/笔记文件名#标题]]`

链接的使用场景：

- 标注"初学易错点"的提示

**教材位置**：

- **Linux**：`/home/iceaxing/MyDoc/_textbook-md/RF Circuit Design-Theory and Applications/`

教材为单个 markdown 文件：
- `RF_Circuit_Design_Theory_and_Applications.md`

配套图片位于 `images/` 文件夹。

**教材特点**：Ludwig & Bretchko 以传输线理论为出发点，从低频电路理论过渡到高频/射频电路设计。全书不采用电磁场方法，而以电路视角（Kirchhoff 定律 + 波的反射/传输）展开射频设计。相比 Razavi RF Microelectronics 的系统级视角，本书更偏向**基础传输线 → Smith 圆图 → S 参数 → 匹配网络 → 放大器/振荡器/混频器设计**的逐层建立路径，适合没有电磁场背景的初学者。

**与 Razavi RF 的互补关系**：
- Razavi RF：系统视角——调制/解调 → 收发机架构 → 各模块（LNA、混频器、振荡器、频率合成）
