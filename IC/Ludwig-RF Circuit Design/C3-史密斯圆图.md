# 3 Smith 圆图

## 3.1 从反射系数到负载阻抗

第 2.9 节定义了负载处（$d=0$）的反射系数 $\Gamma_0 = (Z_L-Z_0)/(Z_L+Z_0)$。沿传输线向源移动 $d$，反射系数以 $\Gamma(d) = \Gamma_0 e^{-j2\beta d}$ 旋转。**从 $\Gamma_0$ 到 $\Gamma(d)$ 的变换正是 Smith 圆图作为图形化设计工具的核心。**

### 3.1.1 反射系数的相量形式

$$\Gamma_0 = \frac{Z_L - Z_0}{Z_L + Z_0} = \Gamma_{0r} + j\Gamma_{0i} = |\Gamma_0| e^{j\theta_L} \tag{3.1}$$

$\theta_L = \tan^{-1}(\Gamma_{0i}/\Gamma_{0r})$。短路 → $\Gamma_0 = -1$（实轴左端），开路 → $\Gamma_0 = +1$（实轴右端），匹配 → 原点。

**例 3-1**：$Z_0 = 50\Omega$，五个负载的反射系数：短路 $=-1$、开路 $=+1$、匹配 $=0$、$(16.67-j16.67)\Omega = 0.54\angle 221^\circ$、$(50+j150)\Omega = 0.83\angle 34^\circ$。

### 3.1.2 归一化阻抗方程

将 $\Gamma(d) = |\Gamma_0| e^{j\theta_L} e^{-j2\beta d} = \Gamma_r + j\Gamma_i$ 代入输入阻抗表达式 $Z_{\text{in}} = Z_0\frac{1+\Gamma}{1-\Gamma}$，并归一化 $z_{\text{in}} = Z_{\text{in}}/Z_0 = r + jx$：

$$z_{\text{in}} = r + jx = \frac{1 + \Gamma_r + j\Gamma_i}{1 - \Gamma_r - j\Gamma_i} \tag{3.4}$$

分子分母同乘分母的共轭，分离实虚部：

$$r = \frac{1 - \Gamma_r^2 - \Gamma_i^2}{(1-\Gamma_r)^2 + \Gamma_i^2} \tag{3.6}
$$
$$
x = \frac{2\Gamma_i}{(1-\Gamma_r)^2 + \Gamma_i^2} \tag{3.7}$$

(3.6) 和 (3.7) 是从 $\Gamma$ 平面到 $z_{\text{in}}$ 平面的显式变换规则——给定 $\Gamma_r, \Gamma_i$ 可直接求出 $r, x$。

**例 3-2**：$Z_L = (30+j60)\Omega$，$Z_0 = 50\Omega$，$l = 2$ cm，$f = 2$ GHz，$v_p = 0.5c$。$\Gamma_0 = 0.2+j0.6 = \sqrt{2/5} e^{j71.56^\circ}$，$\beta = 83.77$ m$^{-1}$，$2\beta l = 191.99^\circ$，$\Gamma_{\text{in}} = -0.32-j0.55$ → $Z_{\text{in}} = 14.7 - j26.7 \, \Omega$。

> **核心直觉**：$\Gamma(d) = \Gamma_0 e^{-j2\beta d}$——波必须走到负载再返回源（$2\beta d$ 的路程），才能定义输入阻抗。

### 3.1.3 参数化反射系数方程

反向问题：给定归一化阻抗 $z_{\text{in}} = r + jx$，如何映射到 $\Gamma$ 平面？对 (3.6) 和 (3.7) 求逆。

**电阻圆**（$r$ 固定，$x$ 任意）：

$$\left(\Gamma_r - \frac{r}{r+1}\right)^2 + \Gamma_i^2 = \left(\frac{1}{r+1}\right)^2 \tag{3.10}$$

- $r = 0$：圆心 $(0,0)$，半径 1 → 整个单位圆
- $r = 1$：圆心 $(1/2, 0)$，半径 $1/2$
- $r \to \infty$：圆心 $(1,0)$，半径 0 → 收敛到实轴右端点

**电抗圆**（$x$ 固定，$r$ 任意）：

$$\left(\Gamma_r - 1\right)^2 + \left(\Gamma_i - \frac{1}{x}\right)^2 = \left(\frac{1}{x}\right)^2 \tag{3.11}$$

- $x = \infty$：圆心 $(1,0)$，半径 0 → 一个点
- $x = 1$：圆心 $(1,1)$，半径 1
- $x \to 0$：圆心 $(1, \infty)$，半径 $\infty$ → 趋近实轴（退化）
- $x < 0$（容性）：圆心在实轴下方 → 下半平面

> 【插入 Ludwig 图 3-2】电阻圆 / 图 3-3 电抗圆

**单独一个映射不是一一对应**——固定 $r$ 的圆对应无穷多个 $x$ 值，反之亦然。两者结合才构成唯一映射。

### 3.1.4 图形表示——Smith 圆图

> 【插入 Ludwig 图 3-4】Smith 圆图——$r$ 圆 + $x$ 圆弧的组合（仅 $|\Gamma| \leq 1$）

**关键规则**：
- 归一化阻抗平面 ↔ 反射系数平面：**一一对应**
- $r$ 范围 $0 \leq r < \infty$，$x$ 范围 $-\infty < x < +\infty$（上半 = 感性，下半 = 容性）
- 旋转方向：$\Gamma(d) = \Gamma_0 e^{-j2\beta d}$，负指数 → **顺时针（CW）旋转**，标注为"朝向信号源（toward generator）"
- 绕单位圆一周 → $2\beta d = 2\pi$ → $d = \lambda/2$ 或 $180^\circ$
- $\beta d$ 称为线的**电长度（electrical length）**

> $|\Gamma| > 1$（负阻）对应圆外区域，压缩 Smith 圆图用于振荡器设计——本书不讨论。

## 3.2 阻抗变换

### 3.2.1 一般负载的阻抗变换

Smith 圆图求输入阻抗的**六步法**：

1. 归一化负载阻抗：$z_L = Z_L/Z_0$
2. 在圆图上定位 $z_L$（$r$ 圆和 $x$ 弧的交点）
3. 从原点到 $z_L$ 的矢量 → $\Gamma_0$ 的幅值和相位
4. 将矢量**顺时针**旋转 $2\beta d$ → 得 $\Gamma_{\text{in}}(d)$
5. 记录旋转后位置对应的归一化输入阻抗 $z_{\text{in}}$
6. 去归一化：$Z_{\text{in}} = z_{\text{in}} \times Z_0$

**例 3-3**：用 Smith 圆图重做例 3-2。$z_L = 0.6 + j1.2$，旋转 $2\beta d = 192^\circ$ → $z_{\text{in}} = 0.3 - j0.53$ → $Z_{\text{in}} = (15 - j26.5)\Omega$（与精确值 $14.7 - j26.7\Omega$ 略有误差，来自图形读取精度）。

> 【插入 Ludwig 图 3-5】六步法图解

### 3.2.2 驻波比（SWR）

$$\text{SWR}(d) = \frac{1 + |\Gamma(d)|}{1 - |\Gamma(d)|} \tag{3.12}, \quad |\Gamma(d)| = \frac{\text{SWR} - 1}{\text{SWR} + 1} \tag{3.13}$$

**在 Smith 圆图上读取 SWR**：SWR 圆就是以原点为圆心、$|\Gamma|$ 为半径的圆。该圆与**右侧实轴**的交点即为 SWR 的数值（因为 $\Gamma_r \geq 0$ 时 $r_L \geq 1$ → SWR = $(1+\Gamma_r)/(1-\Gamma_r) = r_L$）。

**例 3-4**：四个负载 ($50\Omega$, $48.5\Omega$, $75+j25\Omega$, $10-j5\Omega$) → SWR 分别为 1, 1.03, 1.77, 5.05。SWR 圆的半径大小直接反映失配的严重程度。

### 3.2.3 特殊变换条件——开路与短路传输线

旋转量由线长（或频率）控制 → **可以用分布传输线段实现集总电感和电容**。

#### 开路传输线

以 $\Gamma_0 = +1$（实轴右端）为起点，顺时针旋转。

**容性**（$-jX_C$）：$z_{\text{in}} = -j\cot(\beta d_1) = 1/(j\omega C Z_0)$ → $d_1 = \frac{1}{\beta}\left[\cot^{-1}\left(\frac{1}{\omega C Z_0}\right) + n\pi\right]$

**感性**（$jX_L$）：$z_{\text{in}} = -j\cot(\beta d_2) = j\omega L/Z_0$ → $d_2 = \frac{1}{\beta}\left[\pi - \cot^{-1}\left(\frac{\omega L}{Z_0}\right) + n\pi\right]$

> 【插入 Ludwig 图 3-7】开路传输线产生电容/电感

#### 短路传输线

以 $\Gamma_0 = -1$（实轴左端）为起点，顺时针旋转。

**容性**：$z_{\text{in}} = j\tan(\beta d_1) = 1/(j\omega C Z_0)$ → $d_1 = \frac{1}{\beta}\left[\pi - \tan^{-1}\left(\frac{1}{\omega C Z_0}\right) + n\pi\right]$

**感性**：$z_{\text{in}} = j\tan(\beta d_2) = j\omega L/Z_0$ → $d_2 = \frac{1}{\beta}\left[\tan^{-1}\left(\frac{\omega L}{Z_0}\right) + n\pi\right]$

> 【插入 Ludwig 图 3-8】短路传输线产生电容/电感

**例 3-5**：$Z_0 = 50\Omega$，$f = 3$ GHz，$v_p = 0.77c$（$\beta = 81.6$ m$^{-1}$，$\lambda = 77$ mm）。用开路传输线实现 2 pF 电容 → $d_1 = 13.27$ mm（$0.172\lambda$），实现 5.3 nH 电感 → $d_2 = 32.81$ mm（$0.426\lambda$）。

**工程设计权衡**：
- 开路终端易受温度/湿度影响 → **短路终端在实用中更被偏好**
- 但短路通过过孔实现 → 高频下引入寄生电感
- 最小化电路面积时 → **开路优先**（电容开路实现最短、电感短路实现最短）

> 设计流程常是：先用集总元件设计 → 转换为传输线段实现（类似本例步骤）

## 3.3 导纳变换

### 3.3.1 参数化导纳方程

从归一化阻抗 (3.4) 直接取倒数得归一化导纳：

$$y_{\text{in}} = \frac{Y_{\text{in}}}{Y_0} = \frac{1}{z_{\text{in}}} = \frac{1 - \Gamma(d)}{1 + \Gamma(d)} \tag{3.23}$$

其中 $Y_0 = 1/Z_0$。

**关键洞察**：(3.23) 与阻抗式 (3.4) 的形式完全相同，仅 $\Gamma$ 前符号反转：

$$\frac{1 - \Gamma}{1 + \Gamma} = \frac{1 + e^{-j\pi}\Gamma}{1 - e^{-j\pi}\Gamma}$$

即 $y_{\text{in}}(\Gamma) = z_{\text{in}}(\Gamma \cdot e^{-j\pi})$ —— 将反射系数乘以 $e^{-j\pi} = -1$，等效于在复 $\Gamma$ 平面内旋转 **$180^\circ$**。

**例 3-6**：$z_{\text{in}} = 1 + j1 = \sqrt{2}e^{j\pi/4}$ → $y_{\text{in}} = 1/\sqrt{2} e^{-j\pi/4} = 0.5 - j0.5$。在 Smith 圆图上将 $\Gamma$ 旋转 $180^\circ$ 即得。

> 【插入 Ludwig 图 3-10】阻抗到导纳的 $180^\circ$ 旋转转换

**Y-Smith 圆图（导纳 Smith 圆图）**：不旋转 $\Gamma$，而是将整个圆图旋转 $180^\circ$。对应关系变为：

$$r = R/Z_0 \Rightarrow g = G/Y_0 = Z_0 G, \quad x = X/Z_0 \Rightarrow b = B/Y_0 = Z_0 B$$

> 【插入 Ludwig 图 3-11】Z-Smith 圆图 ↔ Y-Smith 圆图的重新解释

**Z ↔ Y 变换的关键对应**：
- $z_L = 0$（短路）↔ $y_L = \infty$（导纳开路）
- $z_L = \infty$（开路）↔ $y_L = 0$（导纳短路）
- 负电纳 $b < 0$（感性）→ Y 图上**半**平面；正电纳 $b > 0$（容性）→ **下**半平面
- 电导从右到左增大

> 存在另一种不旋转 $180^\circ$ 的 Y 图定义——反射系数相位从圆图另一端测量。

### 3.3.2 组合 ZY-Smith 圆图

> 【插入 Ludwig 图 3-12】ZY-Smith 圆图——Z 图和 Y 图叠加在同一图形显示中

**ZY-Smith 圆图**将 Z 和 Y 圆图叠在一起 → **一个点有双重解释**（阻抗或导纳），取决于选 Z 图还是 Y 图读数。允许阻抗和导纳之间直接转换，无需旋转。

**例 3-7**：$z = 0.5 + j0.5$ 在 ZY 图上的对应导纳为 $y = 1 - j1$。$y = 1 + j2$ 对应 $z$ 也同理可读。

> ZY 图因信息密集、"繁忙"，需一定练习才能熟练使用。且电感和电容的正负符号取决于当前用阻抗还是导纳表示法。

## 3.4 并联和串联连接

分析 R/L/C 基本组合在 Smith 圆图上随频率变化的阻抗/导纳轨迹，为第 8 章匹配网络设计和等效电路模型建立直觉。以下所有例子中 $Z_0 = 50\Omega$ 仅作为归一化因子。

### 3.4.1 并联 RL

在 **Y-Smith 圆图**（上半平面）上操作。$g = Z_0/R$，$b_L = +Z_0/(\omega L)$：

$$y_{\text{in}}(\omega) = g - j\frac{Z_0}{\omega L} \tag{3.25}$$

频率 $\uparrow$ → 电纳 $|\!-\!jb_L|$ $\downarrow$ → 沿**恒定 $g$ 圆**向上移动。$L = 10$ nH 时：500 MHz → $b_L = -1.59$、4 GHz → $b_L = -0.20$。

> 【插入 Ludwig 图 3-13】并联 RL 导纳轨迹——恒定 $g$ 圆上的圆弧

### 3.4.2 并联 RC

在 **Y-Smith 圆图**（下半平面）上操作。$b_C = Z_0\omega C$：

$$y_{\text{in}}(\omega) = g + jZ_0\omega C \tag{3.26}$$

频率 $\uparrow$ → 电纳 $\uparrow$ → 沿恒定 $g$ 圆向下移动。$C = 1$ pF：500 MHz → $b_C = 0.16$、4 GHz → $b_C = 1.26$。

> 【插入 Ludwig 图 3-14】并联 RC 导纳轨迹

### 3.4.3 串联 RL

在 **Z-Smith 圆图**（上半平面）上操作。$x_L = \omega L/Z_0$：

$$z_{\text{in}}(\omega) = r + j\omega L/Z_0 \tag{3.27}$$

频率 $\uparrow$ → 电抗 $\uparrow$ → 沿恒定 $r$ 圆向上移动。$L = 10$ nH：500 MHz → $x_L = 0.63$、4 GHz → $x_L = 5.03$。

> 【插入 Ludwig 图 3-15】串联 RL 阻抗轨迹

### 3.4.4 串联 RC

在 **Z-Smith 圆图**（下半平面）上操作。$x_C = 1/(\omega C Z_0)$：

$$z_{\text{in}}(\omega) = r - j\frac{1}{\omega C Z_0} \tag{3.28}$$

频率 $\uparrow$ → 电抗幅值 $\downarrow$ → 沿恒定 $r$ 圆向上（向实轴收缩）。$C = 1$ pF：500 MHz → $x_C = -6.03$、4 GHz → $x_C = -0.8$。

> 【插入 Ludwig 图 3-16】串联 RC 阻抗轨迹

> 【插入 Ludwig 图 3-17】T 网络 → BJT 基极-发射极输入阻抗模型（$R_L \parallel C_L$）+ 串联 $L_1$ + 并联 $C$ + 串联 $L_2$

**在 ZY-Smith 圆图上按节点交替使用 Z 和 Y 视角**：

| 步骤 | 操作 | 圆图模式 | 路径 |
|------|------|----------|------|
| A | $R_L = 31.25\Omega \to g_A = 1.6$ | Y | 定位 |
| A→B | 并联 $C_L = 1.91$ pF $\to b_{C_L} = 1.2$ @ 2 GHz | Y | 沿恒定 $g$ 圆 |
| B | 转 Z 读数：$z_B = 0.4 - j0.3$ | Z | — |
| B→C | 串联 $L_1 \to x_{L_1} = 1.1$ | Z | 沿恒定 $r=0.4$ 圆 |
| C | 转 Y 读数：$y_C = 0.5 - j1.0$ | Y | — |

| D→E | 串联 $L_2 \to x_{L_2} = 1.0$ | Z | 沿恒定 $r=1$ 圆 |

**核心方法**：并联元件在 Y 图上沿恒定 $g$ 圆移动，串联元件在 Z 图上沿恒定 $r$ 圆移动。**ZY 图的作用就是让你在每一步用最方便的模式**——并联用导纳、串联用阻抗。

## 3.5 本章小结

Smith 圆图是 RF 设计中使用最广泛的图形工具，显示传输线阻抗随线长或频率的变化。核心方程：

- **归一化阻抗**：$z_{\text{in}} = (1+\Gamma)/(1-\Gamma)$
- **电阻圆**：$(\Gamma_r - \frac{r}{r+1})^2 + \Gamma_i^2 = (\frac{1}{r+1})^2$
- **电抗圆**：$(\Gamma_r - 1)^2 + (\Gamma_i - \frac{1}{x})^2 = (\frac{1}{x})^2$
- 两圆组合叠在 $|\Gamma| \leq 1$ 单位圆上 → Smith 圆图
- 一圈 = $\lambda/2$（因为 $\Gamma$ 含 $2\beta d$）
- **SWR** = $(1+|\Gamma|)/(1-|\Gamma|)$，可直接从圆图读取

**导纳变换**：$y_{\text{in}} = (1-\Gamma)/(1+\Gamma) = z_{\text{in}}(\Gamma \cdot e^{-j\pi})$ ——只需 $180^\circ$ 旋转。ZY-Smith 圆图叠加使用，实现并联/串联的快速交替计算。

计算工具：MMICAD/ADS 等 CAD 程序，或 MATLAB/Mathematica 等数学软件可实现自定义 Smith 圆图计算。
