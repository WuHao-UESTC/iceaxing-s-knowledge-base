# 引言

反相器是所有数字设计的核心——一旦理解了它的工作和性质，逻辑门、加法器、乘法器和微处理器的电气特性几乎都可以由反相器的结果推断出来；对反相器的分析也可以延伸来解释 NAND、NOR、XOR 等更复杂的门，而这些门又构成乘法器、处理器等模块的建筑块。

本章集中讨论**静态 CMOS 反相器**，它是目前最普遍的反相器。分析围绕第 1 章概括的四个设计指标：

- **成本**：用复杂性和面积表示；
- **完整性和稳定性**：用静态（稳态）特性表示；
- **性能**：由动态（瞬态）响应决定；
- **能量效率**：由能耗和功耗决定。

由此建立门的模型、确定设计参数，并给出选择参数值以满足技术要求的方法；同时讨论这些参数如何受工艺缩小影响。虽然本章只看 CMOS 反相器，但第 6 章会看到同样的方法适用于其他门拓扑。

# 静态 CMOS 反相器——直观综述

用第 3 章的 MOS 开关模型（$|V_{GS}|<|V_T|$ 时无限关断电阻，否则有限导通电阻）即可理解工作原理：

- $V_{in}$ 为高（$=V_{DD}$）：**NMOS 导通、PMOS 截止** → 输出与地之间直接通路 → 稳态 $V_{out}=0$；
- $V_{in}$ 为低（0 V）：**NMOS 截止、PMOS 导通** → $V_{DD}$ 与输出之间通路 → 高电平输出。

从开关级角度可以推出静态 CMOS 的许多重要特性：

1. **输出高、低电平分别为 $V_{DD}$ 和 GND**——电压摆幅等于电源电压，因此噪声容限很大。
2. **逻辑电平与器件相对尺寸无关**，晶体管可取最小尺寸——这种门称为**无比逻辑（ratioless logic）**；有比逻辑则靠组成逻辑的晶体管相对尺寸决定逻辑电平。
3. **稳态时输出与 $V_{DD}$ 或 GND 之间总存在有限电阻通路** → 设计良好的 CMOS 反相器具有**低输出阻抗**（典型 kΩ 量级），对噪声和干扰不敏感。
4. **输入电阻极高**——MOS 管的栅实际上是完全绝缘体，不取任何 dc 输入电流。理论上单个反相器可驱动无穷多个门（无穷大扇出）仍正确工作；但扇出增加会使瞬态响应变差、传播延时增大。
5. **稳态时电源线与地线之间没有直接通路** → 没有电流（忽略漏电流）→ **不消耗任何静态功率**。

> 这些观察看似显然却极为重要，是当今数字技术选择 CMOS 的主要原因之一。20 世纪 70 年代及 80 年代早期情况不同：早期微处理器（如 Intel 4004）只用 NMOS 工艺实现，因缺少互补器件而难以做到零静态功耗；静态功耗严格限制了单片可集成的门数，因此 80 年代工艺缩小到允许更高集成密度时不得不转向 CMOS。

**电压传输特性（VTC）** 的性质和形状可通过图解法叠加 NMOS 与 PMOS 的电流特性得到，这种图形称**负载曲线图**。需把两器件的 I-V 曲线换到一组公共坐标上——取 $V_{in}$、$V_{out}$、$I_{DN}$ 为变量，PMOS 关系经下式变换：

$$I_{DSp} = -I_{DSn},\qquad V_{GSn}=V_{in},\ V_{GSp}=V_{in}-V_{DD},\qquad V_{DSn}=V_{out},\ V_{DSp}=V_{out}-V_{DD}$$

PMOS 负载曲线 = 对 x 轴求镜像 + 向右平移 $V_{DD}$。

为使 dc 工作点成立，流过两管的电流必须相等——图解法即工作点必须处在两条相应负载线的**交点**上。对各 $V_{in}$（0、0.5、1、1.5、2、2.5 V）求交点可见：所有工作点不是在高输出电平就是在低输出电平。因此 **VTC 的过渡区非常窄**，这是开关过渡期间的高增益造成的——此时 NMOS 与 PMOS 同时导通且处于饱和，输入电压的微小变化即引起输出的极大改变。

**瞬态特性的定性分析**：响应主要由门的输出电容 $C_L$（NMOS/PMOS 漏扩散电容 + 连线电容 + 扇出门输入电容）决定。暂且假设晶体管切换瞬时发生，用开关模型可得：

- **由低至高**：$R_p$ 充电 $C_L$，响应时间由时间常数 $R_pC_L$ 决定；
- **由高至低**：$R_n$ 放电 $C_L$，取决于 $R_nC_L$。

（例 4.5 已表明此类电路的传播延时正比于时间常数。）**快速门的设计因此归结为减小输出电容或减小晶体管导通电阻**，后者靠加大 $(W/L)$ 实现。

# CMOS 反相器稳定性的评估——静态特性

定性讨论已给出 $V_{OH}\approx V_{DD}$、$V_{OL}\approx$ GND。本节确定 $V_M$（开关阈值）、$V_{IH}$、$V_{IL}$ 及噪声容限的精确值。

## 开关阈值

**开关阈值 $V_M$** 定义为 $V_{in}=V_{out}$ 的点，可用图解法由 VTC 与直线 $V_{in}=V_{out}$ 的交点求得。在该区域 $V_{DS}=V_{GS}$，PMOS 和 NMOS 总是饱和，令两管电流相等即得 $V_M$ 的解析式。

求解情形为电源电压足够高、两器件都处于**速度饱和**（$V_{DSAT}<V_M-V_T$），并忽略沟长调制：

$$k_nV_{DSATn}\Big(V_M-V_{Tn}-\frac{V_{DSATn}}{2}\Big) + k_pV_{DSATp}\Big(V_M-V_{DD}-V_{Tp}-\frac{V_{DSATp}}{2}\Big) = 0$$

解得

$$V_M = \frac{\Big(V_{Tn}+\dfrac{V_{DSATn}}{2}\Big) + r\Big(V_{DD}+V_{Tp}+\dfrac{V_{DSATp}}{2}\Big)}{1+r},\qquad r = \frac{k_pV_{DSATp}}{k_nV_{DSATn}} = \frac{v_{satp}W_p}{v_{satn}W_n}$$

（这里假设 PMOS 与 NMOS 栅氧厚度相同。）当 $V_{DD}$ 较大（与阈值电压及饱和电压相比）时可简化为

$$V_M \approx \frac{rV_{DD}}{1+r}$$

**开关阈值取决于比值 $r$**——PMOS 与 NMOS 的相对驱动强度比。一般希望 $V_M$ 处在电压摆幅中点（$V_{DD}/2$）附近，使低电平与高电平噪声容限具有相近的值；这要求 $r\approx1$，相当于

$$(W/L)_p = (W/L)_n\times\frac{V_{DSATn}k_n'}{V_{DSATp}k_p'}$$

反解可得使开关阈值等于目标 $V_M$ 所需的尺寸比：

$$\frac{(W/L)_p}{(W/L)_n} = \frac{k_n'V_{DSATn}\big(V_M-V_{Tn}-V_{DSATn}/2\big)}{k_p'V_{DSATp}\big(V_{DD}-V_M+V_{Tp}+V_{DSATp}/2\big)}$$

使用时须确认所选工作点下两器件仍处于速度饱和。

**长沟道器件或低电源电压**（不发生速度饱和，即 $V_M-V_T<V_{DSAT}$）时：

$$V_M = \frac{V_{Tn}+r(V_{DD}+V_{Tp})}{1+r},\qquad r=\sqrt{\frac{k_p}{k_n}}$$

**设计技术——使噪声容限最大**：设计静态 CMOS 电路时，若希望噪声容限最大并获得对称特性，应使 PMOS 部分比 NMOS 部分宽，以均衡晶体管的驱动强度。

**例 5.1**：求使 0.25 μm CMOS 反相器（$V_{DD}=2.5$ V，最小尺寸器件 $W/L=1.5$）开关阈值处在电源中点的尺寸：

$$\frac{(W/L)_p}{(W/L)_n} = \frac{115\times10^{-6}}{30\times10^{-6}}\times\frac{0.63}{1.0}\times\frac{(1.25-0.43-0.63/2)}{(1.25-0.4-1.0/2)} = 3.5$$

模拟（图 5.7）验证：PMOS/NMOS 比为 3.4 时开关阈值 1.25 V，与解析式一致。

![[数字集成电路-图5.7-开关阈值与尺寸比.jpg|700]]
*图 5.7 模拟得到的反相器开关阈值与 PMOS、NMOS 尺寸比的关系（0.25 μm CMOS，$V_{DD}=2.5$ V）*

由曲线可得两个有意义的结果：

1. **$V_M$ 对器件比值的变化相对不敏感**——比值取 3、2.5、2 时 $V_M$ 分别为 1.22 V、1.18 V、1.13 V。因此工业设计中使 PMOS 宽度小于完全对称所需值是可接受的。
2. **改变 $W_p/W_n$ 只是使 VTC 的过渡区平移**——增大 PMOS（或 NMOS）宽度使 $V_M$ 分别移向 $V_{DD}$（或 GND）。**不对称的传输特性在某些设计中恰恰是所希望的**：如图 5.8，输入信号的零值受噪声严重干扰，若通过对称反相器会产生错误输出；提高阈值后即可得到正确响应。但较大程度改变开关阈值并不容易，尤其当电源电压与阈值之比很小时（本例 2.5/0.4 = 6）——使阈值变为 1.5 V 需宽长比 11，进一步加大代价很高。

## 噪声容限

按定义，$V_{IH}$ 和 $V_{IL}$ 是 $\mathrm{d}V_{out}/\mathrm{d}V_{in}=-1$ 时反相器的工作点——即由反相器构成的放大器增益 $g=-1$ 的点。解析表达式确实可以推导，但往往使用不便，且对理解「什么参数决定噪声容限」帮助不大。

更简单的方法是对 VTC 采用**逐段线性近似**：把过渡区近似为一段直线，增益等于开关阈值 $V_M$ 处的增益 $g$，它与 $V_{OH}$、$V_{OL}$ 线的交点用来定义 $V_{IH}$ 和 $V_{IL}$。误差很小，完全在初步设计可接受范围内。由此得到

$$V_{IH}-V_{IL} = -\frac{(V_{OH}-V_{OL})}{g} = \frac{-V_{DD}}{g}$$
$$V_{IH} = V_M-\frac{V_M}{g},\qquad V_{IL} = V_M+\frac{V_{DD}-V_M}{g}$$
$$NM_H = V_{DD}-V_{IH},\qquad NM_L = V_{IL}$$

![[数字集成电路-图5.9-VTC逐段线性近似.jpg|450]]
*图 5.9 对 VTC 进行逐段线性近似简化了 $V_{IL}$ 和 $V_{IH}$ 的推导*

这些表达式清楚表明**过渡区应有较高增益**：增益无穷大的极端情形下，$NM_H\to V_{OH}-V_M$、$NM_L\to V_M-V_{OL}$，即跨越整个电压摆幅。

**中点增益**：饱和区增益与电流斜率关系很大，因此**不能忽略沟长调制系数**（否则会得到无穷大增益）。对开关阈值附近的电流式关于 $V_{in}$ 求导、令 $V_{in}=V_M$ 并忽略某些二次项，得

$$g = -\frac{1}{I_D(V_M)}\frac{k_nV_{DSATn}+k_pV_{DSATp}}{\lambda_n-\lambda_p} \approx \frac{1+r}{(V_M-V_{Tn}-V_{DSATn}/2)(\lambda_n-\lambda_p)}$$

$I_D(V_M)$ 是 $V_{in}=V_M$ 时流过反相器的电流。**增益几乎完全取决于工艺参数（尤其是沟长调制）**，设计者通过电源电压和晶体管尺寸只能产生很小的影响。

**例 5.2**：0.25 μm CMOS 反相器，PMOS 对 NMOS 比为 3.4，NMOS 取最小尺寸（$W=0.375\ \mu m$、$L=0.25\ \mu m$，即 $W/L=1.5$）：

$$I_D(V_M) = 1.5\times115\times10^{-6}\times0.63\times(1.25-0.43-0.63/2)\times(1+0.06\times1.25) = 59\ \mu A$$
$$g = \frac{1}{59\times10^{-6}}\cdot\frac{1.5\times115\times10^{-6}\times0.63 + 1.5\times3.4\times30\times10^{-6}\times1.0}{0.06+0.11} = -27.5$$

于是理论值 $V_{IL}=1.2$ V、$V_{IH}=1.3$ V、$NM_L=NM_H=1.2$ V。而模拟（图 5.10）给出 $V_{IL}=1.03$ V、$V_{IH}=1.45$ V，噪声容限 1.03 V 和 1.05 V。**实际值低于预测**有两方面原因：

1. 式(5.10) 高估了增益——实际最大增益（在 $V_M$ 处）仅 17；
2. 对 VTC 的逐段线性近似对实际噪声容限过于乐观。

模拟提取的低、高电平输出电阻分别为 **2.4 kΩ 和 3.3 kΩ**——输出电阻很好地衡量了门对输出端噪声的敏感程度，希望尽可能小。

![[数字集成电路-图5.10b-电压增益.jpg|400]]
*图 5.10 模拟得到的 CMOS 反相器（0.25 μm，$V_{DD}=2.5$ V）的电压传输特性和电压增益*

> 出乎意料的是，静态 CMOS 反相器也可以作为模拟放大器（过渡区增益相当高），但该区域非常窄，而且电源噪声抑制等性质很差。这正说明**模拟与数字设计的主要差别**：模拟设计者会把放大器偏置在过渡区中点以获得最大线性度，数字设计者则让器件工作在极端非线性区，从而得到定义明确、分离良好的高、低电平信号。

## 再谈稳定性

### 器件参数变化

设计针对典型器件参数，但实际工作温度会在很大范围内变化，制造后的器件参数也会偏离典型值。所幸静态 CMOS 反相器的**直流特性对这些变化相当不敏感**，能在很宽的工作条件下正确工作。

把典型器件替换为最好/最坏组合（好的 NMOS + 差的 PMOS，以及相反）重新模拟（图 5.11）：与典型响应比较表明门的工作不受影响，**这些变化主要引起开关阈值的平移**。这一特性确保了门能在很宽范围条件下工作，也是静态 CMOS 门普遍使用的主要原因。

### 降低电源电压

工艺尺寸连续缩小迫使电源电压按类似比例降低，而器件阈值电压实际上保持不变。这带来两个问题：反相器还能工作吗？电压降低是否存在限制？

**第一条线索**：式(5.10) 表明过渡区增益实际上**随电源电压降低而加大**——固定尺寸比 $r$ 时 $V_M$ 近似正比于 $V_{DD}$。图 5.12(a) 证实：$V_{DD}=0.5$ V（仅比阈值高 100 mV）时过渡区宽度只是电源电压的 10%（最大增益 35），而 $V_{DD}=2.5$ V 时为 17%。

既然能改善直流特性，为什么不全部采用低电源电压？三个重要理由：

1. 不加区分地降低电源电压虽对减少能耗有正面影响，却**绝对会加大门的延时**；
2. 一旦**电源电压与本征电压（阈值）变得可比拟，dc 特性对器件参数变化越来越敏感**；
3. 降低电源电压意味着**减小信号摆幅**——虽能减少内部噪声（如串扰），却使设计对并不减小的外部噪声源更加敏感。

**极限**：图 5.12(b) 画出同一反相器在 $V_{DD}=200$ mV、100 mV、50 mV 时的 VTC。奇怪的是，尽管电源电压不足以使晶体管导通，仍得到反相器特性——这可由**亚阈值工作**解释：亚阈值电流足以使门在高、低电平之间切换并提供足够增益。开关电流很低意味着反相器工作非常慢，但某些应用（如手表）可以接受。

接近 100 mV 时门的特性开始变差：$V_{OL}$ 和 $V_{OH}$ 不再等于电源的两个电平，过渡区增益接近 1。要获得足够增益，电源至少应为热电势 $\phi_T=kT/q$（室温 25 mV）的两倍，故

$$V_{DDmin} > 2\sim4\,\frac{kT}{q}$$

这是电源电压降低的实际限制——使 CMOS 反相器工作在 100 mV 以下的唯一方法是降低环境温度（冷却电路）。

**思考题 5.3**：电源电压低于阈值后晶体管工作在亚阈值区，显示指数 I-V 关系。设对称的 NMOS/PMOS 且 $V_M=V_{DD}/2$ 时增益最大，可推出

$$g = -\Big(\frac{1}{n}\Big)\big(e^{V_{DD}/2\phi_T}-1\big)$$

$n=1.5$、$\phi_T=25$ mV 时，增益在 $V_{DD}=48$ mV 降至 −1。

# CMOS 反相器的性能：动态特性

传播延时取决于分别通过 PMOS 和 NMOS 充电、放电负载电容 $C_L$ 所需的时间——因此**使 $C_L$ 尽可能小是实现高性能 CMOS 电路的关键**。本节先分析 $C_L$ 的主要组成部分，再推导延时并总结优化技术。

## 计算电容值

逐一考虑 MOS 电路中的每个电容在手工分析中事实上不可能（且 MOS 模型含许多非线性电容）。简化处理：把所有电容**集总**成一个接在 $V_{out}$ 与 GND 之间的单个电容 $C_L$——注意这是对实际情形的相当程度简化。

**栅漏电容 $C_{gd1,2}$**：在输出过渡的前半部（至 50% 点），$M_1$ 和 $M_2$ 不是断开就是处于饱和，此时 $C_{gd}$ 只包括 $M_1$、$M_2$ 的**覆盖电容**——沟道电容不起作用，因为它完全处在栅-体（断开时）或栅-源（饱和时）之间。

集总模型要求用接地电容代替浮空的栅漏电容，这通过**密勒效应**实现：在由低至高或由高至低的过渡中，栅漏电容两端的电压向相反方向变化，其电压变化是实际输出电压摆幅的**两倍**；为在输出节点产生同样的负载，接地电容的值必须是浮空电容的两倍：

$$C_{gd} = 2C_{GDO}W$$

$C_{GDO}$ 是 SPICE 模型中采用的单位宽度覆盖电容。

![[数字集成电路-图5.13-串联反相器寄生电容.jpg|700]]
*图 5.13 影响一对串联反相器动态特性的寄生电容*

![[数字集成电路-图5.14-密勒效应.jpg|700]]
*图 5.14 密勒效应——两端经历大小相同、相位相反电压摆幅的电容，可用两倍该值的接地电容代替*

**扩散电容 $C_{db1}, C_{db2}$**：来自反向偏置的 pn 结，是高度非线性的，且很大程度取决于所加电压。简化分析的最好办法是用一个线性电容代替，使它在所关注电压范围内的电荷变化与非线性电容相同——引入乘数因子 $K_{eq}$：

$$C_{eq} = K_{eq}C_{j0}$$

$$K_{eq} = \frac{-\phi_0^m}{(V_{high}-V_{low})(1-m)}\Big[(\phi_0-V_{high})^{1-m}-(\phi_0-V_{low})^{1-m}\Big]$$

$\phi_0$ 是内建结电势，$m$ 是结的梯度系数，反向偏置结的结电压取负值。

**例 5.3**：0.25 μm CMOS 反相器（$V_{DD}=2.5$ V）。传播延时定义在输入、输出翻转的 50% 之间，即 $V_{out}$ 达到 1.25 V 的时刻。因此高→低翻转在 $\{2.5, 1.25\}$ V 区间线性化结电容，低→高翻转在 $\{0, 1.25\}$ V 区间线性化。由此得到：

- NMOS 高→低（$V_{high}=-2.5$ V，$V_{low}=-1.25$ V）：底板 $K_{eq}(m=0.5,\phi_0=0.9)=0.57$，侧壁 $K_{eqsw}(m=0.44)=0.61$；
- NMOS 低→高（$V_{low}=0$，$V_{high}=-1.25$ V）：$K_{eq}=0.79$，$K_{eqsw}=0.81$；
- PMOS 高→低（衬底接 2.5 V，$V_{low}=0$，$V_{high}=-1.25$ V）：$K_{eq}(m=0.48)=0.79$，$K_{eqsw}(m=0.32)=0.86$；
- PMOS 低→高（$V_{low}=-1.25$ V，$V_{high}=-2.5$ V）：$K_{eq}=0.59$，$K_{eqsw}=0.7$。

线性化会使电压和电流波形有微小误差，但对逻辑延时没有明显影响。

**连线电容 $C_w$**：取决于连线的长度和宽度，并与扇出离开驱动门的距离及扇出门数目有关。如第 4 章所述，其重要性随工艺尺寸缩小日益增加。

**扇出的栅电容 $C_{g3}, C_{g4}$**：

$$C_{fan-out} = C_{gate}(\mathrm{NMOS}) + C_{gate}(\mathrm{PMOS})$$
$$= (C_{GSOn}+C_{GDOn}+W_nL_nC_{ox}) + (C_{GSOp}+C_{GDOp}+W_pL_pC_{ox})$$

该式有两方面简化：①假设栅电容的所有部分都连在 $V_{DD}$/GND 之间并忽略栅漏电容的密勒效应（误差较小，因为连接的门在达到 50% 点前不会翻转）；②假设所连接门的沟道电容在关注时间内保持不变——实际总沟道电容在饱和时的约 $\frac{2}{3}WLC_{ox}$ 与线性/截止时的 $WLC_{ox}$ 之间变化。忽略这一变化使估计偏保守、约有 10% 误差，对一阶分析可以接受。

**例 5.4**：0.25 μm CMOS 最小尺寸对称反相器（图 5.15 版图）。由版图算出尺寸、扩散区面积和周长：

- **NMOS 漏区**：金属-扩散接触孔（$4\times4\lambda^2$）+ 接触孔与栅之间的矩形（$3\times1\lambda^2$）= $19\lambda^2 = 0.3\ \mu m^2$；周长（逆时针）$5+4+4+1+1=15\lambda = 1.875\ \mu m$（**不含栅一侧，因为它不算侧壁的一部分**）。
- **PMOS 漏区**：$AD = 5\times9\lambda^2 = 45\lambda^2 = 0.7\ \mu m^2$，$PD = 5+9+5 = 19\lambda = 2.375\ \mu m$。

电容参数：$C_{GDO}(\mathrm{NMOS})=0.31$ fF/μm，$C_J(\mathrm{NMOS})=2$ fF/μm²。导线（Metal1 与多晶，不在有源扩散区上）面积分别为 $42\lambda^2$ 和 $72\lambda^2$；取 $\lambda=0.125\ \mu m$ 并由表 4.2 互连参数得（忽略边缘电容，导线很短）

$$C_{wire} = \frac{42}{8^2}\mu m^2\times30\ \mathrm{aF/\mu m^2} + \frac{72}{8^2}\mu m^2\times88\ \mathrm{aF/\mu m^2} = 0.12\ \mathrm{fF}$$

合并所有部分（用例 5.3 的 $K_{eq}$ 计算扩散电容）：**高→低 $C_L=6.1$ fF，低→高 $C_L=6.0$ fF**。注意负载电容几乎平均分配在它的两个主要部分——本征电容（扩散电容 + 覆盖电容，$C_{int}=3.0$ fF）和外部负载电容（导线 + 所连接的门，$C_{ext}=3.15$ fF）。

## 传播延时：一阶分析

计算传播延时的一种方法是对电容的充（放）电电流积分：

$$t_p = \int_{v_1}^{v_2}\frac{C_L(v)}{i(v)}\,\mathrm{d}v$$

但 $C_L(v)$ 和 $i(v)$ 都是 $v$ 的非线性函数，确切求解很困难。故回到简化的反相器开关模型：用一个在所关注时间间隔内取平均值的**常数线性元件**分别代替导通电阻和负载电容（后者已在上一节精确推导）。平均导通电阻为

$$R_{eq} = \frac{1}{V_{DD}/2}\int_{V_{DD}/2}^{V_{DD}}\frac{V}{I_{DSAT}(1+\lambda V)}\,\mathrm{d}V \approx \frac{3}{4}\frac{V_{DD}}{I_{DSAT}}\Big(1-\frac{7}{9}\lambda V_{DD}\Big)$$

$$I_{DSAT} = k'\frac{W}{L}\Big((V_{DD}-V_T)V_{DSAT}-\frac{V_{DSAT}^2}{2}\Big)$$

于是问题化为一阶线性 RC 电路（与例 4.5 完全相同）——传播延时正比于下拉电阻与负载电容形成的时间常数：

$$t_{pHL} = \ln(2)R_{eqn}C_L = 0.69R_{eqn}C_L$$
$$t_{pLH} = 0.69R_{eqp}C_L$$

（假设两种翻转的等效负载电容相同。）总传播延时取两者平均：

$$t_p = \frac{t_{pHL}+t_{pLH}}{2} = 0.69C_L\Big(\frac{R_{eqn}+R_{eqp}}{2}\Big)$$

希望一个门对上升和下降输入具有相同的传播延时，这可通过使 NMOS 与 PMOS 导通电阻近似相等实现——**这一条件与对称 VTC 所要求的条件相同**。

**例 5.5**：0.25 μm CMOS 反相器（图 5.15）。$V_{DD}=2.5$ V 时 $R_{eqn}=13$ kΩ、$R_{eqp}=31$ kΩ；由版图 NMOS 的 $W/L=1.5$、PMOS 的 $W/L=4.5$：

$$t_{pHL} = 0.69\times\Big(\frac{13\ \mathrm{k}\Omega}{1.5}\Big)\times6.1\ \mathrm{fF} = 36\ \mathrm{ps}$$
$$t_{pLH} = 0.69\times\Big(\frac{31\ \mathrm{k}\Omega}{4.5}\Big)\times6.0\ \mathrm{fF} = 29\ \mathrm{ps}$$
$$t_p = \frac{36+29}{2} = 32.5\ \mathrm{ps}$$

对由版图提取的电路做 SPICE 瞬态模拟（图 5.16）给出 $t_{pHL}=39.9$ ps、$t_{pLH}=31.7$ ps——考虑到手工分析中的诸多简化，结果相当好。特别要注意模拟输出中的**过冲**：它由反相器晶体管的栅漏电容造成——在晶体管对输入变化开始响应之前，就把输入节点上变化陡峭的阶跃电压直接耦合到输出。这些过冲对门性能有负面影响，也解释了为什么模拟延时比估计值大。

> 警告：这不意味着手工分析总能接近实际响应——一阶与高阶模型之间常存在很大偏差。手工分析的目的是获得对电路特性的基本了解并确定主要参数；需要定量数据时，细节模拟不可缺少。

![[数字集成电路-图5.16-模拟瞬态响应.jpg|450]]
*图 5.16 模拟得到的图 5.15 反相器的瞬态响应*

**展开延时公式**（暂且忽略沟长调制 $\lambda$）：

$$t_{pHL} = 0.69\cdot\frac{3}{4}\cdot\frac{C_LV_{DD}}{I_{DSATn}} = 0.52\frac{C_LV_{DD}}{(W/L)_nk_n'V_{DSATn}(V_{DD}-V_{Tn}-V_{DSATn}/2)}$$

多数设计中电源电压足够高，$V_{DD}\gg V_{Tn}+V_{DSATn}/2$，此时**延时实际上与电源电压无关**：

$$t_{pHL}\approx 0.52\frac{C_L}{(W/L)_nk_n'V_{DSATn}}$$

这只是一阶近似：由于沟长调制系数非零，提高 $V_{DD}$ 仍会使性能得到虽小但可观察的改善。图 5.17 与图 3.28（$R_{eq}$ 与 $V_{DD}$ 的关系）形状完全一致；当 $V_{DD}$ 接近 $2V_T$ 时延时开始迅速增加，因此若高性能是主要目标，显然应避免在该工作区工作。

![[数字集成电路-图5.17-传播延时与电源电压.jpg|450]]
*图 5.17 CMOS 反相器传播延时与电源电压的关系（归一至 2.5 V）。小方块为式(5.21) 的预测值；该式只在器件速度饱和时成立，故低电源电压时会有偏差*

**设计技术——减小传播延时的三条途径**：

1. **减小 $C_L$**。负载电容由三部分组成：门本身的内部扩散电容、互连线电容、扇出电容。细致的版图设计有助于减少前两者；优秀的设计实践要求漏扩散区面积越小越好。
2. **增加晶体管的 $(W/L)$**。这是设计者手中最有力、最有效的性能优化工具，但必须当心：增加晶体管尺寸也增加扩散电容，因而增加 $C_L$。一旦本征电容（扩散电容）开始超过由连线和扇出形成的外部负载，**再加大门的尺寸就不再有助于减少延时**，只是加大面积——这称为**自载效应**。此外较宽的晶体管栅电容更大，增加了驱动门的扇出系数，反过来又影响它的速度。
3. **提高 $V_{DD}$**。由图 5.17，门的延时可随电源电压调整，这一灵活性使设计者可以用能量损耗换取性能。但超过一定程度后改善非常有限；同时可靠性考虑（氧化层击穿、热电子效应）迫使深亚微米工艺对电源电压规定严格上限。

**思考题 5.4**：也可以用等于关注时间间隔内平均充（放）电电流值的电流源来代替晶体管，由此用不同方法推导传播延时表达式。

## 从设计角度考虑传播延时

### NMOS 与 PMOS 的比

至今一直使 PMOS 较宽以匹配下拉 NMOS 的电阻（宽度比通常 3~3.5），目的是设计对称 VTC 并使高→低与低→高传播延时相等。**但这并不意味着该比值也给出最小的总传播延时**——如果对称性和噪声容限不是主要考虑因素，实际上有可能通过减小 PMOS 宽度来加快反相器速度。

理由：PMOS 较宽虽因充电电流增加而改善 $t_{pLH}$，却也因产生较大寄生电容而使 $t_{pHL}$ 变差。两种相反效应并存 → 必定存在使传播延时最优的宽度比。

**推导**：考虑两个完全相同的 CMOS 反相器串联，第一个门的负载电容可近似为

$$C_L = (C_{dp1}+C_{dn1}) + (C_{gp2}+C_{gn2}) + C_W$$

设 PMOS 为 NMOS 的 $\beta$ 倍（$\beta=(W/L)_p/(W/L)_n$），则所有晶体管电容近似同比例加大，$C_{dp1}\approx\beta C_{dn1}$、$C_{gp2}\approx\beta C_{gn2}$，于是

$$C_L = (1+\beta)(C_{dn1}+C_{gn2}) + C_W$$

代入总延时表达式，令 $\partial t_p/\partial\beta = 0$，得

$$\beta_{opt} = \sqrt{r\Big(1+\frac{C_w}{C_{dn1}+C_{gn2}}\Big)},\qquad r = \frac{R_{eqp}}{R_{eqn}}$$

- 导线电容可忽略时（$C_{dn1}+C_{gn2}\gg C_w$），$\beta_{opt}=\sqrt{r}$——**不同于非串联情形通常采用的 $r$**；
- 若导线电容占主导地位，则应采用较大的 $\beta$ 值。

这一分析得出一个令人奇怪的结果：**以对称性及噪声容限为代价时，较小的器件尺寸（因而较小的设计面积）反而得到较快的设计**。

**例 5.6**：由等效电阻值得比值 $\beta=2.4\ (=31\ \mathrm{k}\Omega/13\ \mathrm{k}\Omega)$ 时瞬态响应对称；而式(5.26) 预见最优性能的器件比值应为 1.6。模拟（图 5.18）验证：最优点发生在 $\beta=1.9$ 附近（比预见的略高），并在 $\beta=2.4$ 处上升与下降延时相同——当最坏情形延时是主要考虑因素时，这是一个所希望的工作点。

### 考虑性能时反相器尺寸的确定

假设一个对称反相器（PMOS 与 NMOS 尺寸使上升和下降延时相同）。其负载电容可分为**本征**与**外部**两部分，$C_L=C_{int}+C_{ext}$：$C_{int}$ 代表反相器的**自载**（本征输出电容），与 NMOS/PMOS 的扩散电容及栅漏覆盖（密勒）电容有关；$C_{ext}$ 是外部负载电容，来自扇出和导线电容。设 $R_{eq}$ 为门的等效电阻，则

$$t_p = 0.69R_{eq}(C_{int}+C_{ext}) = 0.69R_{eq}C_{int}\Big(1+\frac{C_{ext}}{C_{int}}\Big) = t_{p0}\Big(1+\frac{C_{ext}}{C_{int}}\Big)$$

其中

$$t_{p0} = 0.69R_{eq}C_{int}$$

代表负载只有本征电容（$C_{ext}=0$）时的延时，称**本征延时**或**无负载延时**。

引入**尺寸系数 $S$**（把反相器晶体管尺寸与一个参考门——通常是最小尺寸反相器——的尺寸联系起来）。本征电容 $C_{int}$ 包括扩散电容及密勒电容，都正比于晶体管宽度，故 $C_{int}=SC_{iref}$；门的电阻满足 $R_{eq}=R_{ref}/S$。于是

$$t_p = 0.69(R_{ref}/S)(SC_{iref})\Big(1+\frac{C_{ext}}{SC_{iref}}\Big) = t_{p0}\Big(1+\frac{C_{ext}}{SC_{iref}}\Big)$$

由此得出两个重要结论：

1. **本征延时 $t_{p0}$ 与门的尺寸无关**，只取决于工艺及反相器的版图——不存在外部负载时，门驱动强度的提高完全被随之增加的电容所抵消。
2. **使 $S$ 无穷大将达到最大可能的性能改善**（消除了外部负载的影响，延时降到本征延时）；但任何比 $C_{ext}/C_{int}$ 足够大的尺寸系数 $S$ 都会显著增加硅面积，却得到类似的结果。

**例 5.7**：由表 5.2 得 $C_{ext}/C_{int}\approx1.05$（$C_{int}=3.0$ fF、$C_{ext}=3.15$ fF）→ 最大性能改善预见为 **2.05**；尺寸放大系数为 10 时与最优性能差距在 10% 以内，再加大只能得到可忽略的改善。模拟（图 5.19）预见最大改善为 **1.9**（$t_{p0}=19.3$ ps）：$S=5$ 时已得到大部分改善，$S>10$ 几乎无额外收益。

### 确定反相器链的尺寸

加大反相器尺寸虽减小其延时，却也加大它的输入电容；孤立地确定门的尺寸而不考虑它对前级门延时的影响，纯属脱离实际的研究。研究起点是反相器链。

为决定输入负载效应，需建立反相器的输入栅电容 $C_g$ 与本征输出电容之间的关系。两者均正比于门尺寸，故下列关系与门尺寸无关：

$$C_{int} = \gamma C_g$$

$\gamma$ 是只与工艺有关的比例系数，对大多数亚微米工艺 $\gamma$ 接近于 1。于是

$$t_p = t_{p0}\Big(1+\frac{C_{ext}}{\gamma C_g}\Big) = t_{p0}(1+f/\gamma)$$

**反相器的延时只取决于它的外部负载电容与输入电容间的比值**，该比值称**等效扇出 $f$**。

考虑由 $N$ 个反相器组成的链，第一个反相器（通常为最小尺寸门）输入电容为 $C_{g1}$，链末端为固定的负载电容 $C_L$。第 $j$ 级反相器的延时为

$$t_{p,j} = t_{p0}\Big(1+\frac{C_{g,j+1}}{\gamma C_{g,j}}\Big) = t_{p0}(1+f_j/\gamma)$$

总延时为各级之和（$C_{g,N+1}=C_L$）。该方程含 $N-1$ 个未知数 $C_{g,2},\cdots,C_{g,N}$，通过求 $N-1$ 次偏微分并令其为零（$\partial t_p/\partial C_{g,j}=0$）可得最优条件：

$$C_{g,j+1}/C_{g,j} = C_{g,j}/C_{g,j-1},\qquad j=2,\cdots,N$$

即**每个反相器的最优尺寸是与它相邻前后两个反相器尺寸的几何平均数**：$C_{g,j}=\sqrt{C_{g,j-1}C_{g,j+1}}$。这意味着**每个反相器都相对前一级放大相同的倍数 $f$，各具有相同等效扇出与相同延时**。当 $C_{g,1}$ 和 $C_L$ 给定时，

$$f = \sqrt[N]{C_L/C_{g,1}} = \sqrt[N]{F},\qquad t_p = Nt_{p0}\big(1+\sqrt[N]{F}/\gamma\big)$$

$F=C_L/C_{g,1}$ 是电路的总等效扇出。注意 $t_p$ 与 $F$ 的关系与链的级数密切相关：只有一级时是线性关系，加入第二级变为平方根关系，依次类推。

### 选择一个反相器链的正确级数

对给定 $F=f^N$，选择级数需综合考虑：**级数太多**时本征延时项（第一项）占主导；**级数太少**时每级等效扇出变大，第二项占主导。对级数求导并令其为零得

$$f = e^{(1+\gamma/f)}$$

- 忽略自载（$\gamma=0$）时方程只有一个收敛解：$N=\ln(F)$，每级等效扇出 $f=e=2.71828$。这种以指数形式逐级放大尺寸的缓冲器设计称**指数锥形**。
- 包括自载时只能数值求解：对 $\gamma\approx1$ 的典型情形，最优锥形系数接近于 **3.6**。
- 通常做法是选择最优扇出约为 **4**——选择大于最优值不会过多影响延时，却能减少所需的缓冲器级数和实现面积；反之采用过多级数（$f<f_{opt}$）对延时有明显负面影响，应当避免。

### 输入信号的上升-下降时间

以上表达式都假设输入信号突然从 0 变到 $V_{DD}$（或相反），且假定充（放）电过程中只有两个晶体管中的一个导通。实际上输入信号逐渐变化，PMOS 与 NMOS 会暂时同时导通一段时间——这影响总的充（放）电电流，从而影响传播延时。

SPICE 模拟（图 5.23）表明：一旦 $t_s>t_p$，$t_p$ 随输入斜率（10%~90% 上升或下降时间）的增加而**近似线性增加**。

![[数字集成电路-图5.23-传播延时与输入斜率.jpg|450]]
*图 5.23 扇出为单个门的最小尺寸反相器：$t_p$ 与输入信号斜率（10%~90% 上升或下降时间）的关系*

虽然可以推导输入斜率与传播延时关系的解析式，但结果比较复杂。从设计角度看，把慢斜率的影响直接与造成它的原因（前一级门的有限驱动能力）联系起来更有意义。由此得到反相器链中传播延时的修正表达式：

$$t_p^i = t_{step}^i + \eta\,t_{step}^{i-1}$$

反相器 $i$ 的传播延时等于同样门在**阶跃输入**（斜率无穷大）时的延时 $t_{step}^i$ 加上它前面一级门 $(i-1)$ 阶跃输入延时的一部分。比例因子 $\eta$ 是经验常数，典型值约为 **0.25**。该式非常简单，又展示了计算复杂电路延时所需要的全部关系。

**例 5.9**：对图 5.22 电路，第 2 级反相器（灰色方块）的延时为

$$t_{p,2} = t_{p0}\Big(1+\frac{4C_{g,3}}{\gamma C_{g,2}}\Big) + \eta t_{p0}\Big(1+\frac{4C_{g,2}}{\gamma C_{g,1}}\Big)$$

按思考题 5.5 的方式对整个传播延时分析，得最小延时所需的尺寸修正值：

$$\frac{4(1+\eta)C_{g,2}}{C_{g,1}} = \frac{4(1+\eta)C_{g,3}}{C_{g,2}} = \frac{C_L}{C_{g,3}}$$

若 $\eta=0.25$，则 $f_2$ 和 $f_1$ 估计为 2.47。

**设计挑战**：保持门的输入信号上升时间小于或等于门的传播延时是很有利的——这不仅有利于提高性能，也有利于降低功耗。使信号的上升和下降时间较小且接近相等，是高性能设计面临的主要挑战之一，通常称为**斜率工程设计**。

**思考题 5.6**：降低电源电压使输入信号斜率对传播延时的影响是增加还是减少？为什么？

### 存在（长）互连线时的延时

当门之间的距离进一步加大时，导线的电容和电阻不能再忽略，甚至可能主导瞬态响应。可用第 4 章的导线模型修正延时表达式。考虑一个反相器通过长度为 $L$ 的导线驱动单个扇出：驱动器用单个电阻 $R_{dr}$ 代表（大小等于 $R_{eqn}$ 和 $R_{eqp}$ 的平均值），$C_{int}$ 和 $C_{fan}$ 分别为驱动器的本征电容和扇出门的输入电容。

运用 Elmore 延时表达式得

$$t_p = 0.69R_{dr}(C_{int}+C_{fan}) + 0.69(R_{dr}c_w+r_wC_{fan})L + 0.38r_wc_wL^2$$

因子 **0.38** 说明导线事实上表现为**分布**延时。$C_w$ 和 $R_w$ 分别代表导线的总电容和总电阻。该延时表达式含一个与导线长度成**线性**关系的部分及一个成**平方**关系的部分——正是后者使导线延时在较长导线的总延时中迅速占据支配地位。

![[数字集成电路-图5.24-反相器通过导线驱动门.jpg|450]]
*图 5.24 通过长度为 $L$ 的导线驱动单个门的反相器*

**例 5.10**：设 $C_{int}=3$ fF、$C_{fan}=3$ fF、$R_{dr}=0.5(13/1.5+31/4.5)=7.8$ kΩ；导线由 Metal1 实现、宽 0.4 μm（最小尺寸），得 $c_w=92$ aF/μm、$r_w=0.19\ \Omega/\mu m$。解二次方程得 **$L=65\ \mu m$** 时互连延时等于单纯由器件寄生参数引起的本征延时。

注意此时增加的延时**仅来自方程的线性部分**，更具体地说是由于导线引起的额外电容；二次部分（导线分布延时）只在导线长得多（>7 cm）时才起主导作用——这是由于（最小尺寸）驱动晶体管的高电阻所致。若使用较宽的管子，这两部分的对比情况就会不同。

# 功耗、能量和能量延时

静态 CMOS 的两大诱人之处——理想 VTC 带来的稳定性、稳态几乎零功耗——使它成为大多数现代数字设计的选择。前面的小节解决了「稳不稳、快不快」，本节解决「费不费电」。对 CMOS 功耗起支配作用的是**充放电电容引起的动态功耗**。

## 动态功耗

### 充放电电容引起的动态功耗

设输入上升/下降时间为零（即 NMOS 与 PMOS 绝不同时导通）。L→H 翻转时，电源提供的能量与翻转结束时存储在 $C_L$ 上的能量分别为

$$E_{VDD} = \int_0^\infty i_{VDD}(t)V_{DD}\,\mathrm{d}t = C_LV_{DD}\int_0^\infty \mathrm{d}v_{out} = C_LV_{DD}^2$$
$$E_C = \int_0^\infty i_{VDD}(t)v_{out}\,\mathrm{d}t = C_L\int_0^{V_{DD}}v_{out}\,\mathrm{d}v_{out} = \frac{C_LV_{DD}^2}{2}$$

也可直接观察：$C_L$ 被充以电荷 $C_LV_{DD}$，提供这些电荷需电源供给 $C_LV_{DD}^2$（$=Q\times V_{DD}$）的能量，而存储在电容上的只有 $C_LV_{DD}^2/2$。

![[数字集成电路-图5.25a-低至高翻转等效电路.jpg|400]]
![[数字集成电路-图5.25b-低至高翻转等效电路.jpg|400]]
*图 5.25 由低至高翻转期间的等效电路*

![[数字集成电路-图5.26-充放电输出电压和电源电流.jpg|450]]
*图 5.26 在 $C_L$ 充（放）电期间的输出电压和电源电流*

⚡ **电源提供的能量只有一半存进电容，另一半被 PMOS 消耗——且这一半与 PMOS 尺寸（因而与电阻）无关。** 放电时电荷从电容移去，能量全部消耗在 NMOS 中，同样与 NMOS 尺寸无关。

于是每个完整开关周期（L→H + H→L）消耗固定能量 $C_LV_{DD}^2$。计入开关频率：

$$P_{dyn} = C_LV_{DD}^2f_{0\to1}$$

$f_{0\to1}$ 是消耗能量的翻转频率（对静态 CMOS 即 0→1 翻转频率）。

**量级感**：0.25 μm CMOS、500 MHz、平均负载 15 fF/门、扇出 4、$V_{DD}=2.5$ V → 每门约 **50 μW**；100 万门设计若每时钟边沿都翻转 → **50 W**！这是悲观估计，实际电路的活动性远小于此。

**例 5.11**：例 5.4 的反相器（$C_L=6$ fF，$V_{DD}=2.5$ V）：

$$E_{dyn} = C_LV_{DD}^2 = 37.5\ \mathrm{fJ}$$

以最大可能速率开关（$T=1/f=t_{pLH}+t_{pHL}=2t_p=65$ ps）时 $P_{dyn}=E_{dyn}/(2t_p)=580\ \mu W$。实际电路很少以最高速率开关，输出也不会在两轨线间满摆幅。速率降为 4 GHz（$T=250$ ps）时功耗降为 **150 μW**（模拟 155 μW）。

### 开关活动性与等效电容

用 $f_{0\to1}$ 计算复杂电路功耗很麻烦——开关活动性取决于输入信号的统计特性（输入不变则动态功耗为零）、电路拓扑和实现的功能。故引入

$$P_{dyn} = C_LV_{DD}^2f_{0\to1} = C_LV_{DD}^2P_{0\to1}f = C_{EFF}V_{DD}^2f$$

$f$ 是输入发生变化事件的最大可能速率（常即时钟速率），$P_{0\to1}$ 是时钟事件在门输出端引起 0→1 变化的概率，$C_{EFF}=P_{0\to1}C_L$ 称**等效电容**（每时钟周期发生开关的平均电容）。开关因子 10% 时，上面 5 W 的例子降为 0.5 W。

**例 5.12**：输出波形每 8 个时钟发生 2 次消耗功率的翻转 → 翻转概率 0.25。

### 低能量-功耗设计技术

**降低 $V_{DD}$** 对 $P_{dyn}$ 的影响是**二次方**的：$V_{DD}$ 从 2.5 V 降到 1.25 V，功耗从 5 W 降到 1.25 W（前提是维持相同时钟速率；只要 $V_{DD}$ 远高于阈值，这一前提不算离谱，但 $V_{DD}$ 接近 $2V_T$ 时性能严重下降）。

当 $V_{DD}$ 下限受外部限制、或降压带来的性能损失不可接受时，减少功耗的**唯一办法是减少等效电容**——从两方面入手：**实际电容**与**翻转活动性**。

- 减少翻转活动性只能在**逻辑和结构抽象层次**实现（第 11 章）。
- 减少实际电容同时也能改善性能。组合逻辑中大部分电容是晶体管电容（栅电容 + 扩散电容），故低功耗设计应保持晶体管尺寸尽可能合理地最小。**晶体管尺寸应放大的唯一情形，是负载电容由外部电容（扇出或导线）主导**——这与通常单元库「使晶体管较大以覆盖一定负载与性能范围」的做法相反。

由此引出一个设计挑战：为在满足最低性能要求的同时最小化能耗，一个吸引人的做法是**尽量降低 $V_{DD}$、用加大晶体管补偿性能**——但加大尺寸会增加电容，$V_{DD}$ 足够低时后者将占主导、使能耗反而增加。

**例 5.13 使能耗最小的尺寸确定**：反相器驱动 $C_{ext}$、本身由最小尺寸门驱动。由 5.4.3 的链尺寸方法

$$t_p = t_{p0}\Big[\Big(1+\frac{f}{\gamma}\Big)+\Big(1+\frac{F}{f\gamma}\Big)\Big],\qquad t_{p0}\sim\frac{V_{DD}}{V_{DD}-V_{TE}}$$

$$E = V_{dd}^2C_{g1}\big[(1+\gamma)(1+f)+F\big]$$

（$F=C_{ext}/C_{g1}$ 为总等效扇出，$V_{TE}=V_T+V_{DSAT}/2$。）性能约束为尺寸放大电路的延时等于参考电路（$f=1$、$V_{dd}=V_{ref}$）的延时；取 $\gamma=1$：

$$\frac{t_p}{t_{p,ref}} = \Big(\frac{V_{DD}}{V_{ref}}\Big)\Big(\frac{V_{ref}-V_{TE}}{V_{DD}-V_{TE}}\Big)\Big(\frac{2+f+F/f}{3+F}\Big) = 1$$

这建立了 $f$ 与 $V_{DD}$ 的关系：曲线有显著最小值——从最小尺寸起加大尺寸最初提高性能、因而允许降压，直到 $f=\sqrt F$；再加大只增加自载、反而需要升压。$F=1$ 时参考电路（最小尺寸）已是最好的结果。

$$\frac{E}{E_{ref}} = \Big(\frac{V_{DD}}{V_{ref}}\Big)^2\Big(\frac{2+2f+F}{4+F}\Big)$$

*图 5.28 CMOS 反相器驱动一个外部负载电容 $C_{ext}$，而它本身又由一个最小尺寸的门驱动*

![[数字集成电路-图5.29a-电源电压与尺寸系数关系.jpg|400]]
![[数字集成电路-图5.29b-能量与尺寸系数关系.jpg|400]]

三个结论：①改变尺寸 + 降低 $V_{DD}$ 是减小能耗的非常有效手段，大等效扇出电路可获近**十倍**能量下降；②**过度加大尺寸付出较大能量代价**（而这是当今许多设计的通病）；③**考虑能量的最优尺寸系数小于考虑性能的最优尺寸系数**——扇出 20 时 $f_{opt}$（能量）=3.53 而 $f_{opt}$（性能）=4.47。

⚡ 这是「速度–面积–功耗」三角在反相器上的具体体现：**能量最优与性能最优是两个不同的工作点**。

### 直接通路（短路）电流功耗

输入斜率不为零 → 开关过程中 NMOS/PMOS 同时导通 → $V_{DD}$ 与 GND 间短暂直流通路。设电流脉冲近似三角形、上升下降对称：

$$E_{dp} = t_{sc}V_{DD}I_{peak},\qquad P_{dp} = t_{sc}V_{DD}I_{peak}f = C_{sc}V_{DD}^2f$$

$t_{sc}$ 为两器件同时导通的时间，对直线输入斜率

$$t_{sc} = \frac{V_{DD}-2V_T}{V_{DD}}t_s \approx \frac{V_{DD}-2V_T}{V_{DD}}\cdot\frac{t_{r(f)}}{0.8}$$

**短路电流由输入/输出上升下降时间之比决定**（关键洞察）：

- **负载电容很大**（输出下降时间 ≫ 输入上升时间）：输入在输出开始改变前已通过过渡区，此时 PMOS 的源漏电压近似为 0，几乎未传导电流就断开 → **短路电流接近零**；
- **负载电容很小**（输出下降时间 ≪ 输入上升时间）：PMOS 源漏电压在翻转的大部分时间等于 $V_{DD}$ → **最大短路电流**（= PMOS 饱和电流），这是**最坏情况**。

⚡ 结论：使**输出**上升/下降时间大于**输入**上升/下降时间可最小化短路功耗——但输出太慢会降低速度并在扇出门中引起短路电流。**只顾局部优化而不顾全局会带来不良后果。**

**设计技术**（Veendrick84）：通过使输入和输出信号的上升/下降时间**匹配**来最小化短路功耗；在整个电路层次上，所有信号的上升/下降时间应保持在界定范围内不变。对单个门而言，使输入输出上升时间相等并非其自身最优，但却能把整个电路的短路电流控制在范围内。当输入/输出上升时间比 $r>2\sim3$（负载电容太小）时，功耗主要来自短路电流；$r=1$ 时大部分功耗与动态功耗有关，短路仅占 **<10%**。

- 降低 $V_{DD}$ 使短路电流影响减小（从 $t_{sc}$ 式可见）；极端情形 $V_{DD}<V_{Tn}+|V_{Tp}|$ 时短路功耗完全消除（两器件永不同时导通）。
- 阈值电压以比电源电压更低的速率下降 → 短路功耗在深亚微米工艺中变得较不重要。$V_{DD}=2.5$ V、$V_T\approx0.5$ V 时，输入/输出上升下降时间比为 2 才引起功耗增加 10%。
- 短路功耗可用一个与 $C_L$ 并联的 $C_{sc}=t_{sc}I_{peak}/V_{DD}$ 来模拟。

## 静态功耗

$$P_{stat} = I_{stat}V_{DD}$$

$I_{stat}$ 是没有开关活动时电源两轨线之间流动的电流。理想情况为零（PMOS/NMOS 稳态不同时导通），实际有两个来源：

**① 二极管结泄漏**：源（或漏）与衬底之间反向偏置的二极管结。室温下每单位漏极面积的泄漏电流 **10～100 pA/μm²**。100 万门、每门漏极面积 0.5 μm²、2.5 V → 最坏 **0.125 mW**，不严重。但结泄漏由**热产生的载流子**引起，随结温呈**指数**增加——85 °C（民用硬件结温上限）时为室温的 **60 倍**。故保持电路工作温度低是所期望的目标。

**② 亚阈值电流**（越来越突出的来源）：$V_{GS}$ 小于阈值电压时仍可有漏源电流；$V_T$ 越接近 0 V，$V_{GS}=0$ 时的泄漏越大。为此标准工艺的 $V_T$ **从未小于 0.5～0.6 V**（有时约 0.75 V）。

![[数字集成电路-图5.34-CMOS反相器泄漏电流来源.jpg|450]]
*图 5.34 CMOS 反相器中泄漏电流的来源（$V_{in}=0$ V）*

**核心矛盾**：工艺缩小要求降低 $V_{DD}$；保持 $V_T$ 不变会造成严重性能损失（$V_{DD}$ 接近 $2V_T$ 时）；解决办法是同时降低 $V_T$——但 $V_T$ 的下限由**允许的亚阈值漏电流**决定（图 5.35）。因此

⚡ **阈值电压的选择 = 性能与静态功耗之间的权衡。**

能生产迅速彻底关断特性的工艺将更引人注目——如**绝缘体上硅（SOI）**，其 MOS 管具有接近理想的 **60 mV/十倍电流降**斜率系数。

![[数字集成电路-图5.35-降低阈值增加亚阈值电流.jpg|450]]
*图 5.35 $V_{GS}=0$ 时降低阈值会使亚阈值电流增加*

**例 5.14**：0.25 μm 最小尺寸 NMOS，斜率系数 $S=90$ mV/十倍电流降，$V_T\approx0.5$ V 时关断电流 $10^{-11}$ A。$V_T$ 降 200 mV 到 0.3 V → 关断电流加大 **170 倍**！100 万门设计、1.5 V 电源 → 静态功耗 **2.6 mW**；$V_T$ 进一步降到 100 mV → 约 **0.5 W**（无法接受）——但性能分别提高 25% 和 40%。

**阈值的下限在某种意义上是人为决定的**：CMOS 泄漏电流「必须为零」的观念不正确。泄漏会使噪声容限减小（逻辑电平不再等于全部电源电压），但只要噪声容限在一定范围内就不严重。泄漏引起的静态功耗可用降低 $V_{DD}$ 补偿，而降低 $V_{DD}$ 又不降低性能可通过降低 $V_T$ 达到 → 结果是**动态功耗以平方关系下降**。对 0.25 μm CMOS，以下两组配置可得相同性能：**3 V–$V_T$ 0.7 V** 与 **0.45 V–$V_T$ 0.1 V**，但后者动态功耗可降至前者的 **1/45**。

因此**最佳工作点取决于电路的活动性**。存在相当大静态功耗时，使不工作的模块暂时断电（待机）很重要——可通过切断工作单元与电源线的连接或降低电源电压实现。

## 综合考虑

$$P_{tot} = P_{dyn}+P_{dp}+P_{stat} = (C_LV_{DD}^2+V_{DD}I_{peak}t_s)f_{0\to1}+V_{DD}I_{leak}$$

典型 CMOS 电路中**电容功耗占主导**；直接通路功耗可通过细心设计控制在限定范围内；漏电目前可忽略，但在不久的将来会改变。

### 功耗-延时积与能量-延时积

**功耗-延时积（PDP）**作为逻辑门的质量评定指标：

$$\mathrm{PDP} = P_{av}t_p$$

单位 W×s = 焦耳，是**能量**的衡量。设门以最大可能速率 $f_{max}=1/(2t_p)$ 切换、忽略静态和短路功耗：

$$\mathrm{PDP} = C_LV_{DD}^2f_{max}t_p = \frac{C_LV_{DD}^2}{2}$$

PDP 代表**每次翻转**消耗的能量；一个反相器周期含一个 0→1 和一个 1→0 翻转，故每周期能量 $E_{av}=2\,\mathrm{PDP}$。

**PDP 的缺陷**：对给定结构，它可以通过降低电源电压而任意缩小——照此逻辑，最优电压应是仍能保证功能的最低电压，但这要以牺牲性能为代价。更合适的指标应把性能与能量放在一起：

$$\mathrm{EDP} = \mathrm{PDP}\times t_p = P_{av}t_p^2 = \frac{C_LV_{DD}^2}{2}t_p$$

**EDP 与电压的关系**：高 $V_{DD}$ 减小延时但增加能耗，低 $V_{DD}$ 相反 → 必存在最优工作点。设 NMOS/PMOS 具有可比拟的阈值与饱和电压，把 $t_p\approx\dfrac{\alpha C_LV_{DD}}{V_{DD}-V_{TE}}$ 代入：

$$\mathrm{EDP} = \frac{\alpha C_L^2V_{DD}^3}{2(V_{DD}-V_{TE})}\ \Longrightarrow\ \frac{\partial\,\mathrm{EDP}}{\partial V_{DD}}=0\ \Rightarrow\ V_{DDopt} = \frac{3}{2}V_{TE}$$

这给出一个能**同时**优化性能与能耗的较低电源电压。阈值在 0.5 V 范围的亚微米工艺 → 最优 $V_{DD}$ 约 **1 V**。

**例 5.15**：0.25 μm 工艺 $V_{TEn}=0.74$ V、$V_{TEp}=-0.9$ V → $V_{TE}\approx0.8$ V → $V_{DDopt}=1.2$ V（模拟证实为 1.1 V）。图 5.36 清楚显示了延时与能量之间的互换关系。

![[数字集成电路-图5.36-归一化延时能量EDP.jpg|450]]
*图 5.36 0.25 μm CMOS 反相器归一化的延时、能量及能量-延时积的曲线图*

> 警告：EDP 最优电压并不一定是某给定设计的最优电压。要求延时最小的设计需要以能量为代价的更高电压；低能量设计可以工作在低电压下、并采用流水线或并行性等结构技术来获取系统总性能。

⚡ 与模拟设计的对照（同一晶体管，两种哲学）：模拟电路把晶体管偏置在**过渡区中点**，换取最大线性度与增益（Razavi 的 $g_m$、$r_o$、偏置电流）；数字电路把晶体管推向**极端非线性区**——开关瞬间追求最大电流（要快），稳态追求最小电流（省电）。本节所有折中本质上都是「如何在 $V_{DD}$、$V_T$、$W/L$ 之间分配这笔预算」。

## 利用 SPICE 分析功耗

平均功耗：

$$P_{av} = \frac{1}{T}\int_0^Tp(t)\,\mathrm{d}t = \frac{V_{DD}}{T}\int_0^Ti_{DD}(t)\,\mathrm{d}t$$

HSPICE 可用 `.MEASURE TRAN I(VDD) AVG` 直接计算。其他 SPICE 版本功能有限，但 SPICE 本质是微分方程求解器——可构造一个简单的**积分器电路**：电源电流由电流控制电流源度量并在电容 $C$ 上积分，电阻 $R$ 仅用于直流收敛（尽量大以减小漏电）：

$$C\frac{\mathrm{d}P_{av}}{\mathrm{d}t} = ki_{DD}\ \Longrightarrow\ P_{av} = \frac{k}{C}\int_0^Ti_{DD}\,\mathrm{d}t$$

等效电路参数须满足 $k/C = V_{DD}/T$。

![[数字集成电路-图5.37-SPICE度量平均功耗等效电路.jpg|450]]
*图 5.37 用 SPICE 度量平均功耗的等效电路*

**例 5.16**：例 5.4 的反相器在 250 ps 翻转周期中（$k=1$，$V_{DD}=2.5$ V → $C=100$ pF）：平均功耗约 **157.3 μW**，而 `.MEAS AVG` 给 160.3 μW（两法近似等效），对应能量 39 fJ（接近例 5.11 的 37.5 fJ）。由高至低翻转期间功耗有轻微负向跌落——输入输出间的耦合使输出短暂超过 $V_{DD}$ 时电流注入电源。

# 综述：工艺尺寸缩小及其对反相器衡量指标的影响

短沟器件的尺寸缩小情形（$S$、$U$ 分别为工艺与电压缩小参数）：

| 参数 | 关系式 | 全比例缩小 | 一般化缩小 | 恒压缩小 |
|---|---|---|---|---|
| 面积/器件 | $WL$ | $1/S^2$ | $1/S^2$ | $1/S^2$ |
| 本征延时 | $R_{on}C_{gate}$ | $1/S$ | $1/S$ | $1/S$ |
| 本征能量 | $C_{gate}V^2$ | $1/S^3$ | $1/(SU^2)$ | $1/S$ |
| 本征功率 | 能量/单位延时 | $1/S^2$ | $1/U^2$ | 1 |
| 功率密度 | 功率/单位面积 | 1 | $S^2/U^2$ | $S^2$ |

理论预见已被数十年趋势证实：**门延时以每年 13% 速率指数下降**（每五年减半），与 $S$ 平均约 1.15 一致。两输入 NAND（扇出 4）的延时从 20 世纪 60 年代的几十 ns → 2000 年的 0.1 ns → 2010 年的几十 ps。

![[数字集成电路-图5.39-门延时的减小.jpg|450]]
*图 5.39 门延时的减小*

对 1980–1995 年大量设计的统计表明，功率密度近似随 $S^2$ 增加，对应**恒压缩小**情形；近年期望与**全缩小**（功率密度不变）更一致——因为电源电压加速降低、低功耗设计技术日益受关注。但**芯片总功耗仍将因芯片尺寸增大而继续增长**。

![[数字集成电路-图5.40-功率密度的增加.jpg|450]]
*图 5.40 微处理器和 DSP 处理器中功率密度的增加与尺寸缩小系数 $S$ 的关系（对 4 μm 工艺归一至 1）*

**缩小模型的主要缺陷**：以上只给出仅考虑器件参数的「本征」值。而互连线表现出**不同的尺寸缩小特性**，其寄生参数可能支配整个性能；连线电容充放电的能量也可能占据总能量的主要部分。采用第 4 章的固定电阻模型、并假设驱动器电阻比连线电阻更主要（短至中长连线确实如此）：

| 参数 | 一般化缩小 |
|---|---|
| 导线电容 $WL/t$ | $\varepsilon_c/S_L$ |
| 导线延时 $R_{on}C_{int}$ | $\varepsilon_c/S_L$ |
| 导线能量 $C_{int}V^2$ | $\varepsilon_c/(S_LU^2)$ |
| 导线延时/本征延时、导线能量/本征能量 | $\varepsilon_c S/S_L$ |

$S_L$ 代表导线长度变化的比例系数，$\varepsilon_c$ 代表边缘电容与线间电容的影响。该模型预见**互连引起的延时与能耗随工艺缩小越来越重要**：短连线（$S=S_L$）只因 $\varepsilon_c$ 增加而增大，中等范围的长连线（$S_L<S$）则日益显著。图 5.41 是证实之一。

*图 5.41 导线延时与门延时的比随工艺进步而变化*

⚡ 「互连线将很快使 CMOS 性能饱和而走向末日」之说也许过于夸大（它取决于系统总体结构、设计方法学、晶体管尺寸、互连材料等一系列独立参数），但对互连线的日益关注绝对必要，并可能改变下一代电路设计和优化的方式。

# 小结

静态 CMOS 反相器的主要特点：

- 上拉 PMOS 与下拉 NMOS 组合；因 PMOS 电流驱动能力较低，通常应使它比 NMOS 宽。
- VTC 几乎理想：逻辑摆幅等于电源电压且与晶体管尺寸无关；对称反相器（PMOS 与 NMOS 电流驱动强度相同）的噪声容限接近 $V_{DD}/2$；稳态响应不受扇出影响。
- 传播延时主要由充放电 $C_L$ 的时间决定，一阶近似 $t_p = 0.69C_L\dfrac{R_{eqn}+R_{eqp}}{2}$。保持 $C_L$ 小是实现高性能最有效的手段；只要延时主要受外部（扇出和导线）电容影响，改变晶体管尺寸就可能有助于性能。
- 功耗主要由充放电 $C_L$ 的动态功耗决定，为 $P_{0\to1}C_LV_{DD}^2f$，与电路活动性成正比。开关期间直接通路电流引起的功耗可通过细心的信号斜率修正来限制。静态功耗通常可忽略，但将来可能因亚阈值电流成为主要因素。
- 使工艺尺寸变小是减少面积、传播延时及功耗的有效手段；电源电压同时降低则影响更惊人。
- **互连线的影响将在总延时和总性能中逐渐占有更大比例。**
