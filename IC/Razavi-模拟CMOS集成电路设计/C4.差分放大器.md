# 4.1 单端与差分工作

## 定义

**单端信号（single-ended signal）**：以固定电位（通常为地）为参考测量的信号。

**差分信号（differential signal）**：在两个节点之间测量的信号，两节点围绕一个固定电位做**等幅反相**的摆动，且对该固定电位呈现**相等的阻抗**。

**共模电平（common-mode level, $V_{CM}$）**：差分信号的中心电位——即无信号时的偏置值。

> 【插入 Razavi 图 4.1】(a) 单端信号；(b) 差分信号

严格定义中"等阻抗"的要求容易被忽略——两个节点对参考电位不仅要电压对称，阻抗也必须对称。这是共模抑制比（CMRR）理论的根基。差分不仅是电压关系，更是阻抗关系。

## 差分摆幅：$2\times$ 与 $4\times$

差分系统的摆幅描述是初学时最易混淆的地方。设每路单端输出峰值幅度为 $V_0$：

- 单端峰峰摆幅：$2V_0$
- 差分峰峰摆幅：$4V_0$

若 $V_X = V_0 \cos \omega t + V_{CM}$，$V_Y = -V_0 \cos \omega t + V_{CM}$，则：

$$
V_X - V_Y = 2V_0 \cos \omega t
$$

差分信号的峰值是 $2V_0$，峰峰值是 $4V_0$——是单端峰峰摆幅的两倍。

1V 电源电压的电路可以产生 1.6V 的差分峰峰摆幅。这不是违反能量守恒——两路单端输出反相摆动，差值的变化范围自然翻倍。差分摆幅可以超过电源电压，这是差分电路在低电压设计中最重要的实际优势之一。

## 共模噪声抑制：差分的核心价值

单端信号的根本弱点：参考电位（地、电源）的任何扰动直接进入信号路径。差分信号将信息编码在差值中——任何**对称地**叠加在两路信号上的扰动都被差值运算消去。

### 电容耦合串扰

> 【插入 Razavi 图 4.2】(a) 时钟线对单端敏感信号的电容耦合干扰；(b) 差分信号抑制耦合干扰

相邻走线之间，大摆幅时钟通过寄生电容耦合到敏感信号线。若将敏感信号以差分形式分配、时钟线置于两条差分线正中间——耦合到 $V^+$ 和 $V^-$ 的干扰量相等，$V^+ - V^-$ 不变。共模电平被扰动，差模输出不受影响——**"排斥"共模噪声。**

反过来，将噪声源（aggressor）也做差分分配——两条差分时钟线耦合到同一敏感线的干扰互相抵消。

> 【插入 Razavi 图 4.4】差分时钟对单端信号的耦合抵消

### Example 4.1：victim 和 aggressor 都差分——扭绞线

> 【插入 Razavi 图 4.5】(a) 差分 victim 被差分 aggressor 包围——反而失效；(b) 扭绞对——正确方案

受害者和攻击者都差分时，图 4.5(a) 的排布反而出问题：$V_{out}^+$ 靠近 $CK$，$V_{out}^-$ 靠近 $\overline{CK}$ → 两者经历**方向相反**的扰动 → 差值被破坏。差分对差分不等于自动免疫——走线的物理排布同样决定结果。

解决：**扭绞对（twisted pair）**。每路 victim 一半距离靠近 $CK$、一半距离靠近 $\overline{CK}$，两段耦合抵消。$V_{out}^+$ 和 $V_{out}^-$ 各自的波形都干净，差值也干净。

这个例子揭示的原则：**差分不等于自动免疫。**共模抑制能力取决于版图和走线的物理对称性。不对称差分走线 = 纸面差分、物理单端。

### 电源噪声抑制

> 【插入 Razavi 图 4.3】(a) 单端 CS 级受电源噪声影响；(b) 差分电路抑制电源噪声

在[[C3.单级放大器#3.3.4 有源负载的共源级|有源负载 CS 级]]中已看到：$V_{DD}$ 到 $V_{out}$ 的增益可达 $g_{m2}(r_{O1} \parallel r_{O2})$——量级与信号增益相当。$V_{DD}$ 扰动 $\Delta V$ → $V_{out}$ 变化约 $\Delta V$。单端放大器天然放大电源噪声。

对称差分电路中，$V_{DD}$ 噪声同时影响 $V_X$ 和 $V_Y$，$V_X - V_Y$ 不变。物理本质：电源噪声是共模扰动——它等量地加到两路输出上，差分运算自动消去。

## 更大的输出摆幅

图 4.3(b) 差分电路中：

- X 或 Y 单端峰峰摆幅：$V_{DD} - (V_{GS} - V_{TH})$
- $V_X - V_Y$ 差分峰峰摆幅：$2[V_{DD} - (V_{GS} - V_{TH})]$

差分摆幅是单端的两倍——两路输出反相摆动，差值的变化范围翻倍。

## 其他优势

- **偏置更简单**（第 5 章）：差分对的尾电流源统一设定两管偏置，不需要分别为每路设计偏置网络
- **线性度更高**（第 14 章）：偶次谐波抵消。$V_{in}$ 产生失真项 $\alpha_2 V_{in}^2$，$-V_{in}$ 产生 $\alpha_2 (-V_{in})^2 = \alpha_2 V_{in}^2$——两路失真项**同相**，差分输出中相减抵消。这是[[C3.单级放大器#3.3.2 二极管连接型负载的共源级|二极管负载的平方-开方对消]]之外的另一种非线性对消机制：前者靠级联匹配器件的非线性互相抵消，后者靠对称结构的偶次项自行相消

## 代价：面积

差分电路占用约两倍面积。实践中，噪声免疫、摆幅增大、线性度提升等优势远超面积代价。

## 4.1 在全章中的位置

4.1 没有分析任何具体电路——它建立了差分信号的**思维框架**：

1. **信号 = 差模 + 共模**的分解方式。后续分析差分对时，差模和共模行为分别处理（半电路法），根在此处
2. **共模抑制不是自动的**。它依赖物理对称性——走线、器件匹配、版图。"差分"是电路拓扑选择，"对称"才是抑制能力的物理来源
3. **差分摆幅可超过电源电压**——1V 电源下，单端最大摆幅可能不到 500mV，而差分输出可接近 1V。这是差分在低电压设计中不可替代的原因

4.2 的差分对正是为"放大差分信号、抑制共模变化"而设计的电路：尾电流源 $I_{SS}$ 使 $I_{D1} + I_{D2}$ 与输入共模电平无关——解决了 4.1 提出的"差分好，但怎么实现"的问题。

# 4.2 基本差分对

## 从两个 CS 级到差分对

最直接放大差分信号的方法：两个完全相同的 CS 级分别处理 $V_{in1}$ 和 $V_{in2}$。

> 【插入 Razavi 图 4.6】(a) 两个独立 CS 级构成的简单差分电路；(b) 输入共模过低导致两管截止

这个电路具备差分信号的部分优势（电源噪声抑制、大摆幅），但有一个致命问题：**输入共模电平 $V_{in,CM}$ 的变化直接改变两管的偏置电流**，进而改变 $g_m$（增益变化）和输出共模电平（摆幅损失）。图 4.6(b) 中 $V_{in,CM}$ 过低时两管同时截止——输出严重削波。

物理本质：两个 CS 级的偏置电流**各自独立地**由 $V_{in,CM}$ 决定，没有机制将它们绑定在一起。

**解决方案：尾电流源。**在 $M_1$、$M_2$ 的共源节点接入恒流源 $I_{SS}$，强制 $I_{D1} + I_{D2} = I_{SS}$。

> 【插入 Razavi 图 4.7】基本差分对

$V_{in1} = V_{in2}$ 时，每管偏置电流 = $I_{SS}/2$，输出共模电平 = $V_{DD} - R_D I_{SS}/2$。**$V_{in,CM}$ 不再决定偏置电流——它只影响 $V_P$（源极电位跟随 $V_{in,CM}$ 变化），不影响 $I_{D1} + I_{D2}$。** 这就是差分对超越两个独立 CS 级的根本原因。

电路中包含三个差分量：$V_{in1} - V_{in2}$（输入）、$I_{D1} - I_{D2}$（中间量）、$V_{out1} - V_{out2}$（输出）。

以下大信号分析忽略沟道长度调制和体效应。

## 4.2.1 定性分析

### 差分传输特性

> 【插入 Razavi 图 4.8】(a) $V_{out1}$、$V_{out2}$ 随 $\Delta V_{in}$ 的变化；(b) $V_{out1} - V_{out2}$ 随 $\Delta V_{in}$ 的变化

$V_{in1} - V_{in2}$ 从 $-\infty$ 扫到 $+\infty$：

- **$\Delta V_{in}$ 很大负值**：$M_1$ 截止，$M_2$ 独占 $I_{SS}$ → $V_{out1} = V_{DD}$，$V_{out2} = V_{DD} - R_D I_{SS}$
- **$\Delta V_{in}$ 趋近 0**：$M_1$ 逐渐导通，从 $R_{D1}$ 抽取部分 $I_{SS}$ → $V_{out1}$ 下降；$M_2$ 电流减小 → $V_{out2}$ 上升
- **$\Delta V_{in} = 0$（平衡点/equilibrium）**：$V_{out1} = V_{out2} = V_{DD} - R_D I_{SS}/2$
- **$\Delta V_{in}$ 很大正值**：$M_1$ 独占 $I_{SS}$，$M_2$ 截止 → $V_{out1} = V_{DD} - R_D I_{SS}$，$V_{out2} = V_{DD}$

两个关键属性：

1. **输出最大值和最小值是确定的**（$V_{DD}$ 和 $V_{DD} - R_D I_{SS}$），与输入共模电平无关。尾电流源锁定了总电流，输出摆幅就不受 $V_{in,CM}$ 影响。
2. **小信号增益在平衡点最大，随 $|\Delta V_{in}|$ 增大而下降至零。** 斜率 = 增益——从图 4.8(b) 看，曲线在 $\Delta V_{in} = 0$ 处最陡，两端趋于水平。输入摆幅越大，电路非线性越严重。

### 共模行为与输入共模范围

设 $V_{in1} = V_{in2} = V_{in,CM}$，$I_{SS}$ 由 NFET $M_3$ 实现。对称性要求 $V_{out1} = V_{out2}$。

> 【插入 Razavi 图 4.9】(a) 差分对感知共模变化（$M_3$ 为 NFET 电流源）；(b) $M_3$ 深三极管区时的等效电路；(c) 共模输入-输出特性

- **$V_{in,CM} = 0$**：$M_1$、$M_2$ 栅极电位不高于源极 → 两管截止，$I_{D3} = 0$。$M_3$ 虽有 $V_b$ 形成反型层，但 $V_{DS} = 0$ → 深三极管区。$V_P = 0$，$V_{out1} = V_{out2} = V_{DD}$。
- **$V_{in,CM} \geq V_{TH}$**：$M_1$、$M_2$ 导通。$M_3$ 仍可建模为电阻（图 4.9(b)）。随 $V_{in,CM}$ 上升，$I_{D1}$、$I_{D2}$ 增大，$V_P$ 同步上升——$M_1$、$M_2$ 构成**源极跟随器**，$V_P$ 跟踪 $V_{in,CM}$。
- **$V_{in,CM}$ 足够高**：$V_{DS3}$ 超过 $V_{GS3} - V_{TH3}$ → $M_3$ 进入饱和 → $I_{D1} + I_{D2} = I_{SS}$ 恒定。

**共模范围下界：**
$$
V_{in,CM} \geq V_{GS1} + (V_{GS3} - V_{TH3})
$$

$V_{GS1}$ 是 $M_1$ 承载 $I_{SS}/2$ 所需的栅源电压，$V_{GS3} - V_{TH3}$ 是 $M_3$ 保持饱和所需的最小 $V_{DS}$。

**共模范围上界：** $V_{in,CM}$ 继续升高，$V_{out1}$ 和 $V_{out2}$ 基本不变（$= V_{DD} - R_D I_{SS}/2$）。当 $V_{in,CM} > V_{out1} + V_{TH}$，$M_1$、$M_2$ 的 $V_{GD} < V_{TH}$ 被破坏 → 进入三极管区 → **差模增益下降**（虽然共模特性曲线不变）。

完整共模范围：
$$
V_{GS1} + (V_{GS3} - V_{TH3}) \leq V_{in,CM} \leq \min\left[ V_{DD} - R_D \frac{I_{SS}}{2} + V_{TH},\ V_{DD} \right] \tag{4.1}
$$

### Example 4.2：增益随共模电平的变化

> 【插入 Razavi 图 4.10】差模增益 vs $V_{in,CM}$

三段式行为：$V_{in,CM}$ 超过 $V_{TH}$ 后增益开始上升 → 尾电流源饱和后增益恒定（正常工作区）→ 输入管进入三极管区后增益下降。**增益平坦区的宽度决定了电路对共模波动的容忍能力。**

### 输出摆幅

> 【插入 Razavi 图 4.11】差分对的最大输出摆幅

设 $V_{in,CM} < V_{out,CM}$、增益较高（输入摆幅远小于输出摆幅）。$M_1$、$M_2$ 保持饱和的条件：

- $V_{out}$ 最高可达 $V_{DD}$（$M_1$ 近截止）
- $V_{out}$ 最低 ≈ $V_{in,CM} - V_{TH}$（$M_1$ 的三极管区边界）

**$V_{out,min}$ 由 $V_{in,CM}$ 决定——输入共模越高，输出摆幅越小。**因此希望 $V_{in,CM}$ 尽可能低，但不能低于下界。选定最低允许的 $V_{in,CM}$ 后，单端峰峰输出摆幅 = $V_{DD} - (V_{GS1} - V_{TH1}) - (V_{GS3} - V_{TH3})$——消耗了两个过驱动电压。

### Example 4.3：CS 级 vs 差分对的输出摆幅

CS 级（阻性负载）摆幅 = $V_{DD} - V_{ov}$（消耗一个过驱动）。差分对单端摆幅 = $V_{DD} - 2V_{ov}$（消耗两个过驱动），差分摆幅 = $2V_{DD} - 4V_{ov}$——通常远大于 $V_{DD} - V_{ov}$。**差分对的差分输出摆幅在绝对值上完胜 CS 级，尽管每路的单端摆幅更小。** 这是[[#4.1]]中"差分摆幅可超过电源电压"的电路级体现。

### 纳米设计笔记

40nm 工艺中差分对增益通常不超过 5。此时输入峰值摆幅 $V_0$ 也会限制输出：$V_{out,min} = V_{in,CM} + V_0 - V_{TH}$——负增益电路中输入峰值的"反射"效应。这与高增益假设下的分析结论不同，纳米设计中两种限幅机制（增益不足 + 过驱动消耗）可能同时起作用。

## 4.2.2 定量分析

### 大信号传输特性

> 【插入 Razavi 图 4.12】差分对大信号分析

目标：推导 $\Delta I_D = I_{D1} - I_{D2}$ 与 $\Delta V_{in} = V_{in1} - V_{in2}$ 的关系。假设对称、两管饱和、$\lambda = 0$。

节点 P 的电压既是 $V_{in1} - V_{GS1}$ 又是 $V_{in2} - V_{GS2}$，因此：

$$
V_{in1} - V_{in2} = V_{GS1} - V_{GS2} \tag{4.2}
$$

对平方律器件，$V_{GS} = \sqrt{2I_D / (\mu_n C_{ox} W/L)} + V_{TH}$，代入 (4.2)：

$$
\Delta V_{in} = \sqrt{\frac{2I_{D1}}{\mu_n C_{ox} \frac{W}{L}}} - \sqrt{\frac{2I_{D2}}{\mu_n C_{ox} \frac{W}{L}}} \tag{4.5}
$$

两边平方，代入 $I_{D1} + I_{D2} = I_{SS}$，整理后再平方——推导过程用到的思想是**利用 $I_{D1} + I_{D2} = I_{SS}$ 消去交叉项 $\sqrt{I_{D1} I_{D2}}$**。最终：

$$
I_{D1} - I_{D2} = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} \Delta V_{in} \sqrt{\frac{4 I_{SS}}{\mu_n C_{ox} W/L} - \Delta V_{in}^2} \tag{4.9}
$$

$\Delta I_D$ 是 $\Delta V_{in}$ 的奇函数——在平衡点为零，两侧对称。

**等效跨导 $G_m$：** 对 (4.9) 求导：

$$
G_m = \frac{\partial \Delta I_D}{\partial \Delta V_{in}} = \frac{1}{2} \mu_n C_{ox} \frac{W}{L} \frac{\frac{4 I_{SS}}{\mu_n C_{ox} W/L} - 2\Delta V_{in}^2}{\sqrt{\frac{4 I_{SS}}{\mu_n C_{ox} W/L} - \Delta V_{in}^2}} \tag{4.11}
$$

在平衡点（$\Delta V_{in} = 0$）：

$$
G_{m,max} = \sqrt{\mu_n C_{ox} \frac{W}{L} I_{SS}}
$$

平衡点 $I_{D1} = I_{D2} = I_{SS}/2$，每管的 $g_m = \sqrt{2\mu_n C_{ox} (W/L) (I_{SS}/2)} = \sqrt{\mu_n C_{ox} (W/L) I_{SS}}$——**差分对的等效跨导等于单个晶体管的 $g_m$**，不是两倍。

因此平衡点差模增益：

$$
\lvert A_v\rvert = G_m R_D = g_m R_D \tag{4.12}
$$

与简单 CS 级增益相同——但获得了差分结构的所有优势（共模抑制、大摆幅、线性度）。

### 平衡过驱动与 $\Delta V_{in1}$ 的 $\sqrt{2}$ 关系

$\Delta V_{in1}$ 定义为使一管承载全部 $I_{SS}$（另一管截止）的输入差模电压。此时 $M_1$ 的 $I_{D1} = I_{SS}$，$M_2$ 的 $V_{GS2} = V_{TH}$：

$$
\Delta V_{in1} = V_{GS1} - V_{TH} = \sqrt{\frac{2 I_{SS}}{\mu_n C_{ox} \frac{W}{L}}} \tag{4.14}
$$

平衡时每管 $I_D = I_{SS}/2$，过驱动 = $(V_{GS} - V_{TH})_{eq} = \sqrt{I_{SS} / (\mu_n C_{ox} W/L)}$。因此：

$$
\Delta V_{in1} = \sqrt{2} \cdot (V_{GS} - V_{TH})_{eq} \tag{4.15}
$$

**$\sqrt{2}$ 这个数贯穿差分对设计。**增大 $\Delta V_{in1}$（扩大线性输入范围）→ 必须增大平衡过驱动 → 给定 $I_{SS}$ 下只能减小 $W/L$ → $g_m$ 下降 → 增益下降。或者增大 $I_{SS}$ → 功耗增加。增益与线性度之间的折中被量化在 $\sqrt{2}$ 关系中。

$|\Delta V_{in}| < \Delta V_{in1}$ 时两管均导通，(4.9) 成立。超出此范围，(4.9) 失效——实际中一管已截止，$\Delta I_D$ 饱和于 $\pm I_{SS}$。

> 【插入 Razavi 图 4.14】(a) 基准；(b) $W/L$ 增大 → $\Delta V_{in1}$ 减小，线性范围收窄；(c) $I_{SS}$ 增大 → 线性范围和输出电流摆幅均增大

### 纳米设计笔记

40nm、$W/L = 5\mu\text{m}/40\text{nm}$、$I_{SS} = 0.25\text{mA}$ 的实际模型与平方律模型的对比：截止特性（90% 电流判据）下，$\Delta V_{in1}$ 与平衡过驱动的 $\sqrt{2}$ 关系近似成立。短沟道改变了 $g_m$ 的绝对值，但差分对的基本函数形态（奇函数、饱和特性）保持不变。

### Example 4.5：直流失调的影响

> 【插入 Razavi 图 4.15】(a) 两路输入有直流失配 $V_{OS}$；(b) 输入波形；(c) 输出波形

$V_{OS} = \Delta V_{in1}/2$ 时，直流工作点偏离平衡点 → $G_m$ 降低约 20%。**差分对偏离平衡点工作时，不仅引入输出失调，还损失增益——两个后果来自同一物理原因（$G_m$ 曲线在平衡点最陡）。**

### 小信号分析 — 方法一（叠加法）

> 【插入 Razavi 图 4.16】差分对小信号输入

设 $V_{in2} = 0$，分析 $V_{in1}$ 在 X 和 Y 的响应。

> 【插入 Razavi 图 4.17】(a) $V_{in1}$ 单独作用；(b) $M_2$ 从源极看入 = $1/g_{m2}$，$M_1$ 构成退化 CS 级；(c) 等效电路

- **到 X 的路径**：$M_1$ 是退化 CS 级，退化电阻 = 从 $M_2$ 源极看入的阻抗 $1/g_{m2}$。$\lambda = \gamma = 0$ 时：

$$
\frac{V_X}{V_{in1}} = -\frac{R_D}{\frac{1}{g_{m1}} + \frac{1}{g_{m2}}} \tag{4.18}
$$

- **到 Y 的路径**：$M_1$ 做源极跟随器驱动 $M_2$。将 $V_{in1} + M_1$ 做 Thevenin 等效（$V_T = V_{in1}$，$R_T = 1/g_{m1}$），$M_2$ 成为 CG 级：

> 【插入 Razavi 图 4.18】$V_{in1} + M_1$ 的 Thevenin 等效

$$
\frac{V_Y}{V_{in1}} = \frac{R_D}{\frac{1}{g_{m2}} + \frac{1}{g_{m1}}} \tag{4.19}
$$

$$
(V_X - V_Y)|_{\text{due to }V_{in1}} = -\frac{2R_D}{\frac{1}{g_{m1}} + \frac{1}{g_{m2}}} V_{in1} \tag{4.20}
$$

$g_{m1} = g_{m2} = g_m$ 时：

$$
(V_X - V_Y)|_{\text{due to }V_{in1}} = -g_m R_D V_{in1} \tag{4.21}
$$

由对称性，$V_{in2}$ 单独作用的效果：

$$
(V_X - V_Y)|_{\text{due to }V_{in2}} = g_m R_D V_{in2} \tag{4.22}
$$

叠加：

$$
\frac{V_X - V_Y}{V_{in1} - V_{in2}} = -g_m R_D \tag{4.23}
$$

方法一揭示了一个重要事实：**差模增益的大小恒为 $g_m R_D$，与输入是单端还是差分无关。**但若输出取单端（X 或 Y 对地），增益减半——因为仅利用了差分对一半的输出摆幅。这与 CS 级 $|A_v| = g_m R_D$ 完全相同，但差分对额外提供了共模抑制和更大的差分输出摆幅。

### Example 4.6：不对称差分对

> 【插入 Razavi 图 4.19】$M_2$ 宽度为 $M_1$ 的两倍

$V_{GS1} = V_{GS2}$ 时 $I_{D2} = 2I_{D1} = 2I_{SS}/3$。$g_{m2} = 2g_{m1}$：

$$
\lvert A_v\rvert = \frac{4}{3} g_{m1} R_D
$$

增益低于对称差分对的 $g_{m1} R_D$（注意对称时 $g_m$ 是 $I_{SS}/2$ 偏置下的值，比此处的 $g_{m1}$ 大）。传输特性水平偏移——电路产生**失调（offset）**。第 14 章将利用这一效应来线性化差分对。

### 差分对跨导与 CS 级的比较

给定相同的总偏置电流 $I_{SS}$，差分对每管 $g_m = \sqrt{\mu_n C_{ox} (W/L) I_{SS}}$，而单独一个同尺寸晶体管偏置于 $I_{SS}$ 的 $g_m = \sqrt{2\mu_n C_{ox} (W/L) I_{SS}}$——差 $\sqrt{2}$ 倍。**差分对用两倍器件数换来了共模抑制等差分优势，代价是给定总电流下的等效跨导下降 $1/\sqrt{2}$。**

### 小信号分析 — 方法二（半电路法）

半电路法是差分电路分析中最重要的工具。它的核心是一个引理：

**引理** 对称电路（图 4.20(a)）中，若 $V_{in1}$ 从 $V_0$ 变为 $V_0 + \Delta V_{in}$、$V_{in2}$ 从 $V_0$ 变为 $V_0 - \Delta V_{in}$（纯差分输入），且电路保持线性，则 $V_P$ 不变。设 $\lambda = 0$。

> 【插入 Razavi 图 4.20】节点 P 为虚地的证明

**对称性证明**：只要电路线性（偏置电流差异可忽略），电路对称 → $V_P$ 不能"偏袒"一侧输入而"忽略"另一侧。从 Thevenin 等效看（图 4.21），若 $V_{T1}$ 和 $V_{T2}$ 等幅反向变化，$R_{T1} = R_{T2}$，则 $V_P$ 维持恒定。

> 【插入 Razavi 图 4.21】差分对每半边的 Thevenin 等效

**形式化证明**：设 $V_1$、$V_2$ 平衡值为 $V_a$，变化 $\Delta V_1$、$\Delta V_2$。输出电流变化 $g_m \Delta V_1$ 和 $g_m \Delta V_2$。$I_1 + I_2 = I_T$ → $g_m \Delta V_1 + g_m \Delta V_2 = 0$ → $\Delta V_1 = -\Delta V_2$。又 $V_{in1} - V_1 = V_{in2} - V_2 = V_P$ → $\Delta V_{in} - \Delta V_1 = -\Delta V_{in} - \Delta V_2$ → $2\Delta V_{in} = \Delta V_1 - \Delta V_2 = 2\Delta V_1$。即**差模输入完全被 $V_1$ 和 $V_2$ 吸收**（$\Delta V_1 = \Delta V_{in}$，$\Delta V_2 = -\Delta V_{in}$），$V_P$ 纹丝不动。

> 【插入 Razavi 图 4.22】半电路法的应用——P 为交流地

$V_P$ 是交流地 → 电路分解为两个独立的 CS 半电路。每半边：$V_X / V_{in1} = -g_m R_D$，$V_Y / (-V_{in1}) = -g_m R_D$。差模增益 = $-g_m R_D$。

### Example 4.7：计入 $\lambda$ 的半电路分析

> 【插入 Razavi 图 4.23】$\lambda \neq 0$ 时的半电路

半电路就是带 $r_O$ 的 CS 级：$V_X / V_{in1} = -g_m (R_D \parallel r_O)$，$V_Y / (-V_{in1}) = -g_m (R_D \parallel r_O)$ → $|A_v| = g_m (R_D \parallel r_O)$。方法一在此处需要冗长的代数运算——半电路法的威力一目了然。

**半电路法的前提条件**：电路完全对称，输入为纯差分信号。4.3 节将处理共模响应的半电路分析。

### 任意输入信号的分解

实际输入不一定是纯差分的。任意 $V_{in1}$、$V_{in2}$ 可分解为差模分量 + 共模分量：

$$
V_{in1} = \frac{V_{in1} - V_{in2}}{2} + \frac{V_{in1} + V_{in2}}{2}, \quad V_{in2} = \frac{V_{in2} - V_{in1}}{2} + \frac{V_{in1} + V_{in2}}{2} \tag{4.26-4.27}
$$

> 【插入 Razavi 图 4.24】和【插入 Razavi 图 4.25】任意输入分解为差模 + 共模，分别叠加

差模分量用半电路法处理，共模分量留待 4.3 节分析。**"差模 + 共模"的分解与叠加是差分电路分析的标准范式**——它不仅是一个数学技巧，更是设计直觉的来源：差模增益和共模抑制是两个独立的设计目标。

### Example 4.8：$V_{in1} \neq -V_{in2}$ 且 $\lambda \neq 0$ 时的完整响应

> 【插入 Razavi 图 4.26】(a) 差模半电路；(b) 共模响应电路

差模：$V_X - V_Y = -g_m (R_D \parallel r_O)(V_{in1} - V_{in2})$

共模（理想 $I_{SS}$、完全对称）：$V_X$ 和 $V_Y$ 不变。$M_1$、$M_2$ 从 $R_{D1}$、$R_{D2}$ 抽取的电流恒为 $I_{SS}/2$，与 $V_{in,CM}$ 无关。**电路只放大差值，剔除共模——这就是差分对的本质。**

## 4.2.3 源极退化差分对

> 【插入 Razavi 图 4.27】(a) 源极退化差分对；(b) 有无退化时的传输特性对比

与 CS 级一样（[[C3.单级放大器#3.3.6 源极退化的共源级|3.3.6 节]]），差分对也可以在源极串联电阻以改善线性度。

### 线性输入范围的扩展

设 $M_2$ 在 $\Delta V_{in2}$ 处截止，$I_{D1} = I_{SS}$。$V_{GS2} = V_{TH}$：

$$
V_{in1} - V_{GS1} - R_S I_{SS} = V_{in2} - V_{TH}
$$

$$
\Delta V_{in2} = \sqrt{\frac{2 I_{SS}}{\mu_n C_{ox} \frac{W}{L}}} + R_S I_{SS} = \Delta V_{in1} + R_S I_{SS} \tag{4.33-4.34}
$$

线性输入范围扩展了 $R_S I_{SS}$。物理原因：输入电压的一部分落在 $R_S$ 上，$V_{GS}$ 的变化更平缓——与单端退化的机制完全相同。

### 增益与线性度的折中

半电路即退化 CS 级（$\lambda = \gamma = 0$）：

$$
\lvert A_v\rvert = \frac{R_D}{\frac{1}{g_m} + R_S} \tag{4.35}
$$

$R_S \gg 1/g_m$ 时 $|A_v| \approx R_D/R_S$——增益由电阻比定义，高度线性。代价是增益降低。

### 电压裕度问题及其解决

平衡时每个 $R_S$ 上压降 $R_S I_{SS}/2$——等效于尾电流源需要更多电压裕度。输入共模下界提高 $R_S I_{SS}/2$，输出摆幅也减小相同量。

> 【插入 Razavi 图 4.28】分裂尾电流源的退化差分对

解决方案：将尾电流源一分为二，各自直接接到源极。平衡时 $R_S$ 两端等电位（两路电流相等 = $I_{SS}/2$），**无电流流过 $R_S$——不消耗电压裕度。**只有差分信号产生时，$R_S$ 上才有电流（两路电流不再相等），退化机制才启动。这是"按需退化"的巧妙实现——与[[C3.单级放大器#3.3.6 源极退化的共源级|Example 3.11]]中退化在理想电流源负载下"消失"的机制同源：退化只有在线性化所需的电流变化发生时，才表现为退化。

# 4.3 共模响应

Example 4.8 中的共模响应分析基于两个理想化假设：电路完全对称、尾电流源输出阻抗无穷大。实际电路中两个假设都不成立。共模响应有两种表现形式：

- **纯共模增益**（对称电路 + 有限 $R_{SS}$）：$V_{in,CM}$ 变化 → 输出共模电平漂移 → 偏置点移动、摆幅损失
- **共模-差模转换**（不对称电路 + 有限 $R_{SS}$）：$V_{in,CM}$ 变化 → 输出出现**差分误差分量** → 共模噪声直接污染差模信号

两者的严重性不在同一量级——第二种直接破坏信号本身。

## 对称电路的共模增益

> 【插入 Razavi 图 4.29】(a) 差分对感知共模输入；(b) 对称性允许 X 与 Y 短接；(c) $M_1$ 和 $M_2$ 合并为一个 $2g_m$ 的复合器件

假设电路对称，尾电流源输出阻抗为 $R_{SS}$。$V_{in,CM} \uparrow$ → $V_P \uparrow$ → $I_{D1}$、$I_{D2}$ 均增加 → $V_X$、$V_Y$ 均下降。对称性保证 $V_X = V_Y$ → X 和 Y 可短接 → $M_1$ 和 $M_2$ 的所有端子并联：宽度翻倍、偏置电流翻倍 → **等效跨导 = $2g_m$（$g_m$ 为单管跨导）**。

从图 4.29(c) 的合并电路，这是退化 CS 级（$\lambda = \gamma = 0$）：等效器件跨导 $2g_m$、源极退化电阻 $R_{SS}$、漏极负载 $R_D/2$（两个 $R_D$ 并联）。回路增益：

$$
A_{v,CM} = \frac{V_{out}}{V_{in,CM}} = -\frac{R_D/2}{1/(2g_m) + R_{SS}} \tag{4.37}
$$

$R_{SS} \gg 1/(2g_m)$ 时 $A_{v,CM} \approx -R_D/(2R_{SS})$——尾电流源阻抗越高，共模增益越低。

物理直觉：$M_1$ 和 $M_2$ 做源极跟随器，$V_P$ 跟踪 $V_{in,CM}$，跟踪精度取决于 $R_{SS}$ 和 $1/(2g_m)$ 的分压比。$R_{SS}$ 越大，$V_P$ 越准确地跟随 $V_{in,CM}$，通过 $R_{SS}$ 的电流变化越小 → $V_{GS}$ 变化越小 → 输出漂移越小。

### Example 4.9：电阻偏尾的数值实例

> 【插入 Razavi 图 4.30】$R_{SS} = 500\Omega$ 替代电流源

$(W/L)_{1,2} = 25/0.5$，$\mu_n C_{ox} = 50\mu\text{A/V}^2$，$V_{TH} = 0.6\text{V}$，$V_{DD} = 3\text{V}$，$I_{SS} = 1\text{mA}$。

- (a) 每管 0.5mA → $V_{GS} = 1.23\text{V}$。$R_{SS}$ 上需 0.5V → $V_{in,CM} = 1.73\text{V}$。
- (b) $g_m = 1/(632\Omega)$，差模增益 5 → $R_D = 3.16\text{k}\Omega$。输出共模 = $3 - 0.5\text{mA} \times 3.16\text{k}\Omega = 1.42\text{V}$。$V_{in,CM} = 1.73\text{V}$，$V_{TH} = 0.6\text{V}$ → $M_1$、$M_2$ 距三极管区 $1.73 - 0.6 - 1.42 = -0.29\text{V}$（即 290mV 裕度）。
- (c) $V_{in,CM}$ 增加 50mV → 由 (4.37)，$\Delta V_{X,Y} \approx -96.8\text{mV}$。输出共模从 1.42V 降至 1.323V。裕度从 290mV 压缩至 143mV——**共模扰动直接吃掉了一半的输出摆幅裕度。**

这个例子揭示：共模增益即使不大（此例中约 −1.94），其危害不在于"放大共模信号"，而在**压缩可用电压空间**——这在低电压设计中尤其致命。

### 纳米设计笔记

纳米工艺中尾电流源 $R_{SS}$ 低，纯共模增益本身通常不是主要问题。更严重的是**失配**导致的共模-差模转换。此外，低 $R_{SS}$ 导致共模电平在级联级之间"传播"——第一级输出的共模漂移成为第二级的输入共模扰动，逐级放大。

## 电阻失配：共模-差模转换

> 【插入 Razavi 图 4.31】$R_{D1} = R_D$，$R_{D2} = R_D + \Delta R_D$

假设电路其余部分对称，$M_1$、$M_2$ 的 $\lambda = \gamma = 0$。$M_1$ 和 $M_2$ 构成源极跟随器，$V_P$ 的变化：

$$
\Delta V_P = \frac{R_{SS}}{R_{SS} + \frac{1}{2g_m}} \Delta V_{in,CM} \tag{4.43}
$$

两管电流等量增加 $[g_m/(1 + 2g_m R_{SS})] \Delta V_{in,CM}$，但 $R_{D1} \neq R_{D2}$ → 输出电压变化不同：

$$
\Delta V_X = -\Delta V_{in,CM} \frac{g_m}{1 + 2g_m R_{SS}} R_D \tag{4.44}
$$

$$
\Delta V_Y = -\Delta V_{in,CM} \frac{g_m}{1 + 2g_m R_{SS}} (R_D + \Delta R_D) \tag{4.45}
$$

**输出出现差分分量：** $\Delta V_X - \Delta V_Y \neq 0$。

> 【插入 Razavi 图 4.32】电阻失配时共模噪声污染差模输出的图示

**这就是共模-差模转换（CM-DM conversion）的本质：输入共模变化 + 电路不对称 = 输出差分误差。** 与纯共模增益不同，这个差分误差无法通过后续差分处理来消除——它已经混入了信号所在的"通道"。

## 失配来源与频率效应

> 【插入 Razavi 图 4.33】尾节点的寄生电容 $C_P$

失配的两个主要来源：

1. **负载电阻失配**（$\Delta R_D$）——通常较小（同芯片上电阻匹配可达 0.1% 量级）
2. **输入晶体管失配**（$\Delta g_m$，源于 $\Delta W/L$ 和 $\Delta V_{TH}$）——通常贡献更大的失配

频率升高时问题加剧。尾节点总寄生电容 $C_P$（电流源自身寄生 + $M_1$/$M_2$ 源-衬底结电容）在高频处降低尾阻抗 → 更大的尾电流变化 → CM-DM 转换增强。即使 DC 时 $R_{SS}$ 很大，高频 CM-DM 转换仍可能显著。

## $g_m$ 失配的定量分析

> 【插入 Razavi 图 4.34】(a) 差分对感知共模输入；(b) 小信号等效电路

$g_{m1} \neq g_{m2}$，$\lambda = \gamma = 0$。由 $(I_{D1} + I_{D2}) R_{SS} = V_P$：

$$
(g_{m1} + g_{m2})(V_{in,CM} - V_P) R_{SS} = V_P \tag{4.46}
$$

$$
V_P = \frac{(g_{m1} + g_{m2}) R_{SS}}{(g_{m1} + g_{m2}) R_{SS} + 1} V_{in,CM} \tag{4.47}
$$

$$
V_X - V_Y = -\frac{g_{m1} - g_{m2}}{(g_{m1} + g_{m2}) R_{SS} + 1} R_D V_{in,CM} \tag{4.52}
$$

定义**共模-差模转换增益**：

$$
A_{CM-DM} = -\frac{\Delta g_m R_D}{(g_{m1} + g_{m2}) R_{SS} + 1} \tag{4.53}
$$

$A_{CM-DM}$ 与 $\Delta g_m$ 成正比，与 $R_{SS}$ 成反比。**增大 $R_{SS}$ → 降低 CM-DM 转换，与纯共模增益相同的结论。**

### Example 4.10：级联 + 电源噪声 + 尾电容

> 【插入 Razavi 图 4.35】两级差分对级联，尾节点有 $C_P$

用 $1/(C_P s)$ 替代 (4.53) 中的 $R_{SS}$：

$$
\lvert A_{CM-DM}\rvert = \frac{\Delta g_m R_D}{\sqrt{1 + (g_{m3} + g_{m4})^2 \left|\frac{1}{C_P \omega}\right|^2}} \tag{4.54}
$$

$\omega \uparrow$ → 分母第二项 ↓ → $|A_{CM-DM}| \uparrow$。**CM-DM 转换随频率升高而增强**——这是高频 PSRR 劣化的根源之一。

## 共模抑制比（CMRR）

将 CM-DM 转换的影响归一化到差模增益：

$$
\text{CMRR} = \left| \frac{A_{DM}}{A_{CM-DM}} \right| \tag{4.55}
$$

仅考虑 $g_m$ 失配时（$g_{m1} \neq g_{m2}$，$R_{D1} = R_{D2}$），差模增益为（由 4.2.2 方法一的完整表达式）：

$$
\lvert A_{DM}\rvert = \frac{R_D}{2} \frac{g_{m1} + g_{m2} + 4g_{m1} g_{m2} R_{SS}}{1 + (g_{m1} + g_{m2}) R_{SS}} \tag{4.56}
$$

$$
\text{CMRR} \approx \frac{g_m}{\Delta g_m} (1 + 2g_m R_{SS}) \tag{4.58}
$$

$2g_m R_{SS} \gg 1$ 时 $\text{CMRR} \approx 2g_m^2 R_{SS} / \Delta g_m$。

**CMRR 的两个贡献因子：**

- **$(g_m / \Delta g_m)$**：匹配项。器件匹配越好（$\Delta g_m$ 越小），CMRR 越高
- **$(1 + 2g_m R_{SS})$**：尾阻抗项。$R_{SS}$ 越大，CMRR 越高

两个因子相乘——匹配和尾阻抗对 CMRR 的贡献是**乘性**的。任一因子差都会导致 CMRR 低；但任一因子极好也不能完全补偿另一个。这是设计中的关键认识：**高 CMRR 要求匹配和尾阻抗同时好。**

### Example 4.11：理想尾电流源 = 无限 CMRR？

> 【插入 Razavi 图 4.36】体效应失配

**不是。** 即使 $R_{SS} = \infty$，若两管存在**体效应失配**（$g_{mb1} \neq g_{mb2}$），CM-DM 转换依然发生。

$V_{in,CM} \uparrow$ → $V_P \uparrow$ → $V_{BS}$ 变化 → 体效应产生额外电流 $g_{mb1} V_{BS}$ 和 $g_{mb2} V_{BS}$。若 $g_{mb1} \neq g_{mb2}$ → 两管总电流变化不同 → 差分输出误差。

这揭示了一个更深层的限制：**CMRR 的终极瓶颈不是尾阻抗，而是器件本身的对称性。** 任何两个晶体管之间的差异——尺寸、阈值、迁移率、体效应系数——都在将共模转化为差模。$R_{SS}$ 只能抑制尾电流路径上的转换，不能消除器件自身失配带来的转换。理解了这一点，就能理解为什么高 CMRR 设计首先要追求版图对称和质心布局（common-centroid layout）——第 19 章的内容。

## 4.3 的核心认识

4.3 将差分电路的分析从理想拉回现实。三个层层递进的结论：

1. **有限 $R_{SS}$ → 输出共模随输入共模漂移**（对称电路）→ 偏置点移动、摆幅损失
2. **失配 + 有限 $R_{SS}$ → CM-DM 转换**（不对称电路）→ 共模噪声直接污染差模信号，远比纯共模漂移危险
3. **某些失配（体效应）即使 $R_{SS} = \infty$ 也无法消除** → CMRR 受限于器件物理对称性本身

这三层递进对应了设计中的三个递进目标：增大 $R_{SS}$（电路级）→ 改善匹配（版图级）→ 接受残余失配并通过系统架构处理（如斩波、自调零等动态技术，第 14 章）。

# 4.4 MOS 负载的差分对

第 3 章中 CS 级的各种负载拓扑——二极管连接、电流源、Cascode——通过半电路法**直接迁移**到差分对。半电路将差分对折叠回 CS 级，第三章的所有公式和方法论原封不动地适用。因此 4.4 节的核心不再是推导新公式，而是识别差分对特有的问题：增益-摆幅折中如何在差分环境下表现，以及输出共模电平如何定义。

## 二极管连接负载

> 【插入 Razavi 图 4.37】(a) 二极管连接负载的差分对；(b) 电流源负载的差分对

半电路即[[C3.单级放大器#3.3.2 二极管连接型负载的共源级|二极管连接负载的 CS 级]]：

$$
A_v = -g_{mN}\left(g_{mP}^{-1} \parallel r_{ON} \parallel r_{OP}\right) \approx -\frac{g_{mN}}{g_{mP}} \tag{4.60}
$$

用尺寸比表达（$\lambda = 0$）：

$$
A_v \approx -\sqrt{\frac{\mu_n (W/L)_N}{\mu_p (W/L)_P}} \tag{4.61}
$$

增益仅取决于 NMOS 与 PMOS 的尺寸比，与偏置电流无关——与 CS 级的结论完全相同。平方-开方对消机制在差分环境下同样成立：$M_{1,2}$ 做平方运算（$V_{in} \to I_D$），$M_{3,4}$ 做开方运算（$I_D \to V_{GS}$），级联即线性化。

但差分对多了一个约束：**PMOS 的过驱动直接吃掉输出摆幅。** 由[[C3.单级放大器#3.3.2 二极管连接型负载的共源级|式 (3.37)]]，$|A_v| = |V_{GS3,4} - V_{THP}| / (V_{GS1,2} - V_{THN})$——增益 = 负载管过驱动 / 输入管过驱动。增大增益 → 必须增大 PMOS 过驱动 → 输出共模 $V_{DD} - |V_{GS3,4}|$ 下降 → 输出摆幅压缩。增益、过驱动、摆幅三者被同一个等式绑定，与单端情况完全相同。

## 电流源负载

半电路即[[C3.单级放大器#3.3.3 电流源负载的共源级|电流源负载的 CS 级]]：

$$
A_v = -g_{mN}(r_{ON} \parallel r_{OP}) \tag{4.62}
$$

增益比二极管负载高得多，但代价是输出共模电平**不确定**——两个高阻抗电流源的交叉点对失配极其敏感，$V_{out,CM}$ 可能严重偏离预期值。这与 CS 级电流源负载的偏置不确定性（[[C3.单级放大器#3.3.3 电流源负载的共源级|3.3.3]]）是同一问题。相比之下，二极管负载天然定义 $V_{out,CM} = V_{DD} - |V_{GSP}|$——这是二极管负载的一个重要实际优势，尤其在级联放大器中。高增益差分放大器需要**共模反馈（CMFB）**来定义输出共模（第 9 章）。

### Example 4.12：自偏置电流源负载

> 【插入 Razavi 图 4.38】(a) 用大电阻 $R_1$、$R_2$ 省去 $V_b$ 的自偏置方案；(b) 半电路

$R_1 = R_2$ 为大电阻，直流时 $V_X = V_Y = V_N = V_{DD} - |V_{GS3,4}|$——$M_3$、$M_4$ 自偏置。差模信号下，$V_N$ 不变（对称性 → 交流地，同 4.2.2 半电路引理）：

$$
\lvert A_v\rvert = g_{m1}(r_{O1} \parallel R_1 \parallel r_{O3}) \tag{4.63}
$$

$R_1$、$R_2$ 如果远大于 $r_{O1} \parallel r_{O3}$，几乎不影响增益。这种自偏置方案用两个大电阻替代了独立的 $V_b$ 偏置电压——节省一个偏置支路，代价是电阻占用面积，且 $R_1$ 不够大时会降低增益。

## 辅助电流源：解耦增益与摆幅

二极管负载的根本矛盾：增益 = 负载管过驱动 / 输入管过驱动 → 高增益必然消耗大过驱动 → 压缩摆幅。**减小负载管的 $W/L$ 可以增大过驱动（提高增益），但也增大过驱动，这本身就压缩摆幅。** 有没有方法在不过度减小 $W/L$ 的前提下降低负载管的 $g_m$？

**降低负载管偏置电流。** $g_m = 2I_D / (V_{GS} - V_{TH})$——给定过驱动下，$g_m \propto I_D$。

> 【插入 Razavi 图 4.39】(a) 辅助电流源 + 二极管负载；(b) 辅助电流源 + 电阻负载

方案：用 PMOS 电流源 $M_5$、$M_6$ 提供输入管 80% 的偏置电流。流经二极管连接管 $M_3$、$M_4$ 的电流降至原来的 1/5。保持相同的 $|V_{GS} - V_{TH}|$ → $W/L$ 也可缩小 5 倍 → $g_{m3,4}$ 降为原来的 1/5 → **增益提高 5 倍，过驱动不变。** 增益与摆幅实现了**解耦**——这在[[C3.单级放大器#3.3.2 二极管连接型负载的共源级|Example 3.6（电流抽取）]]中完全相同的思路，只是那里抽取 75%、这里抽取 80%。

图 4.39(a) 的限制：二极管连接管的 $V_{GS}$ 至少为 $|V_{THP}|$（亚阈值以下无意义），输出摆幅仍被 $V_{DD} - |V_{THP}|$ 约束。图 4.39(b) 改用电阻负载：$V_{out,max} = V_{DD} - |V_{GS3,4} - V_{TH3,4}|$——输出可高到一个过驱动以内的范围，而非一个阈值电压。80% 辅助电流下 $R_D$ 可增大 5 倍（电阻压降不变 = $R_D \times 0.2 I_D/2$ vs 原来 $R_D \times I_D/2$）：

$$
\lvert A_v\rvert = g_{mN}(R_D \parallel r_{ON} \parallel r_{OP}) \tag{4.64}
$$

若 PMOS 为长沟道器件（$r_{OP} \gg r_{ON}$），增益受限于 $R_D \parallel r_{ON}$。**$R_D \to \infty$ 时图 4.39(b) 退化为图 4.37(b) 的电流源负载——辅助电流源方案是二极管负载和电流源负载之间的连续谱。**

## Cascode 差分对

> 【插入 Razavi 图 4.40】(a) Cascode 差分对（NMOS + PMOS 双 Cascode）；(b) 半电路

纳米工艺中电流源负载差分对的增益仅 5–10。继续提高增益的方法：将 NMOS 和 PMOS 两侧都做 Cascode——即[[C3.单级放大器#3.6 共源共栅级|第 3.6 节]]的差分版本。

半电路即 Cascode + Cascode 负载（与 [[C3.单级放大器#3.6 共源共栅级|Fig. 3.70]] 相同）：

$$
\lvert A_v\rvert \approx g_{m1}\left[ (g_{m3} r_{O3} r_{O1}) \parallel (g_{m5} r_{O5} r_{O7}) \right] \tag{4.65}
$$

增益 ≈ 两管本征增益的乘积并上两管本征增益的乘积——大致是 $(g_m r_O)^2$ 量级。代价：四层堆叠（$M_1$、$M_3$、$M_5$、$M_7$）消耗四个过驱动 → **输出摆幅 = $V_{DD} - 4V_{ov}$**。这是增益-摆幅折中在 Cascode 差分对中的极致体现。第 9 章将回到这个电路。

## 输出共模电平的定义

四种差分对负载的对比：

| 负载类型 | 增益 | 输出 CM 定义 | 摆幅约束 |
|---|---|---|---|
| 电阻 | $g_{mN} R_D$ | $V_{DD} - R_D I_{SS}/2$ | $V_{DD} - V_{ov}$ |
| 二极管连接 | $g_{mN}/g_{mP}$ | $V_{DD} - \|V_{GSP}\|$ | $V_{DD} - \|V_{THP}\| - V_{ov}$ |
| 电流源 | $g_{mN}(r_{ON} \parallel r_{OP})$ | **不确定** | $V_{DD} - 2V_{ov}$ |
| Cascode | $\approx g_{m1}[(g_{m3}r_{O3}r_{O1}) \parallel (g_{m5}r_{O5}r_{O7})]$ | **不确定** | $V_{DD} - 4V_{ov}$ |

**二极管负载是唯一同时提供增益和明确输出 CM 的负载。** 电流源负载和 Cascode 负载增益更高，但输出 CM 不确定——需要 CMFB 来强制。这是第 9 章运放设计的核心矛盾：增益、摆幅、CM 稳定性三者不可兼得。

## 4.4 的核心认识

4.4 的内容本质是**半电路法的威力展示**：将差分对折叠成 CS 级，第三章的整座知识大厦——二极管负载的平方-开方对消、电流源的偏置不确定性、辅助电流源的增益-摆幅解耦、Cascode 的输出阻抗倍增——全部无缝迁移。4.4 新增的独立见解只有一条：**辅助电流源在差分环境下的应用及其向电流源负载的自然过渡。** 从二极管负载到辅助电流源到电流源负载到 Cascode，是一个增益逐步提高、CM 稳定性逐步丧失、复杂度逐步增加的连续设计空间。

# 4.5 Gilbert 单元

4.5 节是第 4 章的高潮——前面所有关于差分对的知识在此汇聚成一个经典的电路结构。Gilbert 单元的推导不是"给出电路然后分析"，而是**从两个基本观察出发，逐步构造**的过程。

## 两个基本观察

差分对有两个独立于小信号增益之外的深层属性：

1. **增益可控性**：$|A_v| = g_m R_D = \sqrt{\mu_n C_{ox} (W/L) I_{SS}} \, R_D$——增益是尾电流的函数。改变 $I_{SS}$ → 改变增益
2. **电流导向性**：差分对的两管将尾电流**导向**两个输出支路——$V_{in1} \gg V_{in2}$ 时全部 $I_{SS}$ 流向 $M_1$，反之流向 $M_2$

将这两个属性组合 → 增益可由外部信号控制的放大器 → 可变增益放大器 → 模拟乘法器。

## 从简单 VGA 到 Gilbert 单元：四步构造

### 第一步：简单 VGA

> 【插入 Razavi 图 4.41】(a) 控制电压定义尾电流的简单 VGA；(b) 两个增益相反的差分对

用控制电压 $V_{cont}$ 驱动尾电流源的栅极：$V_{cont}$ 变 → $I_{D3}$ 变 → $g_{m1,2}$ 变 → 增益变。$A_v$ 从 0（$I_{D3} = 0$）变化到由电压裕度和尺寸决定的最大值。

局限：增益只能从 0 到正值（或 0 到负值），不能**连续穿越零**改变极性。

### 第二步：两个增益相反的差分对并联

图 4.41(b)：上一对差分对提供 $-g_m R_D$（反相增益），下一对提供 $+g_m R_D$（同相增益）。$I_1$ 和 $I_2$ 反向变化 → 两个增益的幅值也反向变化 → 总增益可以连续从负穿越零到正。

### 第三步：电流域求和

> 【插入 Razavi 图 4.42】(a) 电压求和；(b) 电流域求和；(c) 用差分对控制 $I_1$/$I_2$；(d) Gilbert 单元

如何将两路输出合并？直觉是电压求和 $V_{out1} + V_{out2}$。但更巧妙的方法：

$$
V_{out1} = R_D I_{D1} - R_D I_{D2}, \quad V_{out2} = R_D I_{D4} - R_D I_{D3}
$$

$$
V_{out1} + V_{out2} = R_D(I_{D1} + I_{D4}) - R_D(I_{D2} + I_{D3})
$$

**直接短接对应漏极节点**——电流自动求和，再经 $R_D$ 转为电压。不需要加法器电路。

- $I_1 = 0$（全部 $I_{SS}$ 流向上对）→ $V_{out} = +g_m R_D V_{in}$
- $I_2 = 0$（全部 $I_{SS}$ 流向下对）→ $V_{out} = -g_m R_D V_{in}$
- $I_1 = I_2$ → 增益 = 0

### 第四步：用差分对控制 $I_1$ 和 $I_2$

需要一个电路使 $I_1$ 和 $I_2$ 反向变化——差分对天然具备此特性。$V_{cont1} \gg V_{cont2}$ → $I_{SS}$ 全部流经 $M_5$ → $I_1 = I_{SS}$，$I_2 = 0$。反之亦然。

将控制差分对放在底部、两个信号差分对堆叠在上方 → **Gilbert 单元**（图 4.42(d)）。典型设计中 $M_1$–$M_4$ 完全相同，$M_5$–$M_6$ 完全相同。

这个四步构造过程揭示了一个设计方法论：**从已有基本单元的两个属性出发 → 识别功能缺口 → 用另一个基本单元填补缺口 → 合并简化。** 每一步都只用了已经理解的结构，没有任何"黑魔法"。

### Example 4.13：模拟乘法器

Gilbert 单元可以相乘两个模拟电压。$V_{out} = V_{in} \cdot f(V_{cont})$，将 $f(V_{cont})$ Taylor 展开取一阶项：$V_{out} = \alpha V_{in} V_{cont}$。

乘法器的本质：**任何增益受控于另一电压的 VGA 都是模拟乘法器。** Gilbert 单元是这种思想在差分对上的实现——乘法功能并非偶然，而是增益可控性的直接推论。

Gilbert 单元广泛应用于：
- 模拟乘法器 / 混频器（mixer，RF 收发机核心模块） → [[C4.Transceiver Architecture|RFIC: 收发机架构]]
- 鉴相器（phase detector，PLL 核心模块）
- 可变增益放大器（VGA）

## 电压裕度：堆叠的代价

Gilbert 单元在垂直方向堆叠了两层差分对（$M_1$–$M_4$ 在上、$M_5$–$M_6$ 在下），代价是电压裕度。

设 $V_{CM,in}$ 为 $V_{in}$ 的共模电平，$M_1$–$M_4$ 完全相同。$V_A = V_B = V_{CM,in} - V_{GS1}$。$M_5$、$M_6$ 保持饱和需要：

$$
V_{CM,cont} \leq V_{CM,in} - V_{GS1} + V_{TH5,6}
$$

$V_{GS1} - V_{TH5,6}$ 约等于一个过驱动 → **控制共模电平必须比输入共模电平至少低一个过驱动。** 两层堆叠意味着输入和控制信号不能有相同的共模电平——设计输入/控制信号的直流偏置时必须有意识地留出这个差值。

这与 Cascode 的裕度消耗（[[C3.单级放大器#3.6|3.6 节]]、[[#4.4|4.4 节 Cascode 差分对]]）同源：**垂直堆叠 = 过驱动累加 = 摆幅压缩**。Gilbert 单元是 Cascode 的"功能堆叠"版本——Cascode 堆叠是为了阻抗倍增，Gilbert 堆叠是为了信号处理（乘法）。

## 两种配置：信号在上 vs 信号在下

> 【插入 Razavi 图 4.43】(a) 信号加在底部差分对的 Gilbert 单元；(b) $V_{cont}$ 很大正值时的信号路径；(c) $V_{cont}$ 很大负值时的信号路径

输入和控制信号的角色可以互换——信号加在底部 $M_5$–$M_6$，控制信号加在顶部 $M_1$–$M_4$。

- $V_{cont}$ 很大正值：仅 $M_1$、$M_3$ 导通 → $V_{out} = g_{m5,6} R_D V_{in}$
- $V_{cont}$ 很大负值：仅 $M_2$、$M_4$ 导通 → $V_{out} = -g_{m5,6} R_D V_{in}$
- $V_{cont} = 0$：$V_{out} = 0$

底部输入对的优势：可以在 $M_5$、$M_6$ 源极加退化电阻（[[C3.单级放大器#3.3.6|3.3.6 节]]），实现**线性 V-I 转换**——这是混频器设计中至关重要的考虑（高线性度输入级 + 开关型上对 → 理想乘法）。

**两种配置的选择取决于哪个信号需要更高线性度、哪个信号可以有更大的摆幅。** 在 RF 混频器中，通常底部处理 RF 信号（需线性 V-I 转换）、顶部处理 LO 信号（大摆幅开关切换）。

## Gilbert 单元与 Cascode 的对比

| | Cascode | Gilbert 单元 |
|---|---|---|
| 堆叠方式 | CS + CG（同型或异型管） | 两层差分对 |
| 堆叠目的 | 阻抗倍增、屏蔽 | 电流导向、增益可控 |
| 层间关系 | 电流复用（$I_{D1} = I_{D2}$） | 下层为上层分配尾电流 |
| 功能 | 单端/差分放大器 | 乘法器 / VGA / 混频器 |
| 共通代价 | 裕度消耗（$+V_{ov}$/层） | 裕度消耗（输入和控制 CM 不能相同） |

两者都是"堆叠"思想的产物——这是模拟 IC 设计的核心范式之一：**垂直堆叠器件以换取性能维度（增益、带宽、功能），代价是电压裕度。** 在 $V_{DD}$ 不断降低的纳米工艺中，可堆叠的层数越来越少——Cascode 从三重退到两重，Gilbert 单元的结构创新（如折叠 Gilbert）随之而来。

## 4.5 的核心认识

4.5 不是简单介绍一个电路，而是展示了一套**构造方法论**：

1. 识别基本单元的非显而易见属性（差分对的增益可控 + 电流导向）
2. 发现功能缺口（需要增益可从负到正连续变化）
3. 用已知单元填补缺口（两个增益相反的差分对 → 差分对控制尾电流分配）
4. 优化实现（电流域求和替代电压求和 → 短接漏极即可）

Gilbert 单元是第 4 章所有知识的综合应用——差模-共模分解、半电路法、偏置与裕度、差分对的传输特性——全在这个电路中同时起作用。它也是从"放大器"到"信号处理"的桥梁：同一结构可以放大、可以乘、可以混频、可以鉴相——功能的差异仅在于信号的频率关系和直流偏置安排。
