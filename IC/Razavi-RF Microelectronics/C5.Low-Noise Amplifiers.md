# C5.Low-Noise Amplifiers

# 一般考量

LNA 是接收机的**第一有源级**，直接面对天线/双工器送来的微弱信号与强干扰，其设计由噪声系数、增益、输入回波损耗、稳定性、线性度、带宽、功耗七个参数主导。

## 噪声系数

LNA 的 NF **直接叠加**到整机 NF 上。典型 RX 总 NF = 6–8 dB 的分配：天线开关/双工器 0.5–1.5 dB，LNA 2–3 dB，其余链路 2.5–3.5 dB。现代 RF 设计**不孤立设计 LNA**，而是把整个 RF 链当作一个整体反复迭代。

**NF = 2 dB 的物理量级**：输入参考噪声电压须达 $\sqrt{\overline{V_{n,in}^2}} = 0.696\ \mathrm{nV/\sqrt{Hz}}$（对 $R_S = 50\Omega$）。MOSFET 栅参考热噪声 $4kT\gamma/g_m$ 要达到此值，需 $g_m = (29\Omega)^{-1}$（$\gamma = 1$）——一个**极高的跨导**。

![[RazaviRF-图5.1.jpg|400]]

**例 5.1（走线电阻恶化 NF）**：LNA 输入端经 200 μm 长、0.5 μm 宽金属线连到焊盘，方块电阻 40 mΩ/□ → $R_L = (200/0.5)\times 40\ \mathrm{m}\Omega = 16\Omega$。该电阻与输入参考噪声串联叠加：

$$\mathrm{NF_{tot}} = \mathrm{NF_{LNA}} + \frac{R_L}{R_S} \tag{5.5}$$

$\mathrm{NF_{LNA}} = 2\ \mathrm{dB} \equiv 1.58$，$R_L/R_S = 16/50 = 0.32$ → $\mathrm{NF_{tot}} = 2.79\ \mathrm{dB}$。

> **设计启示**：即使 16Ω 的走线/栅电阻也把 NF 从 2 dB 抬到 2.79 dB。LNA 的版图走线电阻是噪声预算里的"隐形杀手"。

![[RazaviRF-图5.2.jpg|400]]

低噪声要求**限制了拓扑选择**——通常只能有一个晶体管（输入管）主导 NF，因此**排除源极/射极跟随器**等结构（它们的噪声不经增益压缩）。

## 增益

LNA 增益须足够大以**压低后级（下变频混频器）的噪声贡献**。但增益越高，后级非线性越被放大——增益在 NF 与线性度之间折中。

现代 RF 中 LNA **直接驱动混频器**（两者间无阻抗匹配），故链式计算用**电压增益**（而非功率增益）更简单、更有意义。

**关键不对称**：噪声与 IP₃ 被**不同的增益**除。设 LNA 电压增益 $A_{v1}$、混频器单位增益：

$$\mathrm{NF_{tot}} = \mathrm{NF_{LNA}} + \frac{\overline{V_{n,mix}^2}}{A_{v1}^2}\cdot\frac{1}{4kTR_S} \tag{5.7,5.8}$$

混频器噪声被 $A_{v1}^2$ 除；而混频器 IP₃ 被 $\alpha_1^2$ 除，其中 $\alpha_1$ 是输入源到 LNA 输出的电压增益。输入匹配时 $R_{in} = R_S$、$\alpha_1 = 2A_{v1}$：

$$\frac{1}{\mathrm{IP}_{3,\text{tot}}^2} = \frac{1}{\mathrm{IP}_{3,\text{LNA}}^2} + \frac{\alpha_1^2}{\mathrm{IP}_{3,\text{mixer}}^2} \tag{5.9}$$

> **设计启示**：混频器噪声被**较低增益** $A_{v1}$ 除，混频器 IP₃ 被**较高增益** $2A_{v1}$ 除——两者都与设计者愿望相反。增大 LNA 增益改善 NF，却恶化线性度，无法同时最优。

## 输入回波损耗

天线与 LNA 之间的接口是**模拟设计师与微波工程师的分歧点**：电压放大器希望 $Z_{in} \to \infty$；噪声视角希望在输入端加变换网络取最小 NF；信号功率视角希望共轭匹配。三者不可兼得。

**为什么 LNA 最终必须 50Ω 匹配**（三条原因）：

1. 天线与 LNA 之间的（片外）带选滤波器按标准 50Ω 终端设计——若 LNA 输入阻抗偏离 50Ω，滤波器通带/阻带出现损耗与纹波；
2. 天线本身为特定实负载设计，负载偏离会引入未表征损耗；
3. PCB 上信号要跑相当距离，RX 输入端匹配差 → 显著反射、未表征损耗、电压衰减。

所以 LNA 设计为 **50Ω 电阻性输入**。而 RX 内其他接口（LNA-混频器、LO-混频器）无上述约束，故**最大化电压摆幅而非功率传输**。

**回波损耗（return loss）** = 反射功率/入射功率：

$$\Gamma = \left|\frac{Z_{in} - R_S}{Z_{in} + R_S}\right|^2 \tag{5.10}$$

$S_{11} < -10\ \mathrm{dB}$（1/10 功率被反射）通常可接受，实际目标 **−15 dB** 以留封装寄生裕量。

## 稳定性

LNA 必须与"外部世界"接口——**源阻抗不受控**（用户手握天线即改变天线阻抗）。因此 LNA 必须对**所有源阻抗、所有频率**保持稳定。即使只在带内工作，若在任何频率起振，增益就被严重压缩、高度非线性。

**Stern 稳定因子**：

$$K = \frac{1 + |\Delta|^2 - |S_{11}|^2 - |S_{22}|^2}{2|S_{21}||S_{12}|}, \qquad \Delta = S_{11}S_{22} - S_{12}S_{21} \tag{5.11}$$

$K > 1$ 且 $\Delta < 1$ → **无条件稳定**（任意源/负载阻抗都不振荡）。

> 现代 RF 中 LNA 负载（片上混频器输入阻抗）相对可控，$K$ 是**悲观的**稳定判据；且 LNA 输出通常不与混频器匹配，$S_{22}$ 在此环境下意义不大。

**例 5.2（反向隔离 → 稳定）**：共源共栅级反向隔离高（$S_{12} \approx 0$）、输出阻抗高（$S_{22} \approx 1$）。代入得 $|S_{21}| < (1-|S_{22}|^2)/(2|S_{12}|)$——前向增益受限；$\Delta < 1$ 要求 $S_{11} < 1$，即输入电阻保持正。

> **设计启示**：通过**最大化反向隔离**来稳定 LNA——由此引出 5.3 节两种天然稳定的鲁棒拓扑（可无稳定性顾虑地优化其他指标）。高反向隔离还抑制 LO 泄漏到 LNA 输入端。

**失稳来源**：封装带来的接地/电源寄生电感（几十 GHz 时还有片上走线电感）构成输出→输入反馈。共栅管的栅极若有大的串联电感，就可能在某频率失稳——版图与封装建模必须谨慎。

## 线性度

大多数应用中 **LNA 不限制接收机线性度**：RX 链增益累积，后级（基带放大器/滤波器）趋于限制整体 IIP₃ / $P_{1dB}$。故 LNA 设计时**几乎不考虑线性度**。

**例外——全双工（FDD）系统**：收发同时进行，强发射信号泄漏进接收端。CDMA 前端（Fig. 5.5）中双工器 RX 路径损耗 $S_{31}$、TX 路径损耗 $S_{21}$ 约 1–2 dB，而 TX→RX 隔离 $S_{32} \approx -50\ \mathrm{dB}$。若 PA 平均输出 +30 dBm（1 W），LNA 在 TX 频带承受 **−20 dBm**，而待收信号极微弱。TX 信号包络可变 → 峰值再高 ~2 dB → RX 须在 **−18 dBm** 不压缩 → 取 $P_{1dB} \approx -15\ \mathrm{dBm}$（留裕量）。

![[RazaviRF-图5.5.jpg|400]]

> **连锁代价**：LNA 增益 15–20 dB 时，−15 dBm 输入 → 输出 0 ~ +5 dBm（$632\ \mathrm{mV_{pp}}$ ~ $1.12\ \mathrm{V_{pp}}$），可能使 LNA 输出端压缩；下变频混频器 $P_{1dB}$ 也须达 0 ~ +5 dBm（对应 IP₃ 约 +10 ~ +15 dBm）。故有些 CDMA 接收机在 LNA 与混频器间插入片外滤波器滤除 TX 泄漏。

**宽带接收机**（UWB、软件定义、认知无线电）会同时感应大量强干扰，LNA 线性度同样关键。

## 带宽

LNA 须在目标频段内提供**平坦响应**（增益变化 < 1 dB），故其 −3 dB 带宽须远大于实际频段，使边缘滚降 < 1 dB。

**分数带宽（fractional bandwidth）** = 总 −3 dB 带宽 / 中心频率。802.11g LNA 需 $80\ \mathrm{MHz}/2.44\ \mathrm{GHz} = 0.0328$。

**例 5.3（Q 值上限）**：802.11a LNA 需 5–6 GHz 的 −3 dB 带宽。LC 谐振腔分数带宽 = $\Delta\omega/\omega_0 = 1/Q$ → $Q < 5.5\ \mathrm{GHz}/1\ \mathrm{GHz} = 5.5$。

![[RazaviRF-图5.6.jpg|400]]

**频带切换**：分数带宽大时，可用开关电容切换中心频率——$C_2$ 并入谐振腔后 $\omega_1 = 1/\sqrt{L_1C_1} \to \omega_2 = 1/\sqrt{L_1(C_1+C_2)}$（5.5 节详述）。

![[RazaviRF-图5.7a.jpg|280]] ![[RazaviRF-图5.7b.jpg|280]]

## 功耗

LNA 在噪声、线性度、功耗之间存在直接折中。但大多数接收机中 LNA 仅占整机功耗的一小部分——**NF 远比功耗关键**（与基带电路相反）。

> **贯穿性直觉**：5.1 节的七个参数构成 LNA 的"设计八边形"。其中噪声系数与增益、增益与线性度、带宽与 Q 值两两冲突，是后续 5.2（输入匹配）、5.3（拓扑）所有折中的根源。

# 输入匹配的问题

5.1 要求 LNA 提供 **50Ω 电阻性输入、可忽略的输入电抗**。这一要求反过来**限制拓扑选择**——不能先任意设计某拓扑满足噪声与增益，再事后"补"一个匹配。

## CS 级的输入导纳

考察带栅漏交叠电容 $C_F$ 的简单 CS 级（Fig. 5.8）。两个极限：

![[RazaviRF-图5.8.jpg|350]]

- **低频**：$R_D$ 远小于 $C_F, C_L$ 的阻抗 → 输入阻抗 ≈ $[(C_{GS}+C_F)s]^{-1}$（纯容性）；
- **高频**：$C_F$ 短路栅漏 → 输入电阻 = $R_D \parallel (1/g_m)$。

一般地，输入导纳的实部与虚部（Miller 效应）为

$$\mathrm{Re}\{Y_{in}\} = R_D C_F \omega^2 \frac{C_F + g_m R_D (C_L + C_F)}{R_D^2(C_L+C_F)^2\omega^2 + 1} \tag{5.15}$$

代入典型值 $C_F = 10\ \mathrm{fF}$、$C_L = 30\ \mathrm{fF}$、$g_m R_D = 4$、$R_D = 100\Omega$，5 GHz 时 $\mathrm{Re}\{Y_{in}\} = (7.8\ \mathrm{k}\Omega)^{-1}$，**远离 $(50\Omega)^{-1}$**。

> **结论**：$C_F$（10 fF 量级）在该频率引入的反馈太弱——**不能依赖寄生电容 $C_F$ 完成匹配**。

**例 5.4（导纳 vs 阻抗）**：选导纳或阻抗是任意的。若用并联电感抵消输入电容，则 $\mathrm{Im}\{Y_{in}\}$ 更相关；串联电感则抵消 $\mathrm{Im}\{Z_{in}\}$。

## 电阻终端匹配

能否用实体电阻做输入匹配？三步法（Fig. 5.9）：(1) $M_1$+$R_D$ 提供所需 NF 与增益；(2) $R_P$ 并联到输入提供 $\mathrm{Re}\{Z_{in}\} = 50\Omega$；(3) 串联电感抵消 $\mathrm{Im}\{Z_{in}\}$。

![[RazaviRF-图5.9.jpg|400]]

问题在于**终端电阻自身的噪声**。由 Fig. 5.9(b) 总输出噪声：

$$\overline{V_{n,out}^2} = 4kT(R_S\parallel R_P)(g_m R_D)^2 + 4kT\gamma g_m R_D^2 + 4kTR_D \tag{5.17}$$

噪声系数：

$$\mathrm{NF} = 1 + \frac{R_S}{R_P} + \frac{\gamma R_S}{g_m(R_S\parallel R_P)^2} + \frac{R_S}{g_m^2(R_S\parallel R_P)^2 R_D} \tag{5.18}$$

$R_P \approx R_S$ 时 **NF 超过 3 dB**（可能高得多）。

> **核心洞察**：LNA 必须提供 50Ω 输入电阻，却**不能携带实体 50Ω 电阻的热噪声**。这只有靠**有源器件**（晶体管）合成输入阻抗才能做到——引出 5.3 节全部拓扑。

## 匹配网络变换——热力学下限

**例 5.5（能否绕过 3 dB？）**：学生不服，选大 $R_P$ 再用无损匹配网络把它变换下来到 $R_S$（Fig. 5.10）。能否 NF < 3 dB？

![[RazaviRF-图5.10a.jpg|350]] ![[RazaviRF-图5.10b.jpg|350]]

设无损网络 $H(s)$ 使 $Z_{in} = R_S$，则功率守恒：$V_{in}$ 送入 $H(s)$ 的功率全部送达 $R_P$：

$$\frac{V_{in,rms}^2}{4R_S} = \frac{V_{out,rms}^2}{R_P} \;\Rightarrow\; |A_v|^2 = \frac{R_P}{4R_S} \tag{5.19,5.20}$$

**热力学论证**：$R_S$ 与 $R_P$ 处于热平衡，则两者互相输送的噪声功率相等（否则一个升温、一个降温）。由互易网络的对称性可得 $R_{out} = R_P$。于是 $R_S$ 噪声与 $R_P$ 噪声在输出各贡献 $kTR_P$，总输出噪声 $2kTR_P$，除以增益 $|A_v|^2 = R_P/(4R_S)$ 与 $4kTR_S$：

$$\mathrm{NF} = 2 \quad (\text{即 } 3\ \mathrm{dB}) \tag{5.26}$$

> **物理极限而非设计缺陷**：增大 $R_P$ → 增益同步增大 → $kTR_P$ 噪声同步增大 → NF 恒为 2（3 dB），无损匹配网络**无法突破**。学生"试图违背物理定律"。

**总结**：正确的输入（共轭）匹配需要特定电路技术——在**无实体 50Ω 电阻噪声**的前提下产生 50Ω 实部。这些技术即 5.3 节的三种有源方案：电感退化 CS、CG、阻性反馈。

# LNA 拓扑

噪声系数、输入匹配、增益是 LNA 设计三大目标。本节逐一分析各拓扑在这三个目标下的表现（表 5.1 总览）。

## 电感负载共源级

阻性负载 CS 的三大缺陷：不提供匹配、输出节点时间常数限制高频、增益-电压折中。

**增益-电压折中**：低频时

$$|A_v| = g_m R_D = \frac{2V_{RD}}{V_{GS} - V_{TH}} \tag{5.29}$$

$V_{RD}$ 是 $R_D$ 上的直流压降、受 $V_{DD}$ 限制。电源电压随工艺缩小 → $V_{RD}$ 缩小 → 增益更低。沟道长度调制使增益进一步下降。

**电感负载**（Fig. 5.11a）绕开这一折中：电感直流压降小（理想为零）→ 低电源电压可工作；且 $L_1$ 与输出节点总电容**谐振** → 工作频率远高于阻性负载。

![[RazaviRF-图5.11a.jpg|330]] ![[RazaviRF-图5.11b.jpg|330]] ![[RazaviRF-图5.11c.jpg|280]]

**输入匹配分析**：含栅漏交叠电容 $C_F$ 的完整电路（Fig. 5.11b），推导输入阻抗：

$$Z_{in}(s) = \frac{L_1(C_1+C_F)s^2 + R_S(C_1+C_F)s + 1}{[L_1C_1s^2 + (R_SC_1+g_mL_1)s + 1 + g_mR_S]C_F s} \tag{5.32}$$

其中 $C_1$ 为输出节点总电容、$R_S$ 为电感损耗的串联模型。可以选取参数使 $\mathrm{Re}\{Z_{in}\} = 50\Omega$。

**致命缺陷——$C_F$ 反馈导致负阻**：$\mathrm{Re}\{Z_{in}\}$ 的分子在频率 $\omega_1$ 处过零、**变号**：

$$\omega_1^2 = \frac{R_SC_1 + g_mL_1 - (1+g_mR_S)R_S(C_1+C_F)}{g_mL_1^2(C_1+C_F)} \tag{5.36}$$

变号意味着出现**负输入电阻** → 可能失稳。数值例（$C_F=10\ \mathrm{fF}, C_1=30\ \mathrm{fF}, g_m=(20\Omega)^{-1}, L_1=5\ \mathrm{nH}, R_S=20\Omega$）得 $\omega_1 \approx 2\pi\times 11.3\ \mathrm{GHz}$。

**中和 $C_F$**（Fig. 5.12）：用并联谐振 $L_F$ 在部分频段中和 $C_F$。但 $C_F$ 小 → $L_F$ 须大 → 引入显著输入/输出寄生电容（甚至输入-输出之间）→ 性能退化。

![[RazaviRF-图5.12.jpg|350]]

> **结论**：电感负载 CS 解决增益/频率，但 $C_F$ 反馈引入负阻失稳，**现代 RF 设计中很少使用**。真正实用的输入匹配要靠后面 5.3.2–5.3.4 的有源阻抗合成。

## 阻性反馈共源级

工作频率比晶体管 $f_T$ 低一个数量级时可用此拓扑（Fig. 5.13）：$M_2$ 作电流源，$R_F$ 检测输出电压、向输入返回电流。

![[RazaviRF-图5.13a.jpg|330]] ![[RazaviRF-图5.13b.jpg|300]]

**输入匹配**：忽略沟道长度调制时 $R_F$ 与理想电流源串联、$M_1$ 呈二极管连接：

$$R_{in} = \frac{1}{g_{m1}} \tag{5.37}$$

故取 $g_{m1} = 1/R_S$ 即得匹配。

**电压增益**：$M_1$ 的小信号漏电流 $g_{m1}V_X$ 全部流过 $R_F$，产生压降 $g_{m1}V_X R_F$：

$$A_v = \frac{1}{2}\left(1 - \frac{R_F}{R_S}\right) \approx -\frac{R_F}{R_S} \quad (R_F \gg R_S) \tag{5.42,5.43}$$

> **优势**：与阻性负载 CS（Fig. 5.8）不同，此电路**无增益-电压折中**——因为 $R_F$ 不承载偏置电流。

**噪声系数**（$g_{m1} = 1/R_S$）：

$$\mathrm{NF} \approx 1 + \frac{4R_S}{R_F} + \gamma + \gamma g_{m2}R_S \tag{5.50}$$

$\gamma \approx 1$ 时，**NF 超过 3 dB**（即使 $4R_S/R_F + \gamma g_{m2}R_S \ll 1$）。$\gamma$ 项来自 $M_1$ 的沟道热噪声——$M_1$ 的噪声未经任何增益压缩直接出现在输入。

![[RazaviRF-图5.14.jpg|400]]

**例 5.6（第四项的量级）**：$g_{m2}R_S = g_{m2}/g_{m1} = (V_{GS}-V_{TH})_1/|V_{GS}-V_{TH}|_2$。第四项可忽略**仅当电流源过驱动远大于 $M_1$**——低电源电压下难以满足（$|V_{DS2}| = V_{DD} - V_{GS1}$）。

**例 5.7（有源负载版）**：把 PMOS 电流源改为**有源负载**（$M_2$ 也放大输入）。小信号下 $M_1, M_2$ 并联，等效跨导 $g_{m1}+g_{m2}$，输入匹配要求 $g_{m1}+g_{m2} = 1/R_S$：

$$\mathrm{NF} \approx 1 + \frac{4R_S}{R_F} + \gamma \tag{5.52}$$

两管都放大信号 → 噪声更低。但需要 $V_{DD} = V_{GS1} + |V_{GS2}| + V_{I1}$（$V_{I1}$ 为电流源压摆裕度）——**更高的电源电压**。

![[RazaviRF-图5.15.jpg|330]]

> **小结**：阻性反馈 CS 用 $1/g_{m1}$ 合成 50Ω（无实体电阻噪声），但 $M_1$ 的 $\gamma$ 项把 NF 锁在 3 dB 以上；有源负载版降到 $1+4R_S/R_F+\gamma$，代价是电源电压。这是"有源阻抗合成"的第一种途径。

## 共栅级

CG 级的**低输入阻抗**（$1/g_m$）使其适合 LNA。阻性负载 CG 与 CS 一样受增益-电压折中所限，故只用电感负载版（Fig. 5.16）。

![[RazaviRF-图5.16.jpg|400]]

### 基本特性

忽略沟道长度调制与体效应时 $R_{in} = 1/g_m$，取 $g_m = 1/R_S = (50\Omega)^{-1}$。谐振频率处电压增益：

$$\frac{V_{out}}{V_{in}} = \frac{R_1}{2R_S} \tag{5.53,5.54}$$

噪声系数（$g_m = 1/R_S$）：

$$\mathrm{NF} = 1 + \gamma + 4\frac{R_S}{R_1} \tag{5.58}$$

$\gamma \approx 1$ 时 NF 达 3 dB——这是 $g_m = 1/R_S$ 的代价：**$g_m$ 越高 NF 越低，但输入电阻也越低**（允许部分失配可换更低 NF）。

### 偏置选择（例 5.8）

电流源 vs 电阻做偏置：$M_2$ 噪声电流 $\overline{I_{n,M2}^2} = 4kT\gamma \cdot 2I_D/(V_{GS2}-V_{TH2})$，$R_B$ 噪声 $4kTI_D/V_{RB}$。因 $V_{GS2}-V_{TH2} \le V_{RB}$，$M_2$ 噪声约为 $R_B$ 的两倍（$\gamma\approx1$），且 $M_2$ 在输入节点引入显著电容。**电阻更优**（只要 $R_B \gg R_S$ 不衰减输入信号）。

![[RazaviRF-图5.17.jpg|380]]

### 深亚微米的沟道长度调制问题

**正反馈抬升输入阻抗**：漏源电流经 $r_O$ 反馈，输入阻抗变为

![[RazaviRF-图5.19.jpg|350]]

$$R_{in} = \frac{R_1 + r_O}{1 + g_m r_O} \tag{5.64}$$

若 $g_m r_O \gg 1$ 则 $R_{in} \approx 1/g_m + R_1/(g_m r_O)$。但现代工艺 $g_m r_O$ 难超 10 → $R_1/(g_m r_O)$ 可与 $1/g_m$ 相当甚至更大 → **输入阻抗远超 50Ω**。

> **两难**：忽略 CLM 时 $R_{in}$ 太低，考虑 CLM 时又太高。现代工艺面对的是**后者**。

**增大沟长**可减小 CLM、提升 $g_m r_O$，但宽度须同比例增大以保持跨导 → $C_{GS}$ 显著上升 → 恶化回波损耗。

### 共源共栅 CG 级

在 $M_1$ 上叠加 cascode 管 $M_2$（Fig. 5.21）降低输入阻抗。$R_X$（看进 $M_2$ 源极）被 $M_1$ 再变换一次：

![[RazaviRF-图5.21.jpg|350]]

$$R_{in} \approx \frac{1}{g_{m1}} + \frac{R_1}{g_{m1}r_{O1}\,g_{m2}r_{O2}} + \frac{1}{g_{m1}r_{O1}g_{m2}} \tag{5.70}$$

$R_1$ 被**两个本征增益的乘积**除 → 可忽略 → $R_{in} \approx 1/g_{m1}$。

**代价一——$M_2$ 噪声**：低频时 $M_2$ 噪声被 $C_X = C_{DB1}+C_{GD1}+C_{SB2}$ 屏蔽，但超过零点频率 $(2r_{O1}C_X)^{-1}$ 后开始显现。该零点远低于 $f_T$（$2r_{O1} \gg 1/g_m$、$C_X \sim C_{GS}$），故**潜在显著**。例 5.10：在 $g_{m2}/(C_{GS2}+C_X)$ 以下、$(2r_{O1}C_X)^{-1}$ 以上，$M_2$ 噪声几乎**无衰减**到达输出（$V_{out}/V_{in} \approx -R_1 C_X s$）。

![[RazaviRF-图5.22.jpg|400]]

**代价二——电压裕度**：两级堆叠消耗一个 $V_{GS}$ 加一个过驱动 $V_{GS1}-V_{TH1}$。数值例：$I_D = 2\ \mathrm{mA}$、$g_{m1}=(50\Omega)^{-1}$ → $V_{GS1}-V_{TH1} = 200\ \mathrm{mV}$；$V_{GS2}\approx 500\ \mathrm{mV}$；$V_{DD}=1\ \mathrm{V}$ 时偏置电阻 $R_B$ 只剩 300 mV 压降 → $R_B \le 150\Omega$，与 $R_S = 50\Omega$ 相当 → 显著恶化增益与噪声。

### 电感偏置与设计流程

**电感偏置**（Fig. 5.24）：用 $L_B$ 替代偏置电阻/电流源，避免噪声-裕度折中，并**抵消输入电容**（$L_B$ 与 $C_{pad}+C_{SB1}+C_{GS1}$ 谐振）。代价是 $L_B$ 的并联等效电阻 $R_p = QL_B\omega$ 须 $\ge 10\times R_S$。

![[RazaviRF-图5.24.jpg|380]]

**五步设计流程**（Fig. 5.24）：

1. **选 $M_1$**：长度取工艺最小值；仿真 $g_m$-$I_D$ 曲线，选电流密度取饱和 $g_m$ 的 80–90%（速度与功耗近最优），再按 $1/g_{m1}=50\Omega$ 缩放 $W$ 与 $I_D$（$g_m$ 随 $W$、$I_D$ 等比缩放，与器件类型无关）；

![[RazaviRF-图5.25.jpg|380]]
2. **选 $L_B$**：与 $C_{pad}+C_{SB1}+C_{GS1}$ 及自身寄生电容谐振于工作频率；
3. **偏置**：$W_B = 0.2W_1$、$I_{REF} = 0.2I_{D1}$（偏置支路只取 1/5 电流），$C_B$ 提供栅到地的低阻抗并旁路 $M_B$/$I_B$ 噪声；
4. **选 $M_2$**：宽度取 $W_1$ 附近（过窄 → $V_{GS2}$ 过大、$M_1$ 进三极管区；过宽 → $C_X$ 增大而 $g_m$ 饱和）；
5. **选 $L_1$**：与 $C_{GD2}+C_{DB2}$+下级输入电容谐振，$R_1 = QL_1\omega = 500\text{–}1000\Omega$。

**版图技巧**：$M_1$ 漏区与 $M_2$ 源区**共享**（无接触孔、面积最小化）以减小节点 X 电容。

![[RazaviRF-图5.27.jpg|330]]

**设计结果**（例 5.11：5.5 GHz、65 nm）：NF ≈ 3 dB，增益 15–20 dB，**高 IIP₃（+5 ~ +10 dBm）**。增益过高时可在谐振腔并联电阻压到目标值。

![[RazaviRF-图5.29.jpg|400]]

## 电感退化共源共栅级

5.3.1 的电感负载 CS 用 $C_{GD}$ 反馈产生实部，却带来低频负阻。需要一种**输入与电感负载隔离**、且**不靠 $C_{GD}$ 建立输入电阻**的拓扑——电感退化 CS 级。

### 核心思想——电感退化产生实部

忽略 $C_{GD}, C_{SB}$，输入电流 $I_X$ 流过 $C_{GS1}$ 产生 $V_{GS} = I_X/(C_{GS1}s)$、漏电流 $g_m I_X/(C_{GS1}s)$，二者共同流过 $L_1$：

$$Z_{in} = \frac{1}{C_{GS1}s} + L_1 s + \frac{g_m L_1}{C_{GS1}} \tag{5.77}$$

**第三项是频率无关的实部** $\dfrac{g_m L_1}{C_{GS1}} = L_1 \omega_T$（因 $g_m/C_{GS1} \approx \omega_T$）。可令其等于 50Ω。

![[RazaviRF-图5.31a.jpg|330]] ![[RazaviRF-图5.31b.jpg|300]]

**量级问题**：65 nm 工艺 $\omega_T \approx 2\pi\times 160\ \mathrm{GHz}$ → 50Ω 实部只需 $L_1 \approx 50\ \mathrm{pH}$。而实际退化电感常用**键合线**（封装不可避免），即使"downbond"直接接地也有 0.5–1 nH——**远超 50 pH**，输入电阻远高于 50Ω。

**解法**：在 $\omega \ll f_T$ 时降低 $f_T$——增大沟长或在 $C_{GS}$ 上并联显式电容。$L_1 = 0.5\ \mathrm{nH}$ 时 $f_T$ 须降到 ~16 GHz。

### 栅漏电容与焊盘电容的修正

**$C_{GD}$ 效应**（例 5.12，$R_1 \approx 1/g_m$ 的 cascode 情形）：输入电阻下降一个因子 $1 - 2C_{GD}/C_{GS}$。

**焊盘电容效应**（Fig. 5.33）：$C_{pad}$ 把输入电阻进一步压低：

![[RazaviRF-图5.33.jpg|400]]

$$R_{eq} \approx \left(\frac{C_{GS1}}{C_{GS1} + C_{pad}}\right)^2 R_1 \tag{5.85}$$

$C_{GS1} \approx C_{pad}$ 时输入电阻降 4 倍。两个效应意味着 **$f_T$ 不必降那么多**即可得 50Ω；但退化电感已不足以与 $C_{GS1}+C_{pad}$ 谐振，须在栅极**串联 $L_G$**（通常片外）。

![[RazaviRF-图5.34.jpg|350]]

**例 5.13（$L_G$ 必须片外）**：$L_G = 2\ \mathrm{nH}$、片上 $Q = 5$ → 串联电阻 $L_G\omega/Q = 12.6\Omega$，相对 50Ω 不小 → 严重恶化 NF。故 $L_G$ 放片外。

### 噪声系数与跨导

忽略 CLM、体效应、$C_{GD}$、$C_{pad}$，输入网络在 $\omega_0$ 谐振（$(L_1+L_G)C_{GS1} = \omega_0^{-2}$）时：

$$\mathrm{NF} = 1 + g_m R_S \gamma\left(\frac{\omega_0}{\omega_T}\right)^2 \tag{5.95}$$

（仅当输入匹配、且在谐振频率处成立。）

**跨导增益**：

$$\left|\frac{I_{out}}{V_{in}}\right| = \frac{\omega_T}{2\omega_0}\cdot\frac{1}{R_S} \tag{5.91}$$

输入匹配时，电路跨导**与 $L_1, L_G, g_m$ 无关**。

**例 5.14（缩放悖论）**：$W, I_D$ 等比缩小 → $g_m, C_{GS1}$ 减而 $\omega_T$ 不变 → (5.95) 看似 NF 降、功耗也降，能否 NF=1 且零功耗？不能——$C_{GS1}$ 减则 $L_G+L_1$ 须增，输入网络 $Q = L_G\omega_0/R_S \to \infty$，输入电压增益无穷 → $R_S$ 噪声淹没 $M_1$ 噪声 → NF→1；但**实际电感 $Q$ 有限**（寄生电容）限制性能。若固定 $L_G$ 增大 $L_1$，NF→1 但 (5.90) 跨导→0——**零噪声但零增益**。

### 输入网络的电压增益

最大化 $L_G$ 可压低 NF：它给 $V_{in}\to$ 栅极提供电压增益

$$\frac{V_G}{V_{in}} = \frac{1}{2}\left(1 + \frac{L_G\omega_0}{R_S}\right) = \frac{1+Q}{2} \tag{5.96}$$

$Q = L_G\omega_0/R_S$。设计从**可取的最大 $L_G$**（片外、寄生可忽略）开始。输入增益（典型高达 6 dB）会降低 IP₃/$P_{1dB}$，但多数应用仍够用。

### 完整电路与设计流程

输出侧：$C_{GD1}$ 反馈仍会引入负阻，故加 **cascode 管** $M_2$ 抑制（Fig. 5.37）。电压增益：

![[RazaviRF-图5.37.jpg|350]]

$$\frac{V_{out}}{V_{in}} = \frac{\omega_T}{2\omega_0}\frac{R_1}{R_S} = \frac{R_1}{2L_1\omega_0} \tag{5.97,5.98}$$

**注意**：$M_2$ 源极看到的阻抗 $R_X$ 在输出谐振频率处陡升 → $C_{GD1}$ 经受显著 Miller 倍增（(5.99)(5.100)）。$M_2$ 噪声在 $\omega \gtrsim (2r_{O1}C_X)^{-1}$ 时开始显现（同 CG cascode）。

**含负载电阻 $R_1$ 的 NF**（例 5.15，忽略 $M_2$）：

$$\mathrm{NF} = 1 + g_m R_S \gamma\left(\frac{\omega_0}{\omega_T}\right)^2 + \frac{4R_S}{R_1}\left(\frac{\omega_0}{\omega_T}\right)^2 \tag{5.101}$$

**设计流程**：已知 $\omega_0$、$L_1$、$C_{pad}$、$L_G$（后三者可迭代），由两式求解：

$$\frac{1}{(L_G+L_1)(C_{GS1}+C_{pad})} = \omega_0^2, \qquad \left(\frac{C_{GS1}}{C_{GS1}+C_{pad}}\right)^2 L_1\omega_T = R_S \tag{5.102,5.103}$$

由 (5.102) 得 $C_{GS1}$，由 (5.103) 得 $\omega_T$ 与 $g_m(=\omega_T C_{GS1})$，再回 $g_m$-$f_T$ 曲线（Fig. 5.25）选管子。$f_T$ 过高 → 加电容；$C_{pad}$ 过大 → 增大 $L_1$。cascode 管宽度 = 输入管，版图共享漏/源区（Fig. 5.27）。

**偏置**（Fig. 5.38）：$R_B$、$C_B$ 隔离信号路径与偏置噪声。例 5.16：$R_B$ 与信号路径并联，须远大于其并联等效 $R_P \approx Q^2 R_S$（$Q=3$ 时 $R_P\approx 450\Omega$）——$R_B = 10R_S$ 已相当；**长电阻更好**（分布电容虽大，但漏点更高阻抗），或用小 MOS 作电阻。

![[RazaviRF-图5.38.jpg|380]]

### CG 与 CS 的取舍

| | CG | 电感退化 CS |
|---|-----|------------|
| 输入匹配 | 精确、相对**不依赖封装寄生** | 需 $L_G$、受 $C_{pad}$ 影响 |
| NF | ~4 dB（$\gamma$ 项不可消） | 更低（1.5–2 dB，$(\omega_0/\omega_T)^2$ 抑制） |
| 负载电阻 $R_1$ 噪声 | $4R_S/R_1 = 4/增益$（增益 10 时 0.4，显著） | $(4R_S/R_1)(\omega_0/\omega_T)^2$（$\omega_0\ll f_T$ 时可忽略） |
| 带宽 | **宽带**（例 5.17：$L_2=R_1^2C_2$ 时 $\mathrm{Im}\{Z_{in}\}=0$ 与频率无关） | 窄带（$\mathrm{Im}\{Z_{in}\}\propto \Delta\omega$） |

![[RazaviRF-图5.40.jpg|400]]

**选择准则**：NF 要求 ~4 dB 用 CG；更低用 CS。例 5.18（5.5 GHz、65 nm）实测 CS 比 CG **增益更高、NF 更低、带宽更窄**。

## 共栅 LNA 的变体

(5.57) 表明：若 CLM 可忽略（老工艺），CG 的 NF 与输入匹配**被 $g_m R_S = 1$ 锁死**。本节两种变体给设计增加一个自由度以解耦二者。

### 反馈 CG LNA

**电压-电压反馈**（Fig. 5.43）：增益 $\alpha$ 的模块检测输出电压、从输入减去其一部分（$M_1$ 作减法器，因 $I_{D1} \propto V_F - V_{in}$）。环路传输 $g_m Z_L \cdot \alpha$。谐振处输入阻抗：

![[RazaviRF-图5.43.jpg|350]]

$$Z_{in} = \frac{1}{g_m} + \alpha R_1 \tag{5.114}$$

输入电阻可远高于 $1/g_m$。**噪声系数**（输入匹配时）：

$$\mathrm{NF} = 1 + \frac{\gamma}{g_m R_S} + \frac{R_S}{R_1}\left(1 + \frac{1}{g_m R_S}\right)^2 \tag{5.119}$$

与简单 CG 的 (5.57) 形式相同，但 **$g_m R_S$ 不再须等于 1**——提高 $g_m$ 即可降 NF。$g_m R_S = 4$、$\gamma = 1$ 时前两项给出 **0.97 dB**。

**例 5.19（选 $\alpha$）**：先按 NF 与增益需求定 $g_m R_S$ 与 $A_v = R_1/(2R_S)$，再由匹配条件 $g_m R_S - 1 = \alpha g_m R_1$ 解：

$$\alpha = \frac{g_m R_S - 1}{2 g_m R_S A_v} \tag{5.120}$$

$g_m R_S = 4$、$A_v = 6$ → $R_1 = 600\Omega$、$\alpha = 1/16$。

### 前馈 CG LNA（gm-boosting）

**前馈**（Fig. 5.45）：把输入放大 $-A$ 加到 $M_1$ 栅极。输入变化 $\Delta V$ 使 $V_{GS}$ 变 $-(1+A)\Delta V$、漏电流变 $-(1+A)g_m \Delta V$——**跨导被"boost" $(1+A)$ 倍**：

![[RazaviRF-图5.45.jpg|380]]

$$R_{in} = [g_m(1+A)]^{-1}, \qquad \text{增益 } (1+A)g_m R_1 \text{（谐振）}$$

**噪声系数**（输入匹配）：

$$\mathrm{NF} = 1 + \frac{\gamma}{1+A} + \frac{4R_S}{R_1} \tag{5.123}$$

提高 $A$ 可降 NF，约束是 $g_m(1+A) = R_S^{-1}$。

**A 自身的噪声**（问题 5.17）：增益级 A 的输入参考噪声 $\overline{V_{nA}^2}$ 以 $A^2/(1+A)^2$（≈1）折合到输入：

$$\mathrm{NF} = 1 + \frac{\gamma}{1+A} + \frac{4R_S}{R_1} + \frac{A^2}{(1+A)^2}\frac{\overline{V_{nA}^2}}{4kTR_S} \tag{5.124}$$

**A 的噪声几乎不衰减**，故用有源电路实现 A 很困难。

**变压器前馈**（Fig. 5.46）：片上变压器提供电压增益 $kn$（$n = \sqrt{L_2/L_1}$ 匝比、$k$ 耦合系数），方向选负号。但片上变压器即使堆叠螺旋也**难超过 ~3**，且初次级损耗贡献噪声。

![[RazaviRF-图5.46.jpg|350]]

## 噪声消除 LNA

前面所有 NF 推导都有三项：$R_S$ 自身的 1、输入管的贡献、负载电阻的贡献。**噪声消除 LNA 旨在消掉第二项**。

**原理**：找到两个节点，使**信号反极性**而**输入管噪声同极性**。把两节点电压适当缩放相加 → 信号相加、噪声相消（Fig. 5.47）。

![[RazaviRF-图5.47.jpg|380]]

**阻性反馈 CS 是理想候选**（Fig. 5.48）：$M_1$ 噪声电流流过 $R_F$ 和 $R_S$，在栅极（X）与漏极（Y）产生**同极性**电压；信号则反相。把 $V_X$ 放大 $-A_1$ 加到 $V_Y$，即可消除 $M_1$ 噪声。两节点噪声电压比 $1 + R_F/R_S$，故取

![[RazaviRF-图5.48.jpg|400]]

$$A_1 = 1 + \frac{R_F}{R_S}$$

**增益**（输入匹配时）：信号经历两路增益相加

$$\frac{V_{out}}{V_X} = 1 - \frac{R_F}{R_S} - \left(1+\frac{R_F}{R_S}\right) = -\frac{2R_F}{R_S} \tag{5.125,5.126}$$

**噪声系数**（辅助放大器输入参考噪声 $\overline{V_{nA1}^2}$、高输入阻抗）：

$$\mathrm{NF} = 1 + \frac{R_S}{R_F} + \frac{\overline{V_{nA1}^2}}{4kTR_S}\left(1+\frac{R_S}{R_F}\right)^2 \tag{5.128}$$

最大化 $R_F$、最小化 $\overline{V_{nA1}^2}$ 可降 NF。$R_S/R_F$ 是增益倒数 $\ll 1$，第三项 ≈ $\overline{V_{nA1}^2}/(4kTR_S)$——**辅助放大器噪声被直接折合到输入，必须远小于 $R_S$ 噪声**（新的瓶颈）。

**输入电容影响**：$M_1$ 与辅助放大器的输入电容 $C_{in}$ 恶化 $S_{11}$ 与噪声消除，高频须加串联/并联电感。频率相关 NF：

$$\mathrm{NF}(f) = \mathrm{NF}(0) + [\mathrm{NF}(0) - 1 + \gamma]\left(\frac{f}{f_0}\right)^2, \qquad f_0 = \frac{1}{\pi R_S C_{in}} \tag{5.129}$$

**实现**（Fig. 5.49）：$M_2$+$M_3$ 作 CS 放大器（增益 $g_{m2}/(g_{m3}+g_{mb3})$）兼求和电路，$M_3$ 作源随器检测 $M_1$ 漏极信号与噪声。

![[RazaviRF-图5.49.jpg|380]]

**例 5.20（CG/CS 噪声消除 + 单端转差分）**：$M_1$ 噪声经源随路径到 X、经共源路径到 Y，两节点反极性；信号经共栅路径在 X/Y 同极性。噪声消除条件：

![[RazaviRF-图5.50.jpg|350]]

$$R_1 = g_{m2}R_2 R_S \tag{5.131}$$

噪声系数（$M_1$ 噪声已消）：

$$\mathrm{NF} = 1 + \frac{R_S}{R_1} + \gamma\frac{R_2}{R_1} + \frac{R_S R_2}{R_1^2} \tag{5.132,5.133}$$

> **核心优势**：兼具反馈/CG 级的**宽带特性**，又有**更低 NF**。适合跨多个频段或宽频带工作（如 900 MHz–5 GHz）。

## 电抗消除 LNA

一种**天然抵消自身输入电容**的拓扑：利用**负反馈放大器的感性输入阻抗**去抵消 $C_{in}$（Fig. 5.51）。

![[RazaviRF-图5.51a.jpg|330]] ![[RazaviRF-图5.51b.jpg|300]]

**原理**：核心放大器建模为单极点响应 $A_0/(1+s/\omega_0)$，则输入导纳：

$$Y_1(s) = \frac{s + (A_0+1)\omega_0}{R_F(s+\omega_0)} \tag{5.134}$$

实部与虚部：

$$\frac{1}{\mathrm{Re}\{Y_1\}} = \frac{R_F(\omega^2+\omega_0^2)}{(1+A_0)\omega_0^2}, \qquad \mathrm{Im}\{Y_1\} = \frac{-A_0\,\omega\,\omega_0}{R_F(\omega^2+\omega_0^2)} \tag{5.135,5.136}$$

**$\omega \ll \omega_0$ 时**：$1/\mathrm{Re}\{Y_1\} \to R_F/(1+A_0)$ 可设为 $R_S$（匹配）；$\mathrm{Im}\{Y_1\} \approx -A_0\omega/(R_F\omega_0)$——**负值（感性）**，可抵消 $C_{in}\omega$。

> **匹配带宽**：此技术匹配可维持到约 $\omega_0$，要求核心放大器开环带宽覆盖最高工作频率。深亚微米器件的本征速度提供了所需增益与带宽。

**实现**（Fig. 5.52，50 MHz–10 GHz）：三级 CS 提供增益与负反馈，**避免 cascode/源随器以省电压裕度**。$M_1$ 大宽度以满足 50 MHz 处的闪烁噪声要求（$V_{GS}\approx 200\ \mathrm{mV}$）；电流 $I_1$ 从 $R_F$ 抽出、把节点 Y 的静态电压抬高 ~250 mV（$R_F=1\ \mathrm{k}\Omega$ 时 $I_1$ 仅 $200\ \mu\mathrm{A}$，噪声可忽略）。

![[RazaviRF-图5.52.jpg|380]]

**稳定性**：三级增益 → 相位裕度堪忧。四极点（A、B、X、Y 在 10/24.5/22/75 GHz）引入大量相移，但因反馈因子小（$R_S/(R_S+R_F) = 0.048$），相位裕度仍约 $50^\circ$、闭环峰化 1 dB。

**单极点近似的成立**：多极点电路把 B、X、Y 三极点"集总"（时间常数相加）后，单极点模型仍精确预测输入导纳，等效 $\omega_0 = 2\pi\times 9.9\ \mathrm{GHz}$。

**输出**：从节点 X、Y 之间伪差分感知。两节点摆幅略不等、相位差略超 180°，但伪差分感知**同时提升增益与 IP₂**——X 处的二阶失真也出现在 Y，在 $V_Y - V_X$ 中部分抵消。

> **5.3 节全景**：七种拓扑覆盖"宽带（阻性反馈/噪声消除/电抗消除）↔ 窄带低噪（电感退化 CS）↔ 高线性度（CG）"三大阵营。核心主线始终是同一句话——**用有源器件合成 50Ω，避开实体电阻的噪声**。
