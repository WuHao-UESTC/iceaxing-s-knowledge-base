# 5.1 LNA 设计的一般考量

## 5.1.1 噪声系数

LNA 作为接收机第一级有源电路，其噪声系数（noise figure, NF）**直接叠加**到整机噪声系数上。典型 RX 噪声系数 6–8 dB 的分配：

| 模块           | NF 贡献      |
| ------------ | ---------- |
| 天线开关/双工器     | 0.5–1.5 dB |
| LNA          | 2–3 dB     |
| 后续链路（混频器+基带） | 2.5–3.5 dB |

这个分配只是设计起点，实际中各部分可灵活调整。现代 RF 设计中，LNA 很少孤立设计——整个 RF 链路作为整体迭代优化。

**NF = 2 dB 意味着什么？** 考虑图 5.1 的简化模型，LNA 噪声仅用输入参考电压源 $\overline{V_{n,in}^2}$ 表示：

$$\mathrm{NF} = 1 + \frac{\overline{V_{n,in}^2}}{4kTR_S} \tag{5.2}$$

对 $R_S = 50\Omega$，NF = 2 dB → $\sqrt{\overline{V_{n,in}^2}} = 0.696\ \mathrm{nV/\sqrt{Hz}}$。MOSFET 栅参考热噪声 $\overline{V_{n,g}^2} = 4kT\gamma/g_m$，要达到此值需要：

$$g_m = (29\Omega)^{-1} \quad (\gamma = 1)$$

这是极高的跨导——单管难以同时满足功耗和带宽约束，暗示了输入匹配网络和噪声匹配的必要性。

![[Pasted image 20260719233234.png]]

### 输入串联电阻对 NF 的影响（Example 5.1）

200 μm 长、0.5 μm 宽的金属走线，方块电阻 $40\ \mathrm{m\Omega/\square}$ → $R_L = (200/0.5) \times 40\ \mathrm{m\Omega} = 16\Omega$。

$R_L$ 的热噪声直接叠加到 LNA 输入参考噪声上：

$$\mathrm{NF_{tot}} = 1 + \frac{\overline{V_{n,in}^2} + 4kTR_L}{4kTR_S} = \mathrm{NF_{LNA}} + \frac{R_L}{R_S} \tag{5.5}$$

代入 $R_L = 16\Omega$、$R_S = 50\Omega$：NF 从 2 dB (= 1.58) 恶化到 2.79 dB。

**关键洞察**：即使很小的走线电阻或栅电阻（十几欧姆量级）也会明显抬高 LNA 的噪声系数。版图中输入走线需宽金属、多指栅以降低 $R_G$。

![[Pasted image 20260719233307.png]]

### 噪声对拓扑选择的限制

极低的 NF 要求意味着 **只有一个晶体管**（通常是输入器件）可以主导 NF。这直接排除了：
- 源极跟随器 / 射极跟随器（多器件贡献噪声，且无增益压制后级噪声）
- 复杂的有源反馈输入级

→ 这一约束将 LNA 拓扑收敛到 CS 级、CG 级及其衍生结构（5.2–5.4 节）。

→ MOS 噪声基础参见 [[C7放大器噪声#7.2 噪声类型]]（热噪声 $\overline{I_n^2}=4kT\gamma g_m$）和 [[C7放大器噪声#7.4.1 共源级]]（CS 级输入参考噪声推导）。

## 5.1.2 增益

LNA 增益必须足够大以**压制后级噪声**——尤其是下变频混频器。但增益选择在噪声和线性度之间形成折中：增益越高，后级非线性越被放大。

现代 RF 设计中，LNA 直接驱动混频器，两者之间不做阻抗匹配。因此链路计算用**电压增益**而非功率增益，更简单也更有物理意义。

### 增益的不对称保护效应

LNA 的增益对后级噪声和线性度的"保护"程度不同：

![[Pasted image 20260719233346.png]]

考虑 LNA + 混频器级联（假设混频器电压增益 = 1）：

**噪声链**：总输出噪声 = $A_{v1}^2(\overline{V_{n,LNA}^2} + 4kTR_S) + \overline{V_{n,mix}^2}$

$$\mathrm{NF_{tot}} = \mathrm{NF_{LNA}} + \frac{\overline{V_{n,mix}^2}}{A_{v1}^2} \cdot \frac{1}{4kTR_S} \tag{5.8}$$

混频器噪声被 $A_{v1}$（信号源到 LNA 输出的电压增益）的平方除。

**线性度链**：由 Friis 级联 IP3 公式，

$$\frac{1}{\mathrm{IP}_{3,\mathrm{tot}}^2} = \frac{1}{\mathrm{IP}_{3,\mathrm{LNA}}^2} + \frac{\alpha_1^2}{\mathrm{IP}_{3,\mathrm{mixer}}^2} \tag{5.9}$$

混频器 IP3 被 $\alpha_1$（LNA 输入到输出的电压增益）除。若输入匹配 $R_{in} = R_S$，则 $\alpha_1 = 2A_{v1}$。

**核心矛盾**：

|            | NF 计算           | IP3 计算                   |
| ---------- | --------------- | ------------------------ |
| 混频器贡献被除的增益 | $A_{v1}$（较低）    | $\alpha_1 = 2A_{v1}$（较高） |
| 效果         | 增益不够大 → 混频器噪声凸显 | 增益太大 → 混频器非线性凸显          |
|            |                 |                          |

两者**都对设计者不利**：希望增益大以压制后级噪声，但增益大又放大后级非线性。这决定了链路预算必须在 NF 和线性度之间迭代折中——无法通过单一增益值同时最优。

→ 差分对和 CS 级增益公式：[[C3.单级放大器#3.2 放大器的基本考量]]

## 5.1.3 输入回波损耗

LNA 的输入阻抗选择暴露了 RF 设计的一个根本张力——三种互相冲突的需求：

1. **电压放大器视角**：$Z_{in} \to \infty$（理想电压放大器输入阻抗无穷大）
2. **噪声视角**：在天线和 LNA 之间加变换网络以获得最小 NF（噪声匹配）
3. **功率视角**：天线与 LNA 之间共轭匹配（功率匹配）

**最终选择 50Ω 电阻性输入阻抗**，基于三个工程事实：

**(1) 片外带选滤波器**：天线与 LNA 之间的带选滤波器（off-chip）按标准 50Ω 终端设计和表征。若滤波器看到的负载（即 LNA 输入阻抗）显著偏离 $50\Omega$，其通带和阻带特性将出现损耗和纹波。

**(2) 天线本身**：天线按特定实负载阻抗设计。若负载偏离实数值或含虚部，天线将产生未表征的损耗。天线/LNA 协同设计可通过非共轭匹配改善性能，但若天线与发射机共享（FDD 系统），其阻抗必须含可忽略的虚部以有效辐射 PA 信号。

**(3) PCB 走线传输**：天线信号需在 PCB 上传输可观距离才到达接收机。RX 输入端匹配不良 → 显著反射 → 未表征的损耗 + 可能的电压衰减。

**其他片内接口不匹配**：LNA → 混频器、LO → 混频器之间没有上述约束，因此设计为最大化电压摆幅而非功率传输。

### 回波损耗的定义

输入回波损耗（input return loss）定义为反射功率与入射功率之比：

$$\Gamma = \left| \frac{Z_{in} - R_S}{Z_{in} + R_S} \right|^2 \tag{5.10}$$

- $\Gamma = -10\ \mathrm{dB}$：反射 1/10 功率 → 通常可接受
- 实际设计中目标约 $-15\ \mathrm{dB}$，为封装寄生等留裕量

![[Pasted image 20260719234017.png|700]]

在 $Z_{in}$ 复平面上，恒定 $\Gamma$ 轮廓为圆族。例如 $S_{11} = -10\ \mathrm{dB}$ 对应 $\mathrm{Re}\{Z_{in}\} = 61\Omega$、$\mathrm{Im}\{Z_{in}\} = 35.2\Omega$（取特定相位时）。

## 5.1.4 稳定性

LNA 必须面对接收机中最不可控的端口条件——它与"外部世界"接口。天线阻抗随使用环境变化（如手握住手机天线），因此 LNA 必须在**所有源阻抗**和**所有频率**下保持稳定。

即使振荡频率不在工作频带内，一旦起振，LNA 变为强非线性，增益严重压缩——带内性能随之崩塌。

### Stern 稳定性因子

经典稳定性判据使用 Stern 稳定因子：

$$K = \frac{1 + |\Delta|^2 - |S_{11}|^2 - |S_{22}|^2}{2|S_{21}||S_{12}|}, \quad \Delta = S_{11}S_{22} - S_{12}S_{21} \tag{5.11}$$

$K > 1$ 且 $\Delta < 1$ → **无条件稳定**（任何源/负载阻抗组合均不起振）。

**现代 RF 的修正视角**：LNA 负载（片上混频器输入阻抗）相对可控，LNA 输出也不做匹配 → $S_{22}$ 意义有限。$K > 1$ 对片上 LNA 偏悲观。

### Cascode 的自然稳定性（Example 5.2）

Cascode 结构 $S_{12} \approx 0$（高反向隔离度），$S_{22} \approx 1$（高输出阻抗）。代入式 (5.12–5.14)，稳定条件简化为：

$$|S_{21}| < \frac{1 - |S_{22}|^2}{2|S_{12}|}, \quad S_{11} < 1$$

后者仅要求输入电阻为正。

**核心设计推论**：最大化反向隔离度（通过 Cascode）→ **天然稳定** → 其余性能参数（噪声、增益、匹配）可自由优化，无需顾虑稳定性。此外，高反向隔离也压制了 LO 泄漏到 LNA 输入的路径。

### 寄生引起的失稳

LNA 的失稳常来自**封装和版图寄生**：
- 接地 / 电源键合线电感（bondwire inductance）→ 输出到输入的反馈路径
- 共栅管栅极大串联电感 → 显著反馈 → 可能在某频率起振

需要在版图、布局和封装建模中加以防范。

→ 稳定性与反馈的深层联系：[[Razavi-模拟CMOS集成电路设计/稳定性与频率补偿#10.1 稳定性的一般考量|Barkhausen 准则]]

## 5.1.5 线性度

在大多数应用中，LNA **不**限制接收机线性度。接收链路增益逐级累积，后级基带放大器/滤波器通常决定整体 $\mathrm{IP}_3$ 或 $P_{1dB}$。因此 LNA 的线性度在设计优化中一般不作为首要约束。

### 例外：全双工系统（FDD）

在收发同时工作的全双工系统（如 CDMA IS-95/WCDMA）中，强发射信号泄漏到接收路径，LNA 线性度成为关键瓶颈。

![[Pasted image 20260719234233.png]]

双工器（duplexer）为三端口网络：
- $S_{31}$（RX 路径损耗）/ $S_{21}$（TX 路径损耗）：约 1–2 dB
- $S_{32}$（TX → RX 泄漏）：约 **−50 dB** 隔离度

**数值量级**：PA 平均输出 +30 dBm (1 W) → 双工器 50 dB 隔离 → LNA 处 TX 泄漏 **−20 dBm**。TX 信号包络可变，峰值高约 2 dB。因此接收机必须在 **−18 dBm** 输入下不压缩 → $P_{1dB} \approx -15\ \mathrm{dBm}$（留裕量）。

**为何困难**：LNA 增益 15–20 dB → −15 dBm 输入 × 增益 = **0 至 +5 dBm** 输出（$632\text{–}1124\ \mathrm{mV_{pp}}$）。此电压摆幅已经可能使 LNA 自身输出端压缩。混频器 $P_{1dB}$ 也必须达 0 至 +5 dBm（对应 $\mathrm{IP}_3 \approx +10\text{–}+15\ \mathrm{dBm}$），混频器设计也变得极具挑战。

部分 CDMA 接收机在 LNA 和混频器之间插入**片外滤波器**以滤除 TX 泄漏，缓解线性度压力。

### 宽带接收机的线性度需求

超宽带（UWB）、软件定义无线电、认知无线电等宽带接收机可能同时感测大量强干扰信号，LNA 线性度同样关键——但这与窄带 FDD 的 TX 泄漏问题物理机制不同（多个带外干扰 vs 单个带内强泄漏）。

## 5.1.6 带宽

LNA 必须在目标频段内提供**平坦增益**，通常要求增益变化 < 1 dB。因此 −3 dB 带宽须远大于实际工作频段，使带边滚降 < 1 dB。

### 分数带宽

分数带宽（fractional bandwidth）衡量实现所需带宽的难度：

$$\text{Fractional BW} = \frac{\text{3-dB 带宽}}{\text{中心频率}}$$

- 802.11g LNA：80 MHz / 2.44 GHz ≈ **0.033**（窄带，易实现）
- 802.11a LNA：1 GHz / 5.5 GHz ≈ **0.18**（中等难度）

### LC 谐振负载的带宽约束（Example 5.3）

802.11a LNA 需要 5–6 GHz 响应。若负载为二阶 LC 谐振腔（LC tank）：

$$\frac{\Delta\omega}{\omega_0} = \frac{1}{Q}$$

![[Pasted image 20260726054832.png]]

所需分数带宽 = 1 GHz / 5.5 GHz ≈ 0.182 → 要求 $Q < 5.5$。这约束了电感和电容的寄生电阻，也直接关联到谐振负载能提供的增益（$|Z_{load}| \approx R_P = Q\omega_0 L$）。

### 频带切换（Band Switching）

当分数带宽较大时，单谐振腔的 Q 难以兼顾增益和带宽。解决方式：**开关电容切换谐振频率**

![[Pasted image 20260726054859.png]]

$C_2$ 通过开关接入谐振腔 → 中心频率从 $\omega_1 = 1/\sqrt{L_1 C_1}$ 跳至 $\omega_2 = 1/\sqrt{L_1(C_1 + C_2)}$。每个子频带的分数带宽较小 → 可用较高 Q 的谐振腔获得更高增益。

→ 频带切换的详细实现见 5.5 节（Gain Switching and Band Switching）

→ LC 谐振腔作为放大器负载：[[C9.运算放大器#9.2.1 基本拓扑|CS 级增益 ≈ $g_m R_P$]]

→ 变容管 Q 约束：[[Razavi-RF Microelectronics/Passive Devices|片上无源器件]]

## 5.1.7 功耗

LNA 在噪声、线性度和功耗之间存在直接折中。但在大多数接收机设计中，LNA 功耗仅占整机功耗的一小部分。

换言之：**噪声系数远比功耗关键**。这与基带电路（功耗和线性度主导）形成鲜明对比，反映了 RF 前端的根本优先级——NF 每恶化 1 dB 直接叠加到整机，而后级电路的能耗优化空间更大。

但这种"NF 优先"并非绝对：电池供电设备中每 mW 都需合理分配。设计实践中，通常先以噪声和增益为目标确定偏置电流和器件尺寸 → 检查功耗是否在预算内 → 若超标则迭代降低 $g_m$（接受 NF 略微恶化）。

### 5.1 节总结：LNA 设计的七维约束

| 参数   | 典型要求                                    | 核心折中             |
| ---- | --------------------------------------- | ---------------- |
| 噪声系数 | 2–3 dB                                  | 功耗↑ → NF↓（但边际递减） |
| 增益   | 15–20 dB                                | 增益↑ → NF↓ 但线性度↓  |
| 输入匹配 | $S_{11}<-10\ \mathrm{dB}$               | 功率匹配 vs 噪声匹配     |
| 稳定性  | 无条件稳定（$K>1$）                            | Cascode → 天然稳定   |
| 线性度  | FDD 时 $P_{1dB}\approx-15\ \mathrm{dBm}$ | 增益↓ → IP3↑ 但 NF↑ |
| 带宽   | < 1 dB 带内波动                             | BW↑ → Q↓ → 增益↓   |
| 功耗   | 受 NF 约束远大于功耗约束                          | —                |

这七个参数构成 LNA 设计的**约束空间**，5.2–5.4 节的拓扑选择将展示如何在这个空间中寻找可行解。

# 5.2 输入匹配问题

LNA 必须提供 50Ω 输入电阻和可忽略的输入电抗，这一要求直接约束了拓扑选择——不能先设计噪声和增益再"补"匹配。

## 5.2.1 CS 级的输入导纳

以图 5.8 的基本 CS 级为起点，$C_F$ 为栅漏交叠电容（gate-drain overlap capacitance）。

![[Pasted image 20260726055126.png]]

**频率极限行为**：
- **极低频**：$R_D \ll |Z_{C_F}|, |Z_{C_L}|$，输入近似为 $(C_{GS} + C_F)s$ —— 纯容性
- **极高频**：$C_F$ 短路栅漏 → $Z_{in} \approx R_D \parallel (1/g_m)$ —— 电阻性（但数值很大）

完整的输入导纳实部和虚部为：

$$\mathrm{Re}\{Y_{in}\} = R_D C_F \omega^2 \frac{C_F + g_m R_D (C_L + C_F)}{R_D^2 (C_L + C_F)^2 \omega^2 + 1} \tag{5.15}$$

$$\mathrm{Im}\{Y_{in}\} = C_F \omega \frac{R_D^2 C_L (C_L + C_F) \omega^2 + 1 + g_m R_D}{R_D^2 (C_L + C_F)^2 \omega^2 + 1} \tag{5.16}$$

**数值量感**：$C_F = 10\ \mathrm{fF}$、$C_L = 30\ \mathrm{fF}$、$g_m R_D = 4$、$R_D = 100\Omega$ → 5 GHz 时 $\mathrm{Re}\{Y_{in}\} = (7.8\ \mathrm{k\Omega})^{-1}$，远离 $(50\Omega)^{-1}$。

**物理原因**：$C_F$（仅 10 fF）在此频率提供的反馈量太少，不足以在输入端产生显著的实部。$C_F$ 是寄生量级的小电容——不能也不应指望它完成 50Ω 匹配。

### Example 5.4：为何算 $Y_{in}$ 而非 $Z_{in}$？

选择 $Y_{in}$ 或 $Z_{in}$ 在一定程度上是随意的。但在某些电路中 $Y_{in}$ 更简洁。此外：
- 若用**并联电感**抵消输入电容 → $\mathrm{Im}\{Y_{in}\}$ 更相关
- 若用**串联电感**抵消输入电抗 → $\mathrm{Im}\{Z_{in}\}$ 更相关

这预示了 5.3 节的电感退化/谐振匹配技术。

## 5.2.2 电阻终端匹配

既然 $C_F$ 无法提供足够的输入实部，最直接的想法是**并联电阻** $R_P$ 到输入端。

![[Pasted image 20260726055553.png]]

设计三步走：(1) $M_1$ 和 $R_D$ 提供所需的 NF 和增益；(2) $R_P$ 并联在输入端使 $\mathrm{Re}\{Z_{in}\} = 50\Omega$；(3) 在 $R_S$ 和输入端之间插入电感抵消 $\mathrm{Im}\{Z_{in}\}$。

### NF 的定量分析

忽略沟道长度调制，总输出噪声为：

$$\overline{V_{n,out}^2} = 4kT(R_S \parallel R_P)(g_m R_D)^2 + 4kT\gamma g_m R_D^2 + 4kTR_D \tag{5.17}$$

三项依次为：$R_S \parallel R_P$ 热噪声、$M_1$ 沟道热噪声、$R_D$ 热噪声。

电压增益 $A_v = -[R_P/(R_P + R_S)]g_m R_D$（因为 $R_P$ 和 $R_S$ 分压衰减输入信号），代入 NF 定义得：

$$\mathrm{NF} = 1 + \frac{R_S}{R_P} + \frac{\gamma R_S}{g_m(R_S \parallel R_P)^2} + \frac{R_S}{g_m^2(R_S \parallel R_P)^2 R_D} \tag{5.18}$$

**数值量感**：$R_P \approx R_S$ 时，NF 已超过 3 dB —— 且可能远不止 3 dB（后两项进一步恶化）。

### 物理直觉

$R_P$ 在提供 50Ω 实部的同时，贡献了等量的热噪声 $4kTR_P$。这是**物理必然**：任何实体电阻的可用噪声功率恒为 $kT$。$R_P$ 的噪声在输入端与信号直接叠加 → 无法被增益"压制"（两者同时被衰减 $R_P/(R_P+R_S)$）。

### 核心洞察

**LNA 必须提供 50Ω 的输入电阻，但不得带有实体 50Ω 电阻的热噪声。** 这只有通过有源器件实现——利用晶体管的跨导在输入端"合成"电阻，而非放置实体电阻。这是 5.3 节所有 LNA 拓扑的出发点。

→ 无源电阻的噪声基底 $kTR$ 参见 [[C7放大器噪声#7.2 噪声类型|Ch7: 电阻热噪声]]

→ Friis 公式视角：电阻终端可视为一级 $R_P$ + LNA → 后级 NF 被前级衰减恶化

## 5.2.3 匹配网络变换——热力学下限

或许可以用无损匹配网络将一个大电阻 $R_P \gg R_S$ **变换**到 $50\Omega$？大 $R_P$ 的热噪声电流更小，也许能突破 3 dB？

![[Pasted image 20260726095031.png]]

### 论证（Example 5.5）

**第一步：增益**。无损网络 $H(s)$ 使 $Z_{in} = R_S$。无损意味着输入功率全部传到 $R_P$：

$$\frac{V_{in,rms}^2}{4R_S} = \frac{V_{out,rms}^2}{R_P} \quad \Rightarrow \quad |A_v|^2 = \frac{R_P}{4R_S} \tag{5.20}$$

$R_P$ 越大，从 $V_{in}$ 到 $V_{out}$ 的电压增益越高——这正是变换的意图。

**第二步：$R_S$ 的噪声贡献**。$R_S$ 的热噪声 $4kTR_S$ 经式 (5.20) 的增益传到输出：

$$\overline{V_{n,out}^2}|_{RS} = 4kTR_S \cdot \frac{R_P}{4R_S} = kTR_P \tag{5.22}$$

**第三步：$R_P$ 的噪声贡献**。这里用热力学第二定律——若 $R_S$ 和 $R_P$ 处于热平衡，$R_P$ 传到 $R_S$ 的噪声功率必须等于 $R_S$ 传到 $R_P$ 的功率（否则一个升温另一个降温，违反热力学）。互易无源网络在 $R_S$ 端口看到的输出阻抗也是 $R_S$，其可用噪声功率恒为 $kT$。

由此推出 $R_{out} = R_P$（当 $R_{in} = R_S$ 时——阻抗变换的对称性），且：

$$\overline{V_{n,out}^2}|_{RP} = kTR_P \tag{5.25}$$

**第四步：总 NF**。总输出噪声 = $kTR_P + kTR_P = 2kTR_P$：

$$\mathrm{NF} = \frac{2kTR_P}{|A_v|^2 \cdot 4kTR_S} = \frac{2kTR_P}{(R_P/4R_S) \cdot 4kTR_S} = 2 \ (\text{= 3 dB}) \tag{5.26}$$

### 物理含义

**无论 $R_P$ 多大，无论匹配网络多复杂——只要输入端实体电阻参与了匹配，NF 下限就是 3 dB。** 这是热力学约束，不是设计技巧问题。

$R_P$ 增大 → 增益同比例增大（式 5.20），但 $R_P$ 的热噪声功率恰好也同比例增大（$kTR_P$）。分子分母同步缩放 → NF = 2 是恒定的。

**"学生试图挑战物理学定律"**——Razavi 以此强调：这是不可逾越的物理极限，不是电路设计花巧能绕开的。

### 5.2 节总结

| 方案             | 输入实部来源    | NF 下限          | 结论                                        |
| -------------- | --------- | -------------- | ----------------------------------------- |
| CS 级 $C_F$ 反馈  | 寄生电容反馈    | —              | 反馈太弱，$\mathrm{Re}\{Z_{in}\} \gg 50\Omega$ |
| 并联 $R_P$ 终端    | 实体电阻      | > 3 dB         | 电阻噪声直接叠加信号                                |
| $R_P$ + 无损变换网络 | 实体电阻（变换后） | **= 3 dB（精确）** | 热力学约束，不可逾越                                |

**唯一出路**：用有源器件（晶体管）在输入端合成 50Ω 电阻，其噪声不服从 $4kTR$ 的实体电阻热噪声规律。这就是 5.3 节所有 LNA 拓扑的物理基础。

→ 有源阻抗合成的三种途径：CS 电感退化（5.3.1–5.3.3）、CG 级（5.3.4–5.3.6）、阻性反馈（5.3.2）

→ 噪声基底与热力学：[[C2.Basic Concept#噪声|Ch2: 可用噪声功率 $kT$]]

## 5.3.1 电感负载的 CS 级

### 电阻负载 CS 的局限
![[Pasted image 20260727091328.png|315]]
回顾图 5.8 的电阻负载 CS 级：不仅无法提供输入匹配（5.2.1 节），而且增益和电源电压之间存在根本折中：

$$|A_v| = g_m R_D = \frac{2I_D}{V_{GS}-V_{TH}} \cdot \frac{V_{RD}}{I_D} = \frac{2V_{RD}}{V_{GS}-V_{TH}} \tag{5.29}$$

$V_{RD}$（$R_D$ 上的 DC 压降）受 $V_{DD}$ 约束。低电压工艺中 $V_{DD}$ 持续缩小 → $V_{RD}$ 减小 → 增益下降。沟道长度调制使增益更低。

此外，输出节点时间常数 $R_D C_L$ 限制高频工作。

### 电感负载的优势

![[Pasted image 20260727091358.png|187]]

替换 $R_D$ 为电感 $L_1$：
- **DC 压降极小**（理想电感 DC 压降为零）→ 适合低 $V_{DD}$ 工艺
- **$L_1$ 与输出节点总电容谐振** → 谐振频率处阻抗为 $R_P$（电感等效并联电阻），远高于同等 DC 压降的电阻 → 更高工作频率

### $C_F$ 反馈实现输入匹配的尝试

![[Pasted image 20260727091448.png|700]]

忽略 $C_{GS}$，用电感串联损耗电阻 $R_S$ 建模（$R_S$ 随频率变化远小于等效并联电阻），推导 $Z_{in}$：

谐振腔阻抗 $Z_T = \frac{L_1 s + R_S}{L_1 C_1 s^2 + R_S C_1 s + 1}$，流过谐振腔的电流 = $I_X - g_m V_X$。

$$Z_{in}(s) = \frac{L_1(C_1+C_F)s^2 + R_S(C_1+C_F)s + 1}{[L_1 C_1 s^2 + (R_S C_1 + g_m L_1)s + 1 + g_m R_S] C_F s} \tag{5.32}$$

其实部（5.34–5.35）在特定频率下可以调到 $50\Omega$——通过合理选择 $L_1$、$g_m$、$C_1$ 等参数。

### 稳定性隐患

然而 $C_F$ 反馈在**其他频率**会产生**负输入电阻**。$\mathrm{Re}\{Z_{in}\}$ 在以下频率过零变号：

$$\omega_1^2 = \frac{R_S C_1 + g_m L_1 - (1+g_m R_S)R_S(C_1+C_F)}{g_m L_1^2(C_1+C_F)} \tag{5.36}$$

**数值例**：$C_F=10\ \mathrm{fF}$、$C_1=30\ \mathrm{fF}$、$g_m=(20\Omega)^{-1}$、$L_1=5\ \mathrm{nH}$、$R_S=20\Omega$ → $g_m L_1$ 主导分子 → $\omega_1 \approx 2\pi \times (11.3\ \mathrm{GHz})$。

在此频率以上，$\mathrm{Re}\{Z_{in}\} < 0$ —— 潜在的振荡条件。

### 中和（Neutralization）——不实用的补救

![[Pasted image 20260727091516.png|354]]

$L_F$ 与 $C_F$ 并联谐振可在一定频段内"消除" $C_F$ 的反馈效应。但 $C_F$ 本身很小（~10 fF）→ $L_F$ 必须很大 → 引入显著的输入/输出寄生电容 → 性能退化。现代 RF 设计中**很少使用**。

### 评价

电感负载 CS 级解决了增益-摆幅折中和频率限制，但输入匹配仍依赖 $C_F$ 反馈 → 稳定性不可靠。这为 5.3.2–5.3.4 的更优拓扑提供了动机。

## 5.3.2 阻性反馈的 CS 级

若工作频率远低于晶体管 $f_T$（约低一个数量级），可采用图 5.13(a) 的阻性反馈 CS 级。$M_2$ 为电流源，$R_F$ 检测输出电压并反馈电流到输入端。

![[Pasted image 20260727091543.png]]

### 输入匹配

忽略沟道长度调制：$R_F$ 与理想电流源串联 → $M_1$ 呈现二极管接法 → 

$$R_{in} = \frac{1}{g_{m1}} \tag{5.37}$$

→ 输入匹配条件：$g_{m1} = 1/R_S \ (= (50\Omega)^{-1})$。这是精确的匹配条件——直接由跨导决定。

### 增益

$M_1$ 的小信号漏电流 $g_{m1}V_X$ 全部流经 $R_F$，产生压降 $g_{m1}V_X R_F$：

$$\frac{V_{out}}{V_X} = 1 - g_{m1}R_F = 1 - \frac{R_F}{R_S} \tag{5.41}$$

考虑输入匹配时的 1/2 分压：

$$A_v = \frac{1}{2}\left(1 - \frac{R_F}{R_S}\right) \approx -\frac{R_F}{R_S} \quad (R_F \gg R_S) \tag{5.43}$$

**关键优势**：$R_F$ 不承载偏置电流 → 增益与 $V_{DD}$ 之间**不存在**电阻负载 CS 级的直接折中。

### 噪声系数

![[Pasted image 20260727091625.png]]

**$R_F$ 噪声**：直接全部出现在输出 → $\overline{V_{n,out}^2}|_{RF} = 4kTR_F$（与 $R_F$ 两端看到的阻抗无关，增益为 1）。

**$M_1$ 和 $M_2$ 的沟道噪声**：电流流入输出电阻 $R_{out} = \frac{1}{2}(R_F + R_S)$：

$$\overline{V_{n,out}^2}|_{M1,M2} = 4kT\gamma(g_{m1}+g_{m2})\frac{(R_F+R_S)^2}{4} \tag{5.47}$$

经化简（$R_F \gg R_S$）：

$$\mathrm{NF} \approx 1 + \frac{4R_S}{R_F} + \gamma + \gamma g_{m2} R_S \tag{5.50}$$

**数值量感**：即使 $4R_S/R_F$ 和 $\gamma g_{m2} R_S$ 均远小于 1，$\gamma \approx 1$ 项也使 NF 超过 3 dB（= 2，即 3 dB 精确下限）。

### 第四项的物理含义（Example 5.6）

$$g_{m2}R_S = \frac{g_{m2}}{g_{m1}} = \frac{(V_{GS}-V_{TH})_1}{|V_{GS}-V_{TH}|_2} \tag{5.51}$$

要使 $\gamma g_{m2}R_S$ 可忽略，需 $M_2$ 过驱动电压 **远大于** $M_1$ 过驱动 → 即 $M_2$ 的 W/L 远小于 $M_1$。但 $|V_{DS2}| = V_{DD} - V_{GS1}$，低 $V_{DD}$ 下难以同时满足电流源所需电压裕度和高过驱动 → **低电压工艺中不易实现**。

### 有源负载改进版（Example 5.7）

![[Pasted image 20260807152243.png|281]]

将 $M_2$ 从恒定电流源改为有源负载（源极通过 $C_1$ 交流接地）：$M_1$ 和 $M_2$ 小信号并联 → 等效跨导 $g_{m1} + g_{m2}$。

匹配条件变为 $g_{m1} + g_{m2} = 1/R_S$。两管都参与放大 → 式 (5.50) 中 $\gamma(g_{m1}+g_{m2})R_S = \gamma$，第四项消失：

$$\mathrm{NF} \approx 1 + \frac{4R_S}{R_F} + \gamma \tag{5.52}$$

**代价**：需要 $V_{DD} \geq V_{GS1} + |V_{GS2}| + V_{I1}$（$I_1$ 电流源的电压裕度）。

### 评价

阻性反馈 CS 级提供了简洁的 $g_m$ 匹配方案和可调的增益（$R_F/R_S$），无增益-摆幅折中。但 NF 受 $\gamma \approx 1$ 项限制，下限 ~3 dB。适合对 NF 要求不极端、需宽带匹配的场景。

→ 反馈原理：[[C8.反馈#8.2.1 电压-电压反馈|Ch8: 电压-电压反馈]]

→ 互补 CS 结构也见于偏置：[[C5.电流镜与偏置技术#5.4.1 共源级偏置|Ch5: 互补 CS 自偏置]]

## 5.3.3 共栅级（CG）

CG 级的低输入阻抗（$R_{in} \approx 1/g_m$）天然适合 LNA 的 50Ω 匹配。仅考虑电感负载版本——电阻负载同样受增益-摆幅折中限制。

> 【插入 Razavi RF 图 5.16】(a) 电感负载 CG 级，(b) $M_1$ 噪声的等效。

### 基本性能

忽略沟道长度调制和体效应：

- **输入匹配**：$R_{in} = 1/g_m$ → $g_m = 1/R_S = (50\Omega)^{-1}$（精确条件）
- **增益**（谐振频率处）：$\frac{V_{out}}{V_X} = g_m R_1 = \frac{R_1}{R_S}$，考虑输入匹配 1/2 分压 → $A_v = \frac{R_1}{2R_S}$
- **噪声系数**：

$$\overline{V_{n,out}^2}|_{M1} = \frac{4kT\gamma}{g_m} \left(\frac{R_1}{R_S + 1/g_m}\right)^2 = kT\gamma \frac{R_1^2}{R_S} \tag{5.55–5.56}$$

加上 $R_1$ 的热噪声 $4kTR_1$，除以增益和 $4kTR_S$：

$$\mathrm{NF} = 1 + \gamma + 4\frac{R_S}{R_1} \tag{5.58}$$

**NF ≥ 3 dB**（$\gamma \approx 1$）——这是 $g_m = 1/R_S$ 匹配条件的代价。提高 $g_m$ 可降低 NF（因热噪声 $\propto 1/g_m$），但 $R_{in}$ 同时下降，匹配恶化。

### 偏置元件的噪声选择（Example 5.8）

> 【插入 Razavi RF 图 5.17】(a) 电流源偏置，(b) 电阻偏置。

比较偏置元件（$M_2$ 电流源 vs $R_B$ 电阻）的噪声电流：

$$\overline{I_{n,M2}^2} = 4kT\gamma \frac{2I_D}{V_{GS2}-V_{TH2}}, \quad \overline{I_{n,RB}^2} = 4kT\frac{I_D}{V_{RB}}$$

由于 $V_{GS2}-V_{TH2} \leq V_{RB}$（饱和条件 → $V_{DS2} \geq V_{GS2}-V_{TH2}$），$M_2$ 的噪声约为 $R_B$ 的两倍（$\gamma \approx 1$）。此外 $M_2$ 还在输入节点引入显著电容。

→ **偏置电阻 $R_B$ 优于电流源**，前提是 $R_B \gg R_S$ 以免衰减信号。

### 深亚微米的沟道长度调制效应

> 【插入 Razavi RF 图 5.19】$r_O$ 对 CG 输入阻抗的影响。

$r_O$ 通过正反馈抬高输入阻抗：

$$\frac{V_X}{I_X} = \frac{R_1 + r_O}{1 + g_m r_O} \tag{5.64}$$

若 $g_m r_O \gg 1$，$R_{in} \approx 1/g_m + R_1/(g_m r_O)$。纳米工艺 $g_m r_O$ 难超 10 → $R_1/(g_m r_O)$ 可能与 $1/g_m$ 相当甚至更大 → **$R_{in}$ 显著高于 $50\Omega$**。

**讽刺的结论**：忽略 CLM 时 CG 输入阻抗太低，考虑 CLM 时又太高！

连带后果：含 $r_O$ 的增益为

$$\frac{V_{out}}{V_{in}} = \frac{g_m r_O + 1}{2(1 + r_O/R_1)} \tag{5.67}$$

若 $r_O$ 和 $R_1$ 可比 → 增益仅约 $g_m r_O/4$，**极低**。

### Cascode CG 级

> 【插入 Razavi RF 图 5.21】Cascode CG 级。

加入 Cascode 管 $M_2$ 以压制 $R_1$ 对输入阻抗的影响：

$$R_{in} \approx \frac{1}{g_{m1}} + \frac{R_1}{g_{m1}r_{O1} \cdot g_{m2}r_{O2}} + \frac{1}{g_{m1}r_{O1} \cdot g_{m2}} \tag{5.70}$$

$R_1$ 被**两个本征增益的乘积**除 → 其影响可忽略。$R_{in} \approx 1/g_{m1}$ 恢复。

**代价一：$M_2$ 噪声**。$M_2$ 栅参考噪声到输出的传输函数（图 5.22）：

$$\frac{V_{n,out}}{V_{n2}}(s) = \frac{2r_{O1}C_X s + 1}{2r_{O1}C_X s + 2g_{m2}r_{O1} + 1} \cdot g_{m2}R_1 \tag{5.71–5.72}$$

存在零点 $\omega_z = (2r_{O1}C_X)^{-1}$。频率低于 $\omega_z$ 时 $M_2$ 噪声可忽略；高于 $\omega_z$ 时开始显著。由于 $2r_{O1} \gg 1/g_m$，$\omega_z \ll \omega_T$——**此效应可能很重要**。

> 【插入 Razavi RF 图 5.23】含 $C_{GS2}$ 的噪声分析。

Example 5.10 补充：当频率远高于 $\omega_z$（但低于 $f_T$）→ $\frac{V_{out}}{V_{in}} \approx -R_1 C_X s$ —— $M_2$ 噪声**无衰减**传到输出。

**代价二：电压裕度**。$M_1$ 和 $M_2$ 堆叠消耗一台 $V_{GS}$ + 一台过驱动。数值例：$I_D=2\ \mathrm{mA}$、$g_{m1}=(50\Omega)^{-1}$ → $V_{GS1}-V_{TH}=200\ \mathrm{mV}$；$V_{GS2}\approx 500\ \mathrm{mV}$。$V_{DD}=1\ \mathrm{V}$ 时 $R_B$ 可用电压仅 $300\ \mathrm{mV}$ → $R_B \leq 150\Omega$（与 $R_S=50\Omega$ 可比 → 严重退化增益和噪声）。

### 电感偏置路径

> 【插入 Razavi RF 图 5.24】Cascode CG 级的完整偏置。

用 $L_B$ 代替 $R_B$ 作为偏置通路：$L_B$ 与输入寄生电容谐振 → 消除电抗 + 无电阻噪声 + 不衰减信号。但 $L_B$ 的并联等效电阻 $R_p = Q L_B \omega$ 必须 $\gg 10 \times R_S$。

### 设计流程（五步法）

1. **确定 $M_1$ 尺寸和电流**：用仿真扫 $g_m$–$I_D$ 曲线（对给定 $W_0$），选 $I_{D0}$ 达到饱和 $g_m$ 的 80–90%，然后等比例缩放 $W$ 和 $I_D$ 使 $g_m = (50\Omega)^{-1}$
2. **选择 $L_B$**：$L_B$ 与 $C_{pad} + C_{SB1} + C_{GS1}$ 在工作频率谐振；迭代考虑电感自身寄生电容
3. **偏置支路**：$M_B$ 和 $I_{REF}$ 按比例缩小（如 1:5），$C_B$ 提供栅极低阻接地
4. **选择 $M_2$ 宽度**：初始 $W_2 \approx W_1$；$W_2$ 太小 → $V_{GS2}$ 过大压入线性区；$W_2$ 太大 → 增加 $C_X$ 而 $g_m$ 近乎不变
5. **选择 $L_1$**：与输出总电容谐振；$R_1 = Q L_1 \omega$ 通常 500–1000Ω 足够

版图技巧：$M_1$ 和 $M_2$ 共享漏/源区 → 最小化 $C_X$（图 5.27）。

## 5.3.4 Cascode CS 级 + 电感源极退化

这是 RF LNA 设计中最经典、最重要的拓扑。核心思想来自 5.2 节的一个推论：用有源器件而非实体电阻合成输入实部。

### 电感退化产生输入实部

> 【插入 Razavi RF 图 5.31】(a) 电感退化 CS 级输入阻抗，(b) 用键合线实现退化电感。

忽略 $C_{GD}$ 和 $C_{SB}$，$I_X$ 全部流经 $C_{GS1}$ 产生 $V_{GS1} = I_X/(C_{GS1}s)$，进而产生漏电流 $g_m I_X/(C_{GS1}s)$。两者流经 $L_1$：

$$V_P = \left(I_X + \frac{g_m I_X}{C_{GS1}s}\right) L_1 s$$

$$Z_{in} = \frac{V_X}{I_X} = \frac{1}{C_{GS1}s} + L_1 s + \frac{g_m L_1}{C_{GS1}} \tag{5.77}$$

**第三项不含频率变量**——这是一个纯电阻！物理来源：$L_1$ 上的电压由 $g_m V_{GS}$ 产生，$V_{GS}$ 又由输入电流流过 $C_{GS}$ 产生 → 电压与电流同相。

$$\boxed{R_{in} = \frac{g_m L_1}{C_{GS1}} \approx L_1 \omega_T} \tag{核心}$$

**数值量感**：65 nm 工艺 $f_T \approx 160\ \mathrm{GHz}$ → 需 $L_1 \approx 50\ \mathrm{pH}$ 才能得到 $50\Omega$！实际键合线（bond wire）电感 0.5–1 nH → $R_{in}$ 远高于 $50\Omega$。解决：在 $C_{GS}$ 上并联额外电容以降低有效 $f_T$，或用更长沟道。

> 【插入 Razavi RF 图 5.31(b)】downbond 到封装地平面——最短键合线仍有 0.5–1 nH。

### $C_{GD}$ 的效应（Example 5.12）

$C_{GD}$ 将输入电阻降低约 $1 - 2C_{GD}/C_{GS}$ 倍。若 $C_{GD} \approx 0.1C_{GS}$ → 减小约 20%。

> 【插入 Razavi RF 图 5.32】含 $C_{GD}$ 的等效电路。

### Pad 电容效应

> 【插入 Razavi RF 图 5.33】pad 电容对输入电阻的影响。

$C_{pad}$ 经过串联-并联变换 → 等效输入电阻缩小为：

$$R_{eq} \approx \left(\frac{C_{GS1}}{C_{GS1} + C_{pad}}\right)^2 R_1 \tag{5.85}$$

若 $C_{GS1} \approx C_{pad}$ → 缩小 4 倍！**$C_{pad}$ 反而是好事**——降低了所需的有效 $f_T$，避免了故意降低晶体管 $f_T$ 的需求。

### 栅极串联电感 $L_G$

$L_1$ 通常不足以与 $C_{GS1} + C_{pad}$ 在工作频率谐振 → 需串联 $L_G$（通常片外，图 5.34）：

> 【插入 Razavi RF 图 5.34】添加 $L_G$ 完成输入谐振。

Example 5.13：若 $L_G$ 片上集成且 $Q=5$ → 串联电阻 $L_G\omega/Q \approx 12.6\Omega$（与 $50\Omega$ 可比）→ 严重恶化 NF → **$L_G$ 通常片外**。

### 噪声系数——本节最核心结论

> 【插入 Razavi RF 图 5.35】NF 计算等效电路。

忽略 CLM、体效应、$C_{GD}$、$C_{pad}$。输入网络在 $\omega_0$ 谐振：$(L_1+L_G)C_{GS1} = \omega_0^{-2}$。在谐振且输入匹配（$g_m L_1/C_{GS1} = R_S$）条件下：

**跨导增益**（与 $L_1$、$L_G$、$g_m$ 无关！）：

$$\left|\frac{I_{out}}{V_{in}}\right| = \frac{\omega_T}{2\omega_0} \cdot \frac{1}{R_S} \tag{5.91}$$

**噪声系数**（仅 $M_1$）：

$$\boxed{\mathrm{NF} = 1 + g_m R_S \gamma \left(\frac{\omega_0}{\omega_T}\right)^2} \tag{5.95}$$

**物理含义**：NF 与 $(\omega_0/\omega_T)^2$ 成正比。$\omega_T \gg \omega_0$ 是低 NF 的关键——晶体管速度必须远高于工作频率。$g_m R_S$ 项来自匹配条件：$g_m L_1/C_{GS1} = R_S$ → $g_m R_S = \omega_T L_1 / R_S$。实际 NF 可达 **1.5–2 dB**（远优于 CG 和阻性反馈的 3 dB 下限）。

### Example 5.14："零功耗 NF=1"的悖论

等比例缩小 $W$ 和 $I_D$ → $g_m$ 和 $C_{GS}$ 下降而 $\omega_T$ 不变 → NF 下降且功耗下降？**陷阱**：$C_{GS} \to 0$ 迫使 $L_G \to \infty$ → 输入网络 $Q \to \infty$ → $R_S$ 噪声被无限放大压倒 $M_1$ 噪声 → NF → 1。但实际受限：
- 若保持 $L_G$ 固定而增大 $L_1$ → 跨导增益趋于零（零增益"零噪声"无意义）
- 若增大 $L_G$ → 受限于片外电感的 $Q$ 和寄生电容

### 输入网络的电压增益

$$ \frac{V_G}{V_{in}} = \frac{1}{2}\left(1 + \frac{L_G \omega_0}{R_S}\right) \tag{5.96}$$

$L_G\omega_0/R_S$ 是 $L_G$–$R_S$ 串联支路的 $Q$。设计从**最大可用 $L_G$** 开始（通常片外电感，寄生电容可忽略），典型提供高达 6 dB 的输入预增益 → 降低 NF，代价是 IP3/P1dB 相应下降。

### 加入 Cascode 管

> 【插入 Razavi RF 图 5.37】完整的电感退化 Cascode CS LNA。

电感负载 CS 级通过 $C_{GD}$ 反馈导致负阻（5.3.1 节）。加入 Cascode 管 $M_2$ 隔离输入与输出负载。

**电压增益**（跨导增益 × 负载）：

$$\frac{V_{out}}{V_{in}} = \frac{\omega_T}{2\omega_0} \cdot \frac{R_1}{R_S} = \frac{R_1}{2 L_1 \omega_0} \tag{5.97–5.98}$$

**含 $R_1$ 噪声的完整 NF**（Example 5.15）：

$$\mathrm{NF} = 1 + g_m R_S \gamma \left(\frac{\omega_0}{\omega_T}\right)^2 + \frac{4R_S}{R_1} \left(\frac{\omega_0}{\omega_T}\right)^2 \tag{5.101}$$

**关键差异 vs CG**：$R_1$ 的噪声贡献被乘了 $(\omega_0/\omega_T)^2$！当 $\omega_0 \ll \omega_T$ 时 $R_1$ 噪声可忽略。CG 级没有这个因子 → CS 对负载噪声的抑制远优于 CG。

$M_2$ 噪声：与 Cascode CG 相同机制，在频率高于 $(2r_{O1}C_X)^{-1}$ 时开始显著。

### 设计流程

两个核心方程：

$$\frac{1}{(L_G + L_1)(C_{GS1} + C_{pad})} = \omega_0^2 \tag{5.102}$$

$$\left(\frac{C_{GS1}}{C_{GS1} + C_{pad}}\right)^2 L_1 \omega_T = R_S \tag{5.103}$$

流程：(1) 已知 $\omega_0$、$L_1$（键合线估值）、$C_{pad}$、$L_G$（最大可用片外电感）→ 从 (5.102) 求 $C_{GS1}$ → 从 (5.103) 求 $\omega_T$ 和 $g_m$ → (2) 用 $g_m$–$I_D$ 仿真曲线确定 $W$ 和 $I_D$ → (3) $M_2$ 尺寸与 $M_1$ 相同 → (4) $L_D$ 与输出总电容谐振，若增益过高可并联电阻降低 → (5) 验证 Miller 效应对输入匹配的影响，微调 $L_G$。

> 【插入 Razavi RF 图 5.38】完整 LNA 含偏置网络——$M_B$+$I_B$ 提供偏置，$R_B C_B$ 隔离信号路径与偏置噪声。

### 偏置电阻选择（Example 5.16）

$R_B$ 与信号路径并联 → 需 $\gg$ 栅极看到的等效并联电阻 $R_P \approx Q^2 R_S$（而非仅 $10R_S$）。若输入 Q=3 → $R_P \approx 450\Omega$ → $R_B$ 需 $\gg 450\Omega$。长电阻的分布式寄生电容——旁路远端（Q 点）优于近端（P 点，图 5.39）。

|---|---|---|
| NF | ~3–4 dB | **~1.5–2 dB** |

## 5.3.5 CG LNA 的变体

CG 级的核心缺陷：$g_m R_S = 1$（匹配条件）与 $\mathrm{NF} = 1 + \gamma/g_m R_S + \cdots$ 绑定 → NF ≥ 3 dB。增加一个**设计自由度**以解耦匹配与噪声。

### 电压-电压反馈 CG

> 【插入 Razavi RF 图 5.43】反馈 CG LNA。

反馈系数 $\alpha$ 检测输出电压，从输入中减去一部分 → $M_1$ 对 $V_F - V_{in}$ 响应。环路增益 $= g_m Z_L \cdot \alpha$。

闭环输入阻抗（忽略 CLM 和体效应）：

$$Z_{in} = \frac{1}{g_m} + \alpha Z_L \quad \xrightarrow{\text{谐振}} \quad \frac{1}{g_m} + \alpha R_1 \tag{5.113–5.114}$$

$\alpha R_1$ 项使 $R_{in}$ 可以**远大于** $1/g_m$ → $g_m$ 可以更大以降低 NF，而 $\alpha$ 调整匹配。

增益（谐振、匹配）：

$$\frac{V_{out}}{V_{in}} = \frac{R_1}{\frac{1}{g_m} + \alpha R_1 + R_S} = \frac{R_1}{2R_S} \ (\text{匹配时}) \tag{5.115–5.116}$$

噪声系数（匹配条件下）：

$$\mathrm{NF} = 1 + \frac{\gamma}{g_m R_S} + \frac{R_S}{R_1}\left(1 + \frac{1}{g_m R_S}\right)^2 \tag{5.119}$$

**与基本 CG 的 (5.57) 形式完全相同**——但关键区别是 $g_m R_S$ **不必等于 1**！若 $g_m R_S = 4$、$\gamma = 1$ → 前两项 NF = **0.97 dB**。

$\alpha$ 的选择（Example 5.19）：由匹配条件 $g_m R_S - 1 = \alpha g_m R_1$ → $\alpha = (g_m R_S - 1)/(2 g_m R_S A_v)$。例：$g_m R_S = 4$、$A_v = 6$ → $\alpha = 1/16$。

### 前馈 CG（$g_m$-Boosting）

> 【插入 Razavi RF 图 5.45】(a) 前馈 CG LNA，(b) NF 计算。

输入经 $-A$ 放大后加到栅极 → $\Delta V_{GS} = -(1+A)\Delta V$ → 有效跨导**提升** $(1+A)$ 倍：

$$R_{in} = \frac{1}{g_m(1+A)}, \quad \text{增益} = (1+A)g_m R_1$$

NF（匹配时，忽略增益级 A 的噪声）：

$$\mathrm{NF} = 1 + \frac{\gamma}{1+A} + \frac{4R_S}{R_1} \tag{5.123}$$

$A$ 增加 → $\gamma/(1+A)$ 降低。含 A 噪声的完整 NF：

$$\mathrm{NF} = 1 + \frac{\gamma}{1+A} + \frac{4R_S}{R_1} + \frac{A^2}{(1+A)^2}\frac{\overline{V_{nA}^2}}{4kTR_S} \tag{5.124}$$

**A 的输入参考噪声几乎等量传递**（$A^2/(1+A)^2$ 接近 1）→ 用有源电路实现 A 很困难。

> 【插入 Razavi RF 图 5.46】片上变压器实现前馈——电压增益 $kn$（$k$ 耦合系数、$n$ 匝比）。即使堆叠螺旋，增益难以超过 ~3，且初次级损耗贡献额外噪声。

### 评价

两种变体均为 CG 增加了设计自由度以解耦匹配与噪声。反馈方案在 $g_m R_S \gg 1$ 时 NF 显著改善；前馈方案受限于增益级 A 的噪声。实际中这些结构比基本 CG 和电感退化 CS 使用更少，但概念上很重要——解耦匹配与噪声的思想启发了噪声抵消 LNA（5.3.6）。

## 5.3.6 噪声抵消 LNA（Noise-Cancelling LNA）

之前所有 LNA 的 NF 都包含三项：$R_S$ 噪声（=1）、$M_1$ 噪声、负载噪声。**噪声抵消 LNA 旨在消除第二项**。

### 基本原理

> 【插入 Razavi RF 图 5.47】噪声抵消的概念示意。

找到电路中两个节点 X 和 Y，满足：
- **信号**在 X 和 Y 极性**相反**
- **$M_1$ 噪声**在 X 和 Y 极性**相同**

→ 将 X 和 Y 电压适当缩放后相加 → 信号叠加、噪声抵消。

### 阻性反馈 CS 实现

> 【插入 Razavi RF 图 5.48】(a) 阻性反馈 CS 中 $M_1$ 噪声，(b) 噪声抵消实现。

回顾 5.3.2 的阻性反馈 CS：$M_1$ 噪声电流流经 $R_F$ 和 $R_S$ → 在栅极（X）和漏极（Y）产生**同极性**噪声电压。信号在 CS 级中经历反相。

- 信号增益：$V_Y/V_X = 1 - g_m R_F = 1 - R_F/R_S$（匹配时）
- 噪声比：$V_Y/V_X|_{noise} = 1 + R_F/R_S$

取辅助放大器增益 $A_1 = 1 + R_F/R_S$ 处理 $V_X$，与 $V_Y$ 相加：

$$\frac{V_{out}}{V_X} = 1 - \frac{R_F}{R_S} - \left(1 + \frac{R_F}{R_S}\right) = -\frac{2R_F}{R_S} \tag{5.125–5.126}$$

$M_1$ 噪声被完全抵消，信号增益翻倍（$R_F/R_S$ → $2R_F/R_S$）！

**噪声系数**：

$$\mathrm{NF} = 1 + \frac{R_S}{R_F} + \frac{\overline{V_{nA1}^2}}{4kTR_S}\left(1 + \frac{R_S}{R_F}\right)^2 \tag{5.128}$$

- $R_S/R_F$ = 增益的倒数 $\ll 1$
- 辅助放大器的噪声**几乎直接以 1:1** 参考到输入端 → 必须是极低噪声设计

**频率响应**：输入电容 $C_{in}$ 恶化 $S_{11}$ 和噪声抵消效果：

$$\mathrm{NF}(f) = \mathrm{NF}(0) + [\mathrm{NF}(0) - 1 + \gamma]\left(\frac{f}{f_0}\right)^2 \tag{5.129}$$

$f_0 = 1/(\pi R_S C_{in})$。高频时 NF 以 $f^2$ 恶化。

### 实现示例

> 【插入 Razavi RF 图 5.49】噪声抵消 LNA 的实际实现——$M_2$+$M_3$ 构成 CS 放大器兼求和电路，$M_3$ 为源随器检测 $M_1$ 漏极信号。

### CG/CS 噪声抵消 LNA（Example 5.20）

> 【插入 Razavi RF 图 5.50】CG/CS 噪声抵消 LNA——兼做单端转差分。

- $M_1$ 噪声：经源随路径到 X、经 CS 路径到 Y → 两节点**极性相反** → 可抵消
- 信号：经 CG 路径到 X 和 Y → 同极性 → 差分输出

噪声抵消条件：$g_{m1}R_1 = g_{m2}R_2$ → $R_1 = g_{m2}R_2 R_S$（因 $g_{m1} = 1/R_S$）。

抵消后的 NF：

$$\mathrm{NF} = 1 + \frac{R_S}{R_1} + \gamma\frac{R_2}{R_1} + \frac{R_S R_2}{R_1^2} \tag{5.132–5.133}$$

### 优势与应用

噪声抵消 LNA 的核心价值：**兼具反馈/CG 级的宽带特性 + 更低的噪声系数**。适合多频段或跨宽频范围的系统（如 900 MHz 至 5 GHz）。

## 5.3.7 电抗抵消 LNA（Reactance-Cancelling LNA）

此拓扑**利用负反馈放大器固有的感性输入阻抗来抵消自身的输入电容** $C_{in}$。

### 原理

> 【插入 Razavi RF 图 5.51】(a) 电抗抵消 LNA 拓扑，(b) $Y_1$ 实部和虚部随频率变化。

核心放大器建模为单极点响应 $A_0/(1 + s/\omega_0)$，输入端导纳：

$$Y_1(s) = \frac{s + (A_0 + 1)\omega_0}{R_F(s + \omega_0)} \tag{5.134}$$

在 $\omega \ll \omega_0$ 时：

$$\frac{1}{\mathrm{Re}\{Y_1\}} \approx \frac{R_F}{1 + A_0} \quad \text{（可设为 } R_S \text{）}$$

$$\mathrm{Im}\{Y_1\} \approx -\frac{A_0 \omega}{R_F \omega_0} \quad \text{（负值 = 感性！可抵消 } C_{in}\omega \text{）}$$

物理本质：负反馈在输入端口产生一个合成的感性分量，恰好与 $C_{in}$ 的容性分量对消 → 宽带输入匹配（不需片外电感！）。

匹配带宽可达 ~$\omega_0$ → 核心放大器的开环带宽必须覆盖目标最高频率。

### 实现（50 MHz–10 GHz）

> 【插入 Razavi RF 图 5.52】电抗抵消 LNA 的电路实现。

三个 CS 级提供增益和负反馈，不用 Cascode 或源随器以节省电压裕度。$R_F = 1\ \mathrm{k\Omega}$。

$M_1$ 需大宽度以满足 50 MHz 处的闪烁噪声要求 → $V_{GS} \approx 200\ \mathrm{mV}$。若此电压也出现在节点 Y → 输出摆幅无裕度 → $I_1$（$200\ \mu\mathrm{A}$）从 $R_F$ 抽取电流，将 Y 点 DC 电平抬升 ~250 mV。

多极点分析：A/B/X/Y 节点极点分别在 10 / 24.5 / 22 / 75 GHz。**单极点近似仍适用**——将极点时间常数加总得等效 $\omega_0 = 2\pi(9.9\ \mathrm{GHz})$。反馈系数 $R_S/(R_S+R_F) \approx 0.048$ 很小 → 相位裕度 ~$50^\circ$、闭环 peaking 仅 1 dB。

### 伪差分输出

输出取 X 和 Y 之间的差分：增益提升 + 二阶失真在 X 和 Y 同相 → 在 $V_Y - V_X$ 中部分抵消 → **IP2 改善**。

### 评价

电抗抵消 LNA 代表了宽带 LNA 的另一思路：不用片外电感、利用反馈自身产生的感性阻抗抵消输入电容。适合认知无线电等极宽带应用。

→ 反馈放大器的阻抗变换：[[C8.反馈#8.1.1 反馈电路的特性|Ch8: 反馈改变输入/输出阻抗]]

→ 宽带 RF 前端设计：[[C4.Transceiver Architecture|收发机架构（宽带接收机）]]

### 5.3 节总结：七种拓扑的演进逻辑

| 节 | 拓扑 | 核心贡献 | 主要局限 |
|---|------|---------|---------|
| 5.3.1 | 电感负载 CS | 电感解耦增益-摆幅、谐振提速 | $C_F$ 反馈→失稳 |
| 5.3.2 | 阻性反馈 CS | $g_m$ 匹配、无增益-摆幅折中 | NF ≥ 3 dB（$\gamma$ 项） |
| 5.3.3 | CG 级 | 天然低 $R_{in}$、宽带 | NF ≥ 3 dB、CLM 问题 |
| 5.3.4 | **Cascode CS + 电感退化** | **$L_1\omega_T$ 有源合成 50Ω、NF 1.5–2 dB** | 窄带、片外 $L_G$ |
| 5.3.5 | CG 变体 | 解耦匹配与噪声 | 复杂度、辅助电路噪声 |
| 5.3.6 | 噪声抵消 | 消除 $M_1$ 噪声 → 宽带+低 NF | 辅助放大器噪声 1:1 传递 |
| 5.3.7 | 电抗抵消 | 反馈感性阻抗抵消 $C_{in}$ → 超宽带无片外电感 | 多级反馈、相位裕度约束 |

这七种拓扑代表了现代 RF LNA 设计的完整工具箱——从窄带低噪声（5.3.4）到宽带自匹配（5.3.7），从经典（5.3.3）到创新（5.3.6）。

# 5.4 增益切换（Gain Switching）

## 动机与四项约束

接收机的动态范围可达 **100 dB**：手机在基站附近接收 −10 dBm，在车库深处仅 −110 dBm。LNA 按最高灵敏度设计，但当输入信号持续增大时，各级增益必须降低，使后级电路保持足够线性。

增益降低的同时噪声系数上升——但需确保 SNR 不恶化：灵敏度损失必须小于信号电平的增量。

> 【插入 Razavi RF 图 5.53】增益切换对 NF 和 $P_{1dB}$ 的影响：随增益降低，NF 上升而 $P_{1dB}$ 提高。

LNA 增益切换必须满足四项约束：

1. **不影响输入匹配**：$S_{11}$ 必须在所有增益档位保持可接受
2. **增益步长足够小**：大步长 → 瞬时 SNR 突变 → 解调器失锁
3. **附加开关器件不降低速度**：增益切换引入的寄生电容不能恶化 LNA 带宽
4. **高输入时提高线性度**：增益降低的同时 LNA 自身的 $P_{1dB}$ 应提升，否则 LNA 本身成为链路非线性瓶颈

不同 LNA 拓扑对增益切换的适应能力差异显著——这是贯穿 5.4 节的主线。

## CG 级：输入管分解 + 并联开关

CG 级的直接困境：降低增益 → 需减小 $g_m$ → $R_{in} = 1/g_m$ 增大 → 输入匹配丧失。

**解决方案**：将输入管拆分为两路，并加入并联开关电阻补偿输入阻抗。

> 【插入 Razavi RF 图 5.54】CG 级增益切换——$M_{1x}$/M₁y 分解 + $M_2$ 并联开关。

**高增益模式**：GS 为高 → $M_{1x}$ 和 $M_{1y}$ 并联、$M_2$ 关断 → $g_m = g_{m1x} + g_{m1y}$，$R_{in} = 1/(g_{m1x}+g_{m1y}) = R_S$。

**低增益模式**：$M_{1y}$ 关断（$g_m$ 降低 → 增益降低）、$M_2$ 导通 → 并联电阻补足输入阻抗：

$$R_{on2} \parallel (g_{m1x} + g_{mb1x})^{-1} = R_S$$

$M_{1y}$ 的栅极通过电容接地——避免开关的 on-resistance 在高频进入信号路径。

**6 dB 步长**：$M_{1x}$ 和 $M_{1y}$ 等尺寸 → 关断 $M_{1y}$ 将 $g_m$ 减半，增益减半（−6 dB）。此时 $R_{in}$ 变为 $2R_S$，需 $R_{on2} = 2R_S$ 补回 $R_S$。

### Example 5.21：3 dB 增益步长

3 dB → 电压增益除以 $\sqrt{2}$：

$$\frac{W_{1x}}{W_{1x}+W_{1y}} = \frac{1}{\sqrt{2}} \quad\Rightarrow\quad \frac{W_{1y}}{W_{1x}} = \sqrt{2} - 1 \approx 0.414$$

$M_{1y}$ 关断后 $R_{in}$ 升至 $\sqrt{2}R_S$，并联 $R_{on2}$ 恢复匹配：

$$R_{on2} = \frac{\sqrt{2}}{\sqrt{2}-1}R_S \approx 3.41 R_S$$

**注意**：以上忽略沟道长度调制。若式 (5.67) 的上界限制设计，可用 Cascode CG 级（图 5.24）缓解。

**评价**：此方案直接但精度受限——增益步长取决于 $g_m$ 比例和 $R_{on2}$ 的绝对值（工艺/温度敏感）。$M_2$ 导通时贡献噪声和寄生电容。

## CG 级：负载切换（Load Switching）

在输出端而非输入端做文章——用 PMOS 开关与负载 $R_1$ 并联，减小有效负载阻抗从而降低增益。

> 【插入 Razavi RF 图 5.55】负载切换对输入阻抗的影响。

忽略 CLM 且输入匹配时：

$$\frac{V_{out}}{V_{in}} = \frac{R_1 \parallel R_{on2}}{2R_S} \tag{5.139}$$

$R_{on2}$ 越小 → 增益越低。多步长用多个 PMOS 开关并联。

### Example 5.22：两个 3 dB 步长

> 【插入 Razavi RF 图 5.56】两档负载开关实现。

**第一步**（$M_{2a}$ 导通）：

$$R_1 \parallel R_{on,a} = \frac{R_1}{\sqrt{2}} \quad\Rightarrow\quad R_{on,a} = \frac{R_1}{\sqrt{2}-1}$$

**第二步**（$M_{2a}$ 和 $M_{2b}$ 同时导通）：

$$R_1 \parallel R_{on,a} \parallel R_{on,b} = \frac{R_1}{2} \quad\Rightarrow\quad R_{on,b} = \frac{R_1}{2-\sqrt{2}}$$

**设计洞察**：若第二步只用单个 $M_{2b}$（不用 $M_{2a}$），$M_{2b}$ 的 $R_{on}$ 需更小 → 宽度需更大 → 输出节点电容更大。两级级联用更窄的管子分摊了电容贡献——这是开关尺寸优化的典型思路。

### 根本缺陷

改变 $R_1$ 会连带改变 $R_{in}$：

$$R_{in} = \frac{R_1 + r_O}{1 + g_m r_O}$$

$R_1 \downarrow$ → $R_{in}$ 变化 → 输入匹配漂移。加入 Cascode 管（图 5.24）可抑制此效应——这自然引出了第三种方法。

## CG 级：Cascode 电流导向（Current Steering）

前两种方案的根本局限：增益步长依赖 MOS 开关的 $R_{on}$ 绝对值（工艺、温度敏感）。第三种方案通过**分流而非衰减**实现增益步长，精度仅取决于器件尺寸比。

### 原理

> 【插入 Razavi RF 图 5.57】Cascode 电流导向增益切换——$M_3$ 将 $M_1$ 的部分漏电流导向 $V_{DD}$ 而非负载。

在 Cascode CG 级中增加第二个 Cascode 管 $M_3$（与 $M_2$ 并联）。$M_3$ 导通时将 $M_1$ 的部分电流从负载 $R_1$ 旁路到 $V_{DD}$。电流按 $W_3/W_2$ 比例分流：

$$\text{增益降低倍数} = 1 + \frac{W_3}{W_2}$$

若 $M_2$ 和 $M_3$ 等尺寸 → 电流平分 → 增益降 6 dB。

**核心优势**：增益步长**仅取决于尺寸比** $W_3/W_2$，不依赖任何 MOS 开关的 $R_{on}$ 绝对值。工艺/温度变化同时影响两管，比例保持恒定 → 精度远高于前两种方案。

**核心代价**：$M_3$ 在节点 Y 引入额外电容。6 dB 步长需 $W_3 = W_2$ → Y 节点电容翻倍。增益降低 $N$ 倍需 $W_3 = (N-1)W_2$ → 大增益步长时性能退化严重。

### Example 5.23：输入阻抗在不同增益档位的变化

$M_3$ 导通 → $M_2$ 偏置电流减半（$W_3=W_2$ 时）→ 平方律器件：$g_{m2} \downarrow \sqrt{2}$ 倍、$r_{O2} \uparrow 2$ 倍。

$$R_{in2} = \frac{R_1 + 2r_{O2}}{1 + \sqrt{2}g_{m2}r_{O2}}$$

$M_3$ 自身在 Y 节点呈现 $(1/g_{m3}) \parallel r_{O3}$，与 $R_{in2}$ 并联 → $R_Y$ 仍在 $1/g_m$ 量级 → $R_X \approx (R_Y + r_{O1})/(1+g_{m1}r_{O1})$ **在不同增益档位下相对恒定**。

**物理含义**：因为 $R_Y \sim 1/g_m$（低阻），$M_1$ 将 $R_Y$ 变为源极看到的 $1/g_{m1}$ 量级的阻抗——增益切换对输入匹配的影响天然很小。这是 Cascode 电流导向的第二个优势。

### 可编程 Cascode（Programmable Cascode）

> 【插入 Razavi RF 图 5.58】可编程 Cascode——$M_2$ 分解为 $M_{2a}$+$M_{2b}$，$M_3$ 导通时 $M_{2a}$ 关断。

为缓解 $M_3$ 的电容负担，将主 Cascode 管 $M_2$ 分解。当 $M_3$ 导通时同步关断 $M_2$ 的一部分 → 分流不平衡更大 → $M_3$ 可更窄（电容更小）：

$$\text{增益降低倍数} = 1 + \frac{W_3}{W_{2b}} \quad\text{(vs 不分解时的 } 1+\frac{W_3}{W_{2a}+W_{2b}}\text{)}$$

### Example 5.24：两个 3 dB 步长

**第一步**（$M_3$ 导通，$M_{2a}$+$M_{2b}$ 仍导通）：

$$1 + \frac{W_3}{W_{2a}+W_{2b}} = \sqrt{2}$$

**第二步**（$M_3$ 导通，$M_{2b}$ 关断）：

$$1 + \frac{W_3}{W_{2a}} = 2$$

联立解得：

$$\boxed{W_3 = W_{2a} = \frac{W_{2b}}{\sqrt{2}}}$$

> 进一步可把 $M_2$ 拆成三个器件——每档关断一部分，使 $M_3$ 更窄。计算留作练习。

## 电感退化 Cascode CS LNA 的增益切换

### 输入管切换为何失败

> 【插入 Razavi RF 图 5.59】在电感退化 CS 级中切换输入管——吸引力但不可行。

直觉：关断 $M_{1b}$ 减小 $g_m$ → 降低增益。**实际不可行**，有三个致命原因：

1. **输入匹配恶化**：关断 $M_{1b}$，电流密度不变 → $\omega_T$ 恒定 → $\mathrm{Re}\{Z_{in}\} = L_1\omega_T$ 基本不变，但 $\mathrm{Im}\{Z_{in}\}$ 改变（$C_{GS}$ 减小）→ 输入谐振破坏
2. **增益不变**：即使输入匹配被某种方式恢复，电压增益 $R_1/(2L_1\omega)$ **不含 $g_m$**——增益不会降低！
3. **NF 恶化**：开关 $S_1$（$M_{1b}$ 的栅极开关）在高增益模式引入热噪声 → NF 退化

**物理根源**：电感退化 CS 级的增益公式 $R_1/(2L_1\omega)$ 中，$g_m$ 和 $C_{GS}$ 在跨导增益 $\omega_T/(2\omega_0 R_S)$ 中以比值形式出现——而 $\omega_T = g_m/C_{GS}$ 是电流密度的函数，不随并联管数改变。这是拓扑结构的深层约束：**改变输入器件不能改变增益**。

### 可行方案

> 【插入 Razavi RF 图 5.60】(a) 负载切换，(b) Cascode 电流导向。

两种方案与 CG 级完全对应：

**(a) 负载 PMOS 开关**：并联至 $R_1$，减小有效负载阻抗 → 增益降低。缺陷同 CG 级——$R_{on}$ 绝对值敏感。

**(b) Cascode 电流导向**（**推荐**）：与图 5.57 同构，Example 5.24 的计算直接适用。优势总结：
- 增益步长 = 尺寸比（精确、PVT 鲁棒）
- 电流流过负载的比例严格可控
- 对输入阻抗的影响可忽略（$R_Y \sim 1/g_m$ → $M_1$ 源极看入仍为 $\sim 1/g_{m1}$ 量级）
- 代价：节点 Y 电容增加（受限于可编程 Cascode 分解技术缓解）

## CG 变体与噪声抵消 LNA 的增益切换

### 反馈/前馈 CG 变体

两种 CG 变体（5.3.5 节）均可使用 Cascode 电流导向（图 5.57）实现增益切换。但反馈/前馈路径的存在使**通过输入管改变增益**几乎不可能——任何对输入管的修改都会通过反馈或前馈网络扰动输入匹配。Cascode 分流避免了这一问题，因为它在不触及输入器件的条件下重新分配电流。

### 噪声抵消 LNA：最简洁的方案

> 【插入 Razavi RF 图 5.48(b)】噪声抵消 LNA——降低 $R_F$ 即可切换增益。

阻性反馈噪声抵消 LNA（5.3.6 节）的增益切换异常简洁：

$$R_{in} \approx \frac{1}{g_{m1}}, \quad \frac{V_Y}{V_X} = 1 - \frac{R_F}{R_S}$$

- $R_{in}$ **不依赖 $R_F$** → 改变 $R_F$ 不影响输入匹配
- 降低 $R_F$ → $|1 - R_F/R_S|$ 减小 → 增益降低
- 低增益模式下噪声抵消可选择性保留：调整 $A_1 = 1 + R_F/R_S$ 以跟踪 $R_F$ 变化

**这是 5.4 节所有方案中唯一一个增益步长不依赖 MOS 开关 $R_{on}$、不引入额外器件、不增加节点电容的方案。** 代价：噪声抵消 LNA 本身的 NF 下限受辅助放大器噪声约束（5.3.6 节）。

## 线性度与 LNA 旁路（Bypass）

### 增益切换能提高线性度吗？

前面的各种增益降低方案中，**哪个也同时提高了 LNA 的线性度？**

- **CG 和 CS 级**：增益降低后 $V_{GS}$ 摆幅不变（仍为输入电压的一半）→ 线性度改善微乎其微
- **噪声抵消 LNA**（图 5.48b）：降低 $R_F$ → 负反馈加深 → 线性度**在一定程度上提升**

**物理原因**：CG/CS 级增益降低是通过分流电流或衰减负载实现的，输入器件的 $V_{GS}$ 信号摆幅并未减小——而非线性正来源于 $V_{GS}$ 到 $I_D$ 的非线性传输。反馈 LNA 中 $R_F$ 降低强化了反馈环路，等价于增大了环路增益 → 非线性被 $(1+T)$ 除。

### LNA 旁路

> 【插入 Razavi RF 图 5.61】LNA 旁路概念。
> 
> 【插入 Razavi RF 图 5.62】CG 级 LNA 旁路实现。

在极高输入电平下，最简单的方案是**完全旁路 LNA**——让信号直接进入混频器（混频器的线性度通常优于高增益 LNA）。

**CG 级实现**（图 5.62）：
- $M_1$ 关断（输入管禁用）
- $M_2$ 导通 → 提供 $50\Omega$ 终端匹配（维持 $S_{11}$）
- $M_3$ 导通 → 信号直接路由到混频器输入

复杂度在于：必须在旁路状态下仍然维持输入匹配——$M_2$ 的 $R_{on}$ 必须精确 $50\Omega$。

## 5.4 节总结：增益切换方案对比

| 方案 | 适用拓扑 | 精度来源 | 对 $R_{in}$ 影响 | 额外电容 | 线性度改善 |
|------|---------|---------|-----------------|---------|-----------|
| 输入管分解 + $R_{on}$ | CG | $R_{on}$ 绝对值 | 补偿 $R_{on}$ 维持匹配 | $M_2$ 贡献 | 无 |
| 负载 PMOS 开关 | CG / CS | $R_{on}$ 绝对值 | 通过 $r_O$ 耦合影响 | 输出节点 | 无 |
| Cascode 电流导向 | CG / CS | **尺寸比** $(W_3/W_2)$ | **极小**（$R_Y\sim 1/g_m$） | 节点 Y（可编程缓解） | 无 |
| 降低 $R_F$ | 噪声抵消 | $R_F$ 电阻比 | **无影响**（$R_{in}=1/g_{m1}$） | **零** | **有**（反馈加深） |
| LNA 旁路 | CG | — | 需 $M_2$ 提供 $50\Omega$ | 信号路径开关 | 最大（完全绕过） |

**设计准则**：
- 精度优先 → Cascode 电流导向（尺寸比 > $R_{on}$ 绝对值）
- 不增加电容 → 噪声抵消 LNA（仅改 $R_F$）
- 极高输入电平 → LNA 旁路（彻底消除 LNA 非线性）

# 5.5 频带切换（Band Switching）

回顾 5.1.6 节：宽带 LNA 的分数带宽过大时，单 LC 谐振腔的 $Q$ 难以兼顾增益和带宽。解决方案是**开关电容切换谐振频率**——将宽带分解为多个窄子带。

## 开关拓扑：PMOS 还是 NMOS？

> 【插入 Razavi RF 图 5.63】(a) 基本频带切换——$S_1$ 作 PMOS，(b) 改进——$S_1$ 作 NMOS、源极接地。

**直觉方案**（图 5.63a）：$S_1$ 串联在 $C_1$ 和 $C_2$ 之间，$S_1$ 导通时 $\omega_0 = 1/\sqrt{L_1(C_1+C_2)}$，关断时 $\omega_0 = 1/\sqrt{L_1 C_1}$。

**致命缺陷**：输出节点偏置在 $V_{DD}$ 附近 → $S_1$ 必须是 PMOS（NMOS 的栅极无法被拉至 $V_{DD}+V_{TH}$ 以上）。PMOS 的跨导约为 NMOS 的 1/3 → 给定 $R_{on}$ 下 PMOS 需要约 3 倍宽度 → **寄生电容远大于 NMOS**。

关断时 $S_1$ 的寄生电容 $C_{GD}+C_{DB}$ 从输出节点到地 → 降低谐振腔在 high-band（$S_1$ off）时的谐振频率 → 压缩 $C_1$ 的最大允许值 → 限制下一级输入管的尺寸 → 链路增益受损。

若试图减小 $L_1$ 以补偿电容增加 → $R_1 = QL_1\omega$ 同步减小 → 增益直接降低。

**改进方案**（图 5.63b）：将 $S_1$ 改为 NMOS，**源极接地**。$C_2$ 接在输出节点和 $S_1$ 漏极之间。NMOS 的栅极可轻松拉至 $V_{DD}$ 导通，且 NMOS 在相同 $R_{on}$ 下寄生电容远小于 PMOS。

**物理直觉**：通过交换开关位置，将一个 PMOS 问题转化为 NMOS 问题——利用了 NMOS 在相同性能下寄生更小的基本优势。这是 RF 开关设计的通用原则：**优先使用 NMOS，若无法避免 PMOS，重新审视拓扑。**

## 开关宽度的关键折中

选定 NMOS 拓扑（图 5.63b）后，$S_1$ 的宽度选择成为关键设计决策。

### 三种宽度区间

| $S_1$ 宽度 | $R_{on1}$ | 效果 |
|-----------|-----------|------|
| 极窄 | 极高 | 谐振腔"感觉不到"$C_2$——频带切换无效 |
| 中等 | 中等 | $C_2$ 的 $Q$ 被 $R_{on1}$ 限制 → 整体谐振腔 $Q$ 降低 → 增益下降 |
| 极宽 | 极小 | $R_{P1} \gg R_1$（好）但关断电容太大 → 压缩 $C_1$ 上限 |

### 中等宽度区的定量分析

$C_2$ 和 $R_{on1}$ 的串联组合可变换为并联等效网络：

$$Q = \frac{1}{C_2 \omega R_{on1}}, \quad R_{P1} \approx Q^2 R_{on1} = \frac{1}{C_2^2 \omega^2 R_{on1}}$$

$R_{P1}$ 并联在 $R_1$ 上 → 等效负载阻抗降低 → 增益降低：

$$\text{导通时增益} \propto R_1 \parallel R_{P1}$$

**物理含义**：$R_{on1}$ 并非直接与 $R_1$ 并联，而是经过 $C_2$ 的 $Q$ 变换后等效为一个大得多的并联电阻。$R_{on1}$ 越小 → $Q$ 越高 → $R_{P1}$ 越大 → 增益损失越小。

### 关断状态的代价

$S_1$ 关断时，谐振腔看到的等效电容为 $C_2$ 与 $C_{GD1}+C_{DB1}$ 的串联。开关越宽 → $C_{GD1}+C_{DB1}$ 越大 → 等效串联电容越大 → $C_1$ 必须相应减小。

$C_1$ 来源：$M_a$（下一级输入管）、电感 $L_1$ 的寄生电容。$C_1$ 可用的容值空间被开关寄生挤压。

### 折中总结

$$\boxed{\text{开关宽度} \uparrow \quad\Rightarrow\quad \begin{cases} \text{导通增益损失} \downarrow\ \text{（好）} \\ \text{关断时可用 } C_1 \downarrow\ \text{（坏）} \end{cases}}$$

设计目标：$R_{P1} \gg R_1$（导通时增益损失可忽略），且关断寄生电容不显著挤压 $C_1$。

## 多谐振腔方案（Multi-Tank）

> 【插入 Razavi RF 图 5.64】可编程 Cascode 分支实现频带切换。

不切换电容，而是**并行放置多个独立 LC 谐振腔**，各自配备 Cascode 管作为选择开关。

- 导通目标频带的 Cascode 管，关断其余 → 选中对应谐振腔
- 每个谐振腔驱动**自己的下一级副本**（如混频器 $MX_1$, $MX_2$）
- $M_1$ 和频带 1 激活时，$MX_1$ 同步激活

### 优缺点

**优势**：
- 各频带独立优化谐振腔参数（$L$, $C$, $Q$），无需共享
- 无开关 $R_{on}$ 导致的 $Q$ 退化问题

**缺陷**：
- 所有 Cascode 管漏极并联在节点 Y → **总电容 = 所有管子的 $C_{DB}+C_{GD}$**，随频带数线性增加 → 高频性能退化
- 片上螺旋电感占地极大 → 多谐振腔的版图布局困难、走线复杂
- 需要下一级电路的多份副本 → 面积和功耗翻倍

**适用场景**：频带数少（2–3）、电感面积可接受、性能优先于成本的设计。频带数较多时应回退到单谐振腔 + 开关电容方案。

## 5.5 节总结

| 方案                 | 原理                    | 优势                | 缺陷                          |
| ------------------ | --------------------- | ----------------- | --------------------------- |
| 开关电容 + NMOS 接地     | $S_1$ 导通接入 $C_2$，频率下移 | 单谐振腔面积小           | 开关宽度折中（$R_{on}$ vs 关断寄生）    |
| 多谐振腔 + 可编程 Cascode | 每频带独立谐振腔，Cascode 选中   | 无 $R_{on}$ 退化 $Q$ | 节点 Y 电容堆积、多电感面积大、多 mixer 副本 |

**通用设计准则**：RF 开关优先 NMOS → 若受拓扑约束必须用 PMOS → 考虑重构拓扑以避免 PMOS。

# 5.6 高 IP2 的 LNA（High-IP2 LNA）

直接变频接收机中，偶阶失真（尤其是 $\mathrm{IP}_2$）是关键瓶颈。混频器之后的基带电路通常为差分形式 → 自身 $\mathrm{IP}_2$ 高。因此 **LNA 和混频器** 成为整机 $\mathrm{IP}_2$ 的短板。

本章处理 LNA 的 $\mathrm{IP}_2$ 提升技术，第 6 章处理混频器。

## 5.6.1 差分 LNA

### 差分对称 → 高 IP2 的原理

对称电路**天然不产生偶阶失真**（第 2 章结论）。实际电路中随机失配导致残余偶阶分量，但 $\mathrm{IP}_2$ 仍远优于单端。

> 【插入 Razavi RF 图 5.65】差分 (a) CG 和 (b) CS LNA。

任何单端 LNA 拓扑原则上都可转换为差分形式。偏置网络与 5.3.3–5.3.4 节相同。

→ 非线性基础：[[C14.非线性与失配#14.1 非线性|Ch14: 偶阶失真与差分对消]]

### Balun 与差分源阻抗

天线和前选滤波器通常为**单端**输出 → 差分 LNA 前必须插入 **balun**（balanced-to-unbalanced transformer）完成单端转差分。

> 【插入 Razavi RF 图 5.66】(a) Balun 在接收机前端的位置，(b) 简化电路。

**关键参数推导**：天线经 BPF 提供的单端源阻抗 $R_{S1}$（如 $50\Omega$），balun 次级差分的等效源阻抗 $R_{S2}$ 是多少？

对于**无损 1:1 balun**（初次级匝数相等）：

$$R_{S2} = R_{S1}$$

差分 LNA 的噪声系数须**以 $R_{S1}$ 为参考**进行计算。

**输入匹配要求**：差分 LNA 的差模输入阻抗 $R_{in}$ 必须等于 $R_{S1}$ → 每个半电路的**单端输入阻抗**必须等于 $R_{S1}/2$（如 $25\Omega$）。

这一约束直接决定了差分 CG 和 CS LNA 的设计参数——晶体管的 $g_m$ 或退化电感必须加倍以提供更低（一半）的单端输入电阻。

### 差分 CG LNA 噪声系数

> 【插入 Razavi RF 图 5.67】差分 CG LNA 的半电路分解。

每个 CG 管须提供 $R_{in} = R_{S1}/2$（如 $25\Omega$）。利用对称性，总输出噪声 = 两个半电路输出噪声功率之和：

$$\overline{V_{n,out}^2} = \overline{V_{n,out1}^2} + \overline{V_{n,out2}^2}$$

半电路分析代入 $R_S = R_{S1}/2$，套用 5.3.3 节 CG 公式。每个半电路的输出噪声含三项：输入管噪声（式 5.56）、$R_1$ 热噪声 $4kTR_1$、源阻抗 $R_{S1}/2$ 贡献。总输出噪声功率翻倍。

**关键**：差分总电压增益 $A_v = (V_Y - V_W)/(V_X - V_Z)$ **等于半电路增益** $V_Y/V_X = R_1/R_{S1}$ ——是单端 CG LNA 的**两倍**（因为 $g_m$ 加倍以将 $R_{in}$ 降至 $R_{S1}/2$）。

以 $R_{S1}$ 为参考的噪声系数：

$$\boxed{\mathrm{NF} = 1 + \gamma + \frac{2R_{S1}}{R_1}} \tag{5.151}$$

**低于单端 CG 的 NF**（$1 + \gamma + 4R_S/R_1$）！原因是 $g_m$ 加倍 → 增益翻倍 → 负载噪声贡献从 $4R_S/R_1$ 降为 $2R_{S1}/R_1$。

但注意：若希望差分和单端增益相同 → 须将 $R_1$ 减半 → NF 回到单端水平。

> 【插入 Razavi RF 图 5.68】单端 vs 差分 CG LNA 的增益与噪声对比。

### 三种设计场景

| 场景 | 做法 | $R_{in}$（差分） | 增益 | NF |
|------|------|-----------------|------|-----|
| 1. 直接复制 | 不调整参数 | $100\Omega$ | = 单端 | 不匹配 |
| 2. 加倍 $g_m$ | $g_m$ 翻倍 | $50\Omega$ ✓ | **2× 单端** | 更优 |
| 3. 加倍 $g_m$ + 减半 $R_1$ | 增益不变 | $50\Omega$ ✓ | = 单端 | = 单端 |

**场景 2 为推荐选择**——利用差分结构天然的高增益。代价：**给定 NF 下差分 CG LNA 功耗为单端的 4 倍**。

实际 balun 损耗约 0.5 dB → NF 直接加 0.5 dB。

### Example 5.25：差分不一定噪声更低——反例

> 【插入 Razavi RF 图 5.69】(a) 并联电阻匹配的放大器，(b) 差分版本，(c) 半电路。

高输入阻抗放大器用并联电阻 $R_P = R_{S1}$ 实现输入匹配。放大器自身输入参考噪声电流可忽略，输出噪声 = $R_{S1}/2$ 热噪声 + 放大器输入参考噪声 $\overline{V_n^2}$。

**单端 NF**：

$$\mathrm{NF_{sing}} = 2 + \frac{\overline{V_n^2}}{kTR_{S1}}$$

（$R_P = R_S$ 时，源与 $R_P$ 分压损失 1/2 → 增益减半 → NF 含基础项 2 = 3 dB，如 5.2.2 节所预言。）

**差分 NF**（两个复制半电路，每半 $R_P = R_{S1}$，差分输入匹配 → 每半 $R_{in} = R_{S1}/2$ → 半电路等效源阻 $R_{S1}/4$）：

$$\mathrm{NF_{diff}} = 2 + \frac{2\overline{V_n^2}}{kTR_{S1}}$$

**差分 NF 更差！** 放大器噪声项翻倍（$2\overline{V_n^2}$ vs $\overline{V_n^2}$），而信号增益不变。

**关键教训**：差分对 NF 的影响取决于拓扑。差分 CG 的 NF 改善是因为 $g_m$ 加倍带来增益翻倍；而电阻匹配方案中增益不变、噪声加倍 → NF 恶化。**不能不加分析地假定"差分 = 更优 NF"。**

### 差分 CS LNA 噪声系数

> 【插入 Razavi RF 图 5.70】(a) 差分 CS LNA 与 balun，(b) 半电路。

每个半电路的 $R_{in} = L_1\omega_T$，现须等于 $R_{S1}/2$ → **退化电感减半**（$L_1 \to L_1/2$）。输入管宽度和偏置电流与单端版本相同。

增益 $R_1/(2L_1\omega_0)$，因 $L_1$ 减半 → **增益翻倍**。

忽略 Cascode 管噪声，匹配时输入管噪声电流的一半流向输出 → 半电路输出噪声：

$$\overline{V_{n,out1}^2} = kT\gamma g_{m1}R_1^2 + 4kTR_1 + 4kT\frac{R_{S1}}{2}\left(\frac{R_1}{L_1\omega_0}\right)^2$$

总输出噪声 2×，除以 $A_v^2 = R_1^2/(L_1\omega_0)^2$ 和 $4kTR_{S1}$，代入 $L_1\omega_T/2 = R_{S1}/2$：

$$\boxed{\mathrm{NF} = 1 + \frac{\gamma}{2}g_{m1}R_{S1}\left(\frac{\omega_0}{\omega_T}\right)^2 + \frac{2R_{S1}}{R_1}\left(\frac{\omega_0}{\omega_T}\right)^2} \tag{5.157}$$

**与单端 CS [式 (5.101)] 对比：输入管贡献和负载贡献均减半！**

> 【插入 Razavi RF 图 5.71】差分 CS 级被视为跨导器。

**物理原因**：差分跨导 $G_m = (I_1 - I_2)/V_{in} = \omega_T/(\omega_0 R_{S1})$，是单端 $G_m = \omega_T/(2\omega_0 R_S)$ 的两倍。而输入管噪声电流不变 → 等效输入参考噪声电压减半。

**这是差分 CS LNA 最显著的优势——NF 低于单端 CS**，且本就低于差分 CG。差分 CS 的 NF 优势在三种差分拓扑中最为突出。

### 实际约束

**退化电感减半的困难**：键合线（bond wire）的物理长度不可随意缩短 → 最小电感 0.5–1 nH → $L_1/2$ 可能无法用键合线实现。

**替代方案**（图 5.72）：片上退化电感（可精确取小值）+ 将键合线的寄生电感转化为**共模电感**。
- 对称布局下键合线的共模电感不影响差分端口阻抗
- 代价：片上电感 $Q$ 低（串联电阻大）→ 可能恶化 NF

> 【插入 Razavi RF 图 5.72】片上退化电感 + bond wire 转共模的差分 CS LNA。

**Balun 损耗不可忽略** → 式 (5.157) 的理论 NF 优势在实际中被 balun 的 0.5–1 dB 损耗部分抵消。

### 用差分对实现单端转差分

能否省去 balun，用差分对直接完成单端-差分转换？

> 【插入 Razavi RF 图 5.73】(a) 简单差分对做单端转差分，(b) 尾电感谐振中和 $C_P$。

信号加在一输入端、另一输入端接偏置。中低频时 $V_X$ 和 $V_Y$ 呈差分、增益 $g_{m1,2}R_D$。

**高频的两个破坏效应**：

1. **$C_P$（节点 P 寄生电容）衰减并延迟信号**：$M_1$ 的信号经 P 到 $M_2$ 的路径被 $C_P = C_{SB1}+C_{SB2}$ 低通滤波 → $V_X$ 和 $V_Y$ 相位不再精确反相
2. **$C_{GD1}$ 前馈通路**：$M_1$ 的 $C_{GD}$ 提供从栅到漏的非反相直通路径（$M_2$ 无此路径，因其栅极接地） → 两路输出不对称

**补救一**（图 5.73b）：$L_P$ 与 $C_{SB1}+C_{SB2}$ 并联谐振 → 中和 $C_P$ 效应。$L_P$ 可片上实现（$R_P = QL_P\omega_0 \gg 1/g_{m1,2}$）。

> 但 $C_{GD1}$ 前馈无法消除——这是单端转差分的根本非对称性。

### Example 5.26：$L_P$ 该谐振什么电容？

> 【插入 Razavi RF 图 5.74】节点 P 的分压模型。

学生错误地把 $C_{GS2}$ 也计入 $C_P$。**$L_P$ 只应与 $C_{SB1}+C_{SB2}$ 谐振**。

**原因**：$V_P = V_{in} \cdot Z_2/(Z_1+Z_2)$。为实现 $V_P = V_{in}/2$（零相差），需 $Z_1 = Z_2$。$Z_1$ 和 $Z_2$ 各自为 $(g_m+g_{mb})^{-1} \parallel (C_{GS}s)^{-1}$——两者已对称，**不需要**也**不应当**中和 $C_{GS}$。

### Example 5.27：1-to-N Balun——看似聪明实则灾难

> 【插入 Razavi RF 图 5.77】1-to-N balun 用于差分 CS LNA。

学生思路：1-to-N balun 将输入电压放大 $N$ 倍 → 等效源阻抗更优 → NF 更低？

**严酷的现实**：

1-to-N balun 将源阻抗变换为 $N^2 R_S$ → 每半电路需 $R_{in} = N^2 R_S/2$。差分 CS 中 $R_{in} = L_1\omega_T$ → 退化电感须缩至 $1/N^2$。

$$\mathrm{NF} = N^2 \cdot \frac{\gamma}{2} g_{m1} R_S \left(\frac{\omega_0}{\omega_T}\right)^2 + 2N^2 \cdot \frac{R_S}{R_1} \left(\frac{\omega_0}{\omega_T}\right)^2 + 1$$

$$\boxed{\text{NF 前两项被乘 } N^2\text{！}}$$

**物理原因**：$N^2$ 倍的 $L_1$ 缩减 → 跨导 $G_m$ 降低 $N^2$ 倍 → 即使 balun 将 $V_{in}$ 放大了 $N$ 倍，总增益**反而降低了 $N$ 倍**。噪声功率不变、增益降低 → NF 飙升。

**N-to-1 balun 方向呢？** （降压而非升压）→ NF 项乘以 $1/N^2$ → 理论改善。但：
- 片外 balun：退化电感（键合线）需能缩至 $1/N^2$ ——物理不可行
- 片上 balun：非 1:1 匝比设计困难、损耗更高、耦合更低

> 【插入 Razavi RF 图 5.78】非 1:1 balun 的实现：(a) 堆叠螺旋，(b) 嵌入式螺旋。

**教训**：**1:1 balun 是实际中的最佳选择**——升压或降压的 NF"优势"要么被物理约束抵消、要么被非理想因素吞没。

## 5.6.2 其他 IP2 改善方法

外部 balun 的成本/面积和片上 balun 的高损耗/大寄生使**单端 LNA 仍有吸引力**。单端下如何提高 IP2？

### 高通滤波去除 Beat 分量

> 【插入 Razavi RF 图 5.79】一阶高通滤波器去除低频 beat。

二阶交调产生低频 beat 分量（$|f_1-f_2|$）。在 LNA 之后插入一阶 HPF，衰减此低频分量即可有效提升系统 $\mathrm{IP}_2$。

**数值例**：2.4 GHz 频带边缘两个干扰 $f_1=2.4$ GHz、$f_2=2.48$ GHz → beat = 80 MHz。一阶 HPF 衰减 ≈ $2400/80 = 30$ 倍（29.5 dB）。

此衰减足够大 → LNA 的 $\mathrm{IP}_2$ 不再限制整机性能 → 重点转向混频器 $\mathrm{IP}_2$（第 6 章）。

### Example 5.28：Beat 真的在基带内吗？

学生质疑：80 MHz beat 落在 802.11b/g 或蓝牙的基带之外（11b/g 基带仅 $\pm 10$ MHz）→ 不会被混频器搬移到 DC 附近。

**学生正确**。对于 11b/g 直接变频接收机，最坏情况 beat = 10 MHz（$f_1=2.400$ GHz、$f_2=2.410$ GHz）。一阶 HPF 衰减 $2400/10 = 240$ 倍（47.6 dB）。

### 宽带局限

当接收机覆盖极宽频率范围（如 1–10 GHz）时，两个干扰的 beat 可能落在带内 → HPF 无法滤除 → **LNA 成为整机 $\mathrm{IP}_2$ 的真正瓶颈**。此时须结合差分 LNA 或第 6 章的混频器 $\mathrm{IP}_2$ 技术。

## 5.6 节总结

| 方法 | 适用性 | 关键结论 |
|------|--------|---------|
| 差分 CG LNA | 可接受 balun 成本 | NF 低于单端 CG（$2R_{S1}/R_1$ vs $4R_S/R_1$），功耗 4× |
| 差分 CS LNA | 可接受 balun + 片上退化电感 | **NF 最低**——输入管和负载贡献均减半 |
| 差分对 S2D | 省 balun | $C_{GD}$ 前馈无法消除，IP3 低于真差分 |
| 1-to-N balun | — | **灾难**——NF 乘 $N^2$；1:1 为最优 |
| HPF 滤 beat | 单端 LNA、窄带 | 一阶 30× 衰减足够；宽带失效 |

# 5.7 非线性计算（Nonlinearity Calculations）

第 2 章建立了非线性系统的一般理论，本章将其应用于具体 LNA 拓扑——推导 $\alpha_1$、$\alpha_2$、$\alpha_3$ 和 $\mathrm{IP}_3$。

## 隐式微分法

弱静态非线性系统可展开为 $y = \alpha_1 x + \alpha_2 x^2 + \alpha_3 x^3$。在许多电路中难以写出 $y(x)$ 的显式表达式，但可通过**隐式微分**求系数：

$$\alpha_1 = \left.\frac{\partial y}{\partial x}\right|_{x=0}, \quad \alpha_2 = \left.\frac{1}{2}\frac{\partial^2 y}{\partial x^2}\right|_{x=0}, \quad \alpha_3 = \left.\frac{1}{6}\frac{\partial^3 y}{\partial x^3}\right|_{x=0}$$

**关键**：$x=0$ 对应的是偏置点（无信号扰动），此时 $y$ 不一定为零。

> 【插入 Razavi RF 图 5.80】CS 级——$M_1$ 偏置在 $V_{GS0}=V_b$，$V_{in}$ 叠加在此偏置上。

→ 非线性基础（Taylor 展开、IP3、1dB 压缩点）：[[C14.非线性与失配#14.1 非线性|Ch14]]

## 5.7.1 退化 CS 级

> 【插入 Razavi RF 图 5.81】阻性退化 CS 级——$I_D$ 为输出量。

### 系数推导

假设平方律器件 $I_D = K(V_{GS}-V_{TH})^2$，$K = \frac{1}{2}\mu_n C_{ox}W/L$，忽略 CLM 和体效应。

$$V_{GS} = V_{in} - R_S I_D \quad\Rightarrow\quad I_D = K(V_{in} - R_S I_D - V_{TH})^2$$

对 $V_{in}$ 逐次隐式微分，在偏置点取值：

$$\boxed{\alpha_1 = \frac{g_m}{1 + g_m R_S}} \quad \text{（退化跨导，预期结果）}$$

$$\boxed{\alpha_2 = \frac{2K}{(1 + g_m R_S)^3}}$$

$$\boxed{\alpha_3 = \frac{-12 K^2 R_S}{(1 + g_m R_S)^5}}$$

### 最核心的物理洞察

**$R_S=0$ 时 $\alpha_3=0$**（平方律器件无三次非线性——预期结果）。**但 $R_S \neq 0$ 时 $\alpha_3 < 0$**——负号意味着**压缩特性**（compressive）。

平方律器件本应是**扩展特性**（expansive，$\alpha_2>0$ 纯二次），但**电阻退化在平方律器件中创造了三次失真**。这是负反馈的"副作用"——线性化 $G_m$ 的同时引入了三阶项。

### IP3 计算

$$A_{IIP3} = \sqrt{\frac{4}{3}\left|\frac{\alpha_1}{\alpha_3}\right|} = \sqrt{\frac{2 g_m}{3 R_S}} \frac{(1+g_m R_S)^2}{K}$$

$P_{1dB}$ 同表达式，低 9.6 dB（÷ 3.03）。

**$g_m$ 在此仅为偏置值的速记**，不是信号依赖量——否则多项式阶数超过 3。

### Example 5.29：实验室实测 IP3 为何为预测值的一半？

> 【插入 Razavi RF 图 5.82】信号源驱动的 CS 级。

信号发生器内阻 $R_G=50\Omega$，**假定被测电路输入匹配** → 显示电压 = 开路电压的一半（$A_0/2$）。但 CS 级输入阻抗极高 → 实际感测 $A_0$ → 学生读数为电路实际承受电压的一半。

**教训**：IP3 传统上按**可用输入功率**定义，与输入匹配与否有关。实测中需注意源阻抗匹配条件。

### Example 5.30：CG 级的 IP3

> 【插入 Razavi RF 图 5.83】CG 级非线性分析。

CG 级：$V_{GS} = V_b - V_{in} - I_D R_S$。与 CS 相同方法推导：

$$\alpha_1 = \frac{-g_m}{1+g_m R_S} \quad \text{（反相增益）}$$

$$\alpha_2 = \frac{2K}{(1+g_m R_S)^3} \quad \text{（与 CS 相同）}$$

$$\alpha_3 = \frac{+12 K^2 R_S}{(1+g_m R_S)^5} \quad \text{（正号！与 CS 相反）}$$

IP3 公式与 CS 相同。**输入匹配时** $R_S = 1/g_m$，代入得：

$$A_{IIP3} = 4\sqrt{\frac{2}{3}}(V_{GS0} - V_{TH})$$

**物理对比**：CS 和 CG 的 $\alpha_3$ 符号相反——退化 CS 呈压缩特性、退化 CG 呈扩展特性。这源于 $V_{GS}$ 表达式中 $R_S I_D$ 项的符号差异。

## 5.7.2 无退化 CS 级——迁移率退化的影响

次微米器件显著偏离平方律。沟道中垂直和横向电场引起的**迁移率退化**（mobility degradation）修正了 I-V 特性：

$$I_D = \frac{1}{2}\mu_0 C_{ox}\frac{W}{L} \frac{(V_{GS}-V_{TH})^2}{1 + a(V_{GS}-V_{TH})}$$

其中 $a = \frac{\mu_0}{2v_{sat}L} + \theta$（$v_{sat}$ 为载流子饱和速度，$\theta$ 为垂直电场效应）。

分母第二项 $\ll 1$ 时用 $(1+\varepsilon)^{-1} \approx 1-\varepsilon$：

$$I_D \approx K\left[(V_{GS}-V_{TH})^2 - a(V_{GS}-V_{TH})^3\right]$$

代入 $V_{GS} = V_{in} + V_{GS0}$，提取系数：

$$\boxed{\alpha_1 = K[2 - 3a(V_{GS0}-V_{TH})](V_{GS0}-V_{TH})}$$

$$\boxed{\alpha_3 = -K a}$$

### 核心物理洞察

**迁移率退化是短沟道 CS 级三次非线性的根本来源**。纯平方律中 $\alpha_3 = 0$，但迁移率退化引入的 $-(V_{GS}-V_{TH})^3$ 项产生了 $\alpha_3 < 0$（压缩特性）。

这与 5.7.1 节形成鲜明对比：

| 非线性来源 | 机制 | $\alpha_3$ 符号 |
|-----------|------|----------------|
| 退化 CS（$R_S$） | 负反馈创造三阶项 | 负（压缩） |
| 无退化 CS（短沟） | 迁移率退化 | 负（压缩） |

两者在宏观上都表现为压缩，但物理根源完全不同。

### IP3 与过驱动的非单调关系

$$A_{IIP3} = \sqrt{\frac{\frac{8}{3}(V_{GS0}-V_{TH})}{a} - 4(V_{GS0}-V_{TH})^2}$$

> 【插入 Razavi RF 图 5.84】IP3 随过驱动电压的变化——先增后减，存在最大值。

IP3 在 $V_{GS0}-V_{TH} = (3a)^{-1}$ 处达到峰值：

$$\boxed{A_{IIP3,max} = \frac{2}{3a}}$$

**设计启示**：增大过驱动不一定改善线性度——过驱动超过最优值后 IP3 反而下降。这源于 $\alpha_1$ 和 $\alpha_3$ 对过驱动的不同依赖：$\alpha_1$ 受迁移率退化抑制（含 $-3a$ 项），而 $\alpha_3$ 不变。

### Example 5.31：更高阶近似

$(1+\varepsilon)^{-1} \approx 1-\varepsilon+\varepsilon^2$ 用于分母不太小时：

$$\alpha_3 = -Ka[1 - 4a(V_{GS0}-V_{TH})]$$

当 $4a(V_{GS0}-V_{TH}) > 1$ 时 $\alpha_3$ **变号为正** → 扩展特性。这在高过驱动下可能发生——但此时近似本身已不可靠，需完整仿真。

## 5.7.3 差分对与准差分对

> 【插入 Razavi RF 图 5.85】(a) 标准差分对，(b) 准差分对（两个独立 CS 级）。

RF 系统中两种处理差分信号的基本拓扑，**非线性特性截然不同**。

### 准差分对

两个独立 CS 级（无尾电流源耦合），每管的非线性由迁移率退化决定 → IP3 由式 (5.189) 给出（同 5.7.2 节）。三次非线性的唯一来源是器件物理（迁移率退化）。

### 标准差分对——拓扑本身创造三次非线性

差分对的传输函数（平方律器件）：

$$I_{D1} - I_{D2} = \frac{1}{2}\mu_n C_{ox}\frac{W}{L} V_{in} \sqrt{\frac{4I_{SS}}{\mu_n C_{ox}\frac{W}{L}} - V_{in}^2}$$

$|V_{in}| \ll \sqrt{I_{SS}/(\mu_n C_{ox}W/L)}$ 时 Taylor 展开：

$$\boxed{\alpha_1 = \sqrt{\mu_n C_{ox}\frac{W}{L} I_{SS}}}$$

$$\boxed{\alpha_3 = -\left(\mu_n C_{ox}\frac{W}{L}\right)^{3/2}\frac{1}{8\sqrt{I_{SS}}}}$$

IP3：

$$\boxed{A_{IIP3} = \sqrt{6}(V_{GS0} - V_{TH})}$$

### 最核心的洞察

**即使器件是平方律的（$\alpha_{3,\text{device}}=0$），标准差分对仍然有 $\alpha_3 \neq 0$。** 三次非线性来自**尾电流源的约束**——$I_{D1}+I_{D2}=I_{SS}$ 强制了两管电流的非线性耦合，在传输函数中引入平方根项，展开后自然产生 $V_{in}^3$ 项。

**这正是为什么图 5.65(b) 的差分 CS LNA 不使用尾电流源——准差分对（quasi-differential pair）的线性度更优。**

| | 标准差分对 | 准差分对 |
|---|---|---|
| $\alpha_3$ 来源 | 尾电流约束 + 迁移率退化 | 仅迁移率退化 |
| $\alpha_3$（平方律） | $\neq 0$（拓扑造成） | $=0$ |
| 电压裕度 | 有尾电流源 → 消耗裕度 | 无尾电流源 → 裕度更大 |
| 低 $V_{DD}$ 适用性 | 较差 | **更优** |

**设计准则**：线性度优先时选用准差分对（两个独立 CS 级），省去尾电流源同时获得更高的 IP3 和更大的电压裕度——这对低电压工艺尤为重要。

## 5.7.4 退化差分对

> 【插入 Razavi RF 图 5.86】退化差分对——两侧各串 $R_S$。

退化差分对是电感退化 CS LNA（5.3.4 节）的非线性分析基础（$R_S$ 可理解为退化电感在 $\omega_0$ 处的等效阻抗）。

### 系数推导

$I_{D1}+I_{D2}=2I_0$，$\partial(I_{D1}-I_{D2})/\partial V_{in}=2\partial I_{D1}/\partial V_{in}$。由 KVL 和平方律关系：

$$V_{in} - R_S I_{D1} + R_S I_0 = \frac{1}{\sqrt{K}}(\sqrt{I_{D1}} - \sqrt{I_{D2}})$$

隐式微分，在 $V_{in}=0$（$I_{D1}=I_{D2}=I_0$）处取值：

$$\boxed{\alpha_1 = \frac{1}{R_S + \frac{2}{g_m}}}$$

**$\alpha_2 = 0$** —— 差分对称性确保偶阶项消去，这是差分结构最核心的线性度优势。

$$\boxed{\alpha_3 = \frac{-3}{(R_S + \frac{2}{g_m})^4 \cdot g_m I_0^2} \cdot \frac{1}{6}}$$

其中 $g_m = 2I_0/(V_{GS0}-V_{TH})$。

### IP3

$$A_{IIP3} = \frac{2I_0}{3}\sqrt{g_m\left(R_S + \frac{2}{g_m}\right)^3}$$

### 物理含义

- **$\alpha_2 = 0$ 的优雅**：二阶导数在 $V_{in}=0$ 时自动消失——因为 $\partial I_{D1}/\partial V_{in} = -\partial I_{D2}/\partial V_{in}$，两管电流变化率等大反向，使二阶导的对称项对消。
- **退化提升 IP3**：$R_S \uparrow$ → 分母 $(R_S+2/g_m)$ 增大 → $\alpha_3$ 减小（$\propto 1/(R_S+2/g_m)^4$）。但 $\alpha_1$ 也下降 → 这是增益-线性度的经典折中。
- **与单端退化 CS 对比**：差分结构中退化电阻对 $\alpha_3$ 的抑制更强（分母四次方 vs 单端的五次方但含 $R_S$ 更复杂），且天然无 $\alpha_2$。

## 5.7 节总结

| 拓扑 | $\alpha_3$ 来源 | $\alpha_2$ | 关键公式 |
|------|----------------|-----------|---------|
| 退化 CS（平方律） | **$R_S$ 反馈创造** | $\neq 0$ | $\alpha_3 = -12K^2 R_S/(1+g_m R_S)^5$ |
| 无退化 CS（短沟） | **迁移率退化** | $\neq 0$ | $\alpha_3 = -Ka$, IP3 峰值为 $2/(3a)$ |
| 标准差分对（平方律） | **尾电流约束** | $=0$ | $A_{IIP3} = \sqrt{6}(V_{GS0}-V_{TH})$ |
| 准差分对 | 迁移率退化 | $\neq 0$（每管） | 同式 (5.189)，但无尾电流 $\to$ 裕度更大 |
| **退化差分对** | $R_S$ + 尾电流 | **$=0$** | $A_{IIP3} = (2I_0/3)\sqrt{g_m(R_S+2/g_m)^3}$ |

**统一的物理图像**：三次非线性的来源有三种——(a) 反馈/退化的"副作用"、(b) 器件物理（迁移率退化）、(c) 拓扑约束（尾电流固定和）。叠加后由系数法统一量化。
