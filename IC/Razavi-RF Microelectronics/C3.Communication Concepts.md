# 调制基础

调制 = 将基带信号（频谱在 DC 附近，如语音 20 Hz–20 kHz）搬移到载频 $\omega_c$ 附近的通带信号。
![[Pasted image 20260714030021.png]]
通用调制波形：
$$x(t) = a(t) \cos[\omega_c t + \theta(t)]$$
$a(t)$ = 幅度调制，$\theta(t)$ = 相位调制。解调/检测 = 逆过程。
![[Pasted image 20260714030035.png]]
## 三大指标（彼此制约）
![[Pasted image 20260714030052.png]]

| 指标 | 含义 | 代价 |
|------|------|------|
| **可检测性** | 给定噪声下解调质量 | 电平越密 → 噪声容限越低 |
| **带宽效率** | 每 Hz 携带的信息率 | 高效率调制 → 电平密集 → 检测性差 + 需线性 PA |
| **功率效率** | 可用非线性 PA 与否 | 非线性 PA 高效率但只能处理恒包络信号 |
物理：这是通信系统设计的铁三角——三个指标不可能同时最优。

# 模拟调制
## 幅度调制（AM）
![[Pasted image 20260714030259.png]]
$$x_{AM}(t) = A_c[1 + m \cdot x_{BB}(t)]\cos\omega_c t$$
- $m$ = 调制指数
- 频谱 = 基带谱搬移到 $\pm\omega_c$，带宽 = 基带的 **2 倍**
- 缺点：需线性 PA（幅度载信息），对噪声敏感

## 相位/频率调制（PM/FM）
PM：相位 $\propto x_{BB}(t)$
$$x_{PM}(t) = A_c \cos[\omega_c t + m \cdot x_{BB}(t)]$$
![[Pasted image 20260714101107.png|332]]

FM：频率偏移 $\propto x_{BB}(t)$
$$x_{FM}(t) = A_c \cos\left[\omega_c t + m \int_{-\infty}^t x_{BB}(\tau) d\tau\right]$$

> FM 定义是**瞬时频率**与 $x_{BB}(t)$ 成正比：$\omega_{inst} = \omega_c + m \cdot x_{BB}(t)$。而瞬时频率 = 总相位的导数 → 必须有 $\frac{d\phi}{dt} = \omega_c + m x_{BB}$ → 积分得 $\phi = \omega_c t + m\int x_{BB}$。式中的 $\int$ 不是人为加的——它是"频率正比于 $x_{BB}$"这个定义在相位域的对偶表达。

- **恒包络** → 可用高效非线性 PA
- FM 正弦调制时 $x_{BB}=A_m\cos\omega_m t$：调制指数 $\beta = mA_m/\omega_m$
- **窄带 FM**（$\beta \ll 1$ rad）：频谱近似 AM 但边带极性相反

## AM vs FM 边带的物理差异
窄带 FM（$\beta \ll 1$）的展开式与 AM 结构相似，但**下边带符号相反**：
$$x_{AM} \propto {\color{red}{+}}\cos(\omega_c-\omega_m)t + {\color{red}{+}}\cos(\omega_c+\omega_m)t$$
$$x_{NBFM} \propto {\color{red}{-}}\cos(\omega_c-\omega_m)t + {\color{red}{+}}\cos(\omega_c+\omega_m)t$$

这不仅是数学符号差异——它决定了两个边带在复平面上的**旋转方向**，进而决定了调制类型。

### 相量视角：旋转方向决定合成结果
将载波视为静止参考相量。上边带（$\omega_c+\omega_m$）以 $+\omega_m$ 相对载波旋转（正转），下边带（$\omega_c-\omega_m$）以 $-\omega_m$ 相对载波旋转（反转）。
![[Pasted image 20260714205106.png|697]]
- **AM（两边带同号）**：$\cos(-\omega_m t) = \cos(+\omega_m t)$，两者在实轴上的投影始终同向 → 合成相量始终与载波**平行** → 仅改变载波的长度 → **纯幅度调制**

- **NBFM（两边带异号）**：$-\cos(-\omega_m t) = -\cos(+\omega_m t)$，两者在实轴上的投影始终反向 → 实轴分量抵消，虚轴分量叠加 → 合成相量始终与载波**正交** → 仅改变载波的瞬时相位角 → **纯相位调制**

物理本质：$\cos(-\omega_m t)$ 和 $\cos(+\omega_m t)$ 在 $t=0$ 时刻值相同——AM 的同号使二者加强产生幅度偏移，NBFM 的异号使二者在此方向抵消，取而代之的是 $\sin$ 分量（相位偏移方向）叠加。
![[Pasted image 20260714201138.png]]

### 射频设计中的应用：硬限幅器去 AM 留 FM
这一差异直接解释了过驱动差分对的频谱再生行为（教材例 3.4）。输入 = 大载波 $A_c\cos\omega_c t$ + 小边带 $\cos(\omega_c+\omega_m)t$ → 分解为两个对称频谱：

- 同号边带谱 → AM 分量 → 被硬限幅消除（限幅器去除幅度变化）
- 异号边带谱 → FM 分量 → 完整通过（限幅器不改变过零点）

输出因此重新出现了 $\omega_c-\omega_m$ 分量——这是非线性电路从单边带输入产生镜像边带的物理根源。

# 数字调制

数字调制 = 模拟调制的离散版本：ASK ↔ AM、PSK ↔ PM、FSK ↔ FM。
![[Pasted image 20260714201950.png|697]]
**ASK（幅移键控）**：基带比特 0/1 直接乘以载波 → 数据为 1 时载波通过，为 0 时输出为零（OOK）。
$$x_{ASK}(t) = D(t) \cdot A_c\cos\omega_c t, \quad D(t) \in \{0,1\}$$
**PSK（相移键控）**：基带比特映射为 ±1（零均值）→ 乘以载波 → 比特翻转时基带符号改变 → 载波相位跳变 180°。
$$x_{PSK}(t) = D(t) \cdot A_c\cos\omega_c t, \quad D(t) \in \{-0.5, +0.5\}$$

物理本质：ASK 和 PSK 均通过**基带 × 载波**（乘法器/混频器）产生——ASK 是基带直流值 0/1 的通断控制，PSK 是基带正/负值的反相控制。两者本质相同，区别仅在于基带电平的偏置：ASK 有 DC 偏置（含载波分量），PSK 零均值（载波被抑制）。

**FSK（频移键控）**：基带比特直接控制振荡器频率 → 数据为 0 时输出 $\omega_1$，为 1 时输出 $\omega_2$。无法用简单乘法实现——需要 VCO 或双振荡器切换。
$$x_{FSK}(t) = A_c\cos\omega_1 t \ \text{(数据=0)} \quad \text{或} \quad A_c\cos\omega_2 t \ \text{(数据=1)}$$
FSK 本质是 FM 的数字版——恒定包络 → 可用非线性 PA。代价是带宽较宽（两频点间距 + 边带）。

## 码间干扰（ISI）
**成因**：单个矩形脉冲通过带宽受限系统 → 时域产生指数拖尾 → 拖尾延伸到相邻时隙 → 当前比特的判决电平被前后比特的拖尾抬高/压低 → 误码率上升。存在噪声与 ISI 的折衷：降低带宽减少积分噪声，但 ISI 增大。
![[Pasted image 20260714231332.png]]
**物理根源**：一个信号不能同时在时域和频域上受限——时域矩形脉冲 ↔ 频域无限延展的 sinc²；反之，频域受限的信号 ↔ 时域无限延展。带宽受限系统截除部分频谱 → 等价于时域脉冲展宽 → ISI。

### 随机二进制序列的频谱
![[Pasted image 20260714231346.png]]
随机序列模型（$a_n = \pm 1$，以速率 $1/T_b$ 生成）：
$$x_{BB}(t) = \sum_{n=0}^{\infty} a_n p(t - nT_b)$$
其中 $p(t)$ 为基本脉冲形状。序列的功率谱密度由 $p(t)$ 的傅里叶变换唯一决定：
$$S_x(f) = \frac{1}{T_b}|P(f)|^2$$

对于高度为 1、宽度为 $T_b$ 的矩形脉冲（$a_n = \pm 1$）：
$$P(f) = T_b\frac{\sin\pi f T_b}{\pi f T_b}, \qquad S_x(f) = T_b\left(\frac{\sin\pi f T_b}{\pi f T_b}\right)^2$$

这是一个 **sinc² 谱**——在比特率 $1/T_b$ 整数倍处有零点，但有大幅旁瓣（第一旁瓣仅低于主瓣 ~13 dB）→ 频谱宽。
低通滤波器截除高阶旁瓣 → 频域截断 → 时域拖尾 → ISI。
![[Pasted image 20260715095020.png]]
下变频到 RF 后（如 PSK）：$x_{PSK}(t) = x_{BB}(t)\cos\omega_c t$，基带 sinc² 谱搬移到 $\pm\omega_c$。

### 脉冲整形
![[Pasted image 20260715095058.png]]
脉冲整形不消除时域重叠——恰恰相反，整形后的脉冲在时域上重叠得**更多**。
它消除 ISI 的机制是**操控过零点**。

**矩形脉冲 vs sinc 脉冲**：
- 矩形脉冲：时域不重叠（各占 $T_b$），但频域无限 → 经带宽受限系统 → 拖尾无过零点设计 → 邻位采样时刻非零 → ISI
- sinc 脉冲：频域砖墙（最小带宽），时域 $\frac{\sin(\pi t/T_b)}{\pi t/T_b}$ → 脉冲严重重叠，但在 $t=kT_b\ (k\neq 0)$ 处**恰好为零**
![[Pasted image 20260715095126.png]]
**数学条件**（Nyquist 第一准则）：$x_{BB}(t) = \sum a_n p(t-nT_b)$ 在 $t=mT_b$ 采样时，第 $n$ 个脉冲的贡献为 $a_n \cdot p((m-n)T_b)$。消除 ISI 要求：
$$p(0) = 1, \qquad p(kT_b) = 0 \quad (k \neq 0)$$
即脉冲在非自身采样时刻的过零点恰好对准其他符号的采样时刻——在采样瞬时的来自邻位脉冲的干扰恰好为零。

**奈奎斯特信令**：sinc 脉冲天然满足过零点条件。代价：sinc 脉冲难以实际生成（需极其精确的过零点位置），且拖尾按 $1/t$ 衰减——对定时抖动极其敏感。

**升余弦脉冲**（实用方案）：
$$p(t) = \frac{\sin(\pi t/T_S)}{\pi t/T_S} \cdot \frac{\cos(\pi\alpha t/T_S)}{1 - 4\alpha^2 t^2/T_S^2}$$

其中 $T_S$ 为符号周期，$\alpha \in [0,1]$ 为滚降因子（roll-off factor）：
- $\alpha = 0$ → 退化为纯 sinc（砖墙频谱，最窄带宽，但脉冲拖尾衰减最慢）
- $\alpha = 1$ → 频谱最宽（带宽翻倍），但脉冲拖尾按 $1/t^3$ 衰减——远快于 sinc
- 典型值 $\alpha = 0.3\sim 0.5$（带宽与定时容忍度的折衷）
![[Pasted image 20260715095223.png]]
升余弦脉冲的频谱在 $|f| < (1-\alpha)/(2T_S)$ 内平坦，在 $(1-\alpha)/(2T_S) < |f| < (1+\alpha)/(2T_S)$ 内按余弦滚降，$|f| > (1+\alpha)/(2T_S)$ 为零。总占用带宽：
$$BW = \frac{1+\alpha}{T_S}$$

物理：$\alpha$ 控制"多余带宽"——以额外的带宽换取更快的拖尾衰减。$\alpha$ 越大 → 频谱过渡越平缓 → 时域拖尾衰减越快 → 对定时误差越不敏感。这是频域与定时精度之间的又一次折衷。

## 信号星座图
星座图 = 将调制信号在**基函数**（basis function）张成的抽象坐标空间中可视化。每个星座点对应一个可能的符号，其坐标即基函数前的系数。
物理意义：**两点间距 = 噪声容限**——间距越大，噪声需要更大才能使两个符号混淆。

### BPSK / ASK
两者共用同一个基函数 $\cos\omega_c t$，区别在于系数取值：

$$x_{BPSK}(t) = a_n\cos\omega_c t, \quad a_n = \pm 1 \qquad x_{ASK}(t) = a_n\cos\omega_c t, \quad a_n = 0,1$$

均为**一维**星座——所有点沿同一条直线排列。BPSK 两点对称分布在原点两侧（零均值），间距 = 2；ASK 两点在 0 和 1（含 DC），间距 = 1。
噪声使点模糊为"云团"→ 两个云团靠近 → 判决出错概率上升。
![[Pasted image 20260715100149.png]]
BPSK 优于 ASK 的原因：同样峰值功率下 BPSK 点间距是 ASK 的两倍 → 噪声容限高 6 dB。

### FSK
用**两个正交基函数**（$\cos\omega_1 t$ 和 $\cos\omega_2 t$），为**二维**星座：

$$x_{FSK}(t) = a_1\cos\omega_1 t + a_2\cos\omega_2 t, \quad (a_1,a_2) = (1,0) \text{ 或 } (0,1)$$

两点分别在 $(1,0)$ 和 $(0,1)$，间距 = $\sqrt{2}$。<br>![[Pasted image 20260715100207.png]]
**物理对比**：FSK 的两点间距小于 BPSK 的间距（$\sqrt{2} < 2$）→ **BPSK 比 FSK 更抗噪声**。这是星座图作为分析工具的核心价值——几何距离直接转化为误码性能的比较。

### EVM（误差矢量幅度）
定量衡量星座点偏离理想位置的程度。对 $N$ 个测量样本，每个误差矢量幅度为 $e_j$：

$$\text{EVM}_1 = \frac{1}{V_{rms}}\sqrt{\frac{1}{N}\sum_{j=1}^N e_j^2}, \qquad \text{EVM}_1|_{\mathrm{dB}} = 20\log(\text{EVM}_1)$$
$$\text{EVM}_2 = \frac{1}{P_{avg}} \cdot \frac{1}{N}\sum_{j=1}^N e_j^2, \qquad \text{EVM}_2|_{\mathrm{dB}} = 10\log(\text{EVM}_2)$$

- $\text{EVM}_1$ = RMS 误差电压 / RMS 信号电压（电压域，dB 乘 20）
- $\text{EVM}_2$ = 均方误差功率 / 平均信号功率（功率域，dB 乘 10）
![[Pasted image 20260715100227.png|318]]
两者等价但归一化方式不同——$\text{EVM}_1$ 便于与电压测量关联，$\text{EVM}_2$ 便于与功率测量关联。EVM 综合反映**噪声 + 非线性失真 + ISI + I/Q 失配**——是发射机和接收机信号质量的统一度量。现代通信标准（如 802.11）以 EVM 作为发射质量的核心合规指标。

## 正交调制
脉冲整形可将 BPSK 带宽压缩至约 $2/T_b$。**QPSK** 进一步将带宽减半——核心原理：将连续比特两两分组，分配到载波的两个正交分量（I/Q）上。

### QPSK 的调制
![[Pasted image 20260715143911.png|697]]
串并转换（S/P）将奇数位与偶数位分开 → 每路比特宽度拉伸为 $2T_b$ → 符号率 = 比特率 / 2 → 带宽减半。
$$x_{QPSK}(t) = b_{2m}A_c\cos\omega_c t - b_{2m+1}A_c\sin\omega_c t, \quad b_k = \pm 1$$

I/Q 正交 → 两路信号可独立检测而不互相干扰。星座图为正方形四点 $(\pm 1,\pm 1)$，每符号携带 2 bits。换用 $\alpha_1,\alpha_2$ 记法：$x(t) = \alpha_1 A_c\cos\omega_c t + \alpha_2 A_c\sin\omega_c t$，$(\alpha_1,\alpha_2) \in \{(\pm1,\pm1)\}$。
![[Pasted image 20260715143957.png|697]]
物理：QPSK 的带宽效率是 BPSK 的两倍——不是靠压缩脉冲，而是靠**两路正交并行传输**，每路各自以一半速率独立调制。

### QPSK 相位失配
若 I 路载波存在相位误差 $\theta$：
$$x(t) = \alpha_1 A_c\cos(\omega_c t + \theta) + \alpha_2 A_c\sin\omega_c t$$
展开为 $\beta_1 A_c\cos\omega_c t + \beta_2 A_c\sin\omega_c t$，四点变为：
$$(\beta_1,\beta_2) = (+\cos\theta,\ 1-\sin\theta),\ (+\cos\theta,\ -1-\sin\theta),\ (-\cos\theta,\ 1+\sin\theta),\ (-\cos\theta,\ -1+\sin\theta)$$
![[Pasted image 20260715144050.png]]
星座图从正方形扭曲为平行四边形——点间距不均，判决边界偏移 → 误码率升高。
I/Q 失配在收发机中是核心性能瓶颈。

### OQPSK（偏移 QPSK）
**动机**：QPSK 中 I/Q 同时翻转 → 180° 相位跳变 → 经脉冲整形后产生大幅包络变化 → 需要线性 PA。
![[Pasted image 20260715144414.png|375]]
![[Pasted image 20260715144636.png|375]]
**方案**：I/Q 两路数据在时间上偏移半个符号周期（$T_S/2$）→ 两路不会同时翻转 → 最大相位跳变限制为 $\pm 90^\circ$ → 包络变化显著减小。频谱与 QPSK 相同。
![[Pasted image 20260715144619.png|550]]
**代价：不支持差分编码**（差分解码需要相邻符号的相位差信息，OQPSK 的偏移打乱了这一关系）→ 必须相干检测。

### $\pi/4$-QPSK
**方案**：使用两个 QPSK 星座，互相旋转 45°，交替使用：
$$x_1(t) = A_c\cos\left(\omega_c t + k\frac{\pi}{4}\right)\ (k\text{ 为奇数}), \qquad x_2(t) = A_c\cos\left(\omega_c t + k\frac{\pi}{4}\right)\ (k\text{ 为偶数})$$
连续两个符号永远来自不同星座 → 最大相位跳变为 135°（比 QPSK 的 180° 小 45°）。支持差分编码。在最大相位跳变和包络变化方面介于 QPSK 和 OQPSK 之间。
![[Pasted image 20260715144924.png|425]]
![[Pasted image 20260715145027.png|425]]

| 变种               | 最大相位跳变 | 包络变化 | 可差分检测 | 典型应用          |
| ---------------- | ------ | ---- | ----- | ------------- |
| QPSK             | 180°   | 大    | 可     | 基础方案          |
| **OQPSK**        | 90°    | 小    | 否     | IS-95 CDMA 上行 |
| **$\pi/4$-QPSK** | 135°   | 中    | 可     | —             |

物理：相位跳变角 = 载波在星座图上两点间的路径转角。跳变越大 → 轨迹经过或接近原点 → 瞬时幅度越趋近零 → 包络变化越剧烈 → PA 线性度要求越高。三种变种是这个单一物理量的不同折衷。
## GMSK / GFSK
基带脉冲先经高斯滤波器平滑 → 再驱动 FM 调制器：
$$x_{GMSK}(t) = A_c \cos\left[\omega_c t + m \int x_{BB}(t) * h(t)\, dt\right]$$
![[Pasted image 20260715145315.png|391]]

- GMSK（GSM）：$m=0.5$
- GFSK（Bluetooth）：$m=0.28\sim 0.35$
- **恒包络** → 可用高效非线性 PA（Class E/F）

**为什么高斯滤波引入 ISI**：高斯脉冲响应 $h(t) = \frac{1}{\sqrt{2\pi}\sigma}e^{-t^2/2\sigma^2}$ 无过零点结构——拖尾永远非零。矩形基带脉冲经高斯滤波后被"抹圆"并展宽 → 延伸到相邻时隙且在邻位采样时刻非零 → ISI。这与升余弦脉冲整形有本质区别：

| | 升余弦 | 高斯滤波 |
|------|--------|----------|
| 设计目标 | 零 ISI + 紧致频谱 | 紧致频谱 + 恒包络 |
| 过零点 | $p(kT_S) = 0$（Nyquist 准则） | **无此约束** |
| ISI 来源 | 仅来自定时抖动 | 滤波器本身的设计代价 |

BT 乘积控制折衷：$BT$ 大 → 带宽宽 → ISI 小；$BT$ 小 → 频谱紧致 → ISI 大。GSM 选 $BT = 0.3$——**放弃过零点约束，用轻微 ISI 换取极窄带宽**，这是两条不同的脉冲整形哲学。

## QAM
QPSK 的推广——每个正交分量允许多幅值：
$$x_{16QAM}(t) = \alpha_1 A_c \cos\omega_c t - \alpha_2 A_c \sin\omega_c t, \quad \alpha_{1,2} = \pm 1,\pm 2$$
![[Pasted image 20260715145739.png]]

| 调制 | 星座点数 | 带宽（相对 BPSK） | 802.11 应用 |
|------|---------|-------------------|-------------|
| BPSK | 2 | 1× | 6, 9 Mb/s |
| QPSK | 4 | 1/2× | 12, 18 Mb/s |
| 16QAM | 16 | 1/4× | 24, 36 Mb/s |
| 64QAM | 64 | 1/8× | 48, 54 Mb/s |

物理：星座点密度 ↑ → 带宽效率 ↑ → 噪声容限 ↓ + 包络变化 ↑ → 需更线性的 PA。

## 正交频分复用（OFDM）
### 问题引出：多径传播
无线环境中信号经多条路径（直射 + 反射）到达接收机 → 各路延迟不同（"时延扩展"）→ 天线接收的是多路信号的叠加 → 基带出现同一数据的多个时移副本 → **多径 ISI**。
![[Pasted image 20260715155954.png|341]]
恶化条件：时延扩展越大 或 数据率越高。经验法则：室内通信数据率 > ~10 Mb/s 时多径效应开始显著。

### 实现方法
核心思想：将高速串行数据分解为 $N$ 路低速并行流 → 每路符号率 = $r_b/N$ → 每路子载波的符号周期拉伸 $N$ 倍 → 对时延扩展的容忍度提升 $N$ 倍。总带宽与总数据率不变。
![[Pasted image 20260715160018.png]]
### 峰均比（PAR）
$N$ 个子载波在某些时刻同相叠加（瞬时大幅值）、某些时刻相消（小幅度）→ OFDM 信号有**极大的包络变化**——即使每个子信道本身的调制是恒包络的。
![[Pasted image 20260715160055.png|697]]

$$PAR = \frac{\max[x^2(t)]}{\overline{x^2(t)}} \approx 2\ln N \quad (N \text{ 较大时})$$

$N = 52$ → PAR ≈ 7.9 dB。三大因素共同导致高 PAR：(a) 基带脉冲整形、(b) 幅度调制（QAM）、(c) OFDM 本身的多载波叠加。

**射频设计后果**：OFDM 迫使 PA 工作在大回退（back-off）状态——64QAM OFDM（802.11a）平均功率须低于 $P_{1dB}$ 约 8 dB → 峰值功率被限制在 PA 压缩区以下 → PA 效率极低 → 这是 OFDM 的核心代价：**以 PA 效率换取多径免疫力**。
# 频谱再生
变包络信号通过非线性 PA → 输出频谱在 $\omega_c$ 附近比输入更宽 → 污染邻信道。这是调制选择直接决定 PA 线性度要求的物理桥梁。

### 恒包络信号 → 不展宽
![[Pasted image 20260715160800.png]]
输入 $x(t) = A_c\cos[\omega_c t + \phi(t)]$，经三阶非线性：
$$\begin{aligned}
y(t) &= \alpha_3 x^3(t) = \alpha_3 A_c^3 \cos^3[\omega_c t + \phi(t)] \\[2pt]
&= \frac{\alpha_3 A_c^3}{4} {\color{red}\cos[3\omega_c t + 3\phi(t)]} + \frac{3\alpha_3 A_c^3}{4} {\color{blue}\cos[\omega_c t + \phi(t)]}
\end{aligned}$$

第一项在 $3\omega_c$（远高于信号频带，被滤波）；第二项是原始信号的幅度缩放——**频谱形状与输入完全一致**，不发生展宽。

### 变包络信号 → 频谱再生
![[Pasted image 20260715160815.png]]
输入用 I/Q 表示 $x(t) = x_I(t)\cos\omega_c t - x_Q(t)\sin\omega_c t$，经三阶非线性：
$$\begin{aligned}
y(t) &= \alpha_3 [x_I\cos\omega_c t - x_Q\sin\omega_c t]^3 \\
&= \alpha_3 x_I^3 \cdot \frac{\cos 3\omega_c t + {\color{red}3\cos\omega_c t}}{4}
   - \alpha_3 x_Q^3 \cdot \frac{-\cos 3\omega_c t + {\color{red}3\sin\omega_c t}}{4} + \cdots
\end{aligned}$$

关注 $\omega_c$ 项（系数含 3 的分量）：输出在 $\omega_c$ 附近包含 **$x_I^3(t)$ 和 $x_Q^3(t)$ 的频谱**。

**展宽的数学根源**：时域立方 = 频域**自卷积** → $\mathcal{F}\{x_I^3\} = X_I(f) * X_I(f) * X_I(f)$ → 卷积展宽频谱：
- $x_I(t)$ 的带宽为 $B$ → $x_I^3(t)$ 的带宽为 **$3B$**
- 物理：立方的非线性程度远强于线性放大——高频分量被三次方放大更多 → 边带向外扩展

### 案例对比

|                              | 恒包络                                                   | 变包络                                           |
| ---------------------------- | ----------------------------------------------------- | --------------------------------------------- |
| 输入                           | $A_c\cos[\omega_c t + \phi(t)]$                       | $x_I\cos\omega_c t - x_Q\sin\omega_c t$       |
| $\alpha_3$ 在 $\omega_c$ 处的产物 | $\frac{3}{4}\alpha_3 A_c^3\cos[\omega_c t + \phi(t)]$ | $\frac{3}{4}\alpha_3 x_I^3\cos\omega_c t$ + … |
| 频谱变化                         | 仅幅度缩放，形状不变                                            | **展宽**（$x_I^3$ 的带宽 > $x_I$ 的带宽）               |
| 原因                           | $A_c$ 是常数 → $A_c^3$ 仍是常数                              | $x_I(t)$ 是时变信号 → $x_I^3(t)$ 频谱更宽              |

**射频设计含义**：即使基带已脉冲整形到紧致带宽，只要信号有包络变化 → $\alpha_3$ 使频谱再生 → 邻信道干扰 → 标准规定频谱掩模 → 迫使使用线性 PA 或线性化技术。这是第 3 章与第 12 章（PA 设计）之间的直接链路。

# 移动射频通信
## 多径衰落
多路信号以不同相移到达 → 相消干涉 → 接收幅度呈 **Rayleigh 分布** → 约 6% 时间低于均值 > 10 dB。

时延扩展 $\Delta\tau$ 导致频率选择性衰落：$\Delta\tau$ 小 → 平坦衰落；$\Delta\tau$ 大（可达几 μs）→ 选择性衰落带宽数百 kHz。

## 分集技术
- **空间分集**：多天线（间距 $\gg \lambda$）
- **频率分集**：多载频
- **时间分集**：多次传输 + 交织

物理本质：衰落是频率/时间/空间上的局部现象——在不同维度上复制信息是克服衰落的唯一途径。

## 多普勒效应
移动台运动 → 接收频率偏移 → 对相干解调构成挑战。与载频和速度成正比。

# 多址技术
## 双工方式
| | TDD | FDD |
|------|-----|-----|
| 收发 | 同频、分时 | 不同频、同时 |
| 隔离 | RF 开关（< 1 dB 损耗） | 双工滤波器（~3 dB 损耗） |
| 问题 | 相邻 TX 干扰 RX | TX 泄漏到 RX（~50 dB 隔离） |

## FDMA / TDMA / CDMA
|       | FDMA          | TDMA      | CDMA                      |
| ----- | ------------- | --------- | ------------------------- |
| 维度    | 频率            | 时间        | 码字（Walsh）                 |
| 容量    | 硬上限（总 BW/信道宽） | 硬上限（时隙数）  | **软上限**（用户 ↑ → 噪声地板 ↑）    |
| PA 省电 | 不可关断          | 可关断（时隙间隙） | 可关断                       |
| 功率控制  | 不关键           | 不关键       | **关键**（远近效应，电平须在 ~1 dB 内） |

**CDMA 扩频/解扩**：比特 × Walsh 码（N chip）→ 带宽展宽 N 倍 → 接收端乘同码解扩，期望信号恢复、干扰仍展宽为白噪声。远近效应是 CDMA 的致命弱点。

# 差分相移键控

将信息编码在**相邻比特的相位差**中而非绝对相位 → 允许非相干解调（不需恢复绝对载波相位）。

编码规则：$D_{in}=1$ → $D_{out}$ 不变，$D_{in}=0$ → $D_{out}$ 翻转。
