# 接收机设计基础
## 恶劣的通信环境
每用户信道带宽极窄（GSM: 200 kHz）→ 香农上限低速率 → 必须编码+压缩+高效调制。RF 侧：TX 窄带调制防邻道泄漏，RX 在强干扰中提取微弱信号。

## 为什么不能直接 RF 信道选择
GSM 900 MHz 下邻道干扰强 50–60 dB → 信道选择 RF 滤波器 Q 需百万级（例 4.1: 35 dB @ 400 kHz 偏置 → Q ≈ 63,200）。且载频随时变化 → 中心频率须可变 → 不可行。

**结论**：信道选择必须推后到中心频率大幅降低之处。此前所有级须承受全量未滤波干扰 → 线性度由这些级决定。

## 频带 vs 信道选择
| | 频带选择 | 信道选择 |
|------|----------|----------|
| 位置 | 前端无源 BPF | 链路末端低 IF/基带 |
| 对象 | 带外干扰 | 带内干扰 |
| 损耗 | 0.5–1 dB | — |
| 物理 | 选择性 ↑ ⇔ 损耗 ↑ → NF ↑ | 中心频率低 → Q 值合理 |
![[Pasted image 20260716190254.png|542]]
前端每 1 dB 损耗直接加在整机 NF 上（Friis 第一项）→ 被迫接受中等选择性。

## 双工器
FDD 系统 TX/RX 并存（CDMA 功率控制必需）。TX 路径 2 dB 损耗 → 1 W PA 输出中 ~370 mW 耗散在双工器内——超过 RX 链路总功耗。RX 带外抑制仅 ~30 dB @ 20 MHz 偏置。
![[Pasted image 20260716190317.png|310]]

## TX-RX 泄漏
双工器 TX-RX 隔离仅 ~50 dB → 1 W TX 泄漏到 LNA 端 = **−20 dBm** → LNA 直接承受巨大带内干扰。
![[Pasted image 20260716190353.png|337]]
物理：**LNA 是 TX 泄漏的第一个受害者，也是最坚固的屏障**——它之后的 BPF 可以保护后续级，但无法救 LNA 本身。
![[Pasted image 20260716190643.png|457]]

# 外差接收机
## 下变频原理
信号 × 本地振荡 $A_0\cos\omega_{LO}t$ → 频域卷积 → 频谱搬移到 $\pm(\omega_{in} \pm \omega_{LO})$ → LPF 去和频 → 保留 $\omega_{IF} = |\omega_{in} - \omega_{LO}|$。混频器本身噪声高 → 前置 LNA。
![[Pasted image 20260716190900.png]]
覆盖频带的两种方案：
- **恒定 LO**：各信道下变频到不同 IF → 需要可变中心频率的 IF 滤波器
- **恒定 IF**（最常用）：可变 LO → 所有信道下变频到同一 IF → IF 路径设计简化，但需频率合成器
![[Pasted image 20260716191300.png|441]]

## 镜像问题——外差的必然代价
IF 分量：$A\cos\omega_{IF}t = A\cos(\omega_{in} - \omega_{LO})t = A\cos(\omega_{LO} - \omega_{in})t$。余弦是偶函数 → $\omega_{in} > \omega_{LO}$ 和 $\omega_{in} < \omega_{LO}$ 两种情形产生相同的 IF → LO 两侧对称的两个频谱同时下变频到同一 IF → 位于 $\omega_{im} = 2\omega_{LO} - \omega_{in}$ 的分量是**镜像**。
![[Pasted image 20260716191417.png|697]]
若有调制信号 $A_{in}(t)\cos[\omega_{in}t + \phi_{in}(t)]$ 和镜像干扰 $A_{im}(t)\cos[\omega_{im}t + \phi_{im}(t)]$，混频后差频项在 $-\omega_{IF}$ 和 $+\omega_{IF}$ 处重合——两者完全叠加，无法在 IF 域分离。污染程度 = $A_{im}$ 与 $A_{in}$ 的 RMS 比。

**高低边注入**：LO 放在信号之上（高边）或之下（低边）→ 选择镜像落在弱干扰频带。例 4.5：11g 接收机试图将镜像放入 GPS 频带（弱信号），但 80 MHz 的 LO 调谐范围远超 GPS 的 20 MHz 带宽 → 不可行。例 4.6：单 LO 放在 11g 和 11a 中间 → 高边注 11g、低边注 11a → 两个频带互成镜像。

## 镜像抑制滤波器
置于 LNA 与混频器之间 → LNA 增益压低其对 NF 的贡献（Friis 公式）。若放在 LNA 之前 → 前端损耗直接加在 NF 上（前端 BPF 的选择性不足以同时满足镜像抑制要求）。
![[Pasted image 20260716191754.png]]
镜像抑制滤波器要求高选择性和高线性度 → 迫使**片外无源**实现 → 50Ω 输入/输出阻抗 → LNA 必须驱动 50Ω 负载——功耗大、设计困难。

## 镜像抑制 vs 信道选择——根本折衷
镜像与信号间距 = $2\omega_{IF}$。这是一个**两难困局**：
- 高中频 → $2\omega_{IF}$ 大 → 镜像远 → 镜像抑制好 → 但 $\omega_{IF}$ 高 → 信道选择滤波器 Q 值大 → 信道选择难
- 低中频 → $\omega_{IF}$ 低 → 信道选择好做 → 但 $2\omega_{IF}$ 小 → 镜像近 → 镜像抑制难
![[Pasted image 20260716191850.png|697]]
即使无干扰，天线和 LNA 在镜像频带的**热噪声**也会下变频到 IF → 接收机 NF 恶化约 3 dB（例 4.7：太空接收机无干扰但 NF 仍然偏高）→ 必须靠镜像抑制滤波器或窄带 LNA 处理。

## 双下变频
解决镜像抑制与信道选择之间折衷的方案：两次混频 + 渐进式滤波，每级承担部分信道选择 → 各级 Q 值均可接受。
![[Pasted image 20260716191949.png|697]]
链路线性度分配的金科玉律：**每 1 dB 增益需 1 dB 预滤波，每 1 dB 预滤波使后续级 IIP3 要求降低 1 dB**。若 IF 滤波器完全不提供信道选择 → IF 放大器的 IIP3 需比 LNA 高约 40 dB（≈ +30 dBm）→ 在低电源电压下不可行 → IF 滤波减轻后续级线性度负担。

第二级 I/Q 下变频引入二次镜像：$\omega_{im2} = 2\omega_{LO2} - (\omega_{in} - \omega_{LO1})$。仅用两级下变频——三级以上的混频杂散组合爆炸式增长、不可管理。

## 混频杂散
实际混频器 = RF × LO **方波**（即使输入 LO 是正弦——混频器内部将其转换为方波以优化噪声和增益）→ 等价于 RF × LO 的所有谐波。干扰 $\omega_{int}$ 满足下式即落入 IF：
$$\omega_{int} \pm m\omega_{LO1} \pm n\omega_{LO2} = \omega_{in} - \omega_{LO1} - \omega_{LO2}$$
例 4.9：2.4 GHz 接收机，$f_{LO1}=1.98$ GHz，$f_{LO2}=400$ MHz，$f_{IF2}=20$ MHz → LO₂ 二次谐波（800 MHz）在 2.76 GHz 和 2.80 GHz 处产生杂散；LO₁ 二次谐波在 4.38 GHz 产生杂散。

## 现代外差
舍弃所有片外滤波器（仅留前端 BPF）→ 第一 IF 处无信道选择 → 第二混频器须高线性度（CMOS 能实现）；二次镜像问题恶化（无选择性滤波器衰减二次镜像的潜在干扰）。

### 零第二中频
$\omega_{LO2} = \omega_{IF1}$，第二混频输出落在 DC → **无其他频率可作二次镜像下变频到 DC**——这是避免二次镜像的根本手段。代价：信号本身的左右边带互为镜像（自镜像），下变频后两个副本在 DC 处叠加。

是否能承受取决于调制类型：
- **对称调制（AM）**：实基带 → 载波两侧频谱完全对称 → 两个副本携带相同信息 → 叠加不损失信息
- **非对称调制（FM/QPSK/GMSK/QAM）**：基带频率变化映射到载波两侧的不同信息 → 叠加会污染信息（例 4.10：信号 + 邻道干扰下变频后，干扰同时出现在正负频率两侧）

避免自污染的最低非零 IF = 信号带宽的一半（例 4.11）。要下变频到零中频且不损失信息 → **正交下变频**：$x_{IF}(t)$ 与 $\cos\omega_{LO2}t$ 和 $\sin\omega_{LO2}t$ 分别混频 → $x_{BB,I}$ 和 $x_{BB,Q}$ 频谱相同但相位分离 90° → 二者共同重构原始信息（I/Q 解耦的两个副本是正交空间中的独立维度）。

### 滑动中频
单振荡器 → $\div 2$ 得第二 LO（$f_{LO1}/2$）。优势：免多振荡器片上耦合；÷2 电路可同时产生正交 LO 相位。频谱链：$f_{in} \to f_{in} - f_{LO1} \to f_{in} - \frac{3}{2}f_{LO1}$。

> 滑动中频的另一优势：$f_{IF} \propto f_{in}$ → 第一中频的相对带宽与 RF 输入端相同：
> $$\mathrm{BW}_{IF,frac} = \frac{\frac{1}{3}f_2 - \frac{1}{3}f_1}{(\frac{1}{3}f_2 + \frac{1}{3}f_1)/2} = \frac{f_2 - f_1}{(f_2 + f_1)/2} = \mathrm{BW}_{RF,frac}$$
> $1/3$ 因子完全消去。传统恒定 IF 外差中，固定低 IF 导致相对带宽远大于 RF 端 → IF 滤波器设计压力大。滑动中频消除了这一负担。

现代外差无镜像抑制滤波器 → LNA 无需驱 50Ω → LNA/混频器接口可自由优化增益、噪声和线性度。

> 传统外差中，LNA 驱动 50Ω 不是电路内在需求，而是**镜像抑制滤波器的"遗产"**：滤波器须片外无源实现才满足选择性/线性度 → 片外 = 50Ω 系统 → 滤波器呈现 50Ω 输入阻抗 → LNA 被迫驱动 50Ω（功耗大）。移除片外滤波器 = 移除 50Ω 约束 = LNA 可用高阻电压驱动混频器 → 省电。但须窄带 LNA 以压制镜像频带热噪声（例 4.7 的解决方案）。RF 混频器可用 LC 负载提供温和片上带通。

# 直接变频接收机

**别名**：零中频 (Zero-IF)、零差 (Homodyne)。

## 架构与核心思想

$\omega_{LO} = \omega_{in}$ → 频谱一次搬移到 DC。

三大优势相对外差：
1. **无镜像** → 无需镜像抑制滤波器 → 免除片外 50Ω 约束
2. **片上 LPF 信道选择** → 有源滤波器可实现陡峭截止
3. **混频杂散大幅减少** → $f_1 \approx n f_{LO}$ 才落入基带，而 $f_{LO} = f_{ch}$ → 杂散需在接收频带内 → 被前端 BPF + LNA 选择性抑制

> 物理：外差的正交下变频困境在 DCR 中不存在——信号直接到 DC，正交分离是**主动操作**而非被动规避。

## LO 泄漏

**机制**：LO 通过两条路径耦合到天线：
1. 混频器 LO/RF 端口间寄生电容 → LNA 反向隔离路径（$C_{GD}$ / 衬底耦合）
2. LO 螺旋电感 → 衬底 → 输入焊盘

**例：共源共栅 LNA 的 LO 泄漏**（例 4.15）。级联 LNA 的反向隔离度：
$$\frac{V_{ant}}{V_X} \approx \frac{R_{ant} C_{GD1} \omega}{g_{m2} r_{O2}}$$

> 物理：共栅管 $M_2$ 的 $r_{O2}$ 是反向阻抗的核心屏障——$g_{m2} r_{O2}$ 越大泄漏越小，但 $C_{GD1}$ 在高频提供低阻抗路径。**典型容许值**：−50 ~ −70 dBm（天线端测得）。

**差分对称抑制**：差分 LO → 两条对称泄漏路径在天线端对消。泄漏仅源于随机或确定性不对称。

> 外差也有 LO 泄漏，但 $f_{LO}$ 在频带外 → 前端 BPF 在发射方和受害方都能衰减 → 不是严重问题。

## DC 偏移——最致命缺陷

### 自混频机制

LO 泄漏 $kV_{LO}$ 到达 LNA 输入 → 放大 → 在混频器中与 LO 自混频：
$$\text{LO 泄漏} \times \text{LO} → \frac{k V_{LO}^2}{2} \ (\text{DC})$$

> 物理：正弦波自乘产生 DC——$\cos^2$ 展开的 $(1/2)$ 因子是交叉项的物理根源。

### 为什么致命

**例：DC 偏移电压计算**（例 4.16）。接收机需放大 **70–100 dB**（天线到基带末端 ~0 dBm）。LO 泄漏**也享全部增益**——它不在带外，而是**与 LO 同频**：

| 信号 | 天线电平 | 增益 | 基带末端 |
|------|---------|------|----------|
| 有用信号 | −80 dBm | 80 dB | 0 dBm |
| LO 泄漏 | −60 dBm | **同一增益** | +20 dBm DC → 饱和 |

> **例：I/Q DC 偏移不等的原因**（例 4.17）。泄漏经不同路径到达各混频器 → $V_{dc,I} \propto \cos(\phi_{leak} + \phi_{ckt})$，$V_{dc,Q} \propto -\sin(\phi_{leak} + \phi_{ckt})$。

**外差零第二中频同理**：第二本振泄漏到 IF 混频器输入 → 同样自混频，虽 $f_{LO2}$ 远低于 $f_{LO1}$，仍足以饱和基带。

### 交流耦合——不实际

$C_1$ 隔直，$R_1$ 偏置。高通滤波切除零频附近信号能量 → ISI。规则：$f_1 = (2\pi R_1 C_1)^{-1} < \text{符号率}/1000$。

| 标准 | 比特率 | 所需 $f_1$ | 可行性 |
|------|--------|-----------|--------|
| GSM | 271 kb/s | 20–30 Hz | 电容/电阻太大 |
| 802.11b | 20 Mb/s | 20 kHz | 勉强集成 |

**额外缺陷**：$f_1$ 极低 → 时间常数极大 → LO 频率/LNA 增益切换时偏移突变 → 瞬态响应极慢。大调制指数 FSK 在 $f_c$ 有深陷波 → 更安全；小调制指数仍有大量 DC 附近能量。

### 有源反馈抵消

**例：有源反馈 DC 偏移抵消**（例 4.18）。负反馈支路 $R_1, C_1, -G_{mF}$ 将低频电流返回 → 驱动输出 DC 趋零：

$$\frac{V_{out}}{V_{in}} = \frac{G_{m1} R_D A_1 (R_1 C_1 s + 1)}{R_1 C_1 s + G_{mF} R_D A_1 + 1}$$

> 物理：极点被环路增益放大 $G_{mF}R_DA_1$ 倍 → 高通角频率远高于无源 RC → 需要**更大** $R_1C_1$ 才能获得同样低 $f_1$。但 $C_1$ 可用 MOSFET 实现。

### 数字 DAC 抵消——主流方案

**原理**：DAC 注入/抽取校正电流 $I_1$ → 上电校准后**冻结** → 不影响基带频率响应。ADC 数字化输出 → 反馈环收敛使 $V_{out}$ 最小 → 值锁存。

**优势**：CMOS 缩微下 DAC + 寄存器面积远小于耦合电容；ADC 信号接收时复用；LO/增益变化可预存 LUT。

**缺陷**：有限分辨率 → 残留偏移。**例：多 DAC 降低残留偏移**（例 4.19）。3-bit DAC → 10 mV → 1.2 mV → 基带增益 40 dB → 仍有 120 mV（第二级再加 3-bit DAC → ~16 mV）。

> 物理：数字存储是**开环校正**——校准后固定，不跟踪信号统计特性，但也不适应校准后的漂移。

## 偶阶失真——DCR 特有

### 拍频产生与泄漏

两强干扰 $\omega_1, \omega_2$ 经 $\alpha_2 x^2$ → 低频拍频 $\omega_2 - \omega_1$：

$$\alpha_2 A^2 \cos(\omega_1 - \omega_2)t$$

> 物理：$\cos\omega_1 t \cdot \cos\omega_2 t = \frac{1}{2}[\cos(\omega_1+\omega_2)t + \cos(\omega_1-\omega_2)t]$ → 差频即拍频。

**拍频如何到达基带**——混频器 RF 直通项：

单端混频器：$V_{out} = V_{in}(t) \cdot S(t) = V_{in}(t)[S(t) - \frac{1}{2}] + \underline{V_{in}(t) \cdot \frac{1}{2}}$

> 物理：方波 $S(t)$ 的 dc 分量为 $1/2$ → RF 直通的根源。$S(t)-\frac{1}{2}$ 是零 dc 方波 → 仅奇次谐波 → 正常混频。

差分混频器：两路直通项 $V_{in}/2$ 对消 → 对消程度取决于**开关管匹配**。

### IP₂ 定义

两音测试，关注输出**拍频**幅度（而非 IM₃）。拍频 $\propto A^2$ → log-log 斜率 2。

**例：含混频器直通的 IP₂ 计算**（例 4.20）。设经混频器后拍频衰减因子 $k$（取决于版图对称性），信号增益为 1：

$$k\alpha_2 A_{IIP2}^2 = \alpha_1 A_{IIP2} \quad\Rightarrow\quad A_{IIP2} = \frac{1}{k} \cdot \frac{\alpha_1}{\alpha_2}$$

> $k \ll 1$（差分对称好）→ $A_{IIP2}$ 放大 → 高 IP₂ 本质是**用对称性压制 RF 直通**，而非消除非线性本身。

### AM 解调效应

变包络信号 $[A_0 + a(t)] \cos[\omega_c t + \phi(t)]$ 经 $\alpha_2$ 项，展开平方后按频率拆分为三类分量：

$$
\alpha_2 x_{in}^2 = \underbrace{\frac{\alpha_2}{2}A_0^2}_{\text{真 DC}} + \underbrace{\vphantom{\frac{\alpha_2}{2}}\alpha_2 A_0 a(t) + \frac{\alpha_2}{2}a^2(t)}_{\text{时变低通}} + \underbrace{\vphantom{\frac{\alpha_2}{2}}\frac{\alpha_2}{2}[A_0^2 + 2A_0 a(t) + a^2(t)] \cos[2\omega_c t + 2\phi(t)]}_{\text{高频 } 2\omega_c}
$$

> 物理：$\cos^2$ 展开的 DC 项 $(1/2)$ 将**包络变化直接释放到基带**——平方律本身即是包络检波器。

三个低通项的性质截然不同：

| 项 | 是否时变 | 携带 $a(t)$ 信息 | 能否消除 |
|---|---|---|---|
| $\frac{\alpha_2}{2}A_0^2$ | 否——**常数** | 否 | ✅ 隔直 / DAC 抵消 |
| $\alpha_2 A_0 a(t)$ | 是 | 是——**AM 被解调** | ❌ 与信号频谱重叠 |
| $\frac{\alpha_2}{2}a^2(t)$ | 是 | 是——二次失真 | ❌ 与信号频谱重叠 |

> 物理：真 DC 是恒定偏移——不随时间变化、不携带信息、不造成误码，仅偏置工作点。而 $\alpha_2 A_0 a(t)$ 和 $\frac{\alpha_2}{2}a^2(t)$ **随包络起伏**，频谱覆盖基带信号带宽，无法在频域与有用信号分离。这就是只有后两项构成"corruption"的原因——DC 不污染信号，时变低通量污染。

**例：AM 自污染 SNR**（例 4.21）。忽略 DC 项，仅计入时变低通量且 $a(t) \ll A_0$ 时，污染近似为 $\alpha_2 A_0 a(t)$：$\text{SNR} = \frac{A_{IIP2}}{\sqrt{2} \cdot a_{rms}}$。实际不太严重——$a_{rms}$ 大到接近 $A_{IIP2}$ 时 $A_0$ 已触发 LNA 增益切换。

**例：干扰 AM 解调所需 IIP₂**（例 4.22）。有用信号 $A_{sig} \cos[\omega_c t + \phi_{sig}]$ 伴大 AM 干扰 $[A_{int} + a(t)] \cos[\omega_c t + \phi_{int}]$。有用信号经 $\alpha_1$ + 混频器（增益 1）→ 基带 rms = $\alpha_1 A_{sig}/\sqrt{2}$。干扰经 $\alpha_2 x_{int}^2$ 的低通分量 $\alpha_2 A_{int} a(t)$（$a(t) \ll A_{int}$ 时主导）→ 混频器 RF 直通（衰减 $k$）→ 基带污染 rms = $k\alpha_2 A_{int} a_{rms}$：

$$\mathrm{SNR} = \frac{\alpha_1 A_{sig} / \sqrt{2}}{k \alpha_2 A_{int} a_{rms}} \tag{4.36}$$

代入 $A_{IIP2} = \frac{1}{k}\frac{\alpha_1}{\alpha_2}$（式 4.32）→ $k\alpha_2 = \alpha_1/A_{IIP2}$：
$$\mathrm{SNR} = \frac{A_{IIP2} \cdot A_{sig} / \sqrt{2}}{A_{int} \cdot a_{rms}} \tag{4.37}$$

**与自污染的关键区别**：

| | 自污染 (4.34) | 干扰 AM 解调 (4.36) |
|---|---|---|
| 分子 | $\alpha_1 A_0 / \sqrt{2}$ | $\alpha_1 A_{sig} / \sqrt{2}$ |
| 分母 | $k\alpha_2 A_0 a_{rms}$ | $k\alpha_2 A_{int} a_{rms}$ |
| 代入 IP₂ 后 | $\frac{A_{IIP2}}{\sqrt{2} a_{rms}}$ | $\frac{A_{IIP2} A_{sig} / \sqrt{2}}{A_{int} a_{rms}}$ |

> 物理：自污染中 $A_0$ **同时在分子和分母** → 代入 IP₂ 后抵消 → SNR 与信号幅度无关。干扰 AM 解调中 $A_{sig}$ 和 $A_{int}$ **独立变化** → $A_{int}$ 只在分母 → SNR $\propto 1/A_{int}$。干扰每增大 10 倍，SNR 恶化 10 倍——这就是干扰远低于 $P_{1dB}$ 却仍能造成严重污染的根本原因：$A_{int}$ 不经压缩直接进入分母。

例：$A_{sig} = -100\text{ dBm}$（$3.16\text{ }\mu\text{V}_{pk}$），$A_{int} = 5\text{ mV}_{pk}$（−36 dBm），$a_{rms} = 1\text{ mV}$ → SNR = 20 dB 需 $A_{IIP2} = 22.4\text{ V}$ = **+37 dBm**！干扰仅 −36 dBm（远低于 $P_{1dB}$），却需 +37 dBm IIP₂——偶阶失真对 DCR 的要求是数量级的提升。高 IP₂ 设计见第 6 章。

## 闪烁噪声

### 问题根源

LNA/混频器增益被线性度限制在 ~30 dB → 下变频信号在 DC 附近 → $1/f$ 噪声直接污染。

### 噪声惩罚因子

设 $S_{1/f} = \alpha/f$，转角频率 $f_c$ 处 $\alpha = f_c S_{th}$。积分 $f_{BW}/1000$ 到 $f_{BW}$：

$$\frac{P_{n1}}{P_{n2}} = 1 + \left(5.9 + \ln\frac{f_c}{f_{BW}}\right) \frac{f_c}{f_{BW}}$$

> 物理：惩罚取决于 $f_c/f_{BW}$——转角频率覆盖的带宽**比例**越大，$1/f$ 贡献越多。窄带系统遭更大惩罚——不是噪声更大，而是信号带宽被噪声覆盖的比例更大。

| 标准 | $f_{BW}$ | $f_c$ (典型) | 惩罚 | 结论 |
|------|----------|-------------|------|------|
| 802.11g（例 4.23） | 10 MHz | 200 kHz | **1.04** (0.17 dB) | 可忽略 |
| GSM（例 4.24） | 100 kHz | 200 kHz | **16.4** (12 dB) | 致命 |

> GSM 惩罚 12 dB → 零中频对窄带标准不适用 → 引出低中频架构（§4.2.5）。前端增益↑ → 基带末端 $S_{th}$ 由天线/LNA/混频器主导 → $f_c$↓ → 惩罚降低。

## I/Q 失配

### 失配来源

- LO 正交产生电路误差 + 混频器间失配 + 基带 I/Q 路径失配 + LO 路径延迟差

**DCR 比外差更严重**：10 ps @ 5 GHz → $18^\circ$；10 ps @ 1 GHz → $3.6^\circ$。高频器件尺寸缩小 → 失配增大。

### 对 QPSK 星座的影响

振幅失配 $\epsilon$，相位失配 $\theta$，全归入 LO 路径：
$$x_{LO,I} = 2(1 + \epsilon/2) \cos(\omega_c t + \theta/2),\quad x_{LO,Q} = 2(1 - \epsilon/2) \sin(\omega_c t - \theta/2)$$

基带输出：
$$x_{BB,I} = a(1+\epsilon/2)\cos(\theta/2) - b(1+\epsilon/2)\sin(\theta/2)$$
$$x_{BB,Q} = -a(1-\epsilon/2)\sin(\theta/2) + b(1-\epsilon/2)\cos(\theta/2)$$

- **纯增益失配**：I/Q 各轴独立缩放 → 星座点位移
- **纯相位失配**：每路含另一路串扰 → 星座沿一对角线压缩、另一对角线拉伸

**增益失配的星座画法**（Fig. 4.50）。$\theta=0$ 代入 → $\cos 0=1$, $\sin 0=0$：

$$x_{BB,I} = a(1+\epsilon/2),\quad x_{BB,Q} = b(1-\epsilon/2)$$

四 QPSK 点 $(a,b) = (\pm1, \pm1)$ 逐点映射：

$$\begin{aligned} (+1,+1) &\to \big(1+\epsilon/2,\; 1-\epsilon/2\big) \\ (+1,-1) &\to \big(1+\epsilon/2,\; -(1-\epsilon/2)\big) \\ (-1,+1) &\to \big(-(1+\epsilon/2),\; 1-\epsilon/2\big) \\ (-1,-1) &\to \big(-(1+\epsilon/2),\; -(1-\epsilon/2)\big) \end{aligned}$$

$\epsilon > 0$ → I 方向拉伸 $(1+\epsilon/2)$、Q 方向压缩 $(1-\epsilon/2)$ → 正方形变为**矩形**。变换矩阵 $\mathrm{diag}(1+\epsilon/2,\;1-\epsilon/2)$——对角矩阵，特征向量恰好是 I 轴和 Q 轴。

**相位失配的星座画法**（Fig. 4.51）。$\epsilon=0$ 代入，写成矩阵：

$$\begin{bmatrix} x_{BB,I} \\ x_{BB,Q} \end{bmatrix} = \underbrace{\begin{bmatrix} \cos\frac{\theta}{2} & -\sin\frac{\theta}{2} \\ -\sin\frac{\theta}{2} & \cos\frac{\theta}{2} \end{bmatrix}}_{\text{对称矩阵，非正交}} \begin{bmatrix} a \\ b \end{bmatrix}$$

求特征值和特征向量：

- 特征向量 $\begin{bmatrix}1\\1\end{bmatrix}$（$a=b$ 对角线）：$\lambda_1 = \cos\frac{\theta}{2} - \sin\frac{\theta}{2} \approx 1 - \frac{\theta}{2} < 1$ → **压缩**
- 特征向量 $\begin{bmatrix}1\\-1\end{bmatrix}$（$a=-b$ 对角线）：$\lambda_2 = \cos\frac{\theta}{2} + \sin\frac{\theta}{2} \approx 1 + \frac{\theta}{2} > 1$ → **拉伸**

四 QPSK 点映射：

$$\begin{aligned} (+1,+1) &\to \big(\cos\frac{\theta}{2}-\sin\frac{\theta}{2},\; \cos\frac{\theta}{2}-\sin\frac{\theta}{2}\big) &&\text{沿 }a=b\text{ 对角线向原点内缩} \\ (+1,-1) &\to \big(\cos\frac{\theta}{2}+\sin\frac{\theta}{2},\; -(\cos\frac{\theta}{2}+\sin\frac{\theta}{2})\big) &&\text{沿 }a=-b\text{ 对角线远离原点} \\ (-1,+1) &\to \big(-(\cos\frac{\theta}{2}+\sin\frac{\theta}{2}),\; \cos\frac{\theta}{2}+\sin\frac{\theta}{2}\big) &&\text{沿 }a=-b\text{ 对角线远离原点} \\ (-1,-1) &\to \big(-(\cos\frac{\theta}{2}-\sin\frac{\theta}{2}),\; -(\cos\frac{\theta}{2}-\sin\frac{\theta}{2})\big) &&\text{沿 }a=b\text{ 对角线向原点内缩} \end{aligned}$$

正方形 → **菱形**。

$$
\mathbf{M}_\epsilon = \begin{bmatrix}1+\epsilon/2 & 0 \\ 0 & 1-\epsilon/2\end{bmatrix}, \qquad
\mathbf{M}_\theta = \begin{bmatrix}\cos\frac{\theta}{2} & -\sin\frac{\theta}{2} \\ -\sin\frac{\theta}{2} & \cos\frac{\theta}{2}\end{bmatrix}
$$

|      | 增益失配                                                               | 相位失配                                                                                                                       |     |
| ---- | ------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | --- |
| 失配参数 | $\epsilon$                                                         | $\theta$                                                                                                                   |     |
| 变换矩阵 | $\mathbf{M}_\epsilon$ | $\mathbf{M}_\theta$ |     |
| 特征向量 | I 轴 / Q 轴                                                          | $a=b$ 对角线 / $a=-b$ 对角线                                                                                                     |     |
| 几何结果 | 正方形 → 矩形                                                           | 正方形 → 菱形                                                                                                                   |     |
| 画法   | 逐点乘各轴缩放因子                                                          | 特征分解 → 两对角线各乘 $\lambda_{1,2}$                                                                                              |     |

> 物理：I/Q 是二维正交基——失配相当于**基底非正交归一**。两者的**矩阵结构不同**直接决定了星座畸变的几何形态：增益失配矩阵是对角阵 → 畸变沿坐标轴方向；相位失配矩阵非对角 → 特征向量旋转到 $\pm45^\circ$ → 畸变沿对角线方向。

### FSK 天然免疫

**例：FSK 对 I/Q 失配的容忍**（例 4.25）。$x_{BB,I} = -A_1 \cos a\omega_1 t$，$x_{BB,Q} = +A_1 \sin a\omega_1 t$（$a = \pm 1$）。D 触发器采样极性即可判决——不需精确正交振幅关系。接近 $90^\circ$ 相位失配时才因加性噪声误码。

### OFDM 的苛刻需求

OFDM (128 子信道, QPSK)：增益/相位失配 $< -0.6\text{ dB} / < 6^\circ$。802.11a/g → 裸器件匹配 + 版图不足 → **必须校准**。

**校准方案**：上电注入 RF 单音 → 基带极低频正弦波 → 精确测量失配 → 数字域校正星座；或 LO 路径可变相移 + 基带可变增益 → 调整至可接受 → 控制字存储。

## 混频杂散

DCR 极少受混频杂散困扰：$f_1 \approx n f_{LO}$ 且 $f_{LO} = f_{ch}$ → $f_1$ 在带内 → 已被前端选择性衰减。

**例外**：接收机带宽 > 2 倍频程（TV 调谐器、软件无线电、认知无线电）→ 低端谐波落入高端 → LO 谐波杂散重现。

## DCR 五重代价总结

| 问题     | 物理实质                    | 取决于                             |
| ------ | ----------------------- | ------------------------------- |
| LO 泄漏  | 反向隔离度有限                 | $g_m r_O$、版图对称性                 |
| DC 偏移  | $\cos^2$ 自混频 DC 项       | LO 泄漏量、链路总增益                    |
| 偶阶失真   | $\alpha_2$ 包络检波 + 混频器直通 | 差分对称性 ($k$)、$\alpha_1/\alpha_2$ |
| 闪烁噪声   | DC 下变频 → $1/f$ 与信号重叠    | $f_c/f_{BW}$                    |
| I/Q 失配 | 正交基底非正交化                | 频率、器件匹配                         |

> 架构选择本质：$f_{LO} = f_{in}$ → 无镜像，承受五重代价；$f_{LO} \neq f_{in}$ → 有镜像，避开 DC 相关问题。混频器闪烁噪声 → 第 6 章；高 IP₂ 设计 → 第 6 章；振荡器 $1/f$ 搬移 → 第 8 章。

# 镜像抑制接收机

**核心思想**：信号处理消镜像，免去镜像抑制滤波器 → 打破镜像抑制与信道选择的折衷。

## Hilbert 变换与 90° 移相——数学基础

### 定义

对余弦 $A\cos\omega_c t = (A/2)[\exp(+j\omega_c t) + \exp(-j\omega_c t)]$ 移相 90°：

$$A\cos(\omega_c t - 90^\circ) = -\frac{A}{2}j e^{+j\omega_c t} + \frac{A}{2}j e^{-j\omega_c t} = A\sin\omega_c t$$

在频域：
$$X_{90^\circ}(\omega) = X(\omega) \cdot [-j \,\mathrm{sgn}(\omega)]$$

> 物理：$+\omega_c$ 处脉冲 × $(-j)$ → 顺时针旋转 90°；$-\omega_c$ 处脉冲 × $(+j)$ → 逆时针旋转 90°。Hilbert 变换**区分正负频率**——这是镜像抑制的关键。

两次 Hilbert 变换 = 原信号取反：$[-j\,\mathrm{sgn}(\omega)] \cdot [-j\,\mathrm{sgn}(\omega)] = -1$。

**例 4.27**：$A\cos\omega_c t + jA\sin\omega_c t = A\exp(+j\omega_c t)$ → 单边谱（仅在 $+\omega_c$ 有脉冲）。$I(t) + jQ(t)$（$Q$ 是 $I$ 的 Hilbert 变换）→ **解析信号**——仅在正频率有能量。

### RC-CR 移相网络

![]  *(Fig. 4.58)*

$$H_{HPF}(s) = \frac{R_1C_1 s}{R_1C_1 s + 1}, \quad H_{LPF}(s) = \frac{1}{R_1C_1 s + 1}$$

$$\angle H_{HPF} - \angle H_{LPF} = \frac{\pi}{2} \quad (\text{所有频率})$$

> 物理：高通—低通对的相位差恒为 90°，**与 $R_1C_1$ 值无关**。但幅度仅在 $\omega = (R_1C_1)^{-1}$ 处相等（$1/\sqrt{2}$）→ 偏离中心频率幅度失配。

### 正交下变频 = Hilbert 变换器

![]  *(Fig. 4.59)*

RF 信号 × $\cos\omega_{LO}t$ 和 $\sin\omega_{LO}t$ → IF 处两路输出互为 Hilbert 变换。

> 物理：$\cos$ 混频 → 正/负 LO 脉冲均为 $+1/2$ → IF 谱对称；$\sin$ 混频 → 正 LO 脉冲为 $-j/2$，负 LO 为 $+j/2$ → IF 谱恰好是另一路的 Hilbert 变换。

**关键区分——高边注入 vs 低边注入**：
- **低边注入** ($\omega_c > \omega_{LO}$)：Q 路 = $I$ 路的 Hilbert 变换 → 信号被"标记"为正频率
- **高边注入** ($\omega_c < \omega_{LO}$)：Q 路 = $I$ 路的**负** Hilbert 变换 → 信号被"标记"为负频率

> 物理：正交下变频通过 Hilbert 变换的**符号**区分信号与镜像——信号和镜像在 3D 频谱（Fig. 4.61）中位于不同半平面。这就是 Hartley/Weaver 能选择性消除镜像的根本原因。

## Hartley 架构

![]  *(Fig. 4.62 / Fig. 4.64)*

### 原理

I/Q 正交下变频（产生信号和镜像的 Hilbert 变换对）→ Q 路再经 90° 移相（第二次 Hilbert）→ 与 I 路相加：

- **信号**：$[+j\,\mathrm{sgn}(\omega)] \cdot [-j\,\mathrm{sgn}(\omega)] = +1$ → 两路信号**同相叠加** → ×2
- **镜像**：$[-j\,\mathrm{sgn}(\omega)] \cdot [-j\,\mathrm{sgn}(\omega)] = -1$ → 两路镜像**反相对消** → ×0

> 物理：第一次正交混频给信号乘以 $+j\,\mathrm{sgn}$，给镜像乘以 $-j\,\mathrm{sgn}$（低边注入）；第二次 Hilbert 再乘 $-j\,\mathrm{sgn}$。信号经历正 → 负 → 回到正；镜像经历负 → 负 → 反相。**两次 Hilbert 的符号级联决定了谁被保留、谁被对消**。

**例 4.30——高边注入陷阱**：高边注入下正交混频给信号 × $-j\,\mathrm{sgn}$、镜像 × $+j\,\mathrm{sgn}$ → 第二次 Hilbert 后信号反相、镜像同相 → 加法器输出**信号对消、镜像保留**——变成"信号抑制接收机"！差分解：加法改减法。

### 解析推导（低边注入）

输入 $x(t) = A_{sig}\cos(\omega_c t + \phi_{sig}) + A_{im}\cos(\omega_{im}t + \phi_{im})$，LO 幅度归一化为 1：

$$x_A(t) = \frac{A_{sig}}{2}\cos[(\omega_c-\omega_{LO})t + \phi_{sig}] + \frac{A_{im}}{2}\cos[(\omega_{im}-\omega_{LO})t + \phi_{im}]$$

$$x_B(t) = -\frac{A_{sig}}{2}\sin[(\omega_c-\omega_{LO})t + \phi_{sig}] - \frac{A_{im}}{2}\sin[(\omega_{im}-\omega_{LO})t + \phi_{im}]$$

$x_B$ 经 90° 移相（需区分正负频率——镜像项 $\omega_{im}-\omega_{LO} < 0$，重写为正频率再移相）：

$$x_C(t) = \frac{A_{sig}}{2}\cos[(\omega_c-\omega_{LO})t + \phi_{sig}] - \frac{A_{im}}{2}\cos[(\omega_{im}-\omega_{LO})t + \phi_{im}]$$

$x_A + x_C$ → 信号保留，镜像对消。

### 镜像抑制比 (IRR)

将所有失配归入 LO 路径：一路为 $\sin\omega_{LO}t$，另一路为 $(1+\epsilon)\cos(\omega_{LO}t + \Delta\theta)$：

$$\mathrm{IRR} = \frac{(1+\epsilon)^2 + 2(1+\epsilon)\cos\Delta\theta + 1}{(1+\epsilon)^2 - 2(1+\epsilon)\cos\Delta\theta + 1}$$

> 注意：IRR 是功率比 → 取 $10\log\mathrm{IRR}$（非 $20\log$）。

小失配近似 ($\epsilon \ll 1$, $\Delta\theta \ll 1\text{ rad}$)：
$$\mathrm{IRR} \approx \frac{4}{\epsilon^2 + \Delta\theta^2}$$

| 失配量 | IRR |
|--------|-----|
| $\epsilon = 10\%$ (0.83 dB) | 26 dB |
| $\Delta\theta = 10^\circ$ | 21 dB |
| 典型（含各种失配） | **< 35 dB** |

> 物理：IRR ∝ $1/(\epsilon^2 + \Delta\theta^2)$——失配的**平方和**决定抑制比。每 10 倍失配改善 → 20 dB IRR 提升。这是硬限制——版图和器件匹配决定天花板。

### RC-CR 网络的四重缺陷

**1. 绝对值变化 → 增益失配**

$R_1, C_1$ 随工艺/温度漂移，但 $\omega_{IF}$ 不变 → 幅度不相等：
$$\epsilon = \frac{\Delta R}{R_1} + \frac{\Delta C}{C_1}$$

$\Delta R/R_1 = 20\%$ → IRR 仅 20 dB。以上还未计入 HPF 和 LPF 间的**元件失配**。

> 物理：RC-CR 相位差恒为 90° 的代价是幅度相等仅在一个频率点保证——绝对值和失配双重恶化。

**2. 带宽限制**

信道宽度 → 偏离 $\omega_{IF}$ 处增益失配恶化：
$$\mathrm{IRR} = \left(\frac{\omega_{IF}}{\Delta\omega}\right)^2$$

例：$2\Delta\omega/\omega_{IF} = 5\%$ → IRR 仅 32 dB。这意味着 $\omega_{IF}$ **不能为零** → Hartley 必然是外差架构（Fig. 4.65），需第一 LO 的正交相位 → 额外代价。

> 物理：宽带信号的两端离 $(R_1C_1)^{-1}$ 越远 → HPF/LPF 的幅度差越大 → 等效为 $\epsilon$ 增大 → IRR 恶化。

**3. 3 dB 衰减 + 噪声**

HPF/LPF 在 $\omega_{IF}$ 处幅度各为 $1/\sqrt{2}$ → 3 dB 信号衰减 → 直接放大加法器的噪声贡献。输入阻抗 $|R_1 + (C_1 s)^{-1}| = \sqrt{2}R_1$ @ $\omega_{IF}$ → 混频器负载与移相网络热噪声之间的折衷。

**4. 电压加法器**

差分对 VI 转换 → 电流求和 → IV 转换（Fig. 4.66）。加法器的噪声和非线性直接进入信号路径。

## Weaver 架构

![]  *(Fig. 4.67)*

### 核心创新

**用第二次正交混频替代 RC-CR 移相网络**——免除 RC-CR 的全部缺陷。

> 物理：正交混频 = Hilbert 变换（Fig. 4.59 的结论）。Weaver 用**有源混频**实现第二次 Hilbert 变换——无无源衰减、无 RC 绝对值漂移、宽带特性不受单频点限制。

### 工作原理

输入经第一级正交下变频 → $x_A(t), x_B(t)$（同上）→ 第二级正交混频（$\sin\omega_2 t, \cos\omega_2 t$）→ LPF 滤除上变频分量：

$$x_E(t) - x_F(t) = \frac{A_{sig}}{2}\cos[(\omega_c - \omega_1 - \omega_2)t + \phi_{sig}]$$

> 加法还是减法取决于两次注入的高低边组合——四种组合各有不同符号结果（Problem 4.19）。

图形解释（Fig. 4.69，低边+低边）：第二级混频将 I/Q 两路频谱在正频率处同相叠加、负频率处反相对消 → 减法输出单边信号。

### 二次镜像 (Secondary Image)

![]  *(Fig. 4.70)*

若 RF 输入端存在 $2\omega_2 - \omega_{in} + 2\omega_1$ 分量 → 第一次下变频后成为 $\omega_2$ 的镜像 → 第二次混频落入与有用信号相同 IF。

> 物理：二次混频为镜像抑制创造了新的镜像问题——二次镜像频率与 $\omega_1$ 对称分布于 $\omega_2$ 上下。**零第二 IF** 是根本解决方案（Fig. 4.71）：信号到 DC → 无其他频率可作二次镜像（与 DCR 零中频消镜像同理）。此时第二级也须正交下变频 → 双正交架构。

### 对比 Hartley

| | Hartley | Weaver |
|------|---------|--------|
| 移相实现 | RC-CR 无源网络 | 第二次正交混频 |
| RC 绝对值漂移 | 严重（$\epsilon = \Delta R/R + \Delta C/C$） | 无 |
| 带宽限制 | $\mathrm{IRR} \propto (\omega_{IF}/\Delta\omega)^2$ | 无（混频器宽带） |
| 衰减 | HPF/LPF 各 3 dB | 无（有源混频可提供增益） |
| 噪声 | RC-CR 热噪声 + 加法器 | 第二混频器噪声 |
| 复杂度 | 1 LO + RC-CR + 加法器 | 2 LO（或 LO + ÷2）+ 4 混频器 |
| 混频杂散 | 仅第一级 | 两级均有 |
| IRR 上限 | < 35 dB | **< 40 dB** |
| 二次镜像 | 无 | 有（零第二 IF 解决） |

## 校准

IRR > 40 dB 需求时，Hartley 和 Weaver 都必须校准——通过测量和抵消增益/相位失配。多个校准技术已有报道 [7, 9]。

# 低中频接收机

**核心思想**：$f_{LO}$ 放在信道边沿 → IF = 半信道带宽 → 避开 DC 的闪烁噪声和偏移问题，镜像落入邻道 → 用镜像抑制架构处理（容忍中等 IRR）。

## 动机——窄带标准的零中频困境

GSM (200 kHz BW)：零中频 → $1/f$ 惩罚 16.4× (12 dB) + DC 偏移高通滤波不可行。将 LO 放在信道边沿 → IF = 100 kHz → 信号在 DC 附近能量极少 → $1/f$ 惩罚大幅降低 + 片上交流耦合可行。

![]  *(Fig. 4.72)*

> 物理：低中频是零中频和外差的**折衷**——既不承受 DC 处的全部代价，也不面对远距离镜像的苛刻抑制需求。LO 与信号的间距恰好使镜像落入邻道。

## 闪烁噪声惩罚——大幅缓解

**例：低中频 GSM 的闪烁噪声惩罚**（例 4.33）。设高通滤波切除 DC 偏移同时也去除了 20 kHz 以下的闪烁噪声，积分 20 kHz → 200 kHz：

$$\frac{P_{n1}}{P_{n2}} = \frac{f_c \cdot S_{th} \ln 10}{200\text{kHz} \cdot S_{th}} = 2.3 \ (= 3.62\text{ dB})$$

| 架构 | $1/f$ 惩罚 (GSM) | DC 偏移 |
|------|-----------------|---------|
| 零中频 | 16.4× (12 dB) | 致命 |
| 低中频 | 2.3× (3.62 dB) | 交流耦合可行 |

> 物理：高通滤波切除 0–20 kHz 的同时也丢弃了该区间的 $1/f$ 噪声——**隔直和降噪声是同一次操作的两种收益**。这是低中频独有的"免费午餐"。

## 镜像——邻道弱干扰

低中频引入镜像，但镜像正好在**邻道**。GSM 标准要求接收机容忍邻道仅比信号高 **9 dB**（Fig. 4.72(b)）→ IRR = 30 dB 即可将镜像压低到信号以下 21 dB。

> 关键：低中频可行性的前提是**镜像本身就不强**——窄带标准的邻道干扰限制相对宽松。若邻道干扰高达 40–50 dB（某些宽带标准），低中频的 IRR 需求就无法满足。

## 镜像抑制的实现方案

### 方案 1：传统 Hartley/Weaver——各有问题

- **Hartley + IF 处 RC-CR**：低 IF 频谱延伸到零频 → HPF 在 DC 处增益为零 → 信道内 IRR 严重退化（$\mathrm{IRR} \propto (\omega_{IF}/\Delta\omega)^2$ 在 $\omega_{IF} \to 0$ 时发散）
- **Weaver**：二次镜像问题（除非第二 IF 为零）；零第二 IF → 闪烁噪声问题又回来了

### 方案 2：RF 路径 90° 移相（Fig. 4.74）

将 RC-CR 移相网络从 IF 路径**移到 RF 路径**——中心频率高（~900 MHz），25 MHz 接收带宽的相对带宽小 → 带宽内 IRR 退化可接受：

$$\mathrm{IRR} \approx 20\log\frac{900\text{ MHz}}{12.5\text{ MHz}} = 37\text{ dB}$$

但 RC 绝对值变化仍限制 IRR 在 ~20 dB [$\epsilon = \Delta R/R + \Delta C/C$]。

### 方案 3：数字域 Hilbert 变换（Fig. 4.75）——最实用

正交下变频 → LPF + 放大 → ADC 数字化 → **数字域 90° 移相** → 求和。避开模拟 RC-CR 的全部缺陷。

代价：ADC 需处理**两倍**带宽（镜像和信号各占 IF 两侧）。窄带标准（如 GSM）ADC 功耗占总系统比例小 → 可接受。

![]  *(Fig. 4.75)*

### 方案 4：Polyphase 滤波器——利用序列不对称性

见下一节。

## Polyphase 滤波器 (PPF)

### 基本单元——单级 RC 网络

![]  *(Fig. 4.76)*

$$V_{out} = \frac{V_1 + R_1 C_1 s V_2}{R_1 C_1 s + 1}$$

> 物理：RC 串联支路计算 $V_1$（电阻贡献）和 $V_2$（电容贡献，经 $C_1$ 旋转 90°）的**加权矢量和**。$C_1$ 对 $V_2$ 再旋转 90°，使信号和镜像经历不同的矢量和。

在 $\omega = (R_1 C_1)^{-1}$ 处：

- **$V_2 = -jV_1$（信号——Hilbert 变换）**：$C_1$ 将 $-jV_1$ 再转 90° → $-j \cdot (-jV_1) = -V_1$ → 与 $V_1$ 同向叠加 → $|V_{out}| = \sqrt{2}V_1$，$\angle V_{out} = \angle V_1 - 45^\circ$
- **$V_2 = +jV_1$（镜像——负 Hilbert 变换）**：$C_1$ 将 $+jV_1$ 再转 90° → $-j \cdot (+jV_1) = +V_1$ → 与 $V_1$ 反向对消 → $V_{out} = 0$

> 核心：单级 RC 网络仅凭信号和镜像的**输入序列不同**（一个顺时针、一个逆时针）选择性通过或抑制——这就是"序列不对称"的含义。

### 差分正交 PPF（Fig. 4.77–4.78）

**例：差分正交 PPF 驱动**（例 4.34–4.35）。四路正交输入 $(+V_1, -jV_1, -V_1, +jV_1)$ → 四个 RC 支路排列成环：

![]  *(Fig. 4.78)*

在 $\omega = (RC)^{-1}$ 处，信号（顺时针序列：$+V_1 \to -jV_1 \to -V_1 \to +jV_1$）→ 每节点旋转 −45° 输出 → 四路正交输出**保留**。镜像（逆时针序列：$+V_1 \to +jV_1 \to -V_1 \to -jV_1$）→ **全部对消**。

> 物理：PPF 是**方向选择性**滤波器——信号和镜像在四个输入端以相反方向"旋转"，电路只对顺时针序列有响应。这像旋转门：顺时针推 → 门开；逆时针推 → 门锁死。

### 偏离中心频率的行为

$\omega = (RC)^{-1} + \Delta\omega$ 时：

$$|V_{out1}| \approx \sqrt{2}|V_{sig}|\left(1 - \frac{5}{8}R^2 C^2 \Delta\omega^2\right)$$

$$\angle V_{out1} = \angle V_{sig} - \left(\frac{\pi}{4} + \frac{RC\Delta\omega}{2}\right)$$

输出信号和镜像仍保持相反序列 → 可级联进一步抑制。

### 级联 PPF

![]  *(Fig. 4.81)*

**加载效应**：第二级加载使第一级输出衰减 2 倍（若两级 RC 值相同，例 4.36）。每级衰减信号 $\sqrt{2}$ 倍。

**两级抑制**：
$$\left|\frac{V_{im,out}}{V_{im,in}}\right| \approx \frac{(R_0 C_0 \Delta\omega)^2}{2}$$

> 物理：$N$ 级级联 → 镜像抑制 ∝ $(\Delta\omega)^N$——零点从单级的一阶提升到 $N$ 阶，带内平坦度改善。

**带宽展宽技术——分裂截止频率**：两级取不同 $RC$（$f_1 = (R_1C_1)^{-1} < f_0 < f_2 = (R_2C_2)^{-1}$）→ 镜像抑制乘积在 $f_0$ 处仍深 → 带宽显著宽于两级同频（Fig. 4.85）。60 dB 抑制 → $f_1 - f_2$ 不超过 $f_0$ 的 ~18%。

![]  *(Fig. 4.84 / Fig. 4.85)*

### PPF 的局限性

- **衰减**：每级 3 dB → 多级级联信号衰减严重 → 后级用大电阻缓解衰减，但噪声增加
- **噪声**：RC 热噪声直接进入信号路径
- **结论**：PPF 在 RF 接收机中**仅偶尔使用**。在低中频架构中，PPF 可实现为"复数滤波器"兼做信道选择 [12]

## 双正交下变频 (Double-Quadrature Downconversion)

![]  *(Fig. 4.86)*

**核心创新**：RF 信号先分解为正交分量 → 每路 RF 分量各自正交下变频 → 加减组合产生最终 I/Q IF 输出。

总增益和相位失配：
$$\frac{\Delta A}{A} = \underbrace{\frac{\Delta A_{RF}}{A_{RF}} \cdot \frac{\Delta A_{LO}}{A_{LO}}}_{\text{极小，可忽略}} + \frac{\Delta G_{mix}}{G_{mix}}$$

$$\tan(\Delta\phi) = \underbrace{\tan(\Delta\phi_{RF}) \cdot \tan(\Delta\phi_{LO})}_{\text{极小，可忽略}} + \frac{\tan(\Delta\phi_{mix})}{2}$$

> 物理：RF 路径和 LO 路径的失配以**乘积**形式出现 → 二阶小量 → IRR 仅受**混频器自身失配**限制。这是用复杂度换鲁棒性——四个混频器的代价让 IRR 不再受限于 RF/LO 路径的版图匹配。

然而即使无相位失配，$\Delta G_{mix}/G_{mix} < 0.1\%$ 才达到 IRR = 60 dB——电阻匹配的极严苛要求 → **仍须校准**以达到高性能 [7, 9]。

| 维度 | 零中频 | 低中频 | 外差 |
|------|--------|--------|------|
| 镜像 | 无 | 邻道（弱） | 远频（强） |
| $1/f$ 惩罚 | 重（12 dB） | 轻（3.62 dB） | 无 |
| DC 偏移 | 致命 | 交流耦合可解 | 无 |
| IRR 需求 | — | 中等（~30 dB） | 高（>60 dB） |
| ADC 带宽 | $f_{BW}$ | $2f_{BW}$ | $f_{BW}$ |
| 适用标准 | 宽带（11g） | **窄带（GSM）** | 高性能窄带 |

> 低中频是 GSM 等窄带标准的最优解——闪烁噪声可承受、镜像只需邻道 IRR、数字域 Hilbert 避开模拟 RC-CR 陷阱。架构选择 = 在 LO 位置图上选择一个点，均衡 DC 相关代价和镜像抑制难度。

# 发射机架构

## 一般考量 (§4.3.1)

发射机 = 调制 + 上变频 + 功率放大。现代系统以**正交基带信号**驱动：

$$x(t) = A(t) \cos[\omega_c t + \phi(t)] = \underbrace{A(t)\cos\phi(t)}_{x_{BB,I}(t)} \cos\omega_c t - \underbrace{A(t)\sin\phi(t)}_{x_{BB,Q}(t)} \sin\omega_c t$$

> 物理：任意窄带调制都可分解为正交基带形式——$\cos\omega_c t$ 和 $\sin\omega_c t$ 是两个正交载波，$x_{BB,I}$ 和 $x_{BB,Q}$ 是两个独立调制维度。这是 I/Q 发射机的普适性基础。

**基带脉冲成形**（Fig. 4.87）：矩形数据脉冲 → ROM 查表（过采样）→ DAC → LPF → 平滑脉冲。模拟域脉冲成形需笨重滤波器 → 数字 + 模拟混合方案为主流。

与接收机的关键区别：基带信号在发射端**自身产生** → 幅度足够大（几百 mV）→ 混频器噪声远不如接收机苛刻。

## 直接变频发射机 (§4.3.2)

![]  *(Fig. 4.88)*

I/Q 基带 → 正交上变频 → PA → 匹配网络 → 天线。匹配网络提供最大功率传输 + 滤除 PA 非线性产生的带外分量。

### PA 与前级驱动（例 4.37）

PA 用大晶体管承载大电流 → 输入电容大 → 需**预驱动器 (predriver)** 缓冲。直接放大上变频器驱动 PA 的代价：晶体管宽度 ↑、偏置电流 ↑ → LO 端口负载电容 ↑ → LO 需额外缓冲 + 功耗增大。

> 物理：上变频器和 PA 之间的接口是**电流驱动能力**问题——不是电压摆幅不够，而是电容负载导致的带宽和 LO 驱动负担。

### I/Q 失配——无用边带

**两音测试法**：I/Q 输入各施加 $V_0\cos\omega_{in}t$ 和 $V_0\sin\omega_{in}t$。理想情况输出仅有 $\omega_c + \omega_{in}$ 处的单边带。增益失配 $\varepsilon$ + 相位失配 $\Delta\theta$ 时：

$$\frac{P_{-}}{P_{+}} = \frac{(1+\varepsilon)^2 - 2(1+\varepsilon)\cos\Delta\theta + 1}{(1+\varepsilon)^2 + 2(1+\varepsilon)\cos\Delta\theta + 1}$$

与接收机 Hartley 的 IRR 公式（4.77）**完全相同**——无用边带 $\omega_c - \omega_{in}$ 就是上变频的"镜像"。

> 物理：正交上变频的正交基带 + 正交载波 → 单边带合成的成败取决于两路的对消精度。失配 ↔ 对消失败 ↔ 镜像（无用边带）泄漏。$P_-/P_+ \approx -30\text{ dB}$ 通常足够，但精确需求取决于调制类型。

**校准方案**（Fig. 4.90–4.91）：
1. **相位校准**：单音同时注入 I/Q → 输出功率 $V_0^2[1+(1+\varepsilon)\sin\Delta\theta]$ → 先归零 $\varepsilon$，再驱动 $\sin\Delta\theta \to 0$
2. **增益校准**：依次仅给 I、仅给 Q → 两次输出功率差 $\overline{V_{out1}^2} - \overline{V_{out2}^2} = V_0^2 \varepsilon$ → 驱动至零

$\Delta\theta = 1^\circ$ → $\sin\Delta\theta = 1.75\%$ → 功率测量 ADC 需 ~7–8 bit 分辨率。

### 载波泄漏 (Carrier Leakage)

基带电路和混频器输入端口的 DC 偏移 → 上变频器输出含**未调载波**分量：

$$V_{out}(t) = \underbrace{A(t)\cos(\omega_c t + \phi)}_{\text{调制信号}} + \underbrace{V_{OS1}\cos\omega_c t - V_{OS2}\sin\omega_c t}_{\text{载波泄漏}}$$

$$\text{Relative Carrier Leakage} = \frac{\sqrt{V_{OS1}^2 + V_{OS2}^2}}{\sqrt{\overline{A^2(t)}}}$$

**两个危害**：
1. **星座畸变**（Fig. 4.92）：星座整体平移（I 方向偏移 $V_{OS1}$，Q 方向偏移 $V_{OS2}$）→ EVM 增大
2. **功率控制失效**（Fig. 4.93）：CDMA 移动台靠近基站时需降低发射功率 → 基带幅度减小 → 载波泄漏占比增大 → 泄漏功率主导总输出 → 难以测量实际信号功率。**PA 自身增益调节**可避免此问题

> 物理：载波泄漏 = LO 频率的"恒包络干扰"——与调制信号无关、不携带信息、但占用发射功率。$A(t)$ 增大可降低相对泄漏，但混频器输入端非线性也随之增大 → 折衷。

**DAC 抵消**（Fig. 4.94，例 4.39）：基带处理器输出零 → 功率检测器仅测泄漏 → 双 DAC 注入校正偏移 → 环路收敛 → 值锁存。需双 DAC（式 4.139：单 DAC 无法同时抵消 $V_{OS1}\cos\omega_c t$ 和 $V_{OS2}\sin\omega_c t$ 两项）。LMS 算法或穷举搜索（8-bit DAC → 仅 $256\times256$ 种组合）。

### 混频器线性度

上变频混频器无外来干扰 → 但基带端口非线性 $\alpha_1 x + \alpha_3 x^3$ 会恶化信号：

$$V_{out}(t) = \left(\alpha_1 A + \frac{3}{4}\alpha_3 A^3\right)\cos(\omega_c t + \phi) + \underbrace{\frac{\alpha_3 A^3}{4}\cos(\omega_c t - 3\phi)}_{\text{三倍调制指数 → 带宽扩展}}$$

对变包络信号，$A^3(t)$ 进一步加剧。良好设计中，PA 输出在混频器非线性显现**之前**就进入压缩 → 混频器线性度通常不成为瓶颈。

### TX 线性度与回退 (Back-off)

可变包络调制的信号压缩以**回退**衡量（Fig. 4.95）：802.11a 的 64-QAM OFDM → 平均功率须比 $P_{1dB}$ 低 ~**8 dB**。峰值摆幅 $V_0$ 对应 $P_{1dB}$ → 平均摆幅不超 $V_0/2.51$。

**压缩的瓶颈**（Fig. 4.96）：PA 输出端电压摆幅最大 → PA 主导 TX 压缩。良好设计 = PA 增益最大化 + 前级输出摆幅最小化 → 确保 PA 先于前级进入压缩。

**例：预驱动器 + PA 级联压缩点**（例 4.40）：

$$A_{1dB,in} = \sqrt{0.145 \left| \frac{\beta_1 \alpha_1}{\beta_1 \alpha_3 + \beta_3 \alpha_1^3} \right|}$$

若 $\beta_1\alpha_3 = -\beta_3\alpha_1^3$ → $A_{1dB,in} \to \infty$ → 一级压缩被另一级扩张抵消。输出压缩点：
$$A_{1dB,out} = A_{1dB,in} \times |\alpha_1\beta_1| \times \frac{1}{1.12}$$

### 振荡器牵引 (Injection Pulling)——直接变频发射机特有

**机制**（Fig. 4.97）：PA 输出大摆幅（1 W → $20\text{ V}_{pp}$ @ 50Ω）→ 通过衬底/封装/PCB 耦合到 LO → **注入牵引**。直接变频 TX 中 $\omega_{PA} = \omega_{LO}$ → 耦合最严重。

> 物理：PA 输出可看作注入振荡器的"干扰正弦波" $\omega_{inj} = \omega_{LO} + \Delta\omega$（$\Delta\omega \ll \omega_{LO}$）→ 振荡器输出相位被周期性调制 → 时域出现急剧的 $360^\circ$ 相位跳变（cycle slips）→ 频谱严重不对称（Fig. 4.98）——脉冲间距**不等于** $\Delta\omega$。

**影响因素**：LO 内部摆幅（越大越抗牵引）、振荡器 Q 值、PA 差分布局（耦合低 30–40 dB）、PLL 反馈环的校正能力、版图对称性 + 封装。典型设计中 PA > **0 dBm** 即可能严重牵引。

**解决方案**：$\omega_{LO}$ 与 $\omega_c$ 必须充分分离（> 20%）→ 引出 §4.3.3 的现代架构。

### RX 频带噪声

某些标准（如 GSM）规定了 TX 在 RX 频带的最大可容忍噪声。直接变频 TX 中基带电路 + 上变频器 + PA 都可能贡献 RX 频带噪声 → Offset-PLL 架构可解决（第 9 章）。

## 现代直接变频发射机 (§4.3.3)

核心思想：$\omega_{LO} \neq \omega_c$ → 避免注入牵引。$\omega_c$ 由 $\omega_{LO}$ 通过分频、混频等操作**衍生**。

### 方案 1：LO 在 $2\omega_c$（Fig. 4.99）——最流行

$\omega_{LO} = 2\omega_c$ → ÷2 电路产生 $\omega_c$ 的**正交载波**。双重优势：
1. LO 远离 PA 输出频率 → 注入牵引大幅减小
2. 分频器天然产生 I/Q 正交相位（否则高频正交产生困难——第 8 章）

> PA 非线性仍产生二次谐波分量 → 仍可能对 $2\omega_c$ 的 LO 造成残余牵引 → 依赖版图和隔离技术抑制。

**主要代价**：÷2 电路工作在**两倍载波频率** → 可能成为整个收发机的速度瓶颈（分频器设计见第 10 章）。但相比其他架构的更大缺陷，为 ÷2 电路投入设计努力是完全值得的。

### 方案 2：LO 在 $\omega_c/2$ + 倍频器（Fig. 4.100，例 4.41）

$\omega_{LO} = \omega_c/2$ → 倍频器 → PPF 产生正交相位。**唯一优势**：PA 的**任何**谐波都无法牵引 LO（没有谐波等于 $\omega_{LO}$）。**致命缺陷**：倍频器 + PPF 损耗极大 → 需高功耗缓冲器。

### 方案 3：SSB 混频——单振荡器 + 混频衍生载波

**基本思路**（Fig. 4.101）：单振荡器 $\omega_1$ → ÷2 → 混频器将 $\omega_1$ 与 $\omega_1/2$ 相乘 → 输出含 $\omega_1 \pm \omega_1/2$，即 $\omega_1/2$ 和 $3\omega_1/2$。两者幅度相等、互成"镜像"。

**双载波问题**：若两者均保留 → 一半功率浪费在无用载波 + 无用载波干扰其他信道 → 必须抑制一个。

> LC 二阶滤波器谐振在 $3\omega_1/2$ → 对 $\omega_1/2$ 衰减 $8Q/3$ → Q = 5–10 → 仅 25–30 dB → 功率浪费可接受，信道干扰不可接受。且两频率仅差 3 倍 → 滤波选择性不足。

**SSB 混频器**（Fig. 4.102）：三角函数恒等式 $\cos\omega_1 t \cos\omega_2 t - \sin\omega_1 t \sin\omega_2 t = \cos(\omega_1 + \omega_2)t$ → 正交混频 + 减法 → 产生**仅有一个边带的输出**。

> 物理：SSB 混频器的本质与 Hartley 镜像抑制完全相同——两个频率分量在正交空间中形成不同的旋转序列，叠加/相减选择性保留一个边带、消除另一个。式 4.127 的无用/有用边带功率比与 Hartley IRR 是一回事。

失配 → $P_-/P_+$ 约 30–40 dB → 再经 LC 滤波衰减 25–30 dB → 总抑制约 **55–70 dB**。

**SSB 混频器的谐波杂散**（Fig. 4.103–4.104）：

混频器某端口的三阶非线性 $\alpha_1 x + \alpha_3 x^3$ → 三次谐波与另一端口基频混频 → 两个杂散：$3\omega_1 - \omega_2$ 和 $3\omega_2 - \omega_1$。

$$\begin{aligned} V_{out}(t) &= \left(\alpha_1 A + \frac{3}{4}\alpha_3 A^3\right) \cos(\omega_1 + \omega_2)t \\ &+ \underbrace{\frac{\alpha_3 A^3}{4} \cos(3\omega_1 - \omega_2)t}_{\text{谐波杂散}} \end{aligned}$$

> 物理：$\cos^3\omega_1 t = \frac{1}{4}\cos 3\omega_1 t + \frac{3}{4}\cos\omega_1 t$ → 三次谐波由 $\alpha_3$ 产生 → $3\omega_1$ 与 $\omega_2$ 混频 → 落在 $3\omega_1 \pm \omega_2$。SSB 混频的理想减法只对消基频产生的无用边带，不对消谐波项。

**关键困境**：典型混频器只能线性化**一个端口**（第 6 章）→ 线性化端口的三次谐波可压制到极低 → 但另一端口为保持合理增益必然高度非线性 → **两个杂散只能压制一个**。剩余杂散仅比有用分量低 10 dB（因子 1/3——方波三次谐波正好是基频的 1/3）。

例：$\omega_2 = \omega_1/2$ → 杂散 $3\omega_1 - \omega_2 = 5\omega_1/2$ 和 $3\omega_2 - \omega_1 = \omega_1/2$。若线性化 $\omega_2$ 端口 → $\omega_1/2$ 杂散可压制 → 但 $5\omega_1/2$ 仍需**大量滤波**。

**正交载波 SSB TX**（Fig. 4.105–4.106）：为同时产生 $\cos(\omega_1+\omega_2)t$ 和 $\sin(\omega_1+\omega_2)t$，复制 SSB 混频器为双路 → 完整的正交上变频载波。

![]  *(Fig. 4.106)*

**两个缺点**：
1. 谐波杂散（如 $5\omega_1/2$）需要额外滤波
2. LO 本身需提供正交相位——第 8 章的难题

**例 4.42——÷4 替代 ÷2**：$\omega_2 = \omega_1/4$ → 无用边带 $3\omega_1/4$ 和有用边带 $5\omega_1/4$ 靠更近 → 滤波更难。谐波杂散 $11\omega_1/4$（略高于 ÷2 方案的 $5\omega_1/2$）和 $\omega_1/4$（远低于 ÷2 方案的 $\omega_1/2$ → 更易滤波）。![] *(Fig. 4.107)*

### 三种方案对比

| | LO 在 $2\omega_c$ | LO 在 $\omega_c/2$ | SSB 混频 |
|---|---|---|---|
| 牵引风险 | 残余（二次谐波） | **零** | 低（频率差大） |
| 正交产生 | 分频器天然产生 | 需 PPF | LO 仍需正交 |
| 谐波杂散 | 无 | 无 | **有**（仅可压制一个） |
| 损耗 | 分频器功耗 | 倍频器 + PPF 高损耗 | SSB 混频衰减 |
| 速度瓶颈 | ÷2 需在 $2f_c$ 工作 | 倍频器需在 $f_c$ 工作 | 混频器 + LO 在 $f_c$ 附近 |
| 实用性 | ⭐⭐⭐ **最流行** | ⭐ 极少用 | ⭐⭐ 特定场景

## 外差发射机 (§4.3.4)

核心动机：分**两步**上变频 → LO 频率始终远离 PA 输出频谱 → 从根源规避注入牵引（§4.3.2 直接变频 TX 的顽疾）。外差 TX 是外差接收机（§4.2.1）的**对偶**。

### 两步上变频（Fig. 4.108）

基带 I/Q → 上变频到中频 $\omega_1$ → 再与 $\omega_2$ 混频 → 载波 $\omega_1 + \omega_2$。第二混频器同时产生 $\omega_1 - \omega_2$ → 需 BPF 滤除。

> 物理：I/Q 正交合成在**远低于载波**的中频完成——失配引入的相位误差随频率增长，低频合成的增益/相位失配更小。失配公式与 §4.3.2 直接变频 TX 完全相同（无用边带即上变频的"镜像"）。

![] *(Fig. 4.108)*

### 滑动中频 TX（Fig. 4.109）

仿照滑动中频接收机（Fig. 4.26a）：**取消第一振荡器**，两个 LO 相位都由第二振荡器分频衍生。第二 LO $= \omega_1$，第一 LO $= \omega_1/2$（÷2）→ 载波 $= \omega_1 + \omega_1/2 = 3\omega_1/2$。

> 物理：与滑动中频 RX 对偶——单振荡器省去一个 VCO（避免双振荡器互相牵引 + 省面积），代价是载波锁定为 $3\omega_1/2$，中频不能自由选取。

![] *(Fig. 4.109)*

### 载波泄漏（Fig. 4.110）

两处 DC 偏移各产生一个泄漏分量：
- **基带 DC 偏移** → 正交上变频器输出 $\omega_1/2$ 处泄漏 → 可用 §4.3.2 的 DAC 抵消最小化
- **RF 混频器输入 DC 偏移** → $\omega_1$ 处泄漏 → 只能靠滤波

$\omega_1$ 泄漏比下边带 $\omega_1/2$ **更靠近**有用信号（$3\omega_1/2$）→ 更难滤除，但其幅度**远小于**下边带。RF 混频后的滤波器须同时压制二者。

![] *(Fig. 4.110)*

### 混频杂散——两类 LO 谐波

**① 第一 LO 谐波（Fig. 4.111）**：开关式混频器输出遵循 sinc 包络 → 正交上变频器将基带与第一 LO 的 3、5 次谐波混频 → 信号频谱复制到 $\omega_1/2,\ 3\omega_1/2,\ 5\omega_1/2$，幅度依次为 $1,\ 1/3,\ 1/5$。与第二 LO $\omega_1$ 混频后上下搬移：有用边带 $+3\omega_1/2$ 反被 $5\omega_1/2$ 与 $\omega_1$ 的混频产物**增强**；无用边带 $\omega_1/2,\ 5\omega_1/2,\ 7\omega_1/2$ 由 RF BPF 压制。

**② 第二 LO 谐波（Fig. 4.112）——自污染**：IF 频谱不仅与 $\omega_1$ 混频，还与 $3\omega_1,\ 5\omega_1$ 混频 → IF 边带 $-3\omega_1/2$ 与 $+3\omega_1$ 混频后落到 $+3\omega_1/2$，**正好压在有用边带上**；$-5\omega_1/2$ 与 $+5\omega_1$ 同理。

> 物理：自污染是外差 TX **特有**的痛点——无用边带被第二 LO 高次谐波搬回有用频率，与信号同频 → 滤波无法去除。直接变频 TX 无此机制（例 4.43）。

**严重程度**：$-3\omega_1/2$ 边带比有用信号低 10 dB，再与 $3\omega_1$（方波三次谐波 $=$ 基频 $1/3$ → 约 10 dB）混频又降 10 dB → 污染约 **$-20$ dB**。仅对中等 SNR（10–12 dB，如 QPSK）或中等误码率（$10^{-2}$）的调制可接受，且上变频前仍需 IF 滤波，以免无用边带落入邻道。

**例：直接变频与外差 TX 的杂散对比**（例 4.43）：直接变频 TX（Fig. 4.106）主杂散仅在 $5\omega_1/2$，**无**自污染；外差 TX（Fig. 4.109）杂散更多且存在自污染。

**SSB IF 混频改进（Fig. 4.113）**：把 RF 混频器的无用边带 $\omega_1 - \omega_1/2$ 用 SSB 混频抑制 → IF 须做成正交形式，双正交上变频器产生

$$x_{IF,I}(t) = A(t)\cos\theta\cos\frac{\omega_1 t}{2} - A(t)\sin\theta\sin\frac{\omega_1 t}{2} = A(t)\cos\left(\frac{\omega_1 t}{2} + \theta\right)$$

$$x_{IF,Q}(t) = A(t)\cos\theta\sin\frac{\omega_1 t}{2} + A(t)\sin\theta\cos\frac{\omega_1 t}{2} = A(t)\sin\left(\frac{\omega_1 t}{2} + \theta\right)$$

RF SSB 混频器再搬到 $\omega_1 + \omega_1/2$。

![] *(Fig. 4.113)*

**三个代价**：① 振荡器须提供正交输出（第 8 章难题）；② 混频器数量翻倍；③ 负载翻倍。代价 ① 可用 $2\omega_1$ 振荡器 + ÷2 缓解，但这样只比直接变频架构（Fig. 4.106）略简单。**÷4 变体**：将 ÷2 换成 ÷4 → IF 在 $\omega_1/4$、RF 在 $\omega_1 + \omega_1/4 = 5\omega_1/4$（Problem 4.25）。

### 直接变频 ↔ 外差 TX 的根本对偶

| | 直接变频（§4.3.2–3） | 外差（§4.3.4） |
|---|---|---|
| 注入牵引 | 严重（$\omega_{LO}=\omega_c$）→ 需衍生载波规避 | **天然免疫**（LO 远离 PA 频率） |
| I/Q 合成频率 | 载波频率 | **低中频** → 失配更小 |
| 混频杂散 | 少（主杂散 $5\omega_1/2$） | 多 + **自污染**（同频不可滤） |
| 滤波负担 | 轻 | 重（下边带 + $\omega_1$ 泄漏 + 谐波杂散） |

> 外差 TX 用"多一级混频 + 更重的滤波和自污染"换取"彻底摆脱注入牵引 + 低频 I/Q 合成"——与外差 RX 用"镜像代价"换取"高选择性"是同一种取舍逻辑。

## 其他发射机架构 (§4.3.5)

Offset-PLL、环内调制（in-loop modulation）——第 10 章；极性调制（polar modulation）——第 12 章。

# 架构选择
| 架构 | 镜像 | DC 偏移 | 闪烁噪声 | 适用 |
|------|------|---------|----------|------|
| 外差 | 重 | 无 | 无 | 高性能窄带 |
| 直接变频 | 无 | 重 | 重（窄带） | 宽带/多标准 |
| 低中频 | 轻（邻道） | 无 | 轻 | 窄带（GSM） |

物理：LO 相对信号的位置决定瓶颈——重合 → DC/闪烁；偏离 → 镜像；边沿 → 折衷。全双工 → TX 泄漏推高 $P_{1dB}$。多标准 → 零中频最灵活，架构选择 = 选择承受哪种代价。
