# 2.1 传输线的集总元件电路模型

传输线理论是场分析与基本电路理论之间的桥梁，在微波电路与器件分析中极其重要。波在传输线上的传播既可从电路理论的推广入手，也可从 Maxwell 方程的特殊化入手——本书两个视角都讲，且传播方程与第 1 章平面波方程非常相似。

## 从集总到分布：传输线的本质

电路理论与传输线理论的**关键区别是电尺寸**。电路分析假设网络物理尺寸远小于电波长；传输线则可能是波长的可观分数甚至多个波长。故传输线是**分布参数网络（distributed-parameter network）**——电压电流的幅值和相位沿线变化；普通电路分析处理**集总元件（lumped element）**——电压电流在元件尺寸上几乎不变。

传输线（TEM 波）总是至少两个导体，常画成双线（图 2.1a）。取无限小长度 $\Delta z$ 的一段建模为集总电路（图 2.1b），其中 $R, L, G, C$ 都是**单位长度量**：

- $R$ = 单位长度串联电阻（两导体），Ω/m
- $L$ = 单位长度串联电感（两导体），H/m
- $G$ = 单位长度并联电导，S/m
- $C$ = 单位长度并联电容，F/m

物理来源：$L$ 是两导体的总自感，$C$ 来自两导体的靠近；$R$ 来自导体有限电导率，$G$ 来自导体间介质的介电损耗。$R$、$G$ 代表损耗。有限长传输线 = 图 2.1b 节段级联。

**So what**：$\lambda \sim d$ 判据（[[C1-电磁理论基础#分布元件与集总元件的分界|§1.1 分布 vs 集总]]）在这里落实为"传输线是否需要分布参数描述"。↔ Hayt 用时间延迟判据表述同一件事（[[Hayt-工程电磁场/C10-传输线#10.1 传输线中波传播的物理描述|Hayt: 时间延迟判据]]）。

## 电报方程（时域形式）

对图 2.1b 的回路用 KVL、对上方结点用 KCL：

$$v(z,t) - R\Delta z\, i(z,t) - L\Delta z\frac{\partial i(z,t)}{\partial t} - v(z+\Delta z,t) = 0 \tag{2.1a}$$

$$i(z,t) - G\Delta z\, v(z+\Delta z,t) - C\Delta z\frac{\partial v(z+\Delta z,t)}{\partial t} - i(z+\Delta z,t) = 0 \tag{2.1b}$$

除以 $\Delta z$ 取 $\Delta z \to 0$ 极限：

$$\frac{\partial v(z,t)}{\partial z} = -R i(z,t) - L\frac{\partial i(z,t)}{\partial t} \tag{2.2a}$$

$$\frac{\partial i(z,t)}{\partial z} = -G v(z,t) - C\frac{\partial v(z,t)}{\partial t} \tag{2.2b}$$

这就是**传输线方程（transmission line equations）**，即**电报方程（telegrapher equations）**的时域形式——电压/电流沿线变化率由串联阻抗压降与并联导纳漏流决定。

**Why 名字**：历史上源于电报线的建模。**So what**：这是传输线理论的核心方程，一切后续分析（波传播、反射、Smith 圆图）都从它出发。↔ 与 [[Hayt-工程电磁场/C10-传输线#10.2 传输线方程|Hayt: 电报方程 (10.5)(10.8)]] 完全一致。

## 电报方程（频域相量形式）

正弦稳态（cosine 相量）下，(2.2) 化简为：

$$\frac{dV(z)}{dz} = -(R+j\omega L)I(z) \tag{2.3a}$$

$$\frac{dI(z)}{dz} = -(G+j\omega C)V(z) \tag{2.3b}$$

**关键观察**：(2.3a)(2.3b) 与 Maxwell 旋度方程 (1.41a)(1.41b) 形式完全对偶——$V \leftrightarrow E$、$I \leftrightarrow H$、$R+j\omega L \leftrightarrow j\omega\mu$、$G+j\omega C \leftrightarrow j\omega\epsilon$。这是"传输线理论 = Maxwell 的一维降维"的数学证据。

## 传输线上的波传播

联立求解 (2.3a)(2.3b) 得 $V(z)$、$I(z)$ 的波动方程：

$$\frac{d^2 V(z)}{dz^2} - \gamma^2 V(z) = 0 \tag{2.4a}$$

$$\frac{d^2 I(z)}{dz^2} - \gamma^2 I(z) = 0 \tag{2.4b}$$

其中**复传播常数（complex propagation constant）**：

$$\gamma = \alpha + j\beta = \sqrt{(R+j\omega L)(G+j\omega C)} \tag{2.5}$$

（频率的函数。）行波解：

$$V(z) = V_o^+ e^{-\gamma z} + V_o^- e^{\gamma z} \tag{2.6a}$$

$$I(z) = I_o^+ e^{-\gamma z} + I_o^- e^{\gamma z} \tag{2.6b}$$

$e^{-\gamma z}$ 项 = $+z$ 方向行波，$e^{\gamma z}$ 项 = $-z$ 方向行波。把 (2.6a) 代入 (2.3a) 求电流，比较 (2.6b)，定义**特性阻抗（characteristic impedance）**：

$$Z_0 = \frac{R+j\omega L}{\gamma} = \sqrt{\frac{R+j\omega L}{G+j\omega C}} \tag{2.7}$$

联系线上电压电流：

$$\frac{V_o^+}{I_o^+} = Z_0 = \frac{-V_o^-}{I_o^-}$$

故电流可写为：

$$I(z) = \frac{V_o^+}{Z_0}e^{-\gamma z} - \frac{V_o^-}{Z_0}e^{\gamma z} \tag{2.8}$$

（注意反射波电流前的负号。）

时域电压波形：

$$v(z,t) = |V_o^+|\cos(\omega t - \beta z + \phi^+)e^{-\alpha z} + |V_o^-|\cos(\omega t + \beta z + \phi^-)e^{\alpha z} \tag{2.9}$$

**波长** $\lambda = 2\pi/\beta$，**相速度** $v_p = \omega/\beta = \lambda f$。

**Why γ 与 Z₀ 是核心参数**：$\gamma$ 描述传播（衰减 + 相位），$Z_0$ 描述行波电压/电流比。**So what**：$Z_0 = V^+/I^+$ 是微波工程最重要的阻抗概念，与平面波本征阻抗 $\eta = E/H$ 同构（$Z_0$ 含几何因子，$\eta$ 仅取决于介质）。↔ 平面波 $\gamma$ 同一数学结构（[[C1-电磁理论基础#一般有损耗介质中的平面波|§1.4 平面波 γ]]）。

## 无损耗线

一般传输线含损耗，$\gamma$、$Z_0$ 为复数。但很多实际线损耗很小可忽略。令 $R=G=0$，由 (2.5)：

$$\beta = \omega\sqrt{LC} \tag{2.12a}$$

$$\alpha = 0 \tag{2.12b}$$

特性阻抗 (2.7) 退化为：

$$Z_0 = \sqrt{\frac{L}{C}} \tag{2.13}$$

（纯实数。）无损耗线电压电流一般解：

$$V(z) = V_o^+ e^{-j\beta z} + V_o^- e^{j\beta z} \tag{2.14a}$$

$$I(z) = \frac{V_o^+}{Z_0}e^{-j\beta z} - \frac{V_o^-}{Z_0}e^{j\beta z} \tag{2.14b}$$

波长 $\lambda = 2\pi/\beta = 2\pi/(\omega\sqrt{LC})$，相速度 $v_p = \omega/\beta = 1/\sqrt{LC}$。

**So what**：无损耗假设使 $Z_0$ 为实数、$v_p$ 与频率无关（无色散）——2.3 节端接无损耗线分析、Smith 圆图全部建立在这个假设上。↔ [[Hayt-工程电磁场/C10-传输线#10.3 无损耗传输|Hayt: v=1/√(LC)]]。

# 2.2 传输线的场分析

本节从 Maxwell 方程重新推导时谐形式的电报方程：先用场量导出传输线参数 $(R, L, G, C)$，再对同轴线特例用这些参数导出电报方程。

## 传输线参数：从场量到 RLGC

考虑 1 m 长均匀传输线，场 $\bar{E}$、$\bar{H}$，$S$ 为横截面（图 2.2）。设导体间电压 $V_o e^{\pm j\beta z}$、电流 $I_o e^{\pm j\beta z}$。

时间平均存储磁能（(1.86)）$W_m = \frac{\mu}{4}\int_S \bar{H}\cdot\bar{H}^* ds$，电路理论给 $W_m = L|I_o|^2/4$，故单位长度自感：

$$L = \frac{\mu}{|I_o|^2}\int_S \bar{H}\cdot\bar{H}^* ds \ \mathrm{H/m} \tag{2.17}$$

电能同理（(1.84)，$W_e = C|V_o|^2/4$）：

$$C = \frac{\epsilon}{|V_o|^2}\int_S \bar{E}\cdot\bar{E}^* ds \ \mathrm{F/m} \tag{2.18}$$

导体有限电导率损耗（(1.131)，$\bar{H}$ 切向于 $S$）$P_c = \frac{R_s}{2}\int_{C_1+C_2}\bar{H}\cdot\bar{H}^* d\ell$，电路理论 $P_c = R|I_o|^2/2$，故：

$$R = \frac{R_s}{|I_o|^2}\int_{C_1+C_2}\bar{H}\cdot\bar{H}^* dl \ \Omega/\mathrm{m} \tag{2.19}$$

（$R_s = 1/\sigma\delta_s$ 为表面电阻，$C_1+C_2$ 为导体边界积分路径。）

有损介质耗散（(1.92)，$\epsilon''$ 为复介电常数虚部）$P_d = \frac{\omega\epsilon''}{2}\int_S\bar{E}\cdot\bar{E}^* ds$，电路理论 $P_d = G|V_o|^2/2$，故：

$$G = \frac{\omega\epsilon''}{|V_o|^2}\int_S \bar{E}\cdot\bar{E}^* ds \ \mathrm{S/m} \tag{2.20}$$

**关键思想**：这四式是"场量 → 电路量"的翻译器——用场储能/场损耗分别对应 $L/C$ 与 $R/G$。**Why**：传输线参数必须从场分布算出来，才能既保留几何信息又降维到电路。**So what**：对简单 TEM 线可直接积分出闭式参数；对复杂线则直接求场解（第 3 章）。

## 例题 2.1：同轴线的传输线参数

同轴线内 TEM 行波场（图 2.3）：

$$\bar{E} = \frac{V_o\hat{\rho}}{\rho\ln b/a}e^{-\gamma z},\qquad \bar{H} = \frac{I_o\hat{\phi}}{2\pi\rho}e^{-\gamma z}$$

导体表面电阻率 $R_s$，填充介质复介电常数 $\epsilon = \epsilon' - j\epsilon''$、磁导率 $\mu = \mu_0\mu_r$。用 (2.17)–(2.20) 算：

$$L = \frac{\mu}{2\pi}\ln\frac{b}{a}\ \mathrm{H/m}$$

$$C = \frac{2\pi\epsilon'}{\ln b/a}\ \mathrm{F/m}$$

$$R = \frac{R_s}{2\pi}\left(\frac{1}{a} + \frac{1}{b}\right)\ \Omega/\mathrm{m}$$

$$G = \frac{2\pi\omega\epsilon''}{\ln b/a}\ \mathrm{S/m}$$

## 从 Maxwell 到场分析电报方程（同轴线特例）

证明电路理论导出的电报方程 (2.3) 也可由 Maxwell 方程得到。同轴线 TEM 波：$E_z = H_z = 0$，方位对称 $\partial/\partial\phi = 0$。场满足旋度方程：

$$\nabla\times\bar{E} = -j\omega\mu\bar{H} \tag{2.21a}$$

$$\nabla\times\bar{H} = j\omega\epsilon\bar{E} \tag{2.21b}$$

（$\epsilon = \epsilon' - j\epsilon''$ 可为复，含介质损耗；此处忽略导体损耗。）展开 (2.21) 得 (2.22)。因 $\hat{z}$ 分量为零，$E_\phi$、$H_\phi$ 必为：

$$E_\phi = \frac{f(z)}{\rho},\qquad H_\phi = \frac{g(z)}{\rho} \tag{2.23}$$

由边界条件 $E_\phi = 0$ 在 $\rho = a, b$，且 $E_\phi$ 形如 (2.23a) → $E_\phi = 0$ 处处；再由 (2.22a) 的 $\hat{\rho}$ 分量得 $H_\rho = 0$。(2.22) 化为：

$$\frac{\partial E_\rho}{\partial z} = -j\omega\mu H_\phi \tag{2.24a}$$

$$\frac{\partial H_\phi}{\partial z} = -j\omega\epsilon E_\rho \tag{2.24b}$$

由 (2.23b)(2.24a) 知 $E_\rho = h(z)/\rho$。代入 (2.24)：

$$\frac{\partial h(z)}{\partial z} = -j\omega\mu g(z),\qquad \frac{\partial g(z)}{\partial z} = -j\omega\epsilon h(z) \tag{2.26}$$

定义电压电流：

$$V(z) = \int_a^b E_\rho d\rho = h(z)\ln\frac{b}{a} \tag{2.27a}$$

$$I(z) = \int_0^{2\pi} H_\phi(a,z)\, a\, d\phi = 2\pi g(z) \tag{2.27b}$$

用 (2.27) 消去 $h,g$，并用前面算出的 $L, G, C$，得电报方程：

$$\frac{\partial V(z)}{\partial z} = -j\omega L I(z) \tag{2.28a}$$

$$\frac{\partial I(z)}{\partial z} = -(G+j\omega C)V(z) \tag{2.28b}$$

（不含 $R$，因假设理想导体。）其他简单传输线可类似分析。

**关键洞察**：场论与电路完全等价——同一条同轴线，用 Maxwell 旋度方程 + 场积分定义的 $V/I$，导出的正是 Kirchhoff 定律得到的电报方程。**So what**：这验证了"传输线 = Maxwell 的一维降维"，也是第 4 章"非 TEM 线 V/I 不唯一 → 需等效 V/I"的动机（[[C4-微波网络分析#TEM 线的电压电流唯一且良定义|§4.1 等效 V/I]]）。

## 无损耗同轴线的传播常数、阻抗与功率流

联立 (2.24a)(2.24b) 消元得 $E_\rho$ 的波动方程：

$$\frac{\partial^2 E_\rho}{\partial z^2} + \omega^2\mu\epsilon E_\rho = 0 \tag{2.29}$$

传播常数 $\gamma^2 = -\omega^2\mu\epsilon$，无损耗介质退化为：

$$\beta = \omega\sqrt{\mu\epsilon} = \omega\sqrt{LC} \tag{2.30}$$

（后一等式用 (2.12)。）**与无损耗介质平面波的传播常数同形——这是 TEM 传输线的一般结果。**

**波阻抗（wave impedance）** $Z_w = E_\rho/H_\phi$，由 (2.24a)（$e^{-j\beta z}$ 依赖）：

$$Z_w = \frac{E_\rho}{H_\phi} = \frac{\omega\mu}{\beta} = \sqrt{\frac{\mu}{\epsilon}} = \eta \tag{2.31}$$

**波阻抗 = 介质本征阻抗 $\eta$——TEM 传输线的一般结果。**

**特性阻抗（characteristic impedance）**：

$$Z_0 = \frac{V_o}{I_o} = \frac{E_\rho\ln b/a}{2\pi H_\phi} = \frac{\eta\ln b/a}{2\pi} = \sqrt{\frac{\mu}{\epsilon}}\frac{\ln b/a}{2\pi} \tag{2.32}$$

特性阻抗与几何有关，不同传输线构型不同。

**关键区分**：$Z_w = E_\rho/H_\phi = \eta$（仅取决于介质）vs $Z_0 = V_o/I_o = \eta\cdot(\text{几何因子})$（取决于介质+几何）。这是 TEM 线的重要概念，三种阻抗（$\eta$ 本征 / $Z_w$ 波 / $Z_0$ 特性）的完整区分见第 4 章（[[C4-微波网络分析#阻抗概念的三种形态|§4.1 三种阻抗]]）。

**功率流**（Poynting 矢量）：

$$P = \frac{1}{2}\int_S \bar{E}\times\bar{H}^*\cdot d\bar{s} = \frac{1}{2}V_o I_o^* \tag{2.33}$$

与电路理论一致。**结论**：传输线的功率**完全通过两导体之间的场传递**，而非沿导体内部传输。有限电导率时功率可能进入导体，但那是耗散为热，不送到负载。

**So what**：这一结论是导体损耗微扰法的基础——用无损耗场分布近似计算 $P_c$（2.7 节）。

# 2.3 端接无损耗传输线

图 2.4 显示端接任意负载阻抗 $Z_L$ 的无损耗传输线。此问题展示传输线上的波反射——分布系统的基本性质。

## 反射系数 $\Gamma$

设源在 $z<0$ 产生入射波 $V_o^+ e^{-j\beta z}$。行波的电压电流比是 $Z_0$；但负载 $Z_L \ne Z_0$ 时，负载处电压电流比必须是 $Z_L$，故必须激发适当幅值的反射波来满足此条件。总电压 = 入射 + 反射（(2.14a)）：

$$V(z) = V_o^+ e^{-j\beta z} + V_o^- e^{j\beta z} \tag{2.34a}$$

$$I(z) = \frac{V_o^+}{Z_0}e^{-j\beta z} - \frac{V_o^-}{Z_0}e^{j\beta z} \tag{2.34b}$$

在 $z=0$ 处 $Z_L = V(0)/I(0)$，解出 $V_o^-$，定义**电压反射系数（voltage reflection coefficient）**：

$$\Gamma = \frac{V_o^-}{V_o^+} = \frac{Z_L - Z_0}{Z_L + Z_0} \tag{2.35}$$

总电压电流：

$$V(z) = V_o^+(e^{-j\beta z} + \Gamma e^{j\beta z}) \tag{2.36a}$$

$$I(z) = \frac{V_o^+}{Z_0}(e^{-j\beta z} - \Gamma e^{j\beta z}) \tag{2.36b}$$

线上电压电流 = 入射 + 反射的叠加，称**驻波（standing waves）**。只有 $\Gamma = 0$ 才无反射；$\Gamma = 0$ 要求 $Z_L = Z_0$，称**匹配（matched）**负载。

时间平均功率流：

$$P_{\mathrm{avg}} = \frac12\frac{|V_o^+|^2}{Z_0}(1 - |\Gamma|^2) \tag{2.37}$$

功率流沿线处处恒定；送到负载的功率 = 入射功率 $|V_o^+|^2/(2Z_0)$ 减去反射功率 $|V_o^+|^2|\Gamma|^2/(2Z_0)$。$\Gamma=0$ 送最大功率；$|\Gamma|=1$ 不送功率（假设源匹配，无再反射）。

**So what**：$\Gamma = (Z_L-Z_0)/(Z_L+Z_0)$ 是微波工程最重要的公式之一——与平面波 $\Gamma = (\eta-\eta_0)/(\eta+\eta_0)$ 同构（$Z_0 \leftrightarrow \eta$），见 [[C1-电磁理论基础#一般介质反射系数与传输系数|§1.7 平面波 Γ]]。

## 驻波比 SWR

失配时反射波导致驻波，电压幅值沿线振荡。由 (2.36a)（$\ell = -z$ 为距负载的正向距离，$\Gamma = |\Gamma|e^{j\theta}$）：

$$|V(z)| = |V_o^+|\,|1 + |\Gamma|e^{j(\theta - 2\beta\ell)}| \tag{2.39}$$

极大值（相位项 $=1$）$V_{\max} = |V_o^+|(1+|\Gamma|)$，极小值（相位项 $=-1$）$V_{\min} = |V_o^+|(1-|\Gamma|)$。

定义**驻波比（standing wave ratio, SWR）**，也称**电压驻波比（VSWR）**：

$$\mathrm{SWR} = \frac{V_{\max}}{V_{\min}} = \frac{1 + |\Gamma|}{1 - |\Gamma|} \tag{2.41}$$

$1 \le \mathrm{SWR} \le \infty$，SWR = 1 表示匹配。相邻两个电压极大（或极小）间距 $\ell = \lambda/2$；极大与极小间距 $\lambda/4$。

**So what**：SWR 是失配的经典度量——高 SWR → 功率传输效率低 → 需阻抗匹配网络（第 5 章）。⚡ trade-off: SWR 反映匹配质量。

## 沿线反射系数变换

(2.35) 定义的是负载处（$\ell = 0$）的反射系数，可推广到线上任一点。由 (2.34a)，反射分量与入射分量之比：

$$\Gamma(\ell) = \frac{V_o^- e^{-j\beta\ell}}{V_o^+ e^{j\beta\ell}} = \Gamma(0)e^{-2j\beta\ell} \tag{2.42}$$

**So what**：$\Gamma(\ell) = \Gamma(0)e^{-2j\beta\ell}$ 是 Smith 圆图上旋转的数学基础——沿线移动 = 相位旋转 $2\beta\ell$，幅值不变（无损耗线）。

## 输入阻抗：传输线阻抗方程

线上实功率流恒定，但电压幅值（失配时）沿线振荡 → 看向负载的输入阻抗必随位置变化。距负载 $\ell$ 处：

$$Z_{\mathrm{in}} = \frac{V(-\ell)}{I(-\ell)} = Z_0\frac{1 + \Gamma e^{-2j\beta\ell}}{1 - \Gamma e^{-2j\beta\ell}} \tag{2.43}$$

用 (2.35) 代入化简得**传输线阻抗方程（transmission line impedance equation）**：

$$Z_{\mathrm{in}} = Z_0\frac{Z_L + jZ_0\tan\beta\ell}{Z_0 + jZ_L\tan\beta\ell} \tag{2.44}$$

**So what**：任意负载经任意长度线后的输入阻抗——是 Smith 圆图、阻抗匹配、放大器设计的核心公式。

## 短路终端（$Z_L = 0$）

短路负载：$\Gamma = -1$，SWR = ∞。由 (2.36)：

$$V(z) = -2jV_o^+\sin\beta z \tag{2.45a}$$

$$I(z) = \frac{2V_o^+}{Z_0}\cos\beta z \tag{2.45b}$$

负载处 $V = 0$（符合短路）、电流最大。输入阻抗：

$$Z_{\mathrm{in}} = jZ_0\tan\beta\ell \tag{2.45c}$$

纯虚数，可取 $+j\infty$ 到 $-j\infty$ 间任意值。$\ell=0$ 时 $Z_{\mathrm{in}}=0$；$\ell=\lambda/4$ 时 $Z_{\mathrm{in}}=\infty$（等效开路）。

**So what**：短路短截线 = 任意电抗值等效，是单短截线调谐的基础（[[C5-阻抗匹配与调谐#单短截线调谐|第 5 章]]）。

> 【插入 Pozar 图 2.6】短路线上电压/电流/阻抗沿线分布。

## 开路终端（$Z_L = \infty$）

开路负载：$\Gamma = 1$，SWR = ∞。由 (2.36)：

$$V(z) = 2V_o^+\cos\beta z \tag{2.46a}$$

$$I(z) = \frac{-2jV_o^+}{Z_0}\sin\beta z \tag{2.46b}$$

负载处 $I = 0$（符合开路）、电压最大。输入阻抗：

$$Z_{\mathrm{in}} = -jZ_0\cot\beta\ell \tag{2.46c}$$

**对偶**：开路 $Z_{\mathrm{in}} = -jZ_0\cot\beta\ell$ 与短路 $Z_{\mathrm{in}} = jZ_0\tan\beta\ell$ 对偶。

> 【插入 Pozar 图 2.8】开路线电压/电流/阻抗沿线分布。

## 四分之一波长变换器（$\ell = \lambda/4$或 $\lambda/4 + n\lambda/2$）

特殊长度：$\ell = \lambda/2$（或其整数倍）时 (2.44) 给出：

$$Z_{\mathrm{in}} = Z_L \tag{2.47}$$

半波长线不改变负载阻抗（无论 $Z_0$ 为何）。

$\ell = \lambda/4$（更一般 $\ell = \lambda/4 + n\lambda/2$）时：

$$Z_{\mathrm{in}} = \frac{Z_0^2}{Z_L} \tag{2.48}$$

称**四分之一波长变换器（quarter-wave transformer）**——以反比方式变换负载阻抗。2.5 节详述。

**So what**：$\lambda/4$ 变换器是阻抗反转器，匹配网络设计的基础（[[C5-阻抗匹配与调谐#四分之一波长变换器|第 5 章]]）。⚡ trade-off: 精确匹配仅单频。

## 两段传输线的连接

特征阻抗 $Z_0$ 的线馈给另一特征阻抗 $Z_1$ 的线（图 2.9）。若负载线无限长（或其远端匹配，无反射），馈线看到的输入阻抗 = $Z_1$，反射系数：

$$\Gamma = \frac{Z_1 - Z_0}{Z_1 + Z_0} \tag{2.49}$$

并非全部入射波被反射，部分透射到第二根线，由**传输系数（transmission coefficient）**给出。$z<0$ 电压 $V(z) = V_o^+(e^{-j\beta z} + \Gamma e^{j\beta z})$；$z>0$（无反射）只有出射波 $V(z) = V_o^+ T e^{-j\beta z}$。$z=0$ 处电压连续：

$$T = 1 + \Gamma = \frac{2Z_1}{Z_1 + Z_0} \tag{2.51}$$

**So what**：$T = 1 + \Gamma = 2Z_1/(Z_1+Z_0)$ 与平面波 $T$ 同构（[[C1-电磁理论基础#一般介质反射系数与传输系数|§1.7]]）；是网络级联 S 参数视角的前身（[[C4-微波网络分析]]）。

## 回波损耗与插入损耗

失配时源可用功率并未全部送到负载，这个"损失"称**回波损耗（return loss, RL）**：

$$\mathrm{RL} = -20\log|\Gamma|\ \mathrm{dB} \tag{2.38}$$

匹配负载（$\Gamma=0$）RL = ∞ dB（无反射功率）；全反射（$|\Gamma|=1$）RL = 0 dB（全反射）。无源网络的 RL 非负。

两段线连接的**插入损耗（insertion loss, IL）**：

$$\mathrm{IL} = -20\log|T|\ \mathrm{dB} \tag{2.52}$$

**单位制（POINT OF INTEREST：分贝与奈培）**：
- 功率比 $P_1/P_2$ 用分贝表示 $10\log(P_1/P_2)$ dB。功率比 2 → 3 dB，0.1 → −10 dB。级联组件用 dB 加减（6 dB 衰减器 + 23 dB 放大器 = 17 dB 增益）。
- 等电阻负载下电压比 $20\log(V_1/V_2)$ dB。
- 电压比也可用**奈培（neper, Np）** $\ln(V_1/V_2)$ Np；功率比 $\frac12\ln(P_1/P_2)$ Np。$1\ \mathrm{Np} = 10\log e^2 = 8.686$ dB。
- 绝对功率：以 1 mW 为参考，$10\log(P_1/1\ \mathrm{mW})$ dBm。1 mW = 0 dBm，1 W = 30 dBm。

# 2.4 Smith 圆图

**Smith 圆图（Smith chart）** 是求解传输线问题的图形工具（图 2.10），1939 年由 P. Smith 在 Bell 实验室发明。它不仅是图形技巧——已是现代 CAD 软件与测试设备的一部分，且提供了无需数值计算即可可视化传输线现象的方法，是建立阻抗匹配直觉的核心工具。

## $\Gamma$ 平面上的阻抗圆

Smith 圆图基于反射系数 $\Gamma$ 的极坐标图。$\Gamma = |\Gamma|e^{j\theta}$：$|\Gamma|$（$\le 1$）为半径，$\theta$（$-180^\circ$ 到 $180^\circ$）从水平直径右侧逆时针度量。任何无源可实现的 $|\Gamma|\le1$ 对应图上唯一点。

圆图的真正用途：用印在圆图上的阻抗（导纳）圆，在反射系数与归一化阻抗之间转换。归一化量用小写字母：$z = Z/Z_0$。

负载反射系数（由 (2.35)）：

$$\Gamma = \frac{z_L - 1}{z_L + 1} = |\Gamma|e^{j\theta} \tag{2.53}$$

解出 $z_L$：

$$z_L = \frac{1 + |\Gamma|e^{j\theta}}{1 - |\Gamma|e^{j\theta}} \tag{2.54}$$

写 $\Gamma = \Gamma_r + j\Gamma_i$、$z_L = r_L + jx_L$，分离实虚部：

$$r_L = \frac{1 - \Gamma_r^2 - \Gamma_i^2}{(1-\Gamma_r)^2 + \Gamma_i^2},\qquad x_L = \frac{2\Gamma_i}{(1-\Gamma_r)^2 + \Gamma_i^2} \tag{2.55}$$

整理得两族圆：

$$\left(\Gamma_r - \frac{r_L}{1+r_L}\right)^2 + \Gamma_i^2 = \left(\frac{1}{1+r_L}\right)^2 \tag{2.56a}$$

$$(\Gamma_r - 1)^2 + \left(\Gamma_i - \frac{1}{x_L}\right)^2 = \left(\frac{1}{x_L}\right)^2 \tag{2.56b}$$

(2.56a) 是**电阻圆（resistance circles）**，(2.56b) 是**电抗圆（reactance circles）**。$r_L = 1$ 圆圆心 $\Gamma_r = 0.5$、半径 0.5，过圆图中心。所有电阻圆圆心在 $\Gamma_i = 0$ 轴、都过右侧 $\Gamma = 1$ 点；电抗圆圆心在 $\Gamma_r = 1$ 竖线（图外），也过 $\Gamma = 1$ 点。电阻圆与电抗圆正交。

**关键**：$\Gamma = (z_L-1)/(z_L+1)$ 是 Möbius 变换——把阻抗右半平面映射到单位圆内。↔ 这是 [[C2-传输线理论#反射系数 $\Gamma$|2.3 节 Γ]] 定义的图形化：Smith 圆图 = Γ 极坐标图 + 阻抗网格。

> 【插入 Pozar 图 2.10】Smith 圆图。

## 沿线移动 = 沿等 $\Gamma$ 圆旋转

传输线阻抗方程 (2.44) 用广义反射系数写为：

$$Z_{\mathrm{in}} = Z_0\frac{1 + \Gamma e^{-2j\beta\ell}}{1 - \Gamma e^{-2j\beta\ell}} \tag{2.57}$$

与 (2.54) 同形，只差 $\Gamma$ 项的相位。故：若已在图上画出负载 $\Gamma$，看入长度 $\ell$ 的线的输入阻抗 = 把点绕圆心**顺时针**旋转 $2\beta\ell$（$\theta$ 减去 $2\beta\ell$）。半径不变（无损耗线 $|\Gamma|$ 沿线不变）。

圆图外圈刻有"朝向/远离发生器（generator）"的电波长刻度（WTG/WTL）——发生器方向即远离负载方向。刻度相对，只有两点间波长差有意义。范围 0 到 0.5 波长，反映传输线现象的周期性：$\lambda/2$ 线（或其整数倍）需旋转 $2\beta\ell = 2\pi$ 回到原位 → $\lambda/2$ 线不改变输入阻抗。

**So what**：沿线移动 = 沿等 $|\Gamma|$ 圆旋转，是 VNA 端口延伸（port extension）校准的数学基础（[[C4-微波网络分析#参考面移动|S 参数参考面移动]]）。

### 例题 2.2 Smith 圆图基本操作

负载 $Z_L = 40 + j70\ \Omega$ 端接 100 Ω 线，线长 0.3λ。求负载反射系数、输入端反射系数、输入阻抗、SWR、回波损耗。

归一化 $z_L = 0.4 + j0.7$。在 Smith 圆图上读：$|\Gamma| = 0.59$、SWR = 3.87、RL = 4.6 dB、负载 $\Gamma$ 相角 $104^\circ$。向发生器移 0.3λ（WTG 0.106λ → 0.406λ），得 $z_{\mathrm{in}} = 0.365 - j0.611$ → $Z_{\mathrm{in}} = 36.5 - j61.1\ \Omega$。输入 $\Gamma$ 幅值仍 0.59，相角 $248^\circ$。

## 阻抗-导纳组合 Smith 圆图

Smith 圆图同样可用于归一化导纳，并转换阻抗 ↔ 导纳。归一化形式下，接 $\lambda/4$ 线的负载输入阻抗（由 (2.44)）：

$$z_{\mathrm{in}} = 1/z_L$$

即把归一化阻抗转为归一化导纳。

一圈 = $\lambda/2$，故 $\lambda/4$ 变换 = $180^\circ$ 旋转 = 把某阻抗（导纳）点关于圆心成像得到对应导纳（阻抗）点。

故一个 Smith 圆图既可作阻抗图也可作导纳图。用叠加了常规刻度与旋转 $180^\circ$ 刻度的**阻抗-导纳 Smith 圆图（impedance and admittance Smith chart）** 可减少混淆，通常用不同颜色刻度。

**So what**：并联元件用导纳圆图方便，是短截线匹配的图形化设计基础（[[C5-阻抗匹配与调谐#单短截线调谐|第 5 章]]）。

$z_L = 2 + j1$。用 zy 组合圆图：同一点读导纳刻度得 $y_L = 0.40 - j0.20$ → $Y_L = y_L/Z_0 = 0.0080 - j0.0040$ S。WTG 刻度负载位置 0.214λ，移 0.15λ → 0.364λ，交点 $y = 0.61 + j0.66$ → $Y = 0.0122 + j0.0132$ S。

## 开槽测量线

**开槽测量线（slotted line）** 是允许采样端接线上驻波电场幅值的传输线构型（波导/同轴）。用它可测 SWR 和从负载到第一个电压极小的距离，从而确定负载阻抗。因负载阻抗一般复数（两自由度），需测两个独立量。

虽已被现代矢量网络分析仪（VNA）在精度、多用性、方便性上取代，但开槽测量线在毫米波高端、避免连接器失配等场合仍有用；且是学习驻波与失配概念的最佳工具。

测得 SWR 和 $\ell_{\min}$（负载到第一个电压极小距离）后，反射系数幅值：

$$|\Gamma| = \frac{\mathrm{SWR} - 1}{\mathrm{SWR} + 1} \tag{2.58}$$

电压极小出现在 $e^{j(\theta - 2\beta\ell)} = -1$，故反射系数相位：

$$\theta = \pi + 2\beta\ell_{\min} \tag{2.59}$$

（电压极小每 $\lambda/2$ 重复，$\ell_{\min}$ 加任意 $\lambda/2$ 的整数倍不改变结果。）得 $\Gamma$ 后用 (2.43)（$\ell = 0$）求负载阻抗：

$$Z_L = Z_0\frac{1 + \Gamma}{1 - \Gamma} \tag{2.60}$$

**So what**：两个独立测量量（SWR + $\ell_{\min}$）确定复阻抗——这是理解驻波概念的经典工具，也是 VNA 之前测量阻抗的标准方法。

### 例题 2.4 用开槽测量线测量阻抗

50 Ω 同轴开槽测量线两步测未知负载：

1. 短路校准：电压极小在 $z = 0.2, 2.2, 4.2$ cm → $\lambda = 4.0$ cm。
2. 接未知负载：SWR = 1.5，极小在 $z = 0.72, 2.72, 4.72$ cm。取负载在 4.2 cm，则 $\ell_{\min} = 4.2 - 2.72 = 1.48$ cm = 0.37λ。

$|\Gamma| = (1.5-1)/(1.5+1) = 0.2$；$\theta = \pi + (4\pi/4.0)(1.48) = 86.4^\circ$ → $\Gamma = 0.2e^{j86.4^\circ} = 0.0126 + j0.1996$。故 $Z_L = 50(1+\Gamma)/(1-\Gamma) = 47.3 + j19.7\ \Omega$。

Smith 圆图版：SWR = 1.5 圆；电压极小对应图左侧水平轴（最小阻抗点），从该点向负载移 0.37λ（逆时针）得 $z_L = 0.95 + j0.4$ → $Z_L = 47.5 + j20\ \Omega$，与公式法吻合。
