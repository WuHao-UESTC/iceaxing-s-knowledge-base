# 电磁理论 知识体系 — 项目配置

## 项目概述

本文件夹是 **电磁理论** 的知识体系仓库，覆盖工程电磁场基础与微波工程。以两本经典教材为学习路径，建立从静态场到高频微波的完整知识索引。

**核心理念**：
- 电磁场是同一个物理实体——静态场（Hayt）与微波网络（Pozar）是对同一套 Maxwell 方程在不同频率/结构下的"视角切换"
- 笔记各自保持独立的叙事风格，但通过 `[[知识导图]]` 索引中枢和 wikilink 互联
- 概念本体（Markmap 思维导图）稳定，阅读路径（子文件夹）随学习扩展
- 与 IC 板块的 RF/模拟知识天然交叉：S 参数、阻抗匹配、传输线理论 ↔ LNA 匹配网络、互连线建模

## 知识导图 (Markmap) 索引体系

### 架构

本项目的概念索引由 `[[知识导图]]` 一文承担，采用 **纯 Markdown 标题层级 = 思维导图** 的方案（通过 `obsidian-markmind` 插件渲染为 Markmap）。

语法即结构，无需额外格式：

| 层级 | Markdown | 含义 | 示例 |
|------|----------|------|------|
| L0 | `#` | 根节点 | `# 电磁理论 知识体系` |
| L1 | `##` | 知识域 | `## 静电场` |
| L2 | `###` | 子域 | `### 高斯定律` |
| L3 | `####` | 具体概念 | `#### 对称性简化` |
| L4 | `- [[wikilink]]` | 笔记链接 | `- [[Hayt-工程电磁场/高斯定律#3.3\|Hayt: 对称分布的电场]]` |

**Markmap 方案的优势**：
- **零语法**：增删概念就是增删 markdown 标题，不需要学任何 DSL
- **零坐标**：自动树形布局，永远不重叠
- **可点击**：`- [[wikilink]]` 列表项在思维导图中直接可点击跳转
- **可折叠**：节点多了可以折叠子树，不像 Canvas/Mermaid 那样撑爆视野
- **跨域关联**：通过列表项内的 `→` `←` `↔` `⚡` 等标记 + wikilink 实现

### 跨域关联的标注约定

Markmap 是树结构，不原生支持图边。跨域关系通过 L3 概念下的列表项标注：

```
#### 特性阻抗 Z₀
- [[Pozar-Microwave Engineering/传输线理论#2.1|Pozar: 集总参数模型]]
- ⚡ trade-off: 功率容量 ↑ → Z₀ ↓ / 损耗 ↓ → Z₀ ↑
- → 匹配网络基础: [[IC/Razavi-RF Microelectronics/Low-Noise Amplifiers|LNA 输入匹配]]
- ↔ 同源概念: [[Hayt-工程电磁场/传输线#10|Hayt: 传输线场分析]]
```

常用标记：
- `→` / `←`：单向依赖/应用（"A 用于 B"）
- `↔`：双向关联（"A 与 B 互补/同源"）
- `⚡`：关键 trade-off / 设计洞察

### 知识导图的自动维护规则

**触发时机**：AI 每次完成一篇笔记的撰写或修改后，**必须**执行以下维护：

1. **读取 `[[知识导图]]`**：了解已有概念树结构
2. **增量更新标题层级**：
   - 若笔记引入了新概念 → 在对应 L2 子域下添加 `#### 概念名` + L4 链接列表项
   - 若新概念属于已有 L3 → 在已有 `####` 下添加新的 L4 `- [[link]]`
   - 若新概念需要新建 L2 子域甚至 L1 知识域 → 先与用户确认
3. **添加跨域关联标注**：
   - 若新概念与已有概念存在跨域关系 → 在两端概念下各加一行 `→` / `↔` 标注
   - 若概念与 IC 板块的 RF/模拟知识存在关联 → 添加跨 vault 领域的 wikilink
4. **添加新教材/论文的 L4 链接**：
   - 同一概念多本书时，在对应 `####` 下追加 `- [[新书子文件夹/笔记#标题\|新书: 概念名]]`
   - 可附一句标注各书视角差异（如 "Hayt：侧重物理图像 / Pozar：侧重设计方程"）

**不做的操作**：
- ❌ 不删除已有概念/链接（除非知识归类明显错误且用户确认）
- ❌ 不为每个 `###` 子标题创建 `####` 概念节点（只到笔记的 `#` / `##` 级别）
- ❌ 不为尚未写的章节预建节点

## 笔记撰写通用标准

以下规则适用于所有课本/论文的笔记，不受具体教材风格影响。

### 深度原则

- **深度而非堆砌**：宁可一个知识点写透，也不要罗列十个概念定义
- **联想与贯通**：重在建立前后章节的联系，融汇贯通
- **直觉与数学并重**：每个结论既要物理直觉的直观分析，也要数学表达式的定量理解

### 组织原则

按照知识发展的自然顺序组织笔记——概念从哪里来 → 它是什么 → 它为什么重要 → 它通向哪里。物理直觉、数学推导、设计启示在知识展开中自然融入。

- 物理直觉和数学公式穿插使用，哪个适合解释当前问题就用哪个
- 概念定义、推导逻辑、设计意义之间平滑过渡
- 需要深入展开的知识点用 `###` 子标题自然引出

### 语言风格：简明扼要

**核心原则：结论直接说，不铺陈；保留所有技术实质，砍掉一切文字水分。**

- 不要写过渡句和引导句——"一个容易忽略的事实是""值得深思的是"这类句子直接删掉
- 同一个观点只解释一遍——在第一遍解释时就找准角度，一次说透
- 删掉过度修饰——让事实本身说话
- 不开辟大段背景铺陈——直接进入主题，必要的上下文一句话交代即可
- 允许写短段落，甚至一句话成段——节奏感比"完整性"重要
- 公式前后的引导句可以极简——"由此可得""即"

### 标题层级规则

- `#` — 章级小节（对应原书的一级 numbered section）
- `##` — 子节（对应原书的二级 numbered section），或章级小节内的主要子主题
- `###` — 子节内的具体知识点/例题，用于自然切分阅读节奏，不做更深的层级嵌套

### 数学推导准则

1. 给出起点和终点公式
2. 中间步骤写明用到的思想方法和近似，不展开全部代数运算
3. 关键步骤适当展开（如未做近似的原始结论、重要的中间结果）
4. 对结果公式逐项解读物理含义

### 术语规范

- 重要术语首次出现时，中文 + 英文/符号并列：`特性阻抗（characteristic impedance, $Z_0$）`
- 后续统一使用符号或最常用称呼
- 公式中的符号遵循对应原书约定

### 插图（教材笔记专用）

教材插图**直接嵌入**笔记对应位置，不再使用 `> 【插入 … 图 X.XX】` 占位标注。

流程：
1. 从教材 `images/` 目录定位对应图片文件
2. 将该图片**复制**至 `E:\base_Obsidian\iceaxing's knowledge base\System\Attachments\`（文件名若为无意义哈希串，可重命名为 `书名-章节-图号.jpg` 之类的可读名），**原教材 `images/` 目录内容保持不变**
3. 在笔记对应位置用 Obsidian 嵌入语法插入：`![[图片文件名.jpg]]`，可附 `|宽度px` 控制显示尺寸

规则：
- 同一张图只复制一次，避免重复占用
- 图可配一句图注说明内容，图片本身直接嵌入正文
### AI 行为准则

#### 对每个结论，追问两个问题

1. **为什么（Why）**：物理直觉上为什么会这样？数学上为什么必然如此？
2. **然后呢（So What）**：这个结论对微波/EM 设计意味着什么？它会在后续哪一章用到？

#### 联想与贯通

- 遇到与前面章节呼应的内容，使用 `[[子文件夹/章节名]]` 链接，并**用一句话点明联系**
- 主动标注知识点在整个知识体系中的位置（如"这是 Maxwell 方程组的四个实验定律之一：库仑定律 → 高斯定律 → 法拉第定律 → 安培-麦克斯韦定律"）
- 可以将结论与 vault 内其他领域关联：`[[IC/Razavi-RF Microelectronics/Low-Noise Amplifiers]]`、`[[IC/Razavi-RF Microelectronics/Transceiver Architecture]]`、`[[Digital Design]]`

#### 重要概念的首次引入

首次出现的重要概念必须给出：
- 中英双语名称
- 精确定义
- 物理含义
- 在工程设计中的意义

#### 写笔记前的上下文准备

AI 在撰写新章节笔记前，应执行以下步骤：
1. **读 `[[知识导图]]`**：在 Markmap 思维导图中定位该知识点在整体体系中的位置、与哪些已有概念关联
2. **读教材原文**：从对应页数范围读取原书内容
3. **搜相关笔记**：搜索其他子文件夹中是否有同一概念的讲解（用于跨书对比），以及 IC 板块中是否有交叉概念
4. **在笔记中体现位置感**：利用 wikilink 链接到前置概念和后续应用

#### 不要做的事

- ❌ 不要逐句翻译教材段落
- ❌ 不要罗列无解释的公式
- ❌ 不要写"显然"、"易得"——把"为什么显然"说清楚
- ❌ 不要在不确定的情况下编造内容——宁可标注 `（此处需对照原书 X 页确认）`

教材为单个 markdown 文件：

**教材特点**：Hayt 以清晰的物理图像和循序渐进的方式著称，从静态场（静电场 → 恒定磁场）到动态场（时变电磁场 → 传输线 → 平面波 → 导行波 → 天线）。本书强调基本概念和解决问题的基本方法，用大量插图和比拟帮助理解。中文译本由西安交通大学出版社出版。
