# 11.1 自由空间中波的传播

## 从传输线到自由空间：场的自我繁殖

第 10 章已经看到，传输线上的电压波/电流波背后是电场/磁场沿线的分布——传输线只是一种"支撑场"的结构。反过来想：**没有这根结构，场依然存在、依然传播**。自由空间中场不被任何结构约束，其大小、方向完全由激励它的装置（天线）决定。

自由空间无源（$\rho_v = J = 0$），只用 $\mathbf{E}$、$\mathbf{H}$ 描述的 Maxwell 方程：

$$\nabla \times \mathbf{H} = \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}\tag{11.1}$$

$$\nabla \times \mathbf{E} = -\mu_0 \frac{\partial \mathbf{H}}{\partial t}\tag{11.2}$$

$$\nabla \cdot \mathbf{E} = 0\tag{11.3}$$

$$\nabla \cdot \mathbf{H} = 0\tag{11.4}$$

**波动的物理线索藏在两个旋度方程里**：式(11.1) 说，某点 $\mathbf{E}$ 随时间变化 → 该点 $\mathbf{H}$ 有旋度 → $\mathbf{H}$ 在垂直于自身的方向上变化；式(11.2) 又说，随时间变化的 $\mathbf{H}$ → $\mathbf{E}$ 有旋度 → $\mathbf{E}$ 在垂直于自身的方向上变化。于是我们在离初始扰动一小段距离处又得到了一个变化的电场——**这就是"波"：扰动逐点自我繁殖、向外推进**。要验证推进速度就是光速，需定量求解 Maxwell 方程。

> 这是 Maxwell 四个实验定律中后两个的"耦合舞蹈"：法拉第定律用变化的 $\mathbf{H}$ 生 $\mathbf{E}$，安培-麦克斯韦定律用变化的 $\mathbf{E}$ 生 $\mathbf{H}$（含位移电流项）。互为因果，波才能脱离源而存在——这正是 [[时变电磁场和麦克斯韦方程]] 中引入位移电流的必然结果。

## 均匀平面波与一阶耦合方程

**均匀平面波（uniform plane wave）**：$\mathbf{E}$、$\mathbf{H}$ 都位于横向平面内（法向即传播方向），且在该横向平面上为常数——又称 **横电磁波（TEM, transverse electromagnetic wave）**。这个假设把"场在垂直于自身方向上的变化"压缩到唯一的传播方向上。

设 $\mathbf{E} = E_x \mathbf{a}_x$（x 方向极化）、沿 $z$ 传播，则 $E_x$ 只随 $z$ 变化。式(11.2) 的旋度化简为单个项：

$$\nabla \times \mathbf{E} = \frac{\partial E_x}{\partial z} \mathbf{a}_y = -\mu_0 \frac{\partial \mathbf{H}}{\partial t} = -\mu_0 \frac{\partial H_y}{\partial t} \mathbf{a}_y$$

**电场旋度的方向决定了磁场的方向**——$H$ 沿 $y$ 方向，于是 $\mathbf{E}$、$\mathbf{H}$、传播方向三者两两垂直（TEM 的几何本质）。式(11.1) 同理化简，得到一阶耦合方程：

$$\frac{\partial E_x}{\partial z} = -\mu_0 \frac{\partial H_y}{\partial t}\tag{11.7}$$

$$\frac{\partial H_y}{\partial z} = -\varepsilon_0 \frac{\partial E_x}{\partial t}\tag{11.8}$$

**关键洞见：式(11.7)(11.8) 与无损耗传输线的电报方程 [[C10-传输线#10.3 无损耗传输|式(10.20)(10.21)]] 形式完全相同**，对应关系：

$$E_x \leftrightarrow V,\quad H_y \leftrightarrow I,\quad \mu_0 \leftrightarrow L,\quad \varepsilon_0 \leftrightarrow C$$

这不是巧合。传输线电报方程是 Maxwell 方程在 TEM 结构下的一维降维；平面波方程是"去掉结构后"的电报方程。**场论与电路论的统一在这里最赤裸**——Pozar 正是从这条同构出发，把微波电路分析建立在 $V/I$ 与 $\mathbf{E}/\mathbf{H}$ 的对应上（见 [[Pozar-Microwave Engineering/C2-传输线理论#从-maxwell-到场分析电报方程同轴线特例|Pozar: Maxwell → 电报方程]]）。

## 波动方程与光速

式(11.7) 对 $z$ 求导、式(11.8) 对 $t$ 求导，联立消去 $H_y$：

$$\frac{\partial^2 E_x}{\partial z^2} = \mu_0 \varepsilon_0 \frac{\partial^2 E_x}{\partial t^2}\tag{11.11}$$

$$\frac{\partial^2 H_y}{\partial z^2} = \mu_0 \varepsilon_0 \frac{\partial^2 H_y}{\partial t^2}\tag{11.13}$$

一维波动方程，波速

$$v = \frac{1}{\sqrt{\mu_0 \varepsilon_0}} = 3\times 10^{8}\ \mathrm{m/s} = c\tag{11.12}$$

**这是 Maxwell 方程最深刻的预言**：两个纯电磁学常数 $\mu_0$、$\varepsilon_0$ 组合出真空光速。1864 年 Maxwell 由此推断"光就是电磁波"，把光学统一进电磁学。$\mu_0\varepsilon_0 = 1/c^2$ 不是巧合，而是电磁波与光同源的铁证。

通解是正向波与负向波之和：

$$E_x(z,t) = f_1(t - z/v) + f_2(t + z/v)\tag{11.14}$$

$f_1$、$f_2$ 是以 $t \mp z/v$ 为自变量的**任意函数**——任意波形都以速度 $c$ 无畸变传播。

## 正弦稳态：相速、波数与波长

只分析给定频率的正弦波（其他波形由 Fourier 合成得到，见文末）。定义**波数（wave number）**

$$k_0 \equiv \frac{\omega}{c}\ \mathrm{rad/m}\tag{11.16}$$

正向余弦波的瞬时表达式（instantaneous expression）：

$$E_x(z,t) = |E_{x0}|\cos(\omega t - k_0 z + \phi_1) + |E'_{x0}|\cos(\omega t + k_0 z + \phi_2)\tag{11.15}$$

- $\omega$（rad/s）＝单位时间的相移，是**时间频率**；$k_0$（rad/m）＝单位距离的相移，是**空间频率**，即自由空间无损耗传播的相位常数。二者由 $k_0 = \omega/c$ 联系。
- **波长**＝相位差 $2\pi$ 的空间两点距离（固定时间）：$k_0\lambda = 2\pi \Rightarrow \lambda = 2\pi/k_0$。
- **跟踪波峰**：要求 $\omega t - k_0 z = 2m\pi$ 恒成立 → $t$ 增大时 $z$ 必须增大 → 波以相速 $v_p = c$ 向 $+z$ 移动。这是**相速（phase velocity）的严格定义：等相位面的移动速度**。同理 $(\omega t + k_0z)$ 项是 $-z$ 波。

## 相量形式与矢量 Helmholtz 方程

时谐场用相量表示：$\partial/\partial t \to j\omega$，瞬时量 $= \mathrm{Re}[\text{相量}\, e^{j\omega t}]$。式(11.1)–(11.4) 化为相量 Maxwell 方程：

$$\nabla \times \mathbf{H}_s = j\omega\varepsilon_0 \mathbf{E}_s\tag{11.23}$$

$$\nabla \times \mathbf{E}_s = -j\omega\mu_0 \mathbf{H}_s\tag{11.24}$$

$$\nabla \cdot \mathbf{E}_s = 0\tag{11.25}$$

$$\nabla \cdot \mathbf{H}_s = 0\tag{11.26}$$

**注意**：两个散度方程此时**不再是独立的**——分别对两个旋度方程取散度即得（旋度的散度恒为零）。时谐场的"无源"条件已隐含在旋度方程里。

对式(11.24) 取旋度，用矢量恒等式 $\nabla\times\nabla\times = \nabla(\nabla\cdot) - \nabla^2$ 与 $\nabla\cdot\mathbf{E}_s = 0$，得**矢量 Helmholtz 方程（vector Helmholtz equation）**：

$$\nabla^2 \mathbf{E}_s = -k_0^2 \mathbf{E}_s\tag{11.28}$$

直角坐标下每个分量各成一个标量方程；对均匀平面波（$E_{xs}$ 只随 $z$ 变化）：

$$\frac{d^2 E_{xs}}{dz^2} = -k_0^2 E_{xs}\tag{11.30}$$

解为

$$E_{xs}(z) = E_{x0}\, e^{-jk_0 z} + E'_{x0}\, e^{+jk_0 z}\tag{11.31}$$

$e^{-jk_0z}$ 是 $+z$ 行波、$e^{+jk_0z}$ 是 $-z$ 行波；$E_{x0}$、$E'_{x0}$ 为**复振幅**（含初相）。

> **易错点**：$e^{j\omega t}$ 约定下，$e^{-jk_0z}$ 取实部得 $\cos(\omega t - k_0 z)$（$+z$ 行波），$e^{+jk_0z}$ 得 $\cos(\omega t + k_0 z)$（$-z$ 行波）。负号约定源自工程 $e^{j\omega t}$ 时谐约定（与 Pozar 一致，见 [[Pozar-Microwave Engineering/C1-电磁理论基础#时谐场与相量表示|Pozar: e^{jωt} 约定]]）。

### 例 11.1 与 11.2：相量 ↔ 瞬时表达式互转

两者演示同一规则：瞬时量 $\mathcal{E} = \mathrm{Re}[E_s e^{j\omega t}]$，其中 $E_s(z) = E_0 e^{-jk_0z}$（复振幅 $E_0$ 含幅度与初相），$e^{-jk_0z}$ 因子统一携带"空间相位"，各分量的相对相位留在复振幅里。

**例 11.2 的要点**：$k_0 = \omega/c = 0.21\ \mathrm{rad/m}$，两分量 $100\mathbf{a}_x$ 与 $20\angle30^\circ\mathbf{a}_y$ 共用同一 $e^{-jk_0z}$ 因子——$x$、$y$ 分量不同幅、不同相，这已经是一个（椭圆）极化波，极化问题在 [[#11.5 波的极化|11.5 节]] 展开。

## 波阻抗 η₀ 与功率流方向

给定 $\mathbf{E}_s$，由式(11.24) 求 $\mathbf{H}_s$。因 $E_{xs}$ 只随 $z$ 变化，$\dfrac{dE_{xs}}{dz} = -j\omega\mu_0 H_{ys}$，代入式(11.31)：

$$H_{ys} = E_{x0}\sqrt{\frac{\varepsilon_0}{\mu_0}}\, e^{-jk_0z} - E'_{x0}\sqrt{\frac{\varepsilon_0}{\mu_0}}\, e^{+jk_0z}$$

正向波 $E_{x0} = \eta_0 H_{y0}$，负向波 $E'_{x0} = -\eta_0 H'_{y0}$，其中

$$\eta_0 = \sqrt{\frac{\mu_0}{\varepsilon_0}} = 377 \doteq 120\pi\ \Omega\tag{11.35}$$

为**自由空间波阻抗（intrinsic impedance of free space）**，单位 $\Omega$（V/m ÷ A/m）。

**负号是物理的必然**：坡印亭矢量 $\mathbf{S} = \mathbf{E}\times\mathbf{H}$（$\mathrm{W/m^2}$）给出功率流方向。正向波 $\mathbf{E}=+x$、$\mathbf{H}=+y$ → $\mathbf{S}=+z$；负向波若 $\mathbf{E}=+x$，$\mathbf{H}$ 必须为 $-y$ → $\mathbf{S}=-z$。式(11.34b) 的负号保证功率始终沿传播方向。

**$\eta_0$ 与特性阻抗 $Z_0$ 的直接类比**：$Z_0$ 是电压行波/电流行波之比（[[C10-传输线#10.3 无损耗传输|传输线]]），$\eta_0$ 是电场行波/磁场行波之比——都是"行波中对偶量的比例常数"。但 $\eta_0$ 只含介质常数、不含任何几何因子（自由空间没有横截面）。这个 $\eta$（本征）vs $Z_0$（含几何）的区分在波导与微波网络分析中反复出现（见 [[Pozar-Microwave Engineering/C4-微波网络分析#阻抗概念的三种形态|Pozar: 阻抗三种形态 η/Z_w/Z₀]]）。

## 均匀平面波的实在性

严格意义的均匀平面波横向扩展到无穷远、携带无穷大能量，**物理上不存在**。但在局域范围内，天线远区场几乎就是均匀平面波——到达远方目标的雷达信号可近似为均匀平面波。这正是均匀平面波虽最简单却最具实际重要性的原因：**它是远场辐射的局部极限，也是所有更复杂波（反射、波导、天线）的基元解**。

# 11.2 电介质中波的传播

## 复传播常数：α 与 β 的引入

把 11.1 的分析推广到介电常数 $\varepsilon$、磁导率 $\mu$ 的均匀各向同性媒质。Helmholtz 方程形式不变：

$$\frac{d^2 E_{xs}}{dz^2} = -k^2 E_{xs}\tag{11.38}$$

但波数 $k$ 现在是材料参数的函数：

$$k = \omega\sqrt{\mu\varepsilon} = k_0\sqrt{\mu_r \varepsilon_r}\tag{11.37}$$

**关键一步：允许 $k$ 为复数**，记

$$jk = \alpha + j\beta\tag{11.39}$$

则解为

$$E_{xs} = E_{x0}\, e^{-jkz} = E_{x0}\, e^{-\alpha z} e^{-j\beta z}\tag{11.40}$$

$$E_x(z,t) = E_{x0}\, e^{-\alpha z}\cos(\omega t - \beta z)\tag{11.41}$$

- $\beta$＝**相位常数（phase constant）**，仍是 $\omega t - \beta z$ 里的空间频率；
- $\alpha$＝**衰减系数（attenuation constant）**，单位 **Np/m（奈培/米）**，波幅按 $e^{-\alpha z}$ 衰减。$\alpha>0$ 衰减、$\alpha<0$ 增益（如激光放大器）；本书只讨论无源媒质（$\alpha>0$）。
- **$1/\alpha$**＝幅值衰减到 $1/e$ 的距离，即**透射深度（penetration depth）**——11.4 节的集肤深度是它在良导体中的特例。

**核心洞察**：复数 $k$ 的本质是"传播与衰减共存"——经 $jk$ 分解后，实部给衰减、虚部给相位。这与传输线的复传播常数 $\gamma = \alpha + j\beta = \sqrt{(R+j\omega L)(G+j\omega C)}$ 完全同构（见 [[Pozar-Microwave Engineering/C2-传输线理论#复传播常数-gamma|Pozar: 复传播常数 γ]]）。**同一个"复传播常数"概念，传输线里由 $R,G$ 制造损耗，平面波里由 $\varepsilon''$ 制造损耗。**

## 复介电常数与损耗的物理起源

损耗被压缩进一个**复介电常数（complex permittivity）**：

$$\varepsilon = \varepsilon' - j\varepsilon'' = \varepsilon_0(\varepsilon'_r - j\varepsilon''_r)\tag{11.42}$$

三种微观机制贡献 $\varepsilon''$（进而产生损耗）：
1. **束缚电子/离子振动**（bound charge oscillation）；
2. **偶极子弛豫**（dipole relaxation，见附录 D）；
3. **自由电子/空穴导电**（conduction，$J = \sigma E$）——本章重点。

磁损耗也可用复磁导率 $\mu = \mu' - j\mu''$ 建模（铁磁材料、硅钢片），但大多数波传播材料的磁响应远弱于介电响应，故取 $\mu = \mu_0$ 为纯实数。

**为什么"损耗 = 虚部"？** 把复 $\varepsilon$ 代入旋度方程：$\nabla\times\mathbf{H}_s = j\omega(\varepsilon'-j\varepsilon'')\mathbf{E}_s = \omega\varepsilon''\mathbf{E}_s + j\omega\varepsilon'\mathbf{E}_s$。实部项 $\omega\varepsilon''\mathbf{E}_s$ 与 $\mathbf{E}_s$ **同相**、贡献有功功率（欧姆损耗）；虚部项 $j\omega\varepsilon'\mathbf{E}_s$ 与 $\mathbf{E}_s$ 正交、是储能（无功）。这正是虚部对应损耗的数学根源，与 Pozar 的约定一致（见 [[Pozar-Microwave Engineering/C1-电磁理论基础#电介质极化与复介电常数|Pozar: ε = ε′−jε″, tanδ]]）。

## α、β、相速、波长与复波阻抗

由 $k = \omega\sqrt{\mu(\varepsilon'-j\varepsilon'')} = \omega\sqrt{\mu\varepsilon'}\sqrt{1-j\dfrac{\varepsilon''}{\varepsilon'}}$，取 $jk$ 的实部/虚部得精确表达式：

$$\alpha = \omega\sqrt{\frac{\mu\varepsilon'}{2}}\left(\sqrt{1+\left(\frac{\varepsilon''}{\varepsilon'}\right)^2}-1\right)^{1/2}\tag{11.44}$$

$$\beta = \omega\sqrt{\frac{\mu\varepsilon'}{2}}\left(\sqrt{1+\left(\frac{\varepsilon''}{\varepsilon'}\right)^2}+1\right)^{1/2}\tag{11.45}$$

**损耗角正切（loss tangent）$\varepsilon''/\varepsilon'$ 是唯一的无量纲控制参数**：$\varepsilon''=0$ 时 $\alpha=0$（无损耗）；$\varepsilon''\neq0$ 时 $\alpha\neq0$，且 $\beta$ 也偏离无损耗值（损耗会"拉动"相位常数）。它相对 1 的大小决定各种近似的适用范围。

相速与波长仍由 $\beta$ 定义，对任意（有损/无损）媒质成立：

$$v_p = \frac{\omega}{\beta}\tag{11.46}$$
$$ \lambda = \frac{2\pi}{\beta}\tag{11.47}$$

波阻抗现在是**复数**：

$$\eta = \sqrt{\frac{\mu}{\varepsilon'-j\varepsilon''}} = \sqrt{\frac{\mu}{\varepsilon'}}\frac{1}{\sqrt{1-j(\varepsilon''/\varepsilon')}}\tag{11.48}$$

**复数 $\eta$ 的物理含义：$\mathbf{E}$ 与 $\mathbf{H}$ 不再同相**，相位差由 $\eta$ 的辐角给出——这是损耗的直接标志（无损耗时 $\eta$ 为实数、二者同相）。

## 无损耗媒质：理想电介质

特例 $\varepsilon'' = 0$（$\varepsilon = \varepsilon'$）：

$$\alpha = 0,\qquad \beta = \omega\sqrt{\mu\varepsilon'}\tag{11.49}$$

$$\lambda = \frac{2\pi}{\beta} = \frac{\lambda_0}{\sqrt{\mu_r \varepsilon'_r}}\tag{11.51}$$
$$ \eta = \sqrt{\frac{\mu}{\varepsilon}}\tag{11.52}$$

**两个普适结论**：
1. $v_p = \omega/\beta = 1/\sqrt{\mu\varepsilon'} = c/\sqrt{\mu_r\varepsilon'_r}$——媒质中波比真空慢；
2. $\lambda = \lambda_0/\sqrt{\mu_r\varepsilon'_r}$——媒质中波长比真空短。

实际媒质总有 $\mu_r\varepsilon'_r > 1$。**物理图像**：$\varepsilon'$ 增大意味着单位电场存储更多极化能，波的"惯性"增大、传播变慢，波长按同一比例压缩。这是所有"波长缩短、相速减慢"现象的根源，也是介质加载谐振器/天线小型化的物理基础。

### 例 11.3：1 MHz 在淡水中的传播

$\mu_r = 1$，$\varepsilon'_r = 81$，忽略损耗：$\beta = \omega\sqrt{\varepsilon'_r}/c = 0.19\ \mathrm{rad/m}$，$\lambda = 33\ \mathrm{m}$（空气中 $\lambda_0 = 300\ \mathrm{m}$，缩短 $9 = \sqrt{81}$ 倍），$v_p = 3.3\times10^7\ \mathrm{m/s} = c/9$，$\eta = \eta_0/\sqrt{\varepsilon'_r} = 377/9 = 42\ \Omega$。

**注意 $\eta$ 也除以 $\sqrt{\varepsilon'_r}$**：媒质越"密"，波阻抗越低——同样 $E$ 对应更大的 $H$。这个结论是第 12 章所有反射/透射分析的核心输入。

## 损耗、电导率与损耗角正切：$\varepsilon'' = \sigma/\omega$

导电媒质中 $J = \sigma E$（$\sigma$＝电导率）。把旋度方程写成显含传导电流的形式：

$$\nabla\times\mathbf{H}_s = \underbrace{\sigma \mathbf{E}_s}_{J_{\sigma s}} + \underbrace{j\omega\varepsilon' \mathbf{E}_s}_{J_{ds}}\tag{11.55}$$

与复介电常数形式对比，得

$$\varepsilon'' = \frac{\sigma}{\omega}\tag{11.56}$$

**这是把导电损耗"翻译"成复介电常数虚部的桥**。传导电流与位移电流之比：

$$\frac{J_{\sigma s}}{J_{ds}} = \frac{\sigma}{j\omega\varepsilon'} = \frac{\varepsilon''}{j\varepsilon'}\tag{11.57}$$

- 二者空间同向、时间相差 $90^\circ$（位移电流超前传导电流 $90^\circ$，正如电容电流超前并联电阻电流 $90^\circ$）。
- **损耗角正切** $\tan\theta = \varepsilon''/\varepsilon' = \sigma/\omega\varepsilon'$（式 11.58）：$\theta$ 是位移电流超前总电流的角度，$90^\circ-\theta$ 即普通电路里的功率因数角。

> **So What**：$\tan\delta = \sigma/\omega\varepsilon'$ 直接判断材料在给定频率下"像导体还是像介质"——$\sigma/\omega\varepsilon' \ll 1$ 为良电介质（本节近似）、$\sigma/\omega\varepsilon' \gg 1$ 为良导体（11.4 节）。**同一材料在不同频率下可能从介质变导体**：$\omega$ 在分母上，频率越高位移电流越占优、材料越"像介质"。这是 [[#11.4 良导体中波的传播：集肤效应|11.4 节良导体判据]] 的前置概念。

### 例 11.4：2.5 GHz 微波炉加热水

水中偶极子弛豫在微波频段占主导，$\varepsilon' = 78$、$\varepsilon'' = 7$：$\alpha = 21\ \mathrm{Np/m}$，透射深度 $1/\alpha = 4.8\ \mathrm{cm}$。**微波炉的物理**：4.8 cm 透射深度保证食物整个深度内温升相当均匀；频率更高则 $\varepsilon''$ 更大、透射深度减小（能量集中在表面），频率更低则能量吸收不充分——商业微波炉取 2.5 GHz 正是这个折中。同时 $\eta = 43\angle2.6^\circ\ \Omega$，$E_x$ 在每点相位超前 $H_y$ $2.6^\circ$（复 $\eta$ 的辐角）。

## 良电介质近似（小损耗角正切）

当 $\sigma/\omega\varepsilon' \ll 1$（良电介质），用二项式展开 $(1+x)^{1/2} \approx 1 + x/2 - x^2/8 + \cdots$ 化简：

$$\alpha \approx \frac{\sigma}{2}\sqrt{\frac{\mu}{\varepsilon'}}\tag{11.60a}$$

$$\beta \approx \omega\sqrt{\mu\varepsilon'}\left[1 + \frac{1}{8}\left(\frac{\sigma}{\omega\varepsilon'}\right)^2\right] \approx \omega\sqrt{\mu\varepsilon'}\tag{11.61}$$

$$\eta \approx \sqrt{\frac{\mu}{\varepsilon'}}\left[1 + j\frac{\sigma}{2\omega\varepsilon'}\right]\tag{11.62b}$$

**与低损耗传输线的精确类比**（[[C10-传输线#10.7 无损耗传输和低损耗传输|传输线]] 式 10.54a/10.55b）：$\sigma \leftrightarrow G$，$\mu \leftrightarrow L$，$\varepsilon' \leftrightarrow C$。**但注意**：无限大媒质中的平面波**没有与传输线导体电阻 $R$ 对应的量**——平面波没有"导体"，损耗只来自介质。这个"缺失"反过来解释了平面波衰减公式为何比传输线更简单。

**精度判据**：$\sigma/\omega\varepsilon' < 0.1$ 时误差不超过百分之几。例 11.5 用近似公式重算例 11.4（$\tan\delta = 0.09$），结果一致。

# 11.3 坡印亭定理和波的功率

## 坡印亭定理：电磁能量守恒

11.2 已经看到波在损耗媒质中衰减（$\varepsilon''$ 制造损耗），但"功率怎么流、损失到哪去"需要一个能量定理来定量回答——这就是**坡印亭定理（Poynting's theorem）**，1884 年 J. H. Poynting 提出。

从导电媒质的安培-麦克斯韦定律出发：

$$\nabla\times\mathbf{H} = \mathbf{J} + \frac{\partial\mathbf{D}}{\partial t}\tag{11.63}$$

两边点乘 $\mathbf{E}$，代入矢量恒等式 $\nabla\cdot(\mathbf{E}\times\mathbf{H}) = \mathbf{H}\cdot(\nabla\times\mathbf{E}) - \mathbf{E}\cdot(\nabla\times\mathbf{H})$ 与法拉第定律 $\nabla\times\mathbf{E} = -\partial\mathbf{B}/\partial t$，把两个微分项改写成能量密度的时间导数，再体积分并应用散度定理：

$$-\oint_{\text{area}}(\mathbf{E}\times\mathbf{H})\cdot d\mathbf{S} = \int_{\text{vol}}\mathbf{J}\cdot\mathbf{E}\,dv + \frac{\partial}{\partial t}\int_{\text{vol}}\frac12\mathbf{D}\cdot\mathbf{E}\,dv + \frac{\partial}{\partial t}\int_{\text{vol}}\frac12\mathbf{B}\cdot\mathbf{H}\,dv\tag{11.70}$$

**逐项物理含义**（定理的核心）：
- 左边＝流入闭合面的总功率（负号表示流入）；
- 右边第一项 $\int\mathbf{J}\cdot\mathbf{E}\,dv$＝体积内欧姆损耗功率（$\mathbf{J}\cdot\mathbf{E} = \sigma E^2$，焦耳热）；
- 右边第二、三项＝电场储能 $\tfrac12\mathbf{D}\cdot\mathbf{E}$ 与磁场储能 $\tfrac12\mathbf{B}\cdot\mathbf{H}$ 的变化率。

**即：流入功率 = 欧姆损耗 + 电磁储能的增加率**——电磁场的能量守恒定律，是 Maxwell 方程组的直接推论。

> 两个能量密度 $\tfrac12\mathbf{D}\cdot\mathbf{E}$、$\tfrac12\mathbf{B}\cdot\mathbf{H}$ 正是静电学（能量和电位）与恒定磁场中定义的储能密度，此处以"变化率"形式进入时变场功率平衡——静态场只是 $d/dt = 0$ 的特例。Pozar 在 [[Pozar-Microwave Engineering/C1-电磁理论基础#poynting-定理电磁功率平衡|Pozar: P_s=P_o+P_ℓ+2jω(W_m−W_e)]] 中把同一守恒写成复功率形式，是本节相量形式的推广。

## 坡印亭矢量 S = E×H

$$\mathbf{S} = \mathbf{E}\times\mathbf{H}\ \mathrm{W/m^2}\tag{11.72}$$

**坡印亭矢量（Poynting vector）＝瞬时功率密度**：大小是单位面积通过的瞬时功率，方向是该点瞬时功率流动的方向。由叉乘定义，$\mathbf{S}$ 始终垂直于 $\mathbf{E}$、$\mathbf{H}$。

对均匀平面波：$E_x\mathbf{a}_x \times H_y\mathbf{a}_y = S_z\mathbf{a}_z$，功率流方向即传播方向——这正是 11.1 中负向波 $E'_{x0} = -\eta_0 H'_{y0}$ 带负号的原因（保证 $\mathbf{S}$ 指向 $-z$）。

## 瞬时功率密度：理想 vs 损耗介质

**理想电介质**（$\eta$ 实数，$E$、$H$ 同相）：

$$S_z = \frac{E_{x0}^2}{\eta}\cos^2(\omega t - \beta z)\tag{11.73}$$

**损耗电介质**（$\eta = |\eta|\angle\theta_\eta$，$H$ 滞后 $E$ 一个 $\theta_\eta$）：

$$S_z = \frac{E_{x0}^2}{|\eta|}e^{-2\alpha z}\cos(\omega t-\beta z)\cos(\omega t-\beta z-\theta_\eta)\tag{11.74}$$

## 时间平均功率与复坡印亭矢量

正弦信号下真正可测的是**时间平均功率密度**。用 $\cos A\cos B = \tfrac12[\cos(A+B)+\cos(A-B)]$ 展开，二次谐波项在一个周期内积分为零，只剩直流项：

$$\langle S_z\rangle = \frac12\frac{E_{x0}^2}{|\eta|}e^{-2\alpha z}\cos\theta_\eta\tag{11.76}$$

**两个关键观察**：
1. **功率按 $e^{-2\alpha z}$ 衰减，而 $E$、$H$ 按 $e^{-\alpha z}$ 衰减**——功率 ∝ 场²，衰减因子平方。一个透射深度 $\alpha z = 1$ 处场降到 $1/e$、功率降到 $1/e^2 = 0.135$。
2. **$\cos\theta_\eta$ 因子**：损耗越大 $\theta_\eta$ 越偏离 0，同相分量越小、传输的净功率越少——损耗不仅衰减幅值，还通过相位差直接"吃掉"有功分量。

**相量形式（工程上最常用）**：

$$\langle\mathbf{S}\rangle = \frac12\mathrm{Re}\left(\mathbf{E}_s \times \mathbf{H}_s^*\right)\ \mathrm{W/m^2}\tag{11.77}$$

取共轭 $\mathbf{H}_s^*$ 使相位差自动进入实部，$\tfrac12$ 来自 $\cos^2$ 的时间平均。该式对**任意正弦波**成立，同时给出时间平均功率密度的大小与方向，是后续所有功率计算的起点——11.4 的导体损耗、第 12 章的反射功率都从这里算。

（练习 11.6 为冰中不同频率的时间平均功率密度计算，略。）

# 11.4 良导体中波的传播：集肤效应

## 良导体近似：α = β = √(πfμσ)

11.2 处理的是 $\sigma/\omega\varepsilon' \ll 1$（良电介质），本节取**相反极限 $\sigma/\omega\varepsilon' \gg 1$**——良导体（good conductor）。典型数值：100 MHz 时镍铬合金（$\sigma = 10^5\ \mathrm{S/m}$）的 $\sigma/\omega\varepsilon' \approx 2\times10^8$，条件充分满足。

从式(11.59) 出发，$\sigma \gg \omega\varepsilon'$ 时根号内 $1 - j\sigma/\omega\varepsilon' \approx -j\sigma/\omega\varepsilon'$：

$$jk = j\sqrt{-j\omega\mu\sigma}$$

用 $\sqrt{-j} = 1\angle-45^\circ = (1-j)/\sqrt2$：

$$jk = (1+j)\sqrt{\pi f\mu\sigma} = \alpha + j\beta$$

$$\alpha = \beta = \sqrt{\pi f\mu\sigma}\tag{11.79}$$

**良导体的标志性结论：$\alpha = \beta$**（良电介质里 $\alpha \ll \beta$，自由空间 $\alpha = 0$）。衰减与相位"同步"进行——每传播一个波长（$z = \lambda$），幅值正好衰减 $e^{-2\pi}$。

## 集肤深度 δ

$$\delta = \frac{1}{\sqrt{\pi f\mu\sigma}} = \frac{1}{\alpha} = \frac{1}{\beta}\tag{11.82}$$

**集肤深度（skin depth，又称透入深度）** ＝场幅值衰减到表面值 $1/e$ 的距离。铜 $\delta = 0.066/\sqrt{f}\ \mathrm{m}$：60 Hz 时 $\delta = 8.53\ \mathrm{mm}$，10 GHz 时 $\delta = 6.6\times10^{-4}\ \mathrm{mm}$。

**物理图像**：良导体中波的能量**不在导体内部传播**，而在包围导体的外部介质中传播，导体只起"引导"作用；进入导体的场在几个 $\delta$ 内几乎归零，表面电流/电场随深度急剧衰减（第 14 章导行波详述）。

> ![[Pasted image 20260815185956.png]]
> 电流密度 $J_x = J_{x0}e^{-z/\delta}e^{-jz/\delta}$ 的幅值随深度指数衰减；区域 $0<x<L,\ 0<y<b,\ z>0$ 内的平均功率损耗 $= \delta bLJ_{x0}^2/4\sigma$。

**两个工程推论**：
- 工频大电流母线：2×4 英寸实心铜条大部分浪费，壁厚 12 mm 的中空导体即足够（60 Hz 时 $\delta \approx 8.5\ \mathrm{mm}$）。
- 微波频段：$3\ \mu\mathrm{m}$ 镀银玻璃就是极好导体——**高频只需表面薄层，这是镀银/镀金工艺的物理依据**。

## 波长与相速：λ = 2πδ, v_p = ωδ

$$\lambda = 2\pi\delta\tag{11.83}$$
$$v_p = \omega\delta\tag{11.84}$$

**良导体中波被极度"压缩"且极慢**：60 Hz 铜 $\lambda = 5.36\ \mathrm{cm}$（自由空间 3100 km），$v_p = 3.22\ \mathrm{m/s}$——比人跑步还慢，与自由空间的 $c$ 相差约 $10^8$ 量级。

### 例 11.6：海水 1 MHz 与 ELF 潜艇通信

海水 $\sigma = 4\ \mathrm{S/m}$、$\varepsilon'_r = 81$，1 MHz 时 $\sigma/\omega\varepsilon' = 8.9\times10^2 \gg 1$ → 良导体：$\delta = 25\ \mathrm{cm}$，$\lambda = 1.6\ \mathrm{m}$，$v_p = 1.6\times10^6\ \mathrm{m/s}$。25 cm 透入深度使**海水中的射频通信不切实际**。

$\delta \propto 1/\sqrt{f}$ → 降到 10 Hz（ELF 极低频）时 $\delta \approx 80\ \mathrm{m}$，潜艇可在水下接收。代价：信号传输速率极低（传一个词要几分钟），ELF 只用于通知潜艇上浮接收卫星信息——"穿透深度 vs 数据速率"的经典权衡。

## 波阻抗 η = (1+j)/(σδ) 与磁场滞后 45°

从 $\eta = \sqrt{j\omega\mu/(\sigma + j\omega\varepsilon')} \approx \sqrt{j\omega\mu/\sigma}$：

$$\eta = \frac{\sqrt2\angle45^\circ}{\sigma\delta} = \frac{1+j}{\sigma\delta}\tag{11.85}$$

**良导体波阻抗有 $45^\circ$ 相位角**（对比：$\eta_0$ 纯实数、良电介质 $\eta$ 近似实数）。因此

$$H_y = \frac{\sigma\delta E_{x0}}{\sqrt2}e^{-z/\delta}\cos\left(\omega t - \frac{z}{\delta} - \frac{\pi}{4}\right)\tag{11.87}$$

**$H$ 在每一点滞后 $E$ $\pi/4$（1/8 周期）**——磁场"迟到"是良导体 $\eta$ 相角的直接体现，也意味着 $|\eta| = \sqrt2/(\sigma\delta) \ll 377\ \Omega$（良导体中同样的 $E$ 产生很大的 $H$）。

## 功率损耗与表面电阻等效

时间平均坡印亭矢量在表面 $z=0$ 处给出进入导体的功率，全部转化为欧姆损耗。对 $0<x<L$、$0<y<b$ 的表面：

$$P_L = \frac{1}{4\sigma}\delta bL J_{x0}^2\tag{11.88}$$

**关键等价**：把宽度 $b$ 内的总电流均匀分布在深度 $\delta$ 的薄层内，算出的欧姆损耗与精确结果**完全相等**（式 11.89）。于是

> **集肤效应下的导体电阻 = 电流均匀分布、厚度为 $\delta$ 的等效薄板电阻。**

这就是**表面电阻（surface resistance）$R_s = 1/(\sigma\delta) = \sqrt{\pi f\mu/\sigma}$** 的来源：损耗功率 $= \tfrac12 R_s\int|\mathbf{H}_t|^2 ds$。Pozar 在 [[Pozar-Microwave Engineering/C1-电磁理论基础#良导体吸收的功率表面电阻|Pozar: R_s=√(ωμ/2σ)=1/(σδs)]] 中把它系统化为计算任意形状导体损耗的统一工具，也正是第 10 章传输线电阻参数 $R$ 的物理来源（[[C10-传输线#10.7 无损耗传输和低损耗传输|传输线]]）。

## 圆截面导体的高频电阻

对半径 $a \gg \delta$ 的圆导线，等效为宽 $2\pi a$、厚 $\delta$ 的薄板：

$$R = \frac{L}{2\pi a\sigma\delta}\tag{11.90}$$

例：半径 1 mm、长 1 km 铜线，$R_{\mathrm{dc}} = 5.48\ \Omega$；1 MHz 时 $\delta = 0.066\ \mathrm{mm}$，$R = 41.5\ \Omega$——**集肤效应使高频电阻增大约 7.6 倍**，且 $R \propto \sqrt{f}$。

（练习 11.7 为钢管集肤深度/有效电阻/直流电阻/功率损耗计算，略。）

# 11.5 波的极化

## 极化的定义与正交分解原理

11.1–11.4 都假设 $\mathbf{E}$ 固定在单一方向（如 $x$）。但 $\mathbf{E}$、$\mathbf{H}$ 在垂直于 $\mathbf{a}_z$ 的横向平面内的方向会随时间和位置变化，取决于波的产生方式与媒质。**波极化（wave polarization）＝空间某点电场矢量方向随时间变化的函数**。因 $\mathbf{H}$ 由 $\mathbf{E}$ 经 Maxwell 方程唯一确定，描述极化只需电场。

一般相量（沿 $+z$ 传播，含衰减）：

$$\mathbf{E}_s = (E_{x0}\mathbf{a}_x + E_{y0}\mathbf{a}_y)e^{-\alpha z}e^{-j\beta z}\tag{11.91}$$

$$\mathbf{H}_s = \left(-\frac{E_{y0}}{\eta}\mathbf{a}_x + \frac{E_{x0}}{\eta}\mathbf{a}_y\right)e^{-\alpha z}e^{-j\beta z}\tag{11.92}$$

**注意 $H_x$ 前有负号**：$\mathbf{E}$ 的 $+y$ 分量要求 $\mathbf{H}$ 有 $-x$ 分量，才保证 $\mathbf{E}\times\mathbf{H}$ 指向 $+z$（图 11.4）。功率密度为两个正交分量功率之和：

$$\langle S_z\rangle = \frac12\mathrm{Re}\left\{\frac{1}{\eta^*}\right\}(|E_{x0}|^2 + |E_{y0}|^2)e^{-2\alpha z}$$

> 【插入 Hayt 图 11.4】沿 $+z$ 传播的线极化平面波中的 $\mathbf{E}$ 与 $\mathbf{H}$，对应式(11.91)(11.92)。

> **核心原理（贯穿全节）**：任意极化状态都可分解为两个相互垂直的线极化分量 + 它们的相对相位；反之，两个正交分量的任意幅值比与相位差合成出所有极化状态。这是"正交基"思想——11.5 全节都在这个基上做文章。

## 线性极化与椭圆极化

**线性极化（linear polarization）**：$E_{x0}$、$E_{y0}$ 同相（相位差 $\phi = 0$），$\mathbf{E}$ 沿固定直线方向——前面几节默认的状态。

引入相位差 $\phi$（$\phi < \pi/2$，无损耗媒质）：

$$\mathbf{E}_s = (E_{x0}\mathbf{a}_x + E_{y0}e^{j\phi}\mathbf{a}_y)e^{-j\beta z}\tag{11.93}$$

$$\mathbf{E}(z,t) = E_{x0}\cos(\omega t-\beta z)\mathbf{a}_x + E_{y0}\cos(\omega t-\beta z+\phi)\mathbf{a}_y\tag{11.94}$$

**$\phi \neq 0$ 的物理效应**：固定 $t=0$ 沿 $z$ 看，$E_y$ 的波峰从 $E_x$ 波峰处"移开"了 $\phi/\beta$ 的距离（$E_y$ 在空间中滞后 $E_x$）；固定某点看时间，$E_y$ 的波峰先到达观察者，$E_y$ 在时间上**超前** $E_x$。观察者看到总场绕 $z$ 轴旋转、大小变化——**矢量末端轨迹是椭圆，即椭圆极化（elliptical polarization）**。

**椭圆极化是最一般的极化状态**（任意幅值比 + 任意相位差），线性极化是 $\phi = 0$ 的特例。

> 【插入 Hayt 图 11.5】$t=0$ 时 $E_x$、$E_y$ 分量幅值随 $z$ 变化；$z$ 轴上 $y$ 分量滞后 $x$ 分量，但固定点观察时 $y$ 分量时间上领先。

## 圆极化与旋向

椭圆极化的又一特例：$E_{x0} = E_{y0} = E_0$ 且 $\phi = \pm\pi/2$。代入式(11.94)：

$$\mathbf{E}(z,t) = E_0[\cos(\omega t-\beta z)\mathbf{a}_x \mp \sin(\omega t-\beta z)\mathbf{a}_y]\tag{11.96}$$

固定 $z=0$：

$$\phi = +\frac{\pi}{2}:\ \mathbf{E}(0,t) = E_0[\cos(\omega t)\mathbf{a}_x - \sin(\omega t)\mathbf{a}_y]\tag{11.97}\ \text{顺时针 → 左旋}$$

$$\phi = -\frac{\pi}{2}:\ \mathbf{E}(0,t) = E_0[\cos(\omega t)\mathbf{a}_x + \sin(\omega t)\mathbf{a}_y]\tag{11.98}\ \text{逆时针 → 右旋}$$

矢量末端轨迹是圆、大小恒为 $E_0$，即**圆极化（circular polarization）**。

**旋向判定（左右手法则）**：左手拇指指传播方向、其余四指随场旋转 → **左旋圆极化（left-hand circular polarization, LHCP）**；右手拇指指传播方向、四指随场旋转 → **右旋圆极化（right-hand circular polarization, RHCP）**。同一规则推广到椭圆极化（左/右旋椭圆极化）。

> 【插入 Hayt 图 11.6】式(11.98) 描述的 RHCP：波沿 $+z$ 传播时，$xy$ 平面内场矢量逆时针旋转。

瞬时夹角：

$$\theta(z,t) = \arctan\frac{E_y}{E_x} = \mp(\omega t - \beta z)\tag{11.99}$$

$\mp$ 的上号对应 $\phi = +\pi/2$（LHCP）、下号对应 $\phi = -\pi/2$（RHCP）。固定 $t$ 沿 $z$ 看是"螺旋楼梯"空间场型，固定 $z$ 看是旋转（图 11.7）——同一螺旋的两个截面。

## 相量形式与传播方向

圆极化相量（沿 $+z$）：

$$\mathbf{E}_s = E_0(\mathbf{a}_x \pm j\mathbf{a}_y)e^{-j\beta z}\tag{11.100}$$

**$+j$ → 左旋，$-j$ → 右旋**（$+z$ 传播）。沿 $-z$ 传播时：

$$\mathbf{E}_s = E_0(\mathbf{a}_x \pm j\mathbf{a}_y)e^{+j\beta z}\tag{11.101}$$

**旋向反号**：$+j$ → 右旋，$-j$ → 左旋。

> **易错点**：旋向由 $\pm j$ **和** 传播方向共同决定，只看 $\pm j$ 不看 $e^{\mp j\beta z}$ 会判反。这与 Pozar 的约定一致（[[Pozar-Microwave Engineering/C1-电磁理论基础#右旋圆极化rhcp|Pozar: E₁=−jE₂ → RHCP, E₁=+jE₂ → LHCP]]）。

## 圆极化的工程意义与产生（λ/4 片）

**为什么需要圆极化**：圆极化波的接收**与天线在垂直于传播方向的平面内的取向无关**——线极化偶极子必须对齐电场方向，圆极化则"取向宽松"，故卫星通信/遥测常用。光学中圆偏振光穿过任意取向偏振片都能得到线偏振光（损失一半功率）。

**产生：四分之一波长片（quarter-wave plate, λ/4 片）**：各向异性晶体（$\varepsilon$ 随电场方向变化）截成合适长度，使 $45^\circ$ 输入的线极化波的 $E_x$、$E_y$ 分量以不同速度传播、累积 $\pi/2$ 相位差 → 输出圆极化。原理：**极化态的转换靠两正交分量"差相移"实现**。

## 圆极化基：线极化的合成与旋光（例 11.7）

等幅 LHCP + RHCP 叠加（相对相位差 $\delta$）：

$$\mathbf{E}_{sT} = 2E_0\left[\cos\frac{\delta}{2}\mathbf{a}_x + \sin\frac{\delta}{2}\mathbf{a}_y\right]e^{-j(\beta z - \delta/2)}\tag{11.102}$$

结果是一个**线极化波**，方向与 $x$ 轴夹角 $\delta/2$。**反之，任意线极化 = 两个旋向相反的圆极化之和**，方向由二者的相对相位决定。

**应用（旋光/optical activity）**：手性（左手/右手螺旋）有机分子对 LHCP 与 RHCP 的作用不同 → 两圆极化分量传播速度不同 → 累积相位差 → 出射线极化方向旋转。旋转角是材料表征的测量量（旋光仪原理）——这是"圆极化基"的实用价值。

> **通向第 12 章**：极化的意义在反射处凸显——平面波斜入射时，平行/垂直极化对应完全不同的 Fresnel 反射系数，故反射分析必须先按极化分解（见 [[平面电磁波的反射和散射]]）。
