# 10.1 传输线中波传播的物理描述

## 分布参数：何时需要传输线理论

传输线把电能/信号从电源传到负载（发射机-天线、计算机互连、水电厂-变电站……），共同点是**连接距离达到一个波长量级或更大**。基本电路分析假设元件间连线长度可忽略（各点电压同相、时间同步）；当电源与接收器距离足够大，延迟导致的相位差变得可觉察——必须改用**波**的观点。

**判据**：若传播时间延迟与感兴趣的最短时间间隔同量级（正弦稳态下即器件两端有明显相位差），就必须把元件当作**分布参数元件（distributed parameter element）**——电阻、电感、电容都按**每单位长度**计。传输线因此本身成为一个电路元件，对电路呈现复阻抗（随长度和频率变化）。

> 这是 [[Pozar-Microwave Engineering/C1-电磁理论基础#分布元件与集总元件的分界|Pozar: λ ~ d 时集总近似失效]] 的同一判据——Hayt 用"时间延迟"表述，Pozar 用"电尺寸 λ~d"表述，本质相同。第 11 章的平面波是"无结构的传输线"，本章是"有结构的平面波"。

## 波前面：电压电流的传播与反射

闭合开关把电池 $V_0$ 接到无损耗线输入端，$V^+ = V_0$ 以确定速度从源端向负载传播。**波前面（wavefront）** 是"已充电段/未充电段"的分界，电压、电流在穿过波前面时**不连续**（阶跃）。波到达终端后部分或全部反射，取决于负载：开路全反射、匹配部分反射（10.9 节详述）。

## 梯形网络与波速

传输线每单位长度分布有电容和电感（第 6、8 章已求过表达式）。用集总 L、C 建梯形网络模型（图 10.2，称**脉冲发生网络**）：开关闭合后 $L_1$ 电流增大 → $C_1$ 充电 → $L_2$ → $C_2$…逐级向前，波前面位于充电水平相差最大的两电容之间。L、C 越小波速越快，故波速与 $LC$ 乘积成反比——无损耗线 $v = 1/\sqrt{LC}$。

**两种分析方法**：(1) 直接解 Maxwell 方程求 $\mathbf{E}/\mathbf{H}$；(2) 电路模型求 $V/I$（本章采用），场论只用于算 L、C。损耗或高频复杂波行为（模式）时电路模型失效——有损线见 10.7 节，模式见第 13 章。

# 10.2 传输线方程

## 原参数与增量模型

传输线由**原参数（primary parameters）** 描述，均按每单位长度：$L$（电感）、$C$（电容）、$G$（并联电导，模拟介质漏电流，由 $\sigma_d$ 决定）、$R$（串联电阻，由导体 $\sigma_c$ 决定）。后两者决定损耗功率，一般随频率变化。给定频率与尺寸，用前几章公式可算出 R、G、L、C。

取长 $\Delta z$ 的一段，参数为 $R\Delta z, L\Delta z, G\Delta z, C\Delta z$；为对称起见串联元件分成两半、并联元件两端各半（图 10.3）。

## 电报方程

对整段回路用 KVL、对上方中心结点用 KCL，取 $\Delta z \to 0$ 极限：

$$\frac{\partial V}{\partial z} = -\left(RI + L\frac{\partial I}{\partial t}\right)\tag{10.5}$$

$$\frac{\partial I}{\partial z} = -\left(GV + C\frac{\partial V}{\partial t}\right)\tag{10.8}$$

这就是**电报方程（telegrapher's equations）**——电压/电流沿线的变化率由串联阻抗压降和并联导纳漏流决定。历史上源于电报线，是传输线理论的核心。

> **与 Maxwell 旋度方程的形式同构**：$\partial V/\partial z = -(RI + L\partial I/\partial t)$ ↔ $\nabla\times\mathbf{E} = -\partial\mathbf{B}/\partial t$（法拉第），$\partial I/\partial z = -(GV + C\partial V/\partial t)$ ↔ $\nabla\times\mathbf{H} = \mathbf{J} + \partial\mathbf{D}/\partial t$（安培-麦克斯韦）。对应 $V\leftrightarrow E,\ I\leftrightarrow H,\ L\leftrightarrow\mu,\ C\leftrightarrow\varepsilon,\ R\leftrightarrow$ 导电损耗, $G\leftrightarrow$ 介质损耗。这正是 [[C11-均匀平面电磁波#11.1 自由空间中波的传播|第 11 章平面波一阶耦合方程(11.7)(11.8)]] 的"有结构"版本——两章互为镜像。

## 波方程

联立消元（式(10.5) 对 $z$ 求导、式(10.8) 对 $t$ 求导）：

$$\frac{\partial^2 V}{\partial z^2} = LC\frac{\partial^2 V}{\partial t^2} + (LG + RC)\frac{\partial V}{\partial t} + RGV\tag{10.11}$$

电流满足同形方程。这是**传输线波方程的一般形式**，各条件下的解是后续各节主题。

> 【插入 Hayt 图 10.3】长 $\Delta z$ 传输线的集总参数对称模型（串联元件分半、并联元件分半），KVL 与 KCL 分别作用于回路与结点。

# 10.3 无损耗传输

## 波方程与一般解

无损耗：$R = G = 0$，式(10.11) 只剩首项：

$$\frac{\partial^2 V}{\partial z^2} = LC\frac{\partial^2 V}{\partial t^2}\tag{10.13}$$

其解为任意波形以恒定速度 $v$ 传播：

$$V(z,t) = f_1\left(t-\frac{z}{v}\right) + f_2\left(t+\frac{z}{v}\right) = V^+ + V^-\tag{10.14}$$

$f_1$、$f_2$ 是**任意函数**（形式不影响解）；自变量 $(t-z/v)$ 对应 $+z$ 行波、$(t+z/v)$ 对应 $-z$ 行波。代入验证得波速

$$v = \frac{1}{\sqrt{LC}}\tag{10.19}$$

印证 10.1 的猜测：波速与 $LC$ 乘积成反比，$L$、$C$ 越小波越快。

## 特性阻抗 Z₀

无损耗电报方程：

$$\frac{\partial V}{\partial z} = -L\frac{\partial I}{\partial t}\tag{10.20}$$
$$ \frac{\partial I}{\partial z} = -C\frac{\partial V}{\partial t}\tag{10.21}$$

把式(10.14) 代入并对 $t$ 积分，得电流：

$$I(z,t) = \frac{1}{Lv}[f_1 - f_2] = I^+ + I^-\tag{10.23}$$

**注意正向波与负向波前的符号相反**。定义**特性阻抗（characteristic impedance）**

$$Z_0 = Lv = \sqrt{\frac{L}{C}}\tag{10.24}$$

于是

$$V^+ = Z_0 I^+,\qquad V^- = -Z_0 I^-\tag{10.25}$$

**负号的物理意义**（图 10.4）：约定沿线正向（顺时针）电流为正。正极性的负向电压波伴随的是反向流动的电流，故 $V^- = -Z_0 I^-$。这保证功率始终沿传播方向——与第 11 章 $E'_{x0} = -\eta_0 H'_{y0}$ 是**同一个物理事实**（见 [[C11-均匀平面电磁波#11.1 自由空间中波的传播|11.1 波阻抗 η₀]]）。

> **$Z_0$ vs $\eta_0$**：$Z_0 = \sqrt{L/C}$ 含几何因子（L、C 由横截面形状决定），$\eta_0 = \sqrt{\mu_0/\varepsilon_0}$ 只含介质常数。这是"特性阻抗 vs 波阻抗"区分的根源，Pozar 在 [[Pozar-Microwave Engineering/C2-传输线理论#波阻抗-z_w-vs-特性阻抗-z_0|Pozar: Z_w vs Z₀]] 中系统阐述。

> 【插入 Hayt 图 10.4】正极性电压波中的电流方向——负向波电流反向，解释 $V^- = -Z_0 I^-$。

# 10.4 正弦电压的无损耗传输

## 频域分析的基础

任何信号都可分解为正弦波之和——频域分析：传输线对信号的效应 = 对各频率分量的效应之和，再聚合回时域。故先理解单一频率正弦波。

## 相速、相位常数与波长

式(10.14) 取正弦函数，用 $(t \mp z/v_p)$ 代 $t$：

$$\mathcal{V}(z,t) = |V_0|\cos(\omega t \pm \beta z + \phi)\tag{10.26}$$

**相速（phase velocity）$v_p$** 只适用于单一频率正弦波（后面会看到 $v_p$ 可能随频率变化）。正向波 $\mathcal{V}_f = |V_0|\cos(\omega t-\beta z)$、反向波 $\mathcal{V}_b = |V_0|\cos(\omega t+\beta z)$。定义**相位常数（phase constant）**

$$\beta \equiv \frac{\omega}{v_p}\tag{10.28}$$

$\beta$（rad/m）是"空间频率"：单位长度的相移，正如 $\omega$（rad/s）是单位时间的相移。波长

$$\lambda = \frac{2\pi}{\beta} = \frac{v_p}{f}\tag{10.30}$$

**跟踪波峰**：要求 $\omega t - \beta z = 2m\pi$ 恒成立 → $t$ 增大 $z$ 必增大 → 波以 $v_p$ 沿 $+z$ 前进（等相位面速度）。

> 这里与 11.1 节"波数 $k_0 = \omega/c$、跟踪波峰"完全相同——把 $v_p$ 换成 $c$、$\beta$ 换成 $k_0$ 就是 11.1（见 [[C11-均匀平面电磁波#11.1 自由空间中波的传播|11.1]]）。传输线的 $\beta$ 与平面波的 $k$ 是同一"空间频率"概念。

# 10.5 正弦波的复数分析

## 相量表示

复数法使相位累积的计算与多个正弦波的叠加大大简化。由欧拉公式：

$$\cos(x) = \mathrm{Re}[e^{jx}] = \tfrac12 e^{jx} + \mathrm{c.c.}\tag{10.33a}$$

把电压波写成：

$$\mathcal{V}(z,t) = |V_0|\cos(\omega t\pm\beta z+\phi) = \tfrac12\underbrace{|V_0|e^{j\phi}}_{V_0}e^{\pm j\beta z}e^{j\omega t} + \mathrm{c.c.}\tag{10.34}$$

其中**相量（phasor）$V_0 = |V_0|e^{j\phi}$ 是复数振幅**（含幅值与相位）。定义复数瞬态电压 $V_c(z,t) = V_0 e^{\pm j\beta z}e^{j\omega t}$，去掉 $e^{j\omega t}$ 得**相电压（phasor voltage）**

$$V_s(z) = V_0 e^{\pm j\beta z}\tag{10.36}$$

瞬时量 $= \mathrm{Re}[V_s e^{j\omega t}] = \tfrac12 V_s e^{j\omega t} + \mathrm{c.c.}$。**相量的意义**：固定时间、只看空间中的稳态波分布；要求所有波同频率。

### 例 10.1：驻波

两个同频同幅反向传播波叠加：$V_{sT} = V_0 e^{-j\beta z} + V_0 e^{+j\beta z} = 2V_0\cos(\beta z)$，瞬时 $\mathcal{V} = 2V_0\cos(\beta z)\cos(\omega t)$。

这是**驻波（standing wave）**：幅值沿 $\cos(\beta z)$ 变化、随时间 $\cos(\omega t)$ 振荡，零点固定在 $\beta z = m\pi/2$（$m$ 奇）——不传播。驻波是反射波的标志，10.10 节将引出驻波比（VSWR）。

# 10.6 传输线方程组及其相量形式解

## 相量波方程与传播常数

把瞬时波方程(10.11) 中的 $\partial/\partial t \to j\omega$，得相量波方程：

$$\frac{d^2 V_s}{dz^2} = \underbrace{(R+j\omega L)}_{Z}\underbrace{(G+j\omega C)}_{Y}V_s = \gamma^2 V_s\tag{10.40}$$

其中 $Z = R+j\omega L$、$Y = G+j\omega C$ 是单位长度的串联阻抗与并联导纳。**传播常数（propagation constant）**

$$\gamma = \sqrt{(R+j\omega L)(G+j\omega C)} = \sqrt{ZY} = \alpha + j\beta\tag{10.41}$$

解为

$$V_s(z) = V_0^+ e^{-\gamma z} + V_0^- e^{+\gamma z}\tag{10.42a}$$

$$I_s(z) = I_0^+ e^{-\gamma z} + I_0^- e^{+\gamma z}\tag{10.42b}$$

## 特性阻抗的一般表达式

相量电报方程：

$$\frac{dV_s}{dz} = -(R+j\omega L)I_s = -ZI_s\tag{10.44a},\qquad \frac{dI_s}{dz} = -(G+j\omega C)V_s = -YV_s\tag{10.44b}$$

代入解并令 $e^{\pm\gamma z}$ 系数相等：

$$Z_0 = \frac{V_0^+}{I_0^+} = -\frac{V_0^-}{I_0^-} = \sqrt{\frac{Z}{Y}} = \sqrt{\frac{R+j\omega L}{G+j\omega C}}\tag{10.46, 10.47}$$

一般 $Z_0$ 是复数（有损耗时）。**$Z_0$ 的完整定义：单一方向行波的电压电流比**——传输线最重要的参数，决定反射与匹配（10.9 节、Pozar 全书）。

> **γ 与平面波 jk 的同构**：$\gamma = \sqrt{(R+j\omega L)(G+j\omega C)}$ ↔ $jk = \sqrt{j\omega\mu(\sigma + j\omega\varepsilon')}$。$\alpha+j\beta$ 的结构完全相同，只是损耗来源从 $R,G$ 换成 $\sigma$（见 [[C11-均匀平面电磁波#11.2 电介质中波的传播|11.2]]）。这是"传输线 = 一维平面波"的最强证据。

### 例 10.2：无损耗线参数

$L = 0.25\ \mu\mathrm{H/m}$、$C = 100\ \mathrm{pF/m}$、$f = 600\ \mathrm{MHz}$：$Z_0 = \sqrt{L/C} = 50\ \Omega$，$\beta = \omega\sqrt{LC} = 18.85\ \mathrm{rad/m}$，$v_p = \omega/\beta = 2\times10^8\ \mathrm{m/s}$（$= c/1.5$，对应 $\varepsilon_r \approx 2.25$ 的介质）。

# 10.7 无损耗传输和低损耗传输

## 衰减系数 α 的意义

一般解(10.42) 代入 $\gamma = \alpha+j\beta$：

$$V_s(z) = V_0^+ e^{-\alpha z}e^{-j\beta z} + V_0^- e^{\alpha z}e^{j\beta z}\tag{10.48}$$

$$\mathcal{V}(z,t) = V_0^+ e^{-\alpha z}\cos(\omega t-\beta z) + V_0^- e^{\alpha z}\cos(\omega t+\beta z)\tag{10.49}$$

正向波幅值按 $e^{-\alpha z}$ 衰减，反向波按 $e^{\alpha z}$（沿其传播方向也是衰减）。**衰减系数（attenuation constant）$\alpha$ 单位 Np/m**。$\beta$ 仍定义 $v_p = \omega/\beta$、$\lambda = 2\pi/\beta$。仅当 $R = G = 0$ 时 $\alpha = 0$、$\gamma = j\omega\sqrt{LC}$。

## 低损耗近似：α 与 β

低损耗条件 $R \ll \omega L$、$G \ll \omega C$（工程常见）。把 $\gamma$ 改写并二项式展开 $\sqrt{1+x} \approx 1 + x/2 - x^2/8$：

$$\alpha \approx \frac12\left(R\sqrt{\frac{C}{L}} + G\sqrt{\frac{L}{C}}\right)\tag{10.54a}$$

$$\beta \approx \omega\sqrt{LC}\left[1 + \frac18\left(\frac{G}{\omega C} - \frac{R}{\omega L}\right)^2\right]\tag{10.54b}$$

**逐项解读**：
- $\alpha$ 与 $R$、$G$ 成正比——两项分别是串联电阻损耗与并联电导损耗的贡献。
- 式(10.54b) 中含 $R$、$G$ 的平方项使 $v_p = \omega/\beta$ **随频率变化**（色散），导致信号失真。
- 若 $R/L = G/C$（**亥维赛条件/无畸变条件**），平方项为零，$\beta = \omega\sqrt{LC}$ 严格线性，$v_p$、$v_g$ 均与频率无关——**无畸变传输线**。

> **与平面波良电介质近似的精确对应**：$\alpha \approx \frac12(R\sqrt{C/L}+G\sqrt{L/C})$ ↔ $\alpha \approx \frac{\sigma}{2}\sqrt{\mu/\varepsilon'}$（[[C11-均匀平面电磁波#11.2 电介质中波的传播|11.2 式 11.60a]]）。$R\leftrightarrow\sigma$（导电损耗）、$G\leftrightarrow$ 介质损耗、$L\leftrightarrow\mu$、$C\leftrightarrow\varepsilon'$。Pozar 在 [[Pozar-Microwave Engineering/C2-传输线理论#低损耗近似|Pozar: 低损耗线]] 中给出同样的 $\alpha \simeq (R/Z_0 + GZ_0)/2$。

## 低损耗特性阻抗

对 $Z_0 = \sqrt{(R+j\omega L)/(G+j\omega C)}$ 同样二项式展开，$Z_0$ 一般为复数；当无畸变条件 $R/L = G/C$ 成立时，$Z_0$ 精确回到 $\sqrt{L/C}$（与无损耗同）。

### 例 10.3：G = 0

$G=0$、$R$ 有限（低损耗）：$Z_0 \approx \sqrt{L/C}(1 - jR/(2\omega L))$，$|Z_0| \approx \sqrt{L/C}$，相角 $\theta = \arctan(-R/2\omega L)$——小的负虚部（容性）。

## 集肤效应的预告

损耗一般随频率增大而增大，主因是**电阻 $R$ 随频率增大**——集肤效应（电流被挤到导体表面）。这需要场论计算，第 11 章研究集肤效应（[[C11-均匀平面电磁波#11.4 良导体中波的传播：集肤效应|11.4 节]]），并应用于第 13 章传输线结构。

# 10.8 传输功率和损耗特性

## 平均功率与复功率

有损线正向波电压、电流均按 $e^{-\alpha z}$ 衰减，瞬时功率 $\mathcal{P} = \mathcal{V}\mathcal{I} = |V_0||I_0|e^{-2\alpha z}\cos(\omega t-\beta z)\cos(\omega t-\beta z+\theta)$。周期平均（二次谐波积分为零）：

$$\langle\mathcal{P}\rangle = \frac12 |V_0||I_0| e^{-2\alpha z}\cos\theta = \frac12\frac{|V_0|^2}{|Z_0|}e^{-2\alpha z}\cos\theta\tag{10.60}$$

**相量形式（最常用）**：

$$\langle\mathcal{P}\rangle = \frac12\mathrm{Re}\{V_s I_s^*\}\tag{10.63}$$

$I_s^*$ 的共轭使相位差 $\theta$ 自动进入实部。这正是 11.3 节 $\langle\mathbf{S}\rangle = \frac12\mathrm{Re}\{\mathbf{E}_s\times\mathbf{H}_s^*\}$ 的**传输线版本**（[[C11-均匀平面电磁波#11.3 坡印亭定理和波的功率|11.3 式 11.77]]）——$V\leftrightarrow E,\ I\leftrightarrow H$ 的对偶贯穿始终。

## 功率衰减：e^{-2αz} 与 dB

$$\langle\mathcal{P}(z)\rangle = \langle\mathcal{P}(0)\rangle e^{-2\alpha z}\tag{10.65}$$

**功率按 $e^{-2\alpha z}$ 衰减，电压/电流按 $e^{-\alpha z}$ 衰减**——功率 ∝ 幅值²，与 11.3 节的结论完全相同。

用分贝表示（$10^{-k\alpha z} = e^{-2\alpha z} \Rightarrow k = \log_{10}e^2 = 0.869$）：

$$\text{功率衰减(dB)} = 10\log_{10}\frac{\langle\mathcal{P}(0)\rangle}{\langle\mathcal{P}(z)\rangle} = 8.69\,\alpha z\tag{10.68}$$

等价地 $= 20\log_{10}[|V_0(0)|/|V_0(z)|]$。**1 Np = 8.69 dB**（因 $20\log_{10}e = 8.686$）。

**为什么用 dB**：级联器件的总衰减 = 各单元 dB 衰减**相加**（对数把乘法变加法）——系统级损耗预算的基础工具。

### 例 10.4：20 m 线衰减 2 dB

输出/输入功率比 $= 10^{-0.2} = 0.63$；中点（10 m，衰减 1 dB）$= 10^{-0.1} = 0.79$；$\alpha = 2.0/(8.69\times20) = 0.012\ \mathrm{Np/m}$。

# 10.9 波在不连续处的反射

## 反射系数与传输系数

波在终端/连接处反射，起因是必须满足该处的电压、电流边界条件。设负载 $Z_L = R_L + jX_L$ 位于 $z=0$，入射波 $V_i = V_{0i}e^{-\alpha z}e^{-j\beta z}$、反射波 $V_r = V_{0r}e^{+\alpha z}e^{+j\beta z}$。在 $z=0$：$V_L = V_{0i}+V_{0r}$，$I_L = \frac{1}{Z_0}(V_{0i}-V_{0r}) = V_L/Z_L$。联立得

$$\Gamma \equiv \frac{V_{0r}}{V_{0i}} = \frac{Z_L - Z_0}{Z_L + Z_0} = |\Gamma|e^{j\phi_r}\tag{10.73}$$

**反射系数（reflection coefficient）$\Gamma$ 是复数**：幅值 $<1$（反射波幅值减小）、相位是相对入射波的相移。传输系数（transmission coefficient）

$$\tau \equiv \frac{V_L}{V_{0i}} = 1 + \Gamma = \frac{2Z_L}{Z_0 + Z_L}\tag{10.75}$$

> 【插入 Hayt 图 10.5】复阻抗负载 $Z_L$ 引起的电压波反射（入射波 $V_i$、反射波 $V_r$）。

> **Γ 是微波工程最重要的公式之一**（Pozar 全书核心）。它与平面波正入射反射 $\Gamma = (\eta_2-\eta_1)/(\eta_2+\eta_1)$ 同构（$Z_0\leftrightarrow\eta$），见 [[平面电磁波的反射和散射|第 12 章]] 与 [[Pozar-Microwave Engineering/C1-电磁理论基础#一般介质反射系数与传输系数|Pozar: 垂直入射 Γ/T]]。

## 功率关系：|Γ|² 与 1-|Γ|²

$$\frac{\langle\mathcal{P}_r\rangle}{\langle\mathcal{P}_i\rangle} = |\Gamma|^2,\qquad \frac{\langle\mathcal{P}_t\rangle}{\langle\mathcal{P}_i\rangle} = 1 - |\Gamma|^2\tag{10.77}$$

**传输功率比是 $1-|\Gamma|^2$，不是 $|\tau|^2$**（易错点）。$\tau > 1$ 并不矛盾：负载电压可大于入射电压（$I_L < I_i$ 补偿），但负载吸收的平均功率恒 $\le$ 入射功率。

**匹配条件**：$\Gamma = 0 \Leftrightarrow Z_L = Z_0$——负载吸收全部入射功率。无反射是关键设计目标（引出后续匹配技术）。

### 例 10.5 与例 10.6

例 10.5：$Z_L = 50-j75\ \Omega$、$Z_0 = 50\ \Omega$ → $\Gamma = 0.36-j0.48 = 0.60e^{-j93^\circ}$，$P_t = (1-0.6^2)\times100 = 64\ \mathrm{mW}$。

例 10.6：两有损线级联 + 连接点反射，各段 dB 衰减相加：$L_t = 0.2\times10 + 10\log_{10}\frac{1}{1-0.3^2} + 0.1\times15 = 3.91\ \mathrm{dB}$，$P_{out} = 100\times10^{-0.391} = 41\ \mathrm{mW}$。

## 两条线的连接

线 1($Z_{01}$) → 线 2($Z_{02}$)：把线 2 当负载，$\Gamma = (Z_{02}-Z_{01})/(Z_{02}+Z_{01})$，传输功率比 $= 1-|\Gamma|^2$。

# 10.10 电压驻波比

## 开槽测量线与行波/驻波分解

**开槽传输线（slotted line）**：外导体开轴向缝、内放电压探针测内外导体间电压幅值，是测量负载阻抗的经典仪器。三种情形：
- **匹配负载**：无反射，探针读数处处相同（无衰减行波特征）。
- **开路/短路**：纯驻波，节点处零读数，按 $|\sin(\beta z)|$ 或 $|\cos(\beta z+\phi)|$ 变化，节点间距 $\lambda/2$。
- **部分反射**：电压 = 行波 + 驻波。

总相电压 $V_{sT} = V_0 e^{-j\beta z} + \Gamma V_0 e^{j\beta z}$（无损耗线，$\Gamma = |\Gamma|e^{j\phi}$）。加减小 $V_0(1-|\Gamma|)e^{-j\beta z}$ 项分解：

$$V_{sT} = \underbrace{V_0(1-|\Gamma|)e^{-j\beta z}}_{\text{行波}} + \underbrace{2V_0|\Gamma|e^{j\phi/2}\cos(\beta z+\phi/2)}_{\text{驻波}}\tag{10.83}$$

$$\mathcal{V}(z,t) = V_0(1-|\Gamma|)\cos(\omega t-\beta z) + 2|\Gamma|V_0\cos(\beta z+\phi/2)\cos(\omega t+\phi/2)\tag{10.84}$$

**物理图像**：入射波中 $(1-|\Gamma|)$ 部分继续前进（行波），$|\Gamma|$ 部分与等量入射波干涉形成驻波。于是 $V_{\max} = V_0(1+|\Gamma|)$、$V_{\min} = V_0(1-|\Gamma|)$。

## VSWR 与负载阻抗测量

$$s \equiv \frac{V_{\max}}{V_{\min}} = \frac{1+|\Gamma|}{1-|\Gamma|}\tag{10.92}$$

**电压驻波比（voltage standing wave ratio, VSWR）**：匹配负载 $s=1$，全反射 $s=\infty$，故 $1 \le s \le \infty$。由 $s$ 直接得 $|\Gamma| = (s-1)/(s+1)$；再由第一个最大/最小值距负载的位置（式 10.86/10.89）得 $\Gamma$ 的相位 → 反解 $Z_L$。

关键判据：$\phi = 0$（$Z_L > Z_0$ 实数）时负载端为电压最大值；$\phi = \pi$（$Z_L < Z_0$ 或短路）时负载端为最小值。最大/最小值均以 $\lambda/2$ 间隔出现。

> 【插入 Hayt 图 10.6】$|V_{sT}|$ 随 $z$ 变化曲线，反射系数相角 $\phi$ 决定最大/最小值位置。

### 例 10.7：由 VSWR 反推负载

$s = 5$、相邻最大值间距 15 cm（→ $\lambda = 30\ \mathrm{cm}$）、第一个最大值距负载 7.5 cm $= \lambda/4$（→ 负载端为最小值 → $\Gamma$ 负实数）：$|\Gamma| = (5-1)/(5+1) = 2/3$，$\Gamma = -2/3$ → $Z_L = Z_0\frac{1+\Gamma}{1-\Gamma} = 50/5 = 10\ \Omega$。

> 开槽测量线现已被矢量网络分析仪（VNA）取代，但它是理解驻波概念的最佳工具——与 Pozar [[Pozar-Microwave Engineering/C2-传输线理论#开槽测量线|Pozar: 开槽测量线]] 和 [[Pozar-Microwave Engineering/C2-传输线理论#电压驻波比-swr|SWR]] 同源。

# 10.11 有限长传输线

## 输入阻抗方程

终端不匹配的有限长线在两端都有多次反射；稳态下只需考虑一个**净正向波** $V_0^+$ 和一个**净负向波** $V_0^-$（各自是所有入射/反射波的叠加）。定义**波阻抗（wave impedance）** $Z_w(z) = V_{sT}/I_{sT}$，用 $V_0^- = \Gamma V_0^+$、$I_0^\pm = \pm V_0^\pm/Z_0$ 化简，在 $z=-l$ 处得**输入阻抗（input impedance）**：

$$Z_{in} = Z_0\left[\frac{Z_L\cos(\beta l) + jZ_0\sin(\beta l)}{Z_0\cos(\beta l) + jZ_L\sin(\beta l)}\right]\tag{10.98}$$

**这是传输线理论的核心公式**：任意负载经任意长度后的输入阻抗，是 Smith 圆图、阻抗匹配、放大器设计的基石（Pozar 式 2.44）。

> 【插入 Hayt 图 10.7】有限长传输线及其等效电路（源 $V_s$ 内阻 $Z_g$，负载 $Z_L$，线长 $l$）。

## λ/2 与 λ/4 特殊长度

- **半波长**（$l = m\lambda/2$，$\beta l = m\pi$）：$\cos = \pm1$、$\sin = 0$ → $Z_{in} = Z_L$——半波长线"透明"，可移去直接接负载。
- **四分之一波长**（$l = (2m+1)\lambda/4$，$\beta l = (2m+1)\pi/2$）：$\cos = 0$、$\sin = \pm1$ →

$$Z_{in} = \frac{Z_0^2}{Z_L}\tag{10.100}$$

**λ/4 线的阻抗反转**：短路 $Z_L=0$ → $Z_{in}=\infty$（开路）；开路 $Z_L=\infty$ → $Z_{in}=0$（短路）。这是阻抗变换/匹配的基础。

## 四分之一波长匹配

两线 $Z_{01}$、$Z_{03}$ 之间插入 $\lambda/4$ 长、特性阻抗 $Z_{02}$ 的线，其输入端 $Z_{in} = Z_{02}^2/Z_{03}$。令 $Z_{in} = Z_{01}$ 消除连接点反射：

$$Z_{02} = \sqrt{Z_{01}Z_{03}}\tag{10.103}$$

**四分之一波长匹配（quarter-wave matching）**：$Z_{02}$ 取两端阻抗的几何平均。**仅在某确定频率（窄带）成立**——频率偏离后 $\beta l \neq \pi/2$，匹配失效。这与 Pozar [[Pozar-Microwave Engineering/C2-传输线理论#四分之一波长变换器ell--lambda4或-lambda4--nlambda2|Pozar: λ/4 变换器]] 完全对应，第 12 章平面波反射还会再遇到 λ/4 匹配。

# 10.12 几个传输线的例子

本节用 300Ω 双线（TV/FM 天线馈线，$v = 2.5\times10^8\ \mathrm{m/s}$、$f = 100\ \mathrm{MHz}$、长 2 m → $\lambda = 2.5\ \mathrm{m}$、$\beta l = 1.6\pi = 0.8\lambda$）演示完整分析流程。

## 匹配：最大功率传输

负载 = 源 = $Z_0 = 300\ \Omega$（匹配）：$\Gamma = 0$、$s = 1$、$Z_{in} = 300\ \Omega$。源端分压 → $V_{in} = 30\ \mathrm{V}$（60 V 的一半），负载电压 $V_L = 30\cos(\omega t - 1.6\pi)$，仅多 $1.6\pi$ 相位滞后，$P_{in} = P_L = \frac12\times30\times0.1 = 1.5\ \mathrm{W}$。**匹配时无反射、无衰减，全部功率到负载，电压沿线幅值恒定。**

## 失配：并联接收器

两个 300Ω 接收器并联 → $Z_L = 150\ \Omega$，$\Gamma = (150-300)/(150+300) = -1/3$，$s = 2$。输入阻抗不再是 300Ω：

$$Z_{in} = 510\angle-23.8^\circ = 466-j206\ \Omega$$

**输入阻抗呈容性**——物理含义：这种长度的线上 $W_e > W_m$（电场储能大于磁场储能）。传输功率降到 $P_{in} = \frac12(0.0756)^2\times466 = 1.333\ \mathrm{W}$（< 匹配的 1.5 W），每个接收器 0.667 W（电压 20 V，而非匹配时的 30 V）。

**电压极值**：$Z_L < Z_0$ 纯电阻 → 负载端为电压最小值（$z_{\min} = 0, -1.25\ \mathrm{m}$），最大值 $z_{\max} = -0.625, -1.875\ \mathrm{m}$；$V_{\min} = 20\ \mathrm{V}$（负载电压）、$V_{\max} = 40\ \mathrm{V}$（$s=2$）。**负载电压与输入电压的相位差因反射从 288° 变为约 279°**——反射波"扭曲"了相位关系。

### 例 10.8 与例 10.9：复负载与纯电抗

例 10.8 再并联 $-j300\ \Omega$ 电容：$Z_L = 120-j60\ \Omega$，$\Gamma = 0.447\angle-153.4^\circ$，$s = 2.62$，$Z_{in} = 755-j138.5\ \Omega$，$P = 1.2\ \mathrm{W}$（每接收器 0.6 W）。

例 10.9 纯容抗 $Z_L = -j300\ \Omega$：$\Gamma = 1\angle-90^\circ$（$|\Gamma| = 1$）、$s = \infty$、$Z_{in} = j589\ \Omega$（纯电抗）——**纯电抗负载无平均功率传输**（功率全反射）。

> 这些例子揭示失配的代价链条：$Z_L \neq Z_0$ → $\Gamma \neq 0$ → $s > 1$ → 传输功率 $1-|\Gamma|^2$ 下降、输入阻抗变复数。下一节的 Smith 圆图把这些复数运算图形化。

# 10.13 图解法：史密斯圆图

## Smith 圆图的构造：Γ 平面 + 阻抗网格

传输线问题充满复数运算，**史密斯圆图（Smith chart）** 用图解法代替，是应用最广的传输线圆图。本质：**单位圆（$|\Gamma| \le 1$）内的极坐标图**，径向 $|\Gamma|$、角度 $\phi$（$\Gamma = |\Gamma|e^{j\phi}$）。

基于 $\Gamma = (z_L-1)/(z_L+1)$，其中归一化阻抗 $z_L = Z_L/Z_0 = r+jx$，反解 $z_L = (1+\Gamma)/(1-\Gamma)$。令 $\Gamma = \Gamma_r + j\Gamma_i$，分离实虚部得两族圆：

$$(\Gamma_r - \frac{r}{1+r})^2 + \Gamma_i^2 = (\frac{1}{1+r})^2 \quad \text{常电阻圆}\tag{10.112}$$

$$(\Gamma_r-1)^2 + (\Gamma_i-\frac{1}{x})^2 = (\frac{1}{x})^2 \quad \text{常电抗圆}\tag{10.113}$$

**所有圆都通过 $\Gamma = 1+j0$**。$r=0$（纯电抗）→ 单位圆；$r=\infty$ → 点 $\Gamma=1$。两族圆正交，给定 $z_L$ 找交点即得 $\Gamma$。

> 【插入 Hayt 图 10.9】Smith 圆图 = 单位圆内的 Γ 极坐标图（径向 $|\Gamma|$、角度 $\phi$）。

## 沿线移动 = 沿等 |Γ| 圆旋转

由式(10.114)：用 $\Gamma e^{-j2\beta l}$ 代替 $\Gamma$ 得 $z_{in}$——**向电源移动 $l$ = 在 Smith 圆图上顺时针旋转 $2\beta l$**，$|\Gamma|$ 不变（沿等 $|\Gamma|$ 圆）。半波长（$l = \lambda/2$）转一整圈回到原点（$\lambda/2$ 周期性）。圆周刻度 "wtg"（wavelengths toward generator）给出沿线距离。

### 例：$z_L = 0.5+j1$，$l = 0.3\lambda$

交点 A：$\Gamma = 0.62\angle82^\circ$，wtg = 0.135。移动 $0.3\lambda$ → wtg = 0.435，读 $z_{in} = 0.28-j0.40$（$Z_{in} = 14-j20\ \Omega$，解析值 $13.7-j20.2$）。

## Vmax/Vmin 与 VSWR 的读取

电压最大/最小值出现在**输入阻抗为纯电阻**的点（$x=0$ 的 $\Gamma_r$ 轴）——这些点可把负载+线换成纯电阻而不影响电源。$r>1$（wtg=0.25）→ 电压最大值；$r<1$（wtg=0）→ 电压最小值。**VSWR 直接读**：$|\Gamma|$ 圆与 $r$ 轴（$r>1$）交点的 $r$ 值就是 $s$。

## 导纳圆图与单短截线匹配

并联元件用导纳更方便：把 $r$ 圆当 $g$ 圆、$x$ 圆当 $b$ 圆（两处不同：$g>1, b=0$ 对应电压最小值；$\Gamma$ 角加 $180^\circ$）。$\lambda/4$ 旋转 = $z \leftrightarrow y = 1/z$ 互转。

### 开槽测量线与单短截线匹配（示例）

（1）**由 VSWR+最小值位置反推负载**：$s=2.5$、$\lambda = 75\ \mathrm{cm}$、负载电压最小值距负载 $0.030\lambda$ → 从 $z_{in}=2.5$（wtg=0.250）回退 0.030λ → $z_L = 2.1+j0.8$（$Z_L = 105+j40\ \Omega$）。

（2）**单短截线匹配**：$z_L = 2.1+j0.8$ → $\lambda/4$ 旋转得 $y_L = 0.41-j0.16$；在 $s=2.5$ 圆上找实部 $=1$ 的点（$1+j0.95$ 或 $1-j0.95$），选前者使短截线更短 → 短截线距负载 $0.19\lambda$、长度 $0.129\lambda$。

> 【插入 Hayt 图 10.13】实用 Smith 圆图（电阻圆 + 电抗圆 + wtg 刻度 + 径向 $|\Gamma|$ 刻度）。

> Smith 圆图是 $\Gamma$ 极坐标图 + 阻抗网格的完美结合——"沿线移动 = 旋转"是它的灵魂。Pozar 在 [[Pozar-Microwave Engineering/C2-传输线理论#gamma-平面上的阻抗圆|Pozar: Smith 圆图构造]] 中把它系统化为匹配设计的核心工具；如今 CAD 软件仍沿用其图形逻辑。

# 10.14 暂态分析

## 阶跃响应与多次反射

前面是稳态正弦，本节研究**阶跃/脉冲响应（暂态）**——数字信号（脉冲序列）的传输基础。限无损耗无色散线。

**匹配负载**（$R_L = Z_0$）：$t=0$ 闭合开关，电压波 $V^+ = V_0$ 以速度 $v$ 传播，$t = l/v$ 到达负载，无反射，暂态结束——负载电压 = 源电压（延迟 $l/v$）。

**失配负载**（$R_L \neq Z_0$）：波到负载反射 $\Gamma_L = (R_L-Z_0)/(R_L+Z_0)$，反射波回源端再反射 $\Gamma_g = (Z_g-Z_0)/(Z_g+Z_0)$（零内阻源 $\Gamma_g = -1$）……多次来回、幅值逐次减小（$|\Gamma_L| < 1$），最终稳态。叠加所有到达负载的波：

$$V_L = V_1^+(1+\Gamma_L)(1 + \Gamma_g\Gamma_L + \Gamma_g^2\Gamma_L^2 + \cdots) = V_1^+\frac{1+\Gamma_L}{1-\Gamma_g\Gamma_L}\tag{10.118}$$

**有内阻源**（$R_g$）：初始波由分压决定 $V_1^+ = V_0 Z_0/(R_g+Z_0)$（式 10.119）。

## 电压/电流反射图（反弹图）

**反射图（bounce diagram）**：$z$–$t$ 平面上的射线追踪——初始波从 $(z=0,t=0)$ 出发，到 $z=l$（$t=l/v$）反射，回 $z=0$（$t=2l/v$）再反射……每次反射乘对应端反射系数。**某点电压 = 该点垂直线与所有射线交点的值之和**（自下而上累加）。

电流图由电压图导出：$I^+ = V^+/Z_0$、$I^- = -V^-/Z_0$（负向波电流带负号，式 10.120/10.121）。

### 例 10.11：$R_g = Z_0 = 50\ \Omega$、$R_L = 25\ \Omega$、$V_0 = 10\ \mathrm{V}$

$V_1^+ = 5\ \mathrm{V}$（分压一半），$\Gamma_L = -1/3$，$V_1^- = -5/3\ \mathrm{V}$，$\Gamma_g = 0$（源匹配）→ 一次往返后达稳态：$V_L = 10/3\ \mathrm{V}$、$I_g = 10/75 = 1/7.5\ \mathrm{A}$——与直流集总电路分析一致。

## 带电线的放电与脉冲形成线

**带电传输线放电**：初始电压 $V_0$，$z=0$ 处经 $R_g$ 开关放电，$z=l$ 开路。开关闭合发出与 $V_0$ **极性相反**的电压波（抵消原电压）：

$$V_1^+ = -\frac{V_0 Z_0}{Z_0 + R_g}\tag{10.122}$$

**脉冲形成线（pulse-forming line）**：若 $R_g = Z_0$（匹配），$V_1^+ = -V_0/2$，一个往返 $T = 2l/v$ 内完全放电，电阻上得到幅值 $V_R = V_0/2$、宽度 $T$ 的**矩形脉冲**——波形好、噪声低，晶闸管开关可产生纳秒级高压脉冲。这是 10.1 节"脉冲发生网络"的完整理论闭环。

### 例 10.12：$R_g = 100/3\ \Omega$、$Z_0 = 100\ \Omega$、$V_0 = 160\ \mathrm{V}$

$\Gamma_g = -1/2$、$\Gamma_L = 1$（开路）→ $V_1^+ = -120$、$V_2^+ = +60$、$V_3^+ = -30$、$V_4^+ = +15\ \mathrm{V}$，电阻电压阶梯 40 → −20 → 10 → −5 V（每 $2l/v$ 一段）。

> 【插入 Hayt 图 10.21】反射电压图（$z$–$t$ 平面射线追踪），$z=3l/4$ 处电压由该点垂线与各射线交点累加。

> 暂态的多次反射 = 频域稳态的时域对偶（例 10.11 的几何级数 ↔ 式 10.118）。Pozar 在 [[Pozar-Microwave Engineering/C2-传输线理论#反弹图|Pozar: 反弹图]] 中给出同样的方法，是数字信号完整性/TDR 测量、脉冲形成的基础。
