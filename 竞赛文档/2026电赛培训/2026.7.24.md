# 二 赛题预测

（详细的预测可以参考达尔闻前日发布的相关视频）
**信号题的几个可能方向：**
1. 高频信号的调制解调：需要高速AD模块，FPGA或者模拟调制解调（AM/FM）模块
2. 低频线路：按照原有的模块准备即可，对ADC，DDS等模块及其驱动要非常熟悉
3. 称重：可以提前准备压力传感器，仪表放大器与七段数码管
4. 光电门测速：提前准备水管，小球，光电传感器
5. 电流检测：提前准备磁环磁芯漆包线，功放模块等
# 三 调制解调相关知识提要

如果想要做调制解调相关的题目，大概有两种方案可供选择：
1. 采用模拟模块完成：带宽与增益有限，需要混频到中频后解调
2. 采用FPGA：不用担心高频，精度较高
具体概念：《RF Microelectronics》
# 四 FPGA使用的相关说明

在使用FPGA时可以尝试做的事情：
1. 内置 乘法器（Arm的IP核直接调用）（可以沿用原来的方案）
2. 直接数字频率合成（DDS）（可以沿用模块方案）
3. 人机交互（串口屏）（可以沿用原来的方案）
4. 数字滤波器（fir）
5. 快速傅里叶变换以及对其加窗的操作（fft）
6. 在数字域对信号做完整的调制解调（鼓励尝试正交I/Q解调）
7. 拉高频率上线
建议：如果要在纯数字域进行，那么最好将全流程在FPGA中跑通一遍，（尤其是与ADC的交互），减少比赛中反复调试综合所需要的时间

# 五 赛前注意事项
## 时间安排
1. 第一天：花半天到3/4天做方案讨论与验证。务必要确认方案的科学性与可行性
	- 方案在数学上是否可行（尤其是高频，小信号检测相关的题目）
	- 方案的难度对于硬件来说是否过大：采样率/带宽/硬件的数量等，如果不确定就采用ai等工具快速写一个程序进行验证
	- 方案的细节：高频题的阻抗匹配，非线性，任意波的谐波问题，低频线路的精度问题等
	- 可能会提出多套可行的方案，可以根据具体的时间安排，选择先主攻一套，然后另一套用于完善，或者同时进行
	- 早上8点前来科协（吃早餐），晚上十二点前睡觉
2. 第二天：至少完成基础部分的指标，并且根据第一天的效果确定最终方案，晚上早点睡
3. 第三天：在原型机的基础上完善，精进发展指标，以及基础指标的具体细节，检查作品是否合规等
4. 第四天：早上十点前需要基本完成作品，然后留出至少半天的时间撰写报告，提前严格按照要求完成封箱
## 赛前准备
1. 封箱用的箱子
2. 亚克力板或者其他东西（用于固定系统）
3. 足够的线材（能够稳固链接的）
