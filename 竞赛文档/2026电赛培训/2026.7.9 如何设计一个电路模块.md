# 数据手册的结构与重要部分（以AD9834为例）
## 产品特性与描述
通过这一章节，我们需要对该芯片的一些基本特性有一个印象
![[Pasted image 20260709164639.png]]
### 产品特性
1. 供电范围：供电错误会直接导致模块不可用以及芯片的损坏
2. 输入输出类型：决定围绕该芯片的前级与后级电路该如何针对性设计
3. 与微处理器的通信方式：决定了软件驱动怎么写
4. 基本的优缺点：一般有频率，带宽，分辨率等，直接决定芯片的适用范围（**重要**）
### 产品概述
这一部分一般会提及在应用过程中芯片的一些特点与配置方式等，需要仔细阅读，在这篇手册中，其包含的信息为
1. 外部时钟的作用/分辨率与最高输出频率之间的权衡
2. 电源供电方式的提要
3. 通信方式满足时序要求的频率上限
4. 提醒该芯片具有休眠模式

## 功能框图
![[Pasted image 20260709170916.png]]
功能框图不需要大家完全理解，我们先需要理解的主要有两个方面：

## Layout
DDS是一类数模混合芯片，其数据手册中对接地与布局布线的说明具备较强的指导意义
![[Pasted image 20260709190722.png]]
总的来说，关于接地与布局布线有以下几点注意事项
1. 数模隔离，单点链接
2. 数字电路的噪声隔离（避免在器件下方直接布数字类信号线）
3. 电路馈通：垂直走线
4. 电源的隔离与去耦
5. 。。。。
具体的操作细节将在后面PCB布局部分来给大家着重讲解

## 功能的扩展
在数据手册中，有时会给出芯片详细的功能介绍，其中有些是可选的，因为我们的题目往往是不确定的，最大程度上将芯片的功能利用起来是我们在做硬件设计的时候需要关注的一个方面。
![[Pasted image 20260709192141.png]]
另外，在考虑功能扩展时，我们还应当注意一个关键点：我们的输入输出电路是存在限制的，但是我们可以通过对外围电路的设计来解决这样的限制，从而让我们的模块适用于更多，更复杂的场景，例如在这个dds的例子中，存在一个很明显的输出限制
- Iout 与 IoutB 输出的额定幅度都是0.6V，且二者是反向的（伪双通道）。
了解我们模块的特性对我们临场的发挥以及方案设计都是很有帮助的
# 绘制原理图

原理图的绘制步骤
1. 设计电源及其接口
2. 设计芯片外围电路及其输入输出接口
3. 检查并添加测试点

### 电源设计规范
![[Pasted image 20260709193209.png|697]] 
1. 电源接口统一规范（包含正负电源与GND）
2. 所有的电源都应当有电源指示灯
3. 留出电源测试点
### 芯片基础外围电路
![[Pasted image 20260709194948.png]]
芯片基础的外围电路设计，要围绕着数据手册中的引脚定义来做。对于这样一块较为复杂的芯片，我们要注意以下几点
1. 给引脚的内容/性质分组：哪些是电源引脚？哪些是输入信号引脚？哪些是输出信号引脚？那些是模拟/数字引脚？哪些是需要连接到固定器件上的引脚？
2. 电源引脚的连接：要做电源去耦（100nF陶瓷加1uF钽电容）
3. 模拟地与数字地的隔离
4. 应急方案（此处可以体现为电源的复用）
### 通信接口的设计
![[Pasted image 20260709195548.png]]
![[Pasted image 20260709195732.png]]
1. 顺序要保持一致，信号线尽量不要出现交叉的情况
2. 串联电阻防止过冲
3. 给出测试点，模块工作不正常的时候可以调节时序
