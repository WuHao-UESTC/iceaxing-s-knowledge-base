# 6.1 AWGN 信道

回顾 [[Goldsmith-无线通信/第2章-路径损耗与阴影衰落#2.2 发射与接收信号模型|第2章]] 的信号空间概念（[[Goldsmith-无线通信/第5章-数字调制与检测#5.1 信号空间分析|第5.1节]]）：AWGN 信道下，接收信号为 $r(t)=s(t)+n(t)$，其中 $n(t)$ 是零均值、功率谱密度 $N_0/2$ 的白高斯随机过程。

本章的核心问题：给定调制方式和 SNR，误码率是多少？这是通信系统性能分析的起点——后续章节（衰落信道、分集、MIMO）都在此基础上叠加信道损伤。

---

## 6.1.1 信噪比与比特/符号能量

### SNR 的定义

接收信噪比（Signal-to-Noise Power Ratio, SNR）定义为接收信号功率 $P_r$ 与信号带宽内噪声功率之比。

设复包络 $u(t)$ 带宽为 $B$，则已调信号 $s(t)$ 带宽为 $2B$（带通信号的带宽是基带信号的两倍）。噪声在带宽 $2B$ 内的总功率为：

$$N = \frac{N_0}{2} \times 2B = N_0 B$$

因此：

$$\mathrm{SNR} = \frac{P_r}{N_0 B}$$

**注意带宽的选取**：噪声功率 $N = N_0 B$（不是 $N_0 \cdot 2B$），因为 $N_0$ 定义为单边功率谱密度。这里 $N_0/2$ 是双边谱密度，乘以 $2B$ 得 $N_0 B$。

### SNR 与符号能量、比特能量的关系

将 SNR 用每符号能量 $E_s$ 和每比特能量 $E_b$ 表示：

$$\mathrm{SNR} = \frac{P_r}{N_0 B} = \frac{E_s}{N_0 B T_s} = \frac{E_b}{N_0 B T_b} \tag{6.1}$$

其中 $T_s$ 为符号时间、$T_b$ 为比特时间。对二进制调制，$T_s = T_b$ 且 $E_s = E_b$。

**关键特例**：对于满足 $T_s = 1/B$ 的数据脉冲（如升余弦脉冲 $\beta = 1$，即滚降因子最大时）：

$$\mathrm{SNR} = \frac{E_s}{N_0} \quad \text{（多进制信令）}, \qquad \mathrm{SNR} = \frac{E_b}{N_0} \quad \text{（二进制信令）}$$

对于一般脉冲 $T_s = k/B$（$k$ 为某常数），有 $k \cdot \mathrm{SNR} = E_s/N_0$。

> 为什么 $T_s = 1/B$ 时 SNR 恰好等于 $E_s/N_0$？因为 $B$ 是基带带宽，$T_s = 1/B$ 意味着传输速率为 $1/T_s = B$ 符号/秒——此时符号速率等于带宽，频谱效率为 1 Baud/Hz。这是升余弦 $\beta=1$ 时的情形。

### $\gamma_s$ 与 $\gamma_b$：符号 SNR 与比特 SNR

定义：

$$\gamma_s = \frac{E_s}{N_0}, \quad \gamma_b = \frac{E_b}{N_0}$$

分别称为 SNR per symbol（符号信噪比）和 SNR per bit（比特信噪比）。

**性能分析的惯用顺序**：
1. 用信号空间方法计算符号错误概率 $P_s$ 作为 $\gamma_s$ 的函数
2. 通过比特-符号映射关系，将 $P_s$ 转换为比特错误概率 $P_b$（BER）作为 $\gamma_b$ 的函数

### 从 $P_s$ 到 $P_b$：Gray 编码近似

对于 $M$ 进制信令，常使用以下近似：

$$\gamma_b \approx \frac{\gamma_s}{\log_2 M} \tag{6.2}$$

$$P_b \approx \frac{P_s}{\log_2 M} \tag{6.3}$$

近似成立的假设：
1. **符号能量均分**：总符号能量 $E_s$ 均匀分配给每个比特 → $\gamma_b \approx \gamma_s / \log_2 M$
2. **Gray 编码**：相邻符号仅差一个比特 → 在较高 SNR 下，一个符号错误 ≈ 恰好一个比特错误 → $P_b \approx P_s / \log_2 M$

> ⚡ 这两个近似在低 SNR 时会失准——低 SNR 下可能出现多个比特同时错，$P_b$ 会被低估。但在实际工作点（$P_b \ll 10^{-3}$）精度足够，广泛使用。

## 6.1.2 BPSK 与 QPSK 的误码率

### BPSK：二进制相移键控

BPSK 是二进制调制——每个符号一个比特，$P_b = P_s$。

发射信号：0 比特 → $s_1(t) = A g(t)\cos(2\pi f_c t)$，1 比特 → $s_2(t) = -A g(t)\cos(2\pi f_c t)$。

信号星座点：$\mathbf{s}_0 = \sqrt{E_b},\ \mathbf{s}_1 = -\sqrt{E_b}$，最小距离 $d_{\min} = 2\sqrt{E_b}$。

> 这里 $E_b = A^2$ 来自 (5.56)，因为 $g(t)$ 归一化使 $\int g^2(t)\cos^2(2\pi f_c t)dt = 1$。

由第 5 章的最优检测公式 (5.46) $P_b = Q(d_{\min}/\sqrt{2N_0})$，代入得：

$$P_b = Q\left(\frac{2\sqrt{E_b}}{\sqrt{2N_0}}\right) = Q\left(\sqrt{\frac{2E_b}{N_0}}\right) = Q(\sqrt{2\gamma_b}) \tag{6.6}$$

这是相干 BPSK 的精确比特误码率。$Q$ 函数是标准正态分布的尾概率：

$$Q(z) = \frac{1}{\sqrt{2\pi}} \int_z^\infty e^{-x^2/2} dx$$

**物理直觉**：BPSK 的两个星座点相距 $2\sqrt{E_b}$，噪声在任一维度上标准差为 $\sqrt{N_0/2}$。$d_{\min}/(\text{噪声 RMS}) = 2\sqrt{E_b}/\sqrt{N_0/2} = \sqrt{8E_b/N_0}$——这正是 $Q$ 函数的参数 $\sqrt{2E_b/N_0}$ 的来源（差一个 $\sqrt{2}$ 因子是因为 $Q$ 的定义用了 $\sigma=1$ 的标准正态）。

### QPSK：四进制相移键控

QPSK 的实质：**在两个正交支路（I 和 Q）上各自做 BPSK**。I 支路传一个比特，Q 支路传另一个比特，两支路正交 → 互不干扰。

因此每条支路的比特误码率与 BPSK 相同：$P_b = Q(\sqrt{2\gamma_b})$。

符号错误概率 = 至少一个支路出错：

$$P_s = 1 - [1 - Q(\sqrt{2\gamma_b})]^2 \tag{6.7}$$

QPSK 的符号能量均分在 I/Q 两支路，所以 $\gamma_s = 2\gamma_b$。代入得：

$$P_s = 1 - [1 - Q(\sqrt{\gamma_s})]^2 \tag{6.8}$$

用 Gray 编码时，$P_b \approx P_s/2$（每符号 2 比特）。

### 各种界与近似

**Union Bound**（(5.40) 用于 QPSK）：

$$P_s \leq 2Q\left(\frac{A}{\sqrt{N_0}}\right) + Q\left(\frac{\sqrt{2}A}{\sqrt{N_0}}\right) = 2Q\left(\sqrt{\gamma_s/2}\right) + Q\left(\sqrt{\gamma_s}\right) \tag{6.9-6.10}$$

最右项 $Q(\sqrt{\gamma_s})$ 远小于前面两项 → 简化为 $P_s \leq 2Q(\sqrt{\gamma_s})$。

**最近邻近似**（Nearest Neighbor Approximation）：只考虑距离最近星座点之间的错误，$d_{\min} = \sqrt{2A^2}$：

$$P_s \approx 2Q\left(\sqrt{\gamma_s/2}\right) \tag{6.12}$$

**闭合形式界**（Chernoff 界）：

$$P_s \leq \frac{3}{\pi} \exp[-\gamma_s/4] \tag{6.11}$$

### 例题 6.1：数值比较（$\gamma_b = 7$ dB）

| 量 | 公式 | 数值 |
|---|---|---|
| $P_b$（精确） | $Q(\sqrt{10.024})$ | $7.73 \times 10^{-4}$ |
| $P_s$（精确） | $1 - [1 - Q(\sqrt{10.024})]^2$ | $1.55 \times 10^{-3}$ |
| $P_b$（Gray 近似） | $P_s/2$ | $7.72 \times 10^{-4}$ |
| $P_s$（最近邻近似） | $2Q(\sqrt{5.012})$ | $2.52 \times 10^{-2}$ |

**关键观察**：
- Gray 编码近似 $P_b \approx P_s/2$ 在 $\gamma_b = 7$ dB 时与精确值几乎完全一致
- 最近邻近似给出的 $P_s$ 比精确值**大一个数量级以上**——Union Bound 类近似在 BPSK/QPSK 情况下过于宽松
- 原因：最近邻近似假设 $d_{\min}$ 对应的错误独立且占主导，但 QPSK 的每个符号有两个最近邻，Union Bound 把这些错误概率简单相加，实际上这些事件有重叠——接收点不可能同时落入两个相邻判决区域

## 6.1.3 MPSK 的误码率

### 星座结构与判决域

MPSK（M-ary Phase Shift Keying）的星座点均匀分布在半径为 $A$ 的圆上：

$$s_{i1} = A\cos\left[\frac{2\pi(i-1)}{M}\right],\quad s_{i2} = A\sin\left[\frac{2\pi(i-1)}{M}\right],\quad i=1,\dots,M$$

符号能量 $E_s = A^2$，因此 $\gamma_s = A^2/N_0$。

判决域是角度扇区：每个星座点对应的正确接收角度区间为宽度 $2\pi/M$ 的扇形。

### 精确误符号率：无闭式解

接收矢量 $\mathbf{x} = re^{j\theta}$ 的联合 PDF 为：

$$p(r,\theta) = \frac{r}{\pi N_0} \exp\left[-\frac{1}{N_0}\left(r^2 - 2\sqrt{E_s}r\cos\theta + 2E_s^2\right)\right] \tag{6.13}$$

积分掉 $r$ 仅保留相位分布 $p(\theta)$：

$$p(\theta) = \int_0^\infty p(r,\theta)dr \tag{6.14}$$

由对称性，假设 $\mathbf{s}_1 = (A, 0)$ 发射，误符号率为：

$$P_s = 1 - \int_{-\pi/M}^{\pi/M} p(\theta)d\theta \tag{6.15}$$

> ⚡ 这个积分对 $M > 4$ **不存在闭式解**，精确 $P_s$ 必须数值计算。这是 MPSK 性能分析的核心困难——我们被迫依赖近似。

### 最近邻近似

每个 MPSK 星座点有两个最近邻，距离 $d_{\min} = \sqrt{2A^2} = \sqrt{2E_s}$：

$$P_s \approx 2Q\left(\frac{A}{\sqrt{N_0}}\right) = 2Q(\sqrt{\gamma_s}) \tag{6.16}$$

**问题**：如例题 6.1 所示，这个近似对 QPSK 差一个数量级。对更大 $M$，星座点更密 → 错误事件重叠更严重 → Union Bound 更松。

### 紧致近似：利用 $p(\theta)$ 的近似

对 $p(\theta)$ 使用更精确的近似 $p(\theta) \approx \sqrt{\gamma_s}\pi\cos(\theta)e^{-\gamma_s\sin^2(\theta)}$，得到：

$$P_s \approx 2Q\left(\sqrt{2\gamma_s}\sin(\pi/M)\right) \tag{6.18}$$

**物理含义**：$\sqrt{2\gamma_s}$ 是 $d_{\min}/\sqrt{N_0}$（未归一化），$\sin(\pi/M)$ 反映角度判决边界的几何效应——当 $M$ 增大，$\sin(\pi/M)$ 减小 → $Q$ 函数参数变小 → $P_s$ 增大。

> 这个近似在实践中广泛使用：它将复杂的角度 PDF 问题化简为一个只含 $\sin(\pi/M)$ 因子的 $Q$ 函数。

### 例题 6.2：8PSK vs 16PSK（$\gamma_b = 15$ dB）

| 调制方式 | $\gamma_s$ | $P_s$（近似 6.18） | $P_b$（$P_s/\log_2 M$） |
|---|---|---|---|
| 8PSK | $3 \times 31.62 = 94.87$ | $1.36 \times 10^{-7}$ | $4.52 \times 10^{-8}$ |
| 16PSK | $4 \times 31.62 = 126.49$ | $1.92 \times 10^{-3}$ | $4.79 \times 10^{-4}$ |

**关键结论**：相同 $\gamma_b$（每比特能量相同）下，16PSK 的 $P_b$ 比 8PSK **大四个数量级**。

> ⚡ **为什么？** 每比特能量固定的前提下：
> - 8PSK：$\gamma_s = 3\gamma_b$，$E_s = 3E_b$，3 比特共享 1 个符号能量
> - 16PSK：$\gamma_s = 4\gamma_b$，$E_s = 4E_b$，4 比特共享 1 个符号能量
> - 但 16PSK 星座点有 16 个而不是 8 个 → 给定半径下点更密 → $d_{\min}$ 更小
> - $d_{\min}$ 缩小的效应超过了 $E_s$ 增大的效应 → 净结果是性能大幅恶化
>
> 这是数字通信的基本 trade-off：**每符号更多比特 = 更高频谱效率，但代价是功率效率降低**（相同 BER 需要更高 SNR）。

### 载波相位误差的影响

以上分析假设载波相位被完美恢复。相位估计误差的后果：

- **非零相位偏移** → 判决边界旋转 → **不可约误码率**（irreducible error floor）
- **多进制信令比 BPSK 更敏感**：相位误差导致 I/Q 支路交叉耦合，多进制星座点间距更小 → 更易越界
- **快衰落场景尤为严重**：信道相位因多径干涉快速变化 → 即使差分调制，符号间相位漂移也可能产生不可约错误
- 定时误差同样恶化性能——MPSK 的定时误差分析见 [2, Ch.4.3.3]

## 6.1.4 MPAM 与 MQAM 的误码率

### MPAM：M 进制脉冲幅度调制

MPAM 星座点在一维等间距排列：$A_i = (2i - 1 - M)d,\ i=1,2,\ldots,M$。

**内部点与外部点的错误概率不同**：
- $M-2$ 个内部点：有两个最近邻，距离均为 $2d$。错误 = 噪声在任一方向超过 $d$：$P_s(\mathbf{s}_i) = 2Q(d/\sqrt{N_0})$
- 2 个外部点：仅一个最近邻。错误 = 噪声仅在一个方向超过 $d$：$P_s(\mathbf{s}_i) = Q(d/\sqrt{N_0})$

平均值：

$$P_s = \frac{M-2}{M} \cdot 2Q\!\left(\sqrt{\frac{2d^2}{N_0}}\right) + \frac{2}{M} \cdot Q\!\left(\sqrt{\frac{2d^2}{N_0}}\right) = \frac{2(M-1)}{M}Q\!\left(\sqrt{\frac{2d^2}{N_0}}\right) \tag{6.19}$$

MPAM 的平均符号能量（来自 (5.54)）：

$$\overline{E}_s = \frac{1}{M}\sum_{i=1}^M A_i^2 = \frac{1}{3}(M^2-1)d^2 \tag{6.20}$$

> 推导关键：$\sum_{i=1}^M (2i-1-M)^2 = M(M^2-1)/3$。

代入得用 $\overline{\gamma}_s = \overline{E}_s/N_0$ 表示的 $P_s$：

$$P_s = \frac{2(M-1)}{M}Q\!\left(\sqrt{\frac{6\overline{\gamma}_s}{M^2-1}}\right) \tag{6.21}$$

### MQAM：正方形星座

正方形 MQAM（$M = L^2$）可视为两个正交的 $\sqrt{M}$-PAM 系统，分别调制 I/Q 支路，每条支路分配总能量的一半。

每条 I/Q 支路的误符号率用 (6.21) 代入 $L = \sqrt{M}$ 和 $\overline{\gamma}_s/2$（半能量），注意 (6.21) 中的因子 6 来自 (6.20) 的 $1/3$ 倍 $2d^2$；半能量使有效因子变为 3：

$$P_{s,\text{branch}} = \frac{2(\sqrt{M}-1)}{\sqrt{M}}Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right) \tag{6.22}$$

总误符号率 = 至少一条支路出错：

$$P_s = 1 - \left(1 - \frac{2(\sqrt{M}-1)}{\sqrt{M}}Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right)\right)^2 \tag{6.23}$$

> 这与 QPSK 的 (6.8) 结构完全相同——都是两正交支路至少一个出错的概率。区别仅在于每条支路是 BPSK 还是 $\sqrt{M}$-PAM。

**最近邻近似**（对内外点平均）：

$$P_s \approx \frac{2(\sqrt{M}-1)}{\sqrt{M}}Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right) \tag{6.24}$$

**非矩形星座**：上界为

$$P_s \leq 1 - \left[1 - 2Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right)\right]^2 \leq 4Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right) \tag{6.25}$$

最近邻近似为 $P_s \approx M_{d_{\min}} Q(d_{\min}/\sqrt{2N_0})$，其中 $M_{d_{\min}}$ 为星座中最多最近邻数。

### 例题 6.3：16QAM vs 16PSK（$\gamma_b = 15$ dB）

$\gamma_s = 4 \times 31.62 = 126.49$。

| 量 | 公式 | 数值 |
|---|---|---|
| 16QAM $P_s$（精确） | (6.23) | $7.37 \times 10^{-7}$ |
| 16QAM $P_s$（最近邻近似） | (6.24) | $3.68 \times 10^{-7}$ |
| 16PSK $P_s$（近似 6.18） | $2Q(\sqrt{2\gamma_s}\sin(\pi/16))$ | $1.92 \times 10^{-3}$ |

**三个关键观察**：

1. **16QAM 最近邻近似与精确值相差约 2 倍**——远好于 QPSK 的最近邻近似（差一个数量级）。因为 MQAM 内部点数多，最近邻近似对全体取平均后更准确。

2. **16QAM 的 $P_s$ 比 16PSK 小约 2600 倍**。原因：
   - MPSK 仅用相位编码信息——16 个点挤在一个圆上
   - MQAM 用**幅度和相位**联合编码——星座点在二维平面展开，$d_{\min}$ 更大
   - ⚡ 对于相同 $M$ 和 $\gamma_b$，MQAM 的功率效率始终优于 MPSK

3. 这解释了为什么实际系统中高阶调制几乎都是 QAM 而非 PSK——除了需要恒包络的场景（如非线性功率放大器）。

### 幅度估计与 AGC

MQAM 解调需要**幅度和相位**两者的信道估计：
- **相位估计**：同 MPSK 的讨论——误差导致 I/Q 交叉耦合
- **幅度估计（AGC）**：信道增益用于缩放判决门限以匹配发射符号电平。**增益估计错误 → 判决门限缩放错误 → 即使无噪声也可能解调出错**

幅度估计通常通过导频符号获得，但导频估计不完美 → 残余估计误差 → BER floor。详见 [15, Ch.10.3]。

## 6.1.5 FSK 与 CPFSK 的误码率

### 相干二进制 FSK

发射信号：$s_i(t) = A\sqrt{2}/T_b \cos(2\pi f_i t),\ i=1,2$，$E_b = A^2$，$\gamma_b = A^2/N_0$。

判决变量 $\mathbf{z} = \mathbf{x}_1 - \mathbf{x}_2$：$\mathbf{z} > 0$ 判为 1，$\mathbf{z} \leq 0$ 判为 0。

假设 $s_1(t)$ 发射：$\mathbf{z}|1 = A + n_1 - n_2$。$n_1, n_2$ 独立、零均值、方差 $N_0/2$ → $n_1 - n_2 \sim \mathcal{N}(0, N_0)$。

$$P_b = \frac{1}{2}p(A + n_1 - n_2 \leq 0) + \frac{1}{2}p(n_1 - A - n_2 > 0) = Q\!\left(\frac{A}{\sqrt{N_0}}\right) = Q(\sqrt{\gamma_b}) \tag{6.31}$$

> ⚡ **与 BPSK 对比**：$P_{b,\text{BFSK}} = Q(\sqrt{\gamma_b})$ vs $P_{b,\text{BPSK}} = Q(\sqrt{2\gamma_b})$。达到相同 BER，BFSK 需要 **3 dB 更高的 SNR**。
>
> 物理原因：BPSK 的两个信号是**反相**的（$\mathbf{s}_1 = -\mathbf{s}_0$），$d_{\min} = 2\sqrt{E_b}$；BFSK 的两个信号是**正交**的（在两个不同的频率上），$d_{\min} = \sqrt{2E_b}$。反相比正交提供更大的距离——这是"相干检测可以从相位中提取额外信息"的体现。

### M-FSK（$M > 2$）

相干 M-FSK 的精确 $P_s$ 无闭式解。非相干 M-FSK 的 $P_s$ 为：

$$P_s = \sum_{m=1}^{M-1} (-1)^{m+1} \binom{M-1}{m} \frac{1}{m+1} \exp\left[\frac{-m\gamma_s}{m+1}\right] \tag{6.32}$$

> 注意：这个公式是非相干检测的。在无线通信中非相干 FSK 更常见——它避免了载波相位恢复的复杂性。

### CPFSK

CPFSK（连续相位 FSK）的误码率取决于是否相干、是否采用逐符号检测或序列估计。由于调制中的记忆性（相位连续性），误码率分析必须跨多个符号进行，公式复杂。详见 [1, Ch.5.3]。

与线性调制一样，FSK 在频率和定时误差下性能退化。频率偏移在 FSK 中尤其致命——它直接破坏不同频率支路之间的正交性。

## 6.1.6 相干调制的误码率统一近似

前面各节推导的相干调制 $P_s$ 大多可以写成如下统一形式：

$$P_s(\gamma_s) \approx \alpha_M Q\!\left(\sqrt{\beta_M \gamma_s}\right) \tag{6.33}$$

- $\alpha_M$：取决于调制阶数和近似类型。最近邻近似中，$\alpha_M$ = 最近邻数量
- $\beta_M$：将 $d_{\min}$ 与平均符号能量关联的常数

转换为比特误码率（Gray 编码 + 高 SNR 假设）：

$$P_b(\gamma_b) = \hat{\alpha}_M Q\!\left(\sqrt{\hat{\beta}_M \gamma_b}\right) \tag{6.34}$$

其中 $\hat{\alpha}_M = \alpha_M / \log_2 M$，$\hat{\beta}_M = (\log_2 M)\beta_M$。

**Table 6.1 汇总了常用调制的 $\alpha_M$ 和 $\beta_M$**（以最近邻近似为主）。这个统一形式的意义：

1. **简化系统设计**：给定目标 $P_b$，可直接解出所需 $\gamma_b$ → 链路预算
2. **统一比较框架**：不同调制方式的性能差异完全体现在 $(\alpha_M, \beta_M)$ 两个参数中
3. **后续章节（衰落信道）的基础**：衰落下的平均 BER 通过对 (6.33) 在衰落分布上求期望得到

> 典型数值示例：BPSK → $\alpha_2 = 1, \beta_2 = 2$；QPSK → $\alpha_4 = 2, \beta_4 = 1$（最近邻近似）；BFSK → $\alpha_2 = 1, \beta_2 = 1$。

## 6.1.7 差分调制的误码率

### 差分检测的基本原理

差分调制通过**相邻符号的相位差**承载信息，解调时比较前后两个接收符号的相位。相位比较器的输入为 $\mathbf{z}(k)\mathbf{z}^*(k-1)$：

$$\mathbf{z}(k)\mathbf{z}^*(k-1) = A^2 e^{j(\theta(k)-\theta(k-1))} + A e^{j(\theta(k)+\phi_0)} n^*(k-1) + A e^{-j(\theta(k-1)+\phi_0)} n(k) + n(k)n^*(k-1) \tag{6.35}$$

三项成分：
1. **$A^2$ 项**：承载相位差信息的信号项
2. **$A \times$ 噪声项**（两个）：信号与噪声的交叉项
3. **噪声 $\times$ 噪声项**：两个噪声样本的乘积

在合理 SNR 下，第三项远小于第二项，可忽略。除以 $A$ 后：

$$\tilde{z} = A + \Re\{\tilde{n}^*(k-1) + \tilde{n}(k)\} + j\Im\{\tilde{n}^*(k-1) + \tilde{n}(k)\} \tag{6.38}$$

其中 $\tilde{n}(k), \tilde{n}(k-1)$ 与 $n(k), n(k-1)$ 统计特性相同（相位旋转不改变高斯噪声的分布）。

> ⚡ **核心差异**：差分检测有两个噪声项而非一个 → 等效噪声功率是相干检测的**两倍** → 性能约差 **3 dB**。

### DPSK（差分 BPSK）

DPSK 只需取 $\tilde{z}$ 的实部做判决：传输 0 → 若 $x = A + \Re\{\tilde{n}^*(k-1) + \tilde{n}(k)\} < 0$ 则判错。

通过特征函数法求得精确 $P_b$：

$$P_b = \frac{1}{2}e^{-\gamma_b} \tag{6.40}$$

> 与相干 BPSK 的 $P_b = Q(\sqrt{2\gamma_b})$ 对比：DPSK 用指数函数替代 $Q$ 函数——在高 SNR 下衰减更慢（指数 vs 指数的平方）。数值上，要达到 $P_b = 10^{-5}$，DPSK 比相干 BPSK 需要约 0.7 dB 额外 SNR。3 dB 是"等效噪声加倍"的粗糙估计，实际差距随 SNR 变化。

### DQPSK（差分 QPSK）

DQPSK 需同时考虑 $\tilde{z}$ 的实部和虚部（I/Q 两路）。精确 $P_b$ 为 Marcum Q 函数形式：

$$P_b \approx \int_b^\infty x \exp\!\left(\frac{-(a^2+x^2)}{2}\right) I_0(ax)\,dx - \frac{1}{2}\exp\!\left(\frac{-(a^2+b^2)}{2}\right) I_0(ab) \tag{6.41}$$

其中 $a \approx 0.765\sqrt{\gamma_b},\ b \approx 1.85\sqrt{\gamma_b}$，$I_0$ 为零阶修正 Bessel 函数。

> 公式复杂度反映了差分检测的一般特征：涉及两个相关高斯随机变量的非线性函数，不能简化为单个 $Q$ 函数。

### Table 6.1：相干调制误码率速查表

| 调制方式 | $P_s(\gamma_s)$ | $P_b(\gamma_b)$ |
|---|---|---|
| BFSK | — | $P_b = Q(\sqrt{\gamma_b})$ |
| BPSK | — | $P_b = Q(\sqrt{2\gamma_b})$ |
| QPSK, 4QAM | $P_s \approx 2Q(\sqrt{\gamma_s})$ | $P_b \approx Q(\sqrt{2\gamma_b})$ |
| MPAM | $P_s \approx \frac{2(M-1)}{M}Q\!\left(\sqrt{\frac{6\overline{\gamma}_s}{M^2-1}}\right)$ | $P_b \approx \frac{2(M-1)}{M\log_2 M}Q\!\left(\sqrt{\frac{6\overline{\gamma}_b\log_2 M}{(M^2-1)}}\right)$ |
| MPSK | $P_s \approx 2Q\!\left(\sqrt{2\gamma_s}\sin(\pi/M)\right)$ | $P_b \approx \frac{2}{\log_2 M}Q\!\left(\sqrt{2\gamma_b\log_2 M}\sin(\pi/M)\right)$ |
| 矩形 MQAM | $P_s \approx \frac{2(\sqrt{M}-1)}{\sqrt{M}}Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right)$ | $P_b \approx \frac{2(\sqrt{M}-1)}{\sqrt{M}\log_2 M}Q\!\left(\sqrt{\frac{3\overline{\gamma}_b\log_2 M}{(M-1)}}\right)$ |
| 非矩形 MQAM | $P_s \approx 4Q\!\left(\sqrt{\frac{3\overline{\gamma}_s}{M-1}}\right)$ | $P_b \approx \frac{4}{\log_2 M}Q\!\left(\sqrt{\frac{3\overline{\gamma}_b\log_2 M}{(M-1)}}\right)$ |

# 6.2 Q 函数的替代表示（Craig 公式）

## 传统 Q 函数的局限

传统 $Q$ 函数定义为标准正态分布的尾概率：

$$Q(z) = p(x \geq z) = \int_z^\infty \frac{1}{\sqrt{2\pi}} e^{-x^2/2} dx \tag{6.42}$$

三个不便之处：
1. **积分限含参数 $z$**：$z$ 在积分下限 → 对 $z$ 求导/积分时操作繁琐
2. **积分范围无限**：$\int_z^\infty$
3. **被积函数不是纯高斯型**：指数中无 $z$

> 这些不便在 AWGN 分析中尚可容忍，但在衰落信道中——需要对 $P_s(\gamma_s)$ 在 $\gamma_s$ 的随机分布上求期望 $\overline{P}_s = \int_0^\infty P_s(\gamma) p_{\gamma_s}(\gamma) d\gamma$——传统 $Q$ 函数会导致双重积分且无法交换次序。

## Craig 的替代表示（1991）

$$Q(z) = \frac{1}{\pi} \int_0^{\pi/2} \exp\!\left[ \frac{-z^2}{2\sin^2\phi} \right] d\phi \quad (z \geq 0) \tag{6.43}$$

**三个关键改进**：

| 性质 | 传统 $Q(z)$ | Craig 替代形式 |
|---|---|---|
| 积分限 | 含 $z$（下限 $z \to \infty$） | 固定 $[0, \pi/2]$，与 $z$ 无关 |
| 被积函数对 $z$ 的依赖 | 积分下限 | 被积函数内的高斯型 $\exp[-z^2/(2\sin^2\phi)]$ |
| 积分范围 | 无限 | 有限 |

> ⚡ **核心价值**：积分限与 $z$ 无关 + 被积函数是 $z$ 的高斯型 → 在衰落信道上求平均误码率时，可以先对 $z$ 做统计平均（交换积分次序），将双重积分化简为单重积分。这是 6.3 节 MGF 方法的数学基础。

## 在 AWGN 误码率中的应用

**BPSK** — 将 $\sqrt{2\gamma_b}$ 代入：

$$P_b = Q(\sqrt{2\gamma_b}) = \frac{1}{\pi} \int_0^{\pi/2} \exp\!\left[ \frac{-\gamma_b}{\sin^2\phi} \right] d\phi \tag{6.44}$$

**MPSK 的精确 $P_s$**（非近似！）：

$$P_s = \frac{1}{\pi} \int_0^{(M-1)\pi/M} \exp\!\left[ \frac{-g_{psk}\gamma_s}{\sin^2\phi} \right] d\phi \tag{6.45}$$

其中 $g_{psk} = \sin^2(\pi/M)$。

注意 (6.45) 是**精确**表达式，不是 6.1.6 节的 $\alpha_M Q(\sqrt{\beta_M\gamma_s})$ 近似。积分上限 $(M-1)\pi/M$ 是 MPSK 判决域的角度边界——当 $M=2$ 时退回 BPSK 的 $\pi/2$。

> 这个公式的数值计算很简单：有限区间上的光滑被积函数，任何数值积分包都可以快速求解。

## 在后续章节中的角色

Craig 的替代表示是 **MGF（矩生成函数）方法**（6.3.3 节）的前提：$\overline{P}_s = \int P_s(\gamma) p_{\gamma_s}(\gamma) d\gamma$ → 交换积分次序 → $\overline{P}_s = \frac{1}{\pi} \int_0^{\pi/2} \mathcal{M}_{\gamma_s}\!\left(\frac{-1}{\sin^2\phi}\right) d\phi$，其中 $\mathcal{M}_{\gamma_s}(s) = \mathbb{E}[e^{s\gamma_s}]$ 是 $\gamma_s$ 的 MGF。

# 6.3 衰落信道

AWGN 中 SNR $\gamma_s$ 是确定量；衰落信道中接收信号功率因阴影/多径随距离或时间随机变化 → $\gamma_s$ 成为随机变量 → $P_s(\gamma_s)$ 也是随机变量。

## 三种性能度量与衰落速率

性能度量的选择取决于衰落速率——即相干时间 $T_c$（信道近似不变的时间尺度）与符号时间 $T_s$ 的关系：

| 条件 | 性能度量 | 原因 |
|---|---|---|
| $T_s \approx T_c$ | **平均误码率** $\overline{P}_s$ | 衰落逐符号独立变化，错误分散 → 编码可恢复个别错误 |
| $T_s \ll T_c$ | **中断概率** $P_{out}$ | 深衰落持续多个符号 → 突发错误 → 合理复杂度的编码无法纠正 → 信道在某时间/空间分数内不可用 |
| $T_c \ll T_s$ | AWGN 性能（无需额外处理） | 匹配滤波器将衰落平均掉——极快衰落等价于无衰落 |

> ⚡ 这是无线通信设计的核心判断之一：**衰落速率决定了应该用什么指标衡量链路质量**。慢衰落（$T_c$ 大）用中断概率，快衰落（$T_c$ 小）用平均误码率。实际系统常兼顾两者——对数正态阴影（慢）叠加瑞利快衰落。

---

## 6.3.1 中断概率

中断概率定义为 SNR 低于给定门限 $\gamma_0$ 的概率：

$$P_{out} = p(\gamma_s < \gamma_0) = \int_0^{\gamma_0} p_{\gamma_s}(\gamma) d\gamma \tag{6.46}$$

$\gamma_0$ 为满足最低可接受性能所需的最小 SNR。例如：数字语音 $P_b = 10^{-3}$ 人耳不可察觉 → BPSK 在 Rayleigh 衰落中 $\gamma_b < 7$ dB 即判定中断。

### Rayleigh 衰落下的中断概率

Rayleigh 衰落的 SNR 分布为指数分布：$p_{\gamma_s}(\gamma) = \frac{1}{\overline{\gamma}_s} e^{-\gamma/\overline{\gamma}_s}$

$$P_{out} = \int_0^{\gamma_0} \frac{1}{\overline{\gamma}_s} e^{-\gamma_s/\overline{\gamma}_s} d\gamma_s = 1 - e^{-\gamma_0/\overline{\gamma}_s} \tag{6.47}$$

反解：给定目标中断概率 $P_{out}$，所需平均 SNR 为

$$\overline{\gamma}_s = \frac{\gamma_0}{-\ln(1 - P_{out})} \tag{6.48}$$

### 衰落余量（Fade Margin）

以 dB 表示：$\overline{\gamma}_s$ 必须比 $\gamma_0$ 高出

$$F_d = -10\log[-\ln(1 - P_{out})] \quad \text{dB}$$

$F_d$ 称为 **dB 衰落余量**（fade margin）——为在 $100 \times (1 - P_{out})\%$ 时间内维持可接受性能所需的额外 SNR 裕量。

> 物理含义：衰落余量补偿了信道深衰落的随机性。不增加衰落余量 → 只要信道衰减超过平均功率一定量，通信就会中断。

### 例题 6.4：慢 Rayleigh 衰落下 BPSK 的中断概率

**问题**：BPSK 目标 $P_b < 10^{-4}$，要求 95% 时间/空间可用。求所需 $\overline{\gamma}_b$。

- BPSK 在 AWGN 中达到 $P_b = 10^{-4}$ 需 $\gamma_0 = 8.5$ dB
- $P_{out} = 0.05$
- $\overline{\gamma}_b = \frac{10^{0.85}}{-\ln(0.95)} = 138.2 = 21.4$ dB

**关键对比**：AWGN 只需 8.5 dB，Rayleigh 慢衰落需要 **21.4 dB**——多了约 **13 dB 的衰落余量**。这 13 dB 不是噪声补偿，而是为保证 95% 时间内信号不被深衰落"吞没"所需的功率裕量。

> ⚡ 13 dB 的额外功率是巨大的——从 8.5 dB（~7.1×）到 21.4 dB（~138×），发射功率需求增加近 20 倍。这就是为什么衰落信道中几乎不会只用"加大功率"来解决问题——必须借助分集、编码、自适应调制等技术。

## 6.3.2 平均误码率

### 定义与计算方法

当 $T_s \approx T_c$（逐符号独立衰落），平均误码率为 AWGN 误码率在衰落分布上的期望：

$$\overline{P}_s = \int_0^\infty P_s(\gamma) \, p_{\gamma_s}(\gamma) \, d\gamma \tag{6.50}$$

其中 $P_s(\gamma)$ 是 AWGN 下的误码率（可用 Table 6.1 中的近似），$p_{\gamma_s}(\gamma)$ 由衰落幅度分布通过变量代换得到：

$$p_{\gamma_s}(\gamma) d\gamma = p(r) dr \tag{6.51}$$

### Rayleigh 衰落下 SNR 的分布

Rayleigh 幅度分布：$p(r) = \frac{r}{\sigma^2} e^{-r^2/(2\sigma^2)}$，$r \geq 0$。

SNR 与幅度的关系：$\gamma = \frac{r^2 T_s}{2\sigma_n^2}$，其中 $\sigma_n^2 = N_0/2$。通过变量代换：

$$p_{\gamma_s}(\gamma) = \frac{1}{\overline{\gamma}_s} e^{-\gamma/\overline{\gamma}_s} \tag{6.56}$$

> Rayleigh 幅度 → SNR 呈**指数分布**，均值 $\overline{\gamma}_s = \sigma^2/(T_s\sigma_n^2)$。这是理解 Rayleigh 衰落性能的出发点。

### Rayleigh 衰落下的二进制调制性能

将各调制的 AWGN 误码率代入 (6.50) 对指数分布积分：

| 调制 | $\overline{P}_b$（精确） | 高 SNR 近似 |
|---|---|---|
| **BPSK** | $\frac{1}{2}\!\left[1 - \sqrt{\frac{\overline{\gamma}_b}{1+\overline{\gamma}_b}}\right]$ | $\approx \frac{1}{4\overline{\gamma}_b}$ |
| **二进制 FSK** | $\frac{1}{2}\!\left[1 - \sqrt{\frac{\overline{\gamma}_b}{2+\overline{\gamma}_b}}\right]$ | $\approx \frac{1}{4\overline{\gamma}_b}$ |
| **DPSK** | $\frac{1}{2(1+\overline{\gamma}_b)}$ | $\approx \frac{1}{2\overline{\gamma}_b}$ |

**三个重要观察**：

1. **衰落让 BPSK 和 BFSK 趋于一致**：AWGN 中 BPSK 比 BFSK 好 3 dB，但在 Rayleigh 衰落高 SNR 下两者都有 $\overline{P}_b \approx 1/(4\overline{\gamma}_b)$——衰落抹平了相干检测的优势。因为 Rayleigh 衰落更致命的不是噪声，而是信号本身被深衰落"熄灭"——反相还是正交已不重要。

2. **DPSK 约差 3 dB**：$\overline{P}_b \approx 1/(2\overline{\gamma}_b)$ vs BPSK 的 $1/(4\overline{\gamma}_b)$。实际差距略小——DPSK 能跟踪慢相位漂移，这一点在理论计算中未计入。

3. **衰落改变了 BER 曲线的斜率**：AWGN 下 $P_b$ 随 $\gamma_b$ **指数衰减**（$Q(\sqrt{2\gamma_b}) \sim e^{-\gamma_b}$）；Rayleigh 衰落下降为**仅线性衰减**（$\sim 1/\overline{\gamma}_b$）。这是最本质的差异。

### 一般情形的近似

使用 $P_s \approx \alpha_M Q(\sqrt{\beta_M \gamma_s})$ 对指数分布积分：

$$\overline{P}_s \approx \frac{\alpha_M}{2}\!\left[1 - \sqrt{\frac{0.5\beta_M\overline{\gamma}_s}{1+0.5\beta_M\overline{\gamma}_s}}\right] \approx \frac{\alpha_M}{2\beta_M\overline{\gamma}_s} \tag{6.61}$$

（第二个近似在高 SNR 下成立。）

|---|---|---|---|
| $10^{-3}$ | ~8 dB | ~24 dB | ~16 dB |
| $10^{-5}$ | ~9.6 dB | ~44 dB | ~34 dB |

**差距随目标 $P_b$ 降低而急剧扩大**——这是指数衰减 vs 线性衰减的必然结果。在 AWGN 中，SNR 每增加 1 dB，$P_b$ 下降近一个数量级；在 Rayleigh 衰落中，SNR 每增加 1 dB，$P_b$ 只下降到原来的 ~0.8 倍。

### Nakagami 衰落下 BPSK 的性能

Rayleigh 衰落是最恶劣的情形之一。Nakagami-m 衰落中，$m$ 越大 → 衰落越浅 → 性能越接近 AWGN；$m=1$ 退化为 Rayleigh；$m \to \infty$ 收敛于 AWGN。

## 6.3.3 矩生成函数（MGF）方法

### MGF 的定义与直观

非负随机变量 $\gamma$（SNR）的矩生成函数（Moment Generating Function, MGF）：

$$\mathcal{M}_\gamma(s) = \int_0^\infty p_\gamma(\gamma) e^{s\gamma} d\gamma \tag{6.62}$$

MGF 就是 PDF 的 Laplace 变换（符号反转）：$\mathcal{L}[p_\gamma(\gamma)] = \mathcal{M}_\gamma(-s)$。因此大多数感兴趣衰落分布的 MGF 都有闭式解。

> MGF 之所以叫"矩生成函数"，因为 $\mathbb{E}[\gamma^n] = \frac{\partial^n}{\partial s^n} \mathcal{M}_{\gamma_s}(s)\big|_{s=0}$。

### 常见衰落分布的 MGF

| 衰落类型 | $\mathcal{M}_{\gamma_s}(s)$ |
|---|---|
| **Rayleigh** | $(1 - s\overline{\gamma}_s)^{-1}$ |
| **Ricean**（因子 $K$） | $\frac{1+K}{1+K-s\overline{\gamma}_s} \exp\!\left[\frac{K s \overline{\gamma}_s}{1+K-s\overline{\gamma}_s}\right]$ |
| **Nakagami-m** | $(1 - s\overline{\gamma}_s/m)^{-m}$ |

### MGF 方法的核心思想

如果 AWGN 下的误码率可以写成以下两种形式之一，平均误码率就能直接用 MGF 表达。

**形式 1 — 纯指数**：$P_s = c_1 \exp[-c_2 \gamma_s]$

$$\overline{P}_s = \int_0^\infty c_1 e^{-c_2\gamma} p_{\gamma_s}(\gamma) d\gamma = c_1 \mathcal{M}_{\gamma_s}(-c_2) \tag{6.69}$$

**形式 2 — 指数的有限积分**：$P_s = \int_A^B c_1 \exp[-c_2(x)\gamma] dx$

$$\overline{P}_s = c_1 \int_A^B \mathcal{M}_{\gamma_s}(-c_2(x)) dx \tag{6.71}$$

> ⚡ 关键技巧：交换积分次序。$\gamma$ 仅出现在指数中，积分限 $[A, B]$ 与 $\gamma$ 无关 → 可以先对 $\gamma$ 积分（得到 MGF），再对 $x$ 积分。这就是 Craig 替代表示的作用——把 $Q$ 函数变成有限积分限内的指数形式。

### 应用：DPSK

DPSK 的 $P_b = \frac{1}{2}e^{-\gamma_b}$ 恰好是纯指数形式（$c_1=1/2, c_2=1$）：

$$\overline{P}_b = \frac{1}{2} \mathcal{M}_{\gamma_s}(-1) \tag{6.70}$$

对 Rayleigh 衰落代入 $\mathcal{M}_{\gamma_s}(-1) = (1+\overline{\gamma}_b)^{-1}$ → $\overline{P}_b = [2(1+\overline{\gamma}_b)]^{-1}$，与 (6.60) 一致。

### 应用：相干调制（$Q$ 函数的 Craig 形式）

将 $P_s = \alpha Q(\sqrt{2g\gamma_s})$（记法微调：$g = 0.5\beta_M$）用 Craig 形式改写：

$$P_s = \frac{\alpha}{\pi} \int_0^{\pi/2} \exp\!\left[ \frac{-g\gamma}{\sin^2\phi} \right] d\phi \tag{6.73}$$

交换积分次序：

$$\overline{P}_s = \frac{\alpha}{\pi} \int_0^{\pi/2} \mathcal{M}_{\gamma_s}\!\left(\frac{-g}{\sin^2\phi}\right) d\phi \tag{6.74}$$

代入各衰落的 MGF 得到被积函数：

| 衰落 | $\mathcal{M}_{\gamma_s}(-g/\sin^2\phi)$ |
|---|---|
| Rayleigh | $\left(1 + \frac{g\overline{\gamma}_s}{\sin^2\phi}\right)^{-1}$ |
| Ricean | $\frac{(1+K)\sin^2\phi}{(1+K)\sin^2\phi + g\overline{\gamma}_s} \exp\!\left(-\frac{K g \overline{\gamma}_s}{(1+K)\sin^2\phi + g\overline{\gamma}_s}\right)$ |
| Nakagami-m | $\left(1 + \frac{g\overline{\gamma}_s}{m\sin^2\phi}\right)^{-m}$ |

所有这些被积函数都是简单的三角函数——在有限区间 $[0, \pi/2]$ 上数值积分非常容易。

### MPSK 的精确平均误码率

MPSK 的 Craig 公式 (6.45) 积分上限为 $(M-1)\pi/M$（而非 $\pi/2$），$g = \sin^2(\pi/M)$：

$$\overline{P}_s = \frac{1}{\pi} \int_0^{(M-1)\pi/M} \mathcal{M}_{\gamma_s}\!\left(-\frac{g}{\sin^2\phi}\right) d\phi \tag{6.75}$$

这是**精确**表达式，不是近似。

### MQAM：需要 $Q^2(z)$ 的替代表示

MQAM 的精确 $P_s$ 包含 $Q$ 和 $Q^2$。$Q^2(z)$ 的替代形式为：

$$Q^2(z) = \frac{1}{\pi} \int_0^{\pi/4} \exp\!\left[ \frac{-z^2}{2\sin^2\phi} \right] d\phi \tag{6.79}$$

> 与 $Q(z)$ 的区别仅在于积分上限：$\pi/4$ 而非 $\pi/2$。

MQAM 的平均误码率为两个有限积分的差：

$$\overline{P}_s = \frac{4}{\pi}\!\left(1-\frac{1}{\sqrt{M}}\right) \int_0^{\pi/2} \mathcal{M}_{\gamma_s}\!\left(-\frac{g}{\sin^2\phi}\right) d\phi - \frac{4}{\pi}\!\left(1-\frac{1}{\sqrt{M}}\right)^2 \int_0^{\pi/4} \mathcal{M}_{\gamma_s}\!\left(-\frac{g}{\sin^2\phi}\right) d\phi \tag{6.81}$$

其中 $g = 1.5/(M-1)$。

### 非相干 M-FSK

非相干 M-FSK 的 $P_s$ 是有限和 $\sum c_m \exp[-m\gamma/(m+1)]$，直接逐项替换：

$$\overline{P}_s = \sum_{m=1}^{M-1} (-1)^{m+1} \binom{M-1}{m} \frac{1}{m+1} \mathcal{M}_{\gamma_s}\!\left(-\frac{m}{m+1}\right) \tag{6.82}$$

### 差分 MPSK

$$\overline{P}_s = \frac{\sqrt{g_{psk}}}{2\pi} \int_{-\pi/2}^{\pi/2} \frac{\mathcal{M}_{\gamma_s}\!\left(-(1-\sqrt{1-g_{psk}}\cos\theta)\right)}{1-\sqrt{1-g_{psk}}\cos\theta} d\theta \tag{6.84}$$

### MGF 方法的价值总结

| 传统方法（直接积分） | MGF 方法 |
|---|---|
| $\int_0^\infty P_s(\gamma) p(\gamma) d\gamma$，双重积分 | $\frac{\alpha}{\pi} \int_0^{\pi/2} \mathcal{M}(-g/\sin^2\phi) d\phi$，单重积分 |
| 每次换调制/分布需重新推导 | 调制信息在积分参数中，衰落信息在 MGF 中——**解耦** |
| 常无闭式，数值困难 | 有限区间光滑被积函数，易数值求解 |

> ⚡ MGF 方法的核心贡献：**将调制和衰落分离**。$\alpha$, $g$, 积分上下限只取决于调制方式；$\mathcal{M}_{\gamma_s}(\cdot)$ 只取决于衰落分布。两者独立变化 → 新调制+新衰落组合只需"换参数"，极大简化了性能分析。这一框架在第 7 章（分集）中将发挥更大威力。

### 例题 6.5：BPSK 在 Nakagami-m 衰落

BPSK：$\alpha=1, g=1$。Nakagami-m 的 MGF 代入 (6.74)：

$$\overline{P}_b = \frac{1}{\pi} \int_0^{\pi/2} \left(1 + \frac{\overline{\gamma}_b}{m\sin^2\phi}\right)^{-m} d\phi$$

## 6.3.4 中断概率与平均误码率的联合分析

### 动机：快衰落 + 慢衰落的叠加

实际信道常同时存在多种衰落机制。例如：对数正态阴影（慢，大尺度）+ Rayleigh 多径（快，小尺度）。此时单一性能指标不够——需要联合中断概率和平均误码率。

### 三层 SNR 记法

| 符号 | 含义 |
|---|---|
| $\overline{\overline{\gamma}}_s$ | 路径损耗 + 阴影衰落的**平均**SNR（对阴影分布取平均后的值） |
| $\overline{\gamma}_s$ | 路径损耗 + 阴影衰落后的**随机**SNR（阴影是一个随机变量），均值 $\overline{\overline{\gamma}}_s$ |
| $\gamma_s$ | 路径损耗 + 阴影 + 多径的**总随机**SNR |

### 联合度量的逻辑

1. **中断判定**：当仅由阴影和路径损耗决定的 SNR $\overline{\gamma}_s$ 低于门限 $\overline{\gamma}_{s_0}$ 时，宣布中断
2. **非中断时的性能**：在 $\overline{\gamma}_s \geq \overline{\gamma}_{s_0}$ 的时段/位置，对快衰落（多径）取平均

$$\overline{P}_s(\overline{\gamma}_s) = \int_0^\infty P_s(\gamma_s) \, p(\gamma_s | \overline{\gamma}_s) \, d\gamma_s \tag{6.85}$$

3. **门限的确定**：$\overline{\gamma}_{s_0}$ 由最大可接受的平均误码率反解：

$$\overline{P}_{s_0} = \int_0^\infty P_s(\gamma_s) \, p(\gamma_s | \overline{\gamma}_{s_0}) \, d\gamma_s \tag{6.86}$$

当 $\overline{\gamma}_s > \overline{\gamma}_{s_0}$ 时，$\overline{P}_s < \overline{P}_{s_0}$。

### 例题 6.6：两重衰落的功率预算

**场景**：BPSK，对数正态阴影（$\sigma = 8$ dB）+ Rayleigh 快衰落。目标：$\overline{P}_{b_0} = 10^{-4}$，$1 - P_{out} = 0.95$。

**步骤**：
1. Rayleigh 衰落下达到 $\overline{P}_b = 10^{-4}$ 需要 $\overline{\gamma}_{b_0} = 34$ dB（见 6.3.2 节数据）
2. 对数正态阴影：$\overline{\gamma}_b \sim \log\mathcal{N}(\overline{\overline{\gamma}}_b, \sigma^2)$
3. $p(\overline{\gamma}_b > \overline{\gamma}_{b_0}) = Q\left(\frac{\overline{\gamma}_{b_0} - \overline{\overline{\gamma}}_b}{\sigma}\right) = 1 - P_{out} = 0.95$
4. $(\overline{\gamma}_{b_0} - \overline{\overline{\gamma}}_b)/\sigma = Q^{-1}(0.95) = -1.6$（查表）
5. $\overline{\overline{\gamma}}_b = 34 + 1.6 \times 8 = 46.8$ dB

**功率预算的逐层累加**：

| 层 | 所需 SNR 增量 | 累计 |
|---|---|---|
| AWGN 基准（$P_b = 10^{-4}$，BPSK） | — | 8.5 dB |
| + Rayleigh 快衰落（平均误码率） | +25.5 dB | 34 dB |
| + 对数正态阴影（95% 可用性） | +12.8 dB | 46.8 dB |

> ⚡ 从 AWGN 的 8.5 dB 到联合衰落下的 46.8 dB——差距近 **40 dB（10000 倍功率）**。这清楚地说明了衰落是无线通信中最根本的链路预算消耗源。分集、编码、自适应技术不是锦上添花，是生存必需。

# 6.4 多普勒扩展

## 问题本质

差分调制用**前一个符号的相位**作为当前符号的相位参考。如果信道相位在符号间去相关（decorrelate）→ 相位参考充满噪声 → 错误率不受接收功率控制 → 出现**不可约误差地板**（irreducible error floor）。

> 用一句话概括：差分检测的致命弱点是**用过去估计现在**——当信道变化快到"过去"不再能代表"现在"时，差分检测失效。

相位相关性由多普勒频率 $f_D = v/\lambda$ 和符号时间 $T_s$ 共同决定。$f_D T_s$（或 $f_D T_b$）是归一化多普勒——它衡量"一个符号时间内信道相位变化了多少"。

## DPSK 在快 Rician 衰落中的误码率

利用 MGF 技术（基于复高斯随机变量的一般二次型）得到闭式解：

$$\overline{P}_b = \frac{1}{2} \left[ \frac{1 + K + \overline{\gamma}_b (1 - \rho_C)}{1 + K + \overline{\gamma}_b} \right] \exp\!\left(- \frac{K \overline{\gamma}_b}{1 + K + \overline{\gamma}_b}\right) \tag{6.88}$$

其中 $\rho_C$ 是相隔一个比特时间 $T_b$ 的信道相关系数，$K$ 为 Rician 因子。

**Rayleigh 衰落**（$K = 0$）简化为：

$$\overline{P}_b = \frac{1}{2} \left[ \frac{1 + \overline{\gamma}_b (1 - \rho_C)}{1 + \overline{\gamma}_b} \right] \tag{6.89}$$

## 不可约误差地板

令 $\overline{\gamma}_b \to \infty$（无限增大发射功率也消除不了的错误）：

$$\text{DPSK:} \quad \overline{P}_{floor} = \frac{(1 - \rho_C) e^{-K}}{2} \tag{6.90}$$

$$\text{DQPSK:} \quad \overline{P}_{floor} = \frac{1}{2} \left[ 1 - \sqrt{ \frac{(\rho_C/\sqrt{2})^2}{1 - (\rho_C/\sqrt{2})^2} } \right] \exp\!\left[ - \frac{(2-\sqrt{2})(K/2)}{1 - \rho_C/\sqrt{2}} \right] \tag{6.92}$$

**物理直觉**：$1 - \rho_C$ 衡量信道在一个符号时间内的去相关程度。$\rho_C \to 1$（无变化）→ $P_{floor} \to 0$；$\rho_C \to 0$（完全去相关）→ $P_{floor} \to (1/2)e^{-K}$（DPSK）——相位参考完全随机，错误概率接近 1/2。

## 信道相关系数 $\rho_C$

$\rho_C = A_C(T)/A_C(0)$，其中 $A_C(t)$ 是信道自相关函数 = 多普勒功率谱 $S_C(f)$ 的逆 Fourier 变换。

| 多普勒谱类型 | $S_C(f)$ | $\rho_C = A_C(T)/A_C(0)$ |
|---|---|---|
| 矩形 | $S_0/(2B_D), \vert f\vert < B_D$ | $\operatorname{sinc}(2B_D T)$ |
| 高斯 | $S_0/(\sqrt{\pi}B_D) e^{-f^2/B_D^2}$ | $e^{-(\pi B_D T)^2}$ |
| **均匀散射**（Jakes 模型） | $S_0/(\pi\sqrt{B_D^2-f^2}), \vert f\vert < B_D$ | $J_0(2\pi B_D T)$ |
| 一阶 Butterworth | $S_0 B_D / [\pi(f^2+B_D^2)]$ | $e^{-2\pi B_D T}$ |

## 均匀散射模型下的 DPSK 地板

最常用的移动场景多普勒模型——均匀散射（Jakes），$\rho_C = J_0(2\pi f_D T_b)$：

$$P_{floor} = \frac{1 - J_0(2\pi f_D T_b)}{2} \approx 0.5 (\pi f_D T_b)^2 \tag{6.93}$$

近似用了 $J_0(x) \approx 1 - x^2/4$（小 $x$）。

> ⚡ **罕见现象：数据速率越高，误码地板越低。** $P_{floor} \propto T_b^2 = 1/R_b^2$ — 速率提高 10 倍 → 地板下降 100 倍。因为符号时间越短，信道在两个符号之间的变化越小，相位参考越准确。这是数字通信中少数几个"更快 = 更好"的场合。

### 例题 6.7

Rayleigh 衰落 + 均匀散射，$f_D = 80$ Hz。DPSK 的 $P_{floor} < 10^{-4}$ 所需数据速率？

$$0.5(\pi \cdot 80 \cdot T_b)^2 < 10^{-4} \;\Rightarrow\; T_b < 5.63 \times 10^{-5} \;\Rightarrow\; R_b > 17.77 \text{ Kbps}$$

> 80 Hz 多普勒 ≈ 900 MHz 载频下约 96 km/h 车速。结论：在此速度下需保持至少 ~18 Kbps 数据速率，差分检测才不会被多普勒地板限制。

### 图 6.4：DPSK 在快 Rician 衰落

> 【插入 Goldsmith 图 6.4】DPSK 在快 Rician 衰落（均匀散射）下不同 $f_D T_b$ 的平均 $P_b$

- 误差地板在 Rayleigh（$K=0$）下约 $\overline{\gamma}_b = 15$ dB 开始主导
- $K$ 增大（LOS 分量增强）→ 地板出现所需的 $\overline{\gamma}_b$ 提高
- $f_D T_b$ 增大一个数量级 → 地板提高约两个数量级

## 更复杂调制中的多普勒地板

$\pi/4$-DQPSK（IS-54 TDMA 标准采用的调制）的仿真结果表明误差地板在 $10^{-3}$ 到 $10^{-4}$ 之间。一个意外的发现：车速越高，误差地板反而**升高**——尽管符号时间更短意味着去相关更少。这说明对于更复杂的调制格式，多普勒地板不能简单地用 $f_D T_s$ 单一参数描述。

> ⚡ 多普勒扩展对差分调制的限制是**根本性的**——它不是"加功率就能解决"的问题。高速移动场景中，要么提高数据速率（减少 $T_s$），要么放弃差分检测改用导频辅助的相干检测。

# 6.5 符号间干扰（ISI）

## 成因

频率选择性衰落（frequency-selective fading）→ 多径导致信号不同副本以不同延迟到达 → 前一个符号的延迟副本落入当前符号的判决区间 → 符号间干扰（Intersymbol Interference, ISI）。

> ⚡ **ISI 与多普勒地板的核心区别**：多普勒地板的问题在于"参考相位失效"（差分检测特有）；ISI 地板的问题在于"信号自干扰"——**增大发射功率同时增大干扰功率**，因此 ISI 对相干和非相干检测都产生不可约地板。这是频率选择性衰落的根本限制。

## 分析方法

**Bello & Nelin（1963）** 首次系统分析了 ISI 对误码率的影响。采用高斯延迟包络假设，仅考虑相邻符号的 ISI。即使如此简化，表达式仍极复杂且需近似评估。

三种分析策略：

| 方法 | 思路 | 局限 |
|---|---|---|
| 最坏符号序列 | 对所有可能发射序列取最差情况的误码率 | 过于保守 |
| 平均符号序列 | 对所有可能序列取平均 | 依赖信道和序列统计特性，复杂度高 |
| **ISI 视为白高斯噪声** | $\hat{\gamma}_s = P_r/(N_0 B + I)$，$I$ = ISI 功率 | 最简单，但忽略 ISI 的实际相关性结构 |

ISI 视为 AWGN 时，$\hat{\gamma}_s = P_r/(N_0 B + I)$，其中 $I$ 是 ISI 的总功率。若信号和 ISI 都经历平坦衰落，$\hat{\gamma}_s$ 是两个随机变量之比 → 分布常无闭式。

## Chuang 的仿真研究（1987）

Chuang 对 BPSK、DPSK、QPSK、OQPSK、MSK 在不同脉冲形状和功率延迟包络（高斯、指数、等幅两射线、经验模型）下进行了最广泛的 ISI 地板仿真。核心发现：

1. **ISI 地板对 rms 延迟扩展 $\sigma_{T_m}$ 的敏感度远高于功率延迟包络的形状**——这意味着可以用 $\sigma_{T_m}$ 作为单一的 ISI 严重程度指标

2. **脉冲成形显著影响地板**：升余弦脉冲中，$\beta$ 从 0 增大到 1 → ISI 地板可降低一个数量级以上。原因是 $\beta$ 越大 → 脉冲时域衰减越快 → 符号间拖尾越小

3. **经验界**：对于 $0.02 \leq d \leq 0.1$（$d = \sigma_{T_m}/T_s$），所有调制方式大致满足

$$P_{floor} \leq d^2 = \left(\frac{\sigma_{T_m}}{T_s}\right)^2$$

> 【插入 Goldsmith 图 6.5】BPSK、QPSK、OQPSK、MSK 的不可约 BER 与归一化 rms 延迟扩展 $d = \sigma_{T_m}/T_s$ 的关系（高斯功率延迟包络）

### 数值量级感受

即使接受 $P_b = 10^{-2}$（语音已可察觉但尚能容忍），$d < 0.1$ 也需要 $\sigma_{T_m} < 0.1 T_s$：
- 典型城区 $\sigma_{T_m} \approx 2.5$ μs → 符号速率上限 ~40 Kbaud
- 乡村环境 $\sigma_{T_m} \approx 25$ μs（多径衰减小，远距离反射显著）→ 符号速率上限 ~4 Kbaud

> ⚡ 40 Kbaud 对现代高速数据应用远远不够。这正是**均衡器（equalizer）和多载波调制（OFDM）**存在的理由——它们不是可选的优化，而是在频率选择性信道中实现中高速率数据传输的必需品。后续章节将详述。

### 例题 6.8

$\sigma_{T_m} = 3$ μs，$P_b < 10^{-3}$。用 $P_{floor} \leq (\sigma_{T_m}/T_s)^2$：

- BPSK（每符号 1 比特）：$T_b \geq \sigma_{T_m}/\sqrt{P_{floor}} = 94.87$ μs → $R \leq 10.54$ Kbps
- QPSK（每符号 2 比特）：$T_s \geq 94.87$ μs → $R = 2/T_s \leq 21.01$ Kbps

> **QPSK 比 BPSK 更抗 ISI**——相同数据速率下 QPSK 的符号时间更长（$T_s = 2T_b$），意味着归一化延迟扩展 $d$ 更小。这是多进制调制在高阶频谱效率之外的另一优势：更高的每符号比特数带来更大的符号时间，从而更能容忍延迟扩展。

## ISI 与多普勒：两种不可约地板的对比

| | 多普勒地板（6.4 节） | ISI 地板（6.5 节） |
|---|---|---|
| **物理根源** | 信道相位随时间变化 | 多径信号的延迟副本叠加 |
| **关键参数** | $f_D T_s$（归一化多普勒） | $\sigma_{T_m}/T_s$（归一化延迟扩展） |
| **影响范围** | 主要是差分调制 | 所有调制方式 |
| **增大功率** | 无法消除（参考相位噪声） | 无法消除（信号本身干扰自身） |
| **提高符号速率** | 地板下降（$P_{floor} \propto 1/R^2$） | 地板上升（$P_{floor} \propto 1/R^2$，等效地 $T_s$ 减小使 $d$ 增大） |
| **对抗手段** | 导频辅助相干检测、提高数据速率 | 均衡器、扩频/多载波（OFDM）、提高符号时间（高阶调制） |

> ⚡ 注意多普勒和 ISI 对数据速率的**相反需求**：多普勒要求速率**不能太低**（相位来不及变化），ISI 要求速率**不能太高**（符号间干扰加重）。无线系统设计必须在两者之间找到平衡点——这是频率选择性+时变信道的根本设计约束。
