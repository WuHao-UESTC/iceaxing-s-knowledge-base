# 14.1 多用户信道：广播与多址接入

## 两种基本多用户信道

多用户信道（multiuser channel）指多个用户必须共享的任意信道。两类基本拓扑：

| | 广播信道（Broadcast） | 多址接入信道（Multiple Access） |
|---|---|---|
| **流向** | 一个发射机 → 多个接收机 | 多个发射机 → 一个接收机 |
| **共享资源** | 发射机功率和带宽需在用户间分配 | 各发射机功率独立，但接收机带宽需在用户间分配 |
| **典型例子** | 广播电视、卫星下行、蜂窝基站→手机（下行） | 以太网、电话线路、手机→蜂窝基站（上行） |

> 【插入 Goldsmith 图 14.1】广播与多址接入信道示意图

## 多用户通信的核心目标

**在有限系统资源（功率和带宽）下高效利用，同时对用户间产生最小的干扰。**

带宽是最稀缺的资源——由 FCC 分配，昂贵。带宽划分的两种基本模式：

- **多址接入（Multiple Access）**：为用户分配**专用信道** → 适用于语音等持续业务（需要保证信道）
- **随机接入（Random Access）**：不保证信道接入 → 适用于突发数据业务

选择哪种接入方式和信道化方法取决于：业务特征、当前接入技术水平、与其他系统的兼容性。

# 14.2 多址接入技术

多址接入通过**信道化**（channelization）将系统资源正交（或半正交）划分，为用户分配专用信道。信道化方法适用于广播和多址接入信道两者，但性能表现不同。

三种基本划分维度：频率、时间、编码，以及它们的混合。

> **理论等价性**：对于同质用户（等功率和带宽需求），时分（TD）、频分（FD）和正交码分（orthogonal CD）是等价的——它们都在信号空间中进行正交划分。容量区域相同。但半正交码分配合多用户检测时，可达速率**更高**；不用多用户检测时则**更低**。

---

## 14.2.1 频分多址（FDMA）

**带宽**划分为互不重叠的窄带信道，每个用户分配一个独立信道。

**特点**：
- 信道间需要**保护频带**（guard band）——补偿非理想滤波器、邻道干扰和 Doppler 频谱扩展
- 用户信道为窄带 → 经历平坦衰落 →**不需要 ISI 补偿**
- 实现最简单，但**灵活性差**——难以为单个用户动态分配多个信道（需同时解调多个窄带信道）
- 用于大多数模拟蜂窝系统；某种意义上所有系统都在用频分（总带宽有限）

---

## 14.2.2 时分多址（TDMA）

**时间**划分为正交时隙，每个用户分配周期性重复的时隙。

**特点**：
- 常与频分结合，如 GSM 标准
- 传输不连续 → 需要**缓存 + 数字传输**技术
- **不连续传输使切换（handoff）更简单**——可在其他用户时隙执行切换
- 空闲时隙中发射机可 sensing 信道 → 辅助确定切换目标基站
- **上行同步是主要挑战**：不同用户到基站的距离不同 → 传播延迟不同 → 时隙必须同步以保证到达基站后仍正交
- 信道可以是宽带（如 GSM ~200 kHz → 需要均衡器）或窄带（如 IS-54 ~30 kHz → 不需要均衡器）

---

## 14.2.3 码分多址（CDMA）

**时间和频率**同时被不同用户使用，通过**正交或半正交码**调制，接收端利用码结构分离用户。

**正交码 vs 半正交码**：

| | 正交码 CDMA | 半正交码 CDMA |
|---|---|---|
| 用户数限制 | **硬上限** $N$（同 FD/TD） | **干扰受限**——无硬上限 |
| 用户间干扰 | 零（理想正交） | 非零，用户越多干扰越大 |
| 协调需求 | 需码同步 | 无需动态时间/频率协调 |

**扩频 CDMA 的核心优势**：用户间几乎不需要动态协调——码性质即可分离用户。

**近远问题（Near-Far Problem）**：上行链路中，离基站近的用户的信号会"淹没"远处用户的信号 → 必须**功率控制**使所有用户在基站处的接收功率大致相等。这种功率控制本质上是信道反转。

**实现复杂度**：三种技术中最高——需要码同步 + 功率控制。多用户检测可避免功率控制，但接收机复杂度显著增加，且错误检测比特会反馈污染其他用户的解码（类似 DFE 的错误传播问题）。

---

## 14.2.4 标准之争

美国蜂窝和 PCS 多址接入的三大竞争标准：

| 标准 | 多址方式 | 特点 |
|---|---|---|
| **IS-54** | FDMA | 频分，模拟蜂窝演化 |
| **IS-95** | CDMA（扩频） | 码分，需严格功率控制 |
| **GSM** | TDMA + 慢跳频 | 时分频分结合，欧洲主导 |

**功率控制是 CDMA 的实际瓶颈**：商用扩频系统（当时）不使用多用户检测 → 必须严格功率控制以维持基站处各用户接收功率恒定。在衰落环境中严格功率控制极难维持。

> 这场标准之争催生了大量声称某一技术优越的分析研究——但先验假设往往偏向作者有经济利益的那一方。**争论主要针对语音系统；数据和多媒体系统面临不同挑战，结论不一定适用。**

# 14.3 广播信道容量区域

## 容量区域的概念

多用户共享信道时，容量不再是一个单一数值——有无限多种"划分"信道的方式。**容量区域（capacity region）**是所有可同时维持的速率向量 $(R_1, R_2, \ldots, R_K)$ 的集合。

本节按以下顺序展开：AWGN 广播信道（叠加编码+逐次干扰消除 vs TD/FD/CD）→ 扩频 CD 的容量代价 → 衰落信道扩展。

**核心结论预览**：叠加编码 + 逐次干扰消除（superposition coding + SIC）达到广播信道**最大**容量区域。扩频 CD+SIC 比叠加编码有容量损失（随扩频增益增大）。正交 CD 仅能达到 TD/FD 的子集。非正交 CD 无干扰消除则最差。

---

## 14.3.1 AWGN 广播信道模型

### 模型设定

两用户广播信道：一个发射机（总功率 $S$，总带宽 $B$）→ 两个接收机。各自前端 AWGN 噪声密度 $n_1 \leq n_2$（用户 1 信道更好）。

**关键假设**：
- 发射机向不同接收机发送**独立**信息（不是所有用户接收相同信号——与 FM/TV 广播不同）
- 只分析两用户即可推广到多用户——因为达到容量区域的发射分布是**高斯分布** → 来自其他用户的干扰精确建模为高斯噪声，即使少量干扰者也成立

### 边界点

若将所有功率和带宽分配给一个用户：$(C_1, 0)$ 和 $(0, C_2)$，其中

$$C_i = B\log\!\left[1 + \frac{S}{n_i B}\right] \tag{14.1}$$

这两个点是容量区域的边界。内部点通过更公平的资源划分方式达到。

---

## 14.3.2 AWGN 下 TD、FD、CD 的容量区域

### 时分（TD）

**等功率 TD**：发射功率恒定 $S$，用户 1 占用时间比例 $\tau$，用户 2 占用 $1-\tau$：

$$\{(R_1 = \tau C_1,\ R_2 = (1-\tau) C_2);\ 0 \leq \tau \leq 1\} \tag{14.2}$$

这是一条连接 $(C_1, 0)$ 和 $(0, C_2)$ 的**直线**。

**不等功率 TD**：各用户在其时隙内使用不同功率 $S_1, S_2$，约束 $\tau S_1 + (1-\tau)S_2 = S$：

$$\{(R_1 = \tau B\log[1 + S_1/(n_1 B)],\ R_2 = (1-\tau)B\log[1 + S_2/(n_2 B)])\} \tag{14.3}$$

不等功率 TD 与 FD 等价（见下）。

### 频分（FD）

固定频分 $(B_1, B_2)$ 满足 $B_1+B_2 = B$，功率分配 $\{S_1, S_2: S_1+S_2=S\}$：

$$\{(R_1 = B_1\log[1 + S_1/(n_1 B_1)],\ R_2 = B_2\log[1 + S_2/(n_2 B_2)])\} \tag{14.4}$$

Bergmans 证明：当 $n_1 < n_2$，存在功率分配使 FD 速率对**超过**等功率 TD 直线段。

遍历所有频分的并集（可变带宽分配）：

$$\{(R_1 = B_1\log[1 + S_1/(n_1 B_1)],\ R_2 = B_2\log[1 + S_2/(n_2 B_2)]);\ S_1+S_2=S,\ B_1+B_2=B\} \tag{14.5}$$

**TD 与 FD 的等价性**：令 $B_i = \tau_i B$ 和 $\sigma_i = \tau_i S_i$ → (14.3) 变为 (14.6)，与 (14.4) 形式相同。**不等功率 TD = FD**——任何 FD 速率点可通过适当的时隙和功率分配用 TD 实现。

> ⚡ 当 $n_1 = n_2$ 时，(14.5) 退化为 (14.2)——用户 SNR 相同时，最优功率/频率分配退化为等功率 TD，所有频谱共享方式的容量区域相同。**用户 SNR 差异越大，优化功率/频率分配的价值越大。**

> 【插入 Goldsmith 图 14.3, 14.4】两用户容量区域：3 dB SNR 差异和 20 dB SNR 差异

### 叠加编码 + 逐次干扰消除（Superposition + SIC）

**多分辨率编码**：信道好的用户（低 $n_1$）能分辨信号星座的精细结构；信道差的用户（高 $n_2$）仅能分辨粗糙结构。

> 【插入 Goldsmith 图 14.2】32-QAM 内嵌 4-PSK 的叠加星座示例

**实例（图 14.2）**：32-QAM 内嵌 4-PSK。差 SNR 用户提供 2 比特选 4-PSK 超点；好 SNR 用户提供 3 比特选超点周围的 8 个星座点。好用户解码后减去 4-PSK 超点（无干扰）；差用户将 32-QAM 细结构视为噪声。

**容量区域**（Cover 推导）：

$$\{(R_1 = B\log[1 + S_1/(n_1 B)],\ R_2 = B\log[1 + S_2/(n_2 B + S_1)]);\ S_1+S_2=S\} \tag{14.7}$$

**直观解释**：$n_1 < n_2$ → 用户 1 能正确解码用户 2 的信息 → 减去用户 2 的信号后解码自己的（无干扰）。用户 2 不能解码用户 1 的信息 → 用户 1 的信号（功率 $S_1$）对用户 2 是**额外噪声**。

> ⚡ **（14.7）是广播信道的最大可达速率区域——即容量区域本身。** 叠加编码+SIC 超越了 TD 和 FD。但实际系统中逐次消除有**错误传播**问题（解码错误 → 减法后残留 → 后续用户被污染），实践中使用鲁棒性更好的抵消方法。

### 正交码分

扩频正交码（Walsh-Hadamard）：需要扩频增益 $G=N$ 产生 $N$ 个正交码。每个用户信息带宽 $B/N$。

$$\{(R_1 = \tfrac{B}{2}\log[1 + S_1/(n_1 B/2)],\ R_2 = \tfrac{B}{2}\log[1 + S_2/(n_2 B/2)])\} \tag{14.8}$$

= 固定等分频分的 FD → **仅能达到 TD/FD 容量区域的子集**。

### 非正交码分（扩频）+ SIC

最大长度移位寄存器生成的非正交码，互相关 $\approx 1/G$。干扰被扩频增益衰减 $G$ 倍：

$$\{(R_1 = \tfrac{B}{G}\log[1 + \tfrac{S_1}{n_1 B/G}],\ R_2 = \tfrac{B}{G}\log[1 + \tfrac{S_2}{n_2 B/G + S_1/G}])\} \tag{14.9}$$

由 $\log$ 的凸性，$G>1$ 时的区域**小于**叠加编码 (14.7)，且随 $G$ 增大而**恶化**。→ **非正交码应最小化扩频增益以最大化容量。**

### 非正交码分 + 无干扰消除

接收机将所有其他用户信号视为噪声：

$$\{(R_1 = \tfrac{B}{G}\log[1 + \tfrac{S_1}{n_1 B/G + S_2/G}],\ R_2 = \tfrac{B}{G}\log[1 + \tfrac{S_2}{n_2 B/G + S_1/G}])\} \tag{14.10}$$

速率区域的边界是**凸函数**（二阶导数 $\geq 0$）→ 位于 TD/FD 的**凹边界之下** → **非正交 CD 无干扰消除 = 所有方法中最差。**

### 多径对正交码的影响

多径延迟超过码片时间 → 正交码失去正交性 → 产生用户间干扰。此时速率区域形式为 (14.12)，互相关变为 $1/G'$。多径减弱时 $G' \to \infty$，区域收敛于正交码 (14.8)。

### 各方法排名总结

| 排名 | 方法 | 容量区域 |
|---|---|---|
| 1（最优）| 叠加编码 + SIC | 最大 = 广播信道容量区域 |
| 2 | 非正交 CD + SIC（$G$ 小） | 次优，随 $G$ 增大继续下降 |
| 3 | TD（不等功率）= FD | 正交划分信号空间 |
| 4 | 正交 CD | TD/FD 的子集（仅等分带宽点） |
| 5（最差）| 非正交 CD 无 SIC | 凸边界，始终在 TD/FD 之下 |

## 14.3.3 衰落广播信道容量

### 模型

两用户衰落广播信道：时变 SNR $\gamma_j[i] = S g_j[i] / (N_j B)$。定义 $n_j[i] = N_j / g_j[i]$（等效噪声密度）。假设：
- 各接收机知道自己的 $n_j[i]$
- 发射机知道 **两个** $n_1[i]$ 和 $n_2[i]$（CSIT）→ 可随信道状态变化调整功率和带宽分配

### 衰落下的时分

TD 将两用户信道分解为两个**正交的时变单用户信道**，直接套用第 4 章单用户衰落容量。

**等功率 TD**：

$$\{(R_1 = \tau C_1[S, B],\ R_2 = (1-\tau) C_2[S, B]);\ 0 \leq \tau \leq 1\} \tag{14.13}$$

其中 $C_i[S, B]$ 由单用户衰落容量公式给出，最优功率自适应的注水法达到最大区域。

**不等功率 TD**（= 固定 FD）：

$$\{(R_1 = \tau C_1[S_1, B],\ R_2 = (1-\tau) C_2[S_2, B]);\ \tau S_1+(1-\tau)S_2 = S\} \tag{14.14}$$

### 衰落下的频分

**固定频分**：$B_1 + B_2 = B$，$S_1 + S_2 = S$。每个子信道独立套用单用户衰落容量 → 与不等功率 TD (14.14) 等价。

$$\{(R_1 = C[S_1, B_1],\ R_2 = C[S_2, B_2])\} \tag{14.15}$$

**变功率+变带宽分配**（最优 FD）：在每个信道状态 $(n_1[i], n_2[i])$ 下**动态**分配功率和带宽：

$$\{(R_1 = \sum_k C_{1,k}[S_{1,k}, B_{1,k}] \pi_k,\ R_2 = \sum_k C_{2,k}[S_{2,k}, B_{2,k}] \pi_k);\ B_{1,k}+B_{2,k}=B,\ \sum_k (S_{1,k}+S_{2,k})\pi_k = S\} \tag{14.16}$$

其中 $\pi_k = p(n_1[i]=n_{1,k}, n_2[i]=n_{2,k})$ 为联合噪声分布。

> 寻找 (14.16) 的边界需要**在多维空间中对时间和带宽/功率联合优化**——复杂度极高。其容量区域上界 = 叠加编码+SIC 区域；下界 = 所有固定 FD 区域的并集。

### 衰落下的叠加编码 + SIC

在每个时刻根据瞬时 $n_1[i], n_2[i]$ 优化星座，噪声更低的用户做干扰消除。速率区域 = AWGN 区域的加权平均：

$$\begin{aligned} &(R_1 = \sum_k B\log[1 + \tfrac{S_{1,k}}{n_{1,k}B + S_{2,k}\mathbf{1}[n_{1,k} \geq n_{2,k}]}] \pi_k, \\ &R_2 = \sum_k B\log[1 + \tfrac{S_{2,k}}{n_{2,k}B + S_{1,k}\mathbf{1}[n_{2,k} > n_{1,k}]}] \pi_k);\ \sum_k (S_{1,k}+S_{2,k})\pi_k = S\} \end{aligned} \tag{14.17}$$

$\mathbf{1}[\cdot]$ 为指示函数——哪个用户噪声更低，哪个用户就做干扰消除。

**与 FD 的比较**：在任何噪声密度对 $(n_{1,k}, n_{2,k})$ 下，存在叠加编码（总功率 $S_k = S_{1,k}+S_{2,k}$）的容量区域大于 FD → 加权积分后仍大于 FD。**叠加编码+SIC 在衰落信道中仍然是最优的。**

### 无 SIC 的叠加编码

$$\{(R_1 = \sum_k B\log[1 + \tfrac{S_{1,k}}{n_{1,k}B + S_{2,k}}] \pi_k,\ R_2 = \sum_k B\log[1 + \tfrac{S_{2,k}}{n_{2,k}B + S_{1,k}}] \pi_k)\} \tag{14.18}$$

每个 $k$ 项的边界是凸函数 → 加权和也是凸函数 → 在 TD/FD 的凹边界之下——最差。

### 功率自适应的关键性

> 【插入 Goldsmith 图 14.5】两用户在 Rayleigh 衰落下容量区域

**一个重要对比**：
- 单用户衰落信道中，保持发射功率恒定对容量的影响**可忽略**（注水增益仅约 1-2 dB）
- **多用户衰落信道中，功率自适应的作用被显著放大**——因为功率分配不仅影响目标用户的 SNR，还影响对其他用户的干扰

图 14.5 显示：固定功率下，等功率 TD 在靠近端点处**超过**了叠加编码+SIC（无功率优化）——这在 AWGN 中不可能发生，说明功率优化在多用户场景中至关重要。

### 衰落的影响：容量区域缩小

对比图 14.3（AWGN）和图 14.5（Rayleigh 衰落），即使采用最优功率/带宽/编码自适应，**衰落使容量区域缩小**。这与第 4 章结论一致——衰落下的单用户容量始终小于同平均 SNR 的 AWGN 容量。

### 数值计算复杂度

| 区域 | 计算难度 |
|---|---|
| TD (14.13), 固定 FD (14.15) | **简单** — 单用户方法直接套用 |
| 变功率+变带宽 FD (14.16) | 困难 — 需穷举搜索/多维时间优化 |
| 叠加+SIC (14.17), 无SIC (14.18) | 困难 — 二维功率优化或穷举搜索 |
| 实用下界 | 固定功率 $S_{1,k}=S_{2,k}=S$ 代入 (14.17)/(14.18)

# 14.4 多址接入信道容量区域

## 14.4.1 AWGN 多址接入信道（MAC）

### 模型

多址接入信道：$K$ 个发射机（各自功率 $P_i$）→ 一个接收机（AWGN 功率 $n$）。接收信号：

$$Y = \sum_{i=1}^K X_i + N$$

### 两用户容量区域（Cover）

Cover 给出了两用户 MAC 容量区域——满足以下条件的 $(R_1, R_2)$ 闭凸包：

$$\begin{aligned} R_i &\leq B\log\!\left[1 + \frac{P_i}{nB}\right] \\ R_1 + R_2 &\leq B\log\!\left[1 + \frac{P_1 + P_2}{nB}\right] \end{aligned} \tag{14.19}$$

> 【插入 Goldsmith 图 14.6】MAC 容量区域（五边形）

**四个关键点**：

| 点 | 含义 | 达到方式 |
|---|---|---|
| $(C_1, 0)$ | 仅用户 1 全功率发射 | $C_1 = B\log[1+P_1/(nB)]$ |
| $(0, C_2)$ | 仅用户 2 全功率发射 | $C_2 = B\log[1+P_2/(nB)]$ |
| $(C_1, C_2^*)$ | 用户 1 全速 + 用户 2 减速率 | 逐次解码：先解用户 1 → 减去 → 再解用户 2 |
| $(C_1^*, C_2)$ | 反之 | $C_1^* = B\log[1+P_1/(nB+P_2)]$，$C_2^* = B\log[1+P_2/(nB+P_1)]$ |

**逐次解码实现角点**：先解码全速用户（信号强）→ 减去 → 剩余信号中只有另一用户+噪声 → 解码另一用户。速率 $C_i^*$ 来自"另一用户的信号充当额外噪声"。

### TD vs FD vs 叠加编码

**TD**（等功率）：$C_1$ 和 $C_2$ 连线上的直线段。

**FD**（功率不变，带宽 $B_1+B_2=B$）：

$$R_i \leq B_i\log\!\left[1 + \frac{P_i}{nB_i}\right] \tag{14.23}$$

FD **优于**等功率 TD（log 的凸性）。令 $B_i = \tau_i B$ 并将功率提升至 $P_i/\tau_i$，TD (14.24) 等价于 FD (14.23)。

**叠加编码无 SIC**：每个用户的信号对他人是噪声 → 最大速率不超过 $(C_1^*, C_2^*)$ → 次优于 FD（尤其两用户都全功率时最明显）。

**排名**（与广播信道一致）：叠加+SIC > FD = TD(不等功率) > TD(等功率) > 叠加无 SIC

---

## 14.4.2 衰落多址接入信道

衰落 MAC：时变噪声 $n(t)$。发射机 $i$ 跟踪 $n_i(t)$，接收机跟踪两者。发射功率可随 $n(t)$ 调整。

### TD

两个正交时变单用户信道，各自独立优化功率分配 → TD 速率区域是 $(C_1(P_1), C_2(P_2))$ 之间的直线，其中

$$C_i(P_i) = \max_{\{\Phi_{k_i}: \int \pi_k \Phi_{k_i} = P_i\}} \int_k \pi_k B\log\!\left[1 + \frac{\Phi_{k_i}}{nB}\right] \tag{14.26}$$

### 固定 FD

带宽分 $B_1 + B_2 = B$，各用户独立功率自适应：

$$R_i \leq \max_{\Phi_{k_i}} \int \pi_k B_i\log\!\left[1 + \frac{\Phi_{k_i}}{nB_i}\right] \tag{14.27-14.28}$$

### 排名不变

**固定 FD 优于 TD，叠加编码优于两者。** 与广播信道一致——不同频谱共享方式的相对排序在 AWGN 和衰落中保持不变，只是容量区域的形状不同。

# 14.5 随机接入

## 为什么需要随机接入

专用信道分配对**突发数据用户**极其低效——大部分时间信道空闲。且系统总用户数远多于可用信道数 → 只能将信道分配给**当前活跃**的用户。

## ALOHA 协议

Abramson 首创的随机接入协议。

| | 纯 ALOHA（非时隙） | 时隙 ALOHA |
|---|---|---|
| 发送时机 | 任意时刻 | 仅时隙起点 |
| 碰撞模型 | 任意重叠→双方丢包 | 同时隙内→各丢一包 |
| 最大吞吐率 | ~18% | ~36%（翻倍） |
| 同步需求 | 无 | 全网时隙同步（开销显著） |

碰撞后双方随机等待再重传 → 避免再次碰撞。纠错编码可在碰撞后恢复部分包 → 减少不必要重传。

## CSMA、隐藏终端与暴露终端

**CSMA（载波侦听多址）**：发送前侦听信道，忙则延迟 → 仅当所有节点能互相听到时有效。

> 【插入 Goldsmith 图 14.7】隐藏终端与暴露终端

**隐藏终端问题**：节点 3 听不到节点 5 的传输 → 误判信道空闲 → 碰撞。**暴露终端问题**：节点 2 听到节点 3 的传输 → 误判信道忙 → 放弃实际上不冲突的传输。

## 解决方案

- **四步握手**（RTS/CTS/DATA/ACK，802.11 协议核心）：基于单跳路由，多跳网络次优
- **忙音传输**（Busy Tone）：独立控制信道发忙音；集中式下有效，分布式更复杂
- ⚡ 握手和忙音**减少隐藏终端碰撞，但加剧暴露终端问题** → 收发双方同时发忙音可缓解

## 吞吐率 vs 效率

传统吞吐率（时间利用率）不完全反映性能。**效率（efficiency）**考虑了功率和带宽：

$$\text{效率} = \frac{\text{ALOHA 信道容量}}{\text{同功率+同带宽下连续信道容量}}$$

**关键发现**：在低吞吐率+低 SNR 条件下，ALOHA 效率 **→ 1**——即在这些条件下不存在比 ALOHA 容量更高的多址协议。

## 应用与局限

ALOHA 广泛用于窄带应用（~10 Kbps）：三大数字蜂窝标准的信令信道、ARDIS/RAM Mobitex 分组无线网、INMARSAT 卫星请求信道、10 万+ VSAT 地球站。

**宽带挑战**：传统 ALOHA 在宽带下难以实现——突发功率需求过高。**扩频 ALOHA（SAMA）**等第二代宽带版本正在改变这一局面。

# 14.6 调度

## 动机

随机接入在突发短包时有效，但用户有**长数据流或连续数据**时 → 大部分传输碰撞 → 需要**传输调度**系统化分配信道。

## 调度方式

- **集中式调度**（蜂窝系统）：中心控制器分配时隙/频率/码道 → 相对简单
- **分布式调度**（ad hoc 网络）：每个节点自主调度，避免邻节点冲突 → **NP-hard**

Selman 等发现 NP-hard 问题随规模增大存在**相位转变**（phase transition）——复杂度在某临界点急剧变化。识别此转变可帮助在"好的一侧"操作以限制复杂度。

## PRMA（分组预约多址）

**核心思想**：随机接入 + 预约的混合。

1. 初始接入用 ALOHA（系统启动时无法预分配）
2. 成功捕获一个时隙 → **预约**该时隙用于后续所有传输
3. 语音（连续）用户 → 预约后获得专用周期性时隙
4. 数据传输完毕 → 释放时隙，归还空闲时隙池
5. 数据（突发）用户 → 从空闲池中用 ALOHA 竞争

> ⚡ PRMA 将"随机接入的灵活性"和"调度接入的效率"结合——这是语音+数据混合系统的经典设计。信道恶化导致丢包 → 用户失去预约 → 需重新竞争 → 可能显著延迟。

# 14.7 功率控制

## SINR 门限方法

基本框架：维持各用户的 SINR 高于给定门限。核心问题——**是否存在一组可行的发射功率使所有用户同时满足 SINR 要求？**

[28] 给出了在已知链路增益下存在可行功率向量的**充要条件**。在可行集中找最省电的功率向量 → 最小化电池消耗。该算法可**分布式**执行 → 无需集中功率控制。

## 接入控制（Admission Control）

新用户能否接入系统 → 取决于是否破坏已有用户的 SINR：

1. **集中式**：控制器判断是否存在包含新用户的可行功率向量
2. **分布式**：新用户逐步提升功率 → 已有用户为维持 SINR 同步提升功率
   - **可行**：所有用户功率收敛到新可行点，新用户达到 SINR 目标
   - **不可行**：多轮迭代后新用户始终远离 SINR 目标 → 退避并稍后重试（或降低目标）

> 分布式接入控制的美妙之处：系统自动"试探"是否接纳新用户，无需显式计算可行集。

## 时延约束下的功率控制

[28] 通过动态规划同时优化发射功率与信道条件和时延约束。最优策略呈现**三种模式**：

| 模式 | 信道条件 | 时延约束 | 发射功率 |
|---|---|---|---|
| 保守 | 差 | 宽松 | 极低 |
| 正常 | 中等 | 中等 | 中等 |
| 激进 | — | 紧迫 | 极高 |

与恒定功率相比，该策略在满足时延约束的同时**显著节省功率**。
