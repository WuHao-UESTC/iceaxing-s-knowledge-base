# 15.1 蜂窝系统设计

## 蜂窝架构

蜂窝系统的核心思想：利用信号传播功率随距离衰减的特性，在空间分离的位置**复用同一频率信道**。

> 【插入 Goldsmith 图 15.1】蜂窝系统——给定空间区域被划分为不重叠的小区（cell），不同小区分配不同频率/时隙/码字

每个小区的中心发射机连接至**基站（base station）**和**交换局（switching office）**，由集中控制器执行：
- 信道分配
- CDMA 功率控制
- 小区间**切换（handoff）**协调

### 切换（Handoff）机制

移动终端穿越小区边界时触发切换：

```
信号功率下降 → 源基站检测 → 查询相邻基站 → 找到目的基站 → 协调切换
                                                        ↓ 无可用信道
                                                        ↓ 呼叫掉线（dropped）
```

**虚假切换（false handoff）**：多径衰落或阴影导致的接收功率下降 → 源基站误判为小区边界跨越 → 发起不必要的切换。即使终端远离小区边界，深衰落也可能触发切换请求。

⚡ 切换是蜂窝系统的核心支撑机制之一——没有它就没有移动性。但它也是脆弱点：错误切换浪费资源，切换失败导致掉话。这两者的根本原因都是无线信道的随机性。

### 小区尺寸的基本权衡

| 方向 | 效果 |
|------|------|
| **缩小小区的收益** | 单位面积容纳更多用户 → 频谱效率 $\uparrow$ |
| **缩小小区的代价** | 切换频率 $\uparrow$ → 掉话率 $\uparrow$；路由重建更频繁（每次切换需重建）；高层协议负担增大 |

⚡ 小区小型化（macro → micro → pico cells）是提高容量的最直接手段，但它把物理层的不确定性（随机切换）转化为网络层的复杂性（频繁路由重建）。这与 [[Goldsmith-无线通信/第1章-无线通信导论#1.3 技术挑战|第 1 章的跨层设计讨论]] 一脉相承——物理层的随机性穿透协议栈。

### 同信道干扰与干扰受限设计

频率复用 → **同信道干扰（co-channel interference, CCI）**影响每个用户的可达数据率和误码率。

干扰大小取决于同频用户的空间分离距离。设计目标：**在"复用距离最小"（频谱效率最大）和"CCI 可容忍"（性能要求满足）之间找到最优点**。

**干扰受限系统（interference-limited system）**：
- 好的蜂窝系统设计使干扰功率 $\gg$ 噪声功率
- → 噪声可忽略，系统性能由**干扰主导**
- → 任何降低干扰的技术直接转化为容量提升

⚡ 这与 [[Goldsmith-无线通信/第1章-无线通信导论#1.4.1 蜂窝电话系统|第 1 章讨论的]] 完全一致：高效蜂窝系统是**干扰受限**的——这是贯穿全书所有章节的核心设计主线。

### 静态分配 vs 动态分配

| 策略 | 方法 | 优势 | 劣势 |
|------|------|------|------|
| **静态设计** | 基于最差传播条件确定固定复用距离 | 简单 | 频谱和功率效率低（为最差情况留余量） |
| **动态资源分配** | 根据当前传播/用户需求/系统流量动态分配功率、带宽、频率 | 频谱和功率效率大幅提升 | 系统复杂度急剧增加 |

CCI 受阴影和多径衰落的随机影响 → 静态设计必须假设最差传播条件 → 余量过大。动态分配是该问题的直接回答——详见 15.3 节。

# 15.2 蜂窝系统中的频率复用

## 15.2.1 码分系统中的频率复用

CDMA 系统的信道是**半正交**的（扩频码特性）：
- 允许在**每个小区重复使用相同码字**
- 代价：引入两类干扰

| 干扰类型 | 来源 | 英文 |
|----------|------|------|
| **小区内干扰** | 同一小区内所有用户 | intracell interference |
| **小区间干扰** | 相邻小区用户 | intercell interference |

### 近-远问题与功率控制

**近-远效应（near-far problem）**：同一小区内，距离基站近的用户信号强、远的用户信号弱 → 强信号淹没弱信号。

CDMA 系统普遍使用**功率控制**应对。但功率控制有意想不到的副作用：

> 功率控制 = 反转信号衰减 → 小区边界附近的终端路径损耗大 → 功率控制大幅提高其发射功率 → **这些边界终端对相邻小区产生更强的干扰**

⚡ 功率控制的双刃剑：解决了小区内的近-远问题，加剧了小区间的干扰。**CDMA 的容量瓶颈不在小区内，而在小区间。**

两种干扰均被码字的**处理增益（processing gain）**衰减。但由于干扰源数量极大，CDMA 蜂窝系统的性能分析相当复杂，严重依赖传播模型、小区尺寸、移动性模型等系统参数 $[1]$。

### CDMA vs FDMA/TDMA 复用本质差异

| | CDMA | FDMA/TDMA |
|------|------|------|
| 频率复用因子 | $N = 1$（每小区复用） | $N > 1$（簇内分配） |
| 干扰类型 | 小区内 + 小区间 | 仅小区间（同信道） |
| 处理干扰方式 | 扩频增益 + 功率控制 | 空间分离 |
| 设计哲学 | **接受并管理干扰** | **避免干扰** |

⚡ 这是 [[Goldsmith-无线通信/第1章-无线通信导论#1.4.1 蜂窝电话系统|第 1 章]] 讨论过的 FDMA/TDMA vs CDMA 根本哲学差异在蜂窝系统中的具体体现。CDMA 不试图正交分离用户——它接受用户间干扰，通过扩频增益管理它。这直接转化为 $N=1$ 的极端频率复用效率。

## 15.2.2 时分与频分系统中的频率复用

FDMA 和 TDMA 的信道**正交** → **无小区内干扰**。但频率复用在所有使用相同信道的同信道小区间引入同信道干扰。接收 SNR 仅取决于当前的干扰功率。若系统**不是**干扰受限的 → 可进一步增加用户或缩小复用距离。

### 六边形小区几何

> 【插入 Goldsmith 图 15.2】六边形小区布局与坐标系统

$R$ = 小区中心到顶点的距离。小区位置以 $(i, j)$ 坐标标识——以原点 (0,0) 为参考，沿 $u$ 轴移动 $i$ 个小区，然后逆时针 60° 沿 $v$ 轴移动 $j$ 个小区。

相邻小区中心距离 = $\sqrt{3}R$。小区 $(i,j)$ 与原点之间的中心距：

$$D = \sqrt{3}R \sqrt{i^2 + j^2 + ij} \tag{15.1}$$

### 频率分配方法

> 【插入 Goldsmith 图 15.3】频率分配过程

(15.1) 给出了一种频率分配策略：从原点开始 → 沿任意六边形链移动 $i$ 个小区 → 逆时针 60° → 沿新方向移动 $j$ 个小区 → 将频率 A 分配到最终的小区。以任何已有 A 小区为原点重复此过程。

> 【插入 Goldsmith 图 15.4】六边形簇

对所有频率执行此过程 → 形成**六边形小区簇（hexagonal clusters）**，在距离 $D$ 处重复出现。

### 复用因子 N

- 六边形小区面积：$A_{\text{cell}} = 3\sqrt{3}R^2/2$
- 六边形簇面积：$A_{\text{cluster}} = \sqrt{3}D^2/2$
- 每簇小区数（**复用因子**）：

$$N = \frac{D^2}{3R^2} = i^2 + j^2 + ij$$

$N$ 越小 → 频率复用越频繁 → 频谱效率越高。

$N$ 的可能取值（由 $i^2 + j^2 + ij$ 约束）：1, 3, 4, 7, 9, 12, …（注意 $N=1$ 意味每小区复用所有频率——在 FDMA/TDMA 下 CCI 极大，不可行；这在 CDMA 中才是常态）。

> 【插入 Goldsmith 图 15.4】$N=7$ 的簇示例

| $N$ | $(i,j)$ 示例 | 复用距离 $D/R$ | 复用效率 |
|-----|-------------|---------------|---------|
| 1 | (0,0) | $\sqrt{3}$ | 最高（CDMA 可行） |
| 3 | (1,1) | 3 | 较高 |
| 4 | (2,0) | $2\sqrt{3}$ | 中等 |
| 7 | (2,1) | $\sqrt{21}$ | 标准 |
| 12 | (2,2) | 6 | 较低 |

⚡ $N$ 是蜂窝系统设计的核心参数——**频谱效率与同信道干扰的平衡点**。$N$ 越小 → 每个小区分到的频谱越多 → 容量越大 → 但同信道干扰也越大。最优点由可接受的最低 SINR 决定。

# 15.3 蜂窝系统中的动态资源分配

## 静态分配的根本局限

初代蜂窝系统采用**固定频率复用模式**，基于最差传播条件和最差干扰假设设计。这意味着绝大多数时间系统都工作在大幅余量下——频谱和功率利用率极低。

⚡ 固定分配的根本问题：**用最差情况作为一切时刻的设计依据**。无线信道的随机时变性意味着最差情况很少发生，但静态设计必须为它保留全部资源。

## 动态分配策略

动态资源分配将**频率、基站、数据率、功率**根据当前条件自适应分配：

- 当前干扰水平
- 当前传播条件
- 当前用户需求
- 当前系统流量

即使使用相对简单的动态信道分配算法，信道效率已证明可**提升两倍或更多** $[7]$。

但这一分析基于相当简化的系统假设。**真实系统条件下的动态资源分配性能提升仍是开放且有挑战性的研究问题。**

## 复杂度的核心挑战

### 现有研究的局限

大多数动态信道分配研究基于以下简化假设：
- 固定流量强度
- 同质用户需求
- 固定复用约束
- 静态信道和静态用户

即便在这些简化假设下，最优化信道分配已高度复杂。

### 简化尝试的问题

神经网络和模拟退火虽降低了复杂度，但可能**不收敛或产出次优解**。

### 未解决的核心问题

1. **多维随机性联合处理**：同时考虑流量、传播、用户移动性的随机变化——几乎无相关研究
2. **不易推广至多约束**：功率控制、业务分类（如多媒体）、小区切换、用户优先级难以纳入现有框架
3. **负载依赖性**：动态分配在轻载下效率提升最显著；重载下次优分配难以重新调整 → **最优策略本身依赖流量条件**

### 实现可行性

对于**小小区 + 快速变化传播条件 + 高频用户需求变动**的组合，动态资源分配的复杂度在 5–10 年内可能无法克服。

⚡ 这与 [[Goldsmith-无线通信/第1章-无线通信导论#终端硬件约束|第 1 章的多模-低功耗-小型化三角矛盾]] 是同一类问题——理论最优策略在实践中被复杂度上限约束。动态资源分配代表了复杂度换取效率的极端点，其演进将决定蜂窝容量增长的上限。

# 15.4 区域频谱效率（Area Spectral Efficiency）

## 概念引入

第 14 章的多用户容量假设多用户通过正交（FDMA/TDMA）或半正交（CDMA）方式共享同一频段。在实际地理区域上，频谱效率可通过**在不同空间位置的小区复用相同的频率/时隙/码字**进一步提升——利用信号功率随距离衰减来减小小区间干扰的影响。

小区间干扰的大小取决于两个因素：
1. **复用距离 $R_D$**：使用相同资源的两个基站之间的最小距离
2. **传播规律**：控制干扰信号传输的路径损耗法则和功率自适应策略

## 区域频谱效率的定义

区域频谱效率（area spectral efficiency）$A_e$ = 单位面积、单位带宽支持的总比特率：

$$A_e = \frac{\sum_{i=1}^{N} R_i / B}{\pi (0.5 R_D)^2} \quad \text{(bps/Hz/unit area)} \tag{15.3}$$

其中 $R_i$ 是第 $i$ 个用户的速率/容量，$B$ 是总带宽，分母是分配给该组资源的近似覆盖面积。

$R_i$ 取决于该用户的接收信号-干扰比 $\gamma_i = S_i/I_i$：
- $\gamma_i$ 恒定 → $R_i = C_i = B_i \log(1+S_i/I_i)$（AWGN 容量）
- $\gamma_i$ 时变 → $R_i = B_i \int \log(1+\gamma_i) p(\gamma_i) d\gamma_i$（遍历容量）

也可定义为给定系统参数（调制、编码、分集、目标 BER）下的最大可能速率。

## 优化问题与核心挑战

### 复用距离的最优选择

- $R_D$ 增大 → 干扰减小 → 每个用户的速率 $R_i$ 增加 → 但覆盖面积 $\propto R_D^2$ 也增大
- 分子和分母都随 $R_D$ 增大 → **存在最优复用距离**最大化 $A_e$

### 功率控制的全局优化困境

增大某用户的信号功率 → 该用户速率提升 → 但对所有其他用户的干扰也增加 → 其他用户速率下降。

⚡ **最优化单个用户速率的功率控制策略 ≠ 最优化区域频谱效率的策略**。这是一个全局优化问题，依赖于：
- 频谱划分方式（FDMA/TDMA/CDMA）
- 传播特性
- 系统布局
- 用户数量

**多小区系统的全局最优功率控制仍是开放问题**——将所有系统特性纳入分析的优化过于复杂。

### CIS 分布的可获得性

$\gamma_i$ 的分布 $p(\gamma_i)$ 在 CDMA + 高斯干扰假设 + 信道反转功率控制下已有解析结果 $[1, 2, 3]$ 和仿真结果 $[4, 5]$。但其他功率控制策略、FDMA/TDMA 下的 $p(\gamma_i)$ 尚未确定。

一旦获得这些分布，可用区域频谱效率框架对不同功率控制策略和频谱划分方法做全面比较。

> 本节是 15.5–15.7 的概念预览。完整推导和计算见 15.5 节。

- **15.5 节**：干扰模型、复用距离优化、单小区效率计算示例（FDMA + 无功率控制）
- **15.6 节**：功率控制对小区内和小区间干扰的定性影响
- **15.7 节**：干扰缓解方法——天线扇区化、话音激活监测、干扰消除

⚡ 所有多小区系统的共性：**干扰受限 → 任何降低干扰的技术直接转化为容量提升**。这一原则贯穿 15.5–15.7 的所有讨论。

# 15.5 干扰模型与小区效率计算

## 15.5 干扰模型

蜂窝系统是干扰受限的——接收机噪声功率 $\ll$ 干扰功率 → 噪声可忽略。

**干扰分布假设**：
- **CDMA**：大量小区内 + 小区间干扰源 → 大数定律 → 高斯分布假设合理
- **FDMA/TDMA**：通常只有同信道小区的第一层（first tier）中少数几个主要干扰源 → 高斯假设**不总是有效**。前向链路上靠近小区边界的一两个终端通常主导干扰；反向链路上至多 6 个干扰基站

⚡ 但容量计算中，所有用户（期望信号和干扰）的**容量可达分布均为高斯** → 将干扰建模为高斯噪声用于容量计算，对所有划分方式都是可接受的。

## 15.5.1 复用距离、多小区容量与区域效率

### 复用距离 $R_D$

$R_D$ = 使用相同码字/频率/时隙的任意两个基站之间的**最小距离**。

给定 $R_D$ 下每组资源覆盖的面积 ≈ $\pi(0.5 R_D)^2$。$R_D$ 越大 → 资源利用效率越低；$R_D$ 减小 → 小区间干扰增加 → 每小区容量域缩小。

### 多小区容量

$$C_{\text{multicell}} = \frac{(R_1, R_2, \dots, R_N) / B}{\pi (0.5 R_D)^2} \tag{15.2}$$

$(R_1, \dots, R_N)$ 是小区内所有用户可同时维持的最大速率集合。该集合随其他小区的干扰增加而单调减小——干扰通常与 $R_D$ 成反比。

### 区域频谱效率

$$A_e = \frac{\sum_{i=1}^{N} R_i / B}{\pi (0.5 R_D)^2} \quad \text{(bps/Hz/unit area)} \tag{15.3}$$

$R_i$ 是第 $i$ 个用户的容量或可达速率，取决于 $\gamma_i = S_i/I_i$：
- $\gamma_i$ 恒定 → $R_i = B_i \log(1 + S_i/I_i)$
- $\gamma_i$ 时变 → $R_i = B_i \int \log(1+\gamma_i) p(\gamma_i) d\gamma_i$（遍历容量）
- 或定义为给定系统参数（调制/编码/分集/BER 目标）下的最大可能速率

### $\gamma_i$ 分布的获取难度

$p(\gamma_i)$ 在真实多小区系统中极难获得——它依赖于：
- 期望信号和**所有干扰源**的功率控制策略
- 期望信号和干扰源的**信道变化**

**已知结果**：
- CDMA + 高斯干扰 + 信道反转功率控制 → $p(\gamma_i)$ 已有解析 $[1, 2, 3]$ 和仿真 $[4, 5]$
- CDMA + 其他功率控制策略 → **未知**
- FDMA/TDMA + 任何形式功率控制 → **未知**

⚡ 一旦获得这些分布，可对不同功率控制策略和频谱划分方法做全面区域效率比较——这是统一评估框架的核心价值。

## 15.5.2 效率计算示例

以下示例均在简化假设下给出解析公式：忽略噪声、衰落、阴影和用户移动性，所有用户和干扰源固定位置。

### 示例 1：FDMA，无功率控制，最悲观几何

假设：所有用户位于小区边界，所有干扰源位于最靠近目标小区的边界。传播模型：小区内 $K d^{-2}$，小区外 $K d^{-\gamma}$（$2 \leq \gamma \leq 4$）。

发射功率恒定 $S$ → $S_i = S K R^{-2}$，$I_i = 6 S K (R_D - R)^{-\gamma}$。

$$C_i = \frac{B}{N} \log\left(1 + \frac{(R_D - R)^\gamma}{6 R^2}\right) \tag{15.5}$$

$$A_e = \frac{\log\left(1 + \frac{(R_D - R)^\gamma}{6 R^2}\right)}{\pi (0.5 R_D)^2} \tag{15.6}$$

> 【插入 Goldsmith 图 15.5】FDMA 区域效率（$\gamma = 4$）
> 【插入 Goldsmith 图 15.6】FDMA 区域效率（$\gamma = 2$）

**观察**：$\gamma$ 更小（干扰传播衰减更慢）→ 区域效率降低 → 最优 $R_D$ 也减小（需要更紧密的复用）——这个结果有些反直觉。

### 示例 2：干扰源不完全位于边界

若干扰源距其基站 $R/2$：

$$A_e = \frac{\log\left(1 + \frac{(R_D - R/2)^\gamma}{6 R^2}\right)}{\pi (0.5 R_D)^2} \tag{15.7}$$

> 【插入 Goldsmith 图 15.7】干扰源距离 $R_D - R/2$

区域效率比图 15.5 更高，最优复用距离更小——预期之内：干扰源离得更远 → 干扰更弱。

### 示例 3：信道反转功率控制

回到最悲观几何（所有用户在边界）。信道反转让接收信号功率恒为 $S_i = S\rho$。干扰功率受功率控制影响：

$$I_i = 6 S \rho \,[R^2/K]\,[K(R_D - R)^{-\gamma}]$$

**令人惊讶的结果**：

$$\frac{S_i}{I_i} = \frac{(R_D - R)^\gamma}{6 R^2} \tag{15.8}$$

与无功率控制**完全相同**！

⚡ 原因：**对称性**——期望用户和干扰用户有完全相同的传播损耗和干扰条件 → 两者施加相同的功率控制 → 功率控制的效应在分子和分母中相互抵消。

但这一对称性在干扰源距基站更近时被打破。

### 示例 4：信道反转 + 干扰源更近

干扰源距其基站 $R/2$：

$$I_i = 6 S \rho \,[(R/2)^2/K]\,[K(R_D - R/2)^{-\gamma}] \tag{15.9}$$

$$A_e = \frac{\log\left(1 + \frac{(R_D - R/2)^\gamma}{6 (R/2)^2}\right)}{\pi (0.5 R_D)^2} \tag{15.10}$$

> 【插入 Goldsmith 图 15.8】信道反转功率控制（$\gamma = 4$）

与图 15.5（无功率控制）对比 → 信道反转在此几何下**区域效率更高**。说明功率控制的效用高度依赖具体几何布局。

### 示例 5：扩频（CDMA）+ 信道反转

仅考虑小区内干扰（忽略小区间干扰 → 给出下界）。

接收信号功率 $S\rho$。干扰 = 小区内 + 小区间：

$$I_{\text{总}} = \frac{S(N-1)}{G} + \frac{6S}{G} \sum_{i=1}^{N} \frac{(R_D - R_i)^{-\gamma}}{R_i^2} \tag{15.12}$$

其中 $G$ 为扩频增益（互相关倒数）。

若仅考虑小区内干扰（$R_D = 2R$，每小区复用所有码字，$N$ 大），则 $S_i/I_i \approx (N-1)/G \approx 1$：

$$A_e = \frac{\log(1+1)}{\pi(0.5 \cdot 2)^2} = \frac{1}{\pi} = 0.318 \tag{15.14}$$

若加入经验观测值——小区外干扰 ≈ 小区内干扰 → $A_e = \log(1.5)/\pi = 0.186$。

⚡ CDMA 仅靠小区内干扰的下界效率已与 FDMA 最差干扰场景可比。这体现了扩频对干扰的内在容忍度。

### 注水功率控制的评注

在完全对称的边界几何下，注水与信道反转给出相同效率（对称性取消）。但干扰源更近 → 干扰源会增加其功率 → 不再清楚**最差干扰场景**是什么。

# 15.6 功率控制对干扰的影响

> 【插入 Goldsmith 图 15.9】干扰效应示意

本节定性讨论单用户功率控制策略对小区内和小区间干扰的影响。

### 前向链路（移动台 → 基站）的小区内干扰

仅出现在 CDMA（FDMA/TDMA 每频/时隙仅一个用户）。

**近-远效应**：$A_1$ 近、$A_2$ 远 → 无功率控制时 $A_1$ 接收信号远强于 $A_2$ → $A_1$ 对 $A_2$ 的干扰即使在解扩后仍很强。

| 功率控制策略 | 小区内干扰效应 |
|-------------|---------------|
| **信道反转（等接收功率）** | 所有用户接收功率相同。SINR = 扩频增益。公平但对远近用户一视同仁 |
| **注水（Water-Filling）** | 信道好（$A_1$ 近）→ 功率**增加**；信道差（$A_2$ 远）→ 功率**降低**。**递归恶化**：$A_1$↑ → $A_2$ 干扰↑ → $A_2$↓ → $A_1$ 干扰↓ → $A_1$ 再↑ → … |

⚡ **注水在小区内的灾难性后果**：递归效应将移除小区内除最佳信道用户外的所有用户。如果所有用户需要**保证速率**→ 注水不可接受。但若用户可容忍长时间静默 + 偶尔极高数据率突发（分组无线系统）→ 注水可能有更高的吞吐量。

### 前向链路的小区间干扰

来自小区 B 的干扰源 $B_1$（近邻小区边界）和 $B_2$（靠近 B 基站）：

| 功率控制策略 | 边界干扰源 $B_1$ | 近基站干扰源 $B_2$ | 净效果 |
|-------------|----------------|-------------------|--------|
| **无功率控制** | 信号强（近 A 边界） | 信号弱（远） | 边界干扰源主导 |
| **信道反转** | 功率**提高**（距 B 基站远）→ 对 A 干扰**更强** | 功率降低 → 干扰弱 | **放大**边界干扰 |
| **注水** | 功率**降低**（信道差，因距 B 基站远）→ 干扰**弱** | 功率提高 → 干扰强 | 所有干扰源对 A 干扰**大致均等** |

⚡ **注水显著降低前向小区间干扰**——因为主要干扰源通常在小区边界，而注水恰好降低这些用户的功率。这是注水在小区内"自毁"行为的对称补偿。

### 反向链路（基站 → 移动台）

**小区内干扰**：信号和干扰均从基站发出 → 两者到小区内任意点的路径损耗相同 → 无需功率控制来均衡接收信号强度（等效于"无功率控制就是信道反转"）。

注水的递归效应与前向链路相同：基站向信道好的用户发更高功率 → 干扰信道差的用户 → 递归。

**小区间干扰**：基站向 $B_1$ 和 $B_2$ 以相同功率发射 → 两者对 A 的耦合功率相同（与位置无关）。注水下基站向远用户发更高功率 → 但干扰信号到 A 内终端的路径损耗相同 → 难以判断哪种策略造成更严重的小区间干扰。

### 功率控制策略对比总结

| | 信道反转 | 注水（Water-Filling） |
|------|----------|---------------------|
| 小区内（前向） | 公平、等 SINR | 递归自毁——移除除最佳用户外的所有人 |
| 小区间（前向） | 放大边界干扰（边界用户升功率） | 降低边界干扰（边界用户降功率） |
| 小区内（反向） | 天然实现 | 同前向：递归 |
| 小区间（反向） | 难以判断 | 难以判断 |

⚡ 没有一种功率控制策略在所有维度上都最优——**全局最优功率控制策略依赖于对各维度（小区内/小区间、前向/反向）权重的设计选择**。

# 15.7 干扰缓解

## 核心原则

**任何降低干扰而不减少用户数或增大复用距离的技术 → 直接提升容量**。

## 三种干扰缓解技术

### 1. 话音选通（Speech Gating / Voice Activity）

双工语音传输中每方实际说话时间仅约 40% $[6]$。

**机制**：监测语音激活 → 无语音时抑制发射 → 小区内和小区间干扰的平均功率降低 $\rho$ 倍（$\rho$ = 语音激活比 ≈ 0.4）。

⚡ 这是"利用业务特征降低干扰"的经典实例——物理层的收益来自应用层的特性。跨层设计的雏形。

### 2. 天线扇区化（Antenna Sectorization）

**机制**：基站使用定向天线替代全向天线。将 360° 分为 $N_S$ 个扇区，每个扇区用 $120°$ 波束方向性天线覆盖。

每个定向天线看到的干扰源 = 全向天线看到干扰源的 **$1/N_S$** → 总干扰功率降低 $N_S$ 倍。

⚡ 扇区化是空间滤波在蜂窝系统中最直接的实现——用方向性带来的干扰隔离换取容量增益。与 [[Goldsmith-无线通信/第10章-MIMO系统#10.3 智能天线（Smart Antennas）|第 10 章智能天线]] 的思想一致：利用空间维度隔离干扰。

### 3. 多用户检测（Multiuser Detection，CDMA 专用）

接收 CDMA 信号 = 各用户信号的叠加。多用户检测器**联合检测**所有用户的数据序列——若干扰的数据序列已知，可从期望信号中减去。

#### 最优检测器（Verdú $[8]$）

匹配滤波器组 + Viterbi 算法 → ML 或最小误码率检测。

**致命弱点**：复杂度随干扰用户数**指数增长** → 对干扰源多的系统不切实际。还需信号能量知识（不总是可得）。

#### 次优检测器

| 类型 | 原理 | 复杂度 | 代价 |
|------|------|--------|------|
| **去相关器** $[9, 10]$ | 线性变换消除多用户干扰 | 用户数线性 | 不需能量知识 |
| **多级检测器** $[11, 12]$ | 按接收功率从强到弱串行检测 → 逐级减去已检测信号 | 用户数线性（但更高） | 性能优于去相关器 |
| **判决反馈检测器** $[13]$ | 前向 + 反馈滤波器消除干扰 | 中等 | **误差传播**（错误判决级联） |

**串行干扰消除（Successive Interference Cancellation, SIC）**的步骤：
```
检测最强信号（其他全当噪声）→ 从总接收信号中减去 → 检测次强剩余信号 → ... → 全部估计完成
```

⚡ 多用户检测将"干扰"重新定义为"已知结构的信号"——认知的改变带来处理方式的改变。这是 CDMA 系统区别于 FDMA/TDMA 的核心优势：前者可将干扰转化为结构性信息并消除，后者只能将其视为噪声。

上述检测器为 AWGN 信道设计，衰落信道下的多用户检测是后续研究方向 $[14, 15]$。
