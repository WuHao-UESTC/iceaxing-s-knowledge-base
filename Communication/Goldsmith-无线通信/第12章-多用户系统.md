# 第12章 多用户系统

> 第 6 章研究了单用户在 AWGN 和衰落信道下的调制性能。本章的核心问题：**当多个用户共享同一频谱资源时，如何分配和协调？** 主要工具是多载波调制（OFDM）和扩频多址（第 13 章）。

---

# 12.1 正交频分复用（OFDM）

## 基本思想

多载波调制的最简形式：将高速数据流分解为 $N$ 个低速子流，分别在 $N$ 个正交子载波上并行传输。核心参数选择：

$$B_N = \frac{B}{N} \ll B_c$$

其中 $B_N$ 为子信道基带带宽，$B_c$ 为相干带宽。当 $B_N \ll B_c$ 时，每个子信道经历**平坦衰落**（而非频率选择性衰落）→ ISI 几乎完全消除。

> ⚡ OFDM 的根本洞察：**用带宽换符号时间**。$N$ 个子载波 → 每个子载波的符号时间 $T_N \approx N \cdot T_s$（单载波符号时间）。$T_N$ 远大于信道延迟扩展 $\sigma_{T_m}$ → 符号间不再重叠。带宽扩展为 0（总带宽不变），但 ISI 被消除。

## 非重叠子载波

子载波频率：$f_n = f_c + n(2B_N),\ n = 0,\dots,N-1$。每个子信道通带带宽 $2B_N$，总通带带宽 $N \cdot 2B_N = 2B$。

发射信号（一个符号时间内）：

$$s(t) = \Re\!\left\{\sum_{n=0}^{N-1} s_n g(t) e^{j 2\pi f_n t}\right\} \tag{12.1}$$

$s_n$ 为第 $n$ 个子载波上的复符号（通常 MQAM 或 MPSK），$g(t)$ 为脉冲成形。对于升余弦脉冲，$T_N = 0.5(1+\beta)/B_N$。

每个子流数据速率 $R_N = R/N$，总速率 $N \cdot R_N = R$，总带宽不变。

> 非重叠子载波本质上是**频分复用（FDM）**。优点：频率偏移和定时抖动对正交性影响小。缺点：频谱效率低——每个子信道之间有保护间隔。

## 重叠子载波：频谱效率翻倍

### 正交性条件

基带子载波 $\{\cos(2\pi j t/T_N),\ j=1,2,\ldots\}$ 在区间 $[0, T_N]$ 上构成正交基。**不可能用更小的频率间隔构建 $[0, T_N]$ 上的正交子载波集**——最小正交频率间隔为 $1/T_N$。

对于升余弦脉冲 $\beta = 1$，$T_N = 1/B_N$ → 子载波间隔只需 $B_N$。但每个子信道通带带宽为 $2B_N$ → 子载波发生重叠。

> 【插入 Goldsmith 图 12.2】重叠子载波 OFDM 频谱示意

### 解调：利用正交性分离

重叠子载波的解调通过相关接收实现。以同相分量为例（假设矩形脉冲）：

$$\begin{aligned} \hat{s}_i &= \frac{1}{T_N} \int_0^{T_N} \left(\sum_{j=0}^{N-1} s_j \cos(2\pi f_j t)\right) \cos(2\pi f_i t) dt \\ &= \frac{1}{2T_N} \sum_{j=0}^{N-1} s_j \left[ \int_0^{T_N} \cos(2\pi(j-i)t/T_N) dt + \int_0^{T_N} \cos(2\pi(2f_c + j + i)t/T_N) dt \right] \\ &\approx \frac{1}{2} \sum_{j=0}^{N-1} s_j \delta(j-i) = \frac{1}{2}s_i \end{aligned} \tag{12.2}$$

第二个积分在 $f_c \gg 1/T_N$ 时 ≈ 0（高频项）。第一个积分：$j \neq i$ 时余弦在一个完整周期上积分为 0 → $\delta(j-i)$。

> 【插入 Goldsmith 图 12.3】OFDM 重叠子载波接收机

### 双倍的频谱效率——但有代价

重叠子载波的频谱效率是**非重叠方案的两倍**（子载波间距减半），但正交性对以下因素敏感：

- **定时抖动** — 破坏符号区间 $[0, T_N]$ 的精确对齐
- **频率偏移** — 破坏 $f_n = f_c + n/T_N$ 的精确关系 → 子载波间干扰（ICI）
- **衰落** — 信道时变 → 多普勒扩展 → 子载波正交性被破坏

> ⚡ 重叠子载波的脆弱性是 OFDM 系统设计的核心挑战——频率同步的精度直接决定性能上限。这也是为什么 OFDM 需要导频子载波做频率跟踪。

# 12.2 OFDM 的离散实现（离散多音 DMT）

## 历史与动机

OFDM 在 1950 年代被发明，但**每个子信道需要独立的调制器/解调器**——在当时过于复杂。20 年后 FFT/IFFT 的发展 + OFDM 可用 FFT 高效实现的发现 → OFDM 广泛部署。离散实现称为**离散多音调制**（Discrete Multitone, DMT）。

> 核心洞察：OFDM 的发射信号 (12.1) 本质上是 $N$ 个频域符号的 IFFT → 用一块 IFFT 芯片替代 $N$ 个独立调制器。这是工程实现的革命。

## DMT 发射机

> 【插入 Goldsmith 图 12.4】DMT 收发机框图

**发射链路**：QAM → 串并转换 → IFFT → 加循环前缀 → 并串转换 → D/A → 上变频

**关键步骤**：

1. **QAM 调制**：输入比特 → 复符号 $X_k$
2. **串并转换**：生成 $N$ 个并行的 QAM 符号 $\{X_0, \ldots, X_{N-1}\}$——这些就是 OFDM 信号的**离散频域分量**
3. **IFFT**：将频域符号转为时域采样

$$x_n = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} X_k e^{j 2\pi n k/N}, \quad n = 0, 1, \ldots, N-1 \tag{12.4}$$

4. **D/A 转换后**的基带 OFDM 信号：

$$x(t) = \frac{1}{\sqrt{N}} \sum_{k=0}^{N-1} X_k e^{j 2\pi k t/T_N}, \quad 0 \leq t \leq T_N \tag{12.5}$$

子载波频率 $f_i = i/T_N$，采样间隔 $T_N/N$。

## 循环前缀（Cyclic Prefix, CP）

### 为什么需要 CP

即使 $B_N \ll B_c$ 消除了大部分 ISI，信道延迟扩展的残余效应仍可能导致符号间干扰。**完全消除 ISI** 需要知道最大延迟扩展。

### CP 的操作

设信道最大延迟扩展为 $\mu$ 个采样（即 $\mu T_N/N$ 秒）。

1. 取 IFFT 输出的**最后 $\mu$ 个采样** $\{x_{N-\mu}, \ldots, x_{N-1}\}$
2. 将它们**附加到数据块开头** → 新序列为 $\{x_{N-\mu}, \ldots, x_{N-1}, x_0, x_1, \ldots, x_{N-1}\}$
3. 序列总长度从 $N$ 增加到 $N + \mu$

### CP 的数学魔力

无噪声时接收信号为 $r(t) = x(t) * c(t)$。采样信道冲激响应得 $\{c_0, \ldots, c_\mu\}$。将发射序列（含 CP）与信道卷积 → 接收序列长度 $N + \mu$。

接收端**去掉前 $\mu$ 个采样**（CP 部分）后 → 输入 FFT 的是 $\{x_n\}$ 与 $\{c_n\}$ 的**循环卷积**（circular convolution）。

> ⚡ **CP 的核心作用**：将信道的线性卷积转换为循环卷积。循环卷积在频域等价于乘法：
> $$\hat{X}_k = C_k \cdot X_k$$
> 其中 $C_k$ 是 $\{c_n\}$ 的 FFT（即第 $k$ 个子载波上的信道频率响应）。

这意味着**每个子载波上的信道效应简化为一个复数乘法**——子载波之间完全解耦，没有 ICI。

## 频域均衡

在无噪声情况下，只需 $\hat{X}_k / C_k = X_k$ 即可完美恢复。有噪声时：

$$\hat{X}_k = C_k X_k + N_k$$

乘以 $1/C_k$ 恢复 $X_k$，但会**增强噪声**——当 $C_k$ 很小（深衰落子载波）时，$N_k/C_k$ 被放大。

> 这就是为什么仅靠频域均衡不够——需要编码、自适应加载等手段补偿深衰落子载波。12.3 节将展开这些技术。

## DMT 与 OFDM 的实质等同

| 概念 | OFDM 表述 | DMT 表述 |
|---|---|---|
| 子载波调制 | $N$ 个独立模拟调制器 | 一个 IFFT 模块 |
| 子载波解调 | $N$ 个独立相关接收机 | 一个 FFT 模块 |
| 正交通道 | 子载波频率间隔 $1/T_N$ | FFT 的固有正交性 |
| 抗 ISI | 大 $T_N$ 超越延迟扩展 | CP 将线性卷积变为循环卷积 |

DMT 不是"另一种技术"——它就是 OFDM 的高效数字实现。现代所有 OFDM 系统（Wi-Fi、LTE、5G）都用 DMT 架构。

# 12.3 子载波间的衰落

## 问题

OFDM 用窄带子信道**消除 ISI**，但每个子信道经历**平坦衰落**——有些子载波的 SNR 极低 → 高 BER。具体地，子载波 $i$ 的接收 SNR：

$$\gamma_i = \frac{P_i \alpha_i^2}{N_0 B}$$

若 $\alpha_i$（信道增益）很小 → $\gamma_i$ 很低 → 子载波 $i$ 的 BER 不可接受。

> 这正是第 6 章研究过的平坦衰落问题——只不过现在有 $N$ 个并行的平坦衰落子信道。**OFDM 把频率选择性衰落转化为一组平坦衰落子信道，然后逐个面对平坦衰落的困境。**

四种应对策略：频率均衡、预编码、自适应加载、子信道间编码。

---

## 12.3.1 频率均衡

接收端将信号乘以 $1/\alpha_i$ 以**反转衰落**：

- 信号功率：$P_i \alpha_i^2 \to P_i \alpha_i^2 / \alpha_i^2 = P_i$（恢复）
- 噪声功率：$N_0 B \to N_0 B / \alpha_i^2$（**放大**）

$$\mathrm{SNR}_{eq} = \frac{P_i}{N_0 B / \alpha_i^2} = \frac{P_i \alpha_i^2}{N_0 B} = \gamma_i$$

> 均衡前后 SNR **完全相同**——所以频率均衡不改变子载波间的性能差异。它只是一个"数值整理"操作（恢复发射星座尺度），不改善深衰落子载波的 SNR。

---

## 12.3.2 预编码

**思路**：不在接收端反转衰落，而在发射端预先补偿——发射功率设为 $P_i / \alpha_i^2$，信道衰减 $\alpha_i^2$ 后接收功率恰好为 $P_i$。

与频率均衡的关键区别：**噪声在接收端自然引入，不经历任何放大** → 噪声功率保持 $N_0 B$，实际 SNR 不变（与均衡相同）。

预编码在**有线**多载波系统（如 HDSL）中常见，但在**无线**环境中面临两个问题：

1. **信道反转在衰落中功率效率极低**。Rayleigh 衰落下，$\mathbb{E}[1/\alpha^2] \to \infty$——平均发射功率无界。（回顾 [[Goldsmith-无线通信/第6章-数字调制与检测#6.3 衰落信道|6.3 节]]：深衰落时 $\alpha \to 0$ → 需要无限功率反转。）

2. **需要发射端信道状态信息（CSIT）**。无线信道快速时变 → 发射端获取的信道估计可能已过时。这与自适应调制面临同样的问题（[[Goldsmith-无线通信/第9章-自适应调制与编码|第 9 章]]）。

> ⚡ 预编码在无线 OFDM 中几乎不单独使用——要么与自适应加载结合（给好子信道多分功率），要么与编码结合（用编码弥补深衰子信道）。纯信道反转在 Rayleigh 衰落下是灾难性的。

---

## 12.3.3 自适应加载

### 基本思想

自适应加载是[[Goldsmith-无线通信/第9章-自适应调制与编码|第 9 章自适应调制]]在多载波系统中的推广：根据每个子信道的增益 $\alpha_i$，**动态分配功率和速率**。需要发射端知道 $\{\alpha_i\}$。

### 容量最大化——注水法

多载波系统容量（$N$ 个子信道，基带带宽 $B_N$）：

$$C = \sum_{i=1}^{N} B_N \log\!\left(1 + \frac{\alpha_i^2 P_i}{N_0 B_N}\right) \tag{12.6}$$

总功率约束 $\sum_i P_i = \overline{P}$。这与[[Goldsmith-无线通信/第4章-信道容量|第 4.3 节]]的优化问题完全相同 → 最优功率分配是**注水法**（water-filling）：

$$\frac{P_i}{\overline{P}} = \begin{cases} \frac{1}{\gamma_0} - \frac{1}{\gamma_i} & \gamma_i \geq \gamma_0 \\ 0 & \gamma_i < \gamma_0 \end{cases} \tag{12.7}$$

其中 $\gamma_i = \alpha_i^2 \overline{P} / (N_0 B_N)$。截止值 $\gamma_0$ 由功率约束确定。

对应的容量：

$$C = \sum_{i: \gamma_i \geq \gamma_0} B_N \log(\gamma_i / \gamma_0) \tag{12.8}$$

**注水的物理含义**：$\gamma_i$ 高的子信道（"水浅"→ 信道好）分配更多功率；$\gamma_i < \gamma_0$ 的子信道（"水深"→ 信道太差）干脆不用。这与直觉一致——把功率集中在好信道上。

### 速率最大化——MQAM 的变速率变功率

将第 9 章的变速率变功率 MQAM 应用于子信道。总数据速率：

$$R = B_N \sum_{i=1}^{N} \log(1 + K \gamma_i P_i / \overline{P}) \tag{12.9}$$

其中 $K = -1.5 / \ln(5\,\mathrm{BER})$。最优功率分配：

$$\frac{P_i}{\overline{P}} = \begin{cases} \frac{1}{\gamma_0} - \frac{1}{K\gamma_i} & \gamma_i \geq \gamma_0/K \\ 0 & \gamma_i < \gamma_0/K \end{cases} \tag{12.10}$$

对应数据速率：

$$R = B_N \sum_{i: \gamma_i \geq \gamma_0/K} \log(K\gamma_i / \gamma_0) \tag{12.11}$$

**与容量注水的区别**：MQAM 的功率分配中，截止门限多了一个 $K$ 因子——因为 MQAM 需要一定的 SNR 余量来维持目标 BER，不像理想容量可以无限接近 Shannon 限。

> ⚡ 自适应加载是 OFDM 的"杀手级"优化——它将频率选择性衰落从障碍变为机会：好子信道多传比特，差子信道少传或不传。这比单载波系统的自适应调制更灵活——单载波只有一个 SNR，OFDM 有 $N$ 个可独立优化的 SNR。

### 实际考虑

- 自适应加载需要接收端估计所有子载波的 SNR，并将其反馈给发射端
- 反馈延迟 → CSI 过时 → 性能退化。慢变信道（室内、步行速度）中效果最好
- 快速变化的信道中，自适应加载的收益被反馈延迟抵消 → 此时编码跨子信道更有效

## 12.3.4 子信道间编码

### 基本思路

将输入比特编码为长度 $N$ 的码字（$N$ = 子信道数），每个编码比特在**不同子载波**上传输。大多数子信道 SNR 高（正确接收），少数差子信道产生的错误被纠错码纠正。

> 直觉：编码跨 $N$ 个独立子信道 → **频率分集**。深衰落子信道造成的局部错误被分散在码字中 → 可纠正。

### 适用条件

- 只在**延迟扩展大**（相干带宽 $B_c \approx$ 子信道带宽 $B_N$）时有效 → 各子信道**独立衰落** → 频率分集增益最大
- 若 $B_c$ 大（平坦衰落信道）→ 所有子信道相关性高 → 编码几乎无益（所有子载波同时深衰）

### 与其他三种技术的本质区别

| 技术 | 本质 | 利用多载波特性？ |
|---|---|---|
| 频率均衡 | 平坦衰落补偿 | ❌（也可用于单载波） |
| 预编码 | 平坦衰落补偿 | ❌（也可用于单载波） |
| 自适应加载 | 平坦衰落补偿 | ❌（也可用于单载波） |
| **子信道间编码** | **频率分集** | ✅ **利用所有子载波数据的并行处理特性** |

> ⚡ 前三种技术将 OFDM 的 $N$ 个子信道当作 $N$ 个独立的问题分别解决。编码跨子信道是唯一**将 $N$ 个子信道视为一个整体**来利用的技术——它不需要 CSI 反馈，也不增强噪声，只需保证子信道间有足够的频率分集（即信道是频率选择性的）。这正是 OFDM 在广播（DVB-T）和蜂窝下行链路中的核心优势。
