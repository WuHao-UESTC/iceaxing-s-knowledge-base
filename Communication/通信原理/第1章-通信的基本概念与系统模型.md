# 1.1 通信的基本概念

## 1.1.1 通信的发展

**通信**（communication）是发送者与接收者之间通过某种媒体进行的信息传递。从烽火台到电报、电话、互联网，手段在变，本质不变——信息跨越空间传输。

**电信**（telecommunication）是利用电信号传输信息的通信方式。1837 年莫尔斯有线电报开创电信时代。此后关键节点：

- 1876：贝尔发明电话
- 1918：调幅无线电广播
- 1936：商业电视广播
- 1983：蜂窝移动通信网（美国），1987 年广州开通
- 1983：ARPANET 分裂为民网，演化为今日互联网

如今"通信"一般指电信。光通信也属于电信——光即电磁波。本书讨论的通信均指电信。

## 1.1.2 消息、信息与信号

三个概念层层嵌套，是理解通信系统的基础。

**消息**（message）是通信系统传输的对象，是信息的载体。分为两类：

- **连续消息**：状态连续变化、不可数，如语音、温度数据
- **离散消息**：有限个可数状态，如符号、文字、数字数据

**信息**（information）是消息中包含的有效内容。消息是信息的物理表现形式，信息是消息的内涵。例如，天气预报语音是消息，天气状况是信息。通信的核心任务：有效而可靠地传输信息。

**信号**（signal）是消息的传输载体。在电信中，信号是电信号——将消息载荷在电信号的某个参量上（如正弦波的幅度、频率、相位；脉冲波的幅度、宽度、位置）。对应消息的分类，信号也分为两类：

**模拟信号**（analog signal）：载荷消息的信号参量取值连续、不可数、无穷多。关键：连续指**参量取值连续**，不一定时间连续——抽样信号在时间上离散，但幅度取值连续，仍是模拟信号。

**数字信号**（digital signal）：载荷消息的信号参量只有有限个取值。最典型的是二值信号。**码元**（symbol）表示一个符号的电波形，占用一定的时间和带宽。

消息与电信号的转换由传感器完成：话筒（声→电）、摄像机（光→电）、热敏电阻（温度→电）等。

三者关系：
- 消息是信息的物理形式
- 信息是消息的有效内容
- 信号是消息的传输载体

由此，**电信 = 利用电信号传输消息中所包含的信息**。

# 1.2 通信系统模型

## 1.2.1 通信系统一般模型

通信系统的作用是将信息从信源发送到目的地。一般模型概括了任何通信系统的共性：

> 【插入 通信原理 图 1-3】通信系统一般模型

五个组成部分：

**1. 信息源（信源）**：将消息转换成原始电信号。
- 模拟信源：话筒（声→音频）、摄像机（图像→视频）
- 数字信源：电传机、计算机等数字终端
- 模拟信源经数字化处理后也可输出数字信号

**2. 发送设备**：将原始电信号变换为适合信道传输的形式。核心功能：
- 匹配信道特性
- 赋予抗干扰能力
- 提供足够功率以支持远距离传输
- 包含变换、放大、滤波、编码、调制等；多路传输时还包含多路复用器

**3. 信道**：信号传输的物理媒质。
- 无线信道：自由空间
- 有线信道：明线、电缆、光纤
- 信道既传输信号，也引入干扰和噪声——信道的固有特性直接决定通信质量
- 噪声源是分散在各处噪声的集中表示，通常是随机的

**4. 接收设备**：从受损的接收信号中恢复原始电信号。功能与发送设备对称——放大、反变换（解调、译码），尽可能抑制噪声与干扰。

**5. 信宿**：消息的目的地，功能与信源相反——将电信号还原为消息（如扬声器）。

按信道中传输信号的类型，通信系统分为**模拟通信系统**和**数字通信系统**。

## 1.2.2 模拟通信系统模型

模拟通信系统包含**两种核心变换**：

> 【插入 通信原理 图 1-4】模拟通信系统模型

**第一种变换 — 消息 ↔ 基带信号**（由信源/信宿完成）：
连续消息 → 原始电信号，接收端反向变换。

**基带信号**（baseband signal）是原始电信号，频谱从零频附近开始。例如：语音 $300\text{ Hz} \sim 3400\text{ Hz}$，图像 $0 \sim 6\text{ MHz}$。

**第二种变换 — 基带 ↔ 带通**（由调制器/解调器完成）：
基带信号通常不能直接在无线信道中传输（自由空间天线无法高效辐射低频信号），需要通过**调制**将其搬移到高频，在接收端通过**解调**还原。

调制后的信号称为**已调信号**，满足：
1. 携带信息
2. 频谱具有带通形式（中心频率 $f_c$ 附近），因此又称**带通信号**

其他部件（滤波器、放大器、天线等）不使信号发生质变，在系统模型中被视为理想部件。因此**模拟通信的研究重点是调制/解调原理 + 噪声对信号传输的影响**（第 5 章）。在模型中，一般模型的发送设备与接收设备分别简化为调制器与解调器。

## 1.2.3 数字通信系统模型

> 【插入 通信原理 图 1-5】数字通信系统模型

数字通信系统的功能模块更多，反映数字传输对信号处理的额外需求。各模块及核心功能：

**1. 信源编码与译码**（Source Coding）— 两个基本功能：
- **提高有效性**：通过压缩编码减少码元数目，降低码元速率
- **A/D 转换**：模拟信源 → 数字信号，实现模拟信号的数字传输（第 10 章详细展开）

**2. 信道编码与译码**（Channel Coding）— 差错控制：
在信息码元中按规则加入监督码元（冗余），构成"抗干扰编码"。接收端按逆规则解码，发现或纠正错误，**提高可靠性**（第 11 章详细展开）。⸺ 这是数字通信相比模拟通信的独特优势。

**3. 加密与解密**：
人为扰乱数字序列（加密），接收端逆向恢复（解密），用于保密通信。数字信号天然适合加密——离散序列便于施加数学变换。

**4. 数字调制与解调**：
将数字基带信号频谱搬移到高频，形成适合信道传输的带通信号。基本方式：
- ASK（振幅键控）
- FSK（频移键控）
- PSK / DPSK（绝对/差分相移键控）

接收端可用相干解调或非相干解调还原。第 7、8 章重点讨论。

**5. 同步**（Synchronization）— 使收发两端在时间上步调一致，是数字通信**有序、准确、可靠的前提**。分类：
- 载波同步
- 位同步
- 群（帧）同步
- 网同步

详见第 13 章。

**重要补充**：
- 实际系统不一定包含所有环节。例如数字基带传输系统无需调制/解调（第 6 章）。
- 模拟信号经数字编码后可在数字通信系统中传输（如数字电话）；数字信号也可通过模拟电话网传输（需 Modem）。
- 这种双向兼容性是数字通信灵活性的体现。

## 1.2.4 数字通信的特点

数字通信已成为当代通信技术的主流。与模拟通信对比：

### 优点

**1. 抗干扰能力强，且噪声不积累。**
模拟通信要求接收端高度保真地重现原波形——噪声一旦叠加就无法消除。数字通信则不同：接收端只需从受扰信号中**判决**发送的是哪个离散状态（如二进制只有两个状态），不需要精确还原波形。远距离传输时，各中继站可利用**抽样判决再生**的方式，使数字信号再生——噪声不积累。

**2. 传输差错可控。**
通过信道编码加入冗余，接收端可检错与纠错，降低误码率。模拟通信无此能力。

**3. 便于数字信号处理。**
数字信号天然适配计算机和 DSP 芯片——处理、变换、存储、将不同信源信号综合传输。

**4. 易于集成。**
数字电路适合 VLSI 实现，设备微型化、轻量化。

**5. 易于加密，保密性好。**
离散序列便于施加数学加密变换。

### 缺点

**带宽需求更大**：一路模拟电话占用约 $4\text{ kHz}$，而同等语音质量的二进制数字电话可能需要 $20 \sim 60\text{ kHz}$。⸺ 约 5\~15 倍的带宽代价。这是数字通信最核心的 trade-off：用带宽换取可靠性和灵活性。

**对同步要求高，设备较复杂**。但随着 VLSI 技术进步，设备复杂度已不构成实际障碍；同时高效压缩编码和光纤等大容量传输媒介正逐步解决带宽问题。因此数字通信的应用持续扩大。

# 1.3 通信系统分类与通信方式

## 1.3.1 通信系统的分类

通信系统可以从六个维度进行分类：

### 1. 按通信业务
电报、电话、数据、图像等。电话通信网最为普及——电报和远距离数据常借助电话信道传输。综合业务数字通信网（ISDN）统一承载各类业务。

### 2. 按调制方式

**基带传输**：未经调制的信号直接传送，如市内电话、有线广播。

**带通传输**：信号经调制后再传输。常见调制方式：

| 类型     | 调制方式                 | 典型用途         |
| ------ | -------------------- | ------------ |
| 模拟调制   | AM (常规双边带)           | 广播           |
|        | DSB (双边带)            | 立体声广播        |
|        | SSB (单边带)            | 载波通信、无线电台    |
|        | VSB (残留边带)           | 电视广播、传真      |
|        | FM (频率调制)            | 微波中继、卫星通信、广播 |
|        | PM (相位调制)            | 中间调制方式       |
| 数字调制   | ASK (振幅键控)           | 数据传输         |
|        | FSK (频移键控)           | 数据传输         |
|        | PSK/DPSK/QPSK        | 数字微波、空间通信    |
|        | QAM, MSK             | 数字微波、空间通信    |
| 脉冲模拟调制 | PAM / PDM(PWM) / PPM | 遥测、中间调制      |
| 脉冲数字调制 | PCM                  | 市话、卫星通信      |
|        | DM ($\Delta$M)       | 数字电话         |
|        | DPCM, ADPCM          | 图像编码、中速数字电话  |

### 3. 按信号特征
模拟通信系统 / 数字通信系统。前节已述。

### 4. 按传输媒质
- **有线通信**：架空明线、同轴电缆、光导纤维、波导等
- **无线通信**：电磁波在空间传播——短波电离层传播、微波视距传播、卫星中继等

### 5. 按工作波段

波长—频率关系：$\lambda = \frac{c}{f} = \frac{3\times 10^8}{f}$

通信频段覆盖从极低频到可见光的极宽范围：

| 频段 | 名称 | 典型应用 |
|------|------|---------|
| 3~30 Hz | 极低频 ELF | 远程导航、水下通信 |
| 3~30 kHz | 甚低频 VLF | 远程导航、水下通信、声呐 |
| 30~300 kHz | 低频 LF | 导航、无线电信标 |
| 300 kHz~3 MHz | 中频 MF | 广播、海事通信 |
| 3~30 MHz | 高频 HF | 远程广播、电报、电话、业余无线电 |
| 30~300 MHz | 甚高频 VHF | 电视、调频广播、空中交通管制 |
| 0.3~3 GHz | 特高频 UHF | 电视、蜂窝网、GPS、卫星通信 |
| 3~30 GHz | 超高频 SHF | 卫星通信、雷达、微波链路 |
| 30~300 GHz | 极高频 EHF | 雷达着陆、卫星通信、移动通信 |
| 光波 | 红外/可见光/紫外 | 光通信系统 |

直观规律：频率越高，可用带宽越大，但传播损耗也越大、绕射能力越弱。低频适合远距离/水下，高频适合大容量/视距。

### 6. 按信号复用方式

三种基本复用：

- **频分复用**（FDM）：不同信号占据不同频率范围——频谱搬移实现
- **时分复用**（TDM）：不同信号占据不同时间区间——脉冲调制实现
- **码分复用**（CDM）：用正交编码分别携带不同信号——扩频/移动通信常用

模拟通信传统上用 FDM；数字通信的发展推动 TDM 普及；CDM 多用于空间通信和移动通信。此外还有波分复用（WDM）和空分复用（SDM）。

## 1.3.2 通信方式

通信方式指通信双方之间的工作方式或信号传输方式。从三个角度划分。

### 1. 单工、半双工和全双工通信

按消息传递方向与时间关系：

| 方式 | 英文 | 特点 | 例子 |
|------|------|------|------|
| 单工 | Simplex | 消息只能单方向传输，一方只发、一方只收 | 广播、遥控、无线寻呼 |
| 半双工 | Half-duplex | 双方都能收发，但不能同时进行 | 对讲机（同频）、问询检索 |
| 全双工 | Duplex | 双方可同时收发，需双向信道 | 电话、计算机高速数据通信 |

> 【插入 通信原理 图 1-6】三种通信方式示意

### 2. 并行传输和串行传输

按数字码元在信道上的排列方式：

**并行传输**：$n$ 个码元在 $n$ 条信道上同时传输，一个时钟节拍传一组。
- 优点：速度快，节省传输时间
- 缺点：需要 $n$ 条线路，成本高
- 应用：设备间近距离通信（如计算机 ↔ 打印机）

**串行传输**：码元一个接一个在一条信道上传输。
- 优点：只需一条信道，线路费用低
- 缺点：速度慢，需外加同步措施解决收/发双方的码组同步
- 应用：远距离数字传输的主流方式

> 【插入 通信原理 图 1-7, 1-8】并行 vs 串行传输

### 3. 连接方式

- **专线通信**：点到点
- **网通信**：点到多点、多点之间

本书重点在点到点通信——通信网的基础。

# 1.4 信息及其度量

通信的根本目的是传输信息。信息是受信者预先不知而待知的内容——不同形式的消息（语音、文字）可以承载相同的信息。如何量化信息？

## 信息量的定义

信息量的大小与消息的**不确定性**挂钩：事件越不可能发生，发生后带来的信息量越大。概率论提供了自然语言——用事件概率 $P(x)$ 描述不确定程度。

信息量 $I$ 与概率 $P(x)$ 须满足三条公理：

1. $I = I[P(x)]$ — $I$ 是概率的函数
2. $P(x)$ 越小，$I$ 越大；$P(x) = 1$ 时 $I = 0$（必然事件无信息），$P(x) \to 0$ 时 $I \to \infty$
3. 独立事件的信息量可加：$I[P(x_1)P(x_2)\cdots] = I[P(x_1)] + I[P(x_2)] + \cdots$

对数函数天然满足这三条，由此定义：

$$
I = \log_a \frac{1}{P(x)} = -\log_a P(x) \tag{1.4-1}
$$

**信息量单位**由对数底 $a$ 决定：

| 底 $a$ | 单位 | 符号 |
|--------|------|------|
| 2 | 比特（bit） | b |
| e | 奈特（nat） | nat |
| 10 | 哈特莱（Hartley） | — |

通信中最常用比特：

$$
I = \log_2 \frac{1}{P(x)} = -\log_2 P(x) \quad (\text{b}) \tag{1.4-2}
$$

## 等概率离散信源

$M$ 个独立等概率波形，每个出现的概率 $P = 1/M$，则传送一个波形的信息量为：

$$
I = \log_2 \frac{1}{P} = \log_2 M \quad (\text{b}) \tag{1.4-4}
$$

若 $M = 2^k$，则 $I = k$ b。即**传送一个 $M$ 进制波形所需的信息量 = 用二进制脉冲表示它所需的脉冲数目 $k$**。

直观量级感：
- 二进制等概率 → $1$ b/符号
- 四进制等概率 → $2$ b/符号
- 八进制等概率 → $3$ b/符号

**注意**：工程中常把一个二进制码元称为 "1 b"，这一定义兼容信息论中等概率二进制符号的信息量。

## 平均信息量 — 熵

非等概率的一般情形。离散信源有 $M$ 个符号 $x_i$，各以概率 $P(x_i)$ 独立出现，$\sum P(x_i) = 1$。

每个符号所含信息量的统计平均值——**平均信息量**（即**信源熵**，Entropy）：

$$
H(x) = -\sum_{i=1}^{M} P(x_i) \log_2 P(x_i) \quad (\text{b/符号}) \tag{1.4-6}
$$

以热力学熵命名：都度量了系统的"不确定程度"。关键性质：

> **当各符号等概率（$P(x_i) = 1/M$）时，熵最大，$H_{\max} = \log_2 M$。**

这意味着等概率分布时信源的"平均不确定性"最大——每个符号都携带最多信息。

**例 1-2 要点**（4 符号，概率 $3/8, 1/4, 1/4, 1/8$）：
- 直接统计法：108 b / 57 符号 = 1.89 b/符号
- 熵公式法：$H = 1.906$ b/符号，总信息量 $57 \times 1.906 = 108.64$ b

两种算法差异随序列增长而减小。序列较长时，熵公式更方便——直接用概率分布计算而无需逐符号统计。

## 连续消息的信息量

连续消息用概率密度 $f(x)$ 描述，平均信息量为：

$$
H(x) = -\int_{-\infty}^{\infty} f(x) \log_a f(x) \, \mathrm{d}x \tag{1.4-7}
$$

离散熵的连续化——求和变为积分，概率变为概率密度。在信道容量（香农公式）中会再次用到这一概念。

# 1.5 通信系统主要性能指标

通信系统性能指标包括有效性、可靠性、适应性、经济性等。但从信息传输的角度，**有效性和可靠性是最核心的两个指标**。两者通常是一对矛盾。

- **有效性**：传输一定信息量所占用的带宽（频带利用率）
- **可靠性**：传输信息的准确程度

## 1.5.1 有效性

### 模拟通信系统

有效性直接以**传输带宽**衡量——传输同样信号，带宽越小，频带利用率越高。带宽与调制方式密切相关。同一路语音：

| 调制方式 | 占用带宽 | 有效性 |
|---------|---------|--------|
| SSB（单边带调幅）| $\sim 4\text{ kHz}$ | 高 |
| FM（调频，指数=5）| $\sim 48\text{ kHz}$ | 低（带宽为 SSB 的 12 倍）|

### 数字通信系统

有效性用**频带利用率**衡量——单位带宽内的传输速率。

**码元传输速率** $R_B$（传码率/波特率）：每秒传输的码元数，单位 Baud。

$$
R_B = \frac{1}{T_B} \quad (\text{Baud}) \tag{1.5-3}
$$

其中 $T_B$ 为单个码元持续时间。

**信息传输速率** $R_b$（传信率/比特率）：每秒传输的平均信息量，单位 b/s。

$$
R_b = R_B \log_2 M \quad (\text{b/s}) \tag{1.5-4}
$$

核心对应关系：一个 $M$ 进制码元携带 $\log_2 M$ b 信息量。

实例：$R_B = 1200\text{ Baud}$，八进制 $(M=8)$，则 $R_b = 1200 \times 3 = 3600\text{ b/s}$。

码元持续时间与比特持续时间的关系：

$$
T_B = T_b \cdot \log_2 M \tag{1.5-6}
$$

**频带利用率**：

$$
\eta = \frac{R_B}{B} \; (\text{Baud/Hz}) \quad \text{或} \quad \eta_b = \frac{R_b}{B} \; (\text{b/(s·Hz)}) \tag{1.5-1, 1.5-2}
$$

$\eta$ 和 $\eta_b$ 是评价数字通信频谱效率的关键参数。

## 1.5.2 可靠性

### 模拟通信系统

用接收端**输出信号与噪声功率比** $S/N$（信噪比）度量。$S/N$ 反映信号经传输后的"保真"程度和抗噪声能力。$S/N$ 同样与调制方式相关——调频信号的 $S/N$ 高于调幅（抗噪更强），但所需带宽也更宽。

> ⚡ 有效性和可靠性是一对矛盾：更高的可靠性（更优调制）往往以更多的带宽为代价。

### 数字通信系统

用**差错概率**衡量：

**误码率** $P_e$（Symbol Error Rate）：传输过程中码元被传错的概率。

$$
P_e = \frac{\text{错误码元数}}{\text{传输总码元数}} \tag{1.5-7}
$$

**误信率** $P_b$（Bit Error Rate, BER，误比特率）：传输过程中比特被传错的概率。

$$
P_b = \frac{\text{错误比特数}}{\text{传输总比特数}} \tag{1.5-8}
$$

二进制下 $P_b = P_e$。多进制下，一个码元错不等于一个比特错——一个码元对应 $\log_2 M$ 个比特，码元判决错误可能只影响其中部分比特。BER 是数字通信系统最核心的可靠性指标，在后续章节中将看到：通信系统的几乎所有设计选择（调制方式、编码方案、功率分配）最终都映射到 BER 性能上。

# 1.6 小结

第 1 章建立了通信系统的**概念框架**和**基本术语**，是全书的总纲。

**三条概念链**：

1. 消息 → 信息 → 信号：消息是信息的物理形式，信息是消息的内涵，信号是传输载体。信号的模拟/数字二分法（参量取值连续 vs 有限）决定系统的两大分支。

2. 通信系统模型：信源 → 发送设备 → 信道 → 接收设备 → 信宿。数字通信在此框架上增加信源编码、信道编码、加密、同步等模块——每个模块在后续章节中逐一展开。

3. 信息量 → 熵 → 频带利用率 → 差错概率：信息量度量不确定性（$I = \log_2(1/P)$），熵是平均不确定性（$H = -\sum P_i \log_2 P_i$），两者是理解有效性和可靠性的数学基础。

**核心两组矛盾与关系**：

- **模拟 vs 数字**：数字以 5~15 倍带宽代价换取抗干扰、差错可控、易处理（1.2.4）
- **有效性 vs 可靠性**：更高的可靠性需要更多的带宽或更复杂的处理，贯穿全书的设计 trade-off

**关键公式速查**：

| 公式 | 含义 |
|------|------|
| $I = \log_2(1/P)$ | 单个符号信息量 (b) |
| $H = -\sum P_i \log_2 P_i$ | 信源熵 (b/符号) |
| $R_b = R_B \log_2 M$ | 信息速率 ↔ 码元速率 |
| $\eta_b = R_b / B$ | 频带利用率 (b/(s·Hz)) |
| $P_b = \text{错误比特/总比特}$ | 误比特率 (BER) |

后续章节将在第 1 章的框架上逐步展开：第 2-3 章补充数学工具（确知信号与随机过程），第 4 章讨论信道与噪声，第 5 章进入模拟调制，第 6 章起全面展开数字通信系统。
