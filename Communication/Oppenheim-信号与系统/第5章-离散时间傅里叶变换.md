# 5.0 引言

第 4 章建立了连续时间傅里叶变换（CTFT）。第 5 章完成傅里叶分析基本工具的另一半：**离散时间傅里叶变换（DTFT）**。

## 本章与第 4 章的并行结构

第 5 章采用与第 4 章完全相同的策略：从周期信号的傅里叶级数出发 → 令周期趋于无穷 → 推导非周期信号的傅里叶变换表示。这一并行结构既强化对连续/离散时间傅里叶分析共性的理解，也通过对比凸显各自独有特征。

## DT 与 CT 的关键差异（预览）

从 [[Oppenheim-信号与系统/第3章-傅里叶级数表示#3.6 离散时间傅里叶级数|第 3.6 节]] 已看到一个重要差异：DT 周期信号的傅里叶级数是**有限项**的（$N$ 项），而 CT 周期信号是无穷级数。本章将看到，这一差异在傅里叶变换层面体现为：

1. **$X(e^{j\omega})$ 是周期的**（周期 $2\pi$）——源于 $e^{j\omega n}$ 对 $\omega$ 以 $2\pi$ 为周期
2. **合成方程是有限区间积分**（任意 $2\pi$ 区间）——而非 CTFT 在 $(-\infty, \infty)$ 上的积分

这两点都来自同一个根源（[[Oppenheim-信号与系统/第1章-信号与系统导论#1.3.3 离散时间复指数的周期性——与连续时间的关键差异|1.3.3 节]]）：频率相差 $2\pi$ 整倍数的 DT 复指数完全相同。

# 5.1 非周期信号的表示：离散时间傅里叶变换

## 5.1.1 DTFT 的推导

推导策略与 [[Oppenheim-信号与系统/第1章-信号与系统导论|CTFT 的推导]] 完全并行：周期延拓 → 写 FS → 令周期 $N \to \infty$。

**Step 1: 周期延拓。** 设 $x[n]$ 为有限长序列（$-N_1 \leq n \leq N_2$ 外为零，Figure 5.1(a)）。构造周期序列 $\tilde{x}[n]$，使 $x[n]$ 为其中一个周期（Figure 5.1(b)）。当 $N \to \infty$，$\tilde{x}[n] = x[n]$ 对任意有限 $n$ 成立。

**Step 2: 写出 FS。** $\tilde{x}[n]$ 的傅里叶级数（[[Oppenheim-信号与系统/第3章-傅里叶级数表示#3.6 离散时间傅里叶级数|3.6 节，式 (3.94)-(3.95)]]）：

$$\tilde{x}[n] = \sum_{k=\langle N \rangle} a_k e^{jk(2\pi/N)n}, \quad a_k = \frac{1}{N} \sum_{n=\langle N \rangle} \tilde{x}[n] e^{-jk(2\pi/N)n}$$

在一个包含 $-N_1 \leq n \leq N_2$ 的周期内，$\tilde{x}[n] = x[n]$，且 $x[n]$ 在此区间外为零，故可将求和延拓至 $\pm\infty$：

$$a_k = \frac{1}{N} \sum_{n=-\infty}^{+\infty} x[n] e^{-jk(2\pi/N)n}$$

**Step 3: 定义包络函数。** 定义

$$X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n} \tag{5.4}$$

则 FS 系数恰为 $X(e^{j\omega})$ 在 $\omega_k = k\omega_0 = k(2\pi/N)$ 处的采样：

$$a_k = \frac{1}{N} X(e^{jk\omega_0}) \tag{5.5}$$

这正是 4.1 节的 DT 版本——FS 系数是包络函数的等间隔采样。代入 $\tilde{x}[n]$ 的 FS 表达式：

$$\tilde{x}[n] = \sum_{k=\langle N \rangle} \frac{1}{N} X(e^{jk\omega_0}) e^{jk\omega_0 n} = \frac{1}{2\pi} \sum_{k=\langle N \rangle} X(e^{jk\omega_0}) e^{jk\omega_0 n} \omega_0 \tag{5.7}$$

（利用了 $1/N = \omega_0/2\pi$）

**Step 4: 取极限 $N \to \infty$。** $\omega_0 = 2\pi/N \to 0$，求和变为积分。由于被积函数 $X(e^{j\omega})e^{j\omega n}$ 以 $2\pi$ 为周期（Figure 5.2），$N$ 个宽度 $\omega_0$ 的矩形面积之和 → $2\pi$ 区间上的积分：

$$x[n] = \frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) e^{j\omega n} d\omega \tag{5.8}$$

**DTFT 变换对：**

$$\boxed{x[n] = \frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) e^{j\omega n} d\omega} \quad \text{合成方程 (5.8)}$$

$$\boxed{X(e^{j\omega}) = \sum_{n=-\infty}^{+\infty} x[n] e^{-j\omega n}} \quad \text{分析方程 (5.9)}$$

### 与 CTFT 的关键差异

| 特征 | CTFT | DTFT |
|------|------|------|
| 变换的周期性 | $X(j\omega)$ 非周期 | $X(e^{j\omega})$ 周期 $2\pi$ |
| 合成积分区间 | $(-\infty, \infty)$ | 任意 $2\pi$ 区间 |
| 根源 | $e^{j\omega t}$ 对不同 $\omega$ 互异 | $e^{j(\omega+2\pi)n} = e^{j\omega n}$ |

这两个差异都来自同一事实：DT 复指数对频率以 $2\pi$ 为周期。这意味着 DTFT 的**全部信息已包含在任意 $2\pi$ 区间内**——通常取 $-\pi < \omega \leq \pi$ 或 $0 \leq \omega < 2\pi$。

### FS 系数与 DTFT 的关系

式 (5.5) 揭示了一个重要关系：周期信号 $\tilde{x}[n]$ 的 FS 系数 $a_k$ 等于 **一个周期内与 $\tilde{x}[n]$ 相同、其余为零的有限长信号** 的 DTFT 在 $\omega_k = 2\pi k/N$ 处的等间隔采样（乘以 $1/N$）。这一关系在实用信号处理中极为重要（见习题 5.41）。

### DT 频率的低频与高频

由于 $X(e^{j\omega})$ 的周期性，DT 频率的高低判断与 CT 不同（Figure 5.3）：
- **低频**：$\omega$ 靠近 $0, \pm 2\pi, \pm 4\pi, \ldots$（偶数倍 $\pi$）——信号变化缓慢
- **高频**：$\omega$ 靠近 $\pm\pi, \pm 3\pi, \ldots$（奇数倍 $\pi$）——信号振荡最快

$\omega = \pi$ 是 DT 能表示的最高频率（对应 $x[n] = e^{j\pi n} = (-1)^n$，每采样一次符号翻转）。这与 [[Oppenheim-信号与系统/第1章-信号与系统导论#1.3.3 离散时间复指数的周期性——与连续时间的关键差异|1.3.3 节]] 中的结论一致：频率周期 $2\pi$，$\omega_0 = \pi$ 时振荡最快。

## 5.1.2 DTFT 的例子

三个例子，从单边指数到双边指数到矩形脉冲，逐步展示分析方程 (5.9) 的使用。三个变换均以 $2\pi$ 为周期。

### 例 5.1：单边指数 $x[n] = a^n u[n],\; |a| < 1$

直接代入 (5.9)，利用 $u[n]$ 将求和截断到 $n \geq 0$：

$$X(e^{j\omega}) = \sum_{n=0}^{\infty} (ae^{-j\omega})^n = \frac{1}{1 - ae^{-j\omega}}$$

几何级数收敛因为 $|ae^{-j\omega}| = |a| < 1$。

幅度与相位（Figure 5.4）：
- $a > 0$：$|X(e^{j\omega})|$ 在 $\omega = 0$（及 $2\pi$ 整倍数）处最大，在高频（$\omega = \pm\pi$ 附近）衰减——**低通特性**
- $a < 0$：$|X(e^{j\omega})|$ 在 $\omega = \pm\pi$ 处最大——信号 $(a^n) = (-|a|)^n$ 本身正负交替（高频），频谱峰值移向高频

$a$ 越接近 1，极点 $ae^{-j\omega}$ 越靠近单位圆，频谱越尖锐（能量越集中在峰值频率附近）——这是 DT 中的"高 $Q$"行为。

### 例 5.2：双边指数 $x[n] = a^{|n|},\; |a| < 1$

信号关于 $n=0$ 偶对称（Figure 5.5(a)）。将求和拆为正负两部分：

$$X(e^{j\omega}) = \sum_{n=0}^{\infty} (ae^{-j\omega})^n + \sum_{n=-\infty}^{-1} a^{-n} e^{-j\omega n}$$

第二项经 $m = -n$ 代换后：$\sum_{m=1}^{\infty} (ae^{j\omega})^m$。两项均为几何级数，合并：

$$\boxed{X(e^{j\omega}) = \frac{1-a^2}{1 - 2a\cos\omega + a^2}}$$

**关键观察**：$X(e^{j\omega})$ 为**实值、偶函数**（Figure 5.5(b)）。$a^{|n|}$ 是实偶信号 → DTFT 也是实偶——这是 DTFT 共轭对称性的直接体现（5.3.4 节将正式建立）。

与例 5.1 对比：例 5.1 单边 → 复变换（有相位信息）；例 5.2 双边对称 → 纯实变换（相位信息退化为符号正负）。这对应了这样一个直觉：对称的信号去除了频谱中的"延迟"信息，只剩幅度。

### 例 5.3：矩形脉冲

$$x[n] = \begin{cases} 1, & |n| \leq N_1 \\ 0, & |n| > N_1 \end{cases}$$

$$X(e^{j\omega}) = \sum_{n=-N_1}^{N_1} e^{-j\omega n} = \frac{\sin[\omega(N_1 + \frac{1}{2})]}{\sin(\omega/2)} \tag{5.12}$$

> 【插入 Oppenheim 图 5.6】$N_1=2$ 时的矩形脉冲及其 DTFT。

这是 **DT 版本的 sinc 函数**，与 CT 矩形脉冲的傅里叶变换对照：

| 特征 | CT 矩形脉冲 | DT 矩形脉冲 |
|------|------------|------------|
| 变换形式 | $\text{sinc}$ 函数 | $\sin[(N_1+\frac{1}{2})\omega] / \sin(\omega/2)$ |
| 周期性 | 非周期 | 周期 $2\pi$ |
| 零点位置 | $\omega = k\pi/T_1$ | 由分子零点决定（分母在 $\omega=0,\pm2\pi,\ldots$ 处也为零，取极限有限） |

DT 的"类 sinc"在 $\omega=0,\pm2\pi,\ldots$ 处取最大值 $2N_1+1$，过零点约在 $\omega(2N_1+1)/2 = k\pi$ 处。与 CT sinc 的关键区别在于 **周期性**——所有特征在每个 $2\pi$ 区间重复出现。

## 5.1.3 DTFT 的收敛问题

5.1.1 节的推导假设 $x[n]$ 有限长。分析方程 (5.9) 对无穷长序列仍然有效，但需考虑收敛性。

### 收敛条件

分析方程 (5.9) 的无穷求和收敛，若以下之一成立：

1. **绝对可和**：$\sum_{n=-\infty}^{+\infty} |x[n]| < \infty$
2. **有限能量**：$\sum_{n=-\infty}^{+\infty} |x[n]|^2 < \infty$

这两条与 CTFT 的收敛条件完全对应。例 5.1 ($a^n u[n]$) 和例 5.2 ($a^{|n|}$) 都满足绝对可和（几何级数）。

### 合成方程：无 Gibbs 现象

**DTFT 与 CTFT 的一个重要差异**：合成方程 (5.8) 的积分区间有限（任意 $2\pi$ 区间），因此**没有收敛问题**。

在 CT 中，用有限带宽 $W$ 近似理想低通滤波器的单位冲激响应时，被截断的 sinc 积分导致 Gibbs 现象——无论 $W$ 多大，过冲幅度不消失。DT 中的情况完全不同。

### 例 5.4：单位冲激的带限近似

$x[n] = \delta[n]$，其 DTFT 为 $X(e^{j\omega}) = 1$（所有频率等贡献，与 CT 一致）。带限近似：

$$\hat{x}[n] = \frac{1}{2\pi} \int_{-W}^{W} e^{j\omega n} d\omega = \frac{\sin Wn}{\pi n} \tag{5.16}$$

> 【插入 Oppenheim 图 5.7】$W = \pi/4, 3\pi/8, \pi/2, 3\pi/4, 7\pi/8, \pi$ 时的近似结果。

随着 $W$ 增大：
- 振荡频率增加（与 CT 相同——更高频分量被纳入）
- **但振荡幅度相对于 $\hat{x}[0]$ 递减**（与 CT 不同！）
- **$W = \pi$ 时振荡完全消失**：$\hat{x}[n] = \delta[n]$，精确恢复

**本质原因**：DTFT 的合成积分只需到 $W = \pi$ 即覆盖了信号的**全部独立频率分量**。不存在 CT 中"需要无穷大带宽才能精确重构间断点"的问题——因为 DT 信号的频谱是周期的，$|\omega| > \pi$ 并不包含新信息。

换言之，CT signal 在间断点的精确重构需要所有频率到 $\infty$，截断必然留下残留振荡（Gibbs）。DT signal 的最高独立频率就是 $\pi$，所以 $W = \pi$ 时已经包含了**全部**信息。

这一事实对理解 [[Oppenheim-信号与系统/第7章-采样|第 7 章采样定理]] 至关重要——DT 处理天然规避了 CT 中的某些收敛困难。

# 5.2 周期信号的傅里叶变换

与 CT 一样，周期信号可纳入 DTFT 框架——将其变换理解为频域的**周期冲激串**。

### 复指数 $x[n] = e^{j\omega_0 n}$ 的 DTFT

CT 中 $e^{j\omega_0 t} \xleftrightarrow{\mathcal{F}} 2\pi\delta(\omega - \omega_0)$。DT 中，由于 $X(e^{j\omega})$ 必须以 $2\pi$ 为周期，冲激不能只出现在 $\omega_0$ 一处——必须在 $\omega_0 \pm 2\pi, \omega_0 \pm 4\pi, \ldots$ 重复出现：

$$\boxed{X(e^{j\omega}) = \sum_{l=-\infty}^{+\infty} 2\pi \delta(\omega - \omega_0 - 2\pi l)} \tag{5.18}$$

> 【插入 Oppenheim 图 5.8】$e^{j\omega_0 n}$ 的 DTFT——冲激串，间距 $2\pi$。

**验证**：将 (5.18) 代入合成方程 (5.8)，任意 $2\pi$ 区间内只含一个冲激（例如 $\omega_0 + 2\pi r$），故：

$$\frac{1}{2\pi} \int_{2\pi} X(e^{j\omega}) e^{j\omega n} d\omega = e^{j(\omega_0 + 2\pi r)n} = e^{j\omega_0 n}$$

恢复原信号。$2\pi r$ 在指数上不产生任何效果——因为 $e^{j 2\pi r n} = 1$。

### 一般周期信号的 DTFT

周期 $N$ 的信号 $x[n] = \sum_{k=\langle N \rangle} a_k e^{jk(2\pi/N)n}$，利用线性叠加：

$$\boxed{X(e^{j\omega}) = \sum_{k=-\infty}^{+\infty} 2\pi a_k \, \delta\!\left(\omega - \frac{2\pi k}{N}\right)} \tag{5.20}$$

> 【插入 Oppenheim 图 5.9】各项分量 DTFT 的叠加过程。

每个 FS 系数 $a_k$ 对应一个位于 $\omega_k = 2\pi k/N$ 的冲激，面积为 $2\pi a_k$。由于 $a_k$ 本身以 $N$ 为周期（[[Oppenheim-信号与系统/第3章-傅里叶级数表示#3.6 离散时间傅里叶级数|3.6 节]]），$X(e^{j\omega})$ 的冲激模式也以 $2\pi$ 为周期自然重复。

**核心对应**：

$$a_k \;\longleftrightarrow\; \text{频域冲激面积 } 2\pi a_k \; \text{（在 } \omega = 2\pi k/N \text{ 处）}$$

这比 CT 更简洁：CTFS 系数 $a_k$ 与频域冲激面积 $2\pi a_k$ 的关系还有 $\omega_0 = 2\pi/T$ 的间距因子参与；DT 中 $a_k$ 直接对应冲激面积。

### 例 5.5：余弦信号

$x[n] = \cos\omega_0 n = \frac{1}{2}e^{j\omega_0 n} + \frac{1}{2}e^{-j\omega_0 n}$，$\omega_0 = 2\pi/5$。

由 (5.18) 线性组合：

$$X(e^{j\omega}) = \sum_{l=-\infty}^{+\infty} \pi \delta(\omega - \tfrac{2\pi}{5} - 2\pi l) + \sum_{l=-\infty}^{+\infty} \pi \delta(\omega + \tfrac{2\pi}{5} - 2\pi l)$$

在 $-\pi < \omega \leq \pi$ 内：

$$X(e^{j\omega}) = \pi\delta(\omega - \tfrac{2\pi}{5}) + \pi\delta(\omega + \tfrac{2\pi}{5}), \quad -\pi \leq \omega < \pi$$

> 【插入 Oppenheim 图 5.10】$\cos(2\pi n/5)$ 的 DTFT。

### 例 5.6：周期冲激串

$$x[n] = \sum_{k=-\infty}^{+\infty} \delta[n - kN]$$

这是 DT 中最重要的周期信号之一。FS 系数：$a_k = 1/N$（对所有 $k$——可从 (3.95) 直接算出：在一个周期内只有一个 $\delta[n]$，其值为 1）。由 (5.20)：

$$\boxed{X(e^{j\omega}) = \frac{2\pi}{N} \sum_{k=-\infty}^{+\infty} \delta\!\left(\omega - \frac{2\pi k}{N}\right)} \tag{5.27}$$

> 【插入 Oppenheim 图 5.11】时域周期冲激串及其 DTFT（频域也是周期冲激串）。

⚡ **时域冲激串 ↔ 频域冲激串**：这是 DTFT 对偶性（5.7 节）的典型实例——时域周期冲激串的 DTFT 是频域周期冲激串，冲激间距在时域为 $N$、频域为 $2\pi/N$。与 CT 的对应关系（[[Oppenheim-信号与系统/第1章-信号与系统导论|例 4.8]]）比较：

| | CT 周期冲激串 | DT 周期冲激串 |
|---|---|---|
| 时域 | $\sum \delta(t-kT)$ | $\sum \delta[n-kN]$ |
| 频域 | $\frac{2\pi}{T}\sum \delta(\omega - 2\pi k/T)$ | $\frac{2\pi}{N}\sum \delta(\omega - 2\pi k/N)$ |
| 频域周期性 | 非周期（冲激间距 $2\pi/T$） | 周期 $2\pi$（冲激间距 $2\pi/N$） |

DT 版本的关键差异：频域冲激数量在一个 $2\pi$ 周期内恰好等于 $N$（因为间距 $2\pi/N$），共有 $N$ 个互异的冲激位置。这正是 DTFS 只有 $N$ 个互异系数的频域体现。

# 5.3 离散时间傅里叶变换的性质

与 CTFT 一样，DTFT 的性质既加深对变换的理解，也在实际计算中简化变换和逆变换的求解。本节及 5.4–5.5 节逐一介绍，汇总于 Table 5.1（与 CTFT Table 4.1 对照）。推导与 CTFT 本质相同的性质仅给出结论。

记法：$X(e^{j\omega}) = \mathcal{F}\{x[n]\}$，$x[n] = \mathcal{F}^{-1}\{X(e^{j\omega})\}$，$x[n] \xleftrightarrow{\mathcal{F}} X(e^{j\omega})$。

## 5.3.1 周期性

DTFT 始终以 $2\pi$ 为周期：

$$\boxed{X(e^{j(\omega + 2\pi)}) = X(e^{j\omega})} \tag{5.28}$$

这在 5.1 节推导时已确立，是所有 DTFT 性质中最根本的一个——CTFT 一般不具备此性质。周期性意味着分析 DTFT 时只需关注任意 $2\pi$ 区间（通常取 $-\pi < \omega \leq \pi$）。

## 5.3.2 线性

$$ax_1[n] + bx_2[n] \xleftrightarrow{\mathcal{F}} aX_1(e^{j\omega}) + bX_2(e^{j\omega}) \tag{5.29}$$

与 CTFT 完全相同——傅里叶变换是线性运算。这是使用部分分式展开和叠加原理的基础。

## 5.3.3 时移与频移

**时移**：
$$\boxed{x[n - n_0] \xleftrightarrow{\mathcal{F}} e^{-j\omega n_0} X(e^{j\omega})} \tag{5.30}$$

时域延迟 $n_0$ → 频域乘以线性相位因子 $e^{-j\omega n_0}$。幅度谱不变，相位增加 $-\omega n_0$。

**频移**：
$$e^{j\omega_0 n} x[n] \xleftrightarrow{\mathcal{F}} X(e^{j(\omega - \omega_0)}) \tag{5.31}$$

时域乘以复指数 → 频谱搬移 $\omega_0$。这是通信中调制的 DT 版本——基带信号乘以载波 → 频谱搬移到载频。

### 例 5.7：低通 ↔ 高通转换

频移性质在 DT 中有一个特殊应用。由于 DTFT 以 $2\pi$ 为周期，频移 $\pi$（半周期）恰好将低频区域与高频区域互换（Figure 5.12）：

$$H_{\text{hp}}(e^{j\omega}) = H_{\text{lp}}(e^{j(\omega - \pi)}) \tag{5.32}$$

时域对应：
$$h_{\text{hp}}[n] = e^{j\pi n} h_{\text{lp}}[n] = (-1)^n h_{\text{lp}}[n] \tag{5.34}$$

⚡ **只需将低通滤波器的冲激响应每隔一个样本取反，就得到高通滤波器**。这是 DT 独有的简洁设计方法——在 CT 中无法如此简单地实现低通到高通的转换。根源仍是 DT 复指数的周期性：$\omega = \pi$ 对应最高频率。

→ 这一关系在 [[#5.4.1 例子|例 5.14]] 中用于构造带阻滤波器。

## 5.3.4 共轭与共轭对称

**共轭**：
$$x^*[n] \xleftrightarrow{\mathcal{F}} X^*(e^{-j\omega}) \tag{5.35}$$

**实信号的共轭对称**：若 $x[n]$ 为实序列，则
$$X(e^{j\omega}) = X^*(e^{-j\omega}) \quad [x[n] \text{ 实}] \tag{5.36}$$

这意味着实信号的 DTFT 具有以下对称性：
- $\Re e\{X(e^{j\omega})\}$ 为偶函数，$\Im m\{X(e^{j\omega})\}$ 为奇函数
- $|X(e^{j\omega})|$ 为偶函数，$\angle X(e^{j\omega})$ 为奇函数

**偶部/奇部与实部/虚部的对应**：
$$\mathcal{E}v\{x[n]\} \xleftrightarrow{\mathcal{F}} \Re e\{X(e^{j\omega})\}$$
$$\mathcal{O}d\{x[n]\} \xleftrightarrow{\mathcal{F}} j\,\Im m\{X(e^{j\omega})\}$$

⚡ 推论：**实偶信号 ↔ 实偶变换**。[[#5.1.2 DTFT 的例子|例 5.2]] 的 $a^{|n|}$ 正是这种情况——时域实偶 → 频域实偶。

## 5.3.5 差分与累加

这是 CT 微分/积分性质在 DT 中的对应。

**一阶差分**（微分在 DT 中的对应）：
$$x[n] - x[n-1] \xleftrightarrow{\mathcal{F}} (1 - e^{-j\omega}) X(e^{j\omega}) \tag{5.37}$$

直接由线性和时移性质得出。$(1 - e^{-j\omega})$ 是 DT 中的"微分算子"频率响应。

**累加**（积分在 DT 中的对应）：
$$y[n] = \sum_{m=-\infty}^{n} x[m]$$

$$\boxed{\sum_{m=-\infty}^{n} x[m] \xleftrightarrow{\mathcal{F}} \frac{1}{1 - e^{-j\omega}} X(e^{j\omega}) + \pi X(e^{j0}) \sum_{k=-\infty}^{+\infty} \delta(\omega - 2\pi k)} \tag{5.39}$$

第一项 $\frac{1}{1 - e^{-j\omega}} X(e^{j\omega})$ 是 $X(e^{j\omega})$ 除以差分算子的频率响应——与 CT 积分性质中的 $(1/j\omega)X(j\omega)$ 对应。

第二项是**冲激串**：累加可能产生直流或平均值，体现为频域零频处的冲激。$X(e^{j0}) = \sum_{n} x[n]$ 是序列总和——总和不为零 → 累加结果有无界的均值 → 频域出现冲激。这一项在 CT 积分性质中同样存在（式 (4.32) 中的 $\pi X(0)\delta(\omega)$），但在 DT 中冲激是周期的。

### 例 5.8：单位阶跃的 DTFT

已知 $\delta[n] \xleftrightarrow{\mathcal{F}} 1$，且 $u[n] = \sum_{m=-\infty}^{n} \delta[m]$。由累加性质：

$$U(e^{j\omega}) = \frac{1}{1 - e^{-j\omega}} + \pi \sum_{k=-\infty}^{+\infty} \delta(\omega - 2\pi k)$$

$G(e^{j0}) = 1$（$\delta[n]$ 的和为 1）。结果由两部分组成：有理部分 $1/(1-e^{-j\omega})$（对应除 $n=0$ 后 $u[n]=1$ 的部分）+ 周期冲激串（对应非零直流分量）。

⚡ 对比 $a^n u[n]$ 的变换 $1/(1 - ae^{-j\omega})$：$u[n]$ 是 $a=1$ 的退化情形——此时几何级数发散，冲激串正是"修补"该发散的数学机制。

## 5.3.6 时间反转

$$x[-n] \xleftrightarrow{\mathcal{F}} X(e^{-j\omega}) \tag{5.42}$$

推导：在分析方程中直接做变量代换 $m = -n$。时域翻转 ↔ 频域翻转。与 CTFT 完全平行。

结合 5.3.4 节：若 $x[n]$ 为实信号，则 $x[-n] \xleftrightarrow{\mathcal{F}} X^*(e^{j\omega})$（由 $X(e^{-j\omega}) = X^*(e^{j\omega})$）。

## 5.3.7 时间扩展

由于 DT 的时间索引只能取整数，$x[an]$ 对非整数 $a$ 无定义。CT 的时域缩放性质 $x(at) \leftrightarrow \frac{1}{|a|}X(j\omega/a)$ 在 DT 中没有直接对应。

**DT 的替代定义**：令 $k$ 为正整数，在原序列相邻值之间**插入 $k-1$ 个零**以"拉宽"信号：

$$x_{(k)}[n] = \begin{cases} x[n/k], & n \text{ 是 } k \text{ 的整数倍} \\ 0, & \text{否则} \end{cases} \tag{5.44}$$

> 【插入 Oppenheim 图 5.13】$k=3$ 时，$x[n]$ → $x_{(3)}[n]$：原样本之间各插入 2 个零。

其 DTFT：

$$\boxed{x_{(k)}[n] \xleftrightarrow{\mathcal{F}} X(e^{jk\omega})} \tag{5.45}$$

**时域拉宽 $k$ 倍 ↔ 频域压缩 $k$ 倍**（Figure 5.14）。直观：信号在时间上展开 → 变化变慢 → 频谱向低频收缩。注意由于 $X(e^{j\omega})$ 以 $2\pi$ 为周期，$X(e^{jk\omega})$ 的周期变为 $2\pi/k$——频域出现 $k$ 个压缩副本。

⚡ 比较 CT 的 $x(at) \leftrightarrow \frac{1}{|a|}X(j\omega/a)$：DT 版本没有幅度因子 $1/k$（因为插入零点不改变原有样本的能量），且频域的压缩是压缩频谱而非拉伸——与直觉一致：时域"变慢"/拉宽对应低频分量占比更大。

### 例 5.9：利用时间扩展求复杂序列的 DTFT

Figure 5.15(a) 的序列可通过时间扩展 + 时移 + 线性组合表示为已知矩形脉冲的变形：

$$x[n] = y_{(2)}[n] + 2y_{(2)}[n-1]$$

其中 $y[n] = g[n-2]$（矩形脉冲延迟），$g[n]$ 为例 5.3 中 $N_1=2$ 的矩形脉冲。依次应用时间扩展、时移和线性性质，最终得到闭式解。

**这个例子的方法意义**：复杂序列 → 分解为基本序列（矩形脉冲、指数等）的扩展/移位/缩放组合 → 利用 DTFT 性质逐个写出变换 → 叠加。无需从分析方程 (5.9) 重新计算。

## 5.3.8 频域微分

对分析方程 (5.9) 两边求导：

$$\frac{dX(e^{j\omega})}{d\omega} = \sum_{n=-\infty}^{+\infty} -jn\,x[n]\,e^{-j\omega n}$$

即：

$$\boxed{n\,x[n] \xleftrightarrow{\mathcal{F}} j\frac{dX(e^{j\omega})}{d\omega}} \tag{5.46}$$

时域乘以 $n$ ↔ 频域微分（乘以 $j$）。与 CTFT 的 $t x(t) \leftrightarrow j\,dX/d\omega$ 完全平行。

实用场景：当 $X(e^{j\omega})$ 形如 $1/(1 - ae^{-j\omega})^2$（重极点）时，可视为 $1/(1 - ae^{-j\omega})$ 的导数，结合频域微分性质直接写出逆变换——见 [[#5.4.1 例子|例 5.13（$\alpha=\beta$ 情形）]]。

## 5.3.9 Parseval 定理

$$\boxed{\sum_{n=-\infty}^{+\infty} |x[n]|^2 = \frac{1}{2\pi} \int_{2\pi} |X(e^{j\omega})|^2 d\omega} \tag{5.47}$$

- 左边 = 信号的总能量（时域）
- 右边 = 频域能量密度 $|X(e^{j\omega})|^2/2\pi$ 在 $2\pi$ 区间上的积分
- $|X(e^{j\omega})|^2$ 称为信号的**能量密度谱**（energy-density spectrum）

与 CTFT 的 Parseval 定理（式 4.43）以及 DTFS 的 Parseval 定理（式 3.110）本质相同：傅里叶变换**保能量**——变换不损失也不创造能量，只是换了一个域去计算。

⚡ 实用意义：判断信号能量是否有限，只需检查 $|X(e^{j\omega})|^2$ 在 $2\pi$ 区间内的积分是否收敛。也能快速验证变换对是否有误——能量前后一致是必要条件。

### 例 5.10：从 DTFT 反推信号属性

给出 $X(e^{j\omega})$ 的模和相位（Figure 5.16），判断 $x[n]$ 是否：周期性、实值、偶函数、有限能量。利用前述性质逐条判断，无需计算完整逆变换：

| 问题 | 频域判据 | 结论 |
|------|---------|------|
| 周期性？ | $X(e^{j\omega})$ 需仅为谐波频率处冲激 | 否（连续谱） |
| 实值？ | $\|X\|$ 偶 + $\angle X$ 奇 | 是 |
| 偶函数？ | 实信号 + $X$ 纯实偶 | 否（$\angle X = -2\omega$，非零） |
| 有限能量？ | $\int \|X\|^2 d\omega < \infty$ | 是 |

这一工作流在通信信号分析中极为常见——频域观察 → 推断时域特征。

# 5.4 卷积性质

若 $y[n] = x[n] * h[n]$，则

$$\boxed{Y(e^{j\omega}) = X(e^{j\omega}) H(e^{j\omega})} \tag{5.48}$$

其中 $H(e^{j\omega})$ 是 $h[n]$ 的 DTFT——即 LTI 系统的**频率响应**。这与 [[Oppenheim-信号与系统/第3章-傅里叶级数表示#3.8 离散时间 LTI 系统的频率响应|3.8 节式 (3.122)]] 从特征函数角度得到的定义完全一致。

**推导逻辑**（与 CTFT 4.4 节平行）：
1. 合成方程 (5.8) 将 $x[n]$ 分解为复指数 $e^{j\omega n}$ 的线性组合，幅度正比于 $X(e^{j\omega})$
2. 每个 $e^{j\omega n}$ 是 LTI 系统的特征函数 → 输出等于 $H(e^{j\omega})e^{j\omega n}$
3. 叠加 → 输出频谱 = $X(e^{j\omega})H(e^{j\omega})$

⚡ **卷积性质是 DTFT 在 LTI 系统分析中的核心价值**：时域卷积 → 频域相乘。这不仅简化计算，更提供了频域视角理解系统行为——$H(e^{j\omega})$ 在每个频率 $\omega$ 处对输入的各频率分量进行幅度缩放和相位旋转。

**频率选择性滤波**的本质：$H(e^{j\omega}) \approx 1$ 的通带内保留信号分量，$H(e^{j\omega}) \approx 0$ 的阻带内抑制信号分量。

**适用范围**：并非所有 LTI 系统都有频率响应。稳定系统（$h[n]$ 绝对可和）保证 $H(e^{j\omega})$ 收敛。$h[n] = 2^n u[n]$ 这类不稳定系统的频率响应发散 → 第 10 章 Z 变换提供了扩展工具。

## 5.4.1 例子

### 例 5.11：纯时移系统

$h[n] = \delta[n - n_0]$，则 $H(e^{j\omega}) = e^{-j\omega n_0}$。

$$Y(e^{j\omega}) = e^{-j\omega n_0} X(e^{j\omega})$$

与 5.3.3 节的时移性质一致。$|H(e^{j\omega})| = 1$（所有频率等幅度通过），$\angle H(e^{j\omega}) = -\omega n_0$（线性相位——纯延迟不畸变信号波形）。

### 例 5.12：DT 理想低通滤波器

频率响应（Figure 5.17(a)）：$H(e^{j\omega}) = 1$（$|\omega| < \omega_c$），$= 0$（$\omega_c < |\omega| \leq \pi$）。由合成方程求 $h[n]$：

$$h[n] = \frac{1}{2\pi} \int_{-\omega_c}^{\omega_c} e^{j\omega n} d\omega = \frac{\sin\omega_c n}{\pi n} \tag{5.50}$$

> 【插入 Oppenheim 图 5.17】(a) 理想低通频率响应；(b) 对应的 $h[n]$。

与 CT 理想低通滤波器（[[Oppenheim-信号与系统/第1章-信号与系统导论|例 4.18]]）面临相同的问题：
- **非因果**：$h[n] \neq 0$ 对 $n < 0$——物理不可实现
- **振荡特性**：拖尾衰减慢（$\sim 1/n$）——某些应用中不可接受

→ 实际滤波器设计（第 6 章）需要在频率选择性（陡峭过渡带）和时域特性（非振荡、因果性）之间折中。

⚡ 对比 [[#5.1.3 DTFT 的收敛问题|例 5.4]]：例 5.4 中 $\hat{x}[n] = \sin(Wn)/(\pi n)$ 正是对 $\delta[n]$ 的理想低通近似。$W = \omega_c$ 时截断导致振荡，$W = \pi$ 时精确恢复——解释了为什么 DT 的无 Gibbs 性质只在包含所有 $[-\pi,\pi]$ 频率时才成立。

### 例 5.13：卷积求输出——部分分式 + 频域微分

$h[n] = \alpha^n u[n]$，$x[n] = \beta^n u[n]$（$|\alpha|, |\beta| < 1$）。本例展示**频域法求卷积**的完整工作流：

**$\alpha \neq \beta$ 情形**：频域相乘 → 部分分式展开 → 逐项逆变换
$$Y(e^{j\omega}) = \frac{1}{(1 - \alpha e^{-j\omega})(1 - \beta e^{-j\omega})} = \frac{A}{1 - \alpha e^{-j\omega}} + \frac{B}{1 - \beta e^{-j\omega}}$$

其中 $A = \frac{\alpha}{\alpha-\beta},\; B = -\frac{\beta}{\alpha-\beta}$。最终：
$$y[n] = \frac{1}{\alpha-\beta}[\alpha^{n+1} - \beta^{n+1}] u[n] \tag{5.55}$$

**$\alpha = \beta$ 情形（重极点）**：部分分式失效。利用频域微分性质（5.3.8 节）：
$$Y(e^{j\omega}) = \frac{1}{(1 - \alpha e^{-j\omega})^2} = \frac{j}{\alpha} e^{j\omega} \frac{d}{d\omega}\!\left(\frac{1}{1 - \alpha e^{-j\omega}}\right)$$

由频域微分：$n\alpha^n u[n] \leftrightarrow j\frac{d}{d\omega}(\frac{1}{1-\alpha e^{-j\omega}})$；由时移补偿 $e^{j\omega}$ 因子：
$$y[n] = (n+1)\alpha^n u[n] \tag{5.58}$$

⚡ **方法对比**：时域直接卷积 $\sum_k \alpha^k \beta^{n-k}$ 涉及几何级数求和——在复杂系统时繁琐；频域法将卷积化为乘法 + 代数分解 → 系统化且不易出错。两种方法给出相同结果。

### 例 5.14：利用卷积性质分析系统互联

系统框图 Figure 5.18(a)：输入经上下两路 → 理想低通 + 频移 → 相加输出。利用频移 + 卷积 + 线性性质依次追踪各路频谱：

- 上路：$x[n] \xrightarrow{(-1)^n} \xrightarrow{H_{\text{lp}}} \xrightarrow{(-1)^n}$：两次频移 $\pi$，中间低通
- 下路：$x[n] \xrightarrow{H_{\text{lp}}}$：直接低通

最终：
$$H(e^{j\omega}) = H_{\text{lp}}(e^{j(\omega - \pi)}) + H_{\text{lp}}(e^{j\omega})$$

由 [[#5.3.3 时移与频移|例 5.7]]，$H_{\text{lp}}(e^{j(\omega - \pi)})$ 是理想高通。因此 $H(e^{j\omega})$ 是**低通 + 高通 = 带阻**（Figure 5.18(b)），阻带：$\pi/4 < |\omega| < 3\pi/4$。

⚡ 这个例子展示了频域系统分析的范式：框图 → 逐级写频谱方程 → 利用 DTFT 性质化简 → 整体频率响应。整个过程不需要任何时域卷积计算。

# 5.5 相乘性质

时域相乘 ↔ 频域**周期卷积**——卷积性质的频域对偶。

设 $y[n] = x_1[n]\,x_2[n]$。将 $x_1[n]$ 用合成方程 (5.8) 表示，交换积分与求和：

$$\boxed{Y(e^{j\omega}) = \frac{1}{2\pi} \int_{2\pi} X_1(e^{j\theta}) X_2(e^{j(\omega - \theta)}) d\theta} \tag{5.63}$$

积分在任意 $2\pi$ 区间上进行。这是由于 $X_1$ 和 $X_2$ 都是 $2\pi$ 周期函数——两个周期函数的普通卷积在有限区间上的积分，称为**周期卷积**（periodic convolution），以区别于 $(-\infty, \infty)$ 上的非周期卷积。

⚡ **卷积 vs 相乘——完整的对偶关系**：

| 域 | 运算 | 结果 |
|----|------|------|
| 时域 | 卷积 $x_1 * x_2$ | 频域相乘 $X_1 X_2$ |
| 时域 | 相乘 $x_1 \cdot x_2$ | 频域周期卷积 $\frac{1}{2\pi} X_1 \circledast X_2$ |

相乘性质是 [[#采样与重构|第 7 章采样]] 和 [[#调制技术|第 8 章通信]] 的数学基础——采样 = 信号与冲激串相乘，调制 = 信号与载波相乘。

### 例 5.15：周期卷积的计算

两个 sinc 类信号的乘积：

$$x_1[n] = \frac{\sin(3\pi n/4)}{\pi n}, \quad x_2[n] = \frac{\sin(\pi n/2)}{\pi n}$$

其 DTFT $X_1(e^{j\omega})$ 和 $X_2(e^{j\omega})$ 分别是不同宽度的理想低通（由例 5.12，$\sin(\omega_c n)/(\pi n) \leftrightarrow$ 截止频率 $\omega_c$ 的理想低通）。将周期卷积化为普通卷积的技巧：在 $-\pi < \omega \leq \pi$ 外截断 $X_1$ 得到 $\hat{X}_1$，则周期卷积 = 普通卷积 × $1/2\pi$。最终 $X(e^{j\omega})$ 为梯形谱（Figure 5.20）——这正是两个理想低通频谱卷积的结果。

# 5.7 对偶性

CTFT 的分析方程与合成方程之间具有形式上的对称性（除因子 $2\pi$ 和符号差异）。DTFT 的分析方程 (5.9)（求和）与合成方程 (5.8)（积分）**不**具备这种直接对称性。但存在两类对偶关系：
1. **DTFS 内部对偶**（5.7.1）：FS 系数自身是周期序列，可再展开为 FS
2. **跨域对偶**（5.7.2）：DTFT 方程与 CTFS 方程在数学上镜像对称

## 5.7.1 DTFS 中的对偶

DTFS 的系数 $a_k$ 自身是周期为 $N$ 的序列。两个周期序列 $f[m]$ 和 $g[r]$ 通过以下关系对偶：

$$f[m] = \frac{1}{N} \sum_{r=\langle N \rangle} g[r] e^{-jr(2\pi/N)m} \tag{5.65}$$

这一关系有两种解读：
- 令 $m=k,\; r=n$ → $f[k]$ 是 $g[n]$ 的 FS 系数：$g[n] \xleftrightarrow{\mathcal{FS}} f[k]$
- 令 $m=n,\; r=-k$ → $f[n]$ 的 FS 系数为 $\frac{1}{N}g[-k]$：$f[n] \xleftrightarrow{\mathcal{FS}} \frac{1}{N}g[-k]$

⚡ **时域与频域互换**：$g$ 和 $f$ 互为 FS 对，只是其中一个在时域、另一个在频域——这正是对偶的实质。

### 性质对偶

DTFS 的每对性质都有对偶（Table 3.2）：
- 时移 ↔ 频移：$x[n-n_0] \leftrightarrow a_k e^{-jk(2\pi/N)n_0}$ ↔ $e^{jm(2\pi/N)n}x[n] \leftrightarrow a_{k-m}$
- 卷积 ↔ 相乘：$\sum_r x[r]y[n-r] \leftrightarrow N a_k b_k$ ↔ $x[n]y[n] \leftrightarrow \sum_l a_l b_{k-l}$

⚡ 注意卷积性质中 DTFS 的因子是 $N$（非 $2\pi$）且卷积是**周期卷积**（系数卷积）。

### 例 5.16：利用对偶求 FS 系数

已知周期 $N=9$ 的信号 $x[n] = \frac{1}{9}\frac{\sin(5\pi n/9)}{\sin(\pi n/9)}$（$n$ 非 9 倍数），求 $a_k$。

该形式与 [[Oppenheim-信号与系统/第3章-傅里叶级数表示#3.6 离散时间傅里叶级数|例 3.12]] 中方波的 FS 系数 $b_k$ 完全相同。由对偶性：$x[n]$ 的 FS 系数 = 矩形方波的采样（互换 $n$ 和 $k$ 的角色）。结果：$a_k = 1/9$（$|k| \leq 2$），$0$（$2 < |k| \leq 4$），周期 $9$。

**方法意义**：遇到信号形式与已知 FS 系数中的"类 sinc"匹配 → 直接对偶映射，无需重新计算。

## 5.7.2 DTFT 与 CTFS 之间的对偶

对比两组方程：

| | DTFT | CTFS |
|------|------|------|
| 合成 | $x[n] = \frac{1}{2\pi}\int_{2\pi} X(e^{j\omega}) e^{j\omega n} d\omega$ (5.73) | $x(t) = \sum_k a_k e^{jk\omega_0 t}$ (5.75) |
| 分析 | $X(e^{j\omega}) = \sum_n x[n] e^{-j\omega n}$ (5.74) | $a_k = \frac{1}{T}\int_T x(t) e^{-jk\omega_0 t} dt$ (5.76) |

观察：
- DTFT 合成方程 (5.73) 在形式上与 CTFS 分析方程 (5.76) 相似（积分 → 系数）
- DTFT 分析方程 (5.74) 在形式上与 CTFS 合成方程 (5.75) 相似（求和 → 级数合成）

⚡ **对偶的实质**：$X(e^{j\omega})$ 是周期连续函数（周期 $2\pi$），可以看做以 $\omega$ 为"时间"变量做 CTFS 展开。$X(e^{j\omega})$ 的 FS 系数正是 $x[-n]$——时域序列的**时间反转**。

Table 5.3 总结了四种傅里叶表示（CTFS / DTFS / CTFT / DTFT）的时域-频域对偶关系。

### 例 5.17：利用跨域对偶求 DTFT

求 $x[n] = \frac{\sin(\pi n/2)}{\pi n}$ 的 DTFT。

利用对偶：在 CTFS 中找周期 $2\pi$、系数 $a_k = x[k] = \frac{\sin(\pi k/2)}{\pi k}$ 的信号。这是周期方波（$T_1 = \pi/2$，例 3.5）的 FS 系数。将 CTFS 分析方程中的 $k \to n$，$t \to \omega$，经 $n \to -n$ 修正后得出：

$$X(e^{j\omega}) = \begin{cases} 1, & |\omega| \leq \pi/2 \\ 0, & \pi/2 < |\omega| \leq \pi \end{cases}$$

即截止频率 $\pi/2$ 的理想低通。

⚡ **跨域对偶的工作流**：DT 信号 → 找到对应 CT 周期信号（其 FS 系数 = 目标序列）→ 由 CTFS 的时域形状写出 DTFT 的频域形状（经变量重命名）。这是求 DTFT 的一条"旁路"。

# 5.8 线性常系数差分方程描述的 LTI 系统

N 阶 LCCDE：

$$\sum_{k=0}^{N} a_k y[n-k] = \sum_{k=0}^{M} b_k x[n-k] \tag{5.78}$$

对该式两边取 DTFT，利用线性和时移性质：

$$\boxed{H(e^{j\omega}) = \frac{Y(e^{j\omega})}{X(e^{j\omega})} = \frac{\sum_{k=0}^{M} b_k e^{-jk\omega}}{\sum_{k=0}^{N} a_k e^{-jk\omega}}} \tag{5.80}$$

⚡ **可由差分方程直接写出频率响应**——分子系数 = 输入延迟项系数，分母系数 = 输出延迟项系数。这与 CT 中 LCCDE 的频率响应（式 4.76）在代数结构上完全一致，只是变量从 $j\omega$ 变为 $e^{-j\omega}$。

$H(e^{j\omega})$ 是 $e^{-j\omega}$ 的有理函数。其逆变换 $h[n]$ 可通过**部分分式展开 + 逐项查表**获得——与 CT 中求 $h(t)$ 的方法完全相同。

### 例 5.18：一阶系统

$y[n] - a y[n-1] = x[n]$，$|a| < 1$。

$$H(e^{j\omega}) = \frac{1}{1 - a e^{-j\omega}}$$

对比例 5.1，直接得 $h[n] = a^n u[n]$（因果）。

### 例 5.19：二阶系统 + 部分分式分解

$y[n] - \frac{3}{4}y[n-1] + \frac{1}{8}y[n-2] = 2x[n]$。

$$H(e^{j\omega}) = \frac{2}{(1 - \frac{1}{2}e^{-j\omega})(1 - \frac{1}{4}e^{-j\omega})} = \frac{4}{1 - \frac{1}{2}e^{-j\omega}} - \frac{2}{1 - \frac{1}{4}e^{-j\omega}}$$

$$h[n] = \left[4\left(\frac{1}{2}\right)^n - 2\left(\frac{1}{4}\right)^n\right] u[n]$$

### 例 5.20：输入为有理变换时的输出求法

同一系统（例 5.19），输入 $x[n] = (1/4)^n u[n]$。

$$Y(e^{j\omega}) = H(e^{j\omega}) X(e^{j\omega}) = \frac{2}{(1 - \frac{1}{2}e^{-j\omega})(1 - \frac{1}{4}e^{-j\omega})^2}$$

重极点（$(1 - \frac{1}{4}e^{-j\omega})^2$）需要部分分式展开的扩展形式（附录 A）：

$$y[n] = \left\{-4\left(\frac{1}{4}\right)^n - 2(n+1)\left(\frac{1}{4}\right)^n + 8\left(\frac{1}{2}\right)^n\right\} u[n]$$

第二项 $(n+1)(1/4)^n$ 来自重极点——利用 Table 5.2 的 $(n+1)a^n u[n] \leftrightarrow 1/(1 - ae^{-j\omega})^2$。

⚡ **LCCDE + DTFT 的标准工作流**：差分方程 → $H(e^{j\omega})$（有理函数）→ 部分分式 → 逐项逆变换。整个过程是代数运算，无需直接处理时域卷积或递推。
