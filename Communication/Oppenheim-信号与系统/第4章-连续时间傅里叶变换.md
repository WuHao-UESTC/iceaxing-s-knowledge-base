# 4.0 引言

第 3 章用谐波相关的复指数线性组合表示**周期**信号 → 傅里叶级数。第 4 章将这一思想扩展到**非周期**信号。

核心逻辑链：
- 非周期信号 = 周期趋于无穷的周期信号
- 周期 $T \to \infty$ → 基频 $\omega_0 = 2\pi/T \to 0$ → 谐波分量频率间隔趋于零 → 离散和变为连续积分
- 结果：**傅里叶变换**（分析方程）+ **傅里叶逆变换**（综合方程）

与傅里叶级数的对照：

| | 傅里叶级数（第 3 章） | 傅里叶变换（第 4 章） |
|---|---|---|
| 信号类型 | 周期信号 | 非周期信号（有限能量） |
| 频率分量 | 离散谐波 $k\omega_0$ | 连续频率 $\omega$ |
| 表示形式 | 求和 $\sum$ | 积分 $\int$ |
| 系数 | $a_k$（离散谱） | $X(j\omega)$（连续谱，频谱密度） |

Fourier 的原创贡献正是这一步从离散和到连续积分的推广——这个思想在第 3.1 节的历史视角中已有铺垫。

# 4.1.1 傅里叶变换表示的导出

## 动机：从方波的包络线观察出发

以第 3 章例 3.5 的周期方波为起点。周期 $T$，脉宽 $2T_1$，傅里叶级数系数：

$$a_k = \frac{2\sin(k\omega_0 T_1)}{k\omega_0 T}, \quad \omega_0 = \frac{2\pi}{T} \tag{4.1}$$

换一个视角看待同一公式：

$$Ta_k = \left. \frac{2\sin\omega T_1}{\omega} \right|_{\omega = k\omega_0} \tag{4.2}$$

**关键洞察**：将 $\omega$ 视为连续变量，函数 $(2\sin\omega T_1)/\omega$ 是 $Ta_k$ 的**包络线**（envelope）。$a_k$ 不过是这条包络线上以 $\omega_0$ 为间隔的等距采样。

固定 $T_1$，包络线与 $T$ 无关。当 $T$ 增大：
- $\omega_0 = 2\pi/T$ 减小 → 采样越来越密
- 时域上，周期方波趋近于单个矩形脉冲（非周期信号）
- 频域上，$Ta_k$ 的采样点趋近于连续包络线

这就是 Fourier 的核心思想——**非周期信号是周期趋于无穷的极限**。

## 一般推导：从傅里叶级数到傅里叶变换

对有限持续期信号 $x(t)$（$|t| > T_1$ 时 $x(t)=0$），构造周期延拓 $\tilde{x}(t)$，周期为 $T$：

$$\tilde{x}(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t}, \quad a_k = \frac{1}{T} \int_{-T/2}^{T/2} \tilde{x}(t) e^{-jk\omega_0 t} dt \tag{4.3, 4.4}$$

由于在一个周期内 $\tilde{x}(t)=x(t)$ 且周期外 $x(t)=0$，可将积分限扩展到无穷：

$$a_k = \frac{1}{T} \int_{-\infty}^{+\infty} x(t) e^{-jk\omega_0 t} dt$$

定义**包络函数** $X(j\omega)$——即**傅里叶变换**：

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt \tag{4.9}$$

则 $a_k = \frac{1}{T} X(jk\omega_0)$。代入 $\tilde{x}(t)$ 的级数表示：

$$\tilde{x}(t) = \frac{1}{2\pi} \sum_{k=-\infty}^{+\infty} X(jk\omega_0) e^{jk\omega_0 t} \omega_0 \tag{4.7}$$

这是以 $\omega_0$ 为宽的矩形面积之和。取极限 $T \to \infty$：
- $\tilde{x}(t) \to x(t)$
- $\omega_0 \to 0$，求和变为积分

得到**傅里叶变换对**：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} X(j\omega) e^{j\omega t} d\omega \tag{4.8}$$

$$X(j\omega) = \int_{-\infty}^{+\infty} x(t) e^{-j\omega t} dt \tag{4.9}$$

## 物理含义

- **综合方程 (4.8)**：将 $x(t)$ 表示为连续频率复指数的线性组合。每个频率分量 $\omega$ 的"幅度"是 $X(j\omega) \cdot d\omega/2\pi$——无穷小量，而非离散值
- **分析方程 (4.9)**：$X(j\omega)$ 是**频谱**（spectrum），描述信号在各频率上的"密度"——类比于 $a_k$ 是离散频率上的"质量"，$X(j\omega)$ 是连续频率上的"密度"

## 与傅里叶级数的桥梁

若 $\tilde{x}(t)$ 是周期为 $T$ 的信号，$x(t)$ 是它的一个周期截取，则：

$$a_k = \frac{1}{T} X(j\omega)\big|_{\omega = k\omega_0} \tag{4.10}$$

**周期信号的傅里叶系数 = 一个周期波形的傅里叶变换在谐波频率上的采样（除以 $T$）**。

这是第 4.2 节将傅里叶变换推广到周期信号的关键公式，也是实际中常用的计算技巧：需要对周期信号做频域分析时，可以先求一个周期的傅里叶变换，再采样得到 $a_k$。

# 4.1.2 傅里叶变换的收敛性

与傅里叶级数的收敛性讨论（[[第3章-傅里叶级数表示#3.4 傅里叶级数的收敛性|3.4 节]]）平行，傅里叶变换也有两组充分条件。

## 两组收敛条件

**条件一：有限能量（平方可积）**

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt < \infty \tag{4.11}$$

满足此条件时，$X(j\omega)$ 有限（分析方程收敛），且合成信号 $\hat{x}(t)$ 与 $x(t)$ 的误差能量为零：

$$\int_{-\infty}^{+\infty} |e(t)|^2 dt = 0, \quad e(t) = \hat{x}(t) - x(t) \tag{4.12}$$

这与傅里叶级数的式 (3.51)/(3.54) 完全对应。$\hat{x}(t)$ 与 $x(t)$ 可以在**个别点**上取值不同（如间断点处），但二者差异的**能量**为零。

**条件二：Dirichlet 条件（逐点收敛）**

1. $x(t)$ 绝对可积：$\int |x(t)| dt < \infty$（比平方可积更强）
2. 任意有限区间内，$x(t)$ 只有有限个极大值和极小值
3. 任意有限区间内，$x(t)$ 只有有限个间断点，且每个间断点为有限值

满足 Dirichlet 条件时，$\hat{x}(t)$ 在所有连续点等于 $x(t)$，在间断点等于两侧极限的平均值。

## 两组条件的关系

- 绝对可积 $\Rightarrow$ 能量有限？不一定——例如 $x(t) = t^{-1/2}$ 在 $[0,1]$ 上平方可积但非绝对可积
- Dirichlet 条件保证**逐点**收敛，能量条件只保证**能量意义上**的收敛（允许个别点差异）
- 实际中绝大多数物理信号同时满足两组条件

## 周期信号怎么办？

周期信号既不绝对可积也不平方可积（积分区间无穷 → 不收敛），但若允许变换中出现**冲激函数**，周期信号也可以有傅里叶变换。这正是第 4.2 节的内容——将傅里叶级数与傅里叶变换纳入统一框架。

# 4.1.3 连续时间傅里叶变换举例

五个基本例题，每个揭示傅里叶变换的一个侧面。

## 例 4.1：单边指数衰减

$$x(t) = e^{-at} u(t), \quad a > 0$$

$$X(j\omega) = \int_0^\infty e^{-at} e^{-j\omega t} dt = \frac{1}{a + j\omega}$$

幅度与相位：

$$|X(j\omega)| = \frac{1}{\sqrt{a^2 + \omega^2}}, \quad \angle X(j\omega) = -\tan^{-1}\left(\frac{\omega}{a}\right)$$

- $a$ 控制衰减速度：$a$ 越小，时域衰减越慢 → 频域越集中在 $\omega = 0$ 附近（低频成分更强）
- 若 $a$ 为复数（$\Re\{a\} > 0$），公式形式不变
- 这是最基本的傅里叶变换对之一

> 【插入 Oppenheim 图 4.5】$e^{-at}u(t)$ 的幅度谱和相位谱

## 例 4.2：双边指数衰减

$$x(t) = e^{-a|t|}, \quad a > 0$$

$$X(j\omega) = \int_{-\infty}^0 e^{at} e^{-j\omega t} dt + \int_0^\infty e^{-at} e^{-j\omega t} dt = \frac{2a}{a^2 + \omega^2}$$

- **$X(j\omega)$ 是实函数**——因为 $x(t)$ 是实偶函数（对称性在 4.3.3 节展开）
- 频谱全是正实数，无相位成分 → 信号完全由余弦分量合成（无正弦分量）

> 【插入 Oppenheim 图 4.6-4.7】信号与傅里叶变换

## 例 4.3：单位冲激

$$x(t) = \delta(t)$$

$$X(j\omega) = \int_{-\infty}^{+\infty} \delta(t) e^{-j\omega t} dt = 1$$

**所有频率等权重**。$\delta(t)$ 在时域无限窄 → 频域无限宽，且幅度恒定。这是时-频对偶性的极端体现（→ 4.3.6 节）。

## 例 4.4：矩形脉冲

$$x(t) = \begin{cases} 1, & |t| < T_1 \\ 0, & |t| > T_1 \end{cases}$$

$$X(j\omega) = \int_{-T_1}^{T_1} e^{-j\omega t} dt = \frac{2\sin\omega T_1}{\omega}$$

这正是 4.1.1 节方波包络线的连续版本。用 sinc 函数表示：

$$\frac{2\sin\omega T_1}{\omega} = 2T_1 \operatorname{sinc}\left(\frac{\omega T_1}{\pi}\right)$$

**收敛性验证**：
- $x(t)$ 平方可积 → 合成信号 $\hat{x}(t)$ 与 $x(t)$ 能量差异为零
- 满足 Dirichlet 条件 → 在间断点 $t = \pm T_1$ 处 $\hat{x}(t) = 1/2$（两侧平均值）
- 出现 **Gibbs 现象**：有限频率区间 $[-W, W]$ 的逆变换在间断点附近产生过冲纹波，纹波幅度不随 $W$ 增大而减小（仅向间断点压缩），能量趋于零

> 【插入 Oppenheim 图 4.8】矩形脉冲信号及其傅里叶变换

## 例 4.5：理想低通频谱

$$X(j\omega) = \begin{cases} 1, & |\omega| < W \\ 0, & |\omega| > W \end{cases}$$

$$x(t) = \frac{1}{2\pi} \int_{-W}^{W} e^{j\omega t} d\omega = \frac{\sin Wt}{\pi t} = \frac{W}{\pi} \operatorname{sinc}\left(\frac{Wt}{\pi}\right)$$

> 【插入 Oppenheim 图 4.9】理想低通的傅里叶变换对

### 对偶性 preview

例 4.4 和例 4.5 构成对偶关系：

| | 例 4.4 | 例 4.5 |
|---|---|---|
| 时域 | 矩形脉冲 | sinc 函数 |
| 频域 | sinc 函数 | 矩形脉冲 |

这正是 4.3.6 节对偶性（duality）的直接体现。

### 时-频反向关系

当 $W$ 增大（频域矩形变宽）→ $x(t)$ 的主峰变高、第一瓣变窄。极限情况：$W \to \infty$ 时 $X(j\omega) = 1$（全频段），$x(t) \to \delta(t)$（回到例 4.3）。

反之，$T_1$ 增大（时域脉冲变宽）→ $X(j\omega)$ 变窄。

**信号在时域越窄，频域越宽；时域越宽，频域越窄。** 这是 4.3.5 节尺度变换性质的直观表现，也是通信系统中带宽与符号速率之间基本折中的数学根源。

> 【插入 Oppenheim 图 4.11】不同 $W$ 值下的例 4.5 傅里叶变换对

## sinc 函数定义

Oppenheim 采用的标准形式（与国内教材的 $\operatorname{Sa}$ 函数等价但有缩放差异）：

$$\operatorname{sinc}(\theta) = \frac{\sin\pi\theta}{\pi\theta} \tag{4.20}$$

性质：$\operatorname{sinc}(0) = 1$，$\operatorname{sinc}(n) = 0$（$n \neq 0$ 且为整数）。其零点间隔为 1。

# 4.2 周期信号的傅里叶变换

## 核心思想：用冲激函数统一两种表示

傅里叶级数（第 3 章）和傅里叶变换（第 4.1 节）看似针对不同类型的信号，但通过**在频域引入冲激函数**，可以将周期信号也纳入傅里叶变换的框架。

出发点：考虑频域的一个冲激 $X(j\omega) = 2\pi\delta(\omega - \omega_0)$，逆变换得：

$$x(t) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} 2\pi\delta(\omega - \omega_0) e^{j\omega t} d\omega = e^{j\omega_0 t}$$

**单个频率 $\omega_0$ 的复指数在频域对应 $\omega = \omega_0$ 处面积为 $2\pi$ 的冲激。**

## 一般公式

推广到谐波相关的冲激序列：

$$X(j\omega) = \sum_{k=-\infty}^{+\infty} 2\pi a_k \delta(\omega - k\omega_0) \tag{4.22}$$

逆变换：

$$x(t) = \sum_{k=-\infty}^{+\infty} a_k e^{jk\omega_0 t} \tag{4.23}$$

这正是傅里叶级数的综合方程 (3.38)。因此：

> **周期信号的傅里叶变换 = 位于谐波频率上的冲激串，$k\omega_0$ 处的冲激面积为 $2\pi a_k$。**

这是第 4.1.1 节式 (4.10) $a_k = X(jk\omega_0)/T$ 的反向表述：从 $a_k$ 构造 $X(j\omega)$。

## 例 4.6：周期方波

将例 3.5 的周期方波用傅里叶变换表示：

$$a_k = \frac{\sin k\omega_0 T_1}{\pi k}$$

$$X(j\omega) = \sum_{k=-\infty}^{+\infty} \frac{2\sin k\omega_0 T_1}{k} \delta(\omega - k\omega_0)$$

与图 3.7(a) 的柱状图相比：比例因子 $2\pi$ + 冲激替代柱状图。sinc 包络线的形状完全一致。

> 【插入 Oppenheim 图 4.12】周期方波的傅里叶变换（冲激串）

## 例 4.7：正弦与余弦

$$\sin\omega_0 t = \frac{1}{2j}e^{j\omega_0 t} - \frac{1}{2j}e^{-j\omega_0 t}$$

$$X(j\omega) = \frac{\pi}{j}\delta(\omega - \omega_0) - \frac{\pi}{j}\delta(\omega + \omega_0)$$

$$\cos\omega_0 t = \frac{1}{2}e^{j\omega_0 t} + \frac{1}{2}e^{-j\omega_0 t}$$

$$X(j\omega) = \pi\delta(\omega - \omega_0) + \pi\delta(\omega + \omega_0)$$

- $\sin$ 的两个冲激：面积 $\pi/j$ 和 $-\pi/j$（纯虚数，奇对称）——反映 $\sin$ 是奇函数
- $\cos$ 的两个冲激：面积均为 $\pi$（纯实数，偶对称）——反映 $\cos$ 是偶函数
- 这两个变换对在第 8 章正弦调制系统分析中反复使用

> 【插入 Oppenheim 图 4.13】(a) $\sin\omega_0 t$ 和 (b) $\cos\omega_0 t$ 的傅里叶变换

## 例 4.8：周期冲激串

$$x(t) = \sum_{k=-\infty}^{+\infty} \delta(t - kT)$$

傅里叶系数（来自例 3.8）：$a_k = 1/T$（所有谐波等权重）。

$$X(j\omega) = \frac{2\pi}{T} \sum_{k=-\infty}^{+\infty} \delta\left(\omega - \frac{2\pi k}{T}\right)$$

**时域周期冲激串 ↔ 频域周期冲激串**，频域间隔 $2\pi/T$。

时-频反向关系再次体现：时域间隔 $T$ 越大 → 频域间隔 $2\pi/T$ 越小。这一变换对在第 7 章采样定理中起核心作用。

> 【插入 Oppenheim 图 4.14】(a) 周期冲激串；(b) 其傅里叶变换

## 统一框架的意义

至此，所有信号——周期或非周期——都可以用傅里叶变换描述：

| 信号类型 | 傅里叶变换 $X(j\omega)$ |
|---|---|
| 非周期（有限能量） | 连续函数（频谱密度） |
| 周期（傅里叶级数 $a_k$） | 冲激串，面积 $2\pi a_k$ |
| 非周期 + 周期混合 | 连续部分 + 冲激部分 |

这使得后续章节（滤波、调制、采样）可以用统一语言处理所有信号，而不必在"级数"和"变换"之间来回切换。

# 4.3 连续时间傅里叶变换的性质

傅里叶变换的性质揭示时域操作与频域效应之间的对应关系，有三重价值：
- **洞察**：理解时-频关系的本质（如尺度变换 → 时宽-带宽积）
- **简化计算**：复杂信号的变换可通过性质从已知变换对推导
- **桥梁**：傅里叶级数的性质（3.5 节）可通过 4.2 节的统一框架平移为傅里叶变换性质

## 记号约定

| 记号 | 含义 |
|---|---|
| $\mathcal{F}\{x(t)\}$ | $x(t)$ 的傅里叶变换 |
| $\mathcal{F}^{-1}\{X(j\omega)\}$ | $X(j\omega)$ 的傅里叶逆变换 |
| $x(t) \xleftrightarrow{\mathfrak{F}} X(j\omega)$ | 傅里叶变换对 |

# 4.3.1 线性

$$ax(t) + by(t) \xleftrightarrow{\mathfrak{F}} aX(j\omega) + bY(j\omega) \tag{4.26}$$

分析方程 (4.25) 是积分——积分的线性直接继承为傅里叶变换的线性。可推广到任意有限个信号的线性组合。

# 4.3.2 时移

$$x(t - t_0) \xleftrightarrow{\mathfrak{F}} e^{-j\omega t_0} X(j\omega) \tag{4.27}$$

**证明思路**：在综合方程中将 $t$ 替换为 $t-t_0$，则 $e^{j\omega t} \to e^{j\omega(t-t_0)} = e^{-j\omega t_0} e^{j\omega t}$，提取因子 $e^{-j\omega t_0}$ 后识别为新信号的傅里叶变换。

**物理含义**：
- 时域平移 $\Rightarrow$ 频域线性相位旋转 $-\omega t_0$
- **幅度谱不变**：$|X(j\omega)|$ 完全不受时移影响——能量在频率上的分布不因信号延迟而改变
- 相位谱增加线性项：$\angle X(j\omega) \to \angle X(j\omega) - \omega t_0$

这是通信中"时延 = 线性相移"的数学基础。滤波器若要无失真传输（仅延迟），需要在通带内具有线性相位——否则不同频率分量延迟不同，输出波形畸变。

# 4.3.3 共轭与共轭对称性

## 共轭性质

$$x^*(t) \xleftrightarrow{\mathfrak{F}} X^*(-j\omega) \tag{4.28}$$

**证明**：对分析方程两边取共轭，再将 $\omega$ 替换为 $-\omega$。

## 实信号的共轭对称性

若 $x(t)$ 为实信号（$x^*(t) = x(t)$），则：

$$X(-j\omega) = X^*(j\omega) \quad [x(t) \text{ 为实}] \tag{4.30}$$

**四种等价的表述**：

| 形式 | 偶函数 | 奇函数 |
|---|---|---|
| 直角坐标 | $\Re\{X(j\omega)\}$ | $\Im\{X(j\omega)\}$ |
| 极坐标 | $\vert X(j\omega)\vert$ | $\angle X(j\omega)$ |

**工程意义**：实信号的频谱只需给出正频率部分——负频率由对称性自动确定。这就是为什么频谱分析仪通常只显示正频率。

## 实信号的奇偶性 → 频谱的实虚性

从式 (4.30) 可进一步推出（[[第1章-信号与系统导论#1.2.3 偶信号与奇信号|1.2.3 节]]的偶-奇分解在频域的投射）：

| 时域 $x(t)$（实信号） | 频域 $X(j\omega)$ |
|---|---|
| 偶函数 | 实偶函数 |
| 奇函数 | 纯虚奇函数 |
| $\mathcal{E}v\{x(t)\}$（偶部） | $\Re\{X(j\omega)\}$ |
| $\mathcal{O}d\{x(t)\}$（奇部） | $j\,\Im\{X(j\omega)\}$ |

**物理直觉**：偶信号只有余弦分量（实频谱），奇信号只有正弦分量（纯虚频谱）。任意实信号 = 偶部 + 奇部，对应实频谱 = 实部 + j虚部。

## 例 4.10：用对称性简化计算

$e^{-a|t|}$ = $2\,\mathcal{E}v\{e^{-at}u(t)\}$。已知 $\mathcal{F}\{e^{-at}u(t)\} = 1/(a+j\omega)$，由偶部 ↔ 实部的对称性：

$$X(j\omega) = 2\,\Re\left\{\frac{1}{a+j\omega}\right\} = \frac{2a}{a^2 + \omega^2}$$

与例 4.2 的直接积分结果一致，但计算量大幅减少——这是性质的核心价值。

# 4.3.4 微分与积分

## 微分

$$\frac{dx(t)}{dt} \xleftrightarrow{\mathfrak{F}} j\omega X(j\omega) \tag{4.31}$$

从综合方程两边对 $t$ 求导直接得到。**时域微分 = 频域乘 $j\omega$**。

**重要应用**：将微分方程变为代数方程。这是 4.7 节用傅里叶变换分析 LTI 系统（由线性常系数微分方程描述）的核心工具——类似于拉普拉斯变换中 $s$ 的角色，$j\omega$ 在此起同样作用。

## 积分

$$\int_{-\infty}^{t} x(\tau) d\tau \xleftrightarrow{\mathfrak{F}} \frac{1}{j\omega} X(j\omega) + \pi X(0) \delta(\omega) \tag{4.32}$$

积分不仅对应除以 $j\omega$（微分的逆操作），还多出冲激项 $\pi X(0)\delta(\omega)$。

**冲激项的物理含义**：积分可能产生非零的直流分量（积分器的输出可能趋向一个常数）。$X(0) = \int x(t)dt$ 正是 $x(t)$ 的净面积——若 $x(t)$ 面积不为零，积分 $\to \infty$ 时输出含非零均值，对应频域 $\omega = 0$ 处的冲激。

当 $X(0) = 0$（信号净面积为零）时，冲激项消失，积分 = 纯除以 $j\omega$。

## 例 4.11：单位阶跃的傅里叶变换

$u(t) = \int_{-\infty}^t \delta(\tau)d\tau$，已知 $\mathcal{F}\{\delta(t)\} = 1$：

$$u(t) \xleftrightarrow{\mathfrak{F}} \frac{1}{j\omega} + \pi\delta(\omega) \tag{4.33}$$

验证：对 $u(t)$ 求导应回到 $\delta(t)$ → $j\omega[1/(j\omega) + \pi\delta(\omega)] = 1 + 0 = 1$，与 $\delta(t) \leftrightarrow 1$ 一致。

## 例 4.12：微分→简化→积分的工作流

对复杂分段线性信号 $x(t)$：先求导 $g(t) = dx/dt$（得到简单脉冲），写出 $G(j\omega)$，再用积分性质恢复 $X(j\omega) = G(j\omega)/j\omega + \pi G(0)\delta(\omega)$。此处 $G(0) = 0$（导数净面积为零），冲激项消失。

结果 $X(j\omega)$ 为纯虚奇函数 → 与 $x(t)$ 为实奇函数一致（4.3.3 节对称性）。

# 4.3.5 时间和频率尺度变换

$$x(at) \xleftrightarrow{\mathfrak{F}} \frac{1}{|a|} X\left(\frac{j\omega}{a}\right) \tag{4.34}$$

其中 $a$ 为非零实数。

## 时-频反向关系（正式陈述）

| $a$ | 时域 | 频域 | 幅度 |
|---|---|---|---|
| $a > 1$ | 压缩 | 展宽 | $\downarrow$ (乘 $1/a$) |
| $0 < a < 1$ | 展宽 | 压缩 | $\uparrow$ (乘 $1/a$) |
| $a = -1$ | 反转 | 反转 | 不变 |

**物理直觉**：快速变化的信号（时域窄）→ 高频成分丰富（频域宽）；缓慢变化的信号（时域宽）→ 频谱集中在低频（频域窄）。两者乘积受约束——类似于量子力学的不确定原理。

类比：磁带快放（$a > 1$）→ 音调变高（频谱展宽）；慢放（$0 < a < 1$）→ 音调变低沉（频谱压缩）。

## 时间反转

$$x(-t) \xleftrightarrow{\mathfrak{F}} X(-j\omega) \tag{4.35}$$

$a = -1$ 的特例。时域反转 $\Rightarrow$ 频域反转。若 $x(t)$ 为实信号，$X(-j\omega) = X^*(j\omega)$（4.3.3 节），则 $x(-t) \leftrightarrow X^*(j\omega)$。

## 与前文的呼应

尺度变换性质为之前观察到的所有时-频反向现象提供了统一的数学解释：
- 例 4.4/4.5：脉冲宽度 $T_1 \uparrow$ → sinc 主瓣 $\propto 1/T_1 \downarrow$
- 例 4.5 图 4.11：$W \uparrow$ → 时域主峰变窄变高，极限 $W \to \infty$ 退化为 $\delta(t)$
- 例 4.8：时域冲激间隔 $T \uparrow$ → 频域冲激间隔 $2\pi/T \downarrow$

在通信系统中，这一性质是**带宽与符号速率基本折中**的根源：符号速率越高（时域越窄）→ 所需带宽越大。

# 4.3.6 对偶性

## 原理

分析方程与综合方程的形式高度对称——仅差 $1/2\pi$ 因子和指数符号：

$$x(t) = \frac{1}{2\pi} \int X(j\omega) e^{j\omega t} d\omega, \quad X(j\omega) = \int x(t) e^{-j\omega t} dt$$

因此每个傅里叶变换对都对应一个**对偶对**——交换 $t$ 和 $\omega$ 的角色，并调整 $2\pi$ 因子。

## 矩形脉冲 ↔ sinc：最经典的对偶

|---|---|---|
| 时域 | 矩形脉冲 | sinc 函数 |
| 频域 | sinc 函数 | 矩形脉冲 |
| 对偶操作 | $t \leftrightarrow \omega$，乘 $2\pi$ | |

## 使用对偶性的方法：例 4.13

已知 $e^{-|t|} \leftrightarrow 2/(1+\omega^2)$（例 4.2），求 $g(t) = 2/(1+t^2)$ 的傅里叶变换。

**步骤**：
1. 写出已知变换对的综合方程
2. 两边乘 $2\pi$，替换 $t \to -t$
3. 交换变量名 $t \leftrightarrow \omega$
4. 识别右侧为 $g(t)$ 的分析方程

结果：$\mathcal{F}\{2/(1+t^2)\} = 2\pi e^{-|\omega|}$。

## 对偶性导出的三个新性质

每个时域性质对应一个频域对偶：

**频域微分（对偶于时域微分 4.31）**：

$$-jt\,x(t) \xleftrightarrow{\mathfrak{F}} \frac{dX(j\omega)}{d\omega} \tag{4.40}$$

时域乘 $-jt$ ↔ 频域微分。

**频移 / 调制（对偶于时移 4.27）**：

$$e^{j\omega_0 t} x(t) \xleftrightarrow{\mathfrak{F}} X(j(\omega - \omega_0)) \tag{4.41}$$

⚡ 这是**调制**的数学基础——时域乘复指数 = 频谱搬移 $\omega_0$。结合 Euler 公式，$x(t)\cos\omega_0 t \leftrightarrow \frac{1}{2}[X(j(\omega-\omega_0)) + X(j(\omega+\omega_0))]$，即将基带频谱搬移到 $\pm\omega_0$。→ 第 8 章正弦调制系统。

**频域积分（对偶于时域积分 4.32）**：

$$-\frac{1}{jt}x(t) + \pi x(0)\delta(t) \xleftrightarrow{\mathfrak{F}} \int_{-\infty}^{\omega} X(\eta) d\eta \tag{4.42}$$

# 4.3.7 Parseval 关系

$$\int_{-\infty}^{+\infty} |x(t)|^2 dt = \frac{1}{2\pi} \int_{-\infty}^{+\infty} |X(j\omega)|^2 d\omega \tag{4.43}$$

## 物理含义

等式左边 = 信号总能量（时域），右边 = 频域能量积分。能量守恒——能量可以在时域算，也可以在频域算，结果相同。

$|X(j\omega)|^2$ 称为**能量密度谱**（energy-density spectrum），描述能量在各频率上的分布——单位频率的能量为 $|X(j\omega)|^2 / 2\pi$。

这与周期信号的 Parseval 关系（式 3.67）完全对应：周期信号的平均功率 = 各谐波平均功率之和 = $\sum |a_k|^2$。$|a_k|^2$（离散功率谱）↔ $|X(j\omega)|^2$（连续能量密度谱）。

→ 通信原理中，$|X(j\omega)|^2$ 即为能量谱密度 $G(f)$，是 Wiener-Khinchin 定理（[[通信原理/第2章-确知信号#2.2.3 能量信号的能量谱密度|通信原理 2.2.3]]）的核心。

## 例 4.14：从频域直接计算时域量

对给定的 $X(j\omega)$（图 4.18），不经过逆变换求 $x(t)$，直接用性质计算：

- **能量** $E$：用 Parseval，$E = \frac{1}{2\pi} \int |X(j\omega)|^2 d\omega$（频域面积）
- **$t=0$ 处导数** $D = dx/dt|_{t=0}$：$D = g(0) = \frac{1}{2\pi} \int G(j\omega) d\omega = \frac{1}{2\pi} \int j\omega X(j\omega) d\omega$

这展示了性质的实用价值：许多时域特征可直接从 $X(j\omega)$ 读出，无需先求 $x(t)$。

# 4.4 卷积性质

## 核心结论

$$y(t) = h(t) * x(t) \xleftrightarrow{\mathfrak{F}} Y(j\omega) = H(j\omega) X(j\omega) \tag{4.56}$$

**时域卷积 ↔ 频域乘积**。这是傅里叶变换在 LTI 系统分析中最重要的一条性质。

## 两种推导

**推导一（直观）**：将 $x(t)$ 视为傅里叶级数的极限（$T \to \infty$），每个复指数分量 $e^{jk\omega_0 t}$ 是 LTI 系统的特征函数 → 输出各分量被 $H(jk\omega_0)$ 缩放 → 极限回到积分 → $Y(j\omega) = H(j\omega)X(j\omega)$。

**推导二（形式化）**：从卷积积分出发，交换积分次序，用时移性质识别内层积分为 $e^{-j\omega\tau}H(j\omega)$：

$$Y(j\omega) = \int x(\tau) \left[ \int h(t-\tau) e^{-j\omega t} dt \right] d\tau = \int x(\tau) e^{-j\omega\tau} H(j\omega) d\tau = H(j\omega) X(j\omega)$$

## 频率响应 $H(j\omega)$

$H(j\omega) = \mathcal{F}\{h(t)\}$ 即频率响应（已在 3.8 节以 $H(jk\omega_0)$ 的形式引入，此处推广到连续频率）。

**三种等价描述 LTI 系统的方式**：
1. 冲激响应 $h(t)$（时域卷积）
2. 频率响应 $H(j\omega)$（频域乘积）
3. 线性常系数微分方程（4.7 节）

**级联系统**：$H(j\omega) = H_1(j\omega) H_2(j\omega)$（乘积，与顺序无关）。频域描述使级联分析极为简洁——卷积变乘积。

> 【插入 Oppenheim 图 4.19】三个等价的 LTI 系统表示

## 存在条件

$H(j\omega)$ 的存在性等价于 $h(t)$ 的傅里叶变换存在性。**稳定 LTI 系统**（$\int |h(t)| dt < \infty$，绝对可积）→ 满足 Dirichlet 条件 → $H(j\omega)$ 存在。不稳定系统需用拉普拉斯变换（第 9 章）。

## 例 4.15–4.17：基本系统的频率响应

三个基本 LTI 系统的 $H(j\omega)$ 可直接从 4.3 节的性质读出：

|---|---|---|---|

## 例 4.18：理想低通滤波器

$$H(j\omega) = \begin{cases} 1, & |\omega| < \omega_c \\ 0, & |\omega| > \omega_c \end{cases}$$

逆变换：$h(t) = \frac{\sin\omega_c t}{\pi t}$（sinc 函数，来自例 4.5）。

## 例 4.19：用频域法计算卷积

输入 $x(t) = e^{-bt}u(t)$，系统 $h(t) = e^{-at}u(t)$。不直接做卷积积分，而是：

1. $X(j\omega) = 1/(b+j\omega)$，$H(j\omega) = 1/(a+j\omega)$
2. $Y(j\omega) = 1/[(a+j\omega)(b+j\omega)]$（频域乘积）
3. **部分分式展开**（见附录）→ $Y(j\omega) = \frac{1}{b-a}\left[\frac{1}{a+j\omega} - \frac{1}{b+j\omega}\right]$
4. 逐项识别逆变换 → $y(t) = \frac{1}{b-a}[e^{-at} - e^{-bt}] u(t)$

当 $b = a$（重根）：$Y(j\omega) = 1/(a+j\omega)^2$，用频域微分性质（式 4.40）→ $y(t) = te^{-at} u(t)$。

**工作流**：时域卷积 $\xrightarrow{\mathcal{F}}$ 频域乘积 $\xrightarrow{\text{部分分式}}$ 简单项求和 $\xrightarrow{\mathcal{F}^{-1}}$ 时域输出。这个流程在 LTI 系统分析中反复使用。

## 例 4.20：sinc 卷积 sinc = sinc

$x(t) = \frac{\sin\omega_i t}{\pi t}$（频谱 = 宽度 $\omega_i$ 的矩形），$h(t) = \frac{\sin\omega_c t}{\pi t}$（频谱 = 宽度 $\omega_c$ 的矩形）。

频域：两个矩形相乘 → 结果矩形宽度 = $\min(\omega_i, \omega_c)$。

$$y(t) = \frac{\sin(\min(\omega_i, \omega_c) \cdot t)}{\pi t}$$

这展示了卷积性质的威力：两个 sinc 函数的时域卷积极为繁琐，但频域就是两个矩形相乘——平凡到只需取较小者。

# 4.5 相乘性质

## 核心结论

$$r(t) = s(t) p(t) \xleftrightarrow{\mathfrak{F}} R(j\omega) = \frac{1}{2\pi} \int_{-\infty}^{+\infty} S(j\theta) P(j(\omega - \theta)) d\theta = \frac{1}{2\pi} [S * P](j\omega) \tag{4.70}$$

**时域相乘 ↔ 频域卷积**。这是卷积性质（4.4 节）的对偶——通过 $t \leftrightarrow \omega$ 对换即可从卷积性质得到。

又称**调制性质**（modulation property），因时域相乘在通信中对应幅度调制。

## 例 4.21：正弦幅度调制

$p(t) = \cos\omega_0 t$，$P(j\omega) = \pi\delta(\omega-\omega_0) + \pi\delta(\omega+\omega_0)$：

$$r(t) = s(t) \cos\omega_0 t \xleftrightarrow{\mathfrak{F}} R(j\omega) = \frac{1}{2} S(j(\omega-\omega_0)) + \frac{1}{2} S(j(\omega+\omega_0)) \tag{4.71}$$

⚡ 基带频谱 $S(j\omega)$ 被**搬移**到 $\pm\omega_0$，幅度减半。全部信息保留——只是换到更高的频率位置。这是所有正弦幅度调制系统的数学基础。

# 4.5.1 可变中心频率的选频滤波

## 问题

传统带通滤波器：要改变中心频率 $\omega_c$ → 需同时调整多个元件值（R、C 等），难以精确跟踪。替代方案：**固定低通滤波器 + 频谱搬移**。

## 方案（复指数载波）

系统结构：

$$x(t) \xrightarrow{\times e^{j\omega_c t}} y(t) \xrightarrow{\text{LPF}(\omega_0)} w(t) \xrightarrow{\times e^{-j\omega_c t}} f(t)$$

- 第一步：$x(t)$ 频谱右移 $\omega_c$ → $Y(j\omega) = X(j(\omega-\omega_c))$
- 第二步：低通滤波（截止 $\omega_0$）→ 仅保留 $X(j\omega)$ 中原来在 $\omega_c$ 附近的频率分量
- 第三步：频谱左移 $\omega_c$ → 回到原位

等效效果：中心频率 $-\omega_c$、带宽 $2\omega_0$ 的理想带通滤波器。

改变 $\omega_c$ = 转动振荡器频率旋钮 → 带通滤波器中心频率随之改变——无需触碰任何滤波器元件。

> 【插入 Oppenheim 图 4.26-4.28】系统框图和频谱演化，等效带通滤波器

## 实信号情况

取 $f(t)$ 的实部 → 频谱关于 $\omega=0$ 对称 → 等效于中心频率在 $\pm\omega_c$ 的双边带通滤波器（图 4.29-4.30）。

也可用正弦调制（$\cos\omega_c t$）代替复指数——见习题 4.46。

# 4.7 由线性常系数微分方程描述的 LTI 系统

## 核心方法

对微分方程两边取傅里叶变换，利用微分性质 $d^k/dt^k \leftrightarrow (j\omega)^k$，将微分方程变为代数方程。

系统方程：

$$\sum_{k=0}^N a_k \frac{d^k y(t)}{dt^k} = \sum_{k=0}^M b_k \frac{d^k x(t)}{dt^k} \tag{4.72}$$

取傅里叶变换（线性 + 微分性质）：

$$Y(j\omega) \left[ \sum_{k=0}^N a_k (j\omega)^k \right] = X(j\omega) \left[ \sum_{k=0}^M b_k (j\omega)^k \right]$$

$$\boxed{H(j\omega) = \frac{Y(j\omega)}{X(j\omega)} = \frac{\sum_{k=0}^M b_k (j\omega)^k}{\sum_{k=0}^N a_k (j\omega)^k}} \tag{4.76}$$

**频率响应是 $(j\omega)$ 的有理函数**——分子系数 = 方程右侧系数 $\{b_k\}$，分母系数 = 方程左侧系数 $\{a_k\}$。可直接从微分方程**目视写出** $H(j\omega)$。

## 例 4.24：一阶系统

$$\frac{dy}{dt} + ay = x, \quad a > 0$$

$$H(j\omega) = \frac{1}{j\omega + a}$$

对比表 4.2 → $h(t) = e^{-at}u(t)$（例 4.1 的逆）。

## 例 4.25：二阶系统

$$\frac{d^2 y}{dt^2} + 4\frac{dy}{dt} + 3y = \frac{dx}{dt} + 2x$$

$$H(j\omega) = \frac{j\omega + 2}{(j\omega+1)(j\omega+3)} = \frac{1/2}{j\omega+1} + \frac{1/2}{j\omega+3}$$

部分分式展开 → $h(t) = \frac{1}{2}[e^{-t} + e^{-3t}]u(t)$。

## 例 4.26：用频域法解微分方程

同一系统，输入 $x(t) = e^{-t}u(t)$。频域求解流程：

$$Y(j\omega) = H(j\omega)X(j\omega) = \frac{j\omega + 2}{(j\omega+1)^2(j\omega+3)}$$

部分分式展开（含重根项 $(j\omega+1)^{-2}$）→ 三个简单分式 → 逐项逆变换：

$$y(t) = \left[\frac{1}{4}e^{-t} + \frac{1}{2}te^{-t} - \frac{1}{4}e^{-3t}\right]u(t)$$

## 方法总结

用傅里叶变换求解常系数微分方程的完整流程：

1. 从微分方程目视写出 $H(j\omega)$（式 4.76）
2. $Y(j\omega) = H(j\omega)X(j\omega)$（若给定输入）
3. 部分分式展开 $Y(j\omega)$ 为 $\sum A/(j\omega+p_i)^n$ 形式
4. 查表 4.2 → 逐项逆变换 → $y(t)$

**频域法的优势**：将求解微分方程（微积分运算）转化为代数运算（多项式因式分解 + 部分分式 + 查表）。这是傅里叶变换在 LTI 系统分析中最实用的能力之一。

⚡ 注意：此方法要求系统的频率响应存在（即系统稳定，$h(t)$ 绝对可积）。不稳定系统需拉普拉斯变换（第 9 章）。
