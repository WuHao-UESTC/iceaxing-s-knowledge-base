# CLAUDE.md — IELTS 口语语料库

## 项目概述

这是一个面向雅思口语备考的语料库，以 Obsidian 知识库的形式组织。每个话题一个独立的 Markdown 文件，聚焦 **地道表达**（英式/美式均可），从词汇、句式、文化背景三个维度拆解，并附带实战语料。

## 核心原则

### 表达地道性
- 英式表达和美式表达均可收录，但**必须在同一语境下保持一致**（不要在同一段回答中混搭口音特色词汇）
- 优先收录 **collocations（搭配）** 而非孤立单词
- 标注正式度：`formal` / `neutral` / `informal` / `slang`
- 标注使用场景：Part 1 / Part 2 / Part 3 的适用性
- 标注地域属性：`🇬🇧 英式` / `🇺🇸 美式` / `🌐 通用`

### 实用性优先
- 每个表达都必须配 **例句**，例句要贴近真实口语场景
- 句式模板要 **可替换、可组合**，用 `___` 标记可替换部分
- 文化背景要解释 **为什么不这么说** 或 **为什么这么说更地道**，而非单纯罗列知识点

## 文件组织结构

```
口语语料库/
├── CLAUDE.md              ← 本文件
├── 万能工具箱.md            ← 连接词、填充词、习语、发音陷阱、救场句式
├── TopicA.md              ← 用户指定的话题文件
├── TopicB.md
└── ...
```

- 扁平结构，所有话题文件放在根目录
- 文件名即话题名（英文，如 `Education.md`、`Travel.md`）
- 通过 Obsidian 的 `[[]]` 双向链接关联相关话题

## 标签系统

### 按考试部分
- `#part1` — 日常对话，简短回答，个人化
- `#part2` — 连续独白 1-2 分钟，描述+叙事
- `#part3` — 抽象讨论，分析+论证

### 按难度
- `#基础` — 常用表达，6.0 以下目标
- `#进阶` — 地道搭配/习语，6.5+ 目标

### 按内容类型（用于万能工具箱）
- `#词汇` `#句式` `#文化背景` `#实战语料`

## 用户交互模式

1. **用户给出话题**（英文或中文），由 Claude 创建对应的话题文件
2. Claude 负责：搜索地道表达、整理词汇搭配、编写句式模板、挖掘文化背景、撰写实战语料
3. 每个话题文件独立完整，可通过 `[[]]` 链接交叉引用
4. 用户可随时要求补充、修改某个话题文件

## 质量标准

### 词汇
- 每个话题至少 15-20 个核心词汇/短语
- 必须有例句，不能只列单词
- 优先收录 collocations 和 phrasal verbs

### 句式
- 每个 Part 至少 3-5 个句式模板
- 句式之间形成梯度（从基础到进阶）
- 标注可替换位置 `___`

### 文化背景
- 至少 3-5 个中式英语陷阱
- 解释"为什么"，而不只是"对/错"

### 实战语料
- Part 1：至少 2 组 Q&A
- Part 2：至少 1 篇完整范例
- Part 3：至少 2 组 Q&A
- 融入本话题的词汇和句式

### 表达收录优先级
1. 高频、实用、能在多个话题间复用
2. 有英美文化特色的地道表达
3. 中国考生容易用错或不熟悉的表达
4. 能让回答听起来更自然、更"不像背的"
