# 三、中式英语陷阱 & 常见误用

## 3.1 直译型错误

| ❌ 中式表达 | ✅ 地道表达 | 为什么 |
|------------|------------|--------|
| I very like it. | I really like it. / I like it a lot. | "我很喜欢" 的 "很" 不能用 very 修饰动词 like |
| My English is poor. | My English isn't great. / I'm still working on my English. | poor 在英语中过于消极/重，口语中英国人倾向于用 understatement |
| I have something to do. | I've got something on. / I'm tied up. | "我有事" 的地道说法，不是字面翻译 |
| I am so hot. (想说天气热) | It's so hot. / I'm boiling. | "I am so hot" 在英语中可能被误解为 "我很性感" |
| He is a Chinese. | He is Chinese. | 国籍形容词前不加 a/an |
| I went there with my classmates. | I went there with some friends from school. | classmates 在非正式口语中太少用，friends from school/university 更自然 |
| The price is expensive. | It's expensive. / The price is high. | price 本身不能 expensive，是东西 expensive |
| I want to learn more knowledge. | I want to learn more. / gain more knowledge. | learn knowledge 是中式搭配，应说 gain/acquire knowledge |
| I'm living in a school dormitory. | I live in halls. / I'm in student accommodation. | dormitory 太正式，英国用 halls of residence / halls，美国用 dorm |
| Yesterday night. | Last night. | 英语没有 yesterday night 这个搭配 |

## 3.2 语气 & 礼貌陷阱

| ❌ 中式表达 | ✅ 地道表达 | 为什么 |
|------------|------------|--------|
| Give me a cup of coffee. | Could I get a coffee, please? | 英语祈使句直接提要求显得粗鲁，必须用疑问句/间接请求 |
| I want to ask you a question. | I was wondering if I could ask you something. | 英国人尤其是间接表达的高端玩家，"I was wondering" 是标配 |
| No, I don't think so. (对考官) | I'm not sure I agree entirely. / I see what you mean, but... | 直接用 No 否定考官显得对抗性太强，要 soften |
| Wait a moment. | Just a sec. / Bear with me. / Give me a second. | Wait 在英语中比在中文中更生硬 |
| You are wrong. | I'm not sure that's quite right. / That might not be the case. | 直接说 "你错了" 在英语对话中非常 offensive |

## 3.3 过度正式 & 书面语陷阱

| ❌ 考试中说出来怪怪的 | ✅ 更自然的口语替代表达 |
|---------------------|----------------------|
| Moreover / Furthermore | Plus / Also / On top of that / What's more |
| Consequently / As a result | So / Because of that |
| In my opinion (每句话开头都用) | I'd say... / For me... / Personally, I reckon... / I feel like... |
| I would like to... | I'd like to... (口语必须缩写，不缩写听起来像在朗读) |
| It is widely acknowledged that... | Most people would agree that... |
| I am of the opinion that... | I think / I reckon / I'd say |

## 3.4 常见语法小坑

| 问题 | 例句对比 |
|------|---------|
| 可数/不可数名词 | ❌ a good news → ✅ some good news / good news |
| 冠词缺失 | ❌ I am student → ✅ I'm a student |
| 第三人称单数遗忘 | ❌ He go to school → ✅ He goes to school |
| 时态混乱 | ❌ Yesterday I go to... → ✅ Yesterday I went to... |
| there be 句型 + have 混用 | ❌ There has a park → ✅ There is a park |
| will 与 be going to 不分 | 临时决定用 will（I'll grab a coffee），计划用 going to（I'm going to visit my parents） |

# 四、发音要点速查（针对中文母语者）

## 4.1 元音陷阱

| 音标 | 常见错误 | 正确发音要点 | 对比词对 |
|------|---------|-------------|---------|
| /ɪ/ vs /iː/ | 把短元音读成长元音 | /ɪ/ 短促有力，下巴不动 | ship /iː/ → sheep /ɪ/ (你读反了！ship 是短的) |
| /æ/ vs /e/ | 分不清 cat 和 ket | /æ/ 嘴巴张大，舌头下压 | man /men/ vs men /mɛn/ |
| /ʌ/ vs /ɑː/ | 把 bus 读成 "巴斯" | /ʌ/ 嘴自然微开，舌中平 | bus /bʌs/ vs bath /bɑːθ/ (英式) |
| /ʊ/ vs /uː/ | 把 short /ʊ/ 拉太长为 /uː/ | /ʊ/ 嘴唇微圆但不要向前噘太多 | full /fʊl/ vs fool /fuːl/ |
| /ə/ (schwa) | 把弱读都读成拼音"a" | 完全放松的口腔中央音 | about /əˈbaʊt/, teacher /ˈtiːtʃə/ |
| /ɜː/ | 读成拼音"e" | 舌头平放，嘴唇不圆，稍拉长 | bird /bɜːd/, world /wɜːld/ |

## 4.2 辅音陷阱

| 音标 | 常见错误 | 正确发音要点 | 对比词对 |
|------|---------|-------------|---------|
| /θ/ (th) | 读成 /s/ 或 /t/ | 舌尖放在上下齿之间，气流从舌齿缝挤出 | think /θɪŋk/ ≠ sink /sɪŋk/ |
| /ð/ (th) | 读成 /d/ 或 /z/ | 和 /θ/ 一样的舌位但声带振动 | this /ðɪs/ ≠ dis /dɪs/ |
| /v/ | 读成 /w/ | 上齿接触下唇，声带振动 | very /ˈveri/ ≠ wery |
| /w/ | 读成 /v/ | 双唇收圆但不碰牙齿 | wet /wet/ ≠ vet /vet/ |
| /z/ | 读成 /s/ (清化) | /z/ 声带振动 | prize /praɪz/ ≠ price /praɪs/ |
| /ʒ/ | 读成 /r/ 或 /dʒ/ | 类似中文"日"但舌位更高 | usually /ˈjuːʒuəli/ |
| /l/ (dark L) | 读成 /o/ 或直接省略 | 词尾 l 舌尖顶住上齿龈 | well /wel/, people /ˈpiːpəl/ |
| /n/ vs /ŋ/ | n 和 ng 不分 | /ŋ/ 舌后部抬起堵住软腭 | thin /θɪn/ vs thing /θɪŋ/ |
| /r/ | 读成中文"日" | 舌尖不碰任何地方，舌头卷起但不接触 | red /red/ (舌尖不碰上颚) |

## 4.3 重音 & 节奏

| 要点 | 说明 | 例子 |
|------|------|------|
| 单词重音 | 英语单词重音位置不固定，需要单独记忆 | DEvelop (不是 deVElop), INteresting (不是 interesTING) |
| 句子重音 | 内容词（名/动/形/副）重读，功能词（冠/介/代/助动）弱读 | I **went** to the **shop** to **buy** some **milk**. |
| 连读 (linking) | 辅音+元音连读 | an apple → /əˈnæpəl/ |
| 同化 (assimilation) | 相邻音互相影响 | Would you → /wʊdʒuː/ (d + y → dʒ) |
| 弱读 (weak forms) | 功能词在句中变弱读 | to → /tə/ (不是 /tuː/), for → /fə/ (不是 /fɔː/), and → /ən/ 或 /n/ |

## 4.4 常见被读错的单词

| 单词 | 正确音标 | 常见错误 |
|------|---------|---------|
| comfortable | /ˈkʌmftəbəl/ | 读成 comfort-table（只有三个音节！） |
| vegetable | /ˈvedʒtəbəl/ | 读成 vege-table（三个音节，不是四个） |
| clothes | /kləʊðz/ | 读成 cloths /klɒθs/ （/ðz/ 不要省） |
| colleague | /ˈkɒliːɡ/ | 读成 college /ˈkɒlɪdʒ/ |
| idea | /aɪˈdɪə/ | 词尾加 r 音（idea 没有 r！） |
| photography | /fəˈtɒɡrəfi/ | 重音在第二音节，重音不对整个节奏就歪了 |
| island | /ˈaɪlənd/ | s 不发音！ |
| iron | /aɪən/ | r 不发音！（英式） |
| Wednesday | /ˈwenzdeɪ/ | 第一个 d 不发音 |
| suggestion | /səˈdʒestʃən/ | gg 读 /dʒ/ 不是 /ɡ/ |

# 五、救场万能句式（When You're Stuck）

## 5.1 没听清 / 需要重复

| 句式 | 使用场景 |
|------|---------|
| Sorry, could you say that again? | 标准请求重复 |
| Sorry, I didn't quite catch that. | 比 didn't hear 更自然 |
| Could you rephrase the question, please? | 不是没听见，是没听懂措辞时用 |
| Just to clarify, are you asking about ___? | 用自己的话复述以确认理解 |
| Do you mean ___ or ___? | 主动缩小范围 |

## 5.2 完全不知道答案

| 句式 | 使用场景 |
|------|---------|
| I'm not particularly familiar with ___, but if I had to guess, I'd say... | 承认不熟悉但仍尝试回答 |
| I haven't given it much thought, but off the top of my head... | 诚实 + 即兴 |
| To be honest, I don't know much about ___, but from what I've gathered... | 承认无知但有储备 |
| That's not something I've experienced firsthand, but I imagine... | 没亲身经历但可以推想 |

## 5.3 跑题了 / 说太多要拉回来

| 句式 | 使用场景 |
|------|---------|
| Anyway, to get back to the point... | 拉回话题 |
| I'm going off on a tangent here, but... | 意识到自己跑偏了 |
| Where was I? Oh yeah, ... | 自己打断自己后回来 |
| Long story short, ... | 发现时间不够了赶紧收尾 |

## 5.4 需要 1-2 秒缓冲（藏在小动作里）

| 句式 | 用法 |
|------|------|
| Hmm, that's interesting... | 边说边点头，争取 1 秒 |
| Let me put it this way... | 换个角度说的缓冲 |
| How shall I put it... | 最经典的英式缓冲 |
| Actually, now that I think about it... | 假装修正自己，实际在争取时间 |

# 六、Part 1 高频万能应答框架

## 6.1 喜好类问题
> Do you like ___?

```
直接回答 + 程度修饰 + 简短理由 + 对比/举例
"I do, yeah. I'm actually quite into ___, mainly because ___. Like, the other day I ___, and it was ___."
"I wouldn't say I'm a massive fan. I mean, it's fine, but I prefer ___ because ___."
```

## 6.2 频率类问题
> How often do you ___?

```
频率 + 具体情况 + 原因
"Pretty much every day, to be honest. It's become a bit of a habit at this point."
"Not as often as I'd like to, really. I'd say once in a blue moon, mainly because I'm always tied up with ___."
```

## 6.3 变化类问题
> Has ___ changed in recent years?

```
是的 + 具体变化 + 对比过去 + 个人态度
"Massively, yeah. It's almost unrecognisable compared to, say, five years ago. Back then ___, but now ___."
"Not drastically, no. It's more or less the same, although I suppose ___ has become a bit more ___."
```

# 七、Part 2 独白结构模板

## 7.1 通用时间线结构
```
开头句 → 背景(When/Where/Who) → 主体描述(3-4句) → 感受/意义 → 收尾句
```

## 7.2 开头句库
- I'd like to talk about ___, which is something that ___.
- The ___ I want to describe is ___, and it goes back to ___.
- If I had to pick one ___, it would definitely be ___.

## 7.3 收尾句库
- So yeah, that's pretty much the story.
- And that's basically why ___ means so much to me.
- So all in all, it was an experience I'll always remember.
